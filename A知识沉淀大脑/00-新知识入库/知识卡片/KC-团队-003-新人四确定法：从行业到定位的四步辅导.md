# 《新人四确定法：从行业到定位的四步辅导》

> **一句话本质**：新人迷茫不是因为不想做，而是四个"确定"没做完。行业→平台→目标→定位，一步不能跳。

---

## 🧩 因果 / 原理

**它解决了什么问题？**
新人加入后热情来得快去得也快——第一周打了鸡血，第二周不知道干啥，第三周就不见了。不是他不努力，是你没帮他完成"确定"的过程。

**为什么有效？**
四个确定是从外到内的层层锁定：

```
① 确定行业     →  看好趋势，建立信心（宏观）
② 确定平台     →  认可价值观，建立认同（中观）
③ 确定目标     →  有具体方向，建立动力（微观）
④ 确定定位     →  找到角色感，建立身份（内在）
```

每完成一个"确定"，新人就更稳一步。

---

## 🛠 可执行方法

### 第一步：确定大健康行业（解决"为什么做"）

帮新人看清趋势：
- 健康中国2035：人均预期寿命80岁以上
- 大健康产业2030年预计达29.1万亿
- "健康是1，其他都是后面的0"

**辅导动作**：带TA看一次OPP，看一段趋势数据，不是说服，是让TA自己看到。

### 第二步：确定安利这个平台（解决"跟谁做"）

传递安利的核心价值观：
- **"决定一个人的成功，不是赢了多少人，而是帮了多少人"**
- **"拥有自己的事业，即拥有改变人生的机会"**
- **"人类需要从植物中获取营养，而不是从药瓶中"**

**辅导动作**：让新人了解安利的企业文化，建立认同感。

### 第三步：确定想要的结果（解决"做到什么"）

帮新人设定清晰的目标阶梯：
```
先做0-1：帮助10个家庭 → 月收入4000
再做1-4：1万分 → 月收入1.5w → 年收入40~50w
复制4×4：年收入超100w → 被动收入
```

**辅导动作**：不是"你帮我定目标"，而是"你想要什么结果"——帮TA自己说出来。

### 第四步：确定定位与能量（解决"我是谁"）

帮新人建立创业者身份：
- **你是BOSS**，不是打工者
- **能量来自**：文化自信、种好种子、上不封顶的成长
- **发心**：爱在前，利在后——创业的本质是助人
- **连接**：把"你和我"变成"我们"

**辅导动作**：带TA做一次定位梳理——我是谁？我的优势是什么？我凭什么能做成？

## 📍 场景与边界

### 适用场景
- ✅ 新人刚加入，迷茫不知道从哪开始
- ✅ 新人热情消退，开始怀疑自己的选择
- ✅ 新人不行动，催了也没用

### 边界条件
- ⚠️ 四个确定要按顺序来——跳过"确定行业"直接"定目标"，根基不稳
- ⚠️ 不要替TA确定——辅导是引导，不是灌输
- ⚠️ 第四步最难——"定位"需要时间沉淀，不能急
- ⚠️ **在这四步之前，先过"两关"**——参见 [[A知识沉淀大脑/00-新知识入库/洞见卡/DJ-团队-009-培养自动播伙伴的两步根基：价值锚定+愿景强化|DJ-团队-009 两步根基]]。如果伙伴内心没真正相信"非安利不可"，前两步只是走形式
