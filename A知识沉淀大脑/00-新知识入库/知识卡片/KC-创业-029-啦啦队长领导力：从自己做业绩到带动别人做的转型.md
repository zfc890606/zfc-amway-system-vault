# 《啦啦队长领导力：从自己做业绩到带动别人做的转型》

> **一句话本质**：领导力不是你自己做多少业绩，而是你能激发多少人做业绩——从"我是主力"到"我是啦啦队长"的思维切换，是所有团队长的第一道分水岭。

---

## 🧩 因果 / 原理

**它解决了什么问题？**
很多新升领导的人最大的误区：觉得"我要做更多业绩来带动大家"。结果自己累死，伙伴闲死。带团队不是加法（你多做一份伙伴就多一份），是乘法（你帮10个人每人提升10%，总量就翻倍）。

**为什么有效？**
狄维士把自己定位成"啦啦队长"——不是上场打球的人，是让球员发挥最好状态的人。这个角色转换包含三个认知升级：

1. **价值来源变了**：你的价值不再来自你做了多少，来自你帮别人做了多少
2. **时间分配变了**：过去80%时间在自己业务上，现在80%时间在帮伙伴上
3. **成就感来源变了**：过去成就感来自自己的业绩数字，现在来自伙伴突破时的笑容

**核心原理公式**：
```
一个人做100% = 你一个人的力量
帮100人每人做10% = 10个人的力量
这就是领导力的乘法效应
```

---

## 🛠 可执行方法

### 最小行动（今天就能做）
打开你的日程表，算一下上周花在"帮伙伴"上的时间占比——如果低于40%，明天开始每天固定1小时只做帮伙伴的事。

### 完整执行步骤

1. **诊断自己的阶段**：你现在是在"自己下场做"还是"帮别人做"？诚实地写下上周时间分配
2. **80/20时间重置**：把80%的工作时间从"自己做"转向"帮伙伴做"
3. **发现式表扬**：每天观察每个伙伴，发现一件TA做对了的事，马上公开说出来
4. **潜力挖掘对话**：每周和一位伙伴单独聊，帮TA看到自己没意识到的优点——"你刚才那个说法特别好"
5. **乘法思维训练**：每次想"我来做更快"时，问自己："教会TA做，我能省出多少时间？"

## 📍 场景与边界

### 适用场景
- 从个人业绩者转型为团队领导者的关键时刻
- 团队规模3人以上，自己忙不过来的阶段
- 伙伴遇到瓶颈、缺乏信心的状态

### 边界条件
- **什么时候不适用？** 新人还在学习业务阶段（第1-3个月），应该先自己做出样子再谈带动
- **常见失败原因？** 不是"不做业绩只做啦啦队"——你仍然需要示范，但不能只自己做
- **需要什么前提条件？** 你至少有一套自己能跑通的业务流程，否则教不了别人
