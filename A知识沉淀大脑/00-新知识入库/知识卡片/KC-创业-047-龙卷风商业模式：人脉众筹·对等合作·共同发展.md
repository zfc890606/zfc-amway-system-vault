# KC-创业-047-龙卷风商业模式：人脉众筹·对等合作·共同发展

> **一句话本质**：龙卷风=人脉众筹——把几个人各自的人脉放到同一条线上共建一组市场，市场共用、各自独立算钱；一个人做市场靠死磕自己人脉，一群人众筹人脉则"人人都做一得五"，市场涨得飞快，一年卷一条线、三年卷三条线=百万年薪。

---

## 🧩 因果 / 原理

### 为什么一个人做得慢

```
靠一个人推市场 → 必须依赖你自己的资源/人脉
   ↓
资源有限、推动力单点
   ↓
一组12.5万市场很难快速做起来
```

### 龙卷风的解法：众筹人脉

```
A 把"我的人"放到 B 后面
B 把"我的人"放到 B 后面
C 把"我的人"放到 B 后面
B自己也放人
   ↓
同一条线，市场共用（是你的市场，也是他们的市场）
每个人各自独立算钱（互不干扰）
   ↓
团队营业额快速上21%（12.5万）
```

> 本质：**对等合作、共同发展**——不是谁帮谁，是大家共建一条线，人人都做一得五。

### 为什么能"三年百万年薪"

| 年份 | 动作 | 结果 |
|:---:|:---|:---|
| 第一年 | 卷起第一条线（稳12.5万/月） | 达标DD，不做也有 |
| 第二年 | 再找伙伴龙卷风卷第二条线 | 两组市场 |
| 第三年 | 卷第三条线 | 三组市场=营销经理≈百万年薪 |

### 与单打独斗的对比

| 维度 | 单打独斗 | 龙卷风 |
|:---|:---|:---|
| 资源 | 只用自己人脉 | 多人人脉众筹 |
| 速度 | 慢、难 | 市场很快上21% |
| 依赖 | 靠个人能力强 | 靠合作机制（人人可复制） |
| 分配 | 个人独立 | 市场共用但各自独立算钱 |

## 🛠 可执行方法

### 第一步：发起龙卷风

1. 选一条线（你自己做主力）
2. 把办卡二维码/邀请链接保存好，分给要合作的人
3. 各人把"想干的人"从自己链接办进来，落在同一条线下面
4. 一起教他们做市场（如各做6000），市场共用、各算各的账

### 节奏建议

- **先从第一条线卷起**，不贪多（不建议一上来开太多线，带不过来）
- 一条线里大概率出人才 → 有人看懂就继续往下发展
- 第二条线找另一个伙伴再龙卷风，第三条同理

### 常见问题

- "我的人放你后面，会不会吃亏？" → 市场是共用的，各自独立算钱，谁都不干扰谁的业绩
- "没那么多厉害的人怎么办？" → 大部分人都"不厉害"，龙卷风就是让普通人凑资源一起干
- "这是不是拉人头？" → 核心是共同把市场做起来、都有收入，助人自助

## 📍 场景与边界

**适用场景：**
- 团队内部动员（讲清楚"为什么一起干比单干快"）
- 新人快速做第一组市场的路径设计
- 招募有资源但不想自己单打独斗的伙伴

**注意事项：**
- 龙卷风是团队独有模型（华工系统/林伟博士设计），对外讲注意边界
- 前提是每个人都愿意贡献人脉并教会自己下面的人做市场
- 奖金按公司制度各自独立计算，不承诺具体收入
