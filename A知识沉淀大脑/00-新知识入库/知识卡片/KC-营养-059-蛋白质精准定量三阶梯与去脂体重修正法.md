# KC-营养-059-蛋白质精准定量三阶梯与去脂体重修正法

> **一句话本质**：
> 蛋白质是给肌肉和器官吃来修复的，不是给脂肪吃来维持的。计算修复量必须用**去脂体重（或校正体重）** 做基数，否则肥胖人群会过量摄入，加重肝肾负担。
>
> **出处**：ESPEN临床指南、ASPEN重症营养指南、中国DRIs 2023

---

## 🧩 因果 / 原理

### 核心矛盾

蛋白质主要由肌肉等瘦组织（去脂体重）代谢，脂肪细胞对蛋白质需求极低。直接用"实际体重"给高BMI人群计算蛋白质：

```
实际体重 100kg × 1.5g/kg = 150g/天  ← ❌ 错误，严重过量
去脂体重 60kg × 1.5g/kg = 90g/天   ← ✅ 正确
```

差60g/天——等于每天多吃了6勺蛋白粉，肝肾负担翻倍。

## 📊 三阶梯定量标准（来源：ESPEN + 中国DRIs）

| 阶梯 | 状态 | 每公斤体重系数 | 70kg成人参考 | 对应场景 |
|:----:|------|:-------------:|:----------:|---------|
| **① 维持量** | 健康成年人，无消耗 | 0.8~1.0 g/kg·d | 56~70g/天 | 日常保健·瓶身推荐量 |
| **② 修复量** | 慢性低度发炎/慢病修复/肌少症预防 | 1.2~1.5 g/kg·d | 84~105g/天 | 脂肪肝·三高·胰岛素抵抗·术后恢复 |
| **③ 强修量** | 严重消耗/肿瘤恶病质/ICU恢复 | 1.5~2.0 g/kg·d | 105~140g/天 | 重度肌少症·重症恢复·专业指导 |

> **⚠️ 关键区分**：RNI（0.8~1.0g/kg）是健康人的"饿不死"标准，修复量（1.2~2.0g/kg）是身体开始修的"装修"标准。

## 🔬 三种临床修正算法（针对超重/肥胖）

| 算法 | 公式 | 适用场景 | 精确度 |
|:----:|------|---------|:------:|
| **① 理想体重法** | IBW = 身高(cm) - 105 | 快速估算，没有体脂仪 | ★★★ |
| **② 校正体重法** | AjBW = IBW + 0.25×(实际体重 − IBW) | 临床最常用，兼顾脂肪多出的支撑肌肉 | ★★★★ |
| **③ 去脂体重法** | FFM = 体脂仪/生物电阻抗直接测量 | 金标准，精准到个人 | ★★★★★ |

**三种算法对比示例（身高170cm，体重100kg）：**

```
① 理想体重法：170-105 = 65kg → 修复量 65×1.5 = 97.5g/天
② 校正体重法：65 + 0.25×(100-65) = 73.75kg → 修复量 73.75×1.5 = 110.6g/天
③ 去脂体重法：实测 60kg → 修复量 60×1.5 = 90g/天
❌ 实际体重法：100×1.5 = 150g/天 → 严重过量！
```

## 📐 单餐分配原则（来源：mTOR通路机制）

肠道单次触发肌肉合成的最佳单餐摄入量：

| 指标 | 标准 |
|:----:|------|
| 单餐最佳 | 0.4 g/(kg·餐) |
| 成年人每餐 | 20~30g 优质蛋白 |
| 单餐上限 | 40g（超出部分被氧化掉，不用于修复） |

**实操口诀**：总定量 ÷ 3~4餐 = 每餐蛋白量。超过40g/餐就浪费。
