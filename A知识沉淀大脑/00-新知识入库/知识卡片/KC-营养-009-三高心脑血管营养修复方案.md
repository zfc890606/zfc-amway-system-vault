# KC-营养-009-三高心脑血管营养修复方案

> **一句话本质**：三高（高血压/高血脂/高血糖）本质是血管系统的代谢紊乱，核心修复路径是：控炎症+降血脂+护血管内皮。

---

## 🧩 因果 / 原理

三高不是三种独立的病，而是同一套系统出问题的不同表现：
- 血脂高 → 血管内壁沉积物增多（水垢）
- 血压高 → 血管压力增大（水压太大）
- 动脉硬化 → 血管弹性下降（水管变脆）

三者互相加重：血脂高→动脉硬化→血压高→血管损伤→更多沉积。

营养修复的核心逻辑（区别于药物）：
- 药物：强制降指标（阻断某个环节）
- 营养：提供修复原料让身体自己恢复平衡

## 🛠 可执行方案

**三高通用营养方案：**
- 每日基础：蛋白粉 + 维C + 鱼油 + 钙镁片
- 早餐：高蛋白启动代谢（蛋白粉饮+燕麦+坚果）
- 午餐：先吃蔬菜→再吃蛋白→最后主食（粗粮）
- 晚餐：睡前4小时吃完
- 鱼油降甘油三酯、茶族降胆固醇、钙镁调血压

## 📍 适用场景

- **脚本类型**：健康科普类、慢病营养类、产品方案类
- **目标人群**：有对应慢病困扰的30-65岁人群
- **风险提示**：营养辅助修复，非替代治疗，用药请遵医嘱
