# 《爆款词根库 — 基础选题 + 词根 = 爆款候选》

> **一句话本质**：爆款不是选题本身，是「基础选题 + 爆款词根」。词根是给普通选题加的"流量修饰语"，元素（人性底层）永远不变，词根（流行语）每年换。放到本系统 = 在「选题决策卡」之前加一道**选题生成器**，把一个痛点批量变成 3-5 个爆款候选，再筛出最好的那个拍。
>
> **本卡用法**：写脚本卡在"不知道拍啥"时打开 → 从痛点排行榜拿 1 个基础选题 → 按线别套词根 → 过选题决策卡 → 开写。

---

## 🧩 因果 / 原理

**它解决了什么问题？**
- 选题决策卡是"筛子"（判断一个题值不值得拍），但不会"造题"——卡住时容易拍脑袋或重复老套路。
- 词根库补上"造题"这一环：同一个基础选题，套不同词根 = 多个不同天花板的爆款候选。**选题来源从"等灵感"变"按公式生产"。**

**为什么有效？**
- 观众点进来的瞬间，看的不是"你这个选题我熟不熟"，而是"标题里有没有戳中我人性的那个词"。
- 8 大爆款元素 = 8 条人性的底层频道（省钱的 / 好奇的 / 看笑话的 / 慕强的 / 念旧的 / 爱美的 / 站队的 / 自省的）。词根 = 频道里当前最响的那个流行说法。
- 词根负责**把视频推进流量池**（拉新），身份独占负责**在池子里胜出**（涨粉）。两者相乘，就是 059（373K播放/5,671涨粉）的公式：`医生为什么不学营养`（词根=行业揭秘）× `只有医生能讲`（身份独占）。

## 🛠 可执行方法

### 最小行动（今天就能做）

从痛点排行榜随便拿 1 个 TOP 痛点，套 3 个词根，写出 3 个标题候选，每个想好「转给谁」。10 分钟，选题卡住的问题就解决了。

### 完整执行步骤（接入现有管线「①定选题」，放在选题决策卡之前）

```
第0步：从痛点排行榜拿1个基础选题
       例：#91「营养补充按瓶身吃够吗？」（基础题，还没爆款词根）
第1步：打开下方「双线词根库」，按线别（营养线/创业线）挑 2-3 个元素
第2步：每个元素套 1 个词根 → 写出 2-3 个爆款候选（含开头3秒）
       例：猎奇词根「医生为什么」→「医生为什么不让你按瓶身吃营养素？」
           最差词根「白花钱」→「按瓶身吃营养素，是最亏钱的做法」
           反差词根「医生自己」→「医生自己吃营养素，从来不按瓶身」
第3步：把候选过「选题决策卡」6问+8分 → 选最高分 1 个
第4步：开头3秒 = 把词根说人话（身份+事实双钩，照常走反常识观点开头）
第5步：写稿（照常：张医生式笃定 + 推进信息密度 + 文献锚点 + 个人味道）
第6步：质检照常（涨粉复核6要素 / 查重网关 / 医疗合规 / 星光违规解密）
```

> **核心心法：词根只管"进流量池"，不管"内容质量"。** 内容质量靠视频号脚本风格系统，选题天花板靠选题决策卡。079 的教训：内容指标全库顶级，但选题（蛋白质定量）天花板低，播放只有 5.5K——**词根别套在没有流量池的基础题上**。

### 词根换季规则（元素不变，词根每年换）

| 状态 | 定义 | 动作 | 实例 |
|:---:|------|------|------|
| 🔥 **在用** | 已验证、还有搜索量 | 系列化批量用 | `医生为什么XX`（059→082→061→067 一路涨） |
| ⚠️ **疲劳** | 用太多、观众免疫 | 升级同元素新词根 | `XX是不是智商税` 用了8次 → 升级为 `医生为什么XX` / `XX≠XX` / `药店vs安利` |
| ❌ **退役** | 流行语过时 | 删除，元素保留 | 2024年前的旧说法（如"三步就能……"式）→ 换新流行说法 |

> **铁律：元素（猎奇/成本/反差/最差/头牌/怀旧/荷尔蒙/争议/拷问）是底层功率，永不过时；词根是语言外衣，每年换。** 找新词根 = 去评论区/搜索框"偷听"用户最新原话（芒果TV偷听法）。

## 📍 场景与边界

### 适用场景
- **选题卡住时**：拿 1 个基础题，套词根批量出候选，不拍脑袋。
- **批量排期**：一次给 3-5 个痛点各套词根，排出整周选题。
- **系列化延展**：一个爆款词根（如`医生为什么`）横向复制到多个选题（059→082→061→067）。
- **换季更新**：发现同词根用太多次（⚠️疲劳）时，用同元素换新词根。

### 边界条件
- **词根不解决内容质量**：套了词根、内容还是平铺直叙 → 照样划走。词根只负责拉人进来，留人靠视频号脚本风格系统。
- **别套在没有流量池的基础题上**：词根放大的是"有人在搜"的题（079 教训）。
- **成交型脚本不用词根**：转化型内容用「成交型破题开头」（点人/点事/点钱），词根是流量型工具。
- **合规红线始终优先**：词根再好，过不了医疗合规/星光违规解密 → 换词根（收入承诺、副业诱导、医疗功效词等一律不碰）。
- **结论前置检测仍要过**：词根化的标题不能把答案说完（"鱼油不是智商税，是你买的方式错了"→ 删成"鱼油是不是智商税？90%的人买法都错了"）。
