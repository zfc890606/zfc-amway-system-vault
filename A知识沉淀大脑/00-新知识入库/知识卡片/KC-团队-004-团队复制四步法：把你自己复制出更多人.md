# 《团队复制四步法：把你自己复制出更多人》

> **一句话本质**：带团队不是一个人带一百个人，而是带出十个人，每个人再带十个人——复制的关键是你先做到，再教人做到，再看人做到，最后帮人做到。

---

## 🧩 因果 / 原理

**它解决了什么问题？**
很多团队长卡在"自己做可以，带人做就不会了"——因为TA一直在"替人做"，而不是"教人做"。TA累死了，伙伴没成长。

**为什么有效？**
复制四步法是渐进式放权的过程：

```
① 自己做 → 拿到结果（让人看到）
② 带着做 → 复制方法（让人学会）
③ 看着做 → 独立操作（让人做到）
④ 帮TA做 → 复制领导者（让人带人）
```

每一级都是上一级的升级——你在做的不是"做业务"，而是"做系统"。

---

## 🛠 可执行方法

### 第一步：自己做，拿到结果
- 你自己先做出成绩（说到做到才有力量）
- 先帮助10个家庭→拿到2000分→月收入4000
- **为什么这一步最重要？** 你自己没结果，你说的话没人信

### 第二步：带着做，复制方法
- 你做事的时候带着伙伴一起
- 做完一件事，给TA拆解"为什么这么做"
- 把你的方法写成标准动作（SOP）
- **关键**：不是"你帮TA做"，是"TA看你做，然后TA做一次"

### 第三步：看着做，独立操作
- 让伙伴自己上手做
- 你在旁边看，做对了夸，做偏了拉回来
- 逐步放手：先确认TA能独立完成一件事
- **关键**：忍住不插手——哪怕TA做得没你好，也要让TA自己做完

### 第四步：帮TA做，复制领导者
- 当伙伴自己能独立操作了，帮TA带人
- 让TA经历你走过的四步法：TA做→TA带人做→TA看人做→TA帮人带人
- **你的新角色**：从"带伙伴"变成"带伙伴的伙伴"

### 复制金字塔

```
          你
        ┌───┐
        │ 你 │             做→带→看→帮
       ┌┴───┴┐
       │  A  │  ← 你做→带→看→帮，A学会了
      ┌┴────┴┐
      │  B   │  ← A做→带→看→帮，B学会了
     ┌┴─────┴┐
     │  C    │  ← B做→带→看→帮，C学会了
     └───────┘
     指数级复制！
```

## 📍 场景与边界

### 适用场景
- ✅ 你觉得自己"什么事都要亲自上"
- ✅ 伙伴什么都等着你教、等着你做
- ✅ 团队规模大了，你一个人忙不过来
- ✅ 想培养骨干但不知道从哪开始

### 边界条件
- ⚠️ 第一步不能跳——你自己没结果，复制就是空话
- ⚠️ 第二步不能急——"看一遍就会"的人极少，要带着做几遍
- ⚠️ 第三步最难——管住自己的手，让伙伴犯错也是一种学习

### 常见失败原因
- 一直在第一步（永远自己做，累死）
- 跨过第二步（让新人直接干，摔死）
- 卡在第三步（不敢放手，伙伴长不大）
