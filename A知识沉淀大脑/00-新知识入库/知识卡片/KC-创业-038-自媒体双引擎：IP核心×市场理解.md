# 《自媒体双引擎：IP核心 × 市场理解》

> **一句话本质**：做好自媒体的本质不是单点技巧，而是两个引擎同时转——① 你有"自己的东西"（成长中认知拔高的点 = IP核心 = 选题金矿）② 你懂自媒体语言 + 调研市场（怎么表达才打动观众）。缺一个就跑不出去：专业但不懂市场没人看，懂市场但没IP核心立不住。

---

## 🧩 因果 / 原理

**它解决了什么问题？**
"我做了很久自媒体为什么没结果"——大多数人的诊断是"方法不对、技巧不够"，于是疯狂学拍摄、学剪辑、学话术，却忽略了一个更根本的问题：**你到底是"有东西但不会表达"，还是"会表达但没东西"？** 两个引擎缺一个，都是白费。

**为什么有效？**
1. **IP核心是根**：你成长中"脑袋打开"的那些点，是你真正经历、真正相信的东西，讲出来天然有力量，也是别人拿不走的差异化。这就是选题金矿。
2. **市场理解是翅膀**：同样的认知，用自媒体的语言讲、对着当下时代的观众讲，效果天差地别。选题要"怎么拍"，靠的是对市场的调研——什么表达能打动观众。
3. **缺一不可的机理**：专业但不懂市场 → 内容对但没人看（跑不出去）；懂市场但没有IP核心 → 有流量但立不住（没根）。两轮驱动才能跑成 IP。

### 核心逻辑链

```
做自媒体没结果
   │
   ├─ 没"自己的东西"？ → 认知拔高的点没记录/没沉淀 → 补：记录+提炼IP核心
   │
   └─ 懂市场吗？ → 不懂自媒体语言/没调研 → 补：学表达+调研市场
   │
   ▼
  两轮都转 → 有根又有翅膀 → IP 立得住、也跑得出去
```

---

## 🛠 可执行方法

### 最小行动（今天就能做）
翻开手机备忘录，把最近一次让你"脑袋打开"的那句话/那个认知记下来——**这就是你的第一个选题**。

### 完整执行步骤
1. **建认知拔高点清单**：凡是成长中让你认知拔高、脑袋打开的点，随手记下来 → 这就是你的选题金矿（IP核心素材库）
2. **选题双检**：每个选题问两遍——① 这是我的东西吗？换个人讲还成立吗？（IP核心）② 观众会因为哪一句停下来？（市场）
3. **先调研再写稿**：动手写之前，看当下同领域爆款怎么表达、目标观众在评论区问什么——不要自嗨式写稿
4. **按"怎么拍"表达**：用自媒体语言（痛点前置/反差/情绪/具体）把认知点讲出去，而不是写论文
5. **复盘归因**：数据不好时先判断——是"没根"（选题不是你的东西）还是"没翅膀"（表达不抓人）？对症下药，别盲目换方向

## 📍 场景与边界

### 适用场景
- 做自媒体很久没结果，不知道卡在哪
- 帮伙伴辅导选题：为什么你的视频没人看
- 内容定位模糊：不知道自己该讲什么

### 边界条件
- ⚠️ 不是"先有根再有翅膀"的线性顺序，而是两轮同步转、缺哪补哪
- ⚠️ "自己的东西"不等于"自嗨"——认知拔高的点也要经过市场检验（观众关心吗）
- ⚠️ 懂市场 ≠ 追热点，热点的壳要装自己认知的核，否则没根
- ⚠️ 不适合纯执行层场景（已有明确选题，只差拍摄技巧时，应调表现力类卡片）
