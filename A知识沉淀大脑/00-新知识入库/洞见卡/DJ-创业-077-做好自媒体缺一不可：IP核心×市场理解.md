# DJ-创业-077-做好自媒体缺一不可：IP核心×市场理解

> **一句话洞见**：做好自媒体 = 两个点缺一不可——① 你有"自己的东西"（成长中认知拔高的点 = 选题金矿）② 你懂自媒体语言 + 调研市场（怎么表达才打动观众）。专业但不懂市场跑不出去，懂市场但没有IP核心也没根。

---

## 🧩 因果 / 原理

做自媒体的人分两种失败：
- **很专业，但不懂市场** → 内容再对，表达打动不了观众，跑不出去；
- **懂市场，但没有自己的IP核心** → 会追热点会表达，但没自己的东西，立不住。

所以作为 IP 操盘手，核心只盯两件事：**自己的东西（根）× 市场的表达（翅膀）**，缺一不可。

而"自己的东西"从哪来？——**成长过程中让你认知拔高、脑袋打开的那个点**，把它记下来，就是天然的好选题。因为那是你真正经历、真正相信的东西，讲出来才有力量。

## 🛠 可用方法

- **建一个"认知拔高点"记录本**：凡是让你"脑袋打开"的时刻，随手记下来 → 这就是选题金矿
- **每个选题过两道检**：① 这是我的东西吗（IP核心）？② 用自媒体语言怎么表达、哪个点打动观众（市场）？
- **写之前先调研**：当下这个时代的自媒体怎么说话、什么表达最能打动目标观众——不要自嗨式写作
- **复盘时问自己**：这条是"专业但没人看"还是"有流量没根"？缺哪条补哪条

## 📍 适用场景

- **脚本类型**：认知颠覆型 / 个人叙事型
- **位置建议**：做"为什么我做了自媒体没结果"类选题的核心逻辑，或辅导伙伴找选题时用
