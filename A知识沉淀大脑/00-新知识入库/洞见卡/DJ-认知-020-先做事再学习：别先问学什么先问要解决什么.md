# DJ-认知-020 先做事再学习：别先问学什么，先问要解决什么

> **一句话洞见**：别一上来就问"学什么"，先问"**我现在要解决什么**"——先做事 → 遇到问题 → 找到缺口 → 再学需要的。学习是解决问题的副产品，不是起点。

---

## 🧩 因果 / 原理

**为什么"先学再做"会卡住？**
- 学了一堆，没地方用 → 忘得快，学完还是不会做
- 学习没有锚点，不知道什么有用什么没用

**为什么"先做再学"有效？**
- 做的过程中遇到真实问题 → 知识有了"挂钩"，学了立刻用 → 记住 + 用上
- 每个缺口都是精准的学习目标，不多学一分

**做完复盘三问：**
```
① 为什么能解决？
② 哪一步最关键？
③ 下次能不能复用？
```

---

## 🛠 可用方法

### 最小行动
想做新东西时，先干一件最小的事（发一条视频 / 做一次客户沟通），卡住了再针对性地学。

### 完整执行步骤
1. 定义"现在要解决什么"（一句话）
2. 先做，不做功课
3. 卡住了，记下缺口
4. 只学解决缺口需要的
5. 做完复盘三问，沉淀方法

---

## 📍 适用场景

- 想学新技能但不知从哪开始
- 伙伴问"我该学什么"时，先反问"你现在卡在哪"
