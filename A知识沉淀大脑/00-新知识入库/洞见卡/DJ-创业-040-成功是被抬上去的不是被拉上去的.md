# DJ-创业-040 · 成功是被抬上去的，不是被拉上去的

> **一句话洞见**：世界上没有人是被拉上成功阶梯的——他们都是被抬上去的。你帮多少人成功，你就有多成功。

---

## 🧩 因果 / 原理

舒瓦茨在第九章说：成功的本质是"让别人愿意帮你"。不要想着靠单打独斗爬到顶峰——你需要别人的支持、信任和帮助。在安利里尤其如此：你的收入取决于你帮助了多少人建立他们自己的事业。

**安利版翻译：**
- 你能做到DD，是因为你帮人做到了DD
- 你能做到营销经理，是因为你帮人做到了营销经理
- 你能做到FC，是因为你帮很多人实现了他们的目标

## 🛠 可用方法

1. **帮部门①找到他的"A/B/C"** — 帮他列出3个有潜力的候选人，这是"抬他上去"的第一步
2. **帮部门②建立系统** — 给他AI新打法工作指南，让他不用靠你也能带人
3. **帮部门③建立基础** — 先让他稳在3-5万，有了基础自然有人愿意跟他
4. **做"抬人者"而非"拉人者"** — 拉人是你替他做，抬人是给他工具和信心让他自己做

## 📍 适用场景

- **脚本类型**：安利事业观 / 团队管理 / 领导力
- **位置建议**：观点反转——"你以为成功是爬上来的？错，是被抬上来的"
- **适用部门**：部门①/②正在从"自己做"转向"带人做"，正好需要这个认知切换
