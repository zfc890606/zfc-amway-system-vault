# DJ-创业-041 · 失败只是一种思维状态，摔倒了爬起来就行

> **一句话洞见**：失败不是因为你能力不够——失败只是一种思维状态，仅此而已。所谓的失败者，就是摔了跤却不知道从中吸取教训的人。

---

## 🧩 因果 / 原理

舒瓦茨在第十一章中打破了一个常见迷思：大多数人认为"失败"是一个结果——业绩没达标、部门没冲上去、视频没播放量。但真正的"失败"不是这些外部结果，而是你内心对自己下的判断。

**关键洞见：** 你把一件事叫"失败"和叫"反馈"——区别只在于你怎么看它。叫"失败"你就停下来了，叫"反馈"你就继续调整。

**反败为胜五步法：**
1. 研究每次挫折——了解为什么：是方法问题还是执行问题？
2. 做自己的建设性批评者——不怪别人，不怪市场
3. 停止怪运气——找到你还能控制的部分
4. 坚持目标，但灵活变通方法（坚持+实验，像爱迪生）
5. 在每个情境中找到积极面

## 🛠 可用方法

1. **业绩没达标 → 问自己"数据告诉了我什么？"**（而不是"我怎么又没做到"）
2. **部门冲不上 → 问"方法要不要换？"**（而不是"这个部门不行"）
3. **视频没播放量 → 问"选题够不够痛？"**（而不是"我是不是不适合做内容"）
4. **帮部门做挫折复盘**：用五步法引导他们从"我失败了"转到"我学到了"

## 📍 适用场景

- **脚本类型**：创业心态 / 抗挫力 / 成长思维
- **位置建议**：中间翻转——"你以为你失败了？不，你只是拿到了反馈"
- **适用对象**：所有卡在瓶颈期的人——这个认知可能直接击碎他的心理障碍
