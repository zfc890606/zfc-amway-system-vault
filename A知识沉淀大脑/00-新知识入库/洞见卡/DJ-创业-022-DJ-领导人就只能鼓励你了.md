# DJ-创业-022 领导人就只能鼓励你了

> **一句话洞见**：领导人能给的只有情绪价值和方向指引，真正的工作量只能靠自己填——没有过程，找谁都没用。

---

## 🧩 因果 / 原理

很多人遇到困难第一反应是找领导人要"方法"或"资源"，但本质问题是自己的工作量不够。张医生说"继续加油——领导人就只能鼓励你了"，这句话捅破了一层窗户纸：领导人的角色是鼓励和方向指引，但执行层面的"量"别人替代不了。复盘的真相就是：只要工作量够大，方法自然跑出来。找领导人"求安慰"救不了你，只有你自己去填那个量才能破局。

## 🛠 可用方法

短视频可以这样讲：
1. 开头："你做不起来的时候找过你上家吗？"
2. 过渡：很多人觉得缺方法、缺话术、缺资源——跑去找领导人
3. 翻转："领导人就只能鼓励你，能给你方法，但给不了你的量"
4. 收尾："下次别问'我该怎么办'，先问'我今天做了多少'"

- **脚本类型**：创业道理型 / 扎心真相型
- **位置建议**：开头钩子（用"你找过领导吗？"带入）
