# DJ-营养-059 · 算蛋白量先算去脂体重，不然多吃白吃

> 蛋白质是给肌肉和器官吃的，不是给脂肪吃的。用实际体重算修复量，脂肪越多偏得越远，肝肾越累。

**即用方法**：
算客户蛋白修复量的三步：
1. 先问身高 → 算出理想体重（身高−105）
2. 再问实际体重 → 判断是否超重（超重就用校正体重法）
3. 最后选阶梯 → 日常0.8~1.0 / 修复1.2~1.5 / 强修1.5~2.0

**脚本可用金句**：
> "蛋白粉吃多少不是看体重秤上的数字，是看你身上的肌肉有多少。脂肪不消耗蛋白，算错了等于白吃。"

**对口素材**：script-026（按瓶身吃维持量）· script-039（假补蛋白）
