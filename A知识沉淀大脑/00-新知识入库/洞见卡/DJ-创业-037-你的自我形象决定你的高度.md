# DJ-创业-037 · 你的自我形象决定你的高度

> **一句话洞见**：要成为重要的人，你先得觉得自己重要——自尊让别人尊重你，自我认知决定你能做到什么程度。

---

## 🧩 因果 / 原理

舒瓦茨说：自我贬低是人类最大的弱点。你对自己的看法，设定了你成就的上限。如果你觉得自己只是"一个做安利的"，你就会做出"一个做安利的"业绩；如果你觉得自己是"帮助人逆转慢病、改变命运的创业者"，你就会做出对应的结果。

这不是鸡汤——这是**自我实现的预言**。大脑会根据你的自我认知来匹配行为、决策和行动力。

## 🛠 可用方法

1. **每天早上照镜子给自己打气**：说"我是一流人才，今天我要创造价值"
2. **升级你的自我描述**：不说"我是卖营养品的"，说"我是帮人逆转慢病的健康顾问"
3. **穿得像样**：外表影响内心——"look sharp to think sharp"
4. **觉得自己做的事很重要**：你在做的事——帮人恢复健康、帮人创业——是这个时代最有价值的事之一

## 📍 适用场景

- **脚本类型**：创业心态 / 自信建设 / IP塑造
- **位置建议**：开头钩子——"你做安利多久了？有没有觉得自己只是在'卖货'？"
- **适用部门**：所有部门都需要——很多伙伴卡在自我认知太低
