# DJ-认知-021 能运行的知识才是资产：解决什么问题·何时调用·产出什么

> **一句话洞见**：值钱的不是收藏了多少，是沉淀了多少**能反复解决问题的方法**。每段经验入库前想清楚三件事：**解决什么问题？什么情况下调用？调用后产出什么？**

---

## 🧩 因果 / 原理

**为什么收藏了很多知识还是没变强？**
- 知识只进不出 = 收藏夹，不是资产
- 没有"触发场景"的知识，遇到问题时想不起来用它

**为什么"能运行的知识"才是资产？**
- 知识 = 资产的条件：能反复调用、能稳定产出
- 例：短视频选题方法 = "最近不知道拍什么"时 → 看评论/咨询高频问题 → 匹配已有经验 → 产出选题和脚本
- 一条知识能解决什么问题、何时调用、产出什么，三件事写清楚 → AI才能调用，你自己也才知道怎么用

---

## 🛠 可用方法

### 最小行动
把你最近写的一张卡拿出来，补上三行：**解决什么问题？什么情况下调用？调用后产出什么？** 写不出的卡 = 还没消化，回炉。

### 完整执行步骤
1. 每段经验入库前过三问（解决什么 / 何时调用 / 产出什么）
2. 给知识卡片标"触发场景"，像查字典一样查知识
3. 调出来用一遍，又过一遍脑——温故而知新
4. 用不上的、没场景的知识，宁可不入

---

## 📍 适用场景

- 搭第二大脑 / 知识库时判断什么该入库
- 写 KC / DJ 卡时给卡片定"调用场景"
