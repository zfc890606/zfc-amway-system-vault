## 如果将来要重做（换电脑/授权失效）

1. 开通权限：open.feishu.cn → 应用 → 权限管理 → 加 `wiki:wiki`、`docx:document` → 创建版本并发布
2. `python3 reauthorize.py` → 点链接 → 同意（回调端口 9981，应用已登记）
3. `python3 setup_wiki.py`（建知识库，归你所有）
4. `python3 sync_pyq_to_feishu.py`

## 常见问题

| 现象 | 解决 |
|------|------|
| 刷新 token 报 20064 revoked | 授权过期/被轮换，跑一次 `reauthorize.py` |
| 授权页报 20029 重定向 URL 有误 | 回调端口必须用 **9981**（应用已登记），别改 |
| 找不到知识库 | 先跑 `setup_wiki.py` |
| 本地删了 PYQ 卡，飞书里还在 | 正常——飞书文档是快照，需手动删 |

> 脚本：`reauthorize.py` · `setup_wiki.py` · `sync_pyq_to_feishu.py`
