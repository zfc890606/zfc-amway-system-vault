# 飞书文案库同步 · 朋友圈文案库 → 飞书知识库

> 把本地 `朋友圈文案库`（`PYQ-*.md`）自动同步到飞书知识库，手机随时查看、复制。

## 这是什么

| 项目 | 说明 |
|------|------|
| 本地源 | `B自媒体大脑/05-朋友圈创作/交付脚本库/`（`PYQ-*.md`，`index.md` 除外） |
| 云端目标 | 飞书知识库「朋友圈文案库」 |
| 手机端 | 飞书 App / 微信里点知识库链接 |
| 更新方式 | 每次跑脚本：新卡自动建文档，改过的卡覆盖更新 |

## 文件清单

```
飞书文案库同步/
├── reauthorize.py           # ⭐ 一次性：给已有应用补「知识库+写文档」授权（点链接同意）
├── setup_wiki.py            # ⭐ 一次性：用你的身份建知识库（归你所有）
├── sync_pyq_to_feishu.py   # 同步脚本（核心，日常用）
├── config.json             # 配置（凭据留空=自动复用已有应用）
├── 接入指引.md              # ⭐ 一次性配置教程（先看这个）
└── README.md               # 本文档
```

## 快速开始

1. **开通权限**（一次性，约 2 分钟）：飞书后台给已有应用开通 `wiki:wiki` + `docx:document` 并发布版本
2. **授权**（一次性，约 30 秒）：`python3 reauthorize.py` → 点链接 → 同意
3. **建知识库**（一次性）：`python3 setup_wiki.py`
4. **同步**（每次更新都跑）：`python3 sync_pyq_to_feishu.py`

> 凭据不用手动填——脚本自动复用「飞书录音同步」已有的应用（`~/.config/feishu-obsidian/config.json`）。
> 授权/刷新后 token 会自动存回配置，长期有效，不用反复授权。

## 常用命令

```bash
# 重新授权（权限变更/授权过期时跑，点链接同意）
python3 reauthorize.py

# 建知识库（只跑一次）
python3 setup_wiki.py

# 预览会同步哪些文件（不写入）
python3 sync_pyq_to_feishu.py --dry-run

# 正式同步（日常用）
python3 sync_pyq_to_feishu.py
```

## 工作原理

- 不依赖飞书「导入」接口（那只能挂云空间），而是：
  1. 在知识库创建 docx 节点（`wiki/v2/spaces/{id}/nodes`）
  2. 把 markdown 转成飞书 block（标题/正文/引用/列表/分割线/加粗/斜体/链接）
  3. 通过 docx 块接口写入（`docx/v1/documents/{id}/blocks/{id}/children`）
  4. 已同步过的文档：先清空再重写（增量覆盖），不产生垃圾文件
- 同步状态记录在 `.sync_state.json`（自动生成，勿手改；删掉后重跑会重建文档）

## 注意事项

- 需要 `requests` 库（一般自带）：`pip3 install requests`
- 每次请求有频率限制（写块 ≤3 次/秒），脚本已自动限速
- 飞书在线文档是「内容快照」——本地删掉某条 `PYQ-*.md` 后，飞书里的文档**不会自动删除**，需手动删（避免误删）
- 图片 `![[xx.png]]` 不会上传，会转成「【图：见本地笔记】」占位（朋友圈配图本来就由本人负责）
