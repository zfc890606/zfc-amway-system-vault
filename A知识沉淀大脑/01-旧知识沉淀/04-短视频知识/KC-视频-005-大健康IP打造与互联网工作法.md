# 大健康 IP 打造 × 互联网工作法（张飞）

> 一句话：**销售就是搞定别人把产品卖好，营销就是搞定自己让产品好卖**——打造个人IP是让自己强大起来，进而去帮助、影响、赋能更多人。

## 一、营销 vs 推销（先立观念）

- 营销=制造"有问题的结果"；微信发出答案的叫"广告"，发出没有答案的叫"营销"，答案一出来没人看。
- 反面教材示例：晒"乙肝病毒从15.9万降到2350"（引导病情讨论，风险高）→ 正确写法：打卡护肝计划，简单方便。
- 打造IP心法：销售让别人变优秀，营销把自己变优秀；用现在最优秀的自己赚未来的钱。
- **量子纠缠：能量相牵**——打造个人IP不是赌气式跟谁比，而是把内心深处蕴藏多年的能量在某一点爆发。

## 二、大健康 IP 定位

**个性签名（定位公式）**：轻断食指导师，糖尿病防控员，健康塑型教练，大健康百万精英发起人，医生营养师社群百佳组长，国家公共营养师，中国营养学会认证营养顾问...
- 强IP打造=装修自己的门面，明确你对他人的价值。
- 置顶朋友圈：高光时刻、优秀的自己、个人价值体现。

## 三、高能量朋友圈（网红朋友圈/T型朋友圈）

- 朋友圈是社交第一阵地；**谁能获取最多注意力，谁就能最大化生产力**。
- 权威数据：爱发朋友圈死亡风险直降12%（2016《美国科学院院报》，加州大学圣地亚哥分校1200万Facebook用户研究）；经常发布照片者死亡风险低于平均30%。
- **大杂家+小专家**：既做展示美好生活的大杂家（我的生活/我的学习/我的朋友），又做身边小圈子里的小专家（营养早餐KOC朋友圈）。
- 小专家朋友圈四要素：立Flag现身说法、身体力行过程感悟、过程监督充分互动、借力公司内容+一点"自己"（自拍出镜个人感受）。
- **你的形象价值百万（5星制）**：1星随便发发90% / 2星随时模仿80% / 3星固定标准20% / 4星创造自己的游戏规则 / 5星高大上白富美。
- **制造期待感**：人物期待、时间期待、结果期待；"最"搭配：①最贵最少见 ②最远最美丽 ③最亮最有名 ④最多最疯狂（激发购买欲望）。
- **朋友圈内容四类**：你很优秀（高光时刻/荣誉/梦想/心路历程）、你的价值（帮助他人解决问题）、你身边一群牛人（大场面高质量圈子）。
- **文案写法**：指令式提问AI（"请以感动为主题给10段朋友圈文案"）+ 90%模仿+10%创新。

## 四、互联网工作法

### 1. 名单管理：打标签
- **100人有效持续跟进名单**：可以聊天的、会回复的、有种子领导人或顾客方向的、能约见面的。搜索200人有效名单，每天工作30*30*30。
- 有效名单进入读书会鱼塘养群 → 顾客名单进会员群（多项目标签）→ 标签私信与群发。

### 2. 资料管理：资料分组收藏，随时用。

### 3. 跟进沟通：FORM法则
- **F** 家庭family：家庭条件、出身、家庭现状
- **O** occupation：现在到底在做什么（对不同职业用不同需求点）
- **R** recreation：娱乐、兴趣、消遣方式
- **M** money：经济状况、增加收入？

## 五、线上社群与线下

- 经营人脉不是搞关系，而是**创造命运共同体**；关系是麻烦出来的（富兰克林：想交朋友就请他帮你一个忙；聪明地麻烦：不帮太大忙、不谈钱、请对方在擅长领域帮忙——罗辑思维）。
- 线下工具：《线上读书会》《群长手册》。
