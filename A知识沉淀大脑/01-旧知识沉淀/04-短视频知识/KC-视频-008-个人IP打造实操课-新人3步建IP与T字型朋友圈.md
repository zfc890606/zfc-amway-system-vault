# 个人IP打造实操课：新人3步建IP × T字型朋友圈 × 能量维度

> **一句话**：IP不是晒出来的，是让人看见你**从0到1的旅程与能量**——新人2-3个月可立起小IP；朋友圈按 **T字型**发（横=大杂家给情绪价值，竖=小专家给功能价值）；营销只**发结果、不发答案**。
> **对象**：刚进大健康的新伙伴（重点听）+ 做了一段时间想升级的老伙伴。
> **来头**：与「精英班」IP课同源，思路来自广州互联网大咖学费10万的录播课；此前几乎不对新人讲。

---

## 一、新人 0-3 个月建立 IP：三步走

> 导师林伟博士：一个人不管过去是白纸还是宝妈，想把自己IP打造起来，**3个月足够了**。

### 第1步 · 学习期：不是晒厉害，是晒「我正在学」
- 新手最容易误解：一上来就要证明自己很专业、晒案例、晒舞台 → 很难让人信。
- 正确做法：真实呈现**学习过程与场景**——在学营养基础班、在考营养师证、在看《轻断食完整指南》《吃的营养科学观》……
- 学到什么，**用自己的话讲一遍**即可；不需要专业，最真实的表达最好。
- 案例：街舞老师转型的赵旭老师——从真实记录每天在学什么、哪本书哪句打动自己开始，朋友圈一路攒下来，IP打造非常顺。

### 第2步 · 实践期：帮到自己 + 拿到初步结果 → 人设萌芽
- 学习的人没有IP；**关键节点=拿到第一个初步结果**。
- 学了先帮自己：阿维自己做减脂，把自己瘦下来，就是过程+结果的双重呈现。
- 记录双线：①还在学什么 ②自己/身边人实践的变化。
- 考到证 → 从「学习者」变「拿到证的人」，人设开始成立。
- 接着上舞台：社群讲一堂课、线下做一次分享——把「有人请你讲」的过程晒出来。

### 第3步 · 人设成立：水到渠成
- 标志：名片/标签/门面更新，专业度沉淀；有了证、有了自己的案例、能讲课、能帮学员出案例。
- 别人看着你**从0到1**走过来，信任自动发生 → 咨询 → 成交 → 交付/指导费。
- 全程约 **2-3个月**。

> 🎯 心法：**呈现「旅程」而不是「结果」**——张医生当年练6块腹肌全程记录，最后亮结果时信任感极强。真实记录=信任感。

## 二、IP 的本质：能量吸引（先升维，再谈术）

- 案例：第一次去北京，儿科吴医生、北中医内分泌方向罗博士两位**从未见面**的人，请他吃饭、送书、当天开卡。儿科吴医生留言：「一见如故……羡慕张老师蓬勃旺盛的生命力，被深深感染」。
- 为什么？**不是专业**（专业的人很多），是**长期朋友圈IP呈现出来的能量**先影响了他。
- 人影响人的本质=**能量高低**（霍金斯能量表：勇气200为分水岭，向上是能量高；羞愧/内疚/冷漠在最低端）。能量高者自然影响能量低者。
- 张医生的高能量叙事素材（亲测有效）：
  - 26岁、农村孩子出身，投30万开奶茶店（2015）；
  - 三甲医院工作近10年、月入约3万，2020年辞职做大健康。
  - → 别人读到的是「有魄力、敢折腾、有梦想」= 高能量词。
- 转念：当下困难恰恰是**少有的提升能量的机会**（多数人都想平顺）；从困难里爬起来的你，能量才会在身上呈现。
- 破「作秀心结」：打造IP不是跟谁比、不是炫耀，是**让自己强大起来 → 能量出来 → 才能影响人 → 才能帮更多人**。想不通这点，会被自己卡住不敢发圈。

## 三、高能量朋友圈：T 字型结构

> 记住一个「T」：上面一横、下面一竖。

| 一竖（小专家） | 一横（大杂家） |
|---|---|
| 小切口 / 专业 | 生活横向 / 真实状态 |
| 功能价值 → 信任+成交 | 情绪价值 → 温度+共鸣+吸引 |
| KOC/KOL | 有血有肉真性情 |
| 学习→考证→陪跑案例 | 生活方式/家庭/孩子/体验/感悟 |

- **横（大杂家）**：美好生活、凌晨看日出、跑步+读书、打球、旅行、成长——积极真实的生活状态。别发负能量、吐槽、八卦、是非。
- **竖（小专家）**：营养赛道小切口的专业呈现——学习打卡、证书、陪跑客户改善案例、KOC内容，用心做。
- 口诀：**大杂家给情绪价值，小专家给功能价值**。只发专业→太硬；只发生活→没价值；一横一竖=高能量朋友圈。
- 权威背书（可截图）：爱发朋友圈的人死亡风险直降12%——《美国科学院院报》，加州大学圣地亚哥分校，1200万Facebook用户研究。
- 反面教材：健康海报/资讯简报原样搬运（没有自己的话）→ 用AI出模板再**加自己的话**，别当信息搬运工。

## 四、朋友圈门面 5 件套

名字 / 头像 / 背景图 / 简介 / 置顶内容（置顶视频+置顶朋友圈）
- 置顶放什么：你的**高光时刻、优秀的自己、个人价值、帮别人解决的问题、身边高质量圈子/大场面**。
- 学员做法：学习后把微信5件套整体调整，配网红朋友圈风格。
- 原则：门面是价值传递的第一眼——从「文艺头像+文艺签名」升级为「专业营养IP门面」。

## 五、营销 ≠ 推销：只发结果，不发答案

- 「人生无处不营销」——营销中性偏褒；推销才是大家反感的。
- **判别公式**：
  - 发**结果**（谁好了、谁有改善、学员变化）→ 答案留白 → 对方好奇「怎么做到的？」= **营销**，制造期待感。
  - 发**答案**（营养素方案、产品名、步骤方法）→ = **广告**，没人看。
- 微信里，**能把答案发出来的都叫广告**；不发答案的才叫营销。
- 例子：推广轻断食/护肝计划时，两段文案对比——直接给方案的没人看，晒结果+留钩子的有人来问。
- 张医生朋友圈打法：基本只发结果，从不写「我是怎么改善的」。
- 用AI：让AI生成「只讲结果+结尾留一个问题钩子」的朋友圈，不让它写方案。

## 六、落地行动清单

- **新伙伴（0-3个月）**：按三步走，每天真实晒「在学什么/在考什么/在做什么」；先想通分享的意义=让自己强大、帮更多人，才发得出来。
- **老伙伴**：升级T字型配比 + 5件套门面 + 只发结果不发答案；别忘了横轴，热爱生活。
- **导演比喻**：一部好电影是每一帧都认真打磨——别只盯最后成交；前端基础动作做到位，后端交付/成交自然简单。
- **最终目的**：线上IP先替你说话——朋友圈能量出来了，线下链接、沟通、办卡才高效；能量高的时候，**是别人来找你，不是你追别人**。
