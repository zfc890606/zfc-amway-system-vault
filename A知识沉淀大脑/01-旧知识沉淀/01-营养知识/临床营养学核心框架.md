## 第一部分：营养学基础

### 一、宏量营养素

#### 1. 碳水化合物

**分类与功能：**
- **单糖/双糖**：葡萄糖、果糖、蔗糖——快速供能，但升糖快
- **多糖（淀粉）**：米面薯类——缓慢供能，膳食主体
- **膳食纤维**：可溶性（燕麦/果胶）→降胆固醇；不溶性（麸皮/蔬菜）→促肠道蠕动
- **抗性淀粉**：冷却后的米饭/土豆→益生元，改善胰岛素敏感性

**参考摄入量（DRIs 2023）：**
| 人群 | 总碳水 AMDR | 膳食纤维 | 添加糖限制 |
|------|-----------|---------|-----------|
| 1岁以上 | 50%~65% | — | — |
| 成人 | 50%~65% | 25~30g/天 | ≤50g/天（最好≤25g） |

**临床意义：**
- 控血糖：低GI主食替换（全谷物替代精白米面）
- 脂肪肝：减少精制碳水，控制果糖摄入
- 糖尿病：碳水合理分配，避免餐后高血糖

---

#### 2. 蛋白质

**氨基酸分类：**
- **必需氨基酸（9种）**：亮氨酸、异亮氨酸、缬氨酸、赖氨酸、蛋氨酸、苯丙氨酸、苏氨酸、色氨酸、组氨酸
- **条件必需氨基酸**：精氨酸、谷氨酰胺（应激状态下需要）
- **限制氨基酸**：谷类缺赖氨酸，豆类缺蛋氨酸→蛋白质互补作用

**蛋白质质量评价：**
- PDCAAS（蛋白质消化率校正氨基酸评分）：鸡蛋/牛奶/大豆=1.0（最高）
- 氨基酸模式越接近人体→生物价越高

**参考摄入量：**
| 人群 | 蛋白质RNI |
|------|-----------|
| 普通成人 | 0.8~1.0 g/(kg·d) |
| 老年人（65+） | 1.2~1.5 g/(kg·d) |
| 慢性病患者 | 1.0~1.5 g/(kg·d) |
| 危重症患者 | 1.2~2.0 g/(kg·d) |
| 肾病患者（CKD 3-5） | 0.6 g/(kg·d) |
| 透析患者 | 1.2 g/(kg·d) |

**临床意义：**
- 氮平衡：负氮平衡→肌肉流失、免疫力下降
- 亮氨酸：肌肉蛋白合成的关键信号分子（触发mTOR通路）
- 谷氨酰胺：肠粘膜细胞主要燃料，维持肠道屏障

---

#### 3. 脂类

**分类：**
| 类型 | 来源 | 对健康影响 |
|------|------|-----------|
| 饱和脂肪酸（SFA） | 动物脂肪、椰子油 | 过量↑LDL，促炎 |
| 单不饱和脂肪酸（MUFA） | 橄榄油、牛油果、山茶油 | ↓LDL，保护心血管 |
| 多不饱和脂肪酸（PUFA） | 植物油、鱼油 | 必需脂肪酸来源 |
| n-6 PUFA（亚油酸） | 大豆油、玉米油 | 促炎（过量） |
| n-3 PUFA（α-亚麻酸） | 亚麻籽、奇亚籽 | 抗炎，EPA+DHA更直接 |
| EPA+DHA（鱼油） | 深海鱼、鱼油补充剂 | 抗炎、降甘油三酯、脑健康 |
| 反式脂肪酸（TFA） | 氢化植物油、烘焙 | ↑LDL↓HDL，促炎，避之 |

**参考摄入量（DRIs 2023）：**
| 指标 | 推荐量 |
|------|--------|
| 总脂肪 AMDR | 20%~30%（成人） |
| SFA | ≤10%总能量 |
| n-3 PUFA AI | 男1.6g/d，女1.3g/d |
| EPA+DHA（成人） | 250~2000mg/d（治疗剂量） |

**临床意义：**
- 动脉粥样硬化：以MUFA+n-3替代SFA+TFA
- 脂肪肝：严格限制SFA和果糖，增加n-3
- 认知衰退：DHA是脑细胞膜关键组分
- 治疗剂量鱼油：降甘油三酯需2~4g/d EPA+DHA

### 三、水与能量代谢

**水：**
- 每日推荐：男2.5~3.0L，女2.0~2.5L（包括食物水）
- **需水量计算（体重基准法）：** 基础量30ml/kg + 活动/环境/疾病调整
- 临床补水原则：量出为入，防止脱水或水中毒

**能量代谢：**
- **基础代谢率（BMR）：** Harris-Benedict公式或Mifflin-St Jeor公式
- **总能量消耗（TEE）：** BMR × 活动系数（PAL）
- **临床能量目标：** 25~30 kcal/(kg·d)（拇指法则）
  - 急性期/危重：20~25 kcal/(kg·d)（允许性低热卡）
  - 恢复期：30~35 kcal/(kg·d)

## 第二部分：临床营养评估与诊断

### 一、三级诊断体系（石汉平教授提出）

```
一级诊断（营养筛查）→ 二级诊断（营养评估）→ 三级诊断（综合评价）
```

**一级诊断：营养风险筛查——谁来筛？**

所有住院患者入院24小时内完成。

**常用工具：**
| 工具 | 适用人群 | 评分意义 |
|------|---------|---------|
| NRS-2002 | 成年住院患者（最常用） | ≥3分→有营养风险→需进一步评估 |
| MNA-SF | 老年人（65+） | ≤11分→有营养不良风险 |
| MUST | 社区/门诊患者 | 高/中/低风险分层 |
| SGA | 住院患者 | A=营养良好/B=轻中度/C=重度营养不良 |

**NRS-2002评分结构（总分0~7分）：**
| 维度 | 0分 | 1分 | 2分 | 3分 |
|------|-----|-----|-----|-----|
| 营养状态受损 | 正常 | 3个月内体重下降>5%或近1周进食量减少25~50% | 2个月内体重下降>5%或BMI 18.5~20.5+一般状况差或近1周进食量减少50~75% | 1个月内体重下降>5%或BMI<18.5+一般状况差或近1周进食量减少>75% |
| 疾病严重程度 | 正常 | 髋骨骨折、COPD、血液透析、糖尿病、一般肿瘤 | 腹部大手术、卒中、重症肺炎、白血病 | 颅脑损伤、骨髓移植、ICU患者（APACHE>10） |
| 年龄 | — | ≥70岁加1分 | — | — |

---

**二级诊断：营养评估——谁来评？怎么评？**

由临床营养师对筛查阳性者进行ABCD评估：

| 维度 | 内容 | 关键指标 |
|------|------|---------|
| **A**nthropometry 人体测量 | 身高、体重、BMI、中臂围、三头肌皮褶厚度 | BMI：正常18.5~23.9；<18.5为偏瘦 |
| **B**iochemistry 生化检查 | 血常规、肝肾功能、前白蛋白/白蛋白、电解质、维生素水平 | 白蛋白<35g/L提示营养不良；前白蛋白更敏感（半衰期2天） |
| **C**linical 临床评估 | 疾病状态、用药、消化吸收功能、肌肉流失（肉眼可见） | 颞肌/三角肌萎缩=严重肌肉消耗 |
| **D**ietary 膳食评估 | 24h膳食回顾、食物频率问卷、宏量/微量营养素摄入 | 对比DRIs评估缺口 |

---

**三级诊断：GLIM标准（全球领导人营养不良倡议）——国际共识诊断**

诊断需满足 ≥1项表型指标 + ≥1项病因指标：

**表型指标（3选1）：**
1. **非自主性体重下降：** 半年内>5%，或1月内>2%
2. **低BMI：** <20（<70岁以下）或 <22（≥70岁）
3. **肌肉量减少：** 中臂围/小腿围/生物电阻抗/超声/DXA

**病因指标（2选1）：**
1. **摄食减少：** 能量摄入<50%需求持续>1周，或任何摄入减少持续>2周
2. **疾病负担/炎症：** 急性创伤/感染/慢性疾病（肿瘤/COPD/心衰/肾病）

**严重度分级：**
| 等级 | 标准 |
|------|------|
| 中度营养不良 | 半年内体重下降5~10%，或低BMI，或轻度肌肉减少 |
| 重度营养不良 | 半年内体重下降>10%，或更低BMI，或严重肌肉减少 |

### 二、营养不良类型

| 类型 | 特征 | 常见场景 |
|------|------|---------|
| 蛋白质-能量营养不良（PEM） | 能量和蛋白质均不足 | 长期饥饿、厌食 |
| 蛋白质营养不良（Kwashiorkor） | 蛋白质严重不足、能量尚可 | 严重应激/炎症→白蛋白↓ |
| 混合型 | 慢性能量不足+急性应激 | 晚期肿瘤、慢病急性发作 |
| 微量营养素缺乏 | 特定维生素/矿物质不足 | 隐性饥饿（高能量低营养密度饮食） |

## 第三部分：营养治疗路径五阶梯

### 一、五阶梯治疗原则

营养不良的规范治疗遵循 **五阶梯原则**，从下向上逐级：

```
                ┌─────────────────┐
    第五阶梯   │  全肠外营养TPN   │
                └────────┬────────┘
                         ↑
                ┌────────┴────────┐
    第四阶梯   │ PEN + PPN (SPN) │
                └────────┬────────┘
                         ↑
                ┌────────┴────────┐
    第三阶梯   │   全肠内营养TEN   │
                └────────┬────────┘
                         ↑
                ┌────────┴────────┐
    第二阶梯   │ 饮食 + ONS口服营养补充 │
                └────────┬────────┘
                         ↑
                ┌────────┴────────┐
    第一阶梯   │   饮食 + 营养教育    │
                └─────────────────┘
```

**核心切换原则：**
| 方向 | 原则 | 说明 |
|------|------|------|
| 升阶梯（向下→上） | **60%原则** | 当前阶梯不能满足60%目标营养需求持续3~5天（危重2~3天）→上新台阶 |
| 降阶梯（向上→下） | **50%原则** | 下阶梯能满足50%目标需求→逐渐减少上阶梯，增加下阶梯 |

**治疗优先序：** 膳食优先 > 口服优先 > 营养教育优先 > 肠内营养优先

---

### 二、各阶梯详解

#### 第一阶梯：饮食 + 营养教育
**适用：** 所有营养不良患者的基础治疗
**内容：**
- 评估营养不良严重程度和类型
- 分析原因（疼痛、厌食、药物影响、心理等）
- 个体化饮食指导（食物选择、烹饪方式、餐次安排）
- 处理非饮食原因

---

#### 第二阶梯：饮食 + ONS（口服营养补充）
**定义：** 在饮食基础上，额外口服特医食品（全营养配方/组件配方）
**适应症：** 饮食+营养教育后仍不能满足≥60%目标需求者
**推荐模式：** 3正餐 + 3次ONS（3+3模式）
**荷瘤患者：** 推荐**终身ONS**

**常见制剂：**
| 类型 | 特点 | 适用 |
|------|------|------|
| 全营养均衡型 | 能量密度1.0~1.5 kcal/ml | 多数患者 |
| 高蛋白型 | 蛋白质≥20%能量 | 肿瘤、创伤、肌少症 |
| 糖尿病型 | 低碳水+缓释碳水 | 糖尿病患者 |
| 肾病型 | 低蛋白+高BCAA | 肾衰竭 |
| 短肽型 | 预消化、易吸收 | 消化道功能受损 |

---

#### 第三阶梯：全肠内营养（TEN）

**定义：** 通过管饲（鼻胃管/鼻肠管/胃造口/空肠造口）提供全部营养需要

**适应症：**
- 不能经口进食（昏迷、吞咽困难、头颈手术）
- 摄食不足且有胃肠道功能
- 消化道手术前后

**禁忌症：**
| 绝对禁忌 | 相对禁忌 |
|---------|---------|
| 完全性肠梗阻 | 严重吸收不良 |
| 严重上消化道出血 | 胃大部切除后倾倒综合征 |
| 顽固性呕吐/严重腹泻 | 严重胰腺炎急性期 |
| 腹膜炎 | 休克/昏迷 |
| AGIⅣ级（急性胃肠损伤4级） | 空肠瘘 |

**管饲途径选择：**
| 途径 | 适用时长 | 优点 | 缺点 |
|------|---------|------|------|
| 鼻胃管（NGT） | 短期<3~4周 | 操作简便、无创 | 反流/误吸风险 |
| 鼻肠管（NIT） | 短期<3~4周 | 减少反流 | 操作要求高 |
| PEG（经皮内镜胃造口） | 长期>4周 | 舒适、生活影响小 | 有创操作 |
| PEJ（经皮内镜空肠造口） | 长期>4周 | 绕过胃 | 有创操作 |

**制剂分类：**
| 类型 | 氮源 | 适用 |
|------|------|------|
| 整蛋白型 | 完整蛋白（大豆/乳清/酪蛋白） | 消化功能正常 |
| 短肽型 | 水解蛋白、短肽 | 消化功能受损 |
| 氨基酸型 | 单体氨基酸 | 严重消化功能障碍（如短肠综合征） |
| 疾病专用型 | 针对特定疾病调整 | 糖尿病、肾病、肝病、肺病 |

---

#### 第四阶梯：部分肠内 + 补充性肠外营养（PEN + SPN）

**指征：** EN持续3天以上仍不能满足60%目标需要量→在EN基础上补充PN
**目标：** EN + PN 共同达到能量和蛋白质目标

---

#### 第五阶梯：全肠外营养（TPN）

**定义：** 完全通过静脉途径供给营养素

**适应症：** 肠道完全不能使用或EN禁忌
- 短肠综合征（早期）
- 高流量肠瘘
- 肠缺血
- 腹腔间隔室综合征
- 完全性肠梗阻

**输注途径：**
| 途径 | 适用时长 | 说明 |
|------|---------|------|
| 外周静脉（PPN） | ≤7~10天 | 渗透压≤900 mOsm/L |
| 中心静脉（CVC） | >2周 | 首选锁骨下静脉；PICC也常用 |
| 输液港 | >4周/长期需要 | 永久性通路 |

**推荐配方："全合一"All-in-One（全营养混合液）**
- 首选工业化多腔袋
- 脂肪乳剂推荐：中长链脂肪乳、鱼油脂肪乳、多种油制剂

**并发症：**
| 类型 | 具体 | 预防/处理 |
|------|------|----------|
| 导管相关感染 | 穿刺点感染/败血症 | 严格无菌操作 |
| 高血糖 | TPN最常见代谢并发症 | 胰岛素调控 |
| 再喂养综合征 | 严重营养不良者启动PN后 | TPN从低能量开始15~20 kcal/(kg·d)，逐步增加，监测血磷/钾/镁 |
| 脂肪超载综合征 | 脂肪乳输入过快/过量 | 减量或暂停 |
| 肝损伤/胆汁淤积 | 长期TPN | 尽早恢复EN，减量 |

## 第四部分：各系统疾病营养治疗

### 一、代谢及内分泌疾病

#### 1. 糖尿病营养治疗

**核心原则：** 合理控制总能量 + 均衡营养 + 个体化

**营养治疗要点：**
| 营养素 | 推荐 | 注意 |
|--------|------|------|
| 总能量 | 25~30 kcal/(kg·d)；超重/肥胖者减至20~25 | 以标准体重计算 |
| 碳水化合物 | 占总能量50%~60% | **低GI/GL主食**替代精白米面；全谷物、杂豆每餐至少1/3 |
| 蛋白质 | 0.8~1.2 g/(kg·d)；肾病者~0.8 | 瘦肉、蛋、奶、豆制品 |
| 脂肪 | <30%总能量，SFA<10% | MUFA >橄榄油为主；每周2次深海鱼 |
| 膳食纤维 | 25~30g/d | 全谷物、蔬菜、豆类 |
| 钠 | <6g盐/d（合并高血压<5g） | — |
| 甜味剂 | 适量代糖 | 不推荐含糖饮料 |

**体重管理：**
- 糖尿病合并肥胖者：减重干预1年后，糖尿病缓解率可达46%
- 减重目标：体重下降5%~10%

**饮⻝策略：**
- 餐次分配：少量多餐，3主餐+2~3加餐
- 进食顺序：蔬菜→蛋白质→主食（先吃膳食纤维和蛋白→血糖更平稳）
- 杜绝含糖饮料

---

#### 2. 痛风/高尿酸血症营养治疗

**核心原则：** 降尿酸 + 碱化尿液 + 控制体重

| 策略 | 具体措施 |
|------|---------|
| 严格限制 | 动物内脏、浓汤、海鲜（特别是贝类/沙丁鱼）、啤酒、白酒 |
| 适量控制 | 红肉、含糖饮料/果糖（果糖促尿酸生成）、部分鱼类 |
| 鼓励摄入 | 低脂奶制品（降尿酸）、樱桃（促尿酸排泄）、蔬菜、全谷物、水（>2000ml/d） |
| 体重管理 | 减重→显著降尿酸（但避免快速减重→促尿酸升高） |
| 烹饪 | 肉类先焯水去嘌呤；少油少盐 |

**分期蛋白策略：**
| 阶段 | 蛋白质摄入 |
|------|-----------|
| 急性发作期 | 0.8 g/(kg·d)，以蛋/奶为主 |
| 缓解期 | 1.0 g/(kg·d) |

---

#### 3. 肥胖/超重营养干预

**核心原则：** 能量负平衡 + 营养密度提升 + 行为改变

**能量等级：**
| 干预强度 | 能量摄入 | 减重速度 |
|---------|---------|---------|
| 轻度限能 | 比TEE减少300~500 kcal/d | 0.5kg/周 |
| 低能量 | 1000~1200 kcal/d（女），1200~1500（男） | 0.5~1kg/周 |
| 极低能量（VLCD） | 800~1000 kcal/d（医疗监督下） | 1~2kg/周 |

**宏量营养分配：**
- 高蛋白（25~30%蛋白质）更有饱腹感、维持肌肉
- 低碳水（40~45%碳水）有利于控血糖
- 低脂（20~25%脂肪）控制能量密度
- 膳食纤维：25~30g/d（饱腹感+肠道健康）

---

### 二、心血管疾病

#### 1. 高血压营养治疗（DASH饮食原则）

**核心：** 低钠 + 高钾 + 高钙 + 高镁

| 策略 | 具体措施 |
|------|---------|
| 严格限钠 | <5g盐/d（PI-NCD 2000mg钠）；可用低钠盐（肾功能正常者） |
| 增加钾 | 蔬菜水果、豆类、土豆、香蕉→目标3600mg/d |
| 增加钙 | 低脂奶制品、豆制品→目标800~1000mg/d |
| 增加镁 | 深绿叶菜、坚果、全谷物→目标300~330mg/d |
| 限制 | 酒精（男≤25g/d，女≤15g/d）、饱和脂肪 |
| 体重管理 | 每降1kg体重→血压下降约1mmHg |

---

#### 2. 高脂血症营养治疗

**核心：** 降LDL + 降TG + 升HDL

| 脂蛋白 | 营养策略 |
|--------|---------|
| ↑LDL-C（"坏胆固醇"） | 减少SFA和TFA；增加可溶性纤维（燕麦/车前子/苹果）；植物甾醇（豆类/坚果）；n-3 |
| ↑TG（甘油三酯） | 减重、减糖、减少精制碳水；n-3鱼油（2~4g/d EPA+DHA） |
| ↓HDL-C（"好胆固醇"） | 规律运动；MUFA（橄榄油/牛油果）；适量酒精？但推荐红线 |

**膳食胆固醇：** 2023年不再严格限制（但蛋黄等高胆固醇食物仍建议适量）

---

### 三、消化系统疾病

#### 1. 胃部疾病（胃炎/消化性溃疡）

| 原则 | 措施 |
|------|------|
| 少食多餐 | 5~6餐/天，减轻胃负担 |
| 低刺激 | 避免辛辣、过酸、过烫、酒精、咖啡因 |
| 细软易消化 | 软烂食物，充分咀嚼 |
| 蛋白质充足 | 修复胃黏膜 |
| 戒烟 | 烟→胃黏膜血管收缩 |

---

#### 2. 脂肪肝（非酒精性NAFLD）

**核心：** 减重 + 胰岛素抵抗改善 + 抗炎

| 策略 | 具体措施 |
|------|---------|
| 减重 | 减重5~10%→肝脂肪显著减少；减重10%+→肝纤维化逆转可能 |
| 低碳水 | 特别是**果糖**（果糖→肝脏→脂肪合成）；限制含糖饮料 |
| 增加n-3 | 鱼油、亚麻籽→抗炎降肝脂 |
| 限制SFA | 动物脂肪、油炸 |
| 增加膳食纤维 | 全谷物、蔬菜→改善肠道菌群 |
| 维生素E | 非糖尿病NAFLD患者800IU/d可改善肝组织学 |
| 戒酒（或严格限酒） | — |

---

#### 3. 胰腺炎

**急性期：**
- 急性期：暂停经口进食，PN支持
- 恢复早期：低脂短肽型EN（鼻空肠管）
- 恢复后期：低脂软食逐步过渡

**慢性胰腺炎：**
- 低脂（<30g/d脂肪）
- MCT油替代部分长链脂肪（无需胰酶即可吸收）
- 补充脂溶性维生素（A/D/E/K）
- 胰酶替代治疗

---

### 四、慢性肾病（CKD）营养治疗

**核心原则：** 低蛋白 + 低钠 + 控钾/磷 + 能量充足

**分期蛋白策略：**
| CKD分期 | 蛋白质推荐 | 说明 |
|---------|-----------|------|
| CKD 1~2期 | 0.8 g/(kg·d) | 延缓进展 |
| CKD 3~5期（非透析） | 0.6 g/(kg·d) | 优质蛋白≥50% |
| 血液/腹膜透析 | 1.2 g/(kg·d) | 代替透析丢失 |

**关键管理项：**

| 指标 | 策略 |
|------|------|
| 钠 | <5g盐/d（控水+降血压） |
| 钾 | 肾功能不全排尿减少→限制高钾食物（香蕉、橙子、土豆、深绿叶菜） |
| 磷 | 限制加工食品、动物内脏、坚果、碳酸饮料；必要时磷结合剂 |
| 能量 | 充足能量（25~35 kcal/kg/d）防止肌肉分解 |
| 钙 | 补充钙（但注意磷钙平衡） |
| 体液 | 量出为入（前日尿量+500ml） |

**特殊营养素：**
- **BCAA（支链氨基酸）：** 减少肌肉分解
- **α-酮酸类似物：** 配合极低蛋白饮食，减少氮质废物

---

### 五、肿瘤营养治疗

**核心地位：** 营养疗法是肿瘤患者的基础治疗、一线治疗和核心治疗

**五大原则：**
1. **确诊即筛查：** 一经确诊即行营养风险筛查（NRS-2002）
2. **营养三级诊断**：筛查→评估→综合评价
3. **五阶梯治疗**：依据营养诊断结果选择阶梯
4. **EN优先，PN补充**
5. **终身ONS**（特别是荷瘤患者）：3+3模式

**各阶段策略：**

| 阶段 | 营养重点 |
|------|---------|
| 术前 | 纠正营养不良，目标≥1.2 g/(kg·d)蛋白质，术前7~14天 |
| 放化疗 | 高蛋白（>1.2 g/kg/d），处理副作用（黏膜炎→软食/流质；恶心→姜/少量多餐） |
| 终末期 | 舒适喂养、不以治愈为目的、满足患者意愿 |

**恶病质管理（肿瘤恶病质）：** 是能量负平衡+全身炎症的共同结果
- 高能量高蛋白（蛋白质1.5~2.0 g/kg/d）
- n-3脂肪酸（EPA 2g/d）→抗炎、抑制肌肉分解
- 运动干预（阻力训练）→维持肌肉
- 药物辅助（甲地孕酮促食欲、糖皮质激素短期消炎）

---

### 六、围手术期营养治疗

**核心理念：** ERAS（加速康复外科）——术前不挨饿，术后早进食

**术前：**
| 指征 | 启动营养支持 |
|------|-------------|
| 6个月内非随意体重下降>10% | 术前营养支持 |
| BMI <18.5（≤65岁） | 术前营养支持 |
| NRS-2002评分≥5分 | 术前营养支持 |
| 白蛋白<30 g/L | 术前营养支持 |
| 术前支持时长 | 7~14天 |
| 术前碳水负荷 | 术前2~3h喝400ml含碳水饮料（减少胰岛素抵抗） |

**术后：**
- 早期EN（术后24h内启动）→加速肠道功能恢复、降低感染
- 蛋白质≥1.2 g/(kg·d)
- 咀嚼吞咽无障碍→流质→半流→软食渐进

---

### 七、肝胆疾病

**肝炎/肝硬化营养要点：**
| 指标 | 策略 |
|------|------|
| 能量 | 25~35 kcal/(kg·d)（肝糖代谢受损→需更多能量） |
| 蛋白质 | 1.0~1.5 g/(kg·d)（除非肝性脑病） |
| 肝性脑病 | 限制蛋白至0.6~0.8 g/(kg·d)，优先植物蛋白+BCAA |
| 钠 | 腹水→<2g/d钠 |
| 限水 | 严重腹水→量出为入 |
| 补充 | 脂溶性维生素（肝功受损→吸收障碍）；锌、硒 |
| 禁忌 | 酒精→绝对禁酒 |

---

### 八、呼吸系统疾病

**COPD（慢性阻塞性肺病）营养：**
| 指标 | 策略 |
|------|------|
| 能量 | 30~35 kcal/(kg·d)（呼吸耗能增加） |
| 蛋白质 | 1.2~1.7 g/(kg·d)（防肌少→呼吸肌衰减缩短寿命） |
| 碳水 | 适量控制（过量→CO₂产生↑→加重通气负担） |
| 脂肪 | 稍高比例（脂肪产CO₂更少） |
| 小餐多次 | 避免腹胀影响膈肌活动 |

### 三、老年营养与肌少症

**肌少症（Sarcopenia）：**
- 患病率：社区男性12.9%，女性11.2%；养老机构65.9%
- ≥70岁人群营养不良发生率显著高于<70岁

**营养策略：**

| 策略 | 推荐措施 |
|------|---------|
| 能量 | 30 kcal/(kg·d) |
| 蛋白质 | 1.2~1.5 g/(kg·d)；营养不良时≥1.5 g/(kg·d) |
| 优质蛋白分布 | 三餐均匀分配（每餐25~30g蛋白质→最大化肌肉合成） |
| 乳清蛋白 | 牛奶中乳清蛋白对预防肌肉衰减有益 |
| 维生素D | 补充800~2000IU/d（肌少症和骨折预防） |
| 钙 | 1000~1200mg/d（防骨质疏松） |
| 膳食纤维 | 25~30g/d（防便秘） |
| ONS | 食欲差者常规使用口服营养补充 |
| 运动 | 阻力训练+蛋白质补充→最有效抗肌少症组合 |
| 进食方式 | 少量多餐（三餐两点/三点制），食物细软 |

## 第六部分：常见营养素功能速查

### 抗炎营养素

| 营养素 | 作用机制 | 来源 |
|--------|---------|------|
| Omega-3（EPA/DHA） | →促炎介质竞争抑制→炎症消退 | 深海鱼、鱼油 |
| 维生素D | →调节免疫、抑制促炎细胞因子 | 晒太阳、补充剂 |
| 维生素C | →抗氧化、清除自由基 | 鲜果蔬 |
| 维生素E | →保护细胞膜脂质过氧化 | 坚果、种子 |
| 硒 | →谷胱甘肽过氧化物酶（抗氧化核心酶） | 巴西坚果、海鲜 |
| 姜黄素 | →抑制NF-κB通路→减少促炎因子 | 姜黄+黑胡椒 |
| 多酚/类黄酮 | →抗氧化、抗炎 | 茶叶、浆果、深色蔬菜 |
