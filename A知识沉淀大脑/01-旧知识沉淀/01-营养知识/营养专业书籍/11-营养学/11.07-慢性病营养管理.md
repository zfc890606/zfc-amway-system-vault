## 〇、慢病营养管理总则

### 1. 慢病流行的时代背景（为什么要重视）

中国目前正经历全球规模最大的慢性非传染性疾病（简称"慢病"）负担。理解流行病学数据，是营养师面对顾客时的"开场权威背书"：

| 指标 | 中国成人现状（近年监测） | 说明 |
|------|--------------------------|------|
| 糖尿病患病率 | 约 12%（约 1.4 亿人） | 居全球第一，且知晓率仅约 36% |
| 糖尿病前期（糖调节受损） | 约 35% | 是营养干预的"黄金窗口期" |
| 高血压患病率 | 约 27.5%（约 2.45 亿人） | 知晓率、治疗率、控制率"三低" |
| 血脂异常患病率 | 约 40.4% | 是心脑血管病第一危险因素 |
| 超重/肥胖 | 超重约 34%，肥胖约 16% | 与 12 种癌、2 型糖尿病密切相关 |
| 慢性肾病（CKD） | 约 10.8%（约 1.2 亿人） | 早期几乎无症状，靠体检发现 |
| 非酒精性脂肪肝 | 约 30% | 已是第一大慢性肝病 |
| 痛风/高尿酸血症 | 高尿酸约 13%，痛风约 1% | 与果糖、啤酒、内脏密切相关 |

**营养师的判断：** 这些慢病绝大多数都"可防可管"，而**营养是所有干预手段中成本最低、获益最广、可复制性最强的一环**——这正是 AI营养师职业价值的技术底座。

### 2. 共同病理基础（四大通路）

几乎所有主流慢病（代谢性、心脑血管、部分肿瘤）共享同一条病理主线，营养师必须先建立这张"底层地图"：

```
遗传易感 + 环境暴露（高能量密度饮食/久坐/压力/睡眠剥夺/肠菌失调）
        │
        ▼
① 胰岛素抵抗 ─────────────┐
② 慢性低度炎症 ───────────┼──→ 肥胖（中心性脂肪堆积）
③ 氧化应激（ROS↑）───────┤
④ 线粒体功能障碍 + 肠菌失调 ┘
        │
        ▼
代谢综合征五联征（高血压/高血糖/高血脂/中心性肥胖/高尿酸）
        │
        ▼
动脉粥样硬化 → 心梗/脑梗｜肾小球硬化 → 慢性肾病｜肝脏脂肪变 → 脂肪肝→纤维化
        │
        ▼
心脑血管病 / 终末期肾病 / 肝硬化 / 部分肿瘤（结直肠癌、乳腺癌等）
```

**四大病理通路的营养学解读：**

| 通路 | 病理要点 | 对应的营养杠杆 |
|------|----------|----------------|
| 胰岛素抵抗 | 细胞对胰岛素不敏感 → 血糖代偿性升高 → β细胞耗竭 | 减重、低GI碳水、运动增肌、控果糖 |
| 慢性低度炎症 | 脂肪组织巨噬细胞浸润，TNF-α/IL-6/CRP 升高 | 抗炎饮食：n-3、多酚、纤维、减内脏脂肪 |
| 氧化应激 | 自由基增多、抗氧化储备下降，损伤血管内皮/胰岛 | 抗氧化微量营养素：维C/维E/硒/锌/花色苷 |
| 肠菌失调 | 厚壁菌/拟杆菌比例改变，内毒素入血促炎 | 膳食纤维、发酵食物、益生菌/益生元 |

**给营养师的底层信念：** 慢病不是"缺某种药"，而是**长期的"代谢环境失衡"**。营养师的角色不是替代医生，而是帮顾客**重建代谢平衡的土壤**——这与医疗治疗互为补充、不冲突。

### 3. 六大干预杠杆（总纲）

| 杠杆 | 核心动作 | 主要作用 | 证据强度 |
|------|----------|----------|----------|
| ① 能量负平衡 | 控总能量 → 减体重 | 减重是慢病"第一药"，体重下降 5%-10% 即可带来血压/血糖/血脂全面改善 | Ⅰ级强证据 |
| ② 宏量营养素比例 | 减精制碳水、保优质蛋白、控坏脂肪 | 直接改善血糖波动、血脂谱、饱腹感 | Ⅰ级强证据 |
| ③ 微量营养素 | 纠正隐性饥饿（镁/钾/钙/维D/铬等） | 参与胰岛素信号、血管舒张、骨代谢 | Ⅱ-Ⅲ级证据，支持性 |
| ④ 抗炎饮食模式 | n-3、多酚、可溶性纤维 | 降低炎症因子，保护内皮与胰岛 | Ⅱ级证据 |
| ⑤ 进餐模式 | 进餐顺序/频次/时间窗口 | 平滑血糖曲线，改善食欲与代谢 | RCT 支持（先菜后饭） |
| ⑥ 行为+运动 | 睡眠 7h+、压力管理、每周 ≥150min 中强度运动 | 协同降压、增肌、稳定血糖 | Ⅰ级强证据 |

**六大杠杆的优先级：** 对超重/肥胖顾客，**能量负平衡 + 运动**是最高杠杆；对体重正常但血糖/血脂异常的顾客，**宏量营养素比例 + 进餐模式**更关键；对饮食质量差、隐性饥饿明显的顾客，**微量营养素 + 抗炎饮食**优先。三者不互斥，而是分阶段组合。

### 4. 代谢综合征（MetS）——慢病的"集合信号"

代谢综合征不是单一疾病，而是一组代谢异常在同一个体上的聚集。它既是慢病的早期预警，也是营养干预最集中的窗口。

#### 4.1 中国标准（中华医学会糖尿病学分会推荐，符合 3 项及以上即诊断）

| 组分 | 诊断切点 |
|------|----------|
| 腹型肥胖（中心性肥胖） | 腰围：男 ≥90cm，女 ≥85cm（中国标准，低于 IDF 的 94/80） |
| 高血糖 | 空腹血糖 ≥6.1 mmol/L 或糖负荷后 2h 血糖 ≥7.8 mmol/L，或已确诊糖尿病 |
| 高血压 | 血压 ≥130/85 mmHg，或已确诊高血压并治疗 |
| 高甘油三酯 | TG ≥1.7 mmol/L |
| 低高密度脂蛋白 | HDL-C <1.04 mmol/L（男/女同值） |

#### 4.2 代谢综合征的营养解读

- 代谢综合征的五个组分中，**三个以上可被同一种营养策略同时改善**：减重 5%-10%、腰围下降、控糖、降脂、降压。
- **中心性肥胖是"发动机"**：内脏脂肪释放游离脂肪酸和炎症因子，直接驱动胰岛素抵抗与高血压。因此营养师的首要靶点是**腰围**，而不仅是体重。
- 向顾客传递的核心认知："你的血糖/血压/血脂/腰围是一棵树上结的四个果子，根是同一个——代谢失衡。营养师不逐个摘果子，而是修根。"

#### 4.3 代谢综合征的干预目标速查

| 指标 | 干预目标 |
|------|----------|
| 体重 | 降 5%-10%，再评估 |
| 腰围 | 男 <90cm，女 <85cm |
| 空腹血糖 | <6.1 mmol/L（糖尿病者按糖尿病标准） |
| 血压 | <130/85 mmHg（个体化） |
| TG | <1.7 mmol/L |
| HDL-C | 男 >1.0，女 >1.3 mmol/L（越高越好） |

### 5. 营养干预通用路径（六步闭环）

营养师面对任何慢病顾客，都走同一条专业路径：

```
第一步 营养筛查
   ↓ 用 NRS2002 / 营养风险指数，识别"营养不良风险"（尤其老人、肿瘤、肾病）
第二步 营养评估
   ↓ 人体测量（体重/BMI/腰围/体成分）+ 生化指标（血糖/血脂/肝肾功能）+ 膳食调查
第三步 营养诊断
   ↓ 明确：能量过剩 or 不足？宏量比例失衡？微量缺乏？饮食品质差？
第四步 制定方案
   ↓ 按病种+个体化设定能量/宏量/微量/餐次/运动目标
第五步 执行与赋能
   ↓ 教顾客"可操作的动作"（先菜后饭、餐盘法、购物清单），而非抽象说教
第六步 监测与随访
   ↓ 设定复测时间表，根据指标动态调整；体重/血糖/血压/血脂"四件套"定期复看
```

**通用路径的关键原则：**
- **先稳后改**：严重营养不良者先纠营养，再谈减重；营养风险高的顾客不激进限能。
- **小步快跑**：一次只改 2-3 个行为（避免一次改太多导致放弃）。
- **数据说话**：用复测数据验证方案有效性，增强顾客依从性。
- **边界清晰**：营养师负责"吃、动、睡、情绪"；诊断、用药、调药归医生。凡涉及诊疗决策，一律提示"请咨询专业医师/遵循医嘱"。

### 6. 慢病营养干预共同点（速记卡）

无论哪个病种，以下六条是"公共地基"：

| 共同点 | 具体要求 | 覆盖病种 |
|--------|----------|----------|
| 减重是核心 | 超重/肥胖者体重降 5%-10% | 糖尿病/高血压/高血脂/脂肪肝/痛风/冠心病 |
| 低GI主食替换 | 全谷物/杂豆替代精米面的 1/3-1/2 | 糖尿病/高血脂/脂肪肝/肥胖 |
| 限钠 | 一般 <6g 盐/天；合并高血压 <5g/天 | 高血压/肾病/心衰/糖尿病 |
| 好油抗炎 | n-3（深海鱼/亚麻籽）、橄榄油/茶籽油替代动物油 | 高血脂/脂肪肝/冠心病 |
| 纤维充足 | 25-30g/天（蔬菜 1 斤 + 水果 1 个 + 全谷） | 糖尿病/便秘/肠癌/血脂 |
| 控酒 | 男 ≤25g、女 ≤15g 酒精/天；痛风/肝病戒酒 | 高血压/痛风/脂肪肝/肿瘤 |

## 一、2型糖尿病营养管理

### 1. 疾病与营养的关联机制（病理生理）

2型糖尿病（T2DM）的核心是**胰岛素抵抗 + 胰岛β细胞功能进行性减退**。营养在其中的作用链条：

```
长期能量过剩 → 内脏脂肪堆积 → 脂肪组织释放游离脂肪酸 + 炎症因子
        → 胰岛素受体信号受损（胰岛素抵抗）→ 血糖代偿性升高
        → β细胞代偿性分泌过多胰岛素（高胰岛素血症）→ 逐年耗竭
        → 血糖失控 → 糖基化终产物（AGEs）→ 微血管（眼/肾/神经）+ 大血管（心/脑）病变
```

**与营养最相关的病理环节：**
- **高血糖负荷饮食**（精制碳水、含糖饮料）→ 餐后血糖陡升陡降 → 胰岛β细胞负荷加重。
- **果糖过量**（含糖饮料、果汁）→ 不经胰岛素调控，直接入肝合成脂肪 → 加重脂肪肝与胰岛素抵抗。
- **膳食纤维不足** → 血糖吸收快 + 肠菌失调 → 炎症加重。
- **蛋白质不足/肌少** → 肌肉是"血糖缓冲池"，肌肉量下降 → 胰岛素敏感性下降。
- **缺乏运动** → 肌肉 GLUT4 转运体表达下降 → 餐后血糖摄取减少。

**糖尿病前期（空腹 6.1-7.0 或餐后 7.8-11.1 mmol/L）是逆转黄金期**：此时β细胞功能尚可，通过生活方式干预可显著降低进展为糖尿病的风险（大庆研究：生活方式干预 6 年，20 年随访糖尿病发生率降低 43%）。

### 2. 营养治疗目标（可量化）

| 目标维度 | 具体数值 | 依据 |
|----------|----------|------|
| 血糖控制 | 空腹 4.4-7.0 mmol/L；餐后 2h <10.0 mmol/L | 《中国2型糖尿病防治指南》 |
| 糖化血红蛋白 | HbA1c <7.0%（老年人可放宽至 7.5%-8.0%） | 指南目标，个体化 |
| 血压 | <130/80 mmHg（合并高血压者） | 指南 |
| 血脂 | LDL-C <2.6 mmol/L（合并心血管病<1.8） | 指南 |
| 体重 | 超重/肥胖者降 5%-10%；理想 BMI 18.5-23.9 | 指南 |
| 腰围 | 男 <90cm，女 <85cm | 代谢综合征标准 |
| 血脂谱 | TG <1.7 mmol/L；HDL-C 男>1.0/女>1.3 mmol/L | 指南 |
| 血糖波动 | 餐后血糖增幅尽量 <3-4 mmol/L | 血糖管理理念 |
| 逆转目标（可选） | 短期减重 ≥10%-15% → 部分患者实现血糖缓解（HbA1c<6.5% 且停降糖药） | DiRECT 研究 |

### 3. 营养素方案表

| 营养素 | 建议值/范围 | 要点说明 |
|--------|-------------|----------|
| 总能量 | 25~30 kcal/kg（标准体重）；超重/肥胖者减至 20~25 kcal/kg | 标准体重 = 身高(cm)-105 |
| 碳水化合物 | 供能比 45%~60%；**低GI**；全谷物/杂豆占主食 1/3 以上 | 优先低GI，不主张极低碳水作为常规 |
| 蛋白质 | 0.8~1.2 g/kg（肾功能正常）；供能比 15%~20% | 糖尿病肾病按肾病方案（见第七节） |
| 脂肪 | 供能比 20%~30%；SFA <10%；以 MUFA 为主 | 橄榄油/茶籽油/山茶油 |
| 膳食纤维 | 25~30g/天（或 14g/1000kcal） | 全谷、豆类、蔬菜、菌藻 |
| 钠 | <6g 盐/天；合并高血压 <5g 盐/天 | 少用加工食品、酱料 |
| 钾 | 肾功能正常者可多补（3000mg+/天） | 深绿叶菜、豆类、低脂奶 |
| 镁 | 300~350mg/天 | 坚果、全谷、深绿叶菜 |
| 铬/锌/硒 | 按膳食指南均衡即可，不盲目大剂量 | 微量营养素以食补优先 |
| 饮水 | 1500~2000ml/天（无禁忌） | 无糖白水为主 |
| 甜味剂 | 适量、有限使用（争议仍存） | 代糖不等于"无负担"，警惕补偿性进食 |

**碳水选择的 GI 速查：**

| GI 水平 | 代表食物 |
|---------|----------|
| 低GI（<55） | 全麦、燕麦（慢煮）、荞麦、糙米、杂豆（鹰嘴豆/红豆）、薯类（蒸）、苹果/梨/草莓/樱桃/奇异果 |
| 中GI（55-70） | 全麦面包、香蕉（熟）、菠萝、甜玉米 |
| 高GI（>70） | 白米饭、白馒头、白面包、糯米饭、西瓜、南瓜（煮烂）、葡萄糖/麦芽糖 |

### 4. 食物选择：推荐 vs 限制 vs 避免

#### 4.1 推荐（绿灯食物）

| 类别 | 具体清单 |
|------|----------|
| 主食 | 燕麦、荞麦、糙米、藜麦、玉米、全麦、杂豆（红豆/绿豆/鹰嘴豆） |
| 蔬菜 | 深绿叶菜（菠菜/油菜/芹菜）、十字花科（西兰花/菜花）、菌菇、瓜茄类——每天 500g 以上 |
| 蛋白质 | 鱼虾（每周 2-3 次）、去皮禽肉、鸡蛋（每天 1 个）、豆制品、低脂奶 |
| 水果 | 低GI：苹果、梨、草莓、蓝莓、樱桃、柚子——每天 1 份（约 200g），两餐间吃 |
| 脂肪 | 橄榄油/茶籽油、坚果（每天一小把 10g）、牛油果 |
| 饮品 | 白水、淡茶、无糖黑咖啡 |

#### 4.2 限制（黄灯食物——限量吃）

| 类别 | 限制规则 |
|------|----------|
| 精制主食 | 白米饭/馒头/面条 ≤ 每餐一拳头（约 75-100g 生重），且与全谷杂豆搭配 |
| 红肉 | 每周 ≤2-3 次，每次 ≤75g（约一巴掌） |
| 全脂奶/加工奶制品 | 每天 ≤1 杯，优先低脂 |
| 高GI水果 | 香蕉/菠萝/熟西瓜 限量，不单独大量吃 |
| 食用油 | 每天 ≤25g（约 2 汤匙） |
| 天然糖 | 蜂蜜/红糖/果汁 少量，计入碳水 |

#### 4.3 避免（红灯食物）

| 类别 | 原因 |
|------|------|
| 含糖饮料 | 一瓶 500ml 含糖可乐 ≈ 50g 糖，餐后血糖陡升 |
| 果汁（含"鲜榨"） | 打掉纤维=喝糖水，果糖直入肝脏 |
| 精制甜点 | 白砂糖+白面+坏脂肪三重打击 |
| 油炸食品 | 高能量+反式脂肪+AGEs |
| 深加工肉制品 | 香肠/火腿/培根——与结直肠癌风险相关 |
| 白粥/烂面 | 高GI且营养密度低 |
| "无糖"高油糕点 | 无糖≠低能量，油脂照样升糖升脂 |

### 5. 进餐模式与技巧

| 技巧 | 具体做法 | 证据/说明 |
|------|----------|-----------|
| 进餐顺序（强推荐） | 先吃蔬菜 → 再吃蛋白质 → 最后吃主食 | RCT 证据：显著降低餐后血糖峰值与波动 |
| 餐次安排 | 3 主餐 + 1-2 次加餐（可选）；老年人可少量多餐 | 根据降糖药/胰岛素调整，防低血糖 |
| 早餐不能省 | 早餐含优质蛋白+纤维 | 防午餐过度补偿 |
| 主食等量交换 | 用全谷/杂豆/薯类"等量换"精米面，不额外加量 | 糖尿病食物交换份法 |
| 细嚼慢咽 | 每餐 20 分钟以上 | 给饱腹信号时间 |
| 烹饪方式 | 蒸/煮/炖/凉拌优先；少煎炸；蔬菜不切太碎 | 保留纤维，降GI |
| 汤类 | 餐前一小碗清汤可增饱腹（但**不喝浓汤/肉汤**） | 浓汤嘌呤+脂肪高 |
| 外出就餐 | 先点青菜，主动要求少油少盐，主食减半 | 血糖友好的"点菜心法" |

**加餐的血糖友好选择：** 无糖酸奶 + 少量坚果、一小把草莓、半个苹果、一杯淡豆浆。

### 6. 体重管理

- **核心逻辑：** 对超重/肥胖的 T2DM，**减重是改善血糖最有效的一步**。体重下降 5% 即可改善胰岛素敏感性；下降 10%-15% 有望实现血糖缓解。
- **DiRECT 研究（Lancet 2018）：** 采用结构化低能量饮食（825-853 kcal/天，约 3-5 个月）+ 体重管理支持，干预组体重平均下降 10kg；**体重下降 ≥15kg 者，糖尿病缓解率达 46%**（HbA1c<6.5% 且停降糖药至少 2 个月）。
- **适用人群：** 病程短（<6 年）、β细胞功能尚可、无严重并发症的超重/肥胖 T2DM 患者，可评估缓解潜力。
- **蛋白保护：** 减重期蛋白质 1.2-1.5 g/kg + 阻力训练，防肌肉流失（肌肉是血糖缓冲池）。
- **减重速度：** 每周 0.5-1kg 为宜；避免快速节食导致低血糖与代谢率下降。
- **平台期管理：** 调整能量梯度（减少 200-300 kcal）、增加 NEAT（日常活动量）、保证睡眠（睡眠<7h 增食欲）。

### 7. 常见误区与辟谣

| 误区 | 真相 |
|------|------|
| "糖尿病是吃糖吃出来的" | 吃糖是风险因素之一，但根本是能量过剩+胰岛素抵抗+遗传；脂肪肝与肥胖才是更强驱动 |
| "糖尿病不能吃水果" | 错。选低GI水果（苹果/梨/莓类）每天 1 份，两餐间吃，完全可行 |
| "无糖食品随便吃" | 无糖≠无碳水无能量；"无糖"饼干可能仍升糖 |
| "苦瓜/南瓜降糖能停药" | 任何食物都不能替代药物治疗；南瓜是主食类，吃多升糖 |
| "糖尿病要少吃甚至不吃主食" | 长期极低碳水增加低血糖、饥饿、营养不良风险；应"换"而非"删"——换全谷杂豆 |
| "胰岛素会上瘾" | 胰岛素是生理激素，不存在成瘾；需不需要用由医生判断 |
| "血糖正常了就可以停药停药食" | 血糖正常是干预有效的结果，停药/放开饮食需医生评估，否则反弹 |
| "只靠吃药不管嘴就行" | 药物剂量会随饮食失控不断加大，并发症风险仍在；营养是药物治疗的"减负器" |

|----------|------|------|

### 9. 给顾客的"一句话方案"与营养师沟通要点

**一句话方案（可直接对顾客说）：**
> "你先把三件事做到位：① 每顿饭先吃菜、再吃肉、最后吃主食，主食换成全谷杂豆；② 每天一斤蔬菜、一把坚果、一杯无糖酸奶，含糖饮料和果汁先戒掉；③ 体重目标减 5%-10%，每周称一次。三个月后复查血糖和糖化血红蛋白。"

**营养师沟通要点：**
- 用"胰岛素抵抗、血糖缓冲池"等比喻，不讲名词堆砌——顾客听得懂才做得动。
- 明确边界：确诊与调药由医生负责，营养师负责"吃动睡"；提醒"个体情况请咨询专业医师，遵循医嘱"。
- 不强求"完美饮食"，先消灭最大敌人（含糖饮料/白粥烂面/夜宵）。
- 与糖尿病教育结合：血糖监测记录是最好的反馈工具，让顾客看到"行为→血糖"的因果。

## 二、高血压营养管理（DASH饮食）

### 1. 疾病与营养的关联机制（病理生理）

高血压的核心是**外周血管阻力升高 + 血容量/钠负荷增加 + 血管内皮功能受损**。营养与血压的关联是多通路、可逆的：

```
高钠 → 水钠潴留 → 血容量↑ → 心输出量↑ → 血压↑
低钾 → 钠钾泵失衡 → 血管平滑肌收缩↑ → 外周阻力↑
钙/镁不足 → 血管舒张因子(一氧化氮NO)合成↓ → 血管僵硬度↑
肥胖 → 交感神经兴奋 + 肾素-血管紧张素系统(RAS)激活 → 血压↑
酒精 → 直接收缩血管 + 激活RAS → 血压↑
炎症/氧化应激 → 血管内皮损伤 → 动脉硬化 → 收缩压进行性升高
```

**关键认知：** 钠是"元凶"，钾/钙/镁是"解药"。DASH 饮食的设计原理，就是把钠降下来、把钾钙镁补上去——证据显示其降压效果接近单药。

---

### 2. 营养治疗目标（可量化）

| 目标维度 | 具体数值 | 依据 |
|----------|----------|------|
| 诊室血压 | <140/90 mmHg（一般人群）；可耐受者 <130/80 mmHg | 《中国高血压防治指南（2024修订版）》 |
| 家庭自测血压 | 均值 <135/85 mmHg | 指南 |

### 6. 体重管理

- **减重是降压的重要杠杆**：超重/肥胖高血压患者，体重每下降 1kg，收缩压约降 1 mmHg；下降 10kg，收缩压可降 5-20 mmHg。
- **腰围优先**：腹型肥胖与血压关联更紧密，减腰围比单纯减体重对降压更有效。
- **减重节奏**：每周 0.5-1kg；降压药使用者减重期注意监测血压，防药物过量导致低血压（需医生评估）。
- **联合策略**：DASH 饮食 + 减重 + 运动，三者叠加降压效果优于单一干预（DASH 联合减重研究：收缩压下降最多约 16 mmHg）。
- **平台期**：维持热量缺口 300-500 kcal/天；增加步行（每天 8000-10000 步）；保证睡眠。

### 7. 常见误区与辟谣

| 误区 | 真相 |
|------|------|
| "血压正常就停药" | 高血压是慢性病，停药需医生评估；停药反弹对血管损伤更大 |
| "只要少吃盐就行" | 限盐是基础，但补钾/钙/镁、减重、运动同样重要；DASH 是组合拳 |
| "吃芹菜/醋泡花生能降压" | 食物不能替代治疗；可能有辅助，但无足够证据替代药物 |
| "有高血压不能喝牛奶" | 恰恰相反，低脂奶补钙有益降压（无乳糖不耐即可） |
| "高血压没症状就不用管" | 高血压是"无声杀手"，没症状不代表血管没受损 |
| "低钠盐所有人适用" | 低钠盐含钾，肾衰/高钾血症者禁用——需遵医嘱 |
| "泡脚/按摩能治高血压" | 只能辅助放松，不能替代降压 |

| 监测指标 | 频率 | 说明 |
|----------|------|------|
| 家庭血压 | 每天早晚各 1 次（连续 7 天取均值） | 复诊前监测周尤其重要 |
| 诊室血压 | 起始每 1-3 个月 | 稳定后每 3-6 个月 |
| 体重/腰围 | 每周称重，每月量腰围 | 减重有效性 |
| 电解质（血钾/血钠） | 每 6-12 个月（尤其利尿剂使用者） | 防低钾/高钾 |
| 肾功能（肌酐/eGFR） | 每 6-12 个月 | 高血压肾损害早期筛查 |
| 血脂、血糖 | 每 6-12 个月 | 与代谢综合征共存率高 |
| 心电图 | 每年 | 靶器官损害筛查 |

**营养师随访提示：** 家庭血压记录是最佳反馈工具——让顾客把"今天盐多→明天血压高"的关联可视化，行为改变自然发生。

---

### 9. 给顾客的"一句话方案"与营养师沟通要点

**一句话方案：**
> "你把盐每天控制在 5 克以内（大约一个啤酒瓶盖），炒菜用限盐勺、先尝后加盐；每天一斤蔬菜、一个水果、一杯低脂奶把钾钙镁补上；体重减 5%-10%。先做到这三点，一个月后量血压看变化。"

**营养师沟通要点：**
- 高血压"三低"（知晓/治疗/控制率低）——先帮顾客树立"测起来、记下来"的习惯。
- 用"隐形钠"清单让顾客惊讶于"自己没觉得咸但盐超标"。
- 强调 DASH 是"加"法（加蔬菜水果奶坚果）而非单纯"减"法——更容易坚持。
- 提醒：血压药物调整务必遵医嘱；营养改善后血压下降，减药需医生决策。
- 合规：不引导"把你的血压记录发我分析"，改为"你记录好，复诊时给医生看，也给自己看趋势"。

## 三、高脂血症营养管理

### 1. 疾病与营养的关联机制（病理生理）

高脂血症是**血脂代谢紊乱**的统称，核心异常包括 LDL-C 升高（"坏胆固醇"）、TG 升高、HDL-C 降低。营养的致病链条：

```
高饱和脂肪/反式脂肪 → LDL-C↑ → LDL 氧化（ox-LDL）→ 动脉粥样硬化斑块
高糖/精制碳水 → 肝脏 VLDL 合成↑ → TG↑ → 小而密 LDL↑ → 斑块不稳定
反式脂肪（油炸/植脂末）→ LDL↑ + HDL↓ 双重危害
植物甾醇/可溶性纤维不足 → 肠道胆固醇重吸收↑ → 血胆固醇↑
肥胖+胰岛素抵抗 → 脂蛋白脂酶活性↓ → TG 清除↓
```

**关键认知：** 血脂异常的干预要看"三驾马车"——LDL-C（动脉粥样硬化的主犯）、TG（可被饮食快速改变）、HDL-C（保护因素）。**饮食对 TG 最敏感，对 LDL-C 中度敏感**。

---

### 2. 营养治疗目标（可量化）

| 血脂指标 | 目标值 | 分层说明 |
|----------|--------|----------|
| LDL-C（主要靶点） | 超高危 <1.4；极高危 <1.8；高危 <2.6；中危/低危 <2.6~3.4 mmol/L | 《中国血脂管理指南（2023）》，需按 ASCVD 风险分层 |
| TG | <1.7 mmol/L（正常）；≥5.6 mmol/L 需防急性胰腺炎 | 高危/中危 TG ≥2.3 mmol/L 应干预 |
| HDL-C | 男 >1.0，女 >1.3 mmol/L | 越高越好 |
| 非HDL-C | 比 LDL-C 目标 +0.8 mmol/L | 综合致动脉粥样硬化胆固醇 |
| 体重 | 超重者降 5%-10% | 降 TG 尤其显著 |
| 运动 | 每周 ≥150min 中强度 + 每周 2 次抗阻 | 提 HDL、降 TG |

**血脂异常简易分型与营养重点：**

| 类型 | 化验特征 | 营养重点 |
|------|----------|----------|
| 高胆固醇血症 | LDL-C↑（TG 正常） | 减饱和脂肪/反式脂肪、加可溶性纤维/植物甾醇 |
| 高甘油三酯血症 | TG↑ | 减糖减精制碳水、减重、限酒、n-3 鱼油 |
| 混合型 | 两者都高 | 综合干预，能量负平衡 + 减碳 + 好油 |
| 低HDL-C | HDL-C↓ | 运动、MUFA（橄榄油）、戒烟、适量酒精（限） |

### 3. 营养素方案表

| 营养素 | 建议值 | 说明 |
|--------|--------|------|
| 总能量 | 超重/肥胖者减 300-500 kcal/天 | 能量负平衡直接降 TG |
| 碳水化合物 | 供能比 45%-55%；**TG 高者尤其限精制糖** | 精制碳水是 TG 的主要饮食驱动 |
| 蛋白质 | 供能比 15%-20% | 多选植物蛋白（豆类）与鱼 |
| 脂肪总量 | 供能比 20%-30% | 不过分低脂（影响 HDL），重在结构 |
| 饱和脂肪（SFA） | <7%-10% 供能比 | 动物肥肉、黄油、椰子油/棕榈油 |
| 反式脂肪 | 尽量为 0 | 油炸、植脂末、起酥油、代可可脂 |
| 单不饱和脂肪（MUFA） | 供能比 10%-15% | 橄榄油/茶籽油/牛油果/坚果 |

| 膳食胆固醇 | 建议 <300mg/天 | 指南仍建议限量，重点在脂肪结构 |
| 钠 | <5-6g 盐/天 | 合并高血压者更严 |

**"好油换坏油"速查表：**

| 坏脂肪（减） | 好脂肪（增） |
|--------------|--------------|
| 猪油/牛油/黄油 | 橄榄油/茶籽油 |
| 油炸食品 | 凉拌/蒸煮用油 |
| 肥肉/五花肉 | 瘦肉/去皮禽肉 |
| 椰子油/棕榈油（SFA高） | 牛油果/坚果 |
| 植脂末/奶精（反式） | 纯牛奶/无糖酸奶 |
| 加工肉 | 深海鱼（三文鱼/鲭鱼/沙丁鱼） |

### 4. 食物选择：推荐 vs 限制 vs 避免

#### 4.1 推荐（绿灯）

| 类别 | 具体清单 |
|------|----------|
| 全谷/豆类 | 燕麦（可溶性纤维冠军）、豆类（红豆/绿豆/鹰嘴豆）、荞麦、糙米 |
| 蔬菜 | 每天 500g 以上，菌菇海带木耳（多糖降脂） |
| 水果 | 每天 200-300g：苹果/柑橘/浆果/猕猴桃 |
| 深海鱼 | 三文鱼/鲭鱼/秋刀鱼/沙丁鱼——每周 2 次 |
| 坚果 | 每天 10g：核桃/杏仁/腰果（不油炸） |
| 好油 | 橄榄油/茶籽油/亚麻籽油 |
| 低脂蛋白 | 去皮禽肉、鱼虾、蛋清、豆制品、低脂奶 |

#### 4.2 限制（黄灯）

| 类别 | 限制规则 |
|------|----------|
| 红肉 | 每周 ≤2-3 次，每次 ≤75g |
| 全蛋 | 每天 ≤1 个（蛋黄胆固醇偏高但营养密度高，适量 OK） |
| 精制主食 | 白米面减半，与全谷搭配 |
| 天然甜食 | 蜂蜜/红糖每周 ≤2 次 |
| 坚果总量 | 每天一把为限（能量密度高） |

#### 4.3 避免（红灯）

| 类别 | 原因 |
|------|------|
| 反式脂肪来源 | 油炸食品、蛋糕饼干（植脂末）、奶茶（奶精）、代可可脂巧克力、起酥面包 |
| 高糖饮料 | 含糖饮料/果汁——TG 的直接推手 |
| 动物内脏 | 肝/脑/肥肠——胆固醇与饱和脂肪高 |
| 加工肉 | 香肠/培根/腊肉 |
| 高油外卖 | 重油炒菜、油炸小食 |
| 大量酒精 | 升 TG；啤酒尤甚 |

### 5. 进餐模式与技巧

| 技巧 | 做法 |
|------|------|
| 燕麦当早餐 | 每天 40-50g 燕麦（非即食麦片），配牛奶/豆浆 |
| 餐盘比例 | 1/2 蔬菜 + 1/4 蛋白 + 1/4 全谷 |
| 先菜后饭 | 同糖尿病，先纤维后碳水，稳血糖也利血脂 |
| 烹饪方式 | 蒸/煮/炖/凉拌为主，少油少煎炸 |
| 坚果入餐 | 坚果拌酸奶/沙拉，替代零食 |
| 用醋调味 | 醋+橄榄油凉拌，天然低脂高纤 |
| 外食防油 | 过水涮油、少点勾芡/干锅/油炸菜 |
| 限酒 | 高 TG 者建议戒酒；一般男性 ≤25g 酒精/天 |

### 6. 体重管理

- **TG 与体重高度联动**：体重下降 5%-10%，TG 可下降 20%-40%——是降 TG 最有效的一步。
- **LDL-C 减重效应稍弱**：但减重 + 可溶性纤维 + 植物甾醇组合，可协同降低 LDL-C 5%-15%。
- **减脂保肌**：蛋白质 1.2-1.5 g/kg + 抗阻训练，防止减重期 HDL 进一步下降。
- **平台期**：增加运动频率（每周 4-5 次）、调整进餐时间（晚餐提前、不加夜宵）。
- **体重正常但血脂高者**：重点是脂肪结构和精制碳水，不减能量也可显著改善（尤其 TG）。

### 7. 常见误区与辟谣

| 误区 | 真相 |
|------|------|
| "血脂高是吃肉太多，少吃肉就行" | 重点不是肉，是脂肪结构（好油换坏油）和精制糖；纯素食也可能 TG 高（糖多） |
| "吃蛋黄升高胆固醇，不敢吃" | 每天 1 个全蛋对多数人安全；膳食胆固醇对血胆固醇影响有限 |
| "血脂正常就万事大吉" | 血脂要按风险分层看目标；HDL 低、TG 高同样是风险 |
| "只吃他汀就行，不用管嘴" | 饮食可使 LDL 再降 10%-20%，并显著降 TG——药物+饮食双管齐下 |
| "吃点鱼油补剂就能降血脂" | 需足够剂量 EPA+DHA（2-4g/天）才降 TG，普通低剂量不够；且鱼油是营养素补充剂非药物，需遵医嘱 |
| "完全不吃油" | 极端低脂反使 HDL 下降；关键是好油适量（每天 25g 左右） |
| "血脂高不能吃坚果" | 适量坚果（每天一把）反而有助降 LDL |

### 8. 监测与随访

| 监测指标 | 频率 | 说明 |
|----------|------|------|
| 血脂全套（TC/LDL-C/TG/HDL-C） | 饮食干预后 4-6 周复查；达标后每 3-6 个月 | 验证饮食方案有效性 |
| 肝功能 | 服用他汀者每 3-6 个月 | 药物安全性监测 |
| 肌酸激酶（CK） | 服用他汀者如有肌痛时 | 他汀相关肌病排查 |
| 血糖/血压 | 每 3-6 个月 | 代谢综合征共病 |
| 体重/腰围 | 每周称重 | 减重有效性 |
| 颈动脉超声/冠脉评估 | 按风险分层，遵医嘱 | 动脉粥样硬化评估 |

**营养师随访提示：** 4-6 周复查是"证据时刻"——让顾客看到饮食改变后 LDL/TG 的数字变化，是坚持的最大动力。

---

### 9. 给顾客的"一句话方案"与营养师沟通要点

**一句话方案：**
> "你把家里的油换成橄榄油或茶籽油，每天早上一碗燕麦、一把坚果；油炸食品、奶茶、含糖饮料先戒一个月；体重减 5%。一个月后复查血脂，看数字说话。"

**营养师沟通要点：**
- 先分清是"胆固醇高"还是"甘油三酯高"——策略不同，这是专业度的第一体现。
- 用"好油换坏油"代替"少吃油"，方向积极，易执行。
- 强调 4-6 周复查验证，把营养方案变成"可测量的治疗"。
- 提醒：他汀等调脂药由医生处方，不随意停药；营养改善后能否减药由医生判断。
- 合规：不引导"把你的化验单发我"，改为"复诊时带上报告，我们对比趋势"。

## 四、肥胖/超重营养干预

### 1. 疾病与营养的关联机制（病理生理）

肥胖的本质是**长期能量摄入 > 消耗**，但驱动这一失衡的机制远比"管不住嘴"复杂：

```
能量过剩 + 高能量密度食物（高糖高脂）→ 正平衡
        → 脂肪细胞肥大 + 增生 → 脂肪组织功能障碍
        → 游离脂肪酸↑ + 炎症因子（TNF-α/IL-6/瘦素抵抗）→ 慢性低度炎症
        → 胰岛素抵抗 + 交感兴奋 + RAS 激活
        → 内脏脂肪堆积（腰围↑）→ 代谢综合征 → 心脑血管/糖尿病/脂肪肝/关节/睡眠呼吸暂停
        → 脂肪组织雌激素分泌↑ → 部分肿瘤风险↑（乳腺癌/子宫内膜癌/结直肠癌）
```

**与营养相关的关键认知：**
- **食物环境**：高加工食品（能量密度高、纤维低、成瘾性强）是肥胖流行的环境推手。
- **能量密度**：同样 100g 食物，油炸食品能量是蔬菜的 10 倍以上——"吃得多"不如"密度大"。
- **蛋白质杠杆**：高蛋白饮食（25%-30% 供能比）通过增强饱腹感、增加食物热效应、保护肌肉，提升减重成功率。
- **肠菌作用**：纤维喂养有益菌，改善短链脂肪酸（SCFA），调节食欲激素。

---

### 2. 营养治疗目标（可量化）

| 目标维度 | 具体数值 | 说明 |
|----------|----------|------|
| BMI 目标 | 18.5-23.9（中国成人） | 超重 24-27.9，肥胖 ≥28 |
| 体重下降幅度 | 3-6 个月内降 5%-10% | 改善代谢的核心幅度 |
| 减重速度 | 每周 0.5-1kg | 过快要防肌肉流失与反弹 |
| 腰围 | 男 <90cm，女 <85cm | 内脏脂肪指标 |
| 体脂率（男/女） | 男 10%-20%，女 18%-28%（参考） | 体成分分析 |
| 能量缺口 | 300-500 kcal/天（轻度限能） | 可持续的减重能量差 |
| 肌肉保护 | 减重期蛋白质 1.2-1.5 g/kg + 抗阻 | 防"减脂掉肌" |

**减重能量阶梯：**

| 强度 | 能量（kcal/天） | 减重速度 | 适用 | 说明 |
|------|----------------|----------|------|------|
| 轻度限能 | 比日常少 300-500 | 0.5kg/周 | 大多数人 | 首选，最可持续 |
| 低能量膳食（LCD） | 女 1000-1200 / 男 1200-1500 | 0.5-1kg/周 | BMI≥28 或需较快减重 | 需营养师监督 |
| 极低能量（VLCD） | 800-1000 | 1-2kg/周 | 医疗监督下短期使用 | 必须医生+营养师监督，防营养不良 |

---

### 3. 营养素方案表

| 营养素 | 建议值 | 说明 |
|--------|--------|------|
| 总能量 | 制造 300-500 kcal/天缺口 | 用"记录饮食+估算"设定 |
| 蛋白质 | 供能比 25%-30%；或 1.2-1.5 g/kg | 保肌、增饱腹、食物热效应高 |
| 碳水化合物 | 供能比 40%-45%；低GI优先 | 控糖稳食欲，但不过度低碳 |
| 脂肪 | 供能比 20%-25% | 降能量密度，好油为主 |
| 膳食纤维 | 25-30g/天（女性可到 25g，男性 30g+） | 饱腹+菌群+血糖稳定 |
| 钠 | <5-6g 盐/天 | 防水肿、协同降压 |
| 微量营养素 | 全程补齐：铁/钙/维D/锌/B族 | **减重≠减营养**，限能期最易缺 |
| 饮水 | 1500-2000ml/天 | 替代含糖饮料 |
| 酒精 | 尽量戒/限 | 空能量+开食欲 |

**减重期微量营养素"防缺口"清单：**

| 微量营养素 | 缺乏风险 | 富食来源 |
|------------|----------|----------|
| 钙 | 低能量+少奶 → 缺钙 | 低脂奶/酸奶/豆制品/深绿叶菜 |
| 维D | 限能期摄入不足 | 深海鱼/蛋黄/日晒/遵医嘱补充 |
| 铁 | 女性+少红肉 → 缺铁 | 瘦肉/动物血/深绿叶菜+维C同吃 |
| 锌 | 限能+少坚果 → 缺锌 | 生蚝/瘦肉/坚果/全谷 |
| B族（尤其B12/叶酸） | 素食+限能 → 缺乏 | 全谷/瘦肉/蛋/深绿叶菜 |

### 4. 食物选择：推荐 vs 限制 vs 避免

#### 4.1 推荐（绿灯——"多吃不长胖"）

| 类别 | 具体清单 | 理由 |
|------|----------|------|
| 深绿叶菜 | 菠菜/油菜/芹菜/生菜 | 体积大、能量极低、纤维饱腹 |
| 瓜茄类 | 黄瓜/西红柿/冬瓜/西葫芦 | 水分多、能量低 |
| 优质蛋白 | 鱼虾/鸡胸/蛋/豆制品/低脂奶 | 饱腹+保肌 |
| 全谷杂豆 | 燕麦/糙米/藜麦/鹰嘴豆 | 低GI+纤维 |
| 低糖水果 | 莓类/苹果/柚子/猕猴桃 | 替代高糖零食 |
| 菌藻类 | 木耳/海带/香菇 | 纤维+多糖，低能量 |

#### 4.2 限制（黄灯——"控制量"）

| 类别 | 限制规则 |
|------|----------|
| 精制主食 | 每餐一拳头以内 |
| 红肉 | 每周 ≤2-3 次 |
| 坚果 | 每天一小把（10g）——好但能量高 |
| 全脂奶 | 换成低脂/脱脂 |
| 根茎类 | 土豆/红薯算主食，不额外加菜 |
| 果干/果汁 | 浓缩糖，少量 |

#### 4.3 避免（红灯）

| 类别 | 原因 |
|------|------|
| 含糖饮料 | 液体糖，喝下去不觉得饱 |
| 油炸食品 | 能量密度之王 |
| 深加工零食 | 饼干/薯片/蛋糕——糖油混合+反式 |
| 夜宵 | 晚间能量堆积+影响睡眠 |
| 高油外卖 | 隐形油超标 |
| "零卡"代餐滥用 | 不可长期单一使用，营养失衡 |

### 5. 进餐模式与技巧

| 技巧 | 做法 | 说明 |
|------|------|------|
| 餐盘法 | 1/2 蔬菜 + 1/4 蛋白 + 1/4 主食 | 不用称重也能控比例 |
| 先汤后菜再肉后饭 | 清汤→蔬菜→蛋白→主食 | 增饱腹、降主食量 |
| 细嚼慢咽 | 每口咀嚼 20 次，每餐 20min+ | 饱腹信号滞后约 20min |
| 用小餐具 | 换小碗小盘 | 视觉满足、实际减量 |
| 规律三餐 | 不跳过早餐，晚餐不过晚 | 防深夜暴食 |
| 戒夜宵 | 睡前 3 小时不进食 | 能量+睡眠双重影响 |
| 记录饮食 | 拍照或写"饮食日记" | 自我觉察是减重第一工具 |
| 轻断食（可选） | 如 16:8（进食窗口 8h） | 对部分人有效，需个体化，不盲目 |
| 情绪进食管理 | 识别"饿"与"馋" | 压力/无聊进食是隐性杀手 |

### 6. 体重管理（专项深化）

- **减重三阶段管理：**
  | 阶段 | 特点 | 策略 |
  |------|------|------|
  | 快速减重期（前 2-4 周） | 掉水+初期效果好 | 建立信心，记录数据 |
  | 平台期（4-12 周后） | 代谢适应，体重停滞 | 调整能量/增加运动/换刺激（NEAT） |
  | 维持期（≥6 个月） | 最难，反弹高发 | 保持运动习惯，逐步过渡到"维持能量"，定期监测 |

- **防反弹的四个支柱：** ① 每周至少 3 次运动（有氧+抗阻）；② 保持高蛋白（20%-25% 供能比）；③ 每周固定称重（自我监测）；④ 睡眠 ≥7h（睡眠不足升 ghrelin 促食欲）。
- **肌肉保护是第一原则：** 蛋白质 1.2-1.5 g/kg + 每周 2 次抗阻训练；目标"减脂不减肌"，维持基础代谢。
- **微量营养素保障：** 减重期每天补充多种维生素矿物质（必要时在医生指导下），防止"隐性饥饿"。
- **特殊人群注意：** 老年人减重需更保守（防肌少症）、甲状腺功能减退者减重慢、糖尿病/肾病减重需专业监测。

### 7. 常见误区与辟谣

| 误区 | 真相 |
|------|------|
| "不吃主食能减肥" | 短期掉水+肌肉，反弹快；长期伤代谢。应"换"主食（全谷）而非"删" |
| "只吃单一食物（苹果/黄瓜）" | 营养失衡，易反弹；不可持续 |
| "出汗越多=减脂越多" | 出汗是脱水，不是燃脂；桑拿/暴汗服无效 |
| "减肥药一劳永逸" | 所有减重药物都需配合饮食运动，停药易反弹，且需医生处方 |
| "晚上不吃饭能瘦" | 过度饥饿导致深夜暴食+肌肉流失；应规律三餐、晚餐提前 |
| "体重没变=没效果" | 体脂降/肌肉升时体重可不变——要看腰围与体成分 |
| "吃代餐一劳永逸" | 代餐是工具不是终点，需学会"真食物"进食 |
| "越瘦越好" | 过瘦→肌少症、免疫力下降；目标是健康体成分，不是单纯低体重 |

### 8. 监测与随访

| 监测指标 | 频率 | 说明 |
|----------|------|------|
| 体重 | 每周 1 次（同一时间、同一状态） | 趋势比单次数值重要 |
| 腰围 | 每月 1 次 | 内脏脂肪指标 |
| 体成分（体脂率/肌肉量） | 每 3-6 个月 | 验证"减脂保肌" |
| 血压/血糖/血脂 | 减重 3 个月后复查 | 验证代谢获益 |
| 肝肾功能 | 每 6-12 个月 | 排除代谢异常 |
| 甲状腺功能 | 减重困难者排查 | 排除继发性肥胖 |
| 睡眠/情绪 | 每 1-3 个月（随访时问询） | 压力与睡眠是减重变量 |

**营养师随访提示：** 用"体重曲线图"（周记录连成线）替代单次称重，减少情绪波动；每次随访先问"哪件事坚持得最好"，放大正向行为。

### 9. 给顾客的"一句话方案"与营养师沟通要点

**一句话方案：**
> "我们不节食，只做三件事：① 每餐用'半盘蔬菜、一拳蛋白、一拳主食'的餐盘法；② 蛋白质吃够（鱼/蛋/豆/奶），主食换全谷；③ 每天走 8000 步+一周两次力量训练。目标每周减 0.5 公斤，三个月减 5%-8%，先让身体不饿着瘦下来。"

**营养师沟通要点：**
- 避免"减肥"羞辱感，用"改善体成分、代谢健康"的正向框架。
- 一次只改 2-3 个行为，用"小胜"积累信心。
- 强调减重是"马拉松"：平台期是正常生理适应，不是失败。
- 减重药物/手术属于医疗手段，营养师只做生活方式干预，涉及医疗决策请顾客遵医嘱。
- 合规：不承诺具体减重斤数，用"可预期范围"表达。

## 五、痛风/高尿酸血症营养管理

### 1. 疾病与营养的关联机制（病理生理）

痛风与高尿酸血症的核心是**尿酸生成增多或排泄减少**导致的**高尿酸血症（男性 >420 μmol/L，女性 >360 μmol/L）**，尿酸盐结晶沉积于关节（急性关节炎）、肾脏（尿酸性肾病）与软组织（痛风石）。营养相关机制：

```
高嘌呤食物（内脏/浓汤/贝类）→ 外源性尿酸↑
果糖（含糖饮料/果汁/蜂蜜）→ 肝脏 ATP 消耗 → 尿酸生成↑ + 排泄↓（比嘌呤更隐蔽）
酒精（尤其啤酒）→ 尿酸生成↑ + 乳酸竞争排泄↑
内脏肥胖+胰岛素抵抗 → 肾脏尿酸排泄↓（高尿酸与代谢综合征共病）
水不足 → 尿量减少 → 尿酸排泄↓ → 尿酸盐沉积风险↑
```

**关键认知：** 饮食中嘌呤只贡献血尿酸的约 20%（内源性生成占 80%），所以**营养干预不能完全靠"忌口嘌呤"**，更要抓三个杠杆：**控果糖、控酒、促排泄（喝水/减重/碱化尿液）**。

---

### 2. 营养治疗目标（可量化）

| 目标维度 | 具体数值 | 依据 |
|----------|----------|------|
| 血尿酸 | 无痛风石 <360 μmol/L；有痛风石 <300 μmol/L | 《中国高尿酸血症与痛风诊疗指南（2019）》 |
| 体重 | 超重/肥胖者减 5%-10%（**缓减，防急性发作**） | 内脏脂肪与尿酸相关 |
| 饮水 | 每天 2000ml 以上（尿量 >2000ml） | 促尿酸排泄 |
| 嘌呤摄入 | 急性期 <150mg/天；缓解期 <200mg/天（参考） | 传统分层 |
| 尿 pH | 6.2-6.9（碱化尿液促排泄） | 医学生化目标 |
| 酒精 | 急性期戒酒；缓解期严格限量（禁啤酒/白酒） | 指南 |
| 果糖 | 戒含糖饮料；减少高果糖水果/蜂蜜 | 果糖促尿酸 |

**常见食物嘌呤含量分层（每 100g）：**

| 嘌呤水平 | 数值范围 | 代表食物 |
|----------|----------|----------|
| 高嘌呤（严格限制） | 150-1000mg | 动物内脏（肝/腰/脑）、沙丁鱼/凤尾鱼/秋刀鱼、浓肉汤/火锅汤、贝类（扇贝/蛤蜊） |
| 中嘌呤（适量） | 75-150mg | 多数鱼虾（草鱼/鲈鱼/带鱼）、畜禽肉（猪牛鸡鸭）、部分豆类、香菇 |
| 低嘌呤（鼓励） | <75mg | 蛋、奶、绝大多数蔬菜、水果、米面、多数坚果 |

### 3. 营养素方案表

| 营养素 | 建议值 | 说明 |
|--------|--------|------|
| 总能量 | 超重者减 300-500 kcal/天（缓减） | 快速减重→血酮↑→尿酸排泄竞争性↓→诱发痛风 |
| 蛋白质 | 急性期 0.8 g/kg（以蛋奶为主）；缓解期 1.0 g/kg | 蛋奶几乎无嘌呤，是安全蛋白 |
| 脂肪 | 供能比 <30%，SFA 限量 | 高脂抑制尿酸排泄 |
| 碳水化合物 | 供能比 50%-60%；**戒果糖** | 果糖是隐藏杀手 |
| 嘌呤 | 急性期 <150mg/天 | 严格限制期 |
| 水 | 2000ml+/天 | 白水/淡茶为主；苏打水可辅助碱化 |
| 钠 | <5-6g 盐/天 | 合并高血压更严 |
| 维C | 适量（约 500mg/天，食物优先） | 观察性证据：可能促尿酸排泄 |
| 咖啡 | 适量（无糖黑咖啡 2-3 杯/天） | 观察性证据：可能降尿酸（不耐受者不勉强） |
| 酒精 | 急性期禁；缓解期男性 ≤25g/天（优选红酒少量） | 啤酒嘌呤+酒精双重升尿酸，最危险 |

### 4. 食物选择：推荐 vs 限制 vs 避免

#### 4.1 推荐（绿灯）

| 类别 | 具体清单 |
|------|----------|
| 乳制品 | 低脂奶/无糖酸奶（每天 1-2 份）——促尿酸排泄 |
| 蛋类 | 每天 1 个鸡蛋（安全蛋白） |
| 蔬菜 | 绝大多数蔬菜（菠菜/芹菜/黄瓜/西红柿）——素食嘌呤影响小 |
| 水果 | 低果糖水果：樱桃、草莓、蓝莓、苹果、梨、柠檬 |
| 全谷 | 燕麦/糙米/全麦（中等嘌呤，整体有益） |
| 饮品 | 白水 2000ml+、淡茶、无糖黑咖啡 |
| 樱桃 | 观察性证据：可能降低痛风发作风险 |

#### 4.2 限制（黄灯——适量）

| 类别 | 限制规则 |
|------|----------|
| 红肉 | 每周 ≤2-3 次，每次 ≤75g，先焯水去嘌呤 |
| 多数鱼虾 | 每周 ≤2-3 次，急性期暂停 |
| 豆制品 | 传统认为高嘌呤，近年证据：植物嘌呤影响小，可适量（非急性期） |
| 香菇/紫菜/海带 | 嘌呤偏高，适量 |
| 高果糖水果 | 荔枝/龙眼/熟香蕉 少量 |
| 蜂蜜 | 果糖来源，少用 |

#### 4.3 避免（红灯）

| 类别 | 原因 |
|------|------|
| 动物内脏 | 嘌呤之王 |
| 浓肉汤/火锅汤 | 嘌呤溶入汤中 |
| 贝类/沙丁鱼/凤尾鱼 | 高嘌呤海鲜 |
| 啤酒/白酒 | 啤酒=嘌呤+酒精双重打击；白酒促尿酸 |
| 含糖饮料/果汁 | 果糖直接促尿酸生成 |
| 剧烈快速减肥 | 促尿酸急升诱发痛风 |
| 高嘌呤+高脂组合 | 动物内脏+油炸（双重负担） |

### 5. 进餐模式与技巧

| 技巧 | 做法 |
|------|------|
| 肉类先焯水 | 嘌呤溶于水，弃汤弃水再烹饪 |
| 多喝汤不如多喝水 | 肉汤/海鲜汤嘌呤高，白水 2000ml+ |
| 蛋白质以蛋奶为主 | 急性期特别适用 |
| 控果糖 | 戒含糖饮料，果汁换成整果，蜂蜜限量 |
| 缓减体重 | 每周减 0.5kg 以内，防急性发作 |
| 碱化食物 | 多吃蔬菜水果，必要时遵医嘱用碳酸氢钠 |
| 规律进餐 | 不暴饮暴食，不熬夜（熬夜+高嘌呤夜宵=诱发组合） |
| 急性期饮食 | 暂停高/中嘌呤食物，以蛋奶+蔬菜+低嘌呤主食为主，大量饮水 |

---

### 6. 体重管理

- **肥胖与高尿酸强关联**：内脏脂肪促尿酸生成、抑制排泄；减重是长期降尿酸的重要杠杆。
- **缓减原则（铁律）**：快速减重（每周 >1.5kg）会因脂肪分解产生酮体，酮体与尿酸竞争肾小管排泄 → **血尿酸反而升高 → 诱发急性痛风**。目标每周 0.5kg 以内。
- **减重方式**：低嘌呤+低能量饮食；避免"生酮/极低碳水"（酮体↑=风险）。
- **预期获益**：体重下降 5%-10%，血尿酸可下降约 10%-30%（个体差异）。
- **配合运动**：中等强度有氧为主；剧烈运动（大量出汗+乳酸）可促尿酸升高，注意补水和适度。

### 7. 常见误区与辟谣

| 误区 | 真相 |
|------|------|
| "痛风是吃出来的，忌口就行" | 饮食嘌呤只占血尿酸 20%；忌口重要但不够，需综合控代谢+必要时药物 |
| "豆制品完全不能吃" | 近年证据显示植物嘌呤对血尿酸影响小，非急性期可适量吃豆腐/豆浆 |
| "痛风不能吃蔬菜" | 多数蔬菜嘌呤低且有利尿作用；香菇/芦笋适量即可 |
| "喝啤酒不行，喝白酒可以" | 白酒同样升尿酸（酒精+乳酸竞争排泄），啤酒还带嘌呤，都该限 |
| "果汁健康，多喝无妨" | 果汁果糖高，比等量可乐更促尿酸！鲜榨果汁同样要戒 |
| "不痛了就放开吃" | 无症状高尿酸期正是干预窗口，放任会损伤肾脏 |
| "减肥能立刻降尿酸" | 快速减重反而诱发痛风；要"缓减"才安全有效 |
| "吃维生素C补剂能替代治疗" | 维C只是辅助，降尿酸药物由医生决定 |

---

### 8. 监测与随访

| 监测指标 | 频率 | 说明 |
|----------|------|------|
| 血尿酸 | 起始治疗后每 2-4 周；达标后每 3 个月 | 目标是 <360（无痛风石）/ <300（有痛风石）μmol/L |
| 尿常规/尿 pH | 每 3-6 个月 | 评估尿酸性肾病与碱化效果 |
| 肾功能（肌酐/eGFR） | 每 3-6 个月 | 高尿酸肾病筛查 |
| 关节症状 | 随访时问询发作频率/疼痛 | 评估控制效果 |
| 血压/血糖/血脂 | 每 6-12 个月 | 与代谢综合征共病 |
| 体重 | 每周称重（缓减） | 减重有效性 |

**营养师随访提示：** 急性发作后 2 周内不调整降尿酸方案（遵医嘱）；血尿酸要"缓降"，骤降也可能诱发发作。

---

### 9. 给顾客的"一句话方案"与营养师沟通要点

**一句话方案：**
> "你先把三样戒掉：啤酒、白酒、含糖饮料（包括果汁）；每天喝够 2000 毫升水；蛋白质改成以蛋奶为主，肉先焯水再吃；体重每周减不超过 1 斤，慢慢来。三个月复查血尿酸。"

**营养师沟通要点：**
- 破除"痛风全靠忌口"误区，重点讲果糖和酒精的隐蔽危害。
- 强调"缓减体重"——很多人急于减肥反诱发痛风。
- 尿酸盐结晶已沉积者，长期降尿酸需遵医嘱用药，营养师做生活方式协同。
- 合规：不引导"把尿酸化验单发我分析"，改为"复诊给医生看"；急性发作期提示就医。

## 六、非酒精性脂肪肝（NAFLD）营养管理

### 1. 疾病与营养的关联机制（病理生理）

非酒精性脂肪性肝病（NAFLD，现国际上倡议更名 MAFLD——代谢相关脂肪性肝病）指**无过量饮酒**等其他病因的肝脏脂肪沉积。营养是首要病因：

```
高能量 + 果糖/精制碳水过量 → 肝脏脂肪从头合成（DNL）↑
        → 肝细胞甘油三酯堆积（脂肪变性）→ 单纯性脂肪肝
        → 氧化应激 + 炎症（NASH）→ 脂肪性肝炎
        → 肝星状细胞活化 → 纤维化 → 肝硬化
果糖（含糖饮料）→ 不依赖胰岛素，直接入肝，是脂肪肝"第一燃料"
肥胖+胰岛素抵抗 → 脂肪组织释放游离脂肪酸入肝 → 肝脂↑
肠菌失调 → 内毒素/炎症因子经门静脉入肝 → 炎症加重
```

**关键认知：** 肝脏是"全身代谢的中央处理器"，脂肪肝不是孤立的"肝病"，而是**代谢综合征的肝脏表现**——它和糖尿病、血脂异常、肥胖互为因果。

### 2. 营养治疗目标（可量化）

| 目标维度 | 具体数值 | 说明 |
|----------|----------|------|
| 体重 | 减重 5%-10% → 肝脂肪显著减少；减重 ≥10% → 纤维化可能逆转 | 指南核心干预 |
| 腰围 | 男 <90cm，女 <85cm | 内脏脂肪与肝脂相关 |
| 肝功能（ALT/AST） | 降至正常范围 | 炎症改善指标 |
| 血糖/血脂 | 糖尿病者按糖尿病目标；血脂按血脂目标 | 代谢共病管理 |
| 戒酒 | 绝对戒酒（NAFLD 本身虽非酒精所致，但酒精叠加伤肝） | 安全边界 |
| 果糖 | 戒含糖饮料与果汁 | 最大可改因素之一 |
| 能量 | 超重者负平衡 300-500 kcal/天 | 减重驱动 |

| 类别 | 具体清单 |
|------|----------|
| 全谷 | 燕麦、糙米、荞麦、全麦——替代精米面 |
| 蔬菜 | 深绿叶菜、十字花科、洋葱/大蒜（硫化物护肝） |
| 优质蛋白 | 鱼虾、豆制品、去皮禽肉、蛋 |
| 深海鱼 | 三文鱼/鲭鱼——n-3 抗炎 |
| 坚果 | 每天一小把核桃/杏仁 |
| 好油 | 橄榄油/茶籽油 |
| 饮品 | 白水、无糖咖啡、淡茶 |

#### 4.2 限制（黄灯）

| 类别 | 限制规则 |
|------|----------|
| 精制主食 | 减半，换全谷 |
| 红肉 | 每周 ≤2 次 |
| 高果糖水果 | 荔枝/龙眼/熟香蕉 少量 |
| 蜂蜜/红糖 | 尽量不用 |

#### 4.3 避免（红灯）

| 类别 | 原因 |
|------|------|
| 含糖饮料/果汁 | 果糖直驱肝脏脂肪合成 |
| 酒精（任何量） | 叠加肝损伤 |
| 油炸食品 | 高能量+坏脂肪+AGEs |
| 加工肉/内脏 | 高脂肪+潜在肝毒性 |
| 高果葡糖浆食品 | 含糖甜点/奶茶/冰激凌 |
| 盲目"补肝"偏方 | 不明成分可能加重肝损——遵医嘱 |

### 5. 进餐模式与技巧

| 技巧 | 做法 |
|------|------|
| 减重节奏 | 每周 0.5-1kg，目标 3-6 个月减 5%-10% |
| 低碳水晚餐 | 晚餐主食减半（晚间的碳水更易转肝脂） |
| 进食窗口 | 尽量避免深夜进食；间隔 12h 以上不进食（间歇性窗口可考虑） |
| 咖啡习惯 | 每天 2-3 杯无糖咖啡（如能耐受） |
| 烹饪 | 蒸煮炖拌，少油；不喝菜汤 |
| 规律运动 | 每周 ≥150min 有氧 + 2 次抗阻（运动直接降肝脂） |
| 戒"夜宵+啤酒"组合 | 深夜高能量是脂肪肝的加速器 |

### 6. 体重管理

- **减重是 NAFLD 的唯一一线核心治疗**（无论药物是否使用，都需减重）。
- **剂量-反应关系：** 减重 5% → 肝脂肪显著下降；减重 7%-10% → NASH 炎症缓解；减重 ≥10% → **肝纤维化可能逆转**。
- **减重速度**：每周 0.5-1kg；过快减重（如 VLCD 快速）虽短期降肝脂，但需医疗监督，防营养不良与胆结石。
- **运动独立于减重获益**：即使体重未降，规律运动也能降低肝脂肪（运动直接消耗肝内甘油三酯）。
- **保肌**：蛋白质 1.2-1.5 g/kg + 抗阻，防肌少性脂肪肝（少肌合并脂肪肝是更差预后）。

### 7. 常见误区与辟谣

| 误区 | 真相 |
|------|------|
| "脂肪肝是吃油太多" | 主因是能量过剩+果糖/精制碳水；"瘦子脂肪肝"也不少（隐性肥胖/肌少） |
| "不喝酒就没问题" | NAFLD 本身就与酒精无关，肝损伤照样进展 |
| "瘦子不会有脂肪肝" | 约 10%-20% 脂肪肝患者体重正常——内脏脂肪与肌肉量才是关键 |
| "脂肪肝不用管，肝酶正常就没事" | 肝酶可正常但有组织学损伤；需影像随访 |
| "吃保肝营养素就能逆转" | 减重是基石；营养素（如维E）在医生指导下辅助 |
| "喝祛湿茶/偏方护肝" | 不明成分可能肝毒性；真正的"护肝"是减重+戒酒+戒果糖 |
| "脂肪肝早晚会变肝癌，没救" | 早期脂肪肝可完全逆转；重在早干预、长期坚持 |

| 监测指标 | 频率 | 说明 |
|----------|------|------|
| 腹部超声 | 每 6-12 个月 | 肝脂肪/纤维化粗筛 |
| 肝功能（ALT/AST/GGT） | 每 3-6 个月 | 炎症活动 |

| 体重/腰围 | 每周称重 | 减重有效性 |
| 尿酸 | 每 6-12 个月 | 常伴高尿酸 |

**营养师随访提示：** B 超的"脂肪肝消失"是极具说服力的正反馈——用它激励顾客坚持减重。

---

### 9. 给顾客的"一句话方案"与营养师沟通要点

**一句话方案：**
> "你的肝不是吃坏了，是'喂多了'。先把含糖饮料和果汁彻底戒掉，主食换全谷，晚饭主食减半；每周运动 4 次、每次 40 分钟；目标半年减重 10%。减重 5% 肝脏脂肪就明显减少，减到 10% 肝脏的'疤痕'都可能逆转。"

**营养师沟通要点：**
- 用"肝脏是代谢中央处理器"建立整体观——脂肪肝和血糖血脂是一回事。
- 强调"可逆转"，给希望；同时讲清"不管它就会进展"的风险。
- 维E/保肝药等由医生决策，营养师不处方。
- 合规：不引导顾客上传 B 超/化验单求分析，建议正规医院随访。

## 七、慢性肾病（CKD）营养管理

### 1. 疾病与营养的关联机制（病理生理）

慢性肾脏病（CKD）按肾小球滤过率（eGFR）分 1-5 期，营养管理贯穿全程。肾脏是"全身过滤器"和"代谢器官"，肾衰时营养代谢全面紊乱：

```
肾功能下降 → 代谢废物（尿素氮/肌酐）蓄积 → 食欲差、恶心（尿毒症症状）
        → 蛋白质代谢：必须由肾脏排泄的尿素生成受限 → 需低蛋白饮食减负
        → 但蛋白摄入不足 → 营养不良/肌少（CKD 患者死亡独立危险因素）→ 两难平衡
        → 磷排泄↓ → 高磷血症 → 继发性甲旁亢 → 肾性骨病
        → 钾排泄↓ → 高钾血症（心律失常风险）→ 限钾
        → 促红细胞生成素↓ → 肾性贫血 → 需铁
        → 钙磷代谢紊乱 + 维D活化↓ → 骨质疏松
        → 水钠潴留 → 水肿/高血压/心衰 → 限钠限水
糖尿病/高血压是 CKD 两大病因 → 原发病的营养管理同步进行
```

**核心矛盾：** CKD 营养是"既要低蛋白减负，又要防营养不良"的走钢丝——所以必须有分期的蛋白方案和充足能量。

---

### 2. 营养治疗目标（可量化）

| 目标维度 | 具体数值 | 依据 |
|----------|----------|------|
| 分期目标 | 延缓 eGFR 下降、推迟进入透析 | 《中国慢性肾脏病营养治疗指南》 |
| 蛋白质（非透析） | CKD1-2 期 0.8 g/kg；CKD3-5 期 0.6 g/kg（+α-酮酸） | 指南分层 |
| 蛋白质（透析） | 血液透析 1.2 g/kg；腹膜透析 1.2-1.3 g/kg | 透析丢蛋白需补 |
| 能量 | 30-35 kcal/kg（60 岁以上可适当下调） | 防营养不良 |
| 钠 | <5g 盐/天（水肿/高血压者更严） | 控水降压 |
| 钾 | 按血钾调整：高钾者限钾 | 防高钾血症 |

### 6. 体重管理

- **CKD 的体重管理以"防营养不良"为底线**：多数 CKD 患者（尤其 4-5 期）面临的是**消耗与肌少**，而非肥胖——营养师要先保营养，再谈减重。
- **超重/肥胖的早期 CKD（1-2 期）**：适度减重（每周 0.5kg）可延缓肾病进展、改善血压血糖；但能量不宜低于 25 kcal/kg。
- **透析期**：体重管理关注"干体重"（透析后理想体重）与营养状态平衡；透析患者蛋白需求高，不能盲目节食。
- **肌少症预防（重要）**：保证蛋白质摄入 + 抗阻训练（遵医嘱适度），肌少是 CKD 预后不良标志。
- **监测工具**：每周称重、每月营养筛查（如 MIS/GLIM）、体成分分析（水肿干扰评估，需结合）。

---

### 7. 常见误区与辟谣

| 误区 | 真相 |
|------|------|
| "肾不好就少吃蛋白质" | 盲目低蛋白→营养不良/肌少→死亡率升高；必须按分期定蛋白并保证优质 |
| "肾病不能吃豆腐" | 适量豆制品（非急性期）可接受；关键是总蛋白与磷控制 |
| "肾病多喝水排毒" | 少尿/水肿/透析者要"量出为入"，多喝水会加重心衰 |
| "吃香蕉补钾，人人适合" | CKD 患者高钾危险！香蕉对晚期肾病是"毒果" |
| "偏方/营养品能'补肾'" | 不明成分加重肾负担；规范营养管理才是正道 |
| "透析了就可以随便吃" | 透析后蛋白需求增加、钾磷仍需管理，只是口径变了 |
| "肌酐高就得多吃营养品" | 蛋白粉/补剂需遵医嘱；过量蛋白增加肾脏负担 |

### 8. 监测与随访

| 监测指标 | 频率 | 说明 |
|----------|------|------|
| eGFR/血肌酐 | 每 3-6 个月（稳定后 6-12 个月） | 分期核心指标 |
| 尿蛋白/尿微量白蛋白 | 每 3-6 个月 | 病情活动性 |
| 血钾/血磷/血钙 | 每 3 个月（异常时更频） | 电解质管理核心 |
| 血白蛋白/前白蛋白 | 每 3 个月 | 营养状态 |
| 血红蛋白 | 每 3 个月 | 肾性贫血 |
| 血压 | 家庭血压每天 + 复诊 | 高血压与肾病互为因果 |
| 体重 | 每周（判断水肿与营养） | 干体重管理 |
| 25-羟维D/甲状旁腺激素 | 每 6-12 个月 | 肾性骨病 |

**营养师随访提示：** CKD 营养是"多学科协作"样板——营养师必须与肾内科医生、护士紧密配合，所有电解质/蛋白调整都要看最新化验并遵医嘱。

### 9. 给顾客的"一句话方案"与营养师沟通要点

**一句话方案：**
> "你的肾现在需要'减负不减营养'：蛋白质每天按医嘱控制在 X 克，其中一半以上选鸡蛋、瘦肉、鱼；盐每天小于 5 克；蔬菜先焯水再炒；不喝汤、不喝碳酸饮料；每天记体重。具体吃多少，我们每三个月按化验单调整。"

**营养师沟通要点：**
- CKD 方案必须"看化验说话"——钾/磷/蛋白目标因人而异，绝不套模板。
- 强调与肾内科医生同步，营养师不做处方决策。
- 用"减负不减营养"化解顾客"少吃饭怕虚"的焦虑。
- 合规：所有调整需遵医嘱；不引导顾客上传化验单到平台求方案，强调线下随诊。

## 八、肿瘤营养管理

### 1. 疾病与营养的关联机制（病理生理）

肿瘤患者的营养问题来自疾病本身与治疗双重打击，核心是**营养不良-炎症-代谢异常综合征**：

```
肿瘤代谢特征：
  → 糖酵解增强（Warburg效应）+ 蛋白分解（骨骼肌流失）+ 脂肪动员
  → 促炎因子（TNF-α/IL-6）↑ → 全身炎症反应（SIR）
  → 厌食（食欲中枢受抑）+ 味觉改变 + 治疗副作用（恶心/呕吐/黏膜炎/腹泻）
  → 体重下降 → 骨骼肌丢失 → 恶病质（癌性恶病质，1/3 肿瘤患者死于营养不良相关）
治疗副作用（放化疗/手术）：
  → 口腔黏膜炎→进食痛；消化道反应→吸收障碍；味嗅觉改变→厌食
  → 炎症+应激 → 代谢率升高 → 能量需求↑
```

**关键认知：** 营养不良影响治疗耐受性（化疗减量/中断）、感染风险、生活质量和生存期。**营养支持不是"补品"而是"治疗"**——因此国际指南将营养治疗列为肿瘤的"一线/基础治疗"。

---

### 2. 营养治疗目标（可量化）

| 目标维度 | 具体数值 | 说明 |
|----------|----------|------|
| 营养筛查 | 确诊即筛查（NRS2002/PG-SGA） | 高危者进入营养治疗 |
| 能量 | 25-30 kcal/kg/天（活动期） | 恶病质可增至 30-35 |
| 蛋白质 | 1.2-1.5 g/kg（稳定期）；1.5-2.0 g/kg（严重消耗/治疗期） | 防肌少、促修复 |
| n-3（EPA） | 每日 EPA 约 2g（恶病质） | 抗炎、保护肌肉 |
| 体重 | 治疗期尽量维持体重（下降 <5%） | 体重下降是预后不良信号 |
| 肌肉量 | 保持/增加骨骼肌 | 治疗耐受的关键 |
| 蛋白储备 | 血清白蛋白 ≥35g/L（参考） | 营养评估指标 |

**肿瘤营养治疗"五阶梯"：**

| 阶梯 | 措施 | 适用 |
|------|------|------|
| 第1阶梯 | 营养教育与饮食指导 | 能正常进食、营养风险低 |
| 第2阶梯 | 口服营养补充（ONS） | 饮食摄入不足（<目标量 60%） |
| 第3阶梯 | 部分肠内营养（EN） | 口服仍不足 |
| 第4阶梯 | 全肠内营养（TEN） | 无法经口进食但肠道可用 |
| 第5阶梯 | 肠外营养（PN，静脉） | 肠功能障碍/EN 不耐受 |
**原则：EN 优先、能经口则经口、逐级升阶；凡治疗期进食不足，尽早营养支持，不要等"瘦得不行"再补。**

---

### 3. 营养素方案表

| 营养素 | 建议值 | 说明 |
|--------|--------|------|
| 能量 | 25-30 kcal/kg/天；恶病质 30-35 | 保证能量防蛋白分解供能 |
| 蛋白质 | 1.2-2.0 g/kg（分阶段） | 优质蛋白：蛋/奶/鱼/瘦肉/豆制品 |
| n-3（EPA+DHA） | EPA 2g/天（恶病质，遵医嘱） | 抗炎、抑制肌肉分解 |
| 脂肪 | 供能比 25%-35% | 能量密度高、升糖慢 |
| 碳水化合物 | 供能比 40%-55%；适量 | 不追求极低碳（除非医嘱） |
| 膳食纤维 | 25-30g/天（便秘者加，腹泻者减） | 依治疗副作用调整 |
| 微量营养素 | 全面补充（遵医嘱） | 放化疗消耗大；不盲目大剂量抗氧化剂 |
| 水 | 2000ml+/天（无禁忌） | 防脱水与便秘 |
| 谷氨酰胺 | 黏膜炎/腹泻时可考虑（遵医嘱） | 肠黏膜营养 |
| 精氨酸/β-羟基-β-甲基丁酸酯 | 围手术期/恶病质（遵医嘱） | 免疫营养要素 |

**治疗期常见症状的进食对策：**

| 治疗副作用 | 营养对策 |
|------------|----------|
| 恶心/呕吐 | 少量多餐；清淡、凉食、酸味开胃；避开油腻气味 |
| 口腔黏膜炎 | 温凉流质/软食；避免酸辣烫硬；可用吸管 |
| 味觉改变 | 增香调味（香草/柠檬）；金属味者用瓷餐具 |
| 腹泻 | 低纤维、补液、补电解质；暂停乳制品（继发乳糖不耐） |
| 便秘 | 多喝水、可溶性纤维（燕麦/果胶）、适度运动 |
| 食欲差 | 高能量高蛋白小食：蛋羹、酸奶、坚果酱、鱼蓉粥 |
| 疲劳 | 充足能量+优质蛋白+适量铁 |

### 4. 食物选择：推荐 vs 限制 vs 避免

#### 4.1 推荐（绿灯——治疗期营养强化）

| 类别 | 具体清单 |
|------|----------|
| 高生物价蛋白 | 鸡蛋、低脂奶/酸奶、鱼肉（清蒸）、鸡胸肉、豆腐/豆浆 |
| 能量密度食物 | 坚果酱（花生酱/芝麻酱）、牛油果、橄榄油（拌菜） |
| 易消化碳水 | 米粥/烂面/藕粉/山药（食欲差时） |
| 抗炎食材 | 深海鱼、亚麻籽、姜黄（适量）、深色蔬果 |
| 补水 | 白水、淡汤、无糖藕粉/米汤 |

#### 4.2 限制（黄灯）

| 类别 | 限制规则 |
|------|----------|
| 红肉/加工肉 | 加工肉尽量避免；红肉每周 ≤2 次 |
| 腌制/熏烤食品 | 含亚硝胺/多环芳烃，尽量避免 |
| 酒精 | 治疗期戒酒（头颈部肿瘤绝对禁酒） |
| 高糖甜点 | 能量空+血糖波动，少量 |
| 油炸食品 | 加重恶心/消化不良 |

#### 4.3 避免（红灯）

| 类别 | 原因 |
|------|------|
| 生食（生鱼片/生蚝/溏心蛋） | 免疫低下期感染风险（中性粒细胞减少者严格避免） |
| 未消毒食品/久放剩菜 | 食源性感染 |
| "饿死肿瘤"节食 | 先饿死的是自己——加速恶病质 |
| 大量不明"抗癌营养素" | 可能干扰放化疗（如大剂量抗氧化剂在放疗期间争议） |
| 偏方/断食排毒 | 延误规范营养治疗 |

### 5. 进餐模式与技巧

| 技巧 | 做法 |
|------|------|
| 少量多餐 | 每天 6-8 次小餐（3 主餐 + 3-5 加餐） | 
| 高营养密度优先 | 每口都算数：蛋羹、酸奶、坚果糊、营养奶昔 |
| "干稀分开" | 进餐时不大量喝水，餐间补水——增食欲 |
| 温度适宜 | 温凉为主，不烫（黏膜炎时尤其） |
| 气味管理 | 避免油烟气味；家人分餐；开窗通风 |
| 营养强化 | 粥/面里加蛋白粉/肉末/蛋黄（在医生指导下） |
| 治疗日饮食 | 放化疗前后 2 小时进食；当天清淡 |
| 记录饮食 | 记录每天进食量与体重——客观评估摄入 |

### 6. 体重管理

- **肿瘤期体重管理的目标是"防下降、保肌肉"**，与普通减重完全相反——这是一个常被误解的点。
- **每周称重**：体重较治疗前下降 >5%，需警惕营养不良，立即评估营养支持。
- **肌肉保护（核心）**：蛋白质 1.5-2.0 g/kg + 阻力训练（体力允许时），对抗恶病质肌肉流失。
- **恶病质处理**：营养治疗 + n-3（EPA）+ 抗炎 + 肌少管理 + 必要时药物（医生决策）；单纯"多吃饭"无法逆转恶病质，需综合治疗。
- **恢复期增重**：治疗结束后，逐步恢复至正常体重；用"肌肉性增重"而非"脂肪性增重"。
- **超重肿瘤患者**：非急性消耗期可适度减重（降复发风险），但必须保肌、不能快速节食。

### 7. 常见误区与辟谣

| 误区 | 真相 |
|------|------|
| "饿死肿瘤" | ❌ 肿瘤抢营养能力强，饿死的是宿主；营养不良者治疗耐受差、生存期短 |
| "吃素抗癌" | ❌ 优质蛋白是关键；纯素易蛋白质不足、肌肉流失 |
| "大补特补（人参/燕窝/甲鱼）" | ⚠️ 过犹不及；不明补品可能干扰治疗；均衡+专业指导为准 |
| "发物不能吃" | "发物"无科学定义；牛羊肉/鱼虾并非禁忌，除非过敏/医嘱 |
| "放化疗要忌口以免'营养癌细胞'" | 营养支持不"喂养肿瘤"，反而提升治疗耐受与生活质量 |
| "营养粉/营养素越贵越好" | 选正规口服营养补充剂（ONS），成分比价格重要，遵医嘱 |
| "指标正常就不用管营养" | 营养状态随治疗波动，需持续筛查监测 |

### 8. 监测与随访

| 监测指标 | 频率 | 说明 |
|----------|------|------|
| 营养筛查（PG-SGA/NRS2002） | 确诊即查；住院每周复查 | 动态评估 |
| 体重 | 每周（治疗期）；恢复期每月 | 最重要的一线指标 |
| 白蛋白/前白蛋白 | 每 2-4 周 | 内脏蛋白储备 |
| 血常规（血红蛋白/白细胞） | 按治疗周期 | 贫血/感染风险 |
| 炎症指标（CRP） | 每 2-4 周 | 恶病质评估 |
| 肌肉量（体成分/上臂围） | 每 1-3 个月 | 肌少监测 |
| 电解质/肝肾功能 | 按治疗周期 | 代谢并发症 |

**营养师随访提示：** 肿瘤营养是"团队作战"——营养师、肿瘤科医生、护士、心理支持共同配合；营养干预需与放化疗方案同步调整。

### 9. 给顾客的"一句话方案"与营养师沟通要点

**一句话方案：**
> "你要记住一句话：吃进去的是武器，不是负担。治疗期间，每天保证鸡蛋、奶、鱼、肉这些优质蛋白足量，少量多餐一天吃 6 次；体重每周称一次，掉得多了马上告诉医生，我们调整营养支持。营养跟上，治疗才扛得住。"

**营养师沟通要点：**
- 强调"营养是治疗的一部分"（一线/基础治疗），破除"营养是次要"的认知。
- 不替代医疗：所有治疗决策（放化疗/手术/药物）由医生定，营养师做支持。
- 慎言"抗癌食物"——没有单一抗癌食物，是整体营养状态在起作用。
- 合规：不推荐偏方、不承诺疗效；严重营养不良提示就医并配合临床营养支持。

## 九、慢阻肺（COPD）营养管理

### 1. 疾病与营养的关联机制（病理生理）

慢性阻塞性肺疾病（COPD）是气流受限的慢性炎症性肺病。营养问题与疾病形成恶性循环：

```
COPD → 呼吸做功增加（耗能↑）+ 长期炎症 + 低氧
        → 静息能量消耗升高（REE↑ 10%-20%）
        → 呼吸肌（膈肌）耗能大 → 蛋白质需求↑ → 呼吸肌萎缩/衰竭风险
        → 食欲下降（气促进食困难/药物副作用）→ 能量摄入↓
        → 体重下降/肌少（肺恶病质，20%-40% COPD 患者营养不良）
        → 免疫低下 → 急性加重频率↑ → 再住院
        → 反向：肥胖 COPD → 呼吸负荷更重 → 通气受限加重
碳水代谢：大量碳水 → CO₂ 生成↑ → 二氧化碳潴留（对肺功能差者不利）
```

**关键认知：** COPD 营养是"高能量高蛋白 + 平衡碳脂"——既防营养不良（呼吸肌衰竭），又防营养过剩（肥胖加重通气负担）。

---

### 2. 营养治疗目标（可量化）

| 目标维度 | 具体数值 | 说明 |
|----------|----------|------|
| 能量 | 30-35 kcal/kg/天（理想体重） | 呼吸耗能大，防消耗 |
| 蛋白质 | 1.2-1.7 g/kg/天 | 防呼吸肌萎缩、维持免疫 |
| 碳水 | 供能比 40%-50%（不超量） | 防 CO₂ 潴留 |
| 脂肪 | 供能比 30%-40%（适当提高） | 脂肪产 CO₂ 少、能量密度高 |
| 体重目标 | 维持理想体重；BMI 21-25 | 过低/过高都不利 |
| 钠 | <5-6g 盐/天 | 防水肿与肺动脉高压 |
| 微量 | 保证维A/维C/维D/锌/硒 | 抗氧化与免疫 |

---

### 3. 营养素方案表

| 营养素 | 建议值 | 说明 |
|--------|--------|------|
| 总能量 | 30-35 kcal/kg/天 | 活动期 REE 升高 |
| 蛋白质 | 1.2-1.7 g/kg/天 | 优质蛋白优先（蛋/奶/鱼/瘦肉） |
| 碳水化合物 | 供能比 40%-50% | 急性加重/CO₂ 潴留者适当降碳水、提脂肪 |
| 脂肪 | 供能比 30%-40%（n-3 适量） | 能量密度高、呼吸商低（产 CO₂ 少） |
| 膳食纤维 | 25-30g/天 | 通便（便秘影响膈肌运动） |
| 钠 | <5-6g 盐/天 | 控水钠 |
| 水 | 1500-2000ml/天（无禁忌） | 痰液稀释 |
| 磷/钾/镁 | 按化验补充（部分利尿剂使用者偏低） | 呼吸肌收缩依赖电解质 |

### 4. 食物选择：推荐 vs 限制 vs 避免

#### 4.1 推荐（绿灯）

| 类别 | 具体清单 |
|------|----------|
| 高蛋白 | 鸡蛋、低脂奶、鱼、鸡胸、豆腐——每次进食优先蛋白 |
| 好脂肪 | 橄榄油、坚果酱（能量密度高）、深海鱼 |
| 蔬菜水果 | 深色蔬果（维C/抗氧化）：柑橘、猕猴桃、西兰花 |
| 主食 | 燕麦、糙米、薯类（适量，不过量碳水） |
| 补液 | 温开水、淡汤（清痰） |

#### 4.2 限制（黄灯）

| 类别 | 限制规则 |
|------|----------|
| 精制糖/甜点 | 空能量，升血糖，促痰 |
| 产气食物（个别敏感者） | 洋葱/豆类过量产气→腹胀→膈肌上顶影响呼吸 |
| 过饱一餐 | 胃扩张压迫膈肌 → 分餐 |

#### 4.3 避免（红灯）

| 类别 | 原因 |
|------|------|
| 吸烟/二手烟（严格） | 病因本身 |
| 油炸/浓烈油烟 | 刺激气道 |
| 过冷/过烫食物 | 诱发咳嗽/支气管痉挛 |
| 大量纯碳水大餐 | CO₂ 生成↑，加重通气负担 |
| 高盐腌制食品 | 水钠潴留 |
| 酒精 | 抑制呼吸中枢、影响营养 |

### 5. 进餐模式与技巧

| 技巧 | 做法 |
|------|------|
| 小餐多次 | 每天 5-6 次小餐——防腹胀顶膈、减少进食耗氧 |
| 餐前休息 | 餐前休息片刻，别在喘息时进食 |
| 高蛋白优先 | 每餐先吃蛋白，再吃碳水 |
| "干稀分开" | 先干后稀或餐间喝汤——避免胃胀 |
| 细嚼慢咽 | 咀嚼充分，配合呼吸节奏 |
| 烹饪软烂 | 蒸煮炖为主，易咀嚼吞咽 |
| 饭后轻活动 | 餐后坐 30min 再躺（防反流/误吸） |
| 营养强化 | 粥汤中加蛋白粉/蛋黄/坚果酱（医生指导下） |

### 6. 体重管理

- **双目标思维**：消瘦者要"增重保肌"，肥胖者要"适度减重减负荷"——COPD 的体重管理是双向的。
- **低体重/呼吸肌萎缩者（重点）**：高能量高蛋白，目标每周增 0.25-0.5kg；体重恢复可改善呼吸肌力与运动能力。
- **肥胖 COPD 者**：适度减重（BMI 降到 25 以下）可显著减轻呼吸做功、改善通气；但需缓慢减、保蛋白，防肌少。
- **肺康复运动**：呼吸肌训练（缩唇呼吸/腹式呼吸）+ 上肢/下肢抗阻，配合营养同步。
- **监测**：每月体重 + 上臂肌围；急性加重期后重点复查营养状态。

### 7. 常见误区与辟谣

| 误区 | 真相 |
|------|------|
| "慢阻肺要少吃碳水防 CO₂" | 常规期碳脂平衡即可；只有急性 CO₂ 潴留时按医嘱调整，不能长期极低碳 |
| "喘得厉害吃不下就算了" | 进食不足→呼吸肌萎缩→更喘，是恶性循环；必须少量多餐强化 |
| "胖点扛得住" | 肥胖加重通气负担；瘦（肌少）加重呼吸肌衰竭——都要纠 |
| "慢阻肺不能运动" | 肺康复运动（呼吸训练+渐进运动）是核心治疗之一 |
| "多喝补品能补肺" | 均衡高蛋白+抗氧化微量营养素才是正道，不明补品无效且可能有负担 |

### 9. 给顾客的"一句话方案"与营养师沟通要点

**一句话方案：**
> "你的肺每呼吸一次都在消耗能量，所以'吃'就是给呼吸加油。每天 5-6 次小餐，每次先吃鸡蛋/奶/鱼这些优质蛋白；体重维持住不掉；烟必须戒，别吃太甜太咸。吃好了，喘就会轻一些。"

**营养师沟通要点：**

- 强调戒烟（无论饮食多好，不戒烟都白费）。
- 呼吸训练与营养同步；急性加重期配合医嘱。
- 合规：不承诺"治好"，用"改善生活质量、减少加重"的表述。

## 十、骨质疏松营养管理

### 1. 疾病与营养的关联机制（病理生理）

骨质疏松是**骨量减少 + 骨微结构破坏**导致的脆性骨折风险升高。骨骼是一个"活跃的代谢器官"，营养贯穿一生：

```
骨代谢平衡 = 骨形成（成骨细胞）— 骨吸收（破骨细胞）
峰值骨量（约 30 岁前积累）→ 绝经后（雌激素↓→破骨↑）/老年（成骨↓）
营养要素：
  钙 → 骨矿化的原料（钙负平衡 → 从骨骼"借钙"）
  维D → 促进肠钙吸收（维D缺乏 → 钙吸收率从 30% 降到 10-15%）
  蛋白质 → 骨基质（胶原蛋白网架）+ 肌量（保护骨骼）
  维K2 → 促进骨钙素羧化，让钙"沉积到骨"
  磷/镁/锌/维C → 骨矿化与胶原合成
危险因素：钙不足、维D不足、蛋白质不足、少动、绝经、吸烟、过量酒精、激素/药物
```

**关键认知：** 骨质疏松是"沉默的疾病"（骨折前无症状），且**骨量峰值期（青少年到 30 岁）的营养积累决定了中老年骨量的"本金"**。中老年干预重点是"止损 + 补钙维D蛋白 + 抗跌倒"。

---

### 2. 营养治疗目标（可量化）

| 目标维度 | 具体数值 | 说明 |
|----------|----------|------|
| 钙摄入 | 1000-1200mg/天（中国成人参考摄入量） | 绝经后女性/老年 1000-1200mg |
| 维D | 800-1200 IU/天（老年人可至 2000 IU，遵医嘱） | 促进钙吸收 |
| 蛋白质 | 1.0-1.2 g/kg/天 | 骨基质+肌肉 |
| 骨密度（DXA） | 随访 T 值（>-1 正常；-1~-2.5 骨量减少；≤-2.5 骨质疏松） | 诊断标准 |
| 血 25-羟维D | 目标 ≥30 ng/ml（75 nmol/L） | 维D营养状态 |
| 血钙/磷 | 正常范围 | 钙磷代谢平衡 |
| 防跌倒 | 肌力+平衡训练 | 骨折预防关键 |

| 餐后补钙 | 补钙剂随餐或餐后服（胃酸帮助吸收）；避免与铁剂同服 |
| 钙奶错开 | 钙与高草酸/咖啡/浓茶错开 1-2 小时 |
| 维D协同 | 补钙同时确保维D充足（否则钙吸收不了） |
| 蛋白质每餐 | 三餐都有优质蛋白（保肌防跌倒） |
| 烹饪 | 蔬菜焯水去草酸；骨汤不补钙（钙不溶在汤里，脂肪多） |
| 日晒 | 每天 15-20min 日晒（非暴晒时段）助内源性维D |

### 6. 体重管理与运动

- **防肌少是"隐形防线"**：肌肉量下降→平衡差→跌倒→骨折。蛋白质 1.0-1.2 g/kg + 抗阻训练是防跌倒核心。
- **体重适中**：过瘦（BMI<18.5）→骨密度低+髋部脂肪缓冲少→骨折风险高；过胖→跌倒风险与代谢负担。目标 BMI 20-25。
- **负重运动（推荐）**：快走、慢跑、登山、跳舞——机械负荷刺激成骨。
- **抗阻训练（推荐）**：弹力带/轻哑铃——增肌、增骨密度（每周 2-3 次）。
- **平衡训练**：太极拳、单腿站——防跌倒。
- **禁忌注意**：严重骨质疏松/已骨折者，运动前请医生评估，避免弯腰负重、剧烈跳跃。

### 7. 常见误区与辟谣

| 误区 | 真相 |
|------|------|
| "喝骨头汤补钙" | 骨头汤含钙极低（约 2-4mg/100ml），脂肪高——补钙靠奶/豆/菜 |
| "只有老年人才骨质疏松" | 峰值骨量在 30 岁前积累；中青年钙不足是在"透支本金" |
| "吃钙片就够" | 无维D，钙吸收率极低；蛋白、维K2、运动同样关键 |
| "骨质疏松没有症状就不用治" | 无症状但骨折风险在；确诊后要规范管理 |
| "补钙越多越好" | 过量（>2000mg/天）增加肾结石/血管钙化风险 |
| "吃虾皮补钙" | 虾皮钙高但盐高、难消化吸收率低——不是好选择 |
| "补维D就是晒太阳/吃鱼肝油随便来" | 需监测 25-羟维D，剂量遵医嘱，防过量中毒 |

### 营养师沟通六原则（通用）

1. **先共情后给方案**：先认可顾客的处境与努力，再讲干预。
2. **用比喻不用术语**："血糖缓冲池""骨量本金""给呼吸加油"。
3. **一次改 2-3 个行为**：别让顾客被"十件事"吓跑。
4. **数据说话**：复测结果是最好的说服力。
5. **边界清晰**：诊断、用药、调药归医生；营养师管"吃动睡"。
6. **合规兜底**：所有方案加"个体情况请咨询专业医师，遵循医嘱"。

| 顾客表现 | 营养师动作 |
