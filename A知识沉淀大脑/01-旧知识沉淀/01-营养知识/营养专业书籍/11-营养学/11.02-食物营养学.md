## 一、食物分类与膳食结构

### 1.1 为什么先讲"分类"

食物营养学的第一件事，是把日常食物放进一个有逻辑的框架里。我国《中国居民膳食指南（2022）》把食物分成**六大类**：

| 大类 | 包含 | 在膳食中的角色 |
|------|------|---------------|
| 第一类 谷薯类 | 米、面、杂粮、薯类 | 供能主体，碳水+膳食纤维+B族 |
| 第二类 蔬菜水果类 | 各类蔬菜、水果 | 维生素+矿物质+植物化学物+纤维 |
| 第三类 畜禽鱼蛋类 | 猪牛羊鸡鸭鱼虾蛋 | 优质蛋白+铁锌+B12 |
| 第四类 奶类大豆坚果类 | 奶、酸奶、豆制品、坚果 | 钙+优质蛋白+不饱和脂肪 |
| 第五类 烹调油盐 | 食用油、食盐 | 限量"调味"，必需但控量 |
| 第六类 水 | 白开水、淡茶 | 生命必需，饮水 1500~1700ml/天 |

> **记忆锚点：** 前三类管"吃什么"，第四类是"钙和优质脂肪的补位"，第五类是"必需但最易过量"，第六类常被忽略却是最硬的刚需。

### 1.2 平衡膳食的基本逻辑

平衡膳食不是"精确称重每一样食物"，而是遵循三个底层原则：

1. **种类多**：没有任何一种食物能提供全部营养素（母乳除外，仅限婴儿）。食物多样是微量营养素充足的前提。
2. **比例对**：能量来源比例要合理——碳水 50~65%、蛋白质 10~20%、脂肪 20~30%（即 AMDR，详见 11.03）。
3. **控总量**：总能量与消耗匹配，油盐糖等"空能量食物"限量。

### 1.3 中国居民膳食宝塔（2022）总览

膳食宝塔是中国膳食指南的"图形化落地"，共五层 + 塔底两行补充（饮水、身体活动）。建议量均为**可食部生重**。

```
            ▲ 第五层：盐 <5g/天，烹调油 25~30g/天
           ▲▲ 第四层：奶及奶制品 300~500g/天
          ▲▲▲ 第四层：大豆及坚果 25~35g/天
         ▲▲▲▲ 第三层：动物性食物 120~200g/天
          （畜禽 40~75 + 水产 40~75 + 蛋 40~50）
        ▲▲▲▲▲ 第二层：蔬菜 300~500g + 水果 200~350g
       ▲▲▲▲▲▲ 第一层：谷类 200~300g（全谷杂豆 50~150g）+ 薯类 50~100g
       ─────────────────────────────────────────
       塔底：饮水 1500~1700ml/天 · 身体活动 6000步/天
```

### 1.4 五层逐层详解

#### 第一层：谷薯类（主食层）

| 项目 | 建议量 | 说明 |
|------|--------|------|
| 谷类 | 200~300g/天 | 生重；其中**全谷物和杂豆 50~150g** |
| 薯类 | 50~100g/天 | 土豆、红薯、山药、芋头 |
| 换算关系 | 1份谷类 25g（生）≈ 100g 薯类 | 等能量替换（每份约 90kcal） |

这一层是全天能量的**基础盘**，占供能 50% 左右。核心提醒：**用全谷物替换 1/3~1/2 的精米白面**，是中国人最容易做到、收益最被低估的一步（详见第二章）。

#### 第二层：蔬菜水果层

| 项目 | 建议量 | 关键提示 |
|------|--------|---------|
| 蔬菜 | 300~500g/天 | **深色蔬菜应占一半** |
| 水果 | 200~350g/天 | 整果优于果汁 |
| 不能互相替代 | 蔬菜 ≠ 水果 | 两者维生素、矿物质、糖构成不同 |

#### 第三层：动物性食物层（优质蛋白层）

| 项目 | 建议量 | 备注 |
|------|--------|------|
| 畜禽肉 | 40~75g/天 | 优先禽肉（白肉）；少吃肥肉与加工肉 |
| 水产品 | 40~75g/天 | 优先深海鱼（n-3） |
| 蛋类 | 40~50g/天 | 约 1 个鸡蛋，**不要丢弃蛋黄** |

这一层合计 120~200g/天，是优质蛋白、血红素铁、锌、B12 的主要来源。注意：**是"适量吃"，不是"多多益善"**。

#### 第四层：奶类、大豆、坚果层

| 项目 | 建议量 | 说明 |
|------|--------|------|
| 奶及奶制品 | 300~500g/天 | 约 300~500ml 牛奶，或等量酸奶/奶酪 |
| 大豆及坚果 | 25~35g/天 | 大豆 25g ≈ 豆腐 150g 左右；坚果约 10g/天 |

这一层是**补钙主力**，也是多数中国成年人最容易"不够"的一层（中国人均饮奶远低于推荐量）。

#### 第五层：油盐层（限量层）

| 项目 | 建议量 | 危害阈值 |
|------|--------|---------|
| 烹调油 | 25~30g/天 | 供能比 20~30% 内 |
| 食盐 | <5g/天 | 折合钠 <2000mg/天（DRIs 2023 PI-NCD） |

> **提醒：** 第五层不是"可有可无"，而是"必须但限量"——完全无油无盐同样伤身（必需脂肪酸、碘的来源）。

#### 塔底：饮水与身体活动

| 项目 | 建议量 | 说明 |
|------|--------|------|
| 饮水 | 1500~1700ml/天 | 约 7~8 杯；高温/运动时增加 |
| 身体活动 | 6000 步/天 | 含中等强度运动每周 ≥5 天 |

### 1.5 膳食餐盘：宝塔的一餐化应用

宝塔看"全天"，餐盘看"一餐"。2016 年提出的"中国居民平衡膳食餐盘"把一个盘子分成四格：

```
┌────────────────────────────┐
│  1/2 盘：蔬菜 + 水果        │
│  ┌──────────┬─────────────┐ │
│  │ 1/4 盘：  │ 1/4 盘：    │ │
│  │ 全谷物    │ 优质蛋白    │ │
│  │ （主食）   │ （鱼/蛋/肉） │ │
│  └──────────┴─────────────┘ │
│  另配一杯奶 + 适量豆制品      │
└────────────────────────────┘
```

**餐盘三句话：**
- 盘子的一半留给蔬菜水果（深色蔬菜优先）；
- 四分之一是主食（优先全谷物）；
- 四分之一是优质蛋白；
- 旁边配一杯奶，餐中少油少盐。

### 1.6 食物多样化：每天 12 种、每周 25 种怎么落地

指南核心量化指标：**平均每天摄入 12 种以上食物，每周 25 种以上**。

| 餐次 | 建议种类 | 举例 |
|------|---------|------|
| 早餐（4~5 种） | 主食 + 蛋白 + 奶 + 蔬果 | 全麦面包 + 鸡蛋 + 牛奶 + 圣女果 |
| 午餐（5~6 种） | 主食 + 肉 + 2~3 种蔬菜 | 米饭 + 鸡胸 + 西兰花 + 胡萝卜 + 木耳 |
| 晚餐（4~5 种） | 主食 + 豆/鱼 + 蔬菜 | 杂粮饭 + 豆腐 + 菠菜 + 菌菇 |
| 零食（1~2 种） | 水果 / 坚果 / 酸奶 | 苹果 + 一小把坚果 |

**实操技巧：**
- 主食"混搭"：白米 + 糙米/燕麦/杂豆，一顿就多 2~3 种；
- 蔬菜"拼盘"：一餐做"三色菜"（绿 + 红/黄 + 白/黑）；
- 一周食材轮换表：提前列一周菜单，不重复。

## 二、谷薯类（主食）营养价值详解

### 2.1 为什么"谷类为主"

《中国居民膳食指南（2022）》第一条就强调谷类为主。原因有三：

1. **供能经济**：碳水是大脑和肌肉最优先的能量来源；
2. **营养素贡献大**：谷类是 B 族维生素（尤其 B1）、膳食纤维、镁的重要来源；
3. **健康证据**：全谷物摄入与 2 型糖尿病、心血管病、结直肠癌风险降低相关（前瞻性队列证据充分）。

### 2.2 精制谷物 vs 全谷物：差在哪

谷物由三部分构成：**麸皮（外）、胚芽（生命点）、胚乳（淀粉主体）**。精加工把麸皮和胚芽磨掉了，只剩下胚乳。

| 结构 | 富含 | 精制后去向 |
|------|------|-----------|
| 麸皮 | 膳食纤维、B 族、矿物质、植物化学物 | **被去掉** |
| 胚芽 | B 族、维E、不饱和脂肪、矿物质 | **被去掉** |
| 胚乳 | 淀粉、少量蛋白质 | 保留（精白米面） |

**精米白面的代价：** 精白米比糙米损失约 50% 的 B1、70% 以上膳食纤维、大部分镁和维E。

| 对比项 | 精白米（每100g） | 糙米（每100g） |
|--------|----------------|---------------|
| 能量（kcal） | 约 346 | 约 348 |
| 膳食纤维（g） | 约 0.7 | 约 3.4 |
| 维生素B1（mg） | 约 0.11 | 约 0.33 |
| 镁（mg） | 约 34 | 约 143 |

### 2.3 常见全谷物的营养特点

| 全谷物 | 营养亮点 | 典型吃法 |
|--------|---------|---------|
| 燕麦 | β-葡聚糖（可溶性纤维），有助控血脂；蛋白质含量高（约15%） | 燕麦粥、隔夜燕麦 |
| 糙米 | 纤维+B1+镁，升糖比白米缓 | 糙米饭、糙米粥 |
| 荞麦 | 芦丁（黄酮）、纤维；无麸质 | 荞麦面 |
| 小米 | B1 丰富、养胃友好、易消化 | 小米粥（配杂豆） |
| 全麦 | 全谷+纤维 | 全麦面包（看配料表首位） |
| 黑米/紫米 | 花青素、纤维 | 杂粮饭、米糊 |
| 玉米 | 叶黄素、玉米黄质（护眼） | 煮玉米、玉米糁 |
| 藜麦 | 蛋白含赖氨酸（完全性较好）、铁镁 | 沙拉、杂粮饭 |

**β-葡聚糖小知识：** 燕麦水溶性纤维 β-葡聚糖，在肠道形成黏性凝胶，延缓葡萄糖吸收、增加胆汁酸排出，每天约 3g 即有辅助调节血脂的循证依据（欧洲食品安全局认可的健康声称）。

### 2.4 杂豆类：被低估的"主食搭子"

**定义：** 除大豆（黄豆/黑豆/青豆）以外的豆类，包括红豆、绿豆、芸豆、鹰嘴豆、豌豆、蚕豆等。在膳食宝塔中归入"全谷物和杂豆"一起推荐。

| 项目 | 数值（干豆每100g） | 说明 |
|------|-------------------|------|
| 蛋白质 | 约 20~22g | 植物蛋白，赖氨酸丰富（与谷物互补） |
| 碳水化合物 | 约 55~65g | 以淀粉为主，但多为抗性淀粉 |
| 膳食纤维 | 约 7~11g | 显著高于谷物 |
| GI | 低~中 | 优于精白米面 |

**为什么杂豆适合掺进主食：**
- 蛋白质与谷物**氨基酸互补**（谷物缺赖氨酸、豆类富含赖氨酸；豆类缺蛋氨酸、谷物含蛋氨酸）——混吃相当于"植物版优质蛋白"；
- 纤维+抗性淀粉 → 延缓升糖、增加饱腹感、喂养肠道菌群；
- 红豆/绿豆经典做法：杂豆饭、绿豆汤、八宝粥。

> **食用注意：** 豆类含抗营养物质（植酸、皂素、植物凝集素），**彻底煮熟**后失活；鹰嘴豆、芸豆等生食有毒，务必煮透。

### 2.5 薯类：被误解的"健康主食"

薯类归入主食层，按**等能量替换**吃，不是当菜吃（否则会"菜+饭"双份碳水）。

| 薯类（每100g可食部） | 能量(kcal) | 特点 |
|----------------------|-----------|------|
| 土豆 | 约 77 | 高钾（约342mg）、含VC；饱腹感强 |
| 红薯（红心） | 约 86~106 | 胡萝卜素丰富、纤维高 |
| 山药 | 约 57 | 黏蛋白、低脂 |
| 芋头 | 约 79~85 | 钾、氟；黏蛋白 |
| 紫薯 | 约 82~106 | 花青素 |

**薯类的优势：**
- 能量密度低于精米白面（同样是主食，更"耐饿不扛热"）；
- 富钾，有助钠钾平衡；
- 含 VC（多数谷物不含 VC）。

**误区提醒：**
- 炸薯条/薯片是"油裹淀粉"，健康属性归零，不算薯类；
- 红烧土豆、土豆炖肉里的土豆=主食，吃了要减饭量；
- 发芽/变绿土豆含龙葵碱（茄碱），**不能吃**。

### 2.6 谷薯类选择与搭配建议（给顾客）

| 场景 | 建议 |
|------|------|
| 糖尿病患者 | 全谷物+杂豆替换 ≥1/2 精制主食，分餐 |
| 减脂人群 | 主食替换 1/3 为薯类+杂豆，控总量 |
| 儿童 | 避免纯白粥白饭，杂粮循序渐进（防纤维不耐受） |
| 老年人 | 全谷物+细粮混合煮软，兼顾消化与营养 |
| 有胃病者 | 细粮为主、全谷少量试，燕麦/小米较友好 |

**一句话口诀：** "白米白面打底，全谷杂豆替换三分之一，薯类当主食不当菜。"

## 三、蔬菜类营养价值详解

### 3.1 蔬菜的营养共性

蔬菜共同贡献：**维生素C、叶酸、胡萝卜素（维生素A原）、钾、钙（部分）、膳食纤维、植物化学物**。能量密度低，是"营养密度高、能量密度低"的典型代表。

**蔬菜的短板：** 蛋白质少、供能少，不能当主食；部分蔬菜含抗营养素（草酸、植酸），需烹调处理。

### 3.2 深色蔬菜：营养密度之王

深色蔬菜 = 深绿色、红色/橘红色、紫红色蔬菜。指南要求**每天深色蔬菜占蔬菜总量的一半**（即 150~250g）。

| 深色类别 | 代表 | 明星营养素 |
|---------|------|-----------|
| 深绿色 | 菠菜、油菜、西兰花、茼蒿、芹菜叶、空心菜 | 叶酸、胡萝卜素、VC、钾、钙、铁（非血红素） |
| 红色/橘红 | 番茄、胡萝卜、南瓜、红椒 | β-胡萝卜素、番茄红素、VC |
| 紫红色 | 紫甘蓝、紫茄（皮）、红苋菜 | 花青素 |

**为什么深色更"值"：** 以胡萝卜素为例——深绿/红黄蔬菜每 100g 含 β-胡萝卜素数千微克，而浅色蔬菜（白萝卜、冬瓜、莲藕、大白菜）往往只有几十到几百微克。VC、叶酸、钾同样呈"深色更高"规律。

### 3.3 十字花科蔬菜：植物化学物富矿

十字花科包括：**西兰花、菜花、卷心菜、甘蓝、芥蓝、萝卜、大白菜、小白菜、油菜**。

| 成分 | 作用方向（科普表述） |
|------|---------------------|
| 硫代葡萄糖苷（分解为萝卜硫素等） | 体外及动物实验显示有抗氧化、诱导解毒酶等活性；人群证据仍需更多研究 |
| 吲哚类 | 与上述类似，注意不是"抗癌神药" |
| 叶黄素/玉米黄质 | 眼健康 |

**科学表述口径：** 十字花科蔬菜富含硫代葡萄糖苷，其分解产物在实验室研究中有抗氧化、抗炎的活性；流行病学观察到多吃蔬菜与部分癌症风险降低相关，但**不能得出"吃西兰花抗癌"的绝对结论**。讲给顾客时用"多吃十字花科蔬菜是健康饮食的一部分"，不用"抗癌"标签。

### 3.4 菌菇类：被低估的"第四类蔬菜"

| 菌菇 | 营养特点 |
|------|---------|
| 香菇 | 真菌多糖（香菇多糖）、麦角甾醇（紫外线照射可转化为维D2）、鲜味核苷酸（天然的"味精"） |
| 木耳 | 木耳多糖、膳食纤维、铁（但生物利用率低）；泡发时间不宜过长（防米酵菌酸） |
| 金针菇/杏鲍菇/平菇 | 低热量、纤维、B 族；杏鲍菇可当"肉"的质地替代 |
| 口蘑（白蘑菇） | 是少数天然含较多维D的食用菌之一（紫外线处理后更高） |

**菌菇独特价值：** 是**唯一能天然提供维生素D前体（麦角甾醇）的常见蔬菜类食物**；买回来的蘑菇在阳光下晒 1~2 小时，维D2 含量可明显上升——这是个好讲给顾客的"低成本营养技巧"。

### 3.6 蔬菜的选购、储存与烹调（先导）

- **选购**：本地应季优先（营养与风味更好）；变色、萎蔫、异味的不买。
- **储存**：绿叶菜冷藏并用透气的袋子，尽量 3 天内吃完；切开的不久放。
- **烹调**：先洗后切、急火快炒、现做现吃（详见第八章）。

### 3.7 蔬菜食用误区

| 误区 | 真相 |
|------|------|
| 只吃"菜心"，丢菜叶菜梗 | 菜叶营养密度远高于菜帮/菜梗 |
| 天天水煮菜不吃油 | 胡萝卜素/番茄红素/维K 是脂溶性的，需适量油脂帮助吸收 |
| 蔬菜榨汁喝 | 丢纤维、营养氧化、升糖快——直接吃 |
| 把薯类当菜吃 | 土豆/山药是主食，不当菜（否则碳水翻倍） |
| "水果能代替蔬菜" | 不能——蔬菜含糖低、纤维多、矿物质谱不同 |
| 蔬菜沙拉只配低脂酱 | 脂溶性维生素需要脂肪，适量好油更利于吸收 |

## 四、水果类营养价值详解

### 4.1 水果的营养共性

水果主要贡献：**VC、钾、膳食纤维（果胶）、有机酸、植物化学物（花青素、类黄酮、番茄红素等）**。多数水果含糖（果糖、葡萄糖、蔗糖），所以"控量"比"多吃"更重要——推荐 200~350g/天。

**水果 vs 蔬菜：** 水果优点是不需烹调、VC 保存好、自带甜味容易入口；缺点是含糖较高，血糖敏感人群要注意种类和分量。

### 4.2 浆果类：花青素富矿

浆果 = 蓝莓、草莓、桑葚、树莓、黑莓、蔓越莓。

| 浆果 | 亮点 |
|------|------|
| 蓝莓 | 花青素、锰；护眼和认知相关研究热门（注意表述：证据在积累，非结论） |
| 草莓 | VC 突出（约47mg/100g），叶酸 |
| 桑葚 | 花青素、铁（植物性） |
| 蔓越莓 | A型原花青素（与泌尿道健康研究相关） |

**冻果 vs 鲜果：** 应季浆果短期不便吃完，冷冻保存（-18℃）能较好保留花青素等，是性价比高的选择。

### 4.3 柑橘类：VC + 类黄酮

柑橘类 = 橙、柚、橘、柠檬、金橘。共同特点：**VC + 类黄酮（橙皮苷、柚皮苷）**；果肉外的白色"络"（橘络）含类黄酮，别扔。

| 柑橘 | VC(mg/100g) | 特点 |
|------|-------------|------|
| 橙子 | 约 33 | 类黄酮、钾 |
| 柚子 | 约 23 | 含柚皮苷；注意与部分药物相互作用 |
| 柠檬 | 约 22 | 维C不如传说中高；宜作调味 |
| 金橘 | 约 35 | 带皮吃，果胶丰富 |

> **西柚（葡萄柚）与药物：** 西柚汁会抑制肝药酶 CYP3A4，使某些药物（他汀类、部分降压药）血药浓度升高。这属于"食物-药物相互作用"，是真实存在的风险，与"食物相克"无关。服用处方药者如吃西柚，建议咨询医师药师。

### 4.4 其他常见水果

| 水果 | 能量(kcal/100g) | 特点 | 备注 |
|------|----------------|------|------|
| 苹果 | 约 53 | 果胶（可溶性纤维）、钾、槲皮素 | 带皮吃纤维更好（洗净） |
| 香蕉 | 约 93 | 钾、碳水高、供能快 | 运动后友好；减脂控量 |
| 葡萄 | 约 45 | 皮含白藜芦醇等 | 洗净连皮吃 |
| 西瓜 | 约 31 | 水分大、番茄红素（红瓤） | 含糖不低，控量 |
| 猕猴桃 | 约 61 | VC 高、奇异果素 | 对便秘友好（纤维） |
| 牛油果 | 约 171 | 单不饱和脂肪为主、钾、纤维 | 是高脂水果，1天半颗即可 |
| 榴莲 | 约 150 | 能量高、钾 | 减脂/血糖敏感者少吃 |

### 4.5 果汁 ≠ 水果：底层逻辑

| 对比 | 整果 | 果汁 |
|------|------|------|
| 膳食纤维 | 完整保留（果肉、果皮） | 榨汁丢纤维 |
| 维生素C | 现吃现切损失小 | 氧化+存放损失 |
| 血糖反应 | 有纤维"缓冲"，升糖较缓 | 游离糖快速吸收，升糖快 |
| 饱腹感 | 强（有咀嚼） | 几乎无 |
| 能量感知 | 吃2个橙子就饱 | 一杯600ml橙汁=4~5个橙子 |

**结论：** "每天一份水果"指的是**完整水果**。儿童果汁要严格限量（美国儿科学会建议：1~3岁≤120ml/天，4~6岁≤120~180ml/天）。

### 4.6 水果食用误区

| 误区 | 真相 |
|------|------|
| "饭后吃水果助消化" | 无循证；血糖敏感者建议餐间吃 |
| 水果多多益善 | 水果含糖，200~350g/天即可 |
| 果干=健康零食 | 果干浓缩糖，看配料（是否额外加糖），控量 |
| "晚上吃水果会长胖" | 关键在总量与全天能量，不在时间段 |
| 只要甜就升糖快 | 升糖速度看纤维、果胶、进食方式（整果慢，果汁快） |

## 五、畜禽鱼蛋类营养价值详解

### 5.1 优质蛋白的共性

动物性食物的共同标签：**"优质蛋白"**——必需氨基酸种类全、比例接近人体需要、消化吸收率高。同时贡献**血红素铁**（吸收率 20%~30%，远高于植物铁）、**锌、维生素B12**（几乎只在动物性食物中）。

### 5.2 红肉 vs 白肉

| 对比项 | 红肉（猪牛羊） | 白肉（禽类） |
|--------|--------------|------------|
| 蛋白质 | 优质 | 优质 |
| 血红素铁 | 丰富 | 少于红肉 |
| 锌/B12 | 丰富 | 有 |
| 脂肪特点 | 常含较多饱和脂肪 | 总体脂肪低（去皮更明显） |
| 建议 | 适量，≤约 500g/周（烹饪后约 350~500g） | 日常优先 |

**红肉与健康风险（重要科普口径）：**
- 世界卫生组织下属 IARC（2015）将**加工肉制品**列为 1 类致癌物（"确定对人致癌"），将**红肉**列为 2A 类（"很可能对人致癌"，主要是结直肠癌）；
- 但 1 类/2A 类分级讲的是"证据强度"，**不等于"吃就致癌"**——致癌风险与剂量、频率相关；
- 我国膳食指南的建议是：畜禽肉 40~75g/天，**少吃肥肉、烟熏和腌制肉**。这个量级在平衡膳食内是安全的。

> **讲给顾客的口径：** "不是不能吃红肉，是别顿顿大块、别吃加工肉。一天一巴掌大小（40~75g）完全没问题。重点是'适量'，别制造焦虑。"

### 5.3 水产品与深海鱼：n-3 的来源

| 鱼类（每100g可食部） | 蛋白质(g) | n-3（EPA+DHA约，g） | 特点 |
|---------------------|-----------|---------------------|------|
| 三文鱼 | 约 20 | 约 1.5~2.0 | 深海鱼代表，n-3 丰富 |
| 鲭鱼（青花鱼） | 约 18 | 约 1.5 | 性价比高 |
| 沙丁鱼 | 约 19 | 约 1.0~1.5 | 小鱼整吃，钙也好 |
| 带鱼 | 约 18 | 约 0.4 | 国人常见深海鱼 |
| 鲈鱼 | 约 18 | 少量 | 淡水鱼中 DHA 较优 |
| 虾/贝类 | 约 15~18 | 少量 | 富锌、硒；贝类嘌呤较高 |

**建议：** 每周吃鱼 2 次或以上，优先深海鱼。孕产妇、儿童尤其重视 DHA 来源。

**嘌呤提醒：** 高尿酸/痛风人群，贝类、虾、部分鱼嘌呤较高，需要限量（详见 11.07 相关章节），但鱼虾仍是优质蛋白来源，不是"一票否决"。

### 5.4 蛋类：性价比之王

| 项目 | 数值（全蛋每100g） | 说明 |
|------|-------------------|------|
| 蛋白质 | 约 13g | 氨基酸模式最接近人体需要，常作"参考蛋白" |
| 脂肪 | 约 9g | 主要在蛋黄 |
| 胆固醇 | 约 585mg | 1个50g鸡蛋≈292mg |
| 卵磷脂/胆碱 | 蛋黄富含 | 大脑神经递质合成相关 |
| 叶黄素/玉米黄质 | 蛋黄 | 眼底黄斑健康 |
| 维D、维A、B12 | 蛋黄 | 蛋黄是蛋的"营养库" |

**胆固醇争议的澄清：**
- 2015 年起美国膳食指南、2022 年中国膳食指南都**取消"每日胆固醇摄入 <300mg"的硬上限**；
- 膳食胆固醇对血胆固醇的影响远小于**饱和脂肪和反式脂肪**；
- 结论：**每天 1 个全蛋完全没问题**；高血脂人群在医生指导下可吃，不必"扔蛋黄"。

### 5.5 蛋白质互补：植物蛋白的"拼图"

动物蛋白是"满分拼图"，植物蛋白常"缺角"。但把不同植物搭配起来，也能凑齐必需氨基酸：

| 搭配 | 互补逻辑 |
|------|---------|
| 谷物 + 豆类（米饭+豆、馒头+豆沙） | 谷物缺赖氨酸，豆类富含赖氨酸；豆类缺蛋氨酸，谷物含蛋氨酸 |
| 谷类 + 坚果/种子 | 补充赖氨酸与脂肪 |
| 豆制品 + 其他蔬菜 | 多样化 |

这就是为什么"杂粮饭+豆"是植物性饮食的黄金组合。对纯素食者，主食+豆+坚果的组合很重要。

|---------------------|-----------|-----------|---------|--------|------|
| 猪瘦肉 | 约 143 | 约 20 | 约 6 | 约 3 | 血红素铁好来源 |
| 牛瘦肉 | 约 106 | 约 20 | 约 2 | 约 3 | 高蛋白低脂 |

| 鸭肉（去皮） | 约 240 | 约 15 | 约 19 | 约 2 | 去皮后低很多 |

### 5.7 畜禽鱼蛋类误区

| 误区 | 真相 |
|------|------|
| 蛋黄胆固醇高，扔了只吃蛋白 | 蛋黄营养密度远高于蛋白，弃黄=扔营养；健康人每天1个全蛋 |
| 只吃瘦肉不吃肥肉=很健康 | 重点是总量与饱和脂肪；瘦肉也要限量（40~75g/天） |
| "红肉致癌"=不能吃红肉 | IARC 分级=证据强度，不是风险大小；适量红肉在平衡膳食内安全 |
| 鱼越贵越好 | 三文鱼好，但沙丁鱼、鲭鱼、带鱼性价比高、n-3 也不错 |

| 只喝汤不吃肉 | 汤里主要是脂肪、嘌呤和少量水溶性营养，**肉本身的蛋白质还在肉里** |

## 六、奶类、大豆、坚果营养价值详解

### 6.1 奶类及奶制品：补钙主力

| 奶制品 | 钙(mg/100g) | 蛋白质(g) | 特点 |
|--------|------------|-----------|------|
| 牛奶 | 约 104 | 约 3.0 | 钙磷比佳、吸收好 |
| 酸奶 | 约 118 | 约 2.5~3.0 | 发酵后乳糖减少，含益生菌；选低糖 |
| 奶酪 | 约 799 | 约 25 | 钙浓缩，注意钠和脂肪 |
| 羊奶 | 约 82 | 约 1.5 | 部分乳糖不耐者耐受较好 |

**为什么中国成年人普遍缺钙：** 钙 RNI 成人 800mg/天（50 岁以上 1000mg/天），而我国居民平均钙摄入仅约 400mg/天左右——缺的正是"奶豆层"。

**乳糖不耐受怎么办（科普口径）：**
- 酸奶、奶酪（发酵把乳糖分解）；
- 舒化奶/零乳糖奶；
- 少量多次喝牛奶；
- 也可用强化钙豆奶+绿叶菜+豆腐补钙，但吸收率略逊，需吃够量。

### 6.2 大豆及豆制品：植物"完全蛋白"

大豆（黄豆、黑豆、青豆）是少数**蛋白质质量接近动物蛋白**的植物食物。

| 豆制品换算 | 相当量（大豆25g） |
|-----------|------------------|
| 大豆（干） | 25g |
| 北豆腐 | 约 100g |
| 南豆腐 | 约 150g |
| 豆腐干 | 约 50g |
| 豆浆 | 约 365~400ml |
| 腐竹 | 约 20g |

**大豆的营养成分（干黄豆每100g）：** 蛋白质约 35g、脂肪约 16g（以多不饱和为主）、碳水约 34g、膳食纤维约 15g、钙约 191mg、异黄酮（大豆异黄酮）。

**大豆异黄酮（重要辟谣）：**
- 大豆异黄酮是"植物雌激素"，但与雌激素受体结合力弱，且双向调节（低时补充、高时竞争）；
- 大规模人群研究**未发现**正常食用豆制品增加乳腺癌风险，反而观察到保护性关联；
- 乳腺增生、乳腺癌康复人群**无需完全回避**豆制品（特殊医嘱除外）；
- 婴幼儿配方中大豆蛋白也是安全选项之一。

**豆制品选择建议：** 豆腐/豆浆/豆干/腐竹轮换着吃；发酵豆制品（纳豆、豆豉、腐乳）含维K2，但腐乳盐高、控量。

### 6.3 坚果：能量密度高的小体积营养库

| 坚果 | 特点 | 建议 |
|------|------|------|
| 核桃 | n-3（ALA）、维E、多酚 | 每天 2 个即可 |
| 杏仁 | 单不饱和脂肪、维E、钙 | 一小把 |
| 腰果 | 铜、镁 | 一小把 |
| 花生 | 蛋白质、烟酸（是豆科，常归坚果类讨论） | 7~8 粒 |
| 榛子 | 维E、锰 | 一小把 |
| 开心果 | 钾、纤维、叶黄素 | 一小把 |

**建议量：** 每周 50~70g，平均每天约 10g（约等于：2 个核桃，或 7~8 粒花生，或 6 粒腰果，或一小把瓜子）。

**选择原则：**
- 选**原味**（盐焗/糖霜/蜂蜜烤的钠和糖超标）；
- 买**小包装**（防一次吃多）；
- 发霉/哈喇味坚果（黄曲霉毒素/油脂氧化）**直接扔**。

### 6.4 奶豆坚果误区

| 误区 | 真相 |
|------|------|
| "喝奶致癌" | 大规模研究不支持；奶类是钙和优质蛋白的重要来源（详见 11.05） |
| 豆浆补钙和牛奶一样 | 豆浆本身钙低（约20mg/100ml），除非强化钙；补钙还得奶和豆腐 |
| 坚果脂肪高，减脂不能吃 | 每天10g优质脂肪有益心血管；关键是控量 |
| 豆制品"发物"、痛风不能碰 | 干豆嘌呤高，但豆腐/豆浆经加工嘌呤降低；急性痛风期遵医嘱，缓解期适量 |
| 乳糖不耐=完全不能喝奶 | 酸奶/奶酪/零乳糖奶/少量多次可耐受 |

## 七、油、盐、糖、酒——限量类食物

### 7.1 烹调油与脂肪酸

**油=脂肪，脂肪是必需营养素：** 提供必需脂肪酸（亚油酸 n-6、α-亚麻酸 n-3）、帮助脂溶性维生素吸收、构成细胞膜。但能量密度高（9kcal/g），过量是肥胖和慢病推手。

**脂肪酸谱一览：**

| 类型 | 代表油 | 特点 |
|------|--------|------|
| 饱和脂肪 | 猪油、黄油、棕榈油 | 过量升"坏胆固醇"（LDL） |
| 单不饱和脂肪（MUFA） | 橄榄油、菜籽油、茶籽油 | 相对友好，耐热中等 |
| 多不饱和脂肪 n-6（亚油酸） | 大豆油、玉米油、葵花籽油 | 必需，但 n-6/n-3 比例别太偏 |
| 多不饱和脂肪 n-3（ALA） | 亚麻籽油、紫苏油 | 必需，怕热，宜凉拌 |
| 反式脂肪 | 氢化植物油/起酥油/植脂末 | **越少越好**，<2g/天 |

**"换着吃"的真实含义：** 不同油的脂肪酸谱不同，长期只用一种油会导致 n-6/n-3 失衡。实操方案：

| 用途 | 推荐油 | 理由 |
|------|--------|------|
| 日常炒菜 | 菜籽油、花生油、山茶油 | 耐热、MUFA 为主 |
| 凉拌/低温 | 橄榄油、亚麻籽油、芝麻油 | 保留 n-3 与风味 |
| 高温煎炸（偶尔） | 精炼花生油/棕榈油 | 耐高温、烟点高；但煎炸本身少做 |

### 7.2 盐与钠

**换算：** 1g 食盐 ≈ 钠 400mg；**5g 盐 ≈ 钠 2000mg**（= DRIs 2023 钠的 PI-NCD）。

| 来源 | 占每日盐摄入比例（约） | 例子 |
|------|----------------------|------|
| 烹调用盐 | 约 60%~70% | 炒菜放盐 |
| 调味品 | 约 10%~15% | 酱油、蚝油、味精、豆瓣酱、咸菜 |
| 加工食品 | 约 15%~25% | 方便面、火腿、薯片、面包（隐藏钠） |

**减盐技巧：**
- 起锅前放盐（同等咸味用盐更少）；
- 用葱姜蒜、花椒、醋、柠檬提升风味代替部分盐；
- 警惕"隐形盐"——买加工食品看营养成分表钠含量；
- 全家逐步减量，2~4 周味蕾适应。

### 7.3 添加糖

**定义：** 在加工食品中加入的糖及蜂蜜、糖浆等，不包括果蔬天然糖。

| 数值 | 建议 |
|------|------|
| ≤50g/天 | 添加糖控制线（约 10% 供能） |
| 最好 <25g/天 | 更优目标（约 5% 供能） |

**隐形糖大户：** 含糖饮料（一瓶500ml可乐约含糖 53g）、奶茶、果汁、糕点、饼干、果脯、酸奶（风味型）、番茄酱。

**对顾客一句话：** "不是完全不能碰糖，是把'主动喝的甜饮料'先戒掉，一天的糖配额就省下一大半。"

### 7.4 反式脂肪

- 天然来源（反刍动物奶、肉）含量低；
- **主要来源是氢化植物油**：起酥油、植脂末（奶茶伴侣）、代可可脂、人造黄油；
- 上限：<1% 供能（约 **<2g/天**）；
- 看配料表：出现"氢化植物油/起酥油/植脂末/人造奶油"要留意。

### 7.5 酒

**酒精是"空能量"+1 类致癌物（乙醛）。** 指南立场：**最好不喝酒**；如饮酒，限量。

| 人群 | 每日酒精上限 | 折合量（约） |
|------|------------|------------|
| 成年男性 | ≤25g 酒精 | 啤酒 750ml / 葡萄酒 250ml / 白酒（52°）50ml |
| 成年女性 | ≤15g 酒精 | 啤酒 450ml / 葡萄酒 150ml / 白酒（52°）30ml |

**特殊强调：** 备孕、孕妇、哺乳期、儿童青少年**不饮酒**；服头孢类等药物期间严格禁酒。

### 7.6 油盐糖酒数据速查表

| 项目 | 建议量 | 超标后果（科普） |
|------|--------|----------------|
| 烹调油 | 25~30g/天 | 能量过剩、血脂负担 |
| 盐 | <5g/天 | 高血压风险↑ |
| 添加糖 | ≤50g（最好<25g） | 龋齿、能量过剩 |
| 反式脂肪 | <2g/天 | 心血管负担 |
| 酒精 | 男≤25g、女≤15g | 肝、心血管、癌症风险 |

## 八、食物加工、储存与烹调的营养学

### 8.1 营养素流失的五大规律

| 因素 | 影响哪些营养素 | 机制简述 |
|------|--------------|---------|
| **温度** | VC、B1、叶酸 | 高温破坏，时间越长损失越大 |
| **光照** | B2、VC、胡萝卜素 | 光敏氧化 |
| **水（水溶）** | B族、VC、钾 | 溶入水中，弃汤=丢营养 |
| **氧气** | VC、不饱和脂肪酸 | 氧化 |
| **时间** | 几乎所有维生素 | 储存越久流失越多（尤其 VC、叶酸） |

**"三怕"口诀：** 维生素C、B族是"水溶性、怕热、怕光、怕氧"的娇气营养素；矿物质和蛋白相对稳定，但怕"溶水"。

### 8.2 不同烹调方式对营养素的影响

| 方式 | 维生素C保留率（约） | 油脂用量 | 有害副产物风险 | 综合评价 |
|------|---------------------|---------|---------------|---------|
| 蒸 | 75%~90% | 极少 | 低 | ★★★★ 首选 |
| 煮/焯 | 50%~70%（部分溶汤） | 少 | 低 | ★★★ 别弃汤 |
| 急火快炒 | 60%~80% | 中 | 低 | ★★★★ 短时高温损失小 |
| 炖（长时间） | 40%~60% | 少 | 低-中 | ★★★ 汤+料都吃 |
| 微波 | 70%~90% | 极少 | 低 | ★★★★ 快捷 |
| 油炸 | 40%~60% | 多 | 中-高（AGEs/丙烯酰胺） | ★★ 偶尔 |
| 烧烤/明火烤 | 30%~60% | 中 | 高（杂环胺/PAHs） | ★ 少用，焦黑勿食 |
| 腌制 | 大部分流失 | — | 高盐/亚硝酸盐 | ★ 偶尔 |

> 保留率为常见研究范围，受食材、切法、时间、火候影响，勿当精确值。**结论取向：** 蒸、快炒、微波 > 煮炖（不弃汤）> 炸、烤、腌。

### 8.3 烹调与有害物质生成（科普，勿吓唬）

| 副产物 | 生成条件 | 归类（IARC） | 预防 |
|--------|---------|-------------|------|
| 晚期糖基化终末产物（AGEs） | 高温干热、长时间烹肉 | — | 蒸煮炖替代烤炸 |
| 丙烯酰胺 | 淀粉类 >120℃（薯条、烤面包、咖啡） | 2A 类 | 控制油温、少焦黄、不吃过焦 |
| 杂环胺（HCAs） | 肉高温直烤/煎炸 | 部分 2A/2B | 明火改中温、翻动、配蔬菜 |
| 多环芳烃（PAHs） | 烟熏、炭火滴油冒烟 | 1 类（部分） | 少烟熏炭烤 |
| 亚硝酸盐/亚硝胺 | 腌制肉、隔夜绿叶菜 | 亚硝胺为 1 类 | 少吃加工肉、菜现做现吃 |

**安全底线三句话：**
1. 烹调"能蒸煮就不煎炸，能低温就不高温"；
2. 焦黑部分别吃；
3. 剩菜（尤其绿叶菜）冷藏不超过 24 小时，隔夜菜彻底加热后再吃。

### 8.4 各类食物的推荐烹调方式

| 食物 | 推荐方式 | 避免 |
|------|---------|------|
| 绿叶蔬菜 | 急火快炒、蒸、焯水后拌 | 长时间炖煮、反复加热 |
| 根茎类 | 蒸、烤（去皮）、炖 | 油炸 |
| 鱼 | 清蒸、煮汤 | 油炸、烟熏 |
| 肉 | 炖、蒸、炒（切小块） | 明火炭烤、油煎过度 |
| 蛋 | 水煮、蒸蛋、少油煎 | 油温过高 |
| 米 | 正常淘洗1~2次即可 | 过度淘洗、加碱煮粥 |
| 杂粮 | 提前浸泡、混煮 | 加碱 |

### 8.5 食物储存原则

| 类别 | 储存方式 | 保质建议 |
|------|---------|---------|
| 蔬果 | 冷藏（0~4℃），透气 | 绿叶菜 2~3 天，根茎 1~2 周 |
| 奶蛋 | 冷藏 | 蛋放冰箱冷藏，奶看保质期 |
| 肉类 | 冷冻（-18℃） | 畜禽肉可存数周~数月，分装避免反复解冻 |
| 粮油坚果 | 避光、密封、阴凉 | 防氧化哈败；坚果可冷藏 |
| 剩菜 | 冷藏 | 24 小时内吃完，彻底加热 |
| 干货（木耳/香菇） | 干燥密封 | 防霉；泡发木耳/银耳冷藏且 4 小时内食用 |

**绝对不能吃的"变质标志"（直接扔，别可惜）：**
- 发芽、变绿、发苦的土豆（龙葵碱）；
- 发霉的花生、玉米、坚果（黄曲霉毒素，1类致癌物，**加热也破坏不了**）；
- 长了毛、发黏的面包、豆腐、水果；
- 哈喇味（油脂氧化）的食用油、坚果；
- 泡发过久（超过 2~4 小时常温）的木耳、银耳（米酵菌酸中毒风险）。

## 九、食品标签解读（顾客常问）

### 9.1 营养成分表：先认识"4+1"

按 GB 28050《预包装食品营养标签通则》，预包装食品必须标示**能量 + 蛋白质 + 脂肪 + 碳水化合物 + 钠**（"4+1"），以**每 100g / 每 100ml / 每份**为单位。

| 强制项 | 看什么 |
|--------|--------|
| 能量 | 单位是 **kJ**（千焦），除以 4.18 ≈ 大卡（kcal） |
| 蛋白质 | 优质食品看它；"高蛋白"需 ≥20%NRV |
| 脂肪 | 重点看**饱和脂肪**和**反式脂肪** |
| 碳水化合物 | 包含淀粉+糖，**无法从总量看出含糖量**，需看配料表 |
| 钠 | 隐藏盐的来源，选低钠更佳 |

### 9.2 NRV% 与能量换算

**NRV（营养素参考值）：** 每天 2000kcal 能量为基准的成人参考摄入量。

| 营养素 | NRV |
|--------|-----|
| 能量 | 8400 kJ（约2000 kcal） |
| 蛋白质 | 60g |
| 脂肪 | ≤60g |
| 碳水化合物 | 300g |
| 钠 | 2000mg |

**NRV% 怎么看：**
- 每 100g 中某营养素含量 ÷ NRV × 100%；
- **>20%NRV = "高"**（如高蛋白、高纤维）；
- **<5%NRV = "低"**（如低脂、低钠）；
- 单包超过 100%NRV（如钠）→ 警惕，可能一包就超标。

**能量换算例题：** 一包薯片标注能量 2300kJ/100g → 2300 ÷ 4.18 ≈ **550 kcal/100g**；若整包 150g 且一次吃完 → 约 825 kcal。

### 9.3 配料表规则

1. **按含量降序排列**：排第一位 = 含量最多；
2. 排在前面的 **白砂糖/果葡糖浆/麦芽糖浆/玉米糖浆 = 高糖**；
3. **氢化植物油/起酥油/植脂末/代可可脂 = 可能含反式脂肪**；
4. "全麦粉"是否在第一位（很多"全麦面包"第一位是小麦粉）；
5. 名称越长越"加工程度高"，添加剂多在配料表后段。

### 9.4 营养声称与含量声称（GB 28050 合规数值）

| 声称 | 判定标准 |
|------|---------|
| 高蛋白 / 富含蛋白 | ≥20%NRV（即≥12g/100g 固体） |
| 低脂 | 固体 ≤3g/100g；液体 ≤1.5g/100ml |
| 脱脂 | 液体 ≤0.5g/100ml |
| 无糖 | 每100g/100ml 糖 ≤0.5g |
| 低钠 | ≤120mg/100g |
| 高膳食纤维 | ≥6g/100g |
| 0能量 | ≤17kJ/100g 或 100ml |
| 无/零反式脂肪 | ≤0.3g/100g（可标"0"） |

### 9.5 营销话术辟谣大全

| 话术 | 真相 |
|------|------|
| "0脂肪" | 可能把脂肪换成了**糖**，能量照样高 |
| "0蔗糖" | 可能含**果糖、麦芽糖、海藻糖**——依然升糖 |
| "非油炸" | 可能是**烘焙/热风**（还行），也可能是**棕榈油油炸再烘干**（偷换概念）；看脂肪含量 |
| "无添加蔗糖" | ≠ 无糖，原料本身可能含糖（如浓缩果汁） |
| "高蛋白" | 要 ≥20%NRV 才算；低质蛋白粉兑水也算"高蛋白" |
| "能量 xx 千焦" | 除以 4.18 才是大卡，营销用大数字制造"低热量"错觉 |
| "0反式脂肪" | 每100g ≤0.3g 即可标0，不代表绝对没有 |
| "粗粮/全麦饼干" | 看配料表第一位是不是全麦/燕麦；很多是高油高糖"伪粗粮" |
| "果蔬脆片" | 冻干的还行，油炸的=高油零食；看配料和脂肪 |
| "零卡气泡水" | 能量确低，但含代糖（甜味剂），适量无害，别当水猛灌 |

### 9.6 标签速读三步法（教顾客）

1. **一看配料表第一位**（前三位决定了这食品的本质）；
2. **二看营养成分表**：能量（kJ÷4.18）、脂肪（饱和/反式）、钠；
3. **三查声称陷阱**：0脂肪/0蔗糖/非油炸 → 用"高糖？高油？高钠？"反查。

**给顾客一句话：** "不会看标签，等于把'买什么'的决定权交给了包装设计。"

## 十、食物相克？辟谣专区

### 10.1 常见"相克"说法逐条拆解

| 说法 | 真相 | 底层逻辑 |
|------|------|---------|
| 菠菜 + 豆腐 = 结石 | ❌ 不成立 | 草酸与钙在**肠道**结合为草酸钙随粪便排出，不进入血液形成肾结石；真正影响是两者吸收略降——菠菜焯水去草酸即可。**肾结石患者**应关注草酸总量，而非拒绝豆腐 |
| 维生素C + 海鲜 = 砒霜 | ❌ 不成立 | 需把海产品中微量五价砷还原为三价砷，需**巨大剂量+极端条件**，普通一顿饭的量差几个数量级 |
| 豆浆 + 鸡蛋 = 不吸收 | ❌ 不成立 | 生豆浆含抗胰蛋白酶因子，**煮熟即失活**；熟豆浆+鸡蛋没问题 |
| 柿子 + 螃蟹 = 腹痛 | ⚠️ 非"相克" | 柿子高鞣酸 + 螃蟹高蛋白，在胃酸中可能形成"胃柿石"；**空腹/胃动力弱/一次大量**时可能不适，是"量+时机"问题 |
| 桃子 + 西瓜 = 中毒 | ❌ 无稽之谈 | 均高糖水果，一次吃太多只会撑肚子 |
| 葱 + 蜂蜜 = 中毒 | ❌ 无可靠依据 | 偶有个例报道多为**蜂蜜质量问题（肉毒/微生物污染）** |
| 白萝卜 + 胡萝卜 = 破坏维C | ⚠️ 微弱影响 | 白萝卜含抗坏血酸氧化酶，但体内影响可忽略，正常搭配吃无碍 |

### 10.2 底层逻辑：为什么"相克"不成立

1. **剂量问题**：绝大多数"化学反应"需要实验室级别的浓度与条件，日常饮食远达不到；
2. **消化系统是"缓冲器"**：胃酸、肠道菌群、屏障会稀释、分解、拦截大部分物质；
3. **归因错误**：古人把"食物中毒、过敏、不耐受、不洁、吃多"归因为"相克"；
4. **权威立场**：我国食品安全国家标准体系与现代营养学**不承认"食物相克"**；《中国居民膳食指南》也明确辟谣。

### 10.3 真正要注意的食物安全问题（替代"相克"的关注点）

| 真实风险 | 例子 |
|---------|------|
| 食物过敏 | 花生、海鲜、牛奶、鸡蛋过敏 |
| 食物不耐受 | 乳糖不耐、果糖不耐 |
| 微生物污染 | 未熟透的肉蛋、生食贝类、隔夜菜 |
| 天然毒素 | 未熟豆类（皂素）、鲜黄花菜（秋水仙碱）、发芽土豆（龙葵碱）、河豚毒素 |
| 食物-药物相互作用 | 西柚汁+部分他汀/降压药；酒精+头孢 |
| 营养过剩 | 过量某营养素补充剂（详见 11.03 UL 部分） |

## 十一、常见食物营养素密度对比

### 11.1 什么是营养素密度

**营养素密度 = 单位能量（每 100kcal 或每 100g）中所含营养素（维生素/矿物质/蛋白等）的量。**

- 高分食物：能量低、营养素多（深色蔬菜、浆果、瘦肉、蛋、奶、鱼）；
- 低分食物：能量高、营养素少（油、糖、酒精、含糖饮料、油炸零食）——又称**"空能量食物"**。

| 西兰花 | 36 | ★★★★★ | 十字花科+VC+叶酸 |
| 圣女果 | 22 | ★★★★ | VC、番茄红素 |
| 蓝莓 | 57 | ★★★★ | 花青素、锰 |

### 11.3 高分食物清单（营养效率排行榜）

| 榜单 | 食物 |
|------|------|
| 蔬菜营养密度 TOP | 菠菜、西兰花、油菜、羽衣甘蓝、胡萝卜、番茄 |
| 水果 TOP | 蓝莓、草莓、猕猴桃、橙子、柚子 |
| 蛋白 TOP | 鸡蛋、三文鱼、鸡胸、瘦牛肉、豆腐 |
| 补钙 TOP | 奶酪、牛奶、酸奶、北豆腐、芝麻酱（控量） |
| 补铁 TOP | 猪肝（适量）、红肉、鸭血、蛏子；植物铁（菠菜/黑木耳）配合 VC 促吸收 |

### 11.4 应用：给减脂/优化饮食人群

- 减脂不等于"饿肚子"，而是**选高营养密度食物、把能量预算花在刀刃上**；
- "每餐先吃高密度部分"：蔬菜→蛋白→主食，天然控制能量；
- 用营养素密度解释"为什么水果可以吃、果汁不能喝"。

## 十二、"超级食物"辟谣

### 12.1 什么是"超级食物"

"超级食物（Superfood）"是**营销概念，不是营养学分类**。任何食物只要被冠上"超级"，本质是利用"稀缺+奇异+故事"制造购买欲。营养学界没有"超级食物"的定义——只有**超级膳食模式**。

### 12.2 常见"超级食物"逐一拆解

| "超级食物" | 真实营养 | 冷静结论 |
|-----------|---------|---------|
| 牛油果 | 单不饱和脂肪、钾、纤维、叶酸 | 不错的水果，但能量高（一个约200~300kcal），**不是神药**；普通家庭非必需 |
| 藜麦 | 植物蛋白含赖氨酸、铁、镁、纤维 | 优秀，但燕麦、荞麦、糙米同样优秀，**不必追高价** |
| 奇亚籽 | ALA（n-3）、纤维、钙 | 每天一小勺（约15g）即可；**干吃有呛咳风险**，泡水/拌酸奶 |
| 巴西莓 | 花青素、抗氧化 | 抗氧化≠治病；冻干粉贵且无不可替代成分 |
| 姜黄 | 姜黄素（体外抗氧化） | 吸收率极低，需配黑胡椒+油脂；**当调味即可**，不夸大 |
| 诺丽果/玛卡 | 维生素、植物化学物 | 宣传远大于证据；无独特健康承诺 |
| 羽衣甘蓝 | 高维K、胡萝卜素、钙 | 确实优秀，但**菠菜/油菜/西兰花是平价同款** |

### 12.3 结论与给顾客的"翻译"

- **没有单独一种"神药级"食物**，健康来自**长期、多样、均衡**的膳食；
- "超级食物"如果好吃、负担得起，吃它没问题——但**别为营销溢价买单**；
- 对顾客讲："与其追一种超级食物，不如一周凑齐 25 种普通食物的超级搭配。"

### 13.1 应用场景话术表

| 场景 | 讲什么 | 用哪个章节 |
|------|--------|-----------|
| 顾客问"早餐吃什么" | 全谷物 + 鸡蛋 + 奶 + 水果 = 满分组合 | 二、五、六章 |
| 顾客问"怎么补钙" | 奶 300~500ml + 豆腐 + 深绿叶菜；钙吃够量 | 六章 |
| 顾客问"怎么补铁" | 红肉适量 + 动物血/肝 + 维C 促吸收；血红素铁 vs 植物铁 | 五章、十一章 |
| 顾客问"营养补充剂怎么选" | 先食物补（天然食物营养密度最高），缺口再考虑补充剂；不超 UL | 三、六、十三章 + 11.03 |
| 教客户看标签 | 一读配料表（第一位）→ 二看营养成分表（能量/脂肪/钠）→ 三防声称陷阱 | 九章 |
| 辟谣 | 食物相克不成立、果汁≠水果、0脂肪≠健康、超级食物是营销 | 四、九、十、十二章 |
| 给糖尿病顾客 | 全谷物+杂豆替换主食、深色蔬菜过半、整果>果汁、控添加糖 | 二、三、四、七章 |
| 给减脂顾客 | 高营养密度食物、先蔬菜再蛋白后主食、控烹调油 | 八、十一章 |
| 给老人 | 蛋白质 1.0~1.2g/kg·d、奶豆层补钙、软烂烹调不丢营养、防霉变 | 五、六、八章 |

### 13.2 给顾客的"买菜清单"模板（可复制）

```
今日买菜清单（一家三口·一日）
主食：糙米/杂粮（约450g）· 燕麦
蔬菜：深色 300g+（菠菜/西兰花/胡萝卜）+ 浅色（冬瓜/白菜）

坚果：一小把原味核桃/杏仁
油盐：菜籽油约90g/天用量 · 盐<15g（全家用）
```
