## 一、公共营养的定义与学科定位

### 1. 定义

**公共营养（Public Nutrition）：** 研究人群营养状况、营养问题及其影响因素，通过营养调查、监测、教育和干预，改善群体营养状况的应用学科。

它不同于"营养学基础"（研究营养素代谢机制），也不同于"临床营养"（研究个体疾病营养治疗），它把**研究对象从"个体"放大到"人群"**，把**手段从"治疗"转向"预防与促进"**。它的核心问题始终是：

> 谁（哪类人群）缺什么营养素？为什么缺？怎么让一群人吃得更对？

### 2. 与临床营养的区别

| 维度 | 临床营养 | 公共营养 |
|------|---------|---------|
| 对象 | 病人个体 | 人群/社区/家庭/学校/企业 |
| 场景 | 医院（病房/门诊） | 社区、学校、企业、食堂、家庭 |
| 手段 | 营养治疗/营养支持（ONS、EN、PN） | 调查、监测、教育、干预、政策 |
| 目标 | 治病、改善疾病结局 | 防病、改善群体健康、降低慢病风险 |
| 时间跨度 | 疾病周期（相对短） | 长期、可持续 |
| 评价单位 | 个体营养状态 | 人群营养指标（率、均数、分布） |
| 典型产出 | 营养处方、营养支持方案 | 调查报告、科普内容、干预方案、政策建议 |

**一句话记：** 临床营养治"已病"，公共营养管"未病"和"人群"。

### 3. 与相关学科的关系

| 相邻学科 | 关系 |
|---------|------|
| 营养学基础 | 提供"营养素怎么代谢"的底层原理，公共营养是这些原理在人群中的应用 |
| 临床营养 | 处理个体疾病营养，公共营养发现问题后常转介给临床营养；两者互为上下游 |
| 流行病学 | 公共营养的方法学来源（调查设计、抽样、统计） |
| 食品卫生 | 管"食品安不安全"，公共营养管"吃得够不够、对不对" |
| 卫生政策 | 公共营养的最终产出往往落到政策（膳食指南、营养标签、专项行动） |
| 行为科学/健康教育 | 营养教育的行为改变理论基础 |

### 4. 公共营养的核心工作内容

```
营养调查 ──→ 发现问题（谁缺、缺什么）
   │
   ▼
营养监测 ──→ 持续跟踪（变化趋势、干预效果）
   │
   ▼
营养教育 ──→ 改变认知与行为（科普、讲座、课程）
   │
   ▼
营养干预 ──→ 系统性改善（环境、政策、项目）
   │
   ▼
效果评估 ──→ 复测对比（数据说话）
```

五大板块缺一不可：**调查是诊断，监测是随访，教育是处方，干预是治疗，评估是复查。**

### 5. 学科发展简史（快速了解脉络）

| 时期 | 标志性事件 | 意义 |
|------|-----------|------|
| 20世纪初 | 维生素/矿物质缺乏病流行调查 | 公共营养的雏形 |
| 1936年 | 中国营养学会前身成立 | 学科组织化 |
| 1982年起 | 中国每10年开展全国性营养调查 | 建立国家营养数据 |
| 1989年 | 首版《中国居民膳食指南》发布 | 从研究走向大众指导 |
| 2000年 | 《中国居民膳食营养素参考摄入量（DRIs）》发布 | 有"标尺"可依 |
| 2011年 | GB 28050 营养标签通则实施 | 食品包装有了统一"营养语言" |
| 2017年 | "三减三健"专项行动全面推行 | 干预进入国家行动 |
| 2020年 | 《中国居民营养与慢性病状况报告（2020）》发布 | 最新的国家"健康体检报告" |
| 2022年 | 《中国居民膳食指南（2022）》发布 | 平衡膳食八准则 |

## 二、营养调查（第一块基本功）

### 1. 营养调查概述

**概念：** 营养调查（Nutritional Survey）是指运用一定方法，了解特定人群在一定时间内的营养状况及其影响因素的调查研究。它回答三个问题：**吃了什么？够不够？身体怎么样？**

**调查类型：**

| 分类维度 | 类型 | 说明 |
|---------|------|------|
| 按对象 | 个体调查 | 一个人的膳食与营养状况 |
| 按对象 | 群体调查 | 社区/学校/企业/国家样本 |
| 按时间 | 横断面调查 | 一个时间点"拍照" |
| 按时间 | 纵向调查 | 长期跟踪"录像" |

**完整的营养调查四大内容（常组合开展）：**
1. 膳食调查（吃进去多少）
2. 人体测量（身体形态）
3. 生化检查（血液/尿液营养素水平）
4. 临床检查（缺乏/过多体征）

### 2. 膳食调查四类方法详解

#### 2.1 24小时膳食回顾法（24-hour Dietary Recall）

**定义：** 通过访谈，让调查对象回忆并报告过去24小时内（通常从前一天清晨到调查当天清晨，或过去一整天）摄入的全部食物和饮料的种类与数量。

**操作步骤（标准流程）：**

```
① 准备：熟悉食物图谱/食物模型、份量换算表、当地常见食物清单
② 开场：说明目的，建立信任，不评判（"吃多吃少都对"）
③ 回忆：从起床到睡觉，按时间顺序（早餐→上午→午餐→下午→晚餐→夜宵）
④ 追问：逐餐问"吃了什么？喝了什么？加了多少？有没有零食？"
⑤ 定量：用食物图谱、实物模型、家用量具（碗/勺/杯）估计份量
⑥ 复核：最后整体回放一遍，让对象补充遗漏（外卖、零食、饮料）
```

**关键细节：**
- 食物份量估计是最大误差来源，要反复训练调查员
- 尽量覆盖**1个周末日**（饮食模式周内不同）
- 常用做法：连续3天（2个工作日+1个休息日），或非连续3天

**优点：**

| 优点 | 说明 |
|------|------|
| 简便快捷 | 一次访谈10~30分钟 |
| 应答率高 | 不需要长期记录，负担小 |
| 不受文化水平限制 | 口述即可 |
| 不改变饮食习惯 | 不需要称重，较少干扰日常 |
| 可覆盖外食/外卖 | 只要记得住 |

**缺点：**

| 缺点 | 说明 |
|------|------|
| 回忆偏倚 | 遗忘、多报、少报 |
| 份量估计误差 | 高估低估常见 |
| 单日代表性差 | 一天吃的不代表长期 |
| 受调查员水平影响 | 追问技巧差异大 |

**适用场景：** 个体营养咨询、群体横断面调查、评估短期膳食摄入、营养教育前后对比。

#### 2.2 食物频率问卷法（Food Frequency Questionnaire, FFQ）

**定义：** 以问卷形式，询问调查对象在**过去一段时间内**（1个月、3个月、6个月、1年）摄入各种食物或食物类别的**频率**（每天/每周/每月）和大致份量。

**类型：**

| 类型 | 特点 |
|------|------|
| 定性FFQ | 只问频率，不问份量 |
| 定量FFQ | 频率+标准份量 |
| 半定量FFQ（SQFFQ） | 频率+常见份量选项（最常用） |

**操作步骤：**

```
① 确定食物清单：列出当地/目标人群常吃食物（通常50~150项）
② 确定回顾时限：1个月/3个月/1年
③ 设计频率选项：每天几次/每天1次/每周几次/每周1次/每月几次/几乎不吃
④ 确定份量：家庭常用份量或照片
⑤ 面访或自填：由对象勾选频率与份量
⑥ 数据处理：频率×份量×食物成分表→营养素摄入
```

**优点：**

| 优点 | 说明 |
|------|------|
| 反映长期膳食模式 | 适合研究"长期习惯与慢病关系" |
| 成本低 | 可自填，适合大规模流调 |
| 不改变饮食习惯 | 回忆性质 |
| 便于分层分析 | 按频率高低分组比较 |
| 可分类排序 | 把人群按摄入高低排队 |

**缺点：**

| 缺点 | 说明 |
|------|------|
| 精确度低 | 只能估计"大概" |
| 食物清单外遗漏 | 清单外的食物吃再多也统计不到 |
| 频率判断主观 | 不同人对"经常"理解不同 |
| 份量估计粗糙 | 标准化份量与真实份量有偏差 |
| 问卷设计难度大 | 清单长度、可读性、文化适配都要打磨 |

**适用场景：** 营养流行病学（膳食与慢病关联研究）、大规模人群调查、评估长期膳食模式与风险分层。

#### 2.3 称重记录法（Weighed Food Record / 称重法）

**定义：** 要求调查对象在**调查期内（通常3~7天）**，将每餐摄入的食物、饮料以及剩余食物逐一**称重并记录**，以获取最精确的实际摄入量。

**操作步骤：**

```
① 培训：教会对象使用食物秤、记录表、生熟换算
② 记录餐前量：每餐食物称生重/熟重后记录
③ 记录剩余量：餐后称剩余/丢弃量
④ 记录零食饮料：全天所有入口的东西都要称
⑤ 记录做法：注明烹饪方法（煮/炒/炸）、是否去皮
⑥ 汇总折算：净摄入量 = 称入量 − 剩余量；生熟换算回可食部
```

**优点：**

| 优点 | 说明 |
|------|------|
| 精确度高 | 是四法中"金标准" |
| 客观 | 不依赖回忆 |
| 可同时测剩余 | 能算真实"吃进去"而非"端上来" |

**缺点：**

| 缺点 | 说明 |
|------|------|
| 依从性差 | 天天称重很麻烦，掉队率高 |
| 耗时费力 | 对调查对象和调查员都是负担 |
| 可能改变饮食习惯 | 为省事少吃/简化记录 |
| 成本高 | 需要设备、人力、督导 |
| 不适合大样本 | 只能小样本精测 |

**适用场景：** 小样本精确研究、特殊人群（孕产妇、儿童、代谢病房）、验证其他方法的准确性、营养支持方案个体化评估。

#### 2.4 记账法（账本法 / Food Account Method）

**定义：** 在**家庭或集体食堂**中，记录一定时期内（1个月~3个月）食物的**采购量、消耗量、用餐人数及剩余量**，折算成人均每日食物摄入量。

**操作步骤：**

```
① 建账：设计记账本，登记每日采购的食物名称、数量、金额
② 记录消耗：记录每日消耗（从库存中取出使用的量）
③ 记录人数：每天实际就餐人数、年龄性别构成
④ 记录剩余/浪费：餐后剩余食物称重记录
⑤ 折算人均：总消耗量 ÷ 就餐人日数 = 人均每日摄入
⑥ 换算营养素：人均食物量 × 食物成分表 → 人均营养素摄入
```

**优点：**

| 优点 | 说明 |
|------|------|
| 覆盖时间长 | 可连续记录1~3个月 |
| 省人力 | 记账员每日少量登记即可 |
| 不干扰日常 | 家庭照常吃饭 |
| 适合集体 | 食堂、托幼、养老机构 |
| 能看总量趋势 | 便于监测某单位整体饮食结构 |

**缺点：**

| 缺点 | 说明 |
|------|------|
| 不能个体化 | 得到的是"人均"，老人孩子孕妇分不出 |
| 忽略外食/零食 | 在外吃的、买着吃的算不进来 |
| 家庭成员分配不均 | 人均≠每个人真吃的量 |
| 隐性浪费难计 | 清洗损耗、喂宠物等难记录 |

**适用场景：** 家庭户膳食调查、集体食堂（学校、工厂、部队、养老院）膳食评价、地区食物消费水平监测。

### 3. 四类方法对比总表（决策用）

| 对比项 | 24h回顾法 | FFQ | 称重法 | 记账法 |
|--------|----------|-----|--------|--------|
| 反映时段 | 过去24h | 过去1月~1年 | 调查期3~7天 | 1~3个月 |
| 精确度 | 中 | 低 | 最高 | 中低 |
| 成本 | 低 | 低 | 高 | 低 |
| 调查对象负担 | 小 | 小 | 大 | 小 |
| 是否改变饮食习惯 | 否 | 否 | 可能 | 否 |
| 能否个体化 | 能 | 能 | 能 | 不能（人均） |
| 能否看长期 | 不能 | 能 | 不能 | 能 |
| 适合样本量 | 中小 | 大 | 小 | 中大 |
| 典型用途 | 流调、个体咨询 | 营养流行病学 | 科研精测 | 家庭/食堂 |

**选法口诀：** 要准选称重，要快选24h回顾，要看长期选FFQ，要看集体食堂选记账。

### 4. 生化检查（客观指标）

**定义：** 通过血液、尿液等生物样本检测营养素水平或代谢产物，客观反映近期营养状态。

| 指标 | 反映 | 临床意义 |
|------|------|---------|
| 血红蛋白 | 铁营养、贫血 | <130g/L（男）/ <120g/L（女）提示贫血 |
| 血清铁蛋白 | 铁储备 | 低提示铁缺乏 |
| 血清白蛋白 | 内脏蛋白、蛋白质营养 | <35g/L提示蛋白质营养不良（半衰期长，慢指标） |
| 前白蛋白 | 短期蛋白变化 | 半衰期约2天，反映近期蛋白摄入 |
| 血清钙/磷/碱性磷酸酶 | 钙、维生素D、骨代谢 | 辅助判断骨营养 |
| 血清25-(OH)D | 维生素D水平 | <20ng/ml为缺乏 |
| 维生素A（视黄醇） | 维生素A | 低与夜盲相关 |
| 尿碘 | 碘营养 | 反映近期碘摄入 |
| 血糖/血脂 | 糖脂代谢 | 慢病风险评估 |

**注意：** 生化指标受疾病、炎症、脱水等影响，需结合膳食调查和人体测量综合判读，不能单看一项。

### 5. 营养素摄入量评价（对比DRIs）

把膳食调查得到的营养素摄入量与 DRIs（见第三章）对比，判断"够不够"：

```
摄入量 < EAR  → 该营养素摄入不足风险高（人群中约半数人不够）
摄入量 ≥ RNI  → 摄入充足的可能性大
摄入量在 EAR~RNI 之间 → 不能确定是否充足
摄入量 ≥ UL   → 有过量风险
```

**能量评价要点：** 能量摄入"够不够"看体重变化趋势（能量负平衡→体重下降），不看单一营养素，而看三大产能营养素（碳水、蛋白质、脂肪）的比例是否合理。

## 三、膳食营养素参考摄入量（DRIs）

**定义：** DRIs（Dietary Reference Intakes）是一组用于评价和计划人群膳食的营养素摄入参考值，是营养调查的"标尺"。

### 1. 四个核心指标

| 指标 | 全称 | 含义 | 用途 |
|------|------|------|------|
| EAR | 平均需要量 | 满足**50%**人群需要的摄入量 | 评价人群摄入不足比例 |
| RNI | 推荐摄入量 | 满足**97%~98%**人群需要的摄入量（= EAR + 2SD） | 个体摄入目标 |
| AI | 适宜摄入量 | 观察/实验确定的"足够"量（证据不足时替代RNI） | 无EAR时的参考 |
| UL | 可耐受最高摄入量 | 几乎所有人**不会引起不良反应**的最高摄入量 | 避免过量 |

**关系图示：**

```
摄入不足区  |  适宜区  |  过量风险区
     EAR      RNI           UL
     │        │             │
────────┼────────┼─────────────┼─────▶ 摄入量
     ↑人群评价   ↑个体目标      ↑上限
```

## 四、营养状况评价（四维度）

**营养状况评价 = 把四类信息拼在一起，判断一个人/一群人"营养好不好"。**

### 1. 四维度总览

| 维度 | 内容 | 回答的问题 |
|------|------|-----------|
| ① 膳食摄入 | 膳食调查结果 vs DRIs | 吃进去够不够 |
| ② 人体测量 | BMI、皮褶厚度、臂围、腰围等 | 身体形态和储备怎么样 |
| ③ 生化指标 | 血/尿营养素水平 | 体内水平客观如何 |
| ④ 临床体征 | 缺乏/过多体征 | 有没有可见的缺乏表现 |

### 2. 人体测量核心指标与标准

#### 2.1 身高、体重与 BMI

**BMI = 体重(kg) ÷ 身高(m)²**

**中国成人BMI标准（WS/T 428-2013，不同于WHO通用标准）：**

| 分级 | 中国标准 | 备注 |
|------|---------|------|
| 偏瘦 | < 18.5 | 需关注是否摄入不足 |
| 正常 | 18.5 ~ 23.9 | 目标范围 |
| 超重 | 24.0 ~ 27.9 | 慢性病风险开始上升 |
| 肥胖 | ≥ 28.0 | 高风险，需干预 |

> ⚠️ 中国标准比WHO标准更严：WHO定义超重为BMI≥25、肥胖为BMI≥30。用中国标准评估中国人群。

**老年人体重标准补充：** ≥65岁老人，BMI正常范围可放宽至20.0~26.9（适当高一点反而有保护作用，"老来微胖"更安全）。

#### 2.2 腰围与腰臀比（中心型肥胖）

| 指标 | 标准 | 意义 |
|------|------|------|
| 腰围 | 男 < 90cm；女 < 85cm | 超过即为中心型（腹型）肥胖预警 |
| 腰臀比 | 男 < 0.9；女 < 0.85 | 反映脂肪分布 |

**测量方法：** 站立，两脚分开与肩同宽，测量**髂前上棘与第12肋下缘连线的中点**水平绕腹一周（皮尺紧贴皮肤但不压陷），在呼气末读数。

**为什么重要：** 腹型肥胖与代谢综合征、心血管病、2型糖尿病相关性比单纯BMI高，是"看得见的代谢风险"。

#### 2.3 皮褶厚度

| 部位 | 缩写 | 反映 |
|------|------|------|
| 肱三头肌皮褶 | TSF | 全身皮下脂肪代表 |
| 肩胛下皮褶 | SST | 躯干脂肪 |

**用途：** 间接估计体脂率、评价能量储备。需专用皮脂卡尺，误差大，需熟练操作。

#### 2.4 臂围与小腿围

| 指标 | 参考 | 用途 |
|------|------|------|
| 中上臂围（MAC） | 成人约 男25.3cm、女23.2cm（地区差异大） | 反映肌肉+脂肪整体，营养不良时下降 |
| 小腿围（CC） | < 31cm（老年人） | **肌少症筛查**常用指标（ESPEN/亚洲共识） |

> 💡 小腿围是最简单的"肌肉储备"指标——用软尺绕小腿最粗处量，<31cm就要警惕肌肉流失，尤其适合社区快速筛查老人。

#### 2.5 握力（肌力指标）

| 标准（亚洲肌少症工作组AWGS） | 数值 |
|------------------------------|------|
| 男性 | < 28 kg |
| 女性 | < 18 kg |

**意义：** 握力低提示肌少症风险，是"肌肉质量+功能"的快捷测量，与跌倒、失能、全因死亡风险相关。

#### 2.6 体脂率（生物电阻抗法）

| 人群 | 参考范围 |
|------|---------|
| 男性 | 15% ~ 20% |
| 女性 | 20% ~ 25% |

**注意：** 家用体脂秤受水分、进食、运动影响波动大，用于趋势观察而非绝对判断。

#### 2.7 学龄前儿童与青少年（简表）

- 儿童青少年采用**年龄别BMI Z评分**或百分位数判断超重肥胖（用生长标准曲线）
- 常用：WHO儿童生长标准、中国0~18岁儿童青少年生长标准
- 不再用"成人BMI切点"直接套儿童

### 3. 营养缺乏的常见临床体征（识别用）

| 体征 | 常提示缺乏 | 对应营养素 |
|------|-----------|-----------|
| 夜盲、暗适应差 | 维生素A缺乏 | 维生素A |
| 口角炎、舌炎 | B族维生素缺乏 | 维生素B2（核黄素）等 |
| 牙龈出血 | 维生素C缺乏 | 维生素C |
| 皮肤瘀斑、伤口难愈 | 维生素C、蛋白质 | 维生素C、蛋白质 |
| 骨骼变形（儿童鸡胸/膝内翻） | 维生素D缺乏、钙不足 | 维生素D、钙 |
| 面色苍白、乏力 | 贫血 | 铁、叶酸、维生素B12 |
| 甲状腺肿大 | 碘缺乏 | 碘 |
| 反复感染、毛发干枯 | 蛋白质-能量营养不良 | 蛋白质、能量 |
| 龋齿 | 糖摄入过多、氟不足 | 添加糖、氟 |

> ⚠️ 体征只是线索，确诊需结合生化检查与临床评估。发现体征不等于"下诊断"，应建议就医或进一步检测。

## 五、营养监测体系

### 1. 概念与目的

**营养监测（Nutrition Surveillance）：** 对人群营养状况及影响因素进行**长期、连续、系统**的收集、分析和反馈，用于**动态跟踪趋势**和**评价干预效果**。

| 与营养调查的区别 | 调查 | 监测 |
|-----------------|------|------|
| 时间 | 一次性/间断 | 连续/定期 |
| 目的 | 摸清现状 | 跟踪变化、预警 |
| 产出 | 横断面报告 | 时间序列数据 |

### 2. 监测指标分类

| 指标类别 | 具体指标 |
|---------|---------|
| 膳食摄入 | 人均食物消费量、营养素摄入量、膳食结构（谷/肉/蔬果/奶占比） |
| 人体测量 | 身高体重、BMI分布、超重肥胖率、儿童生长迟缓率 |
| 生化营养 | 贫血率、维生素D水平、碘营养、血脂血糖 |
| 疾病相关 | 高血压、糖尿病、血脂异常、痛风等患病率 |
| 行为因素 | 食盐摄入、油摄入、蔬果摄入、身体活动、吸烟饮酒 |

### 3. 中国监测体系与关键数据

**主要来源：**
- 中国居民营养与慢性病状况报告（国家卫健委，约每5年一次，基于全国营养调查+慢病监测）
- 中国健康与营养调查（CHNS，与北卡大学合作，长期纵向队列）
- 全国死因监测、全国肿瘤登记

**《中国居民营养与慢性病状况报告（2020年）》关键数据（引用务必核对最新版）：**

| 指标 | 数据 | 解读 |
|------|------|------|
| 成人超重率 | 34.3% | 每3个成人约1个超重 |
| 成人肥胖率 | 16.4% | 合计**超重肥胖率超50%** |
| 6~17岁儿童青少年超重率 | 11.1% | 儿童超重肥胖率合计约19% |
| 6~17岁儿童青少年肥胖率 | 7.9% | 接近五分之一 |
| 6岁以下儿童超重率 | 6.8% | 低龄也需关注 |
| 6岁以下儿童肥胖率 | 3.6% | — |
| 成人高血压患病率 | 27.5% | 每4个成人约1个 |
| 成人糖尿病患病率 | 11.9% | 每9个成人约1个 |

| 人均每日烹调用盐 | 9.3克 | 高于推荐<5克近一倍 |
| 家庭人均每日烹调用油 | 43.2克 | 高于推荐25~30克 |
| 人均水果摄入 | 明显不足 | 远低于推荐200~350g |
| 乳类消费 | 偏低 | 低于推荐300g/日 |
| 身体活动 | 不足 | 久坐普遍 |

**从数据看到的三大问题（可直接用于科普选题）：**
1. **肥胖超重成为第一大营养问题**——从"营养不良（缺乏）"转向"营养过剩/失衡"
2. **盐、油、糖三高**——高血压高发的膳食根源
3. **蔬果、奶类、全谷不够**——膳食结构失衡，"隐形饥饿"仍存在（微量营养素缺乏）

### 4. 监测与政策的联动

```
监测数据 → 发现趋势 → 制定政策/指南 → 实施干预 → 再监测评估
    ↑                                          │
    └──────────────────────────────────────────┘
```

**典型案例：** 监测发现居民食盐过高 → 全民健康生活方式行动提出减盐 → "三减三健"专项行动 → 持续监测验证减盐效果。

## 六、营养教育（做科普的方法论）

### 1. 概念与目的

**营养教育（Nutrition Education）：** 通过有计划的传播与教育活动，帮助人们**掌握营养知识、形成健康信念、改变饮食行为**的过程。核心不是"灌输知识"，而是"促成行为改变"。

### 2. 营养教育流程（六步法）

```
① 了解目标人群
   │  （谁？年龄/文化/经济/现状/痛点）
   ▼
② 确定核心问题
   │  （这个人群最要紧的营养问题是什么）
   ▼
③ 设定教育目标
   │  （可量化：如"3个月后咸度降低20%"）
   ▼
④ 选择内容与形式
   │  （内容：知识+技能+态度；形式：见下表）
   ▼
⑤ 执行
   │  （传播、互动、实操、答疑）
   ▼
⑥ 评估效果
   （知识前后测、行为改变率、满意度）
```

**目标设定 SMART 原则：** 具体（Specific）、可测量（Measurable）、可达成（Achievable）、相关（Relevant）、有时限（Time-bound）。

### 3. 教育形式与选择

| 形式 | 特点 | 适用 | AI营养师怎么用 |
|------|------|------|---------------|
| 一对一咨询 | 个体化、深度 | 个体健康管理 | 顾客个案跟进 |
| 小组课/讲座 | 效率高、有同伴 | 家庭/社群 | 健康社群开课 |
| 短视频/图文 | 传播广、轻量 | 大众传播 | **主战场** |
| 食物示范/实操 | 学得会、记得住 | 学做饭、控盐控油 | 直播做饭教学 |
| 学校/食堂干预 | 改变环境、覆盖面大 | 儿童肥胖防控 | 对接学校项目 |
| 公众号长文 | 深度、可收藏 | 慢病管理科普 | 公众号输出 |
| 线下活动/义诊 | 面对面信任 | 社区 | 社区健康日 |

### 4. 行为改变理论（提高科普转化率）

| 理论 | 核心 | 应用启示 |
|------|------|---------|
| KAP模型 | 知识→态度→行为 | 先给知识，再改信念，再推行为（单向线性，偏简单） |
| 健康信念模型 | 感知易感性+严重性+收益+障碍 | 让观众觉得"风险离我不远"+"改变不难" |
| 社会认知理论 | 自我效能+观察学习+环境 | 给"我也能做到"的榜样，制造可模仿动作 |
| 计划行为理论 | 态度+主观规范+感知行为控制 | 让"家人朋友都在做"成为推动力 |
| 阶段变化模型 | 前意向→意向→准备→行动→维持 | 不同阶段给不同信息（没想过的人别直接给行动方案） |

> 💡 对大众科普最实用的是**阶段变化模型**：对"完全没想过控盐"的人，先唤起意识；对"已经在减盐"的人，给技巧和鼓励，而不是所有人一套"应该少吃盐"。

### 5. 有效科普三原则

1. **说人话**：把专业术语翻译成生活语言
   - 不说"必需氨基酸"，说"身体的积木"
   - 不说"抗氧化"，说"给身体穿铠甲"
   - 不说"能量负平衡"，说"吃进去的少于消耗掉的"

2. **给动作**：不只讲道理，给"明天就能做"的一步
   - 不说"要减盐"，说"明天炒菜，盐勺减一半"
   - 不说"要补钙"，说"今天开始每天一杯奶"

3. **有依据**：关键观点挂权威来源
   - 指南/官方报告/专家共识
   - 让转发者"有理有据"，降低社交分享风险

**科普翻译对照示例：**

| 专业说法 | 说人话版本 |
|---------|-----------|
| 增加膳食纤维摄入 | 每天多吃一把杂豆、半碗燕麦 |
| 限制钠摄入 | 少放盐、少吃腌菜、看包装上的钠 |
| 优化脂肪酸结构 | 炒菜油换着用，多吃鱼少吃肥肉 |
| 增加优质蛋白 | 每天一个蛋、一杯奶、掌心大的肉 |
| 控制添加糖 | 奶茶换成三分糖，甜饮料改喝水 |

### 6. 营养谣言识别（科普基本功）

#### 6.1 谣言四大特征

| 谣言特征 | 典型话术 | 为什么是坑 |
|---------|---------|-----------|
| 绝对化 | "XX包治百病""XX千万别吃" | 营养学没有"绝对"，剂量和个体差异决定一切 |
| 恐吓营销 | "XX致癌"（脱离剂量） | 抛开剂量谈毒性是耍流氓 |
| 神奇食物 | "XX能抗癌" | 单一食物≠药物，健康是整体膳食的结果 |
| 断章取义 | "研究证明XX"（截取片段） | 断章取义夸大结论，忽略研究条件与样本 |

#### 6.2 谣言识别五问（教给学员的检查清单）

```
① 谁说的？有署名/机构吗？有没有利益关联（卖货）？
② 有多夸张？"根治""神效""一吃就好"→高度怀疑
③ 有出处吗？能追到论文/指南原文吗？还是"国外研究"一句带过？
④ 什么剂量？说"XX抗癌"却没提吃多少、吃多久？
⑤ 怎么反证？有没有相反的证据/权威辟谣？
```

#### 6.3 常见营养谣言速查

| 谣言 | 真相要点 |
|------|---------|
| 喝醋能软化血管 | 醋进胃后分解，到不了血管；无证据 |
| 碱性体质更健康 | 人体pH严格自稳，无"碱性体质"科学概念 |
| 吃某某能治高血压 | 食物辅助，不能替代药物与规范治疗 |
| 某种单一食物抗癌 | 没有"抗癌食物"，是整体膳食模式的作用 |
| 不吃饭能饿死癌细胞 | 会先饿死自己（营养不良），肿瘤照长 |
| 反季节食物有害 | 无充分证据，重点是多样性 |
| 土鸡蛋比洋鸡蛋营养高很多 | 差异很小，营养差别可忽略 |
| 微波炉加热致癌 | 无科学依据，微波加热是安全的 |

> 📌 科普原则：**不确定就说不确定**。用"目前证据认为""大规模研究显示"替代"一定""绝对"。

## 七、社区营养干预（做项目）

### 1. 概念

**社区营养干预（Community Nutrition Intervention）：** 以社区为平台，针对特定营养问题，综合运用**教育、环境改造、政策制度**等手段，系统性地改善人群营养状况的实践活动。

### 2. 干预流程（六步）

```
① 需求评估
   │  （调查→发现痛点：如食堂太咸、孩子零食多）
   ▼
② 设定目标
   │  （可量化：如"半年内食堂人均盐量降15%"）
   ▼
③ 设计干预方案
   │  （选手段：教育+环境+政策，见下）
   ▼
④ 执行
   │  （分工、物料、时间表）
   ▼
⑤ 过程监测
   │  （中途看执行情况，及时纠偏）
   ▼
⑥ 效果评估
   （复测：体重/血压/盐摄入/行为问卷前后对比）
```

### 3. 干预层次（不只靠说教）

| 层次 | 作用机制 | 例子 |
|------|---------|------|
| 个体教育 | 改变认知与行为 | 一对一营养咨询、健康讲座 |
| 人际支持 | 同伴影响 | 减重互助小组、家庭一起改 |
| 环境改变 | 让健康选择更容易 | 食堂减盐减油、便利店显眼处放水果、增加运动场地 |
| 政策/制度 | 制度化约束与激励 | 企业健康餐标准、学校限制含糖饮料、菜单标注热量 |

> 💡 最高效的干预往往是"环境+政策"，因为**改变环境比改变意志力可靠**。教育解决"想不想"，环境解决"能不能"。

### 4. "三减三健"专项行动

**背景：** 全民健康生活方式行动的核心载体，2017年《全民健康生活方式行动方案（2017-2025年）》明确提出，后纳入健康中国行动。

| 内容 | 具体 | 科普对应 |
|------|------|---------|
| 三减·减盐 | 成人每日食盐<5g | 少放盐、少吃腌菜、看钠标签 |
| 三减·减油 | 每日烹调油25~30g | 控油壶、少油炸、多用蒸煮 |
| 三减·减糖 | 添加糖<50g，最好<25g | 少喝甜饮料、少点甜食 |
| 三健·健康口腔 | 早晚刷牙、定期口腔检查 | 控糖+口腔卫生 |
| 三健·健康体重 | 吃动平衡，BMI维持18.5~23.9 | 体重管理、腰围管理 |
| 三健·健康骨骼 | 补钙、维生素D、日晒、运动 | 奶类+户外活动 |

**AI营养师可直接对接：**
- 做健康社群活动主题（"减盐周""健康体重日"）
- 企业/学校健康项目按"三减三健"框架设计
- 引用国家行动作为官方背书

### 5. 健康食堂/健康家庭/健康单位标准（方向性要点）

| 场景 | 核心标准要点 |
|------|-------------|
| 健康食堂 | 减盐减油减糖（用控盐勺/控油壶）、菜品多样（每天≥12种）、提供全谷和蔬果、菜单标注、低盐窗口 |
| 健康家庭 | 全家一起改（每人用勺）、购买时看营养标签、零食水果替代加工零食、规律三餐 |
| 健康单位 | 体检+健康档案、食堂健康化、工间操/运动、健康讲座制度化 |
| 健康学校 | 校园周边限售含糖饮料、食堂减糖、体育锻炼达标、健康教育课 |

### 6. 干预效果评估

| 评估层面 | 指标 |
|---------|------|
| 过程评估 | 活动场次、参与人数、材料发放量 |
| 知识态度评估 | 营养知识前后测得分 |
| 行为评估 | 盐/油/糖摄入量、蔬果摄入、运动频次 |
| 生理评估 | 体重、BMI、腰围、血压、血糖、血脂变化 |
| 健康结局 | 慢病发病率/控制率变化（长期） |

## 八、营养标签与宣传规范（GB 28050）

### 1. 背景

**《食品安全国家标准 预包装食品营养标签通则》GB 28050-2011** 是我国预包装食品营养标签的强制国家标准。核心目的：让消费者"看得懂、会挑选"，也是营养科普的"教材"。

### 2. 营养成分表的强制标示（"1+4"）

| 强制标示项 | 说明 |
|-----------|------|
| 能量 | 千焦（kJ） |
| 蛋白质 | 克（g） |
| 脂肪 | 克（g） |
| 碳水化合物 | 克（g） |
| 钠 | 毫克（mg） |

**格式：** 每100g（或100ml）含量 + 每份含量 + NRV%列。

### 3. NRV% 是什么

**NRV（营养素参考值）：** 用于食品标签的参考值，中国成人每日膳食营养素摄入参考（NRV表）。

| 核心营养素 | NRV |
|-----------|-----|
| 能量 | 8400 kJ |
| 蛋白质 | 60 g |
| 脂肪 | ≤ 60 g |
| 碳水化合物 | 300 g |
| 钠 | 2000 mg |

**NRV% = 该食品每份含量 ÷ NRV × 100%**

> 💡 教顾客读标签口诀：**"一高两低"——看每100g的NRV%：钠越低越好、脂肪越低越好；要补的（蛋白/钙/膳食纤维）越高越好。NRV%超过20%就算"高"贡献，超过100%就"超额"了。**

### 4. 营养声称与条件（GB 28050 常见含量声称）

| 声称 | 条件（以每100g固体为例，方向性） |
|------|--------------------------------|
| 低脂肪 | 脂肪 ≤ 3g |
| 脱脂 | 脂肪 ≤ 0.5g |
| 无糖 | 糖 ≤ 0.5g |
| 低钠/低盐 | 钠 ≤ 120mg |
| 高蛋白 | 蛋白 ≥ 12g（或≥20% NRV） |
| 高钙 | 钙 ≥ 240mg（或≥30% NRV） |
| 富含膳食纤维 | 膳食纤维 ≥ 6g |
| 低能量 | 能量 ≤ 170kJ/100g |

**比较声称：** "减少糖""降低钠"（比同类产品减少25%以上等）。**功能声称：** 必须符合目录且不夸大（如"膳食纤维有助于维持正常肠道功能"）。

### 5. 豁免标示的情况（简表）

| 豁免情形 | 说明 |
|---------|------|
| 生鲜食品 | 果蔬、肉蛋奶、水产品等 |
| 现制现售 | 现场制作 |
| 包装总表面积≤100cm² | 小包装 |
| 每日食用量≤10g或10ml | 如部分调味料、茶、咖啡 |
| 乙醇含量≥0.5%的饮料酒类 | 酒类 |

### 6. 宣传合规红线（做内容必守）

```
✗ 不说治疗功效：营养素不能"治疗/治愈"任何疾病
✗ 不绝对化：不用"最""第一""根治""纯天然更安全"
✗ 不冒充药品：不能暗示可替代药物（"降糖神药"式话术禁止）
✗ 不虚构数据：引用报告/研究必须真实可查
✗ 营养声称要有依据：不能用"高钙"宣称"强骨防骨折"
✓ 守法规边界："保健食品"（注册批文）声称须在其批准功能范围内
```

> 📌 特别提醒：在"保健食品"与"普通食品"之间要区分清楚。只有取得注册/备案批文的"保健食品"才能在限定功能范围内做功能声称；普通食品和营养素补充剂不能做疗效宣传。
