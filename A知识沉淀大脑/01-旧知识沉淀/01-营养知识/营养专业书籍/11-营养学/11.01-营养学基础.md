# 11.01 · 营养学基础

> **一句话定位：** 整个营养学的"内功心法"——宏量营养素、微量营养素、能量代谢、消化吸收。给顾客讲一切营养方案，底子都在这里。

## 一、宏量营养素

### 1.1 碳水化合物

#### 1.1.1 碳水化合物的定义与分类

碳水化合物（Carbohydrate）是人体最主要的能量来源，由碳、氢、氧三种元素构成，因氢氧比例为2:1（似水）而得名。中国居民膳食中，约50%~65%的能量来自碳水化合物。

**按聚合度分类：**

| 大类 | 亚类 | 成员 | 消化吸收特点 |
|------|------|------|-------------|
| **单糖** | 己糖 | 葡萄糖、果糖、半乳糖 | 直接吸收，升糖最快 |
| | 戊糖 | 核糖、脱氧核糖 | 参与核酸组成 |
| **双糖** | — | 蔗糖（葡萄糖+果糖）、乳糖（葡萄糖+半乳糖）、麦芽糖（葡萄糖+葡萄糖） | 需刷状缘酶水解为单糖 |
| **寡糖** | — | 低聚果糖（FOS）、低聚半乳糖（GOS）、棉子糖、水苏糖 | 人体难消化，为益生元 |
| **多糖** | 淀粉 | 直链淀粉、支链淀粉 | 缓慢水解，升糖较缓 |
| | 非淀粉多糖 | 膳食纤维（纤维素、半纤维素、果胶等） | 不可消化，促肠健康 |
| | 糖原 | 动物淀粉（肝糖原/肌糖原） | 体内储存形式，不在食物 |

**按消化吸收性质分类（实用角度）：**

| 类型 | 例子 | 特点 |
|------|------|------|
| 可消化利用的碳水 | 葡萄糖、蔗糖、淀粉、糖原 | 提供能量 |
| 不可消化的碳水（膳食纤维） | 纤维素、果胶、低聚果糖 | 不供能，但促肠健康 |

#### 1.1.2 碳水化合物的生理功能

| 功能 | 说明 |
|------|------|
| **主要供能** | 1g碳水供能4 kcal；大脑几乎只能利用葡萄糖供能 |
| **节约蛋白质** | 碳水充足时，蛋白质不被拆去供能，用于构成与修复 |
| **抗生酮作用** | 脂肪分解需要碳水代谢产物（草酰乙酸）配合，碳水不足→酮体生成过多 |
| **构成组织** | 糖蛋白、糖脂是细胞膜与结缔组织成分；参与核酸合成 |
| **膳食纤维作用** | 促排便、降胆固醇（可溶性纤维）、稳血糖、益生元（喂养有益菌） |

**碳水不足的后果：** 头晕乏力、注意力下降、代谢率下降（身体"节能"）、肌肉流失、饥饿感增强（减脂期尤其注意）。

**碳水过量的后果：** 多余碳水转化为脂肪储存→体重增加；精制碳水（高GI）过量→血糖波动大、胰岛素分泌增加→长期增加2型糖尿病与代谢综合征风险。

#### 1.1.3 血糖指数（GI）

**GI（Glycemic Index）定义：** 含50g可利用碳水化合物的食物，餐后2小时血糖升高曲线下的面积，相对于含等量碳水的葡萄糖（或白面包）的比值百分比。

| 等级 | 范围 | 例子 |
|------|------|------|
| **低GI** | <55 | 全麦、燕麦、豆类、苹果、梨、牛奶、坚果 |
| **中GI** | 55~70 | 糙米、香蕉、菠萝、甜玉米 |
| **高GI** | >70 | 白面包、白米饭、馒头、西瓜、葡萄糖 |

**影响GI的因素：**

| 因素 | 影响 |
|------|------|
| 食物加工程度 | 精加工越细，GI越高（全麦<白面） |
| 烹调方式 | 糊化程度越高，GI越高（粥>干饭） |
| 膳食纤维含量 | 纤维越多，GI越低 |
| 蛋白质/脂肪含量 | 与主食同吃，延缓胃排空，降低GI |
| 直链/支链淀粉比例 | 直链多，GI低（冷饭/寿司米） |
| 酸度 | 醋酸等降低GI（拌醋的凉拌菜） |

> **临床意义：** 糖尿病、胰岛素抵抗、减脂人群优先选择低GI主食。但GI只反映"升糖速度"，不反映"吃多少"，因此需要GL配合。

#### 1.1.4 血糖负荷（GL）与计算实例

**GL（Glycemic Load）定义：** 综合"升糖速度"与"实际摄入量"的指标。

```
GL = GI × 食物中碳水化合物克数 ÷ 100
```

| 等级 | 范围 |
|------|------|
| 低GL | <10 |
| 中GL | 10~20 |
| 高GL | >20 |

**计算实例：**

| 食物 | GI | 一份重量 | 该份碳水含量 | GL计算 | GL | 等级 |
|------|----|---------|-------------|--------|----|------|
| 白米饭（熟） | 83 | 200g（一碗） | 约50g | 83×50÷100 | 41.5 | 高 |
| 西瓜 | 72 | 200g（两片） | 约22g | 72×22÷100 | 15.8 | 中 |
| 苹果 | 36 | 200g（一个） | 约25g | 36×25÷100 | 9.0 | 低 |
| 全麦面包 | 69 | 100g（约2片） | 约40g | 69×40÷100 | 27.6 | 高（但优于白面包同量） |

**从实例得出的规律：**
1. 白米饭GI高、一份又含大量碳水，GL必然高——所以"少吃几口"和"换粗粮"同样重要。
2. 西瓜GI高但含水量大、每份碳水不算多，GL中等——适量吃不必恐慌。
3. 苹果GI、GL都低，是"能啃不喝"的典型代表。

> **应用：** 控糖/减脂选"低GI＋低GL"双低组合；用GL更贴近"实际吃了多少"。

#### 1.1.5 膳食纤维

**定义：** 植物性食物中不能被人体消化酶分解的多糖及木质素。中国成人推荐 **25~30g/d**（PI-NCD），而国人实际摄入普遍偏低（约10~15g/d）。

**分类与作用：**

| 类型 | 代表 | 主要作用 |
|------|------|---------|
| **可溶性纤维** | 果胶、β-葡聚糖（燕麦）、菊粉、低聚果糖 | 吸水成胶→延缓胃排空稳血糖、结合胆汁酸降胆固醇、益生元 |
| **不可溶性纤维** | 纤维素、半纤维素、木质素 | 增加粪便体积、促进肠道蠕动防便秘 |

**食物来源（每100g可食部约含）：**

| 食物 | 膳食纤维含量 | 说明 |
|------|-------------|------|
| 燕麦片 | 约6~10g | 富含β-葡聚糖 |
| 黑豆/红豆 | 约10~15g | 高纤维杂豆 |
| 蔬菜（芹菜/菠菜） | 约2~3g | 每天一斤菜，纤维可观 |
| 苹果（带皮） | 约2.4g | 果胶在皮与果肉 |
| 全麦面包 | 约6g | 比白面包（约2g）高很多 |
| 魔芋 | 约30~40g（葡甘聚糖） | 极高纤维但需注意加工品含糖 |

**膳食纤维过量的注意：** 突然大量摄入→腹胀、产气、腹泻；摄入过多（如>60g/d）可干扰钙、铁、锌等矿物质吸收；便秘者应同时多饮水。

#### 1.1.6 隐形糖与添加糖

**添加糖（Added Sugar）：** 人工添加到食品中的糖类，包括蔗糖、果葡糖浆、蜂蜜、糖浆等。**中国居民膳食指南建议：添加糖每天摄入<50g，最好控制在25g以下。** 含糖饮料是最大的添加糖来源。

**常见"隐形糖"盘点（每份约含糖）：**

| 食物/饮品 | 规格 | 约含糖 | 相当于方糖（4.5g/块） |
|----------|------|--------|---------------------|
| 可乐 | 500ml | 约53g | 约12块 |
| 果汁饮料 | 500ml | 约40~60g | 9~13块 |
| 甜味奶茶 | 500ml（全糖） | 约50~70g | 11~16块 |
| 风味酸奶 | 200g | 约15~20g | 3~4块 |
| 番茄酱 | 1汤匙(15g) | 约4g | 约1块 |
| 即食麦片（加糖） | 100g | 约20~30g | 4~7块 |

**识别隐形糖的技巧：**
1. **看配料表：** 白砂糖、蔗糖、果葡糖浆、玉米糖浆、麦芽糖浆、蜂蜜、浓缩果汁都是"糖"。
2. **看营养成分表：** "碳水化合物-糖"项目反映含糖量。
3. **警惕"无蔗糖"≠无糖：** 可能含果葡糖浆、麦芽糖。

#### 1.1.7 碳水推荐量与临床意义

| 人群 | 碳水供能比 | 备注 |
|------|-----------|------|
| 一般成人 | 50%~65%（AMDR） | 以复合碳水为主 |
| 糖尿病患者 | 供能比个体化（通常40%~60%），强调低GI/低GL | 定时定量，与药物配合 |
| 减脂人群 | 可适度下调（如45%~50%），不宜长期极低碳 | 避免肌肉流失与反弹 |
| 老年人 | 保证主食，粗细搭配 | 防消瘦，注意食物软硬 |

**临床意义要点：**
- 全谷物/杂豆/薯类替代部分精白米面，是国人最易执行的膳食优化之一。
- 长期极低碳水（生酮）需在专业指导下进行，不适合普通人群与肝肾功能异常者。
- 每餐"一拳主食"（约生重75~100g谷类）是直观的份量参考。

### 1.2 蛋白质

#### 1.2.1 蛋白质的构成——氨基酸

蛋白质由20种氨基酸（Amino Acid）通过肽键连接而成。氨基酸按人体需要来源分为三大类：

| 分类 | 定义 | 成员 |
|------|------|------|
| **必需氨基酸（EAA）** | 人体不能合成或合成量不足，必须从食物获得 | 9种（见下） |
| **条件必需氨基酸** | 正常可合成，但在某些生理/病理状态下合成不足需外源补充 | 精氨酸、谷氨酰胺、酪氨酸、半胱氨酸、脯氨酸、甘氨酸等 |
| **非必需氨基酸** | 人体可自身合成，不需从食物获得 | 丙氨酸、天冬氨酸、谷氨酸等 |

#### 1.2.2 必需氨基酸（9种）

记忆口诀：**"苏赖色缬蛋苯亮异组"**（或"携一本亮色书来煮鸡蛋"式谐音记忆）。

| 序号 | 必需氨基酸 | 主要生理功能 | 典型缺乏表现（整体性缺乏时） |
|------|-----------|-------------|------------------------------|
| 1 | **亮氨酸** Leucine | 蛋白质合成"扳机"、肌肉合成 | 肌肉流失、伤口愈合差 |
| 2 | **异亮氨酸** Isoleucine | 与亮/缬共为支链氨基酸（BCAA），供能、修复 | 疲劳、肌肉分解 |
| 3 | **缬氨酸** Valine | 支链氨基酸，神经与能量 | 神经肌肉协调差 |
| 4 | **赖氨酸** Lysine | 赖氨酸参与胶原与肉碱合成 | 儿童生长迟缓、食欲差 |
| 5 | **蛋氨酸** Methionine | 甲基供体、含硫氨基酸 | 脂肪肝倾向、解毒功能下降 |
| 6 | **苯丙氨酸** Phenylalanine | 酪氨酸前体（→儿茶酚胺） | 神经递质合成减少 |
| 7 | **苏氨酸** Threonine | 胶原、免疫球蛋白成分 | 免疫低下 |
| 8 | **色氨酸** Tryptophan | 5-羟色胺（血清素）前体 | 情绪低落、睡眠差 |
| 9 | **组氨酸** Histidine | 组胺前体、血红蛋白 | 婴幼儿必需性强，成人合成量低 |

> **临床意义：** 支链氨基酸（BCAA：亮/异亮/缬）在运动营养、肝病营养中常用；色氨酸涉及情绪与睡眠；谷类蛋白缺乏赖氨酸、豆类蛋白缺乏蛋氨酸——这是"蛋白质互补"的分子基础。

#### 1.2.3 条件必需氨基酸

| 氨基酸 | 条件性缺乏的典型情境 | 临床用途 |
|--------|---------------------|---------|
| 精氨酸 | 创伤、感染、烧伤 | 免疫营养、伤口愈合 |
| 谷氨酰胺 | 危重症、化疗、肠黏膜受损 | 保护肠黏膜屏障、免疫支持 |
| 酪氨酸 | 苯丙酮尿症（苯丙氨酸不能转化） | 特殊配方 |
| 半胱氨酸 | 肝病、低蛋白 | 抗氧化（谷胱甘肽前体） |
| 脯氨酸/甘氨酸 | 胶原合成增加时 | 结缔组织修复 |

#### 1.2.4 蛋白质的生理功能

| 功能 | 说明 | 例子 |
|------|------|------|
| **构成与修复组织** | 蛋白质是肌肉、内脏、皮肤、毛发的主要结构物质 | 肌肉蛋白、胶原蛋白、角蛋白 |
| **构成功能物质** | 酶、抗体、部分激素、转运蛋白 | 消化酶、免疫球蛋白、白蛋白、胰岛素 |
| **调节生理** | 维持血浆渗透压与酸碱平衡 | 白蛋白维持胶体渗透压 |
| **供能** | 1g蛋白供能4 kcal（正常供能占比不高） | 长期饥饿时才大量分解供能 |
| **免疫** | 抗体与免疫细胞增殖都需要蛋白 | 免疫球蛋白 |
| **转运** | 转运营养素与代谢废物 | 载脂蛋白、转铁蛋白 |

#### 1.2.5 蛋白质质量评价（三大指标）

评价蛋白质优劣的三个核心指标：

**① 氨基酸模式（Amino Acid Pattern）：**
- 食物蛋白氨基酸构成与人体需要的必需氨基酸模式越接近，利用率越高。
- "参考蛋白"：鸡蛋蛋白（氨基酸模式最接近人体）。

**② 生物价（BV，Biological Value）：**

```
BV = 体内保留氮 ÷ 体内吸收氮 × 100
```

反映蛋白质被机体利用的效率。**分数越高，利用率越高。**

| 食物蛋白 | 生物价（参考值） |
|---------|----------------|
| 鸡蛋 | 100（参考标准） |
| 牛奶 | 91 |
| 鱼 | 76 |
| 牛肉 | 74~80 |
| 大豆 | 74 |
| 大米 | 64 |
| 小麦（面筋） | 54~67 |
| 玉米 | 60 |

**③ PDCAAS（蛋白质消化率校正氨基酸评分）：**

```
PDCAAS = 氨基酸评分（第一限制氨基酸）× 蛋白质真消化率
```

是国际通用的蛋白质质量评价标准（FAO/WHO推荐）。**满分为1.0。**

| 蛋白质来源 | PDCAAS（参考值） | 说明 |
|-----------|----------------|------|
| 鸡蛋蛋白 | 1.00 | 金标准 |
| 牛奶（酪蛋白/乳清） | 1.00 | 满分 |
| 大豆分离蛋白 | 0.91~1.00 | 植物蛋白中顶级 |
| 牛肉 | 0.92 | 动物蛋白优秀 |
| 豌豆蛋白 | 0.69 | 植物蛋白中等 |
| 小麦蛋白 | 0.40~0.50 | 第一限制氨基酸为赖氨酸 |

> **实用结论：** "鸡蛋、牛奶、大豆"是蛋白质质量的三个满分代表。给顾客讲"优质蛋白"，首选这三类，再推鱼、禽、瘦畜肉。

#### 1.2.6 限制氨基酸与蛋白质互补

**限制氨基酸（Limiting Amino Acid）：** 食物蛋白中相对含量不足、限制了整蛋白利用率的必需氨基酸，称第一限制氨基酸（其次第二、第三……）。

| 食物蛋白 | 第一限制氨基酸 |
|---------|---------------|
| 谷类（小麦、大米） | 赖氨酸 |
| 豆类（大豆） | 蛋氨酸（甲硫氨酸） |
| 玉米 | 赖氨酸、色氨酸 |
| 花生 | 蛋氨酸 |

**蛋白质互补原理：** 把不同蛋白搭配，使"你缺的我补"，整体氨基酸模式趋于平衡，利用率提高。

| 经典互补搭配 | 原理 | 一句话话术 |
|-------------|------|-----------|
| 米饭＋豆类（米豆搭配） | 谷缺赖氨酸、豆富赖氨酸；豆缺蛋氨酸、谷富蛋氨酸 | "米饭配豆，营养翻倍" |
| 面粉＋大豆 | 面筋缺赖氨酸，大豆补上 | "馒头配豆浆/豆包" |
| 谷类＋奶/蛋 | 动物蛋白补齐植物蛋白短板 | "燕麦配牛奶，早餐金牌组合" |
| 坚果＋全谷物 | 氨基酸互补 | "杂粮坚果粥" |

> **应用：** 素食者、经济型膳食尤其要讲蛋白质互补；"蛋奶素"比"纯素"更容易满足优质蛋白需求。

#### 1.2.7 氮平衡（Nitrogen Balance）

蛋白质含氮约16%，蛋白质代谢状况可用氮平衡反映：

```
氮平衡 = 摄入氮（食物蛋白） − 排出氮（尿+粪+皮肤等）
```

| 状态 | 含义 | 常见情境 |
|------|------|---------|
| **零氮平衡** | 摄入=排出 | 健康成人维持体重 |
| **正氮平衡** | 摄入>排出 | 儿童青少年生长、孕妇、恢复期、增肌 |
| **负氮平衡** | 摄入<排出 | 节食/饥饿、感染、创伤、消耗性疾病、老年人衰弱 |

> **临床意义：** 住院病人、术后、慢消耗患者要"防负氮平衡"——保证能量前提下给足蛋白质；这是临床营养（11.06）的基础逻辑之一。

#### 1.2.8 蛋白质推荐量（分级）

| 人群 | 推荐量 | 说明 |
|------|--------|------|
| 一般成人 | 0.8~1.0 g/(kg·d)（中国RNI：男65g/d、女55g/d） | 以标准体重估算 |
| 老年人 | 1.0~1.2 g/(kg·d)，优质蛋白占一半以上 | 防肌肉衰减（少肌症） |
| 孕中晚期/哺乳期 | 孕中期+15g/d、孕晚期+30g/d、哺乳期+25g/d（在RNI基础上） | 胎儿与泌乳需要 |
| 运动/增肌人群 | 1.2~1.7 g/(kg·d) | 按运动强度个体化 |
| 慢性病患者（伤口/感染/术后） | 1.0~1.5 g/(kg·d)（个体化） | 促修复 |
| 慢性肾病未透析 | 0.6~0.8 g/(kg·d)，优质蛋白为主（**遵医嘱**） | 减轻肾脏负担 |

> **"沙子"提示（真实感）：** 蛋白质不是越多越好——过量增加肝肾负担；肾病患者必须遵医嘱限蛋白。给任何顾客建议"多吃蛋白"之前，先问一句"有没有肾脏问题"。

#### 1.2.9 蛋白质缺乏与过量

| 状态 | 表现 | 高危人群 |
|------|------|---------|
| **蛋白质-能量营养不良（PEM）** | 消瘦型（皮下脂肪消失、肌肉萎缩）、水肿型（水肿、肝大、皮肤改变） | 贫困儿童、老年衰弱、慢性消耗 |
| **蛋白质轻度缺乏** | 头发干枯、指甲脆、伤口愈合慢、免疫力下降、下肢水肿（白蛋白低） | 节食、挑食、纯素食规划不当 |
| **过量** | 肝肾负担、脱钙倾向（高蛋白尿钙）、加重肾病 | 盲目高蛋白饮食者 |

### 1.3 脂肪

#### 1.3.1 脂肪的分类（按结构）

| 大类 | 说明 |
|------|------|
| **甘油三酯** | 脂肪的主要储存形式（1甘油+3脂肪酸），食物中占绝大部分 |
| **磷脂** | 细胞膜主要成分，含磷，卵磷脂/脑磷脂 |
| **固醇** | 胆固醇、植物固醇；胆固醇是细胞膜与激素前体 |
| **游离脂肪酸** | 水解后的脂肪酸 |

#### 1.3.2 脂肪酸分类表（按饱和程度）

| 类型 | 化学特点 | 代表 | 健康评价 |
|------|---------|------|---------|
| **饱和脂肪酸 SFA** | 无双键，室温固态 | 动物脂肪（猪油、黄油）、椰子油、棕榈油 | 过量升高LDL（坏胆固醇） |
| **单不饱和脂肪酸 MUFA** | 1个双键 | 橄榄油、菜籽油、牛油果、花生油 | 中性偏保护（升HDL趋势） |
| **多不饱和脂肪酸 PUFA** | ≥2个双键 | 植物油、鱼油 | 必需脂肪酸来源 |
| └ n-6系 | 第一个双键在第6位 | 大豆油、玉米油、葵花籽油 | 必需（亚油酸），过量促炎 |
| └ n-3系 | 第一个双键在第3位 | 亚麻籽油、鱼油（EPA/DHA）、核桃 | 必需（α-亚麻酸），抗炎核心 |
| **反式脂肪酸 TFA** | 双键为反式构型 | 氢化植物油、植脂末、起酥油、部分油炸食品 | **最有害**：升LDL降HDL |

**常见食用油脂肪酸构成（参考）：**

| 油脂 | SFA% | MUFA% | PUFA% | 特点 |
|------|------|-------|-------|------|
| 橄榄油 | 14 | 73 | 11 | MUFA高，耐煎炸中等 |
| 菜籽油 | 7 | 63 | 28 | MUFA高，性价比高 |
| 花生油 | 17 | 46 | 32 | 中式炒菜常用 |
| 大豆油 | 15 | 23 | 58 | n-6较高，油炸易氧化 |
| 亚麻籽油 | 9 | 16 | 68（α-亚麻酸为主） | 富含n-3，不耐热 |
| 椰子油 | 91 | 6 | 2 | SFA极高，不宜当日常主油 |
| 猪油 | 41 | 47 | 11 | SFA高，偶尔使用 |

> **应用：** 家庭用油建议"炒菜用菜籽油/花生油，凉拌用橄榄油/亚麻籽油，轮流换着吃"。

#### 1.3.3 必需脂肪酸（EFA）

人体不能合成的两种多不饱和脂肪酸，必须由食物供给：

| 必需脂肪酸 | 类别 | 食物来源 | 功能 |
|-----------|------|---------|------|
| **亚油酸** Linoleic Acid | n-6 | 大豆油、玉米油、葵花籽油、坚果 | 细胞膜成分、前列腺素前体 |
| **α-亚麻酸** α-Linolenic Acid | n-3 | 亚麻籽油、核桃、奇亚籽 | 可部分转化为EPA/DHA（转化率低） |

**长链n-3（EPA/DHA）：**
- **来源：** 深海鱼（三文鱼、沙丁鱼、鲭鱼）、藻油、鱼油。
- **功能：** 抗炎、降甘油三酯、护心、促进胎儿/婴幼儿神经系统发育、有助认知健康。
- **推荐：** 每周吃鱼2次（其中1次为深海鱼）是DGA与膳食指南共识；孕妇乳母尤其关注DHA。

**必需脂肪酸缺乏表现：** 皮肤干燥脱屑、伤口愈合差、生长发育迟缓、生殖功能下降、智力发育受损（婴幼儿）。

> **临床意义：** 国人n-6摄入普遍偏高、n-3偏低（n-6:n-3比例失衡），增加深海鱼/亚麻籽/核桃是性价比最高的"调油"动作。

#### 1.3.4 反式脂肪（TFA）

**来源：**
1. **工业氢化植物油：** 植脂末（奶茶/咖啡伴侣）、起酥油（面包/蛋糕/饼干）、人造黄油、部分油炸食品。
2. **天然反式：** 反刍动物奶肉中微量（含量低，不必恐慌）。

**危害：** 升高LDL（坏胆固醇）、降低HDL（好胆固醇）、促炎、增加心血管疾病风险。**WHO建议反式脂肪供能<1%，越少越好。**

**识别技巧：** 看配料表出现"氢化植物油、人造奶油、植脂末、起酥油、代可可脂"等字样要警惕；营养成分表"反式脂肪酸"项>0.3g/100g标注。

#### 1.3.5 胆固醇的现状（2023后）

| 认识阶段 | 观点 |
|---------|------|
| 过去（≤2015前后） | 严格限制每日膳食胆固醇（<300mg/d） |
| 现在（2020s） | **膳食胆固醇与血胆固醇关系被重新评估，不再设置严格限量**；真正该限制的是饱和脂肪与反式脂肪 |

**当前共识：**
- 人体胆固醇大部分为内源性合成，膳食胆固醇对血胆固醇影响小于饱和脂肪。
- 高胆固醇食物（如蛋黄）不再一刀切禁止：**每天1~2个全蛋对绝大多数人安全**。
- 但**高胆固醇＋高饱和脂肪**的食物（如肥肉、加工肉类）仍需控制。
- 血脂异常患者仍需个体化限量（遵医嘱）。

**常见食物胆固醇含量（参考，mg/100g可食部）：**

| 食物 | 胆固醇 | 食物 | 胆固醇 |
|------|--------|------|--------|
| 鸡蛋黄 | 约1510 | 猪肝 | 约288 |
| 鸡蛋（全） | 约585（1个约186） | 鱿鱼 | 约268 |
| 虾 | 约193 | 瘦猪肉 | 约81 |
| 带鱼 | 约76 | 牛奶 | 约15 |

#### 1.3.6 脂肪的生理功能

| 功能 | 说明 |
|------|------|
| **供能储能** | 1g脂肪供能9 kcal；甘油三酯是体内最浓缩的储能形式 |
| **构成细胞膜** | 磷脂与胆固醇是细胞膜结构成分 |
| **合成激素** | 胆固醇是性激素、皮质醇、维生素D的前体 |
| **脂溶性维生素载体** | 帮助A/D/E/K的吸收（过少油脂→脂溶性维生素吸收不良） |
| **保温与缓冲** | 皮下脂肪保温、内脏脂肪缓冲保护 |
| **必需脂肪酸供给** | 亚油酸/α-亚麻酸 |
| **饱腹与风味** | 脂肪延长胃排空、带来口感 |

#### 1.3.7 脂肪推荐量

| 人群 | 脂肪供能比（AMDR） | 细分建议 |
|------|-------------------|---------|
| 一般成人 | 20%~30% | 烹调油25~30g/d；饱和脂肪<10%供能 |
| 高血脂/心血管风险 | 20%~30%，结构更严格 | 饱和脂肪<7%供能、反式脂肪越少越好 |
| 儿童青少年 | 25%~30% | 保证必需脂肪酸与脂溶性维生素 |
| 减脂人群 | 20%~25%（个体化） | 不宜过低，保证必需脂肪酸 |

**用油量直观参考：** 每人每天烹调油25~30g ≈ 白瓷勺2.5~3勺。**"控油"三招：** 多用蒸煮炖拌、少油炸；家庭分餐用勺计量；警惕"隐形油"（糕点、饼干、方便面、辣条）。

## 二、微量营养素

### 2.1 维生素总览（脂溶性 vs 水溶性）

| 特性 | 脂溶性（A/D/E/K） | 水溶性（B族+C） |
|------|------------------|----------------|
| 溶解性 | 溶于脂肪与有机溶剂 | 溶于水 |
| 吸收 | 需脂肪与胆汁参与 | 直接吸收 |
| 储存 | 可储存在肝脏与脂肪，不易缺乏 | 储存少，需每日补充 |
| 排泄 | 不随尿排出，**过量蓄积中毒** | 过量多随尿排出，毒性较低 |
| 缺乏速度 | 缺乏出现较慢 | 缺乏出现较快 |
| 过量风险 | **高（A/D尤其）** | 低（B6/B3超量仍有害） |
| 食物来源 | 含脂食物（动物油、内脏、蛋黄、坚果） | 广泛（谷物、肉、蔬果） |

### 2.2 脂溶性维生素

#### 2.2.1 维生素A

**结构：** 视黄醇/视黄醛/视黄酸；前体为β-胡萝卜素（可在体内转化）。

| 维度 | 内容 |
|------|------|
| **主要功能** | ①视觉：构成视紫红质，维持暗视觉；②上皮组织完整：维护皮肤、黏膜；③免疫：维持黏膜屏障与免疫细胞；④生长发育；⑤抗氧化（β-胡萝卜素） |
| **缺乏表现** | 夜盲症（暗适应差）→干眼症（角膜干燥）→角膜软化；皮肤干燥、毛囊角化（"鸡皮"）；呼吸道/肠道感染风险升高；儿童生长发育迟缓 |
| **过量表现** | 急性：头痛、恶心、呕吐、嗜睡；慢性：肝损伤、骨痛、皮肤干燥脱屑、脱发；孕妇过量致胎儿畸形（致畸） |
| **食物来源** | 动物性（直接VA）：肝脏、蛋黄、鱼肝油、奶油；植物性（β-胡萝卜素）：胡萝卜、南瓜、红薯、菠菜、芒果、柑橘 |
| **参考摄入量** | RNI：成年男性800μgRAE/d、女性700μgRAE/d；UL 3000μgRAE/d |
| **临床注意** | 孕妇勿超量补充；长期饮酒者肝损伤风险叠加；β-胡萝卜素在体内按需转化，过量风险低于直接VA |
| **营养应用** | 夜盲/干眼高危人群（儿童、素食者、肝胆疾病患者）注意摄入；深色蔬果是安全的胡萝卜素来源 |

#### 2.2.2 维生素D

**别称：** 钙化醇；人体可由皮肤经日光（UVB）合成，故有"阳光维生素"之称。

| 维度 | 内容 |
|------|------|
| **主要功能** | ①促进肠道钙磷吸收；②骨骼矿化与重塑；③免疫调节；④细胞分化；⑤肌肉功能 |
| **缺乏表现** | 儿童：佝偻病（O型腿、方颅、串珠肋）；成人：骨软化症（骨痛、肌无力）、骨质疏松；免疫力下降；跌倒风险增加（肌力下降） |
| **过量表现** | 高钙血症（恶心、呕吐、乏力、多尿）、肾钙化、血管钙化；UL 50μg/d（2000IU） |
| **食物来源** | 食物来源有限：深海鱼（三文鱼、沙丁鱼）、蛋黄、鱼肝油、强化奶；**主要靠日晒**（面部+手臂晒15~30分钟/天，避开正午暴晒） |
| **参考摄入量** | RNI：成人10μg/d（400IU）、65岁以上15μg/d（600IU）；UL 50μg/d（2000IU） |
| **临床注意** | 室内工作者、北方冬季、老年、肥胖者缺乏率高；肝肾功能不全影响活化；补钙不同步补D效果打折 |
| **营养应用** | "晒太阳+吃鱼+必要时遵医嘱补D"三管齐下；骨质疏松防治中D与钙同等重要 |

#### 2.2.3 维生素E

**别称：** 生育酚（α-生育酚为活性最强形式）。

| 维度 | 内容 |
|------|------|
| **主要功能** | ①抗氧化：保护细胞膜多不饱和脂肪酸免受氧化；②保护红细胞；③与硒协同抗氧化；④免疫调节 |
| **缺乏表现** | 罕见（需长期极低脂/吸收障碍）；溶血性贫血（早产儿）、脊髓小脑变性、周围神经病变、肌病 |
| **过量表现** | 大剂量：出血倾向（抑制血小板聚集、拮抗维生素K）；UL 700mg α-TE/d |
| **食物来源** | 植物油、坚果（杏仁、核桃）、种子、麦胚、绿叶蔬菜 |
| **参考摄入量** | AI：成人14mg α-TE/d |
| **临床注意** | 服用抗凝药（华法林）者避免大剂量补充；补充剂远超AI无额外好处 |
| **营养应用** | 坚果控量（一小把约25~30g/d）即满足；富含E的植物油凉拌更好 |

#### 2.2.4 维生素K

**成员：** 叶绿醌（K1，植物）、甲萘醌（K2，肠道菌群/发酵食品）。

| 维度 | 内容 |
|------|------|
| **主要功能** | ①凝血：参与凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ的γ-羧化；②骨健康：激活骨钙素，帮助钙沉积骨骼；③血管钙化抑制（K2） |
| **缺乏表现** | 出血倾向（皮肤瘀斑、牙龈出血、伤口渗血）；新生儿出血症；骨矿化异常；长期抗生素/吸收不良者风险升高 |
| **过量表现** | 天然K1/K2毒性极低，无明显UL；人工合成K3大剂量可致溶血与黄疸 |
| **食物来源** | 绿叶蔬菜（菠菜、西兰花、羽衣甘蓝）、纳豆（K2丰富）、发酵食品、肠道菌群合成 |
| **参考摄入量** | AI：成人80μg/d（男120/女90为部分国际标准，中国2023按AI 80μg） |
| **临床注意** | 服用华法林者需保持K摄入稳定（避免忽多忽少）；新生儿出生常规注射维生素K预防出血 |
| **营养应用** | 讲"钙要进骨头，离不开D和K"：D负责吸收，K负责定向沉积骨骼 |

### 2.3 水溶性维生素

#### 2.3.1 维生素B1（硫胺素）

| 维度 | 内容 |
|------|------|
| **主要功能** | ①糖代谢关键辅酶（TPP：丙酮酸脱氢酶、α-酮戊二酸脱氢酶）；②神经传导（乙酰胆碱合成）；③心脏功能支持 |
| **缺乏表现** | 干性脚气病（周围神经炎、感觉异常）；湿性脚气病（心衰、水肿）；Wernicke脑病（酒精相关，眼球震颤、共济失调、意识障碍）；食欲差、乏力 |
| **过量表现** | 水溶性，口服毒性极低（无明确UL） |
| **食物来源** | 全谷物、瘦肉、豆类、酵母、坚果、动物内脏 |
| **参考摄入量** | RNI：男1.4mg/d、女1.2mg/d |
| **临床注意** | 精白米面为主者（B1大量损失于谷皮）、酒精依赖者、高糖高能量饮食者风险高；B1需求随碳水摄入增加 |
| **营养应用** | "粗细搭配"不仅为纤维，也为B1；解酒人群注意B1补充（但喝酒本身伤身） |

#### 2.3.2 维生素B2（核黄素）

| 维度 | 内容 |
|------|------|
| **主要功能** | ①能量代谢辅酶（FAD/FMN：参与糖、脂、蛋白代谢）；②抗氧化（谷胱甘肽还原酶）；③维护皮肤黏膜 |
| **缺乏表现** | 口角炎（口角糜烂）、唇炎、舌炎（舌红痛）、阴囊/会阴皮炎、脂溢性皮炎、角膜血管增生 |

#### 2.3.3 维生素B3（烟酸/烟酰胺）

| 维度 | 内容 |
|------|------|
| **主要功能** | ①NAD/NADP辅酶（参与300+氧化还原反应）；②DNA修复；③皮肤健康；④大剂量烟酸降甘油三酯/LDL（医疗用途） |
| **缺乏表现** | 糙皮病（3D：皮炎、腹泻、痴呆）；皮肤对称性光敏性红斑（"佩拉格拉"）；舌炎、口炎 |
| **过量表现** | 皮肤潮红、瘙痒（烟酸扩张血管）；肝损伤（缓释剂型）；升高尿酸；UL 35mg/d |
| **食物来源** | 肉类、鱼类、全谷物、花生、豆类；**色氨酸可内源转化**（牛奶、蛋含色氨酸） |
| **参考摄入量** | RNI：男15mgNE/d、女12mgNE/d（NE=烟酸当量） |
| **临床注意** | 玉米为主食且未经碱处理地区历史上糙皮病高发；大剂量烟酸属医疗行为，勿自行补充 |
| **营养应用** | "肉蛋鱼谷吃得够，烟酸一般不缺"；向顾客科普不夸大烟酸降脂作用 |

#### 2.3.4 维生素B5（泛酸）

| **缺乏表现** | 罕见（泛酸=广泛存在）；"烧灼足综合征"（足底烧灼痛）、疲劳、失眠、胃肠不适 |

| **营养应用** | 很少单独讲B5，归入"B族协同"讲即可 |

#### 2.3.5 维生素B6（吡哆醇）

#### 2.3.6 维生素B7（生物素）

#### 2.3.7 维生素B9（叶酸）

| **主要功能** | ①一碳单位转移：DNA/RNA合成；②红细胞生成；③同型半胱氨酸代谢（→蛋氨酸）；④胎儿神经管发育 |
| **缺乏表现** | 巨幼细胞性贫血；胎儿神经管缺陷（无脑儿/脊柱裂）；同型半胱氨酸升高（心血管风险因素）；舌炎、腹泻 |
| **过量表现** | 可掩盖B12缺乏的血液学表现（延误诊断）；大剂量合成叶酸与部分肿瘤风险的争议（长期超UL）；UL 1000μgDFE/d |

| **营养应用** | 孕期叶酸是"必讲知识点"；老年人补充叶酸需注意与B12同查 |

#### 2.3.8 维生素B12（钴胺素）

| 维度 | 内容 |
|------|------|
| **主要功能** | ①造血（与叶酸协同合成DNA）；②神经髓鞘形成（甲基丙二酰CoA→琥珀酰CoA）；③同型半胱氨酸代谢 |
| **缺乏表现** | 巨幼细胞性贫血；脊髓亚急性联合变性（麻木、步态不稳）；周围神经炎；高同型半胱氨酸血症；舌炎 |
| **过量表现** | 毒性极低（水溶性，肾脏排泄） |
| **食物来源** | **仅动物性食物**：肉、肝、鱼、蛋、奶；植物性食物不含（发酵食品/强化食品除外） |
| **参考摄入量** | RNI：2.4μg/d（孕期2.6、哺乳期2.8μg/d） |
| **临床注意** | 严格素食者必缺（必须补充）；老年人胃酸/内因子下降→吸收障碍（萎缩性胃炎、胃切除）；长期PPI（抑酸药）影响吸收 |
| **营养应用** | 纯素/老年人群是B12重点宣教对象；"植物里没有B12"是必须讲清的事实 |

#### 2.3.9 维生素C（抗坏血酸）

| 维度 | 内容 |
|------|------|
| **主要功能** | ①抗氧化（清除自由基，再生维生素E）；②胶原蛋白合成（脯氨酸羟化酶辅因子）；③**促进铁吸收**（还原Fe³⁺→Fe²⁺）；④免疫支持；⑤合成神经递质与肉碱；⑥维生素C与血管健康 |
| **缺乏表现** | 坏血病：牙龈肿胀出血、皮下瘀点瘀斑、关节痛、伤口愈合差；疲劳、抵抗力下降 |
| **过量表现** | 腹泻、胃肠不适；大量长期→草酸盐结石风险（敏感者）；UL 2000mg/d |
| **食物来源** | 新鲜蔬果：猕猴桃、鲜枣、沙棘、橙柚、草莓、青椒、西兰花；**烹饪损失大（加热、切后放置）** |
| **参考摄入量** | RNI：100mg/d；吸烟者建议+35mg/d（135mg） |
| **临床注意** | 长期大剂量（>1g/d）突然停用可致"反跳性坏血病"；尿路结石患者慎大剂量 |
| **营养应用** | "果蔬吃到量，维C自然够"；补铁餐搭配维C是"性价比最高"的饮食技巧 |

### 2.4 矿物质——宏量元素

#### 2.4.1 钙（Ca）

| 维度 | 内容 |

#### 2.4.2 镁（Mg）

| 维度 | 内容 |
|------|------|
| **主要功能** | ①300+种酶的辅因子（ATP利用必需）；②神经肌肉传导；③心律稳定；④骨骼成分；⑤血糖/血压调节参与 |
| **缺乏表现** | 肌肉痉挛（抽筋）、失眠/焦虑、心律失常、乏力；低钙低钾血症（伴随）；偏头痛相关（部分证据） |
| **过量表现** | 腹泻（氧化镁）；肾排泄障碍者高镁血症（危险，可致心脏抑制）；补充剂UL 700mg/d |
| **食物来源** | 坚果（杏仁、腰果）、深绿叶菜、豆类、全谷物、海产品、黑巧克力 |
| **参考摄入量** | RNI：男330mg/d、女300mg/d |
| **临床注意** | 国人镁摄入普遍不足（精加工去胚芽）；酒精、利尿剂增加镁丢失；糖尿病/服用质子泵抑制剂者风险高 |
| **营养应用** | "坚果一把+绿叶菜一把"是补镁最实际的方案；抽筋勿只归因缺钙，镁也很关键 |

#### 2.4.3 钾（K）

| 维度 | 内容 |

| **主要功能** | ①细胞内主要阳离子；②心肌与神经肌肉兴奋性；③血压调节（促钠排出、血管舒张）；④酸碱平衡；⑤蛋白质与糖原合成 |

| **过量表现** | 高钾血症（主要见于肾排泄障碍、大量补钾、保钾利尿剂）；可致心搏骤停 |

| **参考摄入量** | AI：2000mg/d；促进血压健康的摄入量更高（PI-NCD倾向富钾膳食） |

#### 2.4.4 钠（Na）

| 维度 | 内容 |
|------|------|
| **主要功能** | ①细胞外主要阳离子；②体液与渗透压平衡；③神经肌肉传导；④酸碱平衡 |

| **过量表现** | 硒中毒：脱发、指甲变形断裂、大蒜样口气、胃肠不适；UL 400μg/d |
| **食物来源** | 巴西坚果（2~3颗即近一天需要）、海产品、动物内脏、肉类、富硒食品 |
| **参考摄入量** | RNI：60μg/d |
| **临床注意** | 湖北恩施等富硒地区土壤硒高；**巴西坚果不可过量吃**（超UL风险）；补硒对肿瘤防治证据不一致，不夸大 |
| **营养应用** | "每天1~2颗巴西坚果补硒"；克山病历史是"微量元素防病"的经典案例 |

#### 2.5.5 铬（Cr）

| 维度 | 内容 |
|------|------|
| **主要功能** | ①增强胰岛素作用（"葡萄糖耐量因子"组分，机制仍有争议）；②糖/脂代谢参与 |
| **缺乏表现** | 罕见（长期肠外营养）：葡萄糖耐量受损、外周神经病变 |
| **过量表现** | 铬中毒（职业暴露）：肾损伤、肝损伤；补剂UL未确定 |
| **食物来源** | 全谷物、肉类、西兰花、啤酒酵母、葡萄 |
| **参考摄入量** | AI：30μg/d |
| **临床注意** | **铬补充剂对糖尿病的效果证据不一致，不夸大、不推荐自行大剂量补充** |
| **营养应用** | 归入"均衡膳食即可"；对糖尿病控糖，重点仍是总能量+低GI |

#### 2.5.6 铜（Cu）

| 维度 | 内容 |
|------|------|
| **主要功能** | ①铁代谢（铜蓝蛋白把Fe²⁺氧化为Fe³⁺，参与转运）；②结缔组织合成（弹性蛋白/胶原交联）；③抗氧化（SOD组分）；④神经髓鞘 |
| **缺乏表现** | 罕见：贫血（对铁剂不敏感）、中性粒细胞减少、骨骼异常、色素减退；Menkes病（遗传性） |
| **过量表现** | 肝损伤、神经毒性（Wilson病——铜沉积肝脑）；UL 8mg/d |
| **食物来源** | 牡蛎、动物肝、坚果、可可、全谷物、豆类 |
| **参考摄入量** | RNI：0.8mg/d |
| **临床注意** | **过量补锌可致铜缺乏**（锌铜竞争吸收）；Wilson病需限铜（遵医嘱） |
| **营养应用** | 正常均衡饮食不易缺铜；与"补锌别过量"的提示结合讲 |

|--------|---------|------|-----------|------|

## 三、水与能量代谢

### 3.1 水

#### 3.1.1 水的生理功能

水是生命活动的基本介质，也是常常被忽视的"宏量营养素"：

| 功能 | 说明 |
|------|------|
| 构成机体 | 成人水占体重约55%~65%，肌肉含水多、脂肪含水少 |
| 参与代谢 | 一切生化反应都在水中进行，水是反应介质与底物 |
| 运输 | 运送氧气、营养素、激素，运出代谢废物 |
| 调节体温 | 出汗散热是主要体温调节方式 |
| 润滑 | 关节液、胸腔/腹腔液、黏液 |
| 缓冲保护 | 脑脊液保护中枢神经 |

#### 3.1.2 需水量与水平衡

| 项目 | 数值 |
|------|------|
| 成人每日饮水建议 | 1500~1700ml（约7~8杯） |
| 每日总水摄入建议（含食物水） | 男约3000ml、女约2700ml（DRIs 2013总水AI） |
| 食物中含水 | 约占每日水的20%~30%（蔬果/汤粥） |
| 代谢水 | 体内氧化产生约300ml/d |

**水的排出去向：** 尿液（约1500ml）＋皮肤蒸发/出汗＋呼吸＋粪便。

#### 3.1.3 缺水与水中毒

| 失水程度 | 表现 |
|---------|------|
| 失水1%~2% | 口渴、尿少 |
| 失水2%~4% | 口干、皮肤干燥、注意力下降 |
| 失水5%~8% | 烦躁、心率加快、血压下降 |
| 失水≥10% | 意识障碍、循环衰竭、休克（危及生命） |

**哪些人易缺水：** 老年人（口渴中枢迟钝）、婴幼儿、发热/腹泻者、高温环境、运动后。

**水中毒（稀释性低钠血症）：** 短时间内大量饮水且肾脏排水受限（肾病患者、心衰者）或大量出汗后只补纯水（丢钠）→头晕、恶心、抽搐。预防：运动后补"水+盐"（电解质）。

### 3.2 能量代谢总览

#### 3.2.1 能量单位与食物能量系数

| 概念 | 数值 |
|------|------|
| 热量单位换算 | 1 kcal = 4.184 kJ |
| 碳水化合物供能系数 | 4 kcal/g |
| 蛋白质供能系数 | 4 kcal/g |
| 脂肪供能系数 | 9 kcal/g |
| 酒精供能系数 | 7 kcal/g |
| 有机酸供能系数 | 约2~3 kcal/g |

> **注意：** 膳食纤维供能约2 kcal/g（部分被肠道菌群利用）；乙醇供能"空能量"（无营养素）。

#### 3.2.2 能量消耗构成

```
总能量消耗 TEE（Total Energy Expenditure）
 ├── 基础代谢 BMR（Basal Metabolic Rate）  60%~75%
 ├── 食物热效应 TEF（Thermic Effect of Food）约10%
 └── 身体活动 PA（Physical Activity）  15%~30%（唯一主动可控）
```

| 部分 | 占比 | 说明 |
|------|------|------|
| **基础代谢 BMR** | 60%~75% | 维持心跳、呼吸、体温、细胞代谢的最低能耗；随年龄增长逐年下降 |
| **食物热效应 TEF** | 约10% | 消化吸收与营养素代谢本身消耗的能量 |
| **身体活动** | 15%~30% | 主动运动＋非运动性活动（NEAT）；可干预性最强 |

#### 3.2.3 基础代谢（BMR）

**定义：** 机体清醒、静卧、空腹（进食12小时以上）、环境安静适宜（18~25℃）时维持基本生命活动所需能量。

**影响BMR的因素：**

| 因素 | 影响 |
|------|------|
| 体型与体表面积 | 越大越高 |
| 体成分 | 肌肉越多，BMR越高（肌肉是代谢活跃组织） |
| 年龄 | 随年龄下降（约每10年降2%~3%） |
| 性别 | 男高于女（体脂/肌肉差异） |
| 激素 | 甲状腺激素、性激素影响 |
| 温度 | 寒冷/发热升高 |
| 节食 | 长期低能量饮食使BMR代偿性下降（"节能模式"） |

#### 3.2.4 BMR 估算公式（含算例）

**① Mifflin-St Jeor 公式（1990，更准确，临床常用）：**

```
男：BMR = 10×体重(kg) + 6.25×身高(cm) − 5×年龄(岁) + 5
女：BMR = 10×体重(kg) + 6.25×身高(cm) − 5×年龄(岁) − 161
```

**② Harris-Benedict 公式（1919，经典）：**

```
男：BMR = 13.397×体重(kg) + 4.799×身高(cm) − 5.677×年龄(岁) + 88.362
女：BMR = 9.247×体重(kg) + 3.098×身高(cm) − 4.330×年龄(岁) + 447.593
```

**算例（Mifflin-St Jeor）：** 一位45岁女性，体重60kg，身高160cm：
```
BMR = 10×60 + 6.25×160 − 5×45 − 161
    = 600 + 1000 − 225 − 161
    = 1214 kcal/d
```

**算例（男性）：** 一位30岁男性，体重75kg，身高175cm：
```
BMR = 10×75 + 6.25×175 − 5×30 + 5
    = 750 + 1093.75 − 150 + 5
    = 1698.75 kcal/d（约1699）
```

> **临床意义：** BMR是"躺着不动也烧掉的能量"；减脂餐设计的能量目标必须以BMR为底线，长期低于BMR会伤代谢、掉肌肉、易反弹。

#### 3.2.5 身体活动与活动系数（PAL）

| 活动水平 | 描述 | 活动系数 |
|---------|------|---------|
| 久坐（静息为主） | 办公室工作，几乎不运动 | 1.2 |
| 轻度活动 | 每周1~3次轻运动 | 1.375 |
| 中度活动 | 每周3~5次中等运动 | 1.55 |
| 重度活动 | 每周6~7次高强度运动 | 1.725 |
| 极重活动 | 体力劳动/职业运动员 | 1.9 |

#### 3.2.6 总能量消耗（TEE）计算

```
TEE = BMR × 活动系数
```

**接上例（女性，45岁，BMR=1214，轻度活动）：**
```
TEE = 1214 × 1.375 ≈ 1669 kcal/d
```
→ 维持体重的每日能量约为1670 kcal；减脂可在此基础制造200~300 kcal缺口（约1400 kcal/d，且不低于BMR底线）。

**各活动水平对应TEE速查（以BMR=1200为例）：**

| 活动系数 | 1.2 | 1.375 | 1.55 | 1.725 | 1.9 |
|---------|-----|-------|------|-------|-----|
| TEE（kcal） | 1440 | 1650 | 1860 | 2070 | 2280 |

#### 3.2.7 食物热效应（TEF）

**定义：** 摄食后因消化、吸收、转运、储存和代谢食物而额外消耗的能量，约占每日总能量10%。

**不同营养素TEF差异：**

| 营养素 | TEF（占该营养素能量的比例） | 原因 |
|--------|---------------------------|------|
| 蛋白质 | 20%~30% | 消化代谢复杂，氨基酸代谢耗能高 |
| 碳水化合物 | 5%~10% | 转化与储存耗能 |
| 脂肪 | 0%~3% | 储存路径简单，耗能最低 |

> **应用：** 高蛋白饮食"吃得多消耗也多"是蛋白增饱腹/增耗能的好处之一；但TEF只是辅助，不能替代总能量控制。

### 3.3 三大产能营养素的代谢路径

#### 3.3.1 碳水化合物代谢

```
碳水化合物 → 葡萄糖（吸收）
   │
   ├──→ 糖酵解 → 丙酮酸 → 乙酰CoA
   │                            │
   ├──→ 糖原（肝糖原/肌糖原储存）    ├──→ 三羧酸循环(TCA) → 氧化磷酸化 → ATP + CO₂ + H₂O
   │
   └──→（多余葡萄糖）→ 脂肪酸合成 → 脂肪储存
```

**关键点：** 血糖的调控依赖胰岛素与胰高血糖素；"糖异生"（肝由乳酸、甘油、氨基酸合成葡萄糖）在饥饿时维持血糖。

#### 3.3.2 脂肪代谢

```
脂肪（甘油三酯）→ 脂肪酸 + 甘油
   │
   ├──→ 脂肪酸 → β-氧化 → 乙酰CoA → TCA → ATP
   ├──→（过量乙酰CoA）→ 酮体（饥饿/糖尿病时）→ 脑与肌肉可用
   └──→ 甘油 → 糖异生路径
```

**关键点：** 酮体是长期饥饿或极低碳水时肝脏产生的替代能源；"脂肪只能在碳水火焰中燃烧"——草酰乙酸不足时TCA运转受限，脂肪不完全氧化→酮体。

#### 3.3.3 蛋白质代谢

```
蛋白质 → 氨基酸
   │
   ├──→ 脱氨基 → 碳骨架（α-酮酸）
   │              ├──→ 糖异生（生糖氨基酸）
   │              ├──→ 脂肪酸合成（生酮氨基酸）
   │              └──→ 直接氧化产能（TCA）
   └──→ 氨基 → 尿素循环 → 尿素（经肾排出）
```

**关键点：** 蛋白质不是优先能源（正常情况下供能约10%）；**尿素生成增加→肾脏负担**，这是"蛋白过量伤肾"的分子基础；氮平衡反映蛋白代谢整体状态。

#### 3.3.4 三大营养素代谢关系速查

| 比较 | 碳水 | 脂肪 | 蛋白质 |
|------|------|------|--------|
| 优先供能顺序 | 第一（首选） | 第二 | 第三（保护性） |
| 储存形式 | 糖原（有限） | 甘油三酯（无限） | 肌肉/组织蛋白（结构） |
| 供能系数 | 4 kcal/g | 9 kcal/g | 4 kcal/g |
| 代谢终产物 | CO₂+H₂O | CO₂+H₂O+酮体 | CO₂+H₂O+尿素 |
| 主要调节激素 | 胰岛素/胰高血糖素 | 胰岛素/胰高血糖素 | 皮质醇/生长激素等 |

## 四、消化吸收

### 4.1 消化系统总览

```
口腔 → 咽 → 食管 → 胃 → 小肠（十二指肠→空肠→回肠）→ 大肠 → 肛门
                        ↑（肝/胆囊/胰 分泌消化液进入十二指肠）
```

- **机械消化：** 咀嚼、胃蠕动、小肠分节运动。
- **化学消化：** 消化酶水解（淀粉酶、蛋白酶、脂肪酶）＋胆汁乳化脂肪。
- **吸收部位：** 小肠是吸收主力（面积约200㎡，因绒毛与微绒毛）。

### 4.2 各部位消化与吸收表

| 部位 | 消化什么 | 吸收什么 | 关键机制 |
|------|---------|---------|---------|
| **口腔** | 淀粉（唾液淀粉酶→麦芽糖）、少量脂肪（舌脂肪酶） | 极少（口腔黏膜可吸收少量小分子，如酒精） | 咀嚼增大表面积；唾液含淀粉酶 |
| **食管** | 无（仅输送） | 无 | 蠕动推进 |
| **胃** | 蛋白质（胃酸变性+胃蛋白酶→多肽）、少量脂肪（胃脂肪酶） | 酒精（直接吸收）、水、少量铁（Fe²⁺）、少量药物；**维生素B12的释放需要胃酸** | 胃酸（HCl）活化胃蛋白酶、杀菌；内因子（壁细胞分泌）为B12吸收所必需 |
| **小肠** | 全部营养素：淀粉→葡萄糖（胰淀粉酶+刷状缘酶）、蛋白质→氨基酸/肽（胰蛋白酶/糜蛋白酶/肠肽酶）、脂肪→脂肪酸+甘油（胰脂肪酶+胆汁乳化）、双糖→单糖 | **几乎所有营养素**：葡萄糖、氨基酸/肽、脂肪酸、甘油一酯、维生素、矿物质、水 | 十二指肠（混合）、空肠（铁/钙等主要吸收）、回肠（B12-内因子复合物、胆汁酸重吸收） |
| **大肠** | 膳食纤维被菌群发酵 | 水、电解质（钠钾）、短链脂肪酸（乙酸/丙酸/丁酸，可被吸收利用）、部分B族/K（菌群合成） | 肠道菌群是"第二消化器官" |

**关键结论：** **小肠几乎吸收一切；大肠只吸收水、电解质与短链脂肪酸；胃吸收很少。**

### 4.3 主要营养素的消化吸收要点

| 营养素 | 消化产物 | 吸收特点 | 特殊机制 |
|--------|---------|---------|---------|
| 碳水化合物 | 葡萄糖、果糖、半乳糖 | 空肠为主 | 果糖吸收慢（"多吃水果腹泻"原因之一） |
| 蛋白质 | 氨基酸、二肽/三肽 | 空肠/回肠 | 小肽吸收优于游离氨基酸 |
| 脂肪 | 脂肪酸、甘油一酯 | 空肠 | 需胆汁乳化+形成乳糜微粒经淋巴入血 |
| 铁 | Fe²⁺ | 十二指肠/空肠 | 血红素铁直接吸收；非血红素铁需VC还原 |
| 钙 | Ca²⁺ | 十二指肠/空肠 | 需维生素D、酸性环境；活性吸收+被动扩散 |
| B12 | B12 | 回肠 | 需胃内因子；需胰腺与回肠受体 |
| 叶酸 | 单谷氨酸叶酸 | 空肠 | 需肠黏膜结合酶去谷氨酰基 |

### 4.4 促进与抑制吸收的因素

#### 4.4.1 促进吸收的因素

| 因素 | 促进什么 | 机制/说明 |
|------|---------|----------|
| 维生素C | 铁（非血红素） | 把Fe³⁺还原为Fe²⁺，形成可溶螯合物 |
| "肉类因子"（MPF） | 铁 | 动物蛋白促进非血红素铁吸收 |
| 脂肪与胆汁 | 脂溶性维生素A/D/E/K | 脂肪乳化脂溶性维生素并促进乳糜微粒形成 |
| 胃酸 | 钙、铁、B12 | 酸性环境促钙离子化、促铁溶解、释放食物中B12 |
| 乳糖 | 钙 | 乳糖与钙形成可溶复合物 |
| 有机酸（柠檬酸/苹果酸） | 钙、铁 | 螯合防沉淀 |
| 维生素D | 钙、磷 | 主动转运关键 |

#### 4.4.2 抑制吸收的因素

| 因素 | 抑制什么 | 机制/说明 |
|------|---------|----------|
| 植酸（谷类/豆类麸皮） | 锌、铁、钙 | 形成不溶性植酸盐 |
| 草酸（菠菜、苋菜、甜菜） | 钙、铁 | 形成草酸钙沉淀 |
| 鞣酸/多酚（浓茶、咖啡） | 铁 | 结合非血红素铁 |
| 过量膳食纤维 | 钙、铁、锌 | 高纤维（如麦麸）机械结合矿物质 |
| 酒精 | B1、B12、叶酸 | 损伤肠黏膜、干扰吸收与利用 |
| 抑酸药（PPI） | B12、铁、钙 | 降低胃酸 |
| 抗生素（长期） | B族、K | 杀灭肠道合成菌群 |
| 钙与铁同补 | 二者互扰 | 竞争吸收通道（错开2小时以上） |

#### 4.4.3 实操建议（把吸收知识变成话术）

| 场景 | 建议 |
|------|------|
| 补铁 | 配维C水果/肉类；浓茶咖啡与正餐错开1小时以上 |
| 补钙 | 餐后服、分次、与铁错开；配合维生素D；菠菜先焯水去草酸 |
| 喝咖啡 | 铁缺乏者别在餐后立即喝浓咖啡 |
| 高纤维 | 补矿物质者不宜同时大量麦麸；纤维从食物循序渐进 |
| 老人 | 胃酸↓→B12吸收↓，注意检测与必要时遵医嘱补充 |

### 4.5 消化吸收的临床意义

| 情况 | 营养影响 | 应对原则 |
|------|---------|---------|
| 胃切除/萎缩性胃炎 | B12（内因子↓）、铁、钙吸收↓ | 监测B12、遵医嘱补充；少量多餐 |
| 胰腺疾病 | 脂肪与蛋白消化↓（脂肪泻） | 胰酶替代、低脂膳食 |
| 肝胆疾病 | 脂溶性维生素吸收↓ | 注意A/D/E/K监测 |
| 乳糖不耐受 | 乳糖吸收障碍→腹胀腹泻 | 选无乳糖奶/酸奶/少量多次 |
| 肠炎/短肠综合征 | 吸收面积↓ | 个体化肠内/肠外营养（临床营养范畴） |

> **合规提醒：** 以上临床情况只作科普框架，个体化处理请就医；AI营养师不替代诊疗。
