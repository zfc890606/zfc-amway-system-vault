# 13 · 药学基础（书本级扩展版）

> **一句话定位：** 药物与营养的交叉地带——药理学基础、常见慢病药物、**药物-营养素相互作用**。营养师不需要开药，但必须知道：顾客在吃什么药（决定营养方案怎么给）、哪些药物会耗损营养素（决定要不要提醒）、哪些营养素会干扰药物（决定要不要警示）。
>
> **本书目标读者：** 营养师 / 健康管理师 / 营养顾问，重点服务对象是正在服用慢病药物的中老年人。
>
> ⚠️ **边界声明：** 本文是营养工作者的用药常识，**不是用药指导**。所有药物剂量、用法、停用、调整一律以**医生/药师**为准。本文出现的药物信息仅用于营养方案制定时的参考与沟通，不构成处方建议，不替代诊疗。

**营养师药学知识的三条主线（全书反复出现的主题）：**

1. **耗损**：哪些药会偷走顾客体内的营养素（B12、钾、镁、钙、叶酸、维D、CoQ10…）→ 决定要不要建议监测/补充。
2. **干扰**：哪些食物/营养素会改变药物吸收和效果（钙铁螯合、葡萄柚抑酶、维K拮抗…）→ 决定要不要提醒"隔开吃"。
3. **时机**：服药与用餐、补充剂的先后间隔 → 决定能不能给出可执行的"服用时间表"。

## 一、药理学基础

### 1.1 什么是药理学

药理学（Pharmacology）是研究**药物与机体相互作用**的科学，分两大块：

| 分支 | 研究对象 | 营养师关心的点 |
|------|---------|--------------|
| 药代动力学（PK） | 机体如何对待药物（吸收→分布→代谢→排泄） | 食物/营养素怎么改变药物在体内的浓度 |
| 药效学（PD） | 药物如何对待机体（作用机制、效应） | 药物通过什么机制起作用、消耗什么营养底物 |

**营养师视角的"药理学"不是记药名，而是记"药物-营养的交汇机制"**：药物代谢靠肝酶、药物排泄靠肾脏、药物吸收靠胃肠——这三个环节恰好也是营养素代谢的环节，交叉就在这里。

### 1.2 药物在体内过程（ADME）

```
吸收 Absorb（胃肠→血液）
   ↓
分布 Distribute（血液→组织/靶点）
   ↓
代谢 Metabolize（肝，CYP450酶系为主）
   ↓
排泄 Excrete（肾为主，胆汁/肠道为辅）
```

#### 1.2.1 吸收（Absorption）

| 要点 | 说明 | 营养意义 |
|------|------|---------|
| 吸收途径 | 口服、注射、舌下、经皮、吸入等 | 口服最受食物影响 |
| 影响口服吸收的因素 | 胃排空速度、胃酸、食物成分、胃肠蠕动、首过效应 | 高脂餐、高纤维、钙铁离子都会改变吸收 |
| 空腹 vs 餐后 | 空腹吸收快但刺激胃；餐后吸收慢但更温和 | 决定"餐前/餐后/随餐"的建议 |
| 螯合作用 | 多价金属离子（钙、铁、镁、锌、铝）与某些药物结合成不溶物 | **钙铁与抗生素/优甲乐必须隔开** |

**药物吸收的"吸收窗"思维：** 药物进入血液的量和速度，决定了它能不能达到有效浓度。营养师能实际影响的是：**帮顾客把"抢同一通道"的药物和食物错开**。

#### 1.2.2 分布（Distribution）

- 药物入血后与血浆蛋白（主要是白蛋白）结合，游离型才有药理活性。
- 两个药物都强结合白蛋白时，可能互相"挤"下来，游离浓度升高。
- **营养意义：** 低蛋白血症（营养不良、肝病）时游离药物增多，作用增强、毒性风险升高——这是"营养状态影响药效"的底层机制之一。

#### 1.2.3 代谢（Metabolism）

代谢主要在肝脏，核心是**细胞色素P450酶系（CYP450）**：

| 酶 | 代谢的代表药物 | 营养师最该记住的互动 |
|----|--------------|--------------------|
| CYP3A4 | 他汀（辛伐他汀/洛伐他汀/阿托伐他汀）、地平类、部分镇静药、免疫抑制剂 | **葡萄柚（西柚）抑制CYP3A4** → 药物浓度↑↑ |
| CYP3A4（诱导） | 圣约翰草、酒精（慢性） | 酶被诱导 → 药物浓度↓↓ → 失效 |
| CYP2C9 | 华法林、苯妥英、部分NSAIDs | 维K拮抗华法林主要在此轴外；注意苯妥英与叶酸 |
| CYP2C19 | 氯吡格雷（前药需活化） | 奥美拉唑抑制CYP2C19 → 氯吡格雷效果↓ |

**营养师最需要记住的代谢知识点：**

1. **葡萄柚抑制肠道CYP3A4**，让被它代谢的药物浓度成倍升高——西柚的抑制是不可逆的，隔开几小时吃并不能消除，服药期间最好**整个避免**。
2. **圣约翰草诱导CYP3A4**，效果完全相反——让药物浓度骤降，是"营养素让药失效"的典型。
3. 代谢产物有的活性更高（前药活化），有的有毒（如对乙酰氨基酚的毒性代谢物，慢性饮酒者风险↑）。

#### 1.2.4 排泄（Excretion）

| 排泄途径 | 说明 | 营养意义 |
|---------|------|---------|
| 肾脏（主） | 药物以原形或代谢物经尿排出 | 肾功能不好→药物蓄积；利尿剂→电解质随尿流失 |
| 胆汁/肠道 | 部分药物经胆汁入肠、随粪排出 | 肠道菌群参与某些药物再循环（如部分激素） |
| 其他 | 汗液、唾液、乳汁 | 哺乳期用药需特别注意 |

**肾排泄环节是"药→营养流失"的高发区：** 排钠排水的利尿剂，同时把钾、镁、锌一起带走；肾功能不全时药物蓄积，营养素补充更需谨慎（钾、镁补剂在肾衰时反而危险）。

#### 1.2.5 ADME 汇总表（营养师速记版）

| 环节 | 一句话 | 营养师可干预的方向 |
|------|-------|------------------|
| 吸收 | 胃肠是药物和营养素共同入口 | 错开服用、螯合提醒、餐时选择 |
| 分布 | 蛋白结合、游离浓度 | 关注低蛋白血症风险人群 |
| 代谢 | 肝脏CYP450是交叉枢纽 | 葡萄柚/圣约翰草提醒 |
| 排泄 | 肾脏是营养素流失通道 | 利尿剂补钾镁、多饮水 |

### 1.3 药代动力学关键概念

| 概念 | 定义 | 营养师应用 |
|------|------|-----------|
| 半衰期（t½） | 血药浓度下降一半所需的时间 | 决定给药频次；半衰期长的药更易蓄积 |
| 首过效应 | 口服药先经肝/肠壁代谢，进入体循环前部分被灭活 | 解释为什么同一药口服剂量远大于注射 |
| 生物利用度 | 药物进入体循环的比例 | 食物降低生物利用度→药效打折 |
| 稳态浓度（Css） | 多次给药后血药浓度达到的平衡平台 | 开始服药后约4~5个半衰期起效 |
| 治疗窗 | 有效浓度与中毒浓度之间的区间 | 治疗窗窄的药（华法林、地高辛、优甲乐）最怕波动 |
| 蛋白结合率 | 与血浆蛋白结合的比例 | 低蛋白时游离药物↑ |

**治疗窗窄的药物 = 营养师要最高级别提醒的名单：**

| 药物 | 治疗窗窄的原因 | 营养师提醒重点 |
|------|--------------|---------------|
| 华法林 | 过量出血、不足血栓 | 维K稳定摄入、不随意加补充剂 |
| 地高辛 | 中毒量与治疗量接近 | 低钾/低镁/高钙都促中毒 |
| 左甲状腺素 | 过量甲亢、不足甲减 | 钙铁镁锌隔4小时、固定空腹时段 |
| 锂盐 | 过量即中毒 | 钠摄入稳定（钠变→血锂变） |
| 环孢素 | 免疫抑制与毒性 | 葡萄柚禁忌 |

### 1.4 药效学基础

| 概念 | 说明 |
|------|------|
| 受体 | 药物作用的靶蛋白，药物与受体结合产生效应 |
| 激动剂 | 结合受体并激活效应（如胰岛素促分泌剂） |
| 拮抗剂 | 结合受体但阻断效应（如ARB阻断血管紧张素受体） |
| 量效关系 | 剂量↑→效应↑，但非线性；到达平台后加量不再增效、只增毒 |
| ED50 | 引起50%个体有效反应所需剂量 |
| LD50 | 引起50%个体死亡所需剂量（动物实验概念） |
| 治疗指数 | LD50/ED50，越大越安全 |

**营养师应用：** "加量不吃亏"是错误观念——剂量到平台后多出来的只有副作用。顾客说"我把他汀加了一倍"时，应提醒回归医嘱。

### 1.5 药物不良反应（ADR）

| 分型 | 特点 | 举例 |
|------|------|------|
| A型（剂量相关、可预测） | 与药理作用延伸有关，占多数 | 二甲双胍胃肠不适、他汀肌痛、利尿剂低钾 |
| B型（特异质/过敏） | 与剂量无关、难预测 | 青霉素过敏、别嘌醇皮疹 |

**常见不良反应类型：**

| 类型 | 定义 | 营养相关例子 |
|------|------|------------|
| 副作用 | 治疗作用以外的反应，随剂量出现 | 阿卡波糖腹胀、GLP-1恶心 |
| 毒性反应 | 剂量过大/蓄积所致 | 华法林出血、地高辛中毒 |
| 后遗效应 | 停药后残留效应 | 激素停药后的肾上腺皮质功能不全 |
| 变态反应 | 免疫介导 | 药物皮疹 |
| 继发反应 | 治疗作用的间接后果 | 抗生素杀灭菌群→维K合成↓ |
| 撤药反应 | 骤停引起的反跳 | 激素骤停→皮质功能危象、洛尔骤停→血压反跳 |

**营养师最重要的一条原则：副作用不等于"药不好"，也不能自行停药。** 顾客说"这药我吃了难受，自己停了"——第一时间提醒**不能自行停药**，特别是激素、降压药、抗癫痫药、抗凝药，骤停有反跳风险。同时把营养支持方案给上（见第七章）。

### 1.6 处方药 vs 非处方药（OTC）

| 对比项 | 处方药（Rx） | 非处方药（OTC） |
|--------|-----------|---------------|
| 购买 | 需医生处方 | 药店自购 |
| 适应证 | 慢病、重症、需监测 | 常见小症状 |
| 监管 | 严格，需医嘱 | 相对宽松 |
| 营养师态度 | 高度谨慎，所有干预先问医生 | 仍需谨慎，如长期自购PPI、泻药、NSAIDs同样有问题 |

**营养师要特别提醒的两个"OTC陷阱"：**

1. **长期自购抑酸药（PPI/奥美拉唑类）**：虽然OTC可买，但长期用→B12、钙、镁、铁吸收↓，与处方PPI风险一样。
2. **长期自购泻药/通便茶**：刺激性泻药长期用→电解质丢失、肠道菌群改变、结肠黑变病，还可能与药物（如地高辛）相互作用。
3. **自购止痛药（布洛芬等NSAIDs）**：长期用伤胃、伤肾、升高血压，与阿司匹林、抗凝药、利尿剂、ACEI叠加风险。

### 1.7 药物相互作用基础

| 类型 | 机制 | 例子 |
|------|------|------|
| 药动学相互作用 | 一个药改变另一个药的吸收/分布/代谢/排泄 | 葡萄柚使他汀浓度↑；华法林+维K |
| 药效学相互作用 | 两药作用相加/相减/对抗 | 阿司匹林+华法林出血风险叠加 |
| 食物-药物相互作用 | 食物成分改变药效 | 钙螯合四环素、酪胺+MAOI升压 |

**相互作用严重度分级（营养师判断话术）：**

| 级别 | 含义 | 营养师动作 |
|------|------|-----------|
| 禁用 | 绝对避免合用 | 明确告知，如葡萄柚+部分他汀 |
| 谨慎/需监测 | 合用需调整剂量或监测 | 提醒监测，转介医生 |
| 一般注意 | 错开时间即可 | 给出间隔建议 |
| 无显著 | 可正常合用 | 正常推荐 |

### 1.8 药物与营养的交汇点（核心地图）

#### 1.8.1 肝脏：药物代谢 + 营养代谢共用酶系统

- 肝是CYP450药物代谢的大本营，也是大部分营养素代谢（活化、储存）的场所。
- 药物诱导或抑制肝酶 → 不仅改变其他药物浓度，也改变某些营养素的活化。
  - 例：苯妥英等抗癫痫药诱导肝酶 → 维D分解加速 → 骨软化。
- 肝病患者：药物代谢↓、营养素转化↓，两者都要减量/谨慎。

#### 1.8.2 肾脏：排泄通道

- 药物经肾排；利尿剂在排钠排水时带走钾、镁、锌。
- 肾功能不全：药物蓄积 + 矿物质调节紊乱（高钾/低钙/维D活化障碍）。
- 营养师动作：肾功能不全顾客补充任何钾/镁/磷补剂前，必须提醒咨询医生。

#### 1.8.3 胃肠道：吸收的共用入口

- 同一段肠道吸收同一类成分 → 互相竞争/结合。
- 金属离子（钙铁镁锌铝）与药物螯合 → 两者吸收都下降。
- 肠道菌群：抗生素破坏菌群 → 维K/B族合成减少。

#### 1.8.4 交汇点总表

| 交汇点 | 药物方向 | 营养素方向 | 营养师行动 |
|--------|---------|-----------|-----------|
| 肝CYP450 | 药物代谢 | 维D活化、脂溶性维A等 | 酶诱导药→提示维D监测 |
| 肾小管 | 药物排泄 | 钾、镁、锌、钠平衡 | 利尿剂→补钾镁提示 |
| 胃肠螯合 | 药物吸收 | 钙、铁、镁、锌吸收 | 隔开2~4小时 |
| 肠道菌群 | 部分药物活化/失活 | 维K、B族合成 | 抗生素后益生菌 |
| 血浆蛋白 | 药物分布 | 白蛋白营养状态 | 低蛋白者警惕药效增强 |

## 二、常见慢病药物与营养要点

> 每类药物下面给出：**作用机制（营养师版）→ 营养要点 → 服药时间 → 营养师提醒**。所有剂量、停药、调整以医生/药师为准。

### 2.1 降糖药

#### 2.1.1 二甲双胍（Metformin）—— 最常用的一线口服降糖药

| 项目 | 内容 |
|------|------|
| 机制（营养师版） | 抑制肝糖输出、增加外周胰岛素敏感性、减少肠道葡萄糖吸收；不直接刺激胰岛素分泌 → 单独用低血糖风险低 |
| 营养要点① | **长期使用（通常>1年）→ 维生素B12吸收↓**，风险随剂量和时长增加 → 建议定期查B12，尤其有贫血/周围神经症状者 |
| 营养要点② | 胃肠道反应（腹泻、恶心、腹胀）常见 → **随餐/餐后服用**可显著减轻 |
| 营养要点③ | 可能轻微影响叶酸水平（部分研究） |
| 服药时间 | 普通片随餐或餐后；缓释片通常晚餐随餐 |
| 营养师提醒 | 有报道极低热量/极低碳饮食+二甲双胍增加不适，但不属常规风险；减重期注意B12、叶酸摄入 |

#### 2.1.2 磺脲类（格列XX：格列本脲、格列齐特、格列吡嗪、格列美脲）

| 项目 | 内容 |
|------|------|
| 机制 | 刺激胰岛β细胞分泌胰岛素 → **低血糖风险是本类药物最大安全点** |
| 营养要点 | 规律进餐、定时定量主食，不要因"降糖药"而随意不吃饭；运动后/漏餐时低血糖风险↑ |
| 服药时间 | 通常餐前30分钟（格列吡嗪、格列本脲）；格列美脲可与首餐同服（按说明书） |
| 营养师提醒 | 顾客反复低血糖→提醒就医调整；不要建议用营养素替代；酒精加重低血糖（尤其空腹饮酒） |

#### 2.1.3 格列奈类（瑞格列奈、那格列奈）

| 项目 | 内容 |
|------|------|
| 机制 | 促进胰岛素快相分泌，起效快、维持短 |
| 营养要点 | **"不吃饭不吃药"**：随餐前服用，漏餐则跳过该次用药 |
| 服药时间 | 餐前0~30分钟，紧随第一口饭 |
| 营养师提醒 | 低血糖风险；与磺脲类不合用（机制重叠） |

#### 2.1.4 α-糖苷酶抑制剂（阿卡波糖、伏格列波糖）

| 项目 | 内容 |
|------|------|
| 机制 | 抑制小肠α-糖苷酶 → 延缓碳水化合物分解吸收 → 降低餐后血糖 |
| 营养要点 | 对碳水餐有效；**随第一口饭嚼服**；常见腹胀、排气增多（未吸收碳水被肠菌发酵）|
| 服药时间 | 与第一口饭同服嚼碎 |
| 营养师提醒 | 腹胀是"药物在起作用"的常见反应，可少食多餐、循序渐进增加主食量缓解；单用不易低血糖 |

#### 2.1.5 SGLT2抑制剂（达格列净、恩格列净、卡格列净）

| 项目 | 内容 |
|------|------|
| 机制 | 抑制肾小管钠-葡萄糖共转运蛋白2 → 尿中排糖 → 降糖+减重+轻度降压 |
| 营养要点 | 多尿 → **补水防脱水**；尿糖高 → 泌尿生殖道感染风险↑（保持会阴清洁）；减重获益 |
| 服药时间 | 多数晨服，随餐或不随餐（按说明书） |
| 营养师提醒 | **本类药与极低碳水/生酮饮食合用有酮症酸中毒风险（即使血糖不高）** → 提醒不要自行极端低碳；手术/生病/脱水时暂停（医生决定） |

#### 2.1.6 GLP-1受体激动剂（司美格鲁肽、利拉鲁肽、艾塞那肽）

| 项目 | 内容 |
|------|------|
| 机制 | 肠促胰素类似物：促胰岛素分泌、抑制胰高血糖素、**减慢胃排空、抑制食欲** → 降糖+显著减重 |
| 营养要点 | 恶心、早饱常见 → 小份、低脂、慢食；减重期注意蛋白质与微量营养素（防止肌肉流失）|
| 服药时间 | 注射剂（每日/每周），按医嘱固定时间 |
| 营养师提醒 | 胃排空减慢可能影响口服药吸收——**正在吃其他口服药（尤其华法林、优甲乐、某些激素）的患者，启动GLP-1时建议医生监测药物效果**；减重期帮顾客做"高蛋白+高纤+控油"结构 |

#### 2.1.7 DPP-4抑制剂（西格列汀、利格列汀、沙格列汀）

| 项目 | 内容 |
|------|------|
| 机制 | 抑制DPP-4酶 → 升高内源性GLP-1 → 葡萄糖依赖性地促胰岛素、抑胰高血糖素 |
| 营养要点 | 体重中性，低血糖风险低；营养重点回到总能量与血糖负荷控制 |
| 服药时间 | 多数每日一次，可按说明书与餐无关 |

#### 2.1.8 胰岛素（胰岛素注射是"必须配合进食"的药）

| 项目 | 内容 |
|------|------|
| 机制 | 外源性补充胰岛素 |
| 营养要点 | **定时定量进餐**与胰岛素方案匹配；速效胰岛素随餐注射；低血糖处理：15g快碳水 |
| 服药时间 | 速效（门冬/赖脯）随餐；预混按医嘱早晚 |
| 营养师提醒 | 帮顾客建立"胰岛素剂量↔碳水摄入"意识，但不改剂量；低血糖应急食品建议（葡萄糖片、果汁、蜂蜜） |

#### 2.1.9 降糖药总表（营养师速查）

| 药物类别 | 代表药 | 机制一句话 | 低血糖风险 | 营养要点 | 服药时间 |
|---------|-------|-----------|-----------|---------|---------|
| 双胍类 | 二甲双胍 | 抑肝糖输出+增敏感 | 低 | **B12↓**、胃肠反应 | 随餐/餐后 |
| 磺脲类 | 格列美脲等 | 促胰岛素分泌 | **高** | 规律进餐防低血糖 | 餐前30min |
| 格列奈类 | 瑞格列奈 | 促快相胰岛素 | 中 | 不吃饭不服药 | 餐前即刻 |
| α-糖苷酶抑制 | 阿卡波糖 | 抑碳水吸收 | 低 | 腹胀、随第一口饭 | 第一口饭嚼服 |
| SGLT2i | 达格列净 | 尿排糖 | 低 | **补水、防DKA** | 晨服 |
| GLP-1 | 司美格鲁肽 | 肠促胰素+抑食欲 | 低 | 恶心、高蛋白、注意口服药吸收 | 注射按医嘱 |
| DPP-4 | 西格列汀 | 升内源GLP-1 | 低 | 体重中性 | 每日一次 |
| 胰岛素 | 门冬/甘精 | 外源补充 | **高** | 定时定量进餐、15g快碳水应急 | 速效随餐 |

### 2.2 降压药

#### 2.2.1 噻嗪类利尿剂（氢氯噻嗪、吲达帕胺）

| 项目 | 内容 |
|------|------|
| 机制 | 抑制远曲小管钠-氯转运 → 排钠排水降血压 |
| 营养要点① | **丢钾/镁/锌** → 长期用注意富钾食物（肾功能正常者）、必要时遵医嘱补钾镁 |
| 营养要点② | 可升高血糖、血脂、尿酸（小剂量影响小）→ 合并糖尿病/痛风者关注 |
| 营养要点③ | **减少尿钙排出**（保钙）→ 偶有血钙升高，勿盲目补大剂量钙+维D叠加 |
| 服药时间 | 晨服（避免夜尿影响睡眠） |
| 营养师提醒 | 富钾食物（香蕉、土豆、豆类、深绿蔬菜）适合肾功能正常者；肾功能不全者补钾必须先问医生 |

#### 2.2.2 袢利尿剂（呋塞米、托拉塞米）

| 项目 | 内容 |
|------|------|
| 机制 | 抑制髓袢升支钠-钾-氯共转运 → 强效排钠排水 |
| 营养要点 | **丢钾、镁、钙、锌更多** → 监测电解质、富钾镁食物、遵医嘱补充 |
| 服药时间 | 晨服或分次，避免晚间 |
| 营养师提醒 | 心衰患者常联用，电解质紊乱风险高；**营养师不主动推荐钾补剂，一律转介医生** |

#### 2.2.3 保钾利尿剂（螺内酯、依普利酮）

| 项目 | 内容 |
|------|------|
| 机制 | 拮抗醛固酮 → 保钾排钠 |
| 营养要点 | **血钾可能升高** → 勿大量富钾食物/钾补充剂/低钠盐（低钠盐多为氯化钾） |
| 服药时间 | 按医嘱，螺内酯常随餐服（减少胃肠刺激） |

#### 2.2.4 ACEI（普利类：依那普利、培哚普利、雷米普利）

| 项目 | 内容 |
|------|------|
| 机制 | 抑制血管紧张素转换酶 → 血管扩张、降血压 |
| 营养要点① | **血钾可升高** → 勿乱补钾、勿用高钾低钠盐 |
| 营养要点② | 干咳常见（缓激肽↑）；罕见血管性水肿 |
| 服药时间 | 按医嘱，多数每日一次 |

#### 2.2.5 ARB（沙坦类：氯沙坦、缬沙坦、厄贝沙坦）

| 项目 | 内容 |
|------|------|
| 机制 | 阻断血管紧张素Ⅱ受体 → 扩血管降压 |
| 营养要点 | 血钾可升高（较ACEI轻）；同样避免高钾补剂/低钠盐 |

#### 2.2.6 钙通道阻滞剂（地平类：氨氯地平、硝苯地平、非洛地平）

| 项目 | 内容 |
|------|------|
| 机制 | 阻断L型钙通道 → 血管平滑肌舒张 → 降压 |
| 营养要点① | **下肢水肿、牙龈增生**常见 → 注意口腔卫生、抬高下肢，勿自行停药 |
| 营养要点② | **硝苯地平、非洛地平与葡萄柚相互作用显著**（CYP3A4）→ 避免西柚 |
| 营养要点③ | 氨氯地平作用平缓，与葡萄柚相互作用相对小但仍建议避免 |
| 服药时间 | 长效制剂每日一次晨服 |

#### 2.2.7 β受体阻滞剂（洛尔类：美托洛尔、比索洛尔、普萘洛尔）

| 项目 | 内容 |
|------|------|
| 机制 | 阻断β受体 → 减慢心率、降低心输出量、降压 |
| 营养要点① | **掩盖低血糖症状**（心悸、手抖被掩盖）→ 糖尿病患者注意识别低血糖（出汗仍会出现）|
| 营养要点② | 传统β阻滞剂可能升高甘油三酯、降低HDL（新型的如比索洛尔影响较小）→ 配合血脂管理 |
| 服药时间 | 多数每日一次晨服；脂溶性（美托洛尔、普萘洛尔）与食物同服可提高吸收一致性（按说明书） |

#### 2.2.8 降压药总表（营养师速查）

| 药物类别 | 代表药 | 机制一句话 | 最该记住的营养点 | 服药时间 |
|---------|-------|-----------|----------------|---------|
| 噻嗪类利尿剂 | 氢氯噻嗪 | 排钠排水 | **丢钾镁锌**、升血糖尿酸、保钙 | 晨服 |
| 袢利尿剂 | 呋塞米 | 强排钠水 | 丢钾镁钙、需监测 | 晨服 |
| 保钾利尿剂 | 螺内酯 | 保钾排钠 | 血钾↑、防高钾 | 随餐 |
| ACEI | 培哚普利 | 扩血管 | 血钾↑、干咳 | 每日一次 |
| ARB | 缬沙坦 | 扩血管 | 血钾↑ | 每日一次 |
| 钙拮抗剂 | 氨氯地平 | 扩血管 | 下肢肿、牙龈增生；硝苯地平/非洛地平忌西柚 | 晨服 |
| β阻滞剂 | 美托洛尔 | 减慢心率 | **掩盖低血糖**、血脂影响 | 晨服 |

### 2.3 降脂药

#### 2.3.1 他汀类（阿托伐他汀、瑞舒伐他汀、辛伐他汀、洛伐他汀、普伐他汀、匹伐他汀）

| 项目 | 内容 |
|------|------|
| 机制 | 抑制HMG-CoA还原酶（胆固醇合成限速酶）→ 肝胆固醇合成↓、LDL↓ |
| 营养要点① | **可能降低辅酶Q10（CoQ10）水平**（胆固醇与CoQ10共享合成通路）→ 可考虑补充（部分研究提示可能缓解他汀肌痛，证据有限）|
| 营养要点② | **葡萄柚相互作用分级：** 辛伐他汀/洛伐他汀为最高危（CYP3A4强代谢）→ 避免西柚；阿托伐他汀中度；瑞舒伐他汀/普伐他汀/氟伐他汀影响小（CYP3A4非主要途径）|
| 营养要点③ | 肌痛/肌酶升高：及时就医；合并贝特（吉非罗齐）肌病风险↑ |
| 服药时间 | 辛伐他汀/洛伐他汀**睡前服**（胆固醇合成夜间高峰）；阿托伐他汀/瑞舒伐他汀长半衰期任何固定时间 |
| 营养师提醒 | 高纤维补充剂（如洋车前子）可能减少他汀吸收 → 隔开2小时；不要因"想停他汀"而停药，血脂管理是终身事 |

#### 2.3.2 依折麦布

| 项目 | 内容 |
|------|------|
| 机制 | 抑制肠道NPC1L1 → 胆固醇肠吸收↓ |
| 营养要点 | 与饮食控脂协同；可与他汀联用 |
| 服药时间 | 每日一次，与餐无关 |

#### 2.3.3 贝特类（非诺贝特、吉非罗齐）

| 项目 | 内容 |
|------|------|
| 机制 | 激活PPARα → 降甘油三酯（TG）、升HDL |
| 营养要点 | 肝功监测；**与鱼油都有降TG作用但机制不同，是否联用问医生**（一般可协同但勿自行叠超大剂量）|
| 服药时间 | 非诺贝特随餐服（脂溶性吸收好）|
| 营养师提醒 | 与吉非罗齐合用他汀肌病风险↑，营养师不做联用建议 |

#### 2.3.4 PCSK9抑制剂（依洛尤单抗、阿利西尤单抗）

| 项目 | 内容 |
|------|------|
| 机制 | 单抗抑制PCSK9 → LDL受体降解减少 → LDL大幅↓ |
| 营养要点 | 注射剂，与食物无相互作用；营养上配合心血管饮食模式（地中海式/得舒式）|
| 服药时间 | 皮下注射，按医嘱 |

#### 2.3.5 降脂药总表

| 药物类别 | 代表药 | 机制一句话 | 最该记住的营养点 | 服药时间 |
|---------|-------|-----------|----------------|---------|
| 他汀 | 阿托伐他汀 | 抑胆固醇合成 | **CoQ10↓、西柚分级禁忌、肌痛就医** | 睡前（辛伐/洛伐）|
| 胆固醇吸收抑制剂 | 依折麦布 | 抑肠吸收 | 与控脂饮食协同 | 每日一次 |
| 贝特 | 非诺贝特 | 降TG升HDL | 肝功监测、鱼油联用问医生 | 随餐 |
| PCSK9抑制剂 | 依洛尤单抗 | LDL受体↑ | 注射剂、无食物互作 | 注射 |

### 2.4 抗凝/抗血小板药

#### 2.4.1 华法林（最经典的"营养敏感"药物）

| 项目 | 内容 |
|------|------|
| 机制 | 抑制维K环氧化物还原酶（VKORC1）→ 依赖维K的凝血因子Ⅱ、Ⅶ、Ⅸ、Ⅹ合成受阻 → 抗凝 |
| 营养要点① | **维生素K拮抗华法林** → 绿叶蔬菜（菠菜、西兰花、羽衣甘蓝、芥菜等）**稳定摄入、不要忽多忽少**；不要"干脆不吃"（维K过低反而出血风险↑）|
| 营养要点② | **高剂量维E增强抗凝** → 出血风险（一般>400IU/日需谨慎，>800IU/日风险明显）|
| 营养要点③ | 鱼油（EPA+DHA>3g/日）、大蒜、银杏、人参、丹参等增强出血风险 → 加任何补充剂前问医生 |
| 服药时间 | 每天固定时间（常为晚间）|
| 营养师提醒 | 顾客突发"尿液/牙龈出血、瘀斑增多" → 立即就医；蔓越莓、芒果、西柚等对华法林影响的证据不一，稳妥起见大量食用前咨询医生 |

#### 2.4.2 阿司匹林（低剂量抗血小板）

| 项目 | 内容 |
|------|------|
| 机制 | 不可逆抑制环氧合酶（COX-1）→ 抑制血小板血栓素 → 抗血小板 |
| 营养要点① | **长期用可能胃肠道损伤、隐性失血 → 铁流失** → 胃部不适者饭后服；注意铁营养状态 |
| 营养要点② | 与酒精同服增加胃出血风险 → 提醒限酒 |
| 服药时间 | 肠溶片空腹或随餐（按说明书与医生习惯），多数建议餐后或睡前固定 |
| 营养师提醒 | 与鱼油、大蒜、银杏叠加出血风险；胃溃疡史者慎用（医生决定）|

#### 2.4.3 氯吡格雷（抗血小板，前药）

| 项目 | 内容 |
|------|------|
| 机制 | 前药，需CYP2C19活化 → 抑制血小板P2Y12受体 |
| 营养要点 | **奥美拉唑/艾司奥美拉唑抑制CYP2C19 → 氯吡格雷效果↓**（营养师常见场景：顾客同时吃PPI，提醒医生评估，可换用不抑制CYP2C19的抑酸药如泮托拉唑）|
| 营养师提醒 | 食物影响较小；规律服用 |

#### 2.4.4 新型口服抗凝药（NOACs：达比加群、利伐沙班、阿哌沙班、依度沙班）

| 项目 | 内容 |
|------|------|
| 机制 | 直接抑制凝血因子（Ⅱa或Ⅹa） |
| 营养要点 | **与维K无显著相互作用**（不像华法林）→ 绿叶菜不用回避；利伐沙班15/20mg需随餐服（提高吸收）|
| 营养师提醒 | 出血风险仍存在；鱼油/维E/大蒜/银杏等活血类仍建议谨慎 |

#### 2.4.5 抗凝/抗血小板总表

| 药物 | 机制 | 最该记住的营养点 | 服药时间 |
|------|------|----------------|---------|
| 华法林 | 维K拮抗 | **维K稳定摄入**、维E/鱼油谨慎 | 固定时间（晚间）|
| 阿司匹林 | 抑血小板 | 胃肠道损伤、铁流失、限酒 | 餐后或固定 |
| 氯吡格雷 | 抑血小板（前药） | **奥美拉唑降效**（提醒医生）| 固定时间 |
| NOACs | 直接抑因子 | 维K无显著互作；利伐沙班随餐 | 按医嘱 |

### 2.5 降尿酸药（痛风治疗）

| 药物 | 机制 | 营养要点 | 服药时间 |
|------|------|---------|---------|
| 别嘌醇 | 抑黄嘌呤氧化酶 → 尿酸生成↓ | **多饮水**（促尿酸排出防结石）；罕见情况下可增加铁吸收（长期大剂量者留意铁状态） | 按医嘱 |
| 非布司他 | 选择性抑黄嘌呤氧化酶 | 多饮水；心血管风险人群医生评估 | 每日一次 |
| 苯溴马隆 | 促尿酸排泄 | **多饮水防结石**；肾功能不全慎用 | 按医嘱 |
| 秋水仙碱 | 抗炎、抑微管 | **急性期短期用；长期用可致B12吸收不良**；胃肠腹泻常见 | 按医嘱 |
| 非甾体抗炎药（痛风） | 抗炎止痛 | 胃肠道损伤风险（随餐、护胃）；与利尿剂/ACEI/ARB叠加伤肾 | 随餐 |

**痛风营养通用要点（营养师主打价值）：** 限嘌呤（动物内脏、浓肉汤、部分海鲜）、限酒（尤其啤酒）、限果糖饮料（果糖促尿酸生成）、限高果糖水果、充足饮水、控制体重、低脂奶/樱桃（部分研究提示有益）。**营养干预与药物并行的关键是：不能因为"在吃降尿酸药"就放开饮食。**

### 2.6 甲状腺药

#### 2.6.1 左甲状腺素（优甲乐、雷替斯）——"间隔服用"教科书级药物

| 项目 | 内容 |
|------|------|
| 机制 | 外源性补充甲状腺激素（T4） |
| 营养要点① | **晨起空腹服用**，服后至少30~60分钟再吃早餐（推荐留足1小时）|
| 营养要点② | **与钙、铁、镁、锌补充剂隔开至少4小时**（多价金属螯合影响吸收）|
| 营养要点③ | 高纤维食物、大豆制品、咖啡可能减少吸收 → 尽量固定在同一时段吃、错开 |
| 营养要点④ | 与抗酸药（铝镁）、硫糖铝隔开 |
| 服药时间 | **固定每天同一时间，晨起空腹为金标准** |
| 营养师提醒 | 吸收波动→甲功波动→剂量频繁调整，营养师可帮顾客做"服药-饮食"时间表；不要自行换品牌/剂型 |

#### 2.6.2 抗甲状腺药（甲巯咪唑、丙硫氧嘧啶）

| 项目 | 内容 |
|------|------|
| 机制 | 抑制甲状腺激素合成 |
| 营养要点 | 均衡营养；甲亢本身耗能高 → 治疗期注意充足能量与蛋白质；禁碘/低碘遵医嘱（医生定）|
| 营养师提醒 | 甲亢高代谢期会消耗B族、钙等，营养支持与治疗同步 |

### 2.7 糖皮质激素（泼尼松、甲泼尼龙、地塞米松）

| 项目 | 内容 |
|------|------|
| 机制 | 抗炎、免疫抑制；升血糖、促蛋白分解、促脂肪重分布、促水钠潴留、抑制骨形成 |
| 营养要点① | **骨钙流失 → 补钙（1000~1200mg/日）+ 维D（800~1000IU/日级别）** 是长期用激素的标准配合 |
| 营养要点② | **血糖↑ → 控糖**（尤其与降糖药合用者） |
| 营养要点③ | **蛋白分解 → 保证优质蛋白**（防肌肉流失/肌少症） |
| 营养要点④ | 食欲亢进、水钠潴留 → **控盐、控能量**防体重飙升 |
| 服药时间 | **晨服（早晨一次）顺应皮质醇节律、减少对肾上腺的抑制** |
| 营养师提醒 | **绝对不能自行骤停**（肾上腺危象风险）；长期用者骨质疏松防治是营养师最大发力点 |

### 2.8 骨质疏松药（双膦酸盐：阿仑膦酸钠、利塞膦酸钠）

| 项目 | 内容 |
|------|------|
| 机制 | 抑制破骨细胞活性 → 减少骨吸收 |
| 营养要点① | **晨起空腹白水送服，服后保持直立至少30分钟**（防食管刺激）|
| 营养要点② | 服后**至少30~60分钟再进食/服其他药**；与钙、铁、镁、铝（抗酸药）隔开 |
| 营养要点③ | 用双膦酸盐≠不补钙维D——**钙维D仍是基础治疗**（与药物错开时间）|
| 营养师提醒 | 顾客"吃这个药是不是就不用补钙了"是高频误解 → 明确：钙维D是地基，双膦酸盐是加固 |

## 三、药物导致营养素缺乏全表

> **核心机制（为什么药物会"偷"营养）：**
> ① **吸收竞争/螯合**——药物与营养素在肠道"抢通道"或结合成不溶物；
> ② **胃酸改变**——抑酸药让需要酸性环境吸收的营养素（B12、铁、钙）吸收↓；
> ③ **排泄增加**——利尿剂让电解质随尿跑掉；
> ④ **代谢加速**——肝酶诱导药让维D、叶酸分解加快；
> ⑤ **肠道菌群破坏**——抗生素让合成维K/B族的细菌减少。

### 3.1 药物导致营养素缺乏 · 全表（证据等级排序）

| 药物 | 耗损/干扰的营养素 | 影响强度 | 机制一句话 | 营养对策 |
|------|------------------|---------|-----------|---------|

| 二甲双胍 | 叶酸（可能） | 弱 | 部分研究 | 均衡摄入 |
| 质子泵抑制剂（PPI） | **B12** | 中-强（长期） | 胃酸↓→食物中B12释放/吸收↓ | 长期用监测；动物性B12来源 |
| PPI | **钙** | 中（长期） | 胃酸↓→碳酸钙吸收↓、骨折风险↑ | 保证钙摄入；柠檬酸钙可考虑 |

| 抗癫痫（苯妥英/卡马西平/苯巴比妥） | **叶酸、维D、钙** | 强 | 诱导肝酶→叶酸/维D分解↑ | 补叶酸、维D、钙（遵医嘱）|

### 3.2 重点药物逐条展开

#### 3.2.1 二甲双胍 → B12缺乏

- **人群：** 长期服用（多数研究认为>1年）、大剂量、老年人、素食者、合并胃肠疾病者风险更高。
- **表现：** B12缺乏早期可无症状；后可有疲劳、贫血、周围神经麻木/刺痛、认知下降——这些症状易与糖尿病神经病变混淆。
- **营养师行动：** 长期用二甲双胍的顾客，建议**定期（年度）查B12**；提示医生评估；饮食保证动物性B12来源（肉、蛋、奶、鱼）；如医生同意可考虑口服B12补充。**提醒：不要自行停二甲双胍。**

#### 3.2.2 PPI → B12、钙、铁、镁

- **人群：** 长期（>1年）、大剂量、老年、联合利尿剂（镁丢失叠加）风险更高。
- **表现：** B12缺乏（同上）；低镁（肌肉抽筋、震颤、心律不齐——需急诊就医的信号）；骨质疏松性骨折风险升高（机制包括钙吸收↓）。
- **营养师行动：** 长期用PPI者关注B12、钙、镁；骨健康人群保证钙维D；**是否换药/减量由医生定。**

#### 3.2.3 利尿剂 → 钾、镁、锌

- **噻嗪/袢利尿剂丢钾镁锌**，保钾利尿剂相反（高钾）。
- **营养师行动：** 富钾食物（香蕉、土豆、菠菜、豆类、深绿叶菜、橙子）适合**肾功能正常**者；肾功能不全者严禁自行补钾。镁主要来自坚果、全谷物、豆类、深绿蔬菜。**钾补充剂一律医生决定。**

#### 3.2.4 他汀 → CoQ10

- 胆固醇与CoQ10共享甲羟戊酸合成通路，他汀抑制HMG-CoA还原酶 → 可能降低CoQ10。
- 部分小型研究提示CoQ10补充可能缓解他汀相关肌痛，但证据尚不统一。
- **营养师行动：** 顾客肌痛先提醒**就医排查（肌病/横纹肌溶解虽少见但严重）**；如顾客已在医生知情下补充CoQ10，不反对；**不主动把CoQ10当"吃他汀必备"。**

#### 3.2.5 糖皮质激素 → 钙、维D、蛋白

- 长期用激素：骨吸收↑+骨形成↓ → 骨质疏松核心风险；蛋白分解 → 肌肉流失。
- **营养师行动：** 钙+维D是标准配合（很多指南推荐起始剂量：钙1000~1200mg/日、维D 800~1000IU/日，个体遵医嘱）；高蛋白饮食保护肌肉；限盐限糖。

#### 3.2.6 抗生素 → 菌群、维K、B族

- 广谱抗生素杀灭肠道合成菌 → 维K合成↓（尤其头孢类某些品种）、B族影响。
- **营养师行动：** 疗程结束（或与抗生素隔开2小时）补充益生菌；均衡B族；长期/反复用抗生素者留意维K（出血倾向立即就医）。

#### 3.2.7 口服避孕药 → 叶酸、B6、B12、镁

- 长期用OCP可能降低叶酸、B6、B12水平。
- **营养师行动：** 均衡饮食；备孕/早孕人群叶酸补充是常规（医生指导）。

#### 3.2.8 抗癫痫药 → 叶酸、维D、钙

- 苯妥英、卡马西平、苯巴比妥等诱导肝酶 → 叶酸、维D分解加速 → 骨软化、叶酸缺乏。
- **营养师行动：** 遵医嘱补叶酸、维D、钙；骨密度监测；维D补充剂量医生定（过高维D与苯妥英相互作用需监测）。

#### 3.2.9 泻药（长期） → 电解质、脂溶性维生素

- 刺激性泻药长期用 → 钾丢失、脂溶性维生素吸收不良。
- **营养师行动：** 劝阻长期依赖泻药；高纤、饮水、运动等自然通便策略；电解质异常（乏力、心悸）就医。

#### 3.2.10 其他高价值提醒

| 药物 | 耗损 | 一句话 |
|------|------|-------|
| 异烟肼 | B6 | 抗结核标准配伍即补B6（医生执行）|
| 秋水仙碱 | B12 | 长期预防用者注意B12 |
| 甲氨蝶呤 | 叶酸 | 需遵医嘱补充（通常与给药日错开的特定方案）|
| 别嘌醇 | 铁（罕见） | 大剂量长期者留意铁状态 |

### 3.3 营养师行动清单（用药顾客必问四件事）

1. **你在吃什么药？（列全）** —— 处方药+OTC+营养补充剂全列。
2. **吃多久了？** —— "长期"（>1年）是缺乏风险的分水岭。
3. **有没有这些症状？** —— 疲劳、贫血、手脚麻木、抽筋、骨痛、体重异常。
4. **最近的检查报告？** —— B12、电解质、血钙镁、25-(OH)D、骨密度。

> 若有对应缺乏信号 → **提醒就医复查，不自行开补充剂处方**。营养师的角色是"发现线索 + 营养支持方向 + 转介医生"。

## 四、食物与营养素影响药物

> 本章是"反过来"：食物/营养素怎么改变药效。营养师的价值在于**防住"悄悄失效"和"悄悄过量"**。

### 4.1 葡萄柚（西柚）与 CYP3A4 —— 最经典的"食物让药变毒"

| 项目 | 内容 |
|------|------|
| 机制 | 葡萄柚（及酸橙、柚子/文旦的部分品种）**不可逆抑制肠道CYP3A4** → 该酶代谢的药物浓度**成倍升高** → 药效过强甚至中毒 |
| 关键点① | 抑制作用**不可逆**，新酶需要约24~72小时再生 → **"隔开几小时吃"并不能消除风险** |
| 关键点② | 一小杯（约200ml）西柚汁就可能产生显著影响 |
| 关键点③ | 主要影响**肠道**CYP3A4 → 对"静脉注射药物"影响小；对口服、且主要靠肠道CYP3A4代谢的药物影响最大 |

**受葡萄柚影响的常见药物（营养师必记名单）：**

| 药物类别 | 代表药 | 风险级别 |
|---------|-------|---------|
| 他汀 | **辛伐他汀、洛伐他汀** | 高危（说明书黑框警示）|
| 他汀 | 阿托伐他汀 | 中危 |
| 钙拮抗剂 | **非洛地平、硝苯地平** | 高危（血压骤降风险）|
| 钙拮抗剂 | 氨氯地平 | 低-中危 |
| 镇静/催眠 | 咪达唑仑、三唑仑 | 中危 |
| 免疫抑制剂 | **环孢素、他克莫司** | 高危（浓度↑中毒）|
| 部分抗焦虑 | 丁螺环酮 | 中危 |
| 部分抗过敏（旧） | 特非那定（已少用） | 高危（心律失常，曾致退市）|

**营养师话术：** "吃这些药期间，西柚（葡萄柚）、柚子这类水果最好整个别碰，不是隔开几小时就行。"——不确定时，查药品说明书"相互作用"栏。

### 4.2 维生素K ↔ 华法林

| 项目 | 内容 |
|------|------|
| 机制 | 华法林通过抑制维K循环而抗凝；**食物维K升高→抗凝效果下降**（INR↓）|
| 正确姿势 | **不是"不能吃绿叶菜"，而是"稳定摄入"**：保持维K摄入量每天差不多，别今天不吃、明天吃一大盘 |
| 高维K食物 | 菠菜、羽衣甘蓝、西兰花、芥蓝、卷心菜、生菜、动物肝脏、某些植物油（大豆油、菜籽油）|
| 营养师提醒 | 顾客突然想"多吃菜养生"或"开始喝羽衣甘蓝汁/做青汁" → 提醒先咨询医生并增加INR监测；**不要因维K问题劝顾客戒掉绿叶蔬菜** |

### 4.3 钙 ↔ 左甲状腺素 / 抗生素

| 组合 | 问题 | 间隔 |
|------|------|------|
| 钙（补充剂/高钙食物）+ 左甲状腺素 | 钙螯合左甲状腺素 → 吸收↓ | **至少4小时** |
| 钙 + 喹诺酮类（左氧氟沙星、环丙沙星） | 螯合 → 两者吸收都↓ | 至少2小时（部分说明书4~6小时）|
| 钙 + 四环素类（多西环素、米诺环素） | 螯合 | 至少2~4小时 |
| 钙 + 双膦酸盐 | 螯合 + 影响药物吸收 | 至少1小时以上 |
| 钙 + 铁剂 | 竞争吸收 | 错开（不同时服）|

> **注意：** 奶制品（酸奶、牛奶）也含高钙——吃四环素/喹诺酮时，**别用牛奶送药**，间隔2小时以上再喝奶。

### 4.4 铁剂 ↔ 药物

| 组合 | 问题 | 间隔 |
|------|------|------|
| 铁 + 左甲状腺素 | 螯合→吸收↓ | 至少4小时 |
| 铁 + 喹诺酮/四环素 | 螯合 | 至少2~4小时 |
| 铁 + 双膦酸盐 | 螯合 | 至少2小时 |
| 铁 + 钙/镁/锌补充剂 | 竞争吸收 | 错开 |
| 铁 + 咖啡/茶/红酒 | 鞣酸、茶多酚抑铁吸收 | 隔开1~2小时 |
| 铁 + 维生素C | **促进铁吸收** | 同服有利（缺铁者）|

**铁剂服用小贴士：** 空腹吸收最好但胃肠刺激；随餐可耐受但吸收打折；维C促进、茶咖啡抑制；**便秘**是常见副作用 → 纤维、饮水、活动。

### 4.5 高纤维 ↔ 药物

| 项目 | 内容 |
|------|------|
| 机制 | 高纤维（膳食纤维补充剂如洋车前子、麸皮）可吸附药物、缩短肠转运时间 → 药物吸收↓ |
| 受影响药物 | 左甲状腺素、部分他汀、地高辛、阿司匹林等 |
| 间隔 | 纤维补充剂与其他药**隔开1~2小时** |
| 营养师提醒 | **膳食来源的纤维（蔬菜水果全谷物）通常无需担心**，主要提醒的是"纤维补充剂/冲剂"与药物同服的场景 |

### 4.6 酒精 ↔ 药物

| 药物 | 酒精相互作用 | 后果 |
|------|------------|------|
| 降糖药（磺脲/胰岛素） | 酒精抑制糖异生 | **严重低血糖**（尤其空腹饮酒）|
| 镇静催眠/抗焦虑 | 中枢抑制协同 | 嗜睡、呼吸抑制 |
| 止痛药（阿片类） | 中枢抑制 | 呼吸抑制风险 |
| 对乙酰氨基酚 | 慢性饮酒者肝毒性↑ | 急性肝损伤 |
| 甲硝唑、头孢类（部分） | 双硫仑样反应 | 面红、心悸、恶心（**服药期间禁酒**）|
| 华法林 | 影响INR + 伤肝 | 出血/血栓波动 |
| NSAIDs | 胃黏膜损伤叠加 | 胃出血 |

**营养师话术：** "喝酒要看你吃的药。降糖药、安眠药、止痛药、部分抗生素，喝酒不是'少喝点'的问题，是**最好别喝**——具体问医生/药师。"

### 4.7 高脂餐 ↔ 药物

| 影响方向 | 例子 |
|---------|------|
| 脂溶性药物吸收↑ | 某些脂溶性维生素、灰黄霉素、异维A酸（随高脂餐吸收更好）|
| 某些药吸收↓ | 部分抗生素、双膦酸盐 |
| 时间窗意义 | 有些药说明书要求"随餐/随脂肪餐"或"空腹"，按说明书执行 |

**营养师应用：** 看说明书"空腹/随餐"标注；**不确定时，向顾客强调"按医生/药师/说明书的时间服药"，并保持每天固定**。

### 4.8 圣约翰草（贯叶金丝桃）—— "营养素让药失效"的典型

| 项目 | 内容 |
|------|------|
| 机制 | 强效诱导CYP3A4（及P-糖蛋白）→ 许多药物代谢加速 → 血药浓度骤降 |
| 受影响药物 | 口服避孕药（突破性出血/避孕失败）、环孢素（移植物排异）、华法林、他汀、免疫抑制剂、部分抗抑郁药、地高辛等 |
| 特点 | **在OTC草本补充剂中很常见，顾客常不自知在吃** |
| 营养师提醒 | 问诊时**主动问"有没有在吃什么中草药/草本补充剂"**；圣约翰草与SSRI抗抑郁药同服还有"5-羟色胺综合征"风险 |

### 4.9 酪胺 ↔ MAOI（单胺氧化酶抑制剂）

| 项目 | 内容 |
|------|------|
| 机制 | MAOI抑制酪胺分解 → 富酪胺食物使去甲肾上腺素释放↑ → **高血压危象**（头痛、心悸、脑出血风险）|
| 高酪胺食物 | 陈年奶酪、发酵/腌制/风干肉类（香肠、腊肉）、酱油/豆酱、酸菜、腐乳、部分啤酒/红酒、酵母提取物 |
| 营养师提醒 | 虽然MAOI如今少用，但遇到时是**红线级提醒**：避开上述食物 |

### 4.10 其他值得记住的食物-药物相互作用

| 组合 | 机制/后果 | 营养师提醒 |
|------|----------|-----------|
| 甘草（甘草糖、部分凉茶/草本茶） | 甘草酸促排钾 → 低钾 → 增加地高辛毒性、与利尿剂/激素叠加低钾 | 长期大量含甘草制品+利尿剂者关注低钾 |
| 咖啡因 + 部分药物 | 咖啡因增强部分镇痛药作用；与茶碱类叠加 → 心悸失眠 | 用量与时间合理 |
| 维生素C + 含铝抗酸药 | 维C促铝吸收 | 错开服用 |
| 高钾食物 + ACEI/ARB/保钾利尿剂 | 血钾叠加升高 | 肾功能不全者尤其注意 |
| 蔓越莓/酸果蔓汁 + 华法林 | 部分报道影响INR（证据不一）| 大量食用前咨询医生 |
| 牛油果/豆制品（高钾） + 保钾利尿剂 | 高钾 | 肾功能不全者注意 |

## 五、"间隔服用"通用规则

> 营养师给顾客最实用的一张表。原则：**同一吸收通道的"药物 vs 营养素"，用时间把它们隔开。**

### 5.1 核心间隔表

| 组合 | 间隔 | 原因 |
|------|------|------|
| 左甲状腺素（优甲乐） ↔ 钙片 | **至少4小时** | 螯合 → 优甲乐吸收↓ |
| 左甲状腺素 ↔ 铁剂 | 至少4小时 | 螯合 |
| 左甲状腺素 ↔ 镁/锌/铝（抗酸药） | 至少4小时 | 螯合 |
| 左甲状腺素 ↔ 高钙食物（牛奶、酸奶）| 至少1小时（最好是4小时）| 螯合 |
| 左甲状腺素 ↔ 咖啡/茶 | 至少1小时 | 咖啡因影响吸收 |
| 钙片 ↔ 喹诺酮/四环素类抗生素 | 至少2小时 | 螯合，抗生素失效 |
| 铁剂 ↔ 喹诺酮/四环素类抗生素 | 至少2小时（理想4小时）| 螯合 |
| 益生菌 ↔ 抗生素 | 至少2小时 | 抗生素会杀益生菌 |
| 钙/铁/镁/锌 ↔ 双膦酸盐（骨质疏松药）| 至少1~2小时 | 影响吸收 + 食管刺激 |
| 高纤维补充剂（洋车前子） ↔ 其他药 | 1~2小时 | 吸附药物 |
| 铁剂 ↔ 咖啡/茶/牛奶 | 1~2小时 | 抑制铁吸收 |
| 钙/铁/镁 ↔ 彼此 | 错开1~2小时 | 竞争吸收 |
| 葡萄柚/西柚 ↔ CYP3A4代谢药物 | **整个疗程避免** | 不可逆抑制，隔开无效 |

### 5.2 为什么要间隔（一句话机制）

- **螯合/结合：** 钙铁镁锌铝等金属离子与药物结合成"不溶复合物"，谁也吸收不了 → 所以"隔开"。
- **吸收竞争：** 同类转运通道，同时来谁都进不去。
- **胃酸依赖：** 抑酸药让胃酸环境改变，需要酸性吸收的营养素（铁、钙、B12）受损 → 时间上错开给药时机。
- **酶抑制不可逆：** 葡萄柚对CYP3A4的抑制不是"隔开就好"，所以是"避免"而非"间隔"。

### 5.3 常见错误与纠正

| 顾客常见做法 | 问题 | 营养师纠正 |
|------------|------|-----------|
| "优甲乐和钙片一起吃，反正都是早上" | 吸收大打折扣、甲功波动 | 优甲乐晨起空腹，钙片挪到午餐/晚餐时，隔≥4小时 |
| "抗生素配牛奶喝，护胃" | 牛奶钙螯合抗生素 → 药效↓ | 用白水送药，喝奶与服药隔2小时 |
| "吃抗生素时也吃益生菌" | 益生菌刚吃下就被杀 | 隔开≥2小时，或抗生素疗程结束再补 |
| "他汀和西柚汁一起" | 浓度↑中毒风险 | 整个疗程避免西柚 |
| "铁剂和钙片一起补" | 互相抢吸收 | 错开：铁随维C吃，钙换到另一餐 |
| "用茶送铁剂" | 鞣酸抑铁吸收 | 用白水+维C助吸收 |

### 5.4 给药时机总表（晨起 / 餐前 / 随餐 / 餐后 / 睡前）

| 时机 | 典型药物 | 原因 | 营养师配合 |
|------|---------|------|-----------|
| **晨起空腹** | 左甲状腺素、双膦酸盐 | 吸收最好、防食管刺激 | 空出30~60分钟再吃早餐 |
| **晨起（白天利尿）** | 利尿剂、多数降压药 | 利尿剂防夜尿；降压匹配晨峰 | 晨服利尿剂者补钾镁食物安排在正餐 |
| **餐前30~60分钟** | PPI（奥美拉唑）、部分磺脲（格列吡嗪）| PPI需酸环境时前服；磺脲提前促分泌 | 提醒"提前吃再吃饭" |
| **随餐/第一口饭** | 阿卡波糖、二甲双胍（随餐）、格列奈（餐前即刻）| 随餐减胃肠刺激/匹配碳水 | 阿卡波糖提醒"嚼碎随第一口饭" |
| **餐后** | 阿司匹林、NSAIDs、部分补铁不耐受者 | 减胃肠刺激 | 阿司匹林餐后+护胃 |
| **睡前** | 辛伐他汀/洛伐他汀、部分钙片（补骨方案）| 胆固醇夜间合成峰；钙片分次 | 睡前他汀与晚餐/补剂错开 |
| **固定每天同一时间** | 华法林、优甲乐、大部分慢病药 | 浓度稳定 | 帮顾客做"每日服药-进餐时间表" |

## 六、营养补充剂与药物相互作用

> 顾客常常同时吃**多种营养素/补充剂 + 多种药**。营养师的核心职责是"排雷"。

### 6.1 补充剂-药物相互作用详表

| 补充剂 | 与药物的相互作用 | 风险场景 | 营养师建议 |
|--------|----------------|---------|-----------|
| **鱼油（高剂量）** | 增强抗血小板/抗凝 → 出血 | 华法林、NOAC、阿司匹林、氯吡格雷；手术前后 | 正在抗凝者用鱼油前咨询医生；一般≤3g/日EPA+DHA较稳妥（医生定）|
| **维生素E（高剂量）** | 抗凝增强、出血 | 华法林（>400~800IU/日风险↑）| 不推荐高剂量维E补剂；靠食物油脂获取 |
| **大蒜提取物** | 抗血小板/抗凝 → 出血 | 抗凝药、抗血小板药；手术前 | 手术前停；与抗凝药同用需医生评估 |
| **银杏** | 抗血小板 → 出血 | 阿司匹林、华法林、NSAIDs | 与抗凝/抗血小板药同用风险高 → 提醒 |
| **姜黄素（高剂量）** | 可能影响抗凝、部分药物代谢 | 华法林等 | 高剂量（如数克/日）提取物需谨慎；烹饪用量通常安全 |
| **人参** | 影响抗凝、可能影响血糖/血压、与MAOI/兴奋剂相互作用 | 华法林、降糖药 | 与慢病药同用需医生评估 |
| **钙** | 螯合 → 药物吸收↓ | 优甲乐（4h）、喹诺酮/四环素（2h）、双膦酸盐 | 间隔规则见第五章 |
| **铁** | 螯合 → 药物吸收↓ | 优甲乐、喹诺酮/四环素、双膦酸盐 | 间隔4h（优甲乐）/2h（抗生素）|
| **镁** | 螯合 → 药物吸收↓ | 喹诺酮/四环素、双膦酸盐、优甲乐 | 间隔2~4h；肾功能不全者高镁风险 |
| **锌** | 螯合；影响铜吸收 | 抗生素、优甲乐；长期大剂量锌→铜缺乏 | 间隔2~4h；锌不长期超量 |
| **钾补充剂** | 血钾叠加 → 高钾 | ACEI/ARB、保钾利尿剂；肾功能不全 | **绝不自行补钾**，尤其肾衰者（见6.2）|
| **维生素D** | 与噻嗪类利尿剂合用 → 高钙（罕见）| 大剂量维D + 噻嗪 + 高钙摄入 | 常规剂量维D与噻嗪通常安全；大剂量需医生 |
| **辅酶Q10** | 可能轻度影响华法林 | 华法林 | 用华法林者加CoQ10需医生监测INR |
| **膳食纤维补充剂** | 吸附药物 → 吸收↓ | 优甲乐、他汀、地高辛 | 与其他药隔1~2h |
| **圣约翰草** | 诱导CYP3A4 → 药物失效 | 避孕药、免疫抑制剂、他汀、华法林、抗抑郁药 | 见4.8，风险极高 → 提醒 |
| **蛋白粉/乳清蛋白** | 高蛋白饮食可影响左旋多巴吸收；蛋白餐影响部分药物 | 左旋多巴 | 左旋多巴与高蛋白餐错开（医生指导）|

### 6.2 安全原则（营养师给顾客的三条铁律）

1. **先问医生/药师再叠加**：顾客在用药时，加**任何**营养素/补充剂前，先让医生/药师过目——尤其抗凝、抗癫痫、免疫抑制、甲状腺、心衰用药人群。
2. **手术前2周停"活血"类补充剂**：
   - 鱼油（高剂量）、维生素E（高剂量）、大蒜提取物、银杏、人参、丹参、当归、川芎等活血/抗凝类。
   - **标准话术：** "如果你要手术（包括拔牙、胃肠镜），提前两周把这些补剂停掉，并且告诉医生你在吃什么。"
3. **不超UL上限**：见6.3表。"更多不是更好"，脂溶性维生素和矿物质超量会蓄积中毒。

### 6.3 常用营养素可耐受最高摄入量（UL，成人参考）

| 营养素 | UL（成人每日） | 营养师提醒 |
|--------|---------------|-----------|
| 维生素D | 2000 IU（中国） | 大剂量维D处方除外（医生定）|
| 维生素E | 800 mg（α-生育酚当量）| 高剂量易出血 |
| 叶酸 | 1000 μg（合成补充剂）| 大剂量掩盖B12缺乏 |
| 铁 | 42 mg（中国成人） | 过量伤肝，血色病者禁 |
| 锌 | 40 mg | 长期大剂量→铜缺乏、免疫抑制 |
| 硒 | 400 μg | 过量脱发、指甲变脆 |

| 钙 | 2000 mg | 过量肾结石/高钙 |

## 七、药物营养相关副作用的营养支持方向

> 营养师**不处理药物副作用**，但可以提供**对症的营养支持方向**，缓解不适、辅助营养状态。

### 7.1 药物营养相关副作用 → 营养支持方向大表

| 药物 | 常见副作用 | 营养支持方向 | 注意/红线 |
|------|-----------|------------|----------|
| 二甲双胍 | 胃肠不适、腹泻 | 随餐服；少食多餐；避免高脂油炸同餐 | B12监测；持续腹泻就医 |
| 二甲双胍 | B12↓（长期） | 见第三章 | 医生评估补B12 |
| 他汀 | 肌痛、乏力 | 肌肉不适就医排查；CoQ10（医生知情下）| 不能自行停药 |
| 利尿剂 | 低钾、乏力 | 富钾食物（肾功正常者）：香蕉、土豆、豆类、深绿菜 | 肾衰者禁；补钾药医生定 |
| 利尿剂 | 低镁 | 坚果、全谷、豆类、深绿菜 | 症状（抽筋/心悸）就医 |
| 糖皮质激素 | 食欲亢进、水钠潴留 | 控盐（<5g/日）、控糖、定时定量餐 | 防暴食；体重管理 |
| 糖皮质激素 | 骨钙流失 | 钙+维D、负重运动、优质蛋白 | 见2.7 |
| 阿司匹林/NSAIDs | 胃部不适、隐血 | 餐后服、护胃饮食（温和少刺激）| 黑便/呕血急诊；铁状态 |
| 阿片类止痛药 | 便秘 | **高纤+足量水+活动**（纤维+水同时给否则加重）| 排便困难超3天就医 |
| 抗抑郁药（部分）| 体重增加 | 定时餐、控能量、高蛋白饱腹感 | 不自行停药 |
| 抗抑郁药（部分）| 口干 | 少量多次饮水、无糖润喉 | 蛀牙风险注意口腔 |
| 化疗药 | 恶心、食欲差 | 少食多餐、清淡、生姜/薄荷辅助、避免油烟 | 体重骤降就医/营养科 |
| 化疗药 | 黏膜炎、味觉改变 | 温凉软食、高蛋白、避免辛辣酸烫 | 必要时肠内营养 |
| 抗生素 | 腹泻 | 补水电解质、益生菌（隔2h）、BRAT清淡饮食 | 血便/高热就医 |
| 抗生素 | 菌群失衡 | 疗程后益生菌 | 长期用注意维K |
| PPI | 长期低镁/低B12 | 见第三章 | 监测 |
| 降压药 | 体位性低血压（α阻滞剂、利尿剂）| 缓慢起身、充足饮水、盐按医嘱（勿自行增盐）| 晕厥就医 |
| 抗癫痫药 | 骨代谢异常 | 维D、钙 | 骨密度监测 |
| 激素避孕药 | B族可能↓ | 均衡B族 | — |
| 秋水仙碱 | 腹泻 | 清淡、补水 | 剧烈腹泻就医 |

### 7.2 高价值场景展开（营养师最常被问到的）

#### 7.2.1 阿片类便秘

- **机制：** 阿片激动肠μ受体 → 肠蠕动↓、肠道分泌↓、肛门括约肌张力↑。
- **营养支持：** 纤维 + 水分必须**同时**增加（只加纤维不加水会加重梗阻）；西梅/西梅汁、火龙果等；规律活动；**排便困难、腹痛、呕吐需就医。**
- **红线：** 慢性便秘者加纤维前确认无肠梗阻风险；不要推荐任何"通便营养素"当药。

#### 7.2.2 化疗/放疗的食欲与黏膜支持

- 少食多餐（每日5~6小餐）；高蛋白高能量（瘦肉、鱼、蛋、奶、豆）；温凉软食减少黏膜刺激；避免辛辣、过酸、过烫；口腔溃疡时避免粗糙食物。
- **红线：** 体重明显下降、无法进食时，转介医生/临床营养师（肠内营养支持）。

#### 7.2.3 激素性食欲亢进

- 定时定量三餐 + 计划性加餐，避免"饿到失控"；高蛋白/高纤增加饱腹；控盐控糖；正念进食。
- **红线：** 血糖异常者配合监测，不自行调整降糖药。

#### 7.2.4 利尿剂低钾

- 富钾食物（肾功能正常者）：香蕉、橙子、土豆（连皮）、菠菜、西兰花、豆类、南瓜。
- **红线：** 肾功能不全、同时用ACEI/ARB/保钾利尿剂者**不要自行多补钾**——低钾/高钾都可能致命，交由医生判断。

### 7.3 营养师可给的支持 vs 红线

| ✅ 可以做 | ❌ 不能做 |
|----------|----------|
| 指出副作用对应的营养方向 | 让顾客停药/减药 |
| 提醒监测项目（B12、电解质、骨密度）| 开补充剂"处方"并替代医生判断 |
| 建议"问医生可不可以查/补" | 用营养素宣称"治好"药物副作用 |
| 帮助做"服药-进餐-补充剂"时间表 | 承诺营养素替代药物疗效 |

## 八、营养师工作话术

> 目标：**说得专业、说得安全、顾客听得懂、不越界。** 每个场景给"一句话话术"。

### 8.1 按药物场景话术表

| 场景 | 营养师话术（可直接说） |
|------|---------------------|
| 顾客吃**二甲双胍** | "长期吃二甲双胍，要留意维生素B12，建议定期查一下；这药随餐吃能减轻胃肠不舒服。停药的事问医生。" |
| 顾客吃**他汀** | "吃他汀期间别碰西柚（葡萄柚）；有些人会关注辅酶Q10，可以问医生要不要补。肌肉酸痛要及时跟医生说，不要自己停药。" |
| 顾客吃**华法林** | "绿叶菜可以吃，但要保持稳定量，别今天不吃明天吃一大盘；加任何补剂（维E、鱼油、大蒜、银杏）前一定先问医生。" |
| 顾客吃**阿司匹林** | "饭后吃能少伤胃；长期吃要关注有没有贫血（隐血丢铁），胃不舒服或大便发黑要马上看医生。" |
| 顾客吃**优甲乐（左甲状腺素）** | "优甲乐晨起空腹吃，吃完至少半小时到一小时再吃早饭；钙片铁片和它要隔开4小时，放在午饭或晚饭时吃。" |
| 顾客吃**降压利尿剂** | "利尿药容易丢钾，肾功能正常的话香蕉、土豆、豆类可以多吃；如果在吃保钾药或沙坦/普利类，补钾的事一定要问医生。" |
| 顾客吃**糖皮质激素** | "长期用激素要注意补钙和维生素D，配合优质蛋白，控盐控糖；不能自己突然停药，会很危险。" |
| 顾客吃**抗生素** | "钙片铁片和抗生素要隔开2小时；益生菌也要和抗生素隔开2小时以上，或等吃完药再补。" |
| 顾客吃**PPI抑酸药** | "长期吃奥美拉唑这类药，要留意B12、钙、镁；如果出现抽筋、心慌、手脚麻木，及时就医。" |
| 顾客吃**抗癫痫药** | "这类药长期用要注意叶酸、维生素D和钙，骨密度要定期查；具体补什么、补多少问医生。" |
| 顾客吃**降糖药（磺脲/胰岛素）** | "这类药一定要规律吃饭，别漏餐，尤其不要空腹喝酒（会低血糖）；包里可以放两块糖应急。" |
| 顾客**手术前** | "手术前两周，鱼油、维生素E、大蒜、银杏、人参这些活血类的先停一停，并且把你在吃的药和补剂都告诉医生。" |
| 顾客**问能不能加补剂** | "你在吃的药比较多，加任何补剂前最好让医生或药师过目一下，尤其是抗凝药、抗癫痫药、甲减药、心衰药这几类。" |
| 顾客**想停某种药** | "药能不能停、能不能减，一定要医生来判断，很多药骤停有风险（比如激素、降压药、抗癫痫药）。营养上我们可以帮你把方案做稳，但停药请遵医嘱。" |

### 8.2 通用沟通三原则

1. **先问清楚用药史再开口**：问"在吃什么药（含OTC和补剂）？吃多久了？"，不看药单不谈营养方案。
2. **用"提醒"不用"建议停药/加药"**：话术落点是"建议查一下/问医生/隔开吃/稳定量"，而不是"你该补X/你该停Y"。
3. **给可执行的时间表**：把"隔4小时""晨起空腹""随第一口饭"变成具体的一天安排，顾客才记得住、做得到。

### 8.3 红线清单（营养师绝对不说的）

| ❌ 不说 | 为什么 |
|---------|-------|
| "这个药你别吃了/减半吃" | 越界，停药风险 |
| "吃这个营养素就能把药停了" | 误导，替代治疗 |
| "你按我说的剂量补" | 越界，补充剂量医生定 |
| "评论区/私信把你的体检报告发我，我帮你分析" | 引导问诊，视频号合规红线 |
| "加微信领资料教你调理" | 平台外引流，合规红线 |
| "这个营养素治你的病" | 功效宣称，违规 |

### 8.4 一句话记忆卡（给营养师自己背）

```
药别停 → 先问医生
补别滥 → 先问医生
钙铁镁锌螯合 → 隔开2~4小时
西柚 → 整个疗程避免
优甲乐 → 晨起空腹，钙铁隔4小时
华法林 → 绿叶菜稳定量，补剂先问医生
利尿剂 → 补钾先看肾功能
激素 → 不能骤停，补钙维D
手术前 → 提前2周停活血类补剂
```

## 九、边界与免责声明

### 9.1 边界声明

- 本文是**营养工作者的用药常识参考**，不是用药指导、不是处方建议、不是药品说明书替代品。
- 所有药物剂量、用法、停用、调整、监测，一律以**医生/药师**为准。
- 营养师的角色：**识别线索（药物可能耗损的营养素）→ 提供营养支持方向 → 提醒就医/咨询医生 → 帮助建立"服药-进餐-补充剂"时间表。**
- 营养素的补充与否、补充剂量，在用药背景下需医生/药师评估（尤其抗凝、抗癫痫、甲减、心衰、肾功能不全人群）。

### 9.2 营养师三问自查（每次开口前）

1. **我说的是"营养支持方向"，还是在"指导用药/停药"？** → 后者立即打住。
2. **我推荐的补充剂，顾客正在用的药有没有相互作用风险？** → 不确定就先问医生。
3. **我的建议有没有把医生/药师放在"最终决定者"的位置？** → 没有就补上。

### 9.3 何时必须转介医生/药师

| 信号 | 动作 |
|------|------|
| 顾客想停药/减药/换药 | 转介医生 |
| 顾客要加补充剂但正在用抗凝/抗癫痫/甲减/心衰药 | 建议先咨询医生/药师 |
| 顾客出现药物副作用症状（出血、抽筋、心慌、严重腹泻、低血糖）| 建议立即就医 |
| 顾客肾功能不全/透析 | 所有钾镁磷补剂免谈，转介医生 |
| 顾客要手术/拔牙/胃肠镜 | 提醒术前停活血类补剂 + 告知医生 |
| 顾客怀孕/备孕/哺乳 | 转介医生/药师 |

> **结语：** 药学基础对营养师不是"背药名"，而是**建立一张"药物↔营养素"的风险地图**——知道哪些药会耗损什么营养、哪些食物/补充剂会干扰什么药、什么时间该隔开。把这套地图装进日常问诊，就是营养师在慢病管理中不可替代的价值：**帮顾客把每一粒药和每一口饭，都安排在正确的时间。**

> ⚠️ **再强调一次边界：** 本文所有内容仅作营养工作者的用药常识参考，**不构成用药建议**。个体用药、停药、剂量调整、营养素补充请在**医生/药师**指导下进行。
