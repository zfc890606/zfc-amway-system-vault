# 📚 营养专业书籍总览

> **用途：** AI营养师张医生的个人专业书库。把大学营养学 + 医学基础 + 药学基础三大知识块，按专业教材体系整理成一本"随时可查的专业手册"。
>
> **定位：** 服务「AI营养师」身份——给顾客讲营养慢病解决方案时，讲得出专业依据；给伙伴讲知识体系时，拿得出系统框架。
>
> **四大板块：** ① 基础知识库（底层学科）→ ② 营养学（核心专业）→ ③ 医学基础（临床语境）→ ④ 药学基础（药物与营养交叉）

## 如何用这套书库

### 三种用法

| 场景 | 查什么 |
|------|--------|
| **给顾客讲营养方案** | 11.07慢性病营养管理 + 11.01营养学基础 + 12.06化验解读 |
| **给伙伴讲知识体系** | 11.00营养学总览 + 10基础知识库 + 11.03膳食指南 |
| **专业深造/答疑** | 12医学基础全套 + 13药学基础 + 11.06临床营养 |

### 阅读路径（推荐顺序）

```
第一步：10 基础知识库 → 补化学/细胞/统计底子
   │
   ▼
第二步：11.01 营养学基础 → 营养学最核心（营养素+能量代谢）
   │
   ▼
第三步：11.02 食物营养学 → 营养素落回食物
   │
   ▼
第四步：11.03 膳食指南与DRIs → 落到中国人的吃法
   │
   ▼
第五步：11.04~11.09 → 人群/公共/临床/慢病/食安/药食同源
   │
   ▼
第六步：12 医学基础 → 补人体运转原理（解剖→生理→生化→病理→免疫→化验）
   │
   ▼
第七步：13 药学基础 → 药物与营养的交叉
```
