# 12.06 · 诊断学与化验解读（书本级详解）

> **一句话定位：** 给顾客看体检报告、评估营养状况时"读仪表盘"的能力——体格检查基本功 + 化验单系统解读。给顾客看报告、评估营养缺口、制定饮食对策时，用这一套"仪表盘"知识把每一条异常指标翻译成听得懂的行动。
>
> **⚠️ 三条边界（必须刻在脑子里）：**
> 1. **解读 ≠ 诊断**——营养师做的是"营养评估辅助"，不是临床诊断；异常指标一律建议就医确诊。
> 2. **以报告单参考范围为准**——本文所有参考范围是"通用大致值"，各医院检验科方法学不同，数值有差异，**永远以报告单上标注的参考范围为准**。
> 3. **不引导问诊**——不收集顾客病情做"线上诊断"，话术只做健康科普与生活方式层面的营养建议。

# 一、诊断学概览

## 1.1 诊断三件套：医生怎么"读人"

诊断学是临床医学的入口学科。医生诊断一个病人，靠的是三样东西的组合：

| 方法 | 内容 | 营养师视角的对应物 |
|------|------|---------------------|
| **问诊** | 症状、病史、生活史、家族史 | 饮食问卷 + 生活方式访谈 |
| **体格检查** | 视、触、叩、听 | 皮肤/指甲/眼/口腔观察 + 人体测量 |
| **辅助检查** | 化验、影像、功能检查 | 体检报告单解读 |

> **营养师的角色差异：** 医生用这三件套去"找病"（定诊断），营养师用同样的信息去"找缺口"（定营养干预方向）。同一个指标，医生问"这是什么病"，营养师问"这提示什么营养问题、饮食上怎么帮"。**但两者的边界必须清晰：营养师不替医生下诊断。**

## 1.2 问诊要点（营养师版）

问诊是获取信息成本最低、信息量最大的第一步。营养师做营养评估时，重点问这几块：

### 1.2.1 体重与体型变化（关键中的关键）

| 问什么 | 为什么问 | 可能的营养指向 |
|--------|---------|----------------|
| 近 3~6 个月体重变化多少 | 体重是营养状况的"总仪表" | 快速下降→热量/蛋白不足或疾病消耗；快速上升→热量过剩 |
| 变化是主动还是被动 | 区分自主减重与病理性消瘦 | 被动下降→需警惕，建议就医 |
| 近 1 个月体重变化 | 短期趋势比单点体重更敏感 | 1月内>5%下降→营养风险 |
| 衣服/裤腰松紧 | 比体重秤更真实 | 腹型肥胖判断线索 |
| 是否有意节食/偏食 | 了解摄入缺口 | 素食/节食→B12、铁、蛋白风险 |

> **记忆口诀：** "主动降是战果，被动降是警钟，先看趋势再看点。"

### 1.2.2 食欲与消化

| 问什么 | 为什么问 | 可能的营养指向 |
|--------|---------|----------------|
| 食欲好不好 | 摄入量的基础 | 食欲差→热量蛋白摄入不足 |
| 有无早饱（吃一点就胀） | 胃排空/腹胀 | 早饱→蛋白不足、消化功能弱、或疾病信号 |
| 有无恶心/反酸/烧心 | 上消化道问题 | 反酸→注意减重、清淡、少刺激 |
| 腹泻/便秘/大便形状 | 吸收与菌群 | 慢性腹泻→吸收不良→多种微量营养缺乏 |
| 有无腹胀/排气多 | 菌群/乳糖/膳食纤维 | 胀气→膳食纤维骤增、乳糖不耐、菌群失调 |
| 便血/黑便/大便变细 | **警示信号** | → 建议立即就医，不在营养范畴内处理 |

> **⚠️ 红旗信号（营养师立即建议就医，不处理）：** 不明原因体重骤降、黑便、便血、吞咽困难、持续呕吐、严重贫血。

### 1.2.3 睡眠、压力与运动

| 问什么 | 为什么问 | 可能的营养指向 |
|--------|---------|----------------|
| 睡眠时长与质量 | 皮质醇/食欲激素 | 睡不好→食欲素乱、易胖、血糖波动 |
| 压力水平（工作/家庭） | 慢性应激 | 高压→皮质醇↑→腹部脂肪、血压、血糖 |
| 运动频率/类型 | 消耗与合成 | 久坐→肌肉流失、胰岛素敏感性下降 |
| 烟酒习惯 | 肝脏/代谢 | 酗酒→脂肪肝、GGT↑、B族缺乏 |

### 1.2.4 用药史（影响营养的常见药物）

| 药物类别 | 常见药物 | 营养影响 |
|----------|----------|----------|
| 二甲双胍 | 降糖药 | 长期用→B12吸收下降 |
| 质子泵抑制剂 | 奥美拉唑等 | 抑酸→B12、钙、铁、镁吸收下降 |
| 利尿剂 | 呋塞米等 | 丢钾、丢镁 |
| 糖皮质激素 | 泼尼松等 | 钙流失、血糖↑、肌肉流失 |
| 他汀类 | 降脂药 | 部分人辅酶Q10、维生素D受影响 |
| 华法林 | 抗凝药 | 维生素K摄入需稳定（富含K食物勿骤变） |
| 抗生素 | 长期/反复 | 肠道菌群破坏→注意补充益生菌/纤维 |
| 甲状腺药物 | 优甲乐等 | 服药与补铁/补钙需错开时间 |

> **行动：** 问一句"现在在吃什么药"就行，别硬背表——知道"药会影响营养"这个意识，比记住每一条更重要。具体用药建议由医生/药师给出。

### 1.2.5 家族史（慢病风险画像）

| 家族史 | 提示风险 | 营养预防方向 |
|--------|----------|--------------|
| 糖尿病（父母/兄弟姐妹） | 2型糖尿病风险↑ | 控制腰围、控糖控精制碳水、增肌 |
| 高血压/脑卒中 | 高血压风险↑ | 限钠、补钾、DASH饮食 |
| 血脂异常/冠心病 | 动脉粥样硬化风险↑ | 控饱和脂肪/反式脂肪、增膳食纤维 |
| 痛风 | 高尿酸风险↑ | 限嘌呤、限酒、控果糖 |
| 骨质疏松 | 骨量流失风险↑ | 钙+维D+蛋白+负重运动 |
| 肿瘤（尤其消化系/乳腺） | 相关风险↑ | 抗炎饮食、控体重、限酒 |

> **要点：** 家族史决定"预防的优先级"，不是"注定的命运"。饮食是可改变因素里权重最高的一块。

### 1.2.6 既往化验单（趋势 > 单点）

- **单次数值 = 快照，趋势 = 电影。** 一张化验单只说明"这一刻"，三张连起来才看得出方向。
- 例：空腹血糖 5.9 → 6.3 → 6.5，虽然三次都在"边缘"，但趋势向上 = 红灯。
- **营养师行动：** 让顾客把近 2~3 年的体检报告都带上，横向对比同指标。

## 1.3 体格检查：营养缺乏体征（视诊重点全表）

体格检查的"视诊"是营养师最实用的部分——很多微量营养素缺乏会直接写在脸上、皮肤上、指甲上。**注意：体征只做线索，确诊靠化验+医生。**

### 1.3.1 皮肤体征全表

| 部位/表现 | 典型特征 | 提示缺乏/问题 | 营养师行动方向 |
|-----------|----------|----------------|----------------|
| 毛囊角化（鸡皮疙瘩样） | 上臂/大腿外侧毛囊口角化丘疹 | 维生素A / 必需脂肪酸 / 锌 | 评估维A（动物肝脏、深色蔬果）、优质油脂摄入 |
| 皮肤干燥脱屑 | 全身性干燥、鱼鳞样 | 必需脂肪酸 / 维A / 水分 | 补充必需脂肪酸（深海鱼/坚果）、维A食物 |
| 瘀斑/瘀点 | 无明显外伤的皮下出血点 | 维生素C / 维生素K | 评估维C（新鲜蔬果）、维K（绿叶菜） |
| 皮肤瘀血愈合慢 | 伤口久不愈合 | 维C / 锌 / 蛋白质 | 蛋白+锌+维C组合 |
| 色素沉着（暴露部位） | 面/手背棕褐色 | 烟酸缺乏（糙皮病） | 烟酸（全谷物、瘦肉、花生） |
| 对称性皮炎（日晒处） | 边界清楚的红褐色 | 烟酸缺乏晚期 | 建议就医 + 烟酸食物 |
| 皮下脂肪变薄 | 皮肤褶皱提起皮变薄 | 能量/蛋白不足 | 热量蛋白补充 |
| 蜡样苍白水肿 | 皮肤发白+按压凹陷 | 蛋白缺乏（恶性营养不良） | 优质蛋白优先 |

### 1.3.2 指甲体征全表

| 表现 | 特征 | 提示 | 营养师行动方向 |
|------|------|------|----------------|
| 反甲（匙状甲） | 指甲中央凹陷、边缘翘起，呈勺状 | **缺铁** | 铁评估（铁蛋白/血红蛋白），补铁食物+维C |
| 脆甲/纵裂 | 指甲易裂、分层 | 铁 / 生物素 / 蛋白 / 钙 | 综合评估蛋白质、铁、B族 |
| 白甲（Mees线） | 横向白色条带 | 蛋白质/锌缺乏，或疾病 | 蛋白评估 |
| 甲周倒刺 | 甲沟干燥裂口 | B族 / 必需脂肪酸 / 水分 | B族+油脂+保湿 |
| 指甲苍白 | 按压甲床回血慢 | 贫血 | 血常规确认贫血类型 |
| 杵状指（远端膨大） | 手指末端增宽呈鼓槌状 | **心肺疾病信号** | ⚠️建议就医，非营养问题 |
| 指甲生长缓慢 | 指甲月牙小、长速慢 | 蛋白/微量营养不足 | 综合蛋白与微量营养评估 |

### 1.3.3 眼/口腔/舌/牙龈体征全表

| 部位 | 表现 | 提示 | 营养师行动方向 |
|------|------|------|----------------|
| 眼 | 夜盲（暗处看不清） | 维生素A缺乏 | 维A食物（动物肝脏、胡萝卜、蛋黄） |
| 眼 | 结膜干燥、毕脱斑（灰白色泡沫斑） | 维A缺乏中晚期 | 建议就医 + 维A食物 |
| 眼 | 睑结膜苍白 | 贫血 | 血常规确认贫血类型 |
| 眼 | 巩膜黄染 | **黄疸信号** | ⚠️建议就医，查肝/胆 |
| 口腔 | 口角炎（嘴角裂口） | 维生素B2（核黄素） | 奶、蛋、瘦肉、绿叶菜 |
| 口腔 | 唇炎（唇干裂） | B2 / B族 / 水分 | B族+保湿 |
| 舌 | 舌炎（舌红痛） | 烟酸/B族缺乏 | 全谷物、瘦肉、B族 |
| 舌 | 地图舌（舌面斑块状脱苔） | 叶酸 / B12 / 锌 | B族+锌食物 |
| 舌 | 舌面光滑萎缩（镜面舌） | 叶酸 / B12缺乏 | 叶酸+B12评估（可查血清） |
| 舌 | 舌色苍白 | 贫血 | 血常规确认 |
| 牙龈 | 牙龈出血/红肿 | 维生素C缺乏（牙龈炎） | 维C食物（新鲜蔬果） |
| 牙龈 | 牙龈萎缩 | 维C / 钙 / 口腔卫生 | 维C+钙评估 |
| 牙龈 | 坏血病样牙龈（严重出血、松动） | 维C严重缺乏 | 建议就医 + 维C补充 |

### 1.3.4 颈/下肢/毛发体征全表

| 部位 | 表现 | 提示 | 营养师行动方向 |
|------|------|------|----------------|
| 颈部 | 甲状腺肿大（颈前隆起） | 碘异常 / 甲状腺疾病 | 建议查甲功 + 碘评估（勿自行补碘） |
| 下肢 | 凹陷性水肿（按压留坑） | 蛋白质缺乏 / 心肾功能 | 蛋白评估 + 建议就医（排除心肾） |
| 下肢 | 非凹陷性水肿 | 甲状腺功能减退可能 | 建议查甲功 |
| 下肢 | 小腿肌肉萎缩 | 肌少症 / 蛋白缺乏 | 蛋白+抗阻运动 |
| 毛发 | 毛发稀疏/干枯 | 蛋白质/铁/锌 | 蛋白+铁+锌评估 |
| 毛发 | 头发变红褐色 | 蛋白质/铜缺乏 | 蛋白+铜食物（坚果、贝类） |
| 毛发 | 睫毛/眉毛稀疏 | 甲状腺/锌 | 综合评估 |

> **口诀：** "嘴（口角炎）→B2，舌（镜面舌）→B12叶酸，甲（反甲）→铁，皮（毛囊角化）→维A，牙龈出血→维C，小腿肿→蛋白，脖子粗→碘。"

### 1.3.5 体格检查的边界

- 体征只是"线索"，不是"诊断"；同一种体征可能对应多种原因（如凹陷性水肿可能是蛋白缺乏也可能是心衰、肾病）。
- **任何时候体征明显/进行性加重 → 建议就医，营养师不做治疗性处理。**

## 1.4 人体测量标准（营养评估基本盘）

### 1.4.1 核心人体测量指标

| 指标 | 测量方法 | 参考范围（中国成人） | 意义/解读 |
|------|----------|----------------------|-----------|
| **BMI** | 体重kg ÷ 身高m² | 18.5~23.9 正常；<18.5 偏瘦；24~27.9 超重；≥28 肥胖 | 总体营养/肥胖状态 |
| **腰围** | 呼气末、髂嵴上缘与肋弓下缘中点水平 | 男 <90cm，女 <85cm（中国标准） | 腹型肥胖核心指标，比BMI更能预测代谢风险 |
| 腰臀比 | 腰围÷臀围 | 男<0.90，女<0.85 | 体型判断 |
| **小腿围** | 小腿最粗处 | 男>34cm，女>33cm（肌少症筛查下限） | 肌肉量粗筛 |
| **握力** | 优势手测力计 | 男<28kg、女<18kg 提示肌力下降 | 肌少症核心指标之一 |
| 上臂围 | 肩峰-鹰嘴中点水平 | 男 25~35cm，女 23~33cm | 粗略反映肌肉+脂肪 |
| 血压 | 诊室坐位右上臂 | <140/90 mmHg（中国高血压标准）；理想<120/80 | 高血压筛查 |
| 心率 | 静息 | 60~100 次/分 | 基础代谢参考 |

### 1.4.2 BMI 分层与营养意义（中国成人标准）

| 分类 | BMI | 营养意义 | 营养师行动 |
|------|-----|----------|-----------|
| 偏瘦 | <18.5 | 能量蛋白储备不足，手术/感染风险↑ | 评估摄食量，能量+蛋白补充 |
| 正常 | 18.5~23.9 | 理想区间 | 维持 + 防波动 |
| 超重 | 24~27.9 | 代谢风险开始上升 | 控制能量密度，增活动 |
| 肥胖 | ≥28 | 糖尿病/高血压/脂肪肝/血脂风险显著↑ | 温和减重（每周0.5~1kg），优先减腹 |

> **⚠️ 注意：** BMI 正常但腰围超标 = "瘦胖子"（正常体重代谢异常），也要干预。BMI 是粗筛，腰围和体成分更精细。

### 1.4.3 儿童/老人/孕妇的测量特殊性

| 人群 | 特殊性 |
|------|--------|
| 儿童 | 用生长曲线（WHO/中国标准）百分位评价，不是成人的BMI切点 |
| 老年人 | 肌少症风险：小腿围、握力、步速比BMI更重要；老人微超重可能反而有利（肥胖悖论） |
| 孕妇 | 按孕前BMI分级的孕期增重范围（IOM标准），不适用普通BMI |

# 二、血常规详解

血常规（血细胞分析）是最基础、最便宜的化验，也是营养评估的"第一块敲门砖"。它分三大系：**红细胞系（贫血）、白细胞系（免疫/感染）、血小板系（止血）**。

## 2.1 红细胞系列：贫血的总开关

### 2.1.1 五个关键指标一张表

| 指标 | 英文 | 参考范围（成人·大致） | 说明 |
|------|------|------------------------|------|
| **血红蛋白 Hb** | Hemoglobin | 男 130~175 g/L，女 115~150 g/L | 贫血判定金标准 |
| **红细胞 RBC** | Red Blood Cell | 男 4.3~5.8 ×10¹²/L，女 3.8~5.1 ×10¹²/L | 数量维度 |
| **红细胞压积 HCT** | Hematocrit | 男 40~50%，女 35~45% | 红细胞体积占比 |
| **平均红细胞体积 MCV** | Mean Corpuscular Volume | 80~100 fL | **贫血分型最关键** |
| **平均血红蛋白量 MCH** | Mean Corpuscular Hb | 27~34 pg | 每个红细胞含多少血红蛋白 |
| **平均血红蛋白浓度 MCHC** | Mean Corpuscular Hb Conc | 316~354 g/L | 血红蛋白浓度 |

> **判读顺序：** 先看 **Hb** 定"有没有贫血" → 再看 **MCV** 定"哪一类贫血" → 再看 **MCH/MCHC** 辅助 → 最后用铁蛋白/B12/叶酸等定"缺什么"。

### 2.1.2 贫血分级（Hb，WHO/中国标准）

| 分级 | 成人男性 | 成人女性 | 临床意义 |
|------|----------|----------|----------|
| 轻度 | 110~130 | 110~120 | 可有乏力、头晕 |
| 中度 | 90~110 | 90~110 | 活动后心悸气短 |
| 重度 | 60~90 | 60~90 | 静息也气短、苍白 |
| 极重度 | <60 | <60 | ⚠️急症，立即就医 |

> 孕期贫血切点更严格（Hb<110 g/L 即贫血），且孕妇更易缺铁。

### 2.1.3 Hb 升高/降低的意义与营养关联

| 变化 | 可能原因 | 营养师视角 |
|------|----------|-----------|
| **Hb 降低** | ①缺铁 ②B12/叶酸缺乏 ③慢性病/炎症 ④失血 ⑤地贫遗传 | 贫血分型→针对性营养评估（见2.2） |
| **Hb 升高** | ①脱水/血液浓缩 ②高原 ③吸烟 ④真性红细胞增多症（少见） | 排除脱水；吸烟者建议戒烟；若持续高→就医 |

## 2.2 贫血分型：用 MCV 一锤定音（营养师核心技能）

**这是营养师最值得花时间学会的一张表。** 看到贫血，第一步永远是用 MCV 分大类，再决定往哪个方向评估。

### 2.2.1 MCV 分型总表

| 分型 | MCV | MCH/MCHC | 最常见原因 | 营养对策 |
|------|-----|----------|-----------|----------|
| **小细胞低色素性** | ↓ <80 fL | MCH/MCHC 均↓ | 缺铁性（最常见）；地贫；慢性病 | 见下文分路处理 |
| **正细胞正色素性** | 正常 80~100 | 正常 | 慢性病贫血；肾性贫血；急性失血早期 | 治原发病，蛋白+支持 |
| **大细胞性** | ↑ >100 fL | MCH↑ | 叶酸缺乏；B12缺乏；酒精；药物 | 补叶酸/B12（先分清缺哪个） |

### 2.2.2 四类贫血逐个拆解

#### ① 缺铁性贫血（IDA）——最常见，营养师最该管

- **机制：** 铁是血红蛋白核心原料，铁不够→造不出足够血红蛋白。
- **化验特征：** Hb↓ + MCV↓ + MCH↓ + **铁蛋白↓（<15~30 ng/ml 高度提示缺铁）** + 转铁蛋白饱和度↓ + 血清铁↓。
- **高危人群：** 育龄女性（月经丢失）、孕妇、婴幼儿、青少年、素食者（非血红素铁吸收率低）、慢性失血者（痔疮/消化道出血）。
- **常见症状：** 乏力、头晕、怕冷、脱发、反甲、异食癖（想吃冰/土）、注意力差、运动耐力下降。
- **营养对策：**
  - 血红素铁（动物源）：瘦红肉、动物肝脏、鸭血/猪血、动物肾脏——吸收率15~35%。
  - 非血红素铁（植物源）：豆类、黑木耳、菠菜、红枣、芝麻——吸收率2~20%，需搭配维C。
  - **搭配维C：** 同一餐配新鲜蔬菜/水果（维C可把非血红素铁吸收率提升数倍）。
  - **避开抑制物：** 浓茶、咖啡（鞣酸/多酚）、大量钙片尽量与铁餐错开1~2小时。
  - **疗程：** 补铁后 Hb 一般4周开始回升，但**铁蛋白需继续补足3~6个月**才补满储备，别见Hb正常就停。
  - ⚠️ 营养补充剂建议在医生指导下使用，特别是孕期。

#### ② 巨幼细胞性贫血（MA）——叶酸或B12缺乏

- **机制：** 叶酸/B12 是 DNA 合成的辅酶，缺乏→红细胞"没长熟就变大"。
- **化验特征：** Hb↓ + **MCV↑（>100 fL）** + MCH↑ + 中性粒细胞分叶过多；进一步查**血清叶酸、红细胞叶酸、血清B12、同型半胱氨酸**。
- **鉴别叶酸缺乏 vs B12缺乏（关键）：**
  - **B12缺乏：** 常伴**神经系统症状**（手脚麻木、走路不稳、记忆力下降）+ 舌炎；只补叶酸会"掩盖"B12缺乏、加重神经损伤。**所以大细胞贫血先查清是缺叶酸还是B12，不盲目补。**
  - **叶酸缺乏：** 多因摄入不足/需求增加（孕期）/吸收障碍/酗酒。
- **高危人群：** 老年人（萎缩性胃炎→B12吸收差）、长期素食者、长期吃抑酸药者、孕妇、酗酒者。
- **营养对策：**
  - B12 只来自动物食物（肉/蛋/奶/鱼/贝）；素食者尤其注意，必要时医生指导下用B12补充剂。
  - 叶酸来源：绿叶蔬菜、豆类、全谷物、肝脏。
  - 烹调注意：叶酸怕热怕水，绿叶菜急火快炒、少久煮。

#### ③ 慢性病贫血（ACD）——炎症性贫血

- **机制：** 慢性炎症（感染、肿瘤、自身免疫病、慢性肾病）时，铁被"锁"在储存里用不出来 + 红细胞生成受抑。
- **化验特征：** 多为正细胞性贫血（MCV正常，可轻度偏低）；**铁蛋白反而正常或升高**（因为是炎症性储存铁↑），转铁蛋白/血清铁↓。
- **与缺铁性贫血的鉴别要点：**

| 指标 | 缺铁性贫血 | 慢性病贫血 |
|------|-----------|-----------|
| 铁蛋白 | ↓↓（<15） | 正常或↑ |
| 转铁蛋白饱和度 | ↓↓ | ↓或正常 |
| 总铁结合力 | ↑ | 正常或↓ |
| 可溶性转铁蛋白受体 | ↑ | 正常 |

- **营养对策：** 核心是**治原发病**（由医生）；营养师做支持——保证优质蛋白、避免盲目补铁（铁蛋白不低时补铁无用甚至有害）。

#### ④ 地中海贫血——遗传性，切勿盲目补铁

- **机制：** 血红蛋白珠蛋白链合成缺陷，遗传性疾病（南方/两广地区相对多见）。
- **化验特征：** 小细胞低色素（MCV↓），但**铁蛋白常正常或偏高**；轻型多无症状，体检偶然发现。
- **⚠️ 营养师铁律：** 看到"小细胞低色素 + 铁蛋白不低"→ 高度怀疑地贫，**不要按缺铁补铁**（补铁对地贫无效且可能铁过载伤肝）。建议就医做血红蛋白电泳确诊，并查家族史。
- **营养对策：** 地贫是遗传病，营养不能治愈；营养师做的是**生活质量支持**（均衡饮食、充足叶酸），补铁与否完全听医生的。

### 2.2.3 贫血分型速查流程图

```
看到 Hb↓（贫血）
      │
      ▼
   MCV 是多少？
   │
   ├─ MCV↓（<80）→ 查铁蛋白
   │        ├─ 铁蛋白↓ → 缺铁性贫血 → 补铁+维C+避开抑制物
   │        ├─ 铁蛋白正常/↑ → 地中海贫血? / 慢性病贫血 → 就医查电泳
   │        └─ 铁蛋白正常但转铁蛋白饱和度↓↓+总铁结合力↑ → 慢性病贫血（治原发病）
   │
   ├─ MCV正常（80~100）→ 慢性病贫血? / 肾性贫血? / 急性失血 → 就医定原发病，营养支持
   │
   └─ MCV↑（>100）→ 大细胞 → 查血清叶酸 / 血清B12 / 同型半胱氨酸
            ├─ B12↓+神经症状 → B12缺乏 → 补B12（勿只补叶酸）
            ├─ 叶酸↓ → 叶酸缺乏 → 补叶酸+绿叶菜
            └─ 两者都正常 → 酒精? 药物? 骨髓问题? → 就医
```

## 2.3 白细胞系列：免疫力的仪表

### 2.3.1 白细胞分类与参考范围

| 指标 | 参考范围（成人·大致） | 意义 |
|------|------------------------|------|
| 白细胞总数 WBC | 3.5~9.5 ×10⁹/L | 免疫总动员水平 |
| 中性粒细胞 | 40~75%；绝对值 1.8~6.3 ×10⁹/L | 抗菌主力（细菌） |
| 淋巴细胞 | 20~50%；绝对值 1.1~3.2 ×10⁹/L | 抗病毒/免疫记忆 |
| 单核细胞 | 3~8% | 吞噬/慢性炎症 |
| 嗜酸性粒细胞 | 0.4~8% | 过敏/寄生虫 |
| 嗜碱性粒细胞 | 0~1% | 过敏（少见） |

### 2.3.2 WBC 升高/降低解读

| 变化 | 常见原因 | 营养师视角 |
|------|----------|-----------|
| WBC↑ + 中性粒↑ | 细菌感染、急性炎症 | 保证蛋白+水分支持免疫，建议就医抗感染 |
| WBC↑ + 淋巴↑ | 病毒感染 | 休息+水分+均衡营养 |
| WBC↑ + 嗜酸↑ | 过敏、寄生虫、哮喘 | 排查过敏原；建议就医 |
| WBC正常但淋巴↓ | 应激/免疫波动 | 恢复期营养支持 |
| WBC↓（<3.5） | 病毒感染恢复期、药物、骨髓抑制 | 若持续低→就医；营养支持（蛋白+B族+锌） |
| WBC极低 | ⚠️骨髓抑制、血液病 | 立即就医 |

> **注意：** 白细胞一过性轻度波动很常见（如感冒后）。**持续显著异常→就医。** 营养师不做抗感染建议。

### 血小板异常解读

| 变化 | 常见原因 | 营养师视角 |
|------|----------|-----------|
| PLT↓ | ①病毒感染后一过性 ②药物 ③肝硬化脾功能亢进 ④免疫性血小板减少 ⑤骨髓问题 | 若伴牙龈/皮肤出血→就医；查肝功；勿自行用活血营养素 |

# 三、血糖与糖尿病指标

## 3.1 血糖指标全景

| 指标 | 参考范围 | 糖尿病诊断切点 | 营养师视角 |
|------|----------|----------------|-----------|
| **空腹血糖 FPG** | 3.9~6.1 mmol/L | ≥7.0 mmol/L（两次） | 反映基础糖代谢 |
| **餐后2小时血糖** | <7.8 mmol/L | ≥11.1 mmol/L | 反映餐后胰岛素能力 |
| **糖化血红蛋白 HbA1c** | 4~6% | ≥6.5% | 反映近2~3个月平均血糖，不受单餐影响 |
| 随机血糖 | — | ≥11.1 mmol/L + 症状 | 偶测 |
| 糖化白蛋白 GA | 11~17% | 反映近2~3周血糖 | 短期血糖波动参考 |

> **为什么要测多种血糖指标？** 空腹血糖只看"基础状态"，餐后血糖看"应急能力"，HbA1c看"长期平均"——三者合起来才是完整血糖画像。单查空腹容易漏掉"空腹正常但餐后高"的人。

## 3.2 诊断切点（中国2型糖尿病防治指南）

### 3.2.1 糖代谢状态分类

| 糖代谢分类 | 空腹血糖 (mmol/L) | 餐后2h血糖 (mmol/L) | HbA1c |
|------------|-------------------|---------------------|-------|
| **正常血糖** | <6.1 | <7.8 | <5.7% |
| **空腹血糖受损 IFG** | 6.1~6.9 | <7.8 | 5.7~6.4% |
| **糖耐量减低 IGT** | <7.0 | 7.8~11.0 | 5.7~6.4% |
| **糖尿病** | ≥7.0 | ≥11.1 | ≥6.5% |

### 3.2.2 糖尿病前期（IFG + IGT 统称）——营养师的主战场

- **人群规模：** 中国成人糖尿病前期患病率极高（约1/3成人处于糖尿病前期），是"最后一道可逆转的门"。
- **营养师行动（重点）：**
  - **减重5~10%**：超重/肥胖者体重降5~10%可显著改善胰岛素敏感性（这是证据最强的干预）。
  - **精制碳水→全谷物/粗杂粮**：把白米白面部分换成燕麦、糙米、杂豆。
  - **餐后血糖管理**：进餐顺序"菜→肉→饭"（先膳食纤维和蛋白，最后主食），可改善餐后血糖。
  - **限游离糖/含糖饮料**：含糖饮料是明确的糖尿病风险因素。
  - **增肌+运动**：餐后散步15分钟、每周150分钟中等强度运动。
  - **地中海式/低GI饮食**：多吃蔬菜、豆类、坚果、深海鱼。

> **关键认知：** 糖尿病前期≠糖尿病，**可逆转**；一旦到糖尿病，则进入"控制"而非"逆转"。所以查出"边缘升高"反而是最该行动的警报。

### 3.2.3 糖尿病诊断标准（医生诊断，营养师引用）

满足以下任一即可诊断糖尿病（需医生确认，通常需复查一次）：

1. 空腹血糖 ≥7.0 mmol/L；
2. 口服75g葡萄糖耐量试验2小时血糖 ≥11.1 mmol/L；
3. 糖化血红蛋白 ≥6.5%；
4. 有典型症状（多饮多尿体重下降）+ 随机血糖 ≥11.1 mmol/L。

## 3.3 胰岛素与胰岛功能

### 3.3.1 胰岛素 / C肽

| 指标 | 参考范围（大致） | 解读 |
|------|------------------|------|
| 空腹胰岛素 | 2.6~24.9 mIU/L（单位因实验室而异） | 高→胰岛素抵抗早期信号 |
| 空腹C肽 | 0.3~1.3 nmol/L（约1.1~4.4 ng/ml） | 更稳定反映自身胰岛素分泌量 |
| 餐后胰岛素/C肽 | 峰值为空腹5~10倍 | 反映胰岛"弹药库" |

- **C肽 vs 胰岛素：** C肽不受外源胰岛素干扰，比胰岛素更能反映"自身还能分泌多少"。C肽低→分泌不足（1型/晚期2型）；C肽高→抵抗为主（早期2型）。
- **营养师视角：** 空腹胰岛素高 = 身体"打很多电话没人接"（胰岛素抵抗），是代谢综合征的早期信号，营养干预窗口期。

### 3.3.2 HOMA-IR（胰岛素抵抗稳态模型）

$$HOMA-IR = \frac{空腹血糖(mmol/L) × 空腹胰岛素(mIU/L)}{22.5}$$

- **切点：** 一般 **>2.69 提示胰岛素抵抗**（部分研究用 >2.0；以实验室/文献为准）。
- **意义：** 把"血糖"和"胰岛素"合成一个数，评估胰岛素抵抗程度——比单看血糖更早发现代谢问题。
- **营养对策（HOMA-IR高时）：** 减重、限精制碳水、限游离糖、增肌运动、保证睡眠、控压力。

### 3.3.3 TyG 指数（甘油三酯-葡萄糖指数）

$$TyG = ln[\frac{TG(mg/dL) × FPG(mg/dL)}{2}]$$

- 不抽胰岛素也能估胰岛素抵抗，用常规的血脂+血糖就能算，临床越来越常用。
- 高 TyG → 胰岛素抵抗、心血管代谢风险↑。
- **营养对策与 HOMA-IR 高时相同。**

### 3.3.4 代谢健康评估组合

```
核心四项：空腹血糖 + 空腹胰岛素（→HOMA-IR）
        + 甘油三酯 + HDL-C（→TyG）
辅助：腰围、血压、HbA1c、尿酸
```

> **一句话：** 血糖是"结果"，胰岛素和HOMA-IR/TyG是"原因线索"。营养师在血糖还正常时就能用胰岛素/腰围发现"代谢开始走偏"的人——这是预防的第一道防线。

## 3.4 血糖异常的阶梯式营养策略

| 阶段 | 指标表现 | 营养策略重点 |
|------|----------|--------------|
| 血糖正常但胰岛素↑/腰围↑ | 代谢早期走偏 | 预防为主：减重、抗炎饮食、增肌 |
| 糖尿病前期（IFG/IGT） | 空腹6.1~6.9 / 餐后7.8~11.0 | **逆转窗口**：减重5~10%、全谷物替代、限游离糖 |
| 确诊糖尿病 | 达到诊断切点 | 医生诊疗 + 医学营养治疗（MNT）：控制碳水总量与质量、规律进餐、监测 |
| 糖尿病+肾病/心衰 | 并发症 | 专科营养：蛋白限量按分期、低盐、控钾磷（遵医嘱） |

> **⚠️ 边界：** 糖尿病是慢性病，诊断与用药完全由医生负责。营养师可以做的是：医学营养治疗（MNT）中的饮食教育、生活方式支持，但**所有方案需与医生治疗方案衔接，营养方案不能替代降糖药**。

# 四、血脂与心血管风险

## 4.1 血脂四项/五项全景

| 指标 | 参考范围（中国成人·大致） | 解读 |
|------|---------------------------|------|
| **总胆固醇 TC** | 合适 <5.2 mmol/L；5.2~6.2 边缘升高；≥6.2 升高 | 血脂总盘子 |
| **甘油三酯 TG** | 合适 <1.7 mmol/L；1.7~2.3 边缘升高；≥2.3 升高；极高 >5.6 | 代谢/糖脂转换指标 |
| **低密度脂蛋白胆固醇 LDL-C** | 合适 <3.4；3.4~4.1 边缘；≥4.1 升高 | **降脂核心靶点"坏胆固醇"** |
| **高密度脂蛋白胆固醇 HDL-C** | 男 >1.0，女 >1.3 mmol/L | "好胆固醇"，低→风险↑ |
| **载脂蛋白 ApoB** | 视危险分层（高危通常<0.8~1.0 g/L） | 更准的致动脉粥样硬化颗粒数 |

### 4.1.1 各指标升高/降低含义

| 变化 | 含义 | 营养师行动 |
|------|------|-----------|
| **LDL-C↑** | 动脉粥样硬化核心风险 | 限饱和脂肪（肥肉/猪油/黄油/椰油）、限反式脂肪（油炸/植脂末）、增可溶性纤维（燕麦/豆类/苹果） |
| **TG↑** | 游离糖/精制碳水/酒过量、代谢综合征 | 限糖限酒限精制碳水、减重、增鱼油（深海鱼） |
| **HDL-C↓** | 运动少、吸烟、腹型肥胖 | 有氧运动、戒烟、减腹、适量优质脂肪 |
| **TC↑** | 综合看，需看LDL构成 | 结合LDL分层处理 |
| **ApoB↑** | 动脉粥样硬化颗粒数多 | 同LDL处理，达标值更严 |

### 4.1.2 "脂质三联征"（致动脉粥样硬化性血脂异常）

```
TG↑ + LDL↑ + HDL↓  →  代谢综合征典型血脂谱
```

- 常见于：腹型肥胖、糖尿病前期/糖尿病、脂肪肝、胰岛素抵抗人群。
- 这是**代谢综合征的血液版指纹**，也是营养师最常遇到的组合。
- **本质：** 能量过剩 + 糖代谢紊乱 + 腹部脂肪堆积 → 肝脏产极低密度脂蛋白增多 → TG高、LDL小颗粒多、HDL被拖低。
- **营养对策方向（见11.07高脂血症）：**
  - 减重5~10%（往往同时改善三项）；
  - 限游离糖和精制碳水（TG最敏感）；
  - 限饱和脂肪/反式脂肪（LDL最敏感）；
  - 增加可溶性膳食纤维（豆类、燕麦、果蔬）；
  - 增加 n-3 脂肪酸（深海鱼每周2次）；
  - 规律有氧运动（升HDL）。

---

## 4.2 血脂危险分层与达标（中国血脂管理指南）

血脂要不要"达标"、达标到多少，不是看一个固定值，而是看**整体心血管危险分层**。这就是为什么同样 LDL 3.2，对年轻人可能没事，对糖尿病人就是"太高了"。

### 4.2.1 危险分层简表

| 危险分层 | 判定依据（简） | LDL-C 达标值（大致） |
|----------|----------------|----------------------|
| 低危 | 无危险因素、年轻 | <3.4 mmol/L |
| 中危 | 中危者（有1~2个危险因素） | <2.6 mmol/L |
| 高危 | 糖尿病、或LDL≥4.9、或已确诊ASCVD等 | <1.8 mmol/L |
| 极高危 | 曾患心肌梗死/脑卒中、或合并多脏器 | <1.4 mmol/L |

> **⚠️ 重要：** 精确分层由医生用风险评估工具完成，营养师**不做分层诊断**。营养师只需知道一个原则：**危险因素越多，LDL要控得越严**；具体达标值永远以医生/指南为准。

### 4.2.2 危险因素清单（营养师用来判断"这个人该重视血脂"）

- 年龄（男≥45岁、女≥55岁）
- 吸烟
- 高血压
- 糖尿病
- 肥胖/腹型肥胖
- 早发心血管病家族史
- 低 HDL-C

> **营养师用法：** 数一数这个人有几个危险因素——越多，越要强调血脂管理，越要劝他找医生做正规风险评估。

---

## 4.3 关于"吃胆固醇"的现代认知（科普纠偏点）

- **食物胆固醇对血胆固醇影响有限（约1/3），饱和脂肪和反式脂肪影响更大。** 2016年《中国居民膳食指南》已取消每日300mg胆固醇限量。
- **但"放松"不等于"随便吃"：** 高胆固醇食物往往同时高饱和脂肪（如肥肉、内脏、蛋黄脂质、鱿鱼）。
- **营养师正确话术：** "鸡蛋可以吃（每天1个没问题），关键是把肥肉、油炸、糕点点心这些饱和/反式脂肪的'大户'管住。"

# 五、肝功能与脂肪肝

## 5.1 肝功能指标全景

| 指标 | 参考范围（大致） | 升高含义 | 营养关联 |
|------|------------------|----------|----------|
| **ALT（谷丙转氨酶）** | 男 9~50，女 7~40 U/L | **肝细胞损伤**（脂肪肝最敏感指标） | 脂肪肝、酒精、药物、病毒性肝炎 |
| **AST（谷草转氨酶）** | 男 15~40，女 13~35 U/L | 肝/心肌/骨骼肌损伤 | 结合AST/ALT比值看 |
| **AST/ALT 比值** | 正常 0.8~1.2 | >1 提示酒精肝/肝硬化；>2 更倾向酒精性 | 酒精史问诊 |
| **GGT（γ-谷氨酰转肽酶）** | 男 10~60，女 7~45 U/L | 酒精/胆道淤积/脂肪肝 | 酒精与胆汁淤积敏感指标 |
| **ALP（碱性磷酸酶）** | 45~125 U/L | 胆道梗阻/骨骼病变/肝病 | 儿童/孕期生理性升高 |
| **总胆红素 TBIL** | 3.4~17.1 μmol/L（部分<21） | 黄疸 | 溶血/肝细胞/胆道三来源 |
| **直接胆红素 DBIL** | 0~6.8 μmol/L | 胆道梗阻为主 | 看是直接还是间接 |
| **白蛋白 ALB** | 35~55 g/L | **降低→肝合成差或营养差** | **营养指标！** |
| **前白蛋白 PA** | 0.2~0.4 g/L（200~400 mg/L） | 降低→近期蛋白营养差 | 半衰期短，比白蛋白更敏感 |
| **总胆汁酸 TBA** | 0~10 μmol/L | 胆汁淤积/肝病 | 餐后升高属生理 |

### 5.1.1 胆红素三来源鉴别

| 类型 | 特点 | 提示 |
|------|------|------|
| 溶血性黄疸 | 间接胆红素为主↑ | 溶血、无效造血 |
| 肝细胞性黄疸 | 直接+间接均↑ | 肝炎、肝硬化、药物 |
| 梗阻性黄疸 | 直接胆红素为主↑ | 胆道结石/肿瘤，伴ALP↑GGT↑ |

> 单纯"总胆红素略高一点点、其他全正常"很常见（如吉尔伯特综合征、空腹抽血、劳累），不用恐慌，但**建议让医生看一眼**。

## 5.2 脂肪肝（代谢相关脂肪性肝病 MAFLD）

### 5.2.1 脂肪肝的化验+影像表现

| 表现维度 | 典型发现 |
|----------|----------|
| 化验 | ALT轻中度↑（多为正常上限1.5~2倍以内）、GGT可↑、血脂异常、尿酸可↑ |
| 影像 | 超声示肝脏脂肪浸润（轻/中/重度） |
| 代谢背景 | 肥胖/超重、腹型肥胖、糖尿病前期或糖尿病、高血脂、高血压 |
| 其他 | 多无明显症状，或偶有乏力、右上腹不适 |

### 5.2.2 脂肪肝的真相（营养师科普重点）

- **"瘦子也会得脂肪肝"：** 不胖的人若精制碳水多、久坐、饮酒，同样会得；甚至快速减肥也会诱发。
- **脂肪肝的核心机制：** 肝脏"收脂肪的速度 > 运脂肪的速度"→ 脂肪堆积 → 炎症（NASH）→ 纤维化 → 肝硬化。**但早中期可逆！**
- **酒精性 vs 非酒精性：** 分清有没有饮酒史（酒精性脂肪肝首要对策是戒酒）。

### 5.2.3 脂肪肝营养对策（早中期逆转方向）

| 干预 | 具体做法 |
|------|----------|
| **减重（最重要）** | 目标减重 7~10%（指南推荐，可显著改善肝脏炎症） |
| 戒酒 | 酒精性脂肪肝必须戒酒 |
| 限游离糖 | 含糖饮料、甜点、果汁是"肝脏脂肪合成"的直接原料 |
| 限精制碳水 | 白米白面减量，换全谷物/杂豆 |
| 地中海式饮食 | 橄榄油、坚果、深海鱼、大量蔬菜 |
| 咖啡 | 适量无糖咖啡与脂肪肝改善相关（可提及） |
| 规律运动 | 有氧+抗阻结合，每周150分钟以上 |
| 补充肌醇/胆碱？（科普） | 部分研究提示有益，但**先做好生活方式，营养素补充在医生/营养师指导下** |

> **⚠️ 边界：** 若 ALT 显著升高（>正常上限2倍）、出现黄疸、或超声提示中重度+纤维化 → 建议消化科/肝病科就诊。营养师不承担治疗。

## 5.3 白蛋白与前白蛋白：营养师的眼睛

### 5.3.1 白蛋白 vs 前白蛋白

| 项目 | 白蛋白 ALB | 前白蛋白 PA |
|------|-----------|-------------|
| 半衰期 | 约20天 | 约2~3天 |
| 参考范围 | 35~55 g/L | 0.2~0.4 g/L |
| 反映营养状态 | 中长期蛋白储备 | **近期（数天内）蛋白营养** |
| 降低原因 | 摄入不足/肝合成差/肾病丢失/炎症 | 近期摄入骤减/应激/肝病 |
| 营养师用法 | 评估慢性蛋白营养 | 评估近期蛋白补充效果，更敏感 |

### 5.3.2 低白蛋白的鉴别

| 原因 | 特点 | 营养师行动 |
|------|------|-----------|
| 蛋白摄入不足 | 饮食评估确认摄入低 | 优质蛋白优先（蛋/奶/鱼/瘦肉/豆） |
| 肝合成功能下降 | 伴转氨酶/胆红素异常 | 建议就医查肝 |
| 肾丢失过多 | 尿蛋白阳性/大量 | 建议就医查肾 |
| 炎症/消耗 | 慢性病/肿瘤/感染 | 支持原发病治疗+蛋白支持 |

> **关键认知：** 白蛋白低 ≠ 一定营养不良——肾病、肝病、炎症都会让它低。**先分清"哪条路漏的"，再决定怎么补。**

# 六、肾功能与尿酸

## 6.1 肾功能指标全景

| 指标 | 参考范围（成人·大致） | 升高含义 | 营养关联 |
|------|------------------------|----------|----------|
| **血肌酐 Cr** | 男 57~111，女 41~81 μmol/L | ↑→肾功能下降/肌肉量大/摄入肉多 | 肾排泄能力粗指标 |
| **尿素氮 BUN** | 3.2~7.1 mmol/L | ↑→肾/蛋白摄入多/脱水/消化道出血 | 蛋白代谢+肾双因素 |
| **eGFR（估算肾小球滤过率）** | >90 ml/min/1.73m² | <90↓，<60=CKD3期 | **CKD分期核心** |
| **血尿酸 UA** | 男<420，女<360 μmol/L（绝经前） | ↑→高尿酸血症/痛风 | 嘌呤代谢 |
| **尿蛋白** | 阴性（-） | +→肾损伤线索 | 蛋白丢失途径 |
| **尿微量白蛋白/肌酐比 UACR** | <30 mg/g Cr | 30~300=微量白蛋白尿 | **早期肾损伤最敏感**（糖尿病/高血压必查） |

### 6.1.1 肌酐与尿素氮的解读要点

- **肌酐受肌肉量影响：** 肌肉发达的人肌酐偏高、瘦弱者偏低，属正常个体差异。所以肌酐轻度偏高要先看是不是肌肉量。
- **尿素氮受饮食影响大：** 大量吃蛋白、脱水、发烧会让尿素氮升高；**BUN/Cr 比值**升高（>20:1）→ 提示脱水或消化道出血。
- **eGFR 的意义：** 用肌酐+年龄+性别算出的肾小球滤过率，比单看肌酐更准确。**eGFR<60 持续3个月 = CKD3期**，是慢性肾病的正式分期。

### 6.1.2 CKD 分期与营养对策方向（营养师需知）

| 分期 | eGFR (ml/min/1.73m²) | 说明 | 营养方向（原则） |
|------|----------------------|------|------------------|
| G1 | ≥90 | 正常或有肾损伤 | 防进展：控血压、控血糖、控盐 |
| G2 | 60~89 | 轻度下降 | 同上+定期复查 |
| G3 | 30~59 | 中度下降 | **蛋白限量开始评估**（约0.8g/kg/日，遵医嘱），控磷控钾 |
| G4 | 15~29 | 重度下降 | 严格蛋白限量+低磷低钾，营养师必须与肾内科协同 |
| G5 | <15 / 透析 | 肾衰竭期 | 透析营养管理（高生物价蛋白+严格电解质） |

> **⚠️ 铁律：** CKD 的蛋白限量**因人而异、必须遵医嘱**——不同分期、是否透析、是否合并糖尿病，蛋白质推荐量完全不同。营养师**不要**自己定蛋白限量，只能协助执行医生的方案。肾病患者应转介**注册营养师/肾内科营养门诊**。

## 6.2 高尿酸与痛风

### 6.2.1 尿酸基础知识

- **来源：** 20%来自食物（嘌呤），80%为体内代谢生成；排泄主要靠肾脏。
- **高尿酸血症切点：** 男>420 μmol/L，女>360 μmol/L（绝经前）；血尿酸>420（男）/360（女）即高尿酸血症。
- **痛风：** 尿酸盐结晶沉积关节→急性关节炎（大脚趾常见）。**高尿酸≠痛风**，但痛风必有高尿酸基础。
- **尿酸不只是关节问题：** 高尿酸与高血压、糖尿病、肾病、心血管病均相关。

### 6.2.2 尿酸升高的营养对策（营养师常用）

| 方向 | 具体建议 |
|------|----------|
| **限酒（尤其啤酒）** | 酒精促尿酸生成+抑制排泄，啤酒含嘌呤高 |
| **限含糖饮料/果糖** | 果糖直接促进尿酸生成（比高嘌呤食物影响更大） |
| 限高嘌呤食物 | 动物内脏、浓肉汤、贝类、沙丁鱼 |
| 多喝水 | 每日2000ml以上（肾功能允许时），促进尿酸排泄 |
| 适量奶制品 | 低脂奶/酸奶与尿酸降低相关 |
| 新鲜蔬菜水果 | 樱桃等与痛风发作减少相关（可提及，证据有限） |
| 控制体重 | 减重可降低尿酸；但**避免快速节食**（酮体竞争尿酸排泄，诱发痛风） |
| 低蛋白适度 | 不是完全无嘌呤饮食，蛋奶嘌呤低可放心 |

> **⚠️ 边界：** 痛风急性发作（红肿热痛）→ 立即就医，营养师不做止痛建议；降尿酸药物使用由医生决定，饮食只是辅助。

# 七、甲状腺功能

## 7.1 甲功指标全景

| 指标 | 参考范围（大致，单位因实验室而异） | 意义 |
|------|-------------------------------------|------|
| **TSH（促甲状腺激素）** | 0.27~4.2 mIU/L | 垂体"总指挥"：**筛查首选、最敏感** |
| **FT3（游离三碘甲状腺原氨酸）** | 3.1~6.8 pmol/L | 活性最强的甲状腺激素 |
| **FT4（游离甲状腺素）** | 12~22 pmol/L | 主要循环激素 |
| TT3 / TT4 | 视实验室 | 受蛋白结合影响 |
| **TPOAb（甲状腺过氧化物酶抗体）** | 阴性（<34 IU/L 左右） | 阳性→桥本甲状腺炎（自身免疫） |
| **TgAb（甲状腺球蛋白抗体）** | 阴性 | 阳性→自身免疫倾向 |

> **理解顺序：** 大脑（垂体）→TSH→指挥甲状腺→出FT3/FT4→反馈给大脑。所以 **TSH 变话最快**：甲状腺功能一变，TSH 先动。

## 7.2 甲功模式识别（一张表看懂）

| 模式 | TSH | FT3/FT4 | 典型表现 | 代谢特点 |
|------|-----|---------|----------|----------|
| **正常** | 正常 | 正常 | 无 | 正常 |
| **甲亢（甲状腺功能亢进）** | ↓ | ↑ | 心慌、手抖、怕热多汗、消瘦、易饥、失眠 | 代谢快→体重下降、骨量流失风险 |
| **甲减（甲状腺功能减退）** | ↑ | ↓ | 乏力、怕冷、嗜睡、体重增加、便秘、浮肿、脱发、记忆力差 | 代谢慢→易胖难瘦、血脂可↑ |
| **亚临床甲减** | ↑ | 正常 | 症状轻或无 | 介于中间，易胖倾向 |
| **亚临床甲亢** | ↓ | 正常 | 症状轻或无 | 介于中间 |
| **桥本甲状腺炎** | 视阶段 | 视阶段 | TPOAb/TgAb阳性 | 自身免疫，可走向甲减 |

### 7.2.1 桥本甲状腺炎（营养师最常遇到）

- **是什么：** 自身免疫攻击甲状腺，TPOAb（+）/TgAb（+），是**甲减最常见病因**。
- **营养师能做（辅助，非治疗）：**
  - 保证**碘不过量**（不刻意补碘，海带紫菜适量）；碘过量可能加重自身免疫。
  - 保证**硒**（甲状腺抗氧化所需，坚果/海产品）。
  - 充足的**蛋白、铁、锌、维D**（甲状腺激素合成所需）。
  - 如已甲减用药（优甲乐）：**补铁/补钙需与服药错开4小时**（影响吸收）。
- **边界：** 桥本是自身免疫病，营养干预是"支持"，不能替代内分泌科诊疗与药物。

### 7.2.2 甲功与体重（顾客最关心的点）

| 状态 | 体重表现 | 营养师话术 |
|------|----------|-----------|
| 甲减 | 易胖、难减（基础代谢降15~40%） | "先治病（遵医嘱用药），在药物稳定的前提下再谈减重；配合力量训练保肌肉" |
| 甲亢 | 瘦、易饥、吃得多人还瘦 | "治疗期要保证能量蛋白防止过度消耗，体重回升是治疗有效的表现之一" |
| 药物稳定后 | 体重趋向正常 | "甲功正常后，体重管理回归'能量缺口'老规矩" |

> **⚠️ 关键认知：** 甲状腺问题**先治病后减重**——药物没调好之前，营养怎么使力都收效甚微。营养师不碰"调药"，一切以医生方案为准。

### 7.2.3 碘的平衡

| 状态 | 表现 | 建议 |
|------|------|------|
| 缺碘 | 甲状腺肿、甲减倾向 | 使用加碘盐、适量海产品（但现代中国城市居民缺碘已少见） |
| 碘过量 | 可诱发甲功异常/加重自身免疫 | 不盲目补碘；海带紫菜等高碘食物勿天天大量吃 |
| 桥本/甲亢治疗期 | 对碘敏感 | **遵医嘱限碘** |

> **一句话：** 碘是"双刃剑"，缺了不行、多了坏事。日常加碘盐就够了，不需要额外补碘剂。

# 八、营养素水平检测

这是营养师的"看家本领"——直接测身体里的营养弹药够不够。**注意：** 并不是所有营养素都能方便地测，且血清水平≠组织水平，解读需谨慎。

## 8.1 微量营养素检测全景

### 8.1.1 维生素 D（25-羟维生素D）

| 水平 | 25-羟维D (ng/ml) | 25-羟维D (nmol/L) | 解读 |
|------|-------------------|--------------------|------|
| 严重缺乏 | <10 | <25 | 骨骼健康风险显著↑ |
| 缺乏 | <20 | <50 | 需干预 |
| 不足 | 20~30 | 50~75 | 亚健康，建议补充 |
| **充足** | **≥30** | **≥75** | 目标水平 |
| 理想 | 30~50 | 75~125 | 多数指南推荐区间 |
| 过量 | >100 | >250 | ⚠️中毒风险（少见） |

- **为什么重要：** 维D影响钙吸收、骨骼、免疫、肌肉功能、情绪；中国成人普遍不足。
- **来源：** 日晒（UVB）、富脂鱼、蛋黄、强化食物、营养素补充剂。
- **营养师行动：** 不足/缺乏时，在医生/营养师指导下补充，并同时保证钙摄入（维D+钙协同）；鼓励日晒（避开暴晒时段，每周数次每次15~30分钟）。

### 8.1.2 叶酸

| 指标 | 参考（大致） | 说明 |
|------|--------------|------|
| 血清叶酸 | >6 ng/ml（约13.6 nmol/L） | 反映近期摄入 |
| **红细胞叶酸** | ≥400 nmol/L（约>150 ng/ml） | **反映中长期储备，更稳定** |

- **缺乏后果：** 巨幼细胞贫血、同型半胱氨酸升高、胎儿神经管缺陷（孕前/孕早期）。
- **来源：** 绿叶蔬菜、豆类、肝脏、全谷物。
- **注意：** 叶酸怕热怕光，烹调损失大；备孕/孕期需遵医嘱补充叶酸（通常400~800μg/日）。

### 8.1.3 维生素 B12

| 指标 | 参考（大致） | 说明 |
|------|--------------|------|
| 血清B12 | 187~883 pg/ml（约138~650 pmol/L） | 边缘（<200 pg/ml）需关注 |
| 活性B12（holoTC） | >50 pmol/L（大致） | 更敏感，可查 |
| 甲基丙二酸 MMA / 同型半胱氨酸 | MMA<0.4 μmol/L（大致）；Hcy<15 | **功能指标**：B12缺乏时两者升高（比血清B12更早） |

- **高危人群：** 老年人（萎缩性胃炎→内因子不足）、长期素食者、胃切除者、长期二甲双胍/抑酸药使用者。
- **来源：** 只存在于动物食物（肉/鱼/蛋/奶）；素食者应通过强化食品或医生指导下补充。
- **⚠️ 大细胞贫血时的铁律：** 先确认是缺B12还是缺叶酸再补；**B12缺乏伴神经症状者，只补叶酸会掩盖B12缺乏**。

### 8.1.4 铁代谢全套（铁蛋白是主角）

| 指标 | 参考（大致） | 解读 |
|------|--------------|------|
| **铁蛋白** | 男 30~400，女 13~150 ng/ml | **低=缺铁；高=炎症/铁过载**（注意：炎症时铁蛋白会假性升高） |
| 血清铁 | 男 11~32，女 9~29 μmol/L | 循环中的铁 |
| **转铁蛋白饱和度 TSAT** | 15~50% | **<15~20% 提示铁缺乏** |
| 总铁结合力 TIBC | 45~77 μmol/L | 缺铁时↑ |
| 可溶性转铁蛋白受体 sTfR | 视实验室 | 炎症干扰小时更准 |

- **铁蛋白的"双面性"（重要）：** 铁蛋白既是"仓库"，又是**急性期蛋白**——有炎症/感染/肝病时它会升高，掩盖真实缺铁。所以**单看铁蛋白高不一定是铁多，单看铁蛋白低大概率是缺铁**。
- **营养师行动（铁评估流程）：** 血红蛋白低 + 铁蛋白低 → 缺铁性贫血方向；血红蛋白正常但铁蛋白低（<30 ng/ml）→ "铁储备不足"阶段，是补铁的黄金窗口期。
- **补铁注意：** 见2.2.2①，搭配维C、避开浓茶咖啡、疗程要足。

### 8.1.5 血镁

| 指标 | 参考（大致） | 说明 |
|------|--------------|------|
| 血清镁 | 0.75~1.0 mmol/L | 缺镁时血清镁可仍正常（<1%镁在血中） |
| 红细胞内镁 | 更准但少测 | 组织镁状态 |
| 尿镁（24h） | 视实验室 | 镁丢失评估 |

- **为什么关注：** 镁参与300+酶反应，与血糖、血压、肌肉、睡眠、情绪相关；糖尿病人/利尿剂使用者/酗酒者易缺。
- **来源：** 绿叶蔬菜、坚果、种子、全谷物、豆类。
- **营养师提醒：** 血清镁正常≠不缺镁（敏感性差）；有抽筋/失眠/便秘/血压高+高危因素，可建议"镁食物摄入评估"而非单纯看血值。

### 8.1.6 锌与硒

| 指标 | 参考（大致） | 说明 |
|------|--------------|------|
| 血清锌 | 10.7~17 μmol/L（约70~110 μg/dl） | 低→味觉减退、脱发、伤口难愈、免疫力差 |
| 血清硒 | 0.6~1.4 μmol/L（约46~110 μg/L） | 低→甲状腺/免疫/抗氧化 |

- **锌：** 来源为贝类（牡蛎）、红肉、坚果、种子；素食者易边缘缺乏。锌与味觉、免疫、皮肤、生殖相关。
- **硒：** 来源为坚果（巴西果）、海产品、肉类；甲状腺抗氧化（与桥本相关）。
- **注意：** 血清锌硒是"边缘值参考"，轻度缺乏时血值可能正常；**锌补多了会抑制铜吸收**，硒过量有害（上限勿超，巴西果每天1~2颗即可），勿自行大剂量补。

### 8.1.7 同型半胱氨酸（Hcy）

| 指标 | 参考（大致） | 解读 |
|------|--------------|------|
| 同型半胱氨酸 | 5~15 μmol/L | 理想<10；>15 明显升高 |
| 升高含义 | 心脑血管风险相关 | B12/叶酸/B6缺乏是最常见营养原因 |

- **营养对策：** Hcy高 → 评估叶酸/B12/B6 → 补充绿叶菜、豆类、瘦肉、全谷物（对应营养素）；必要时医生指导下补充叶酸+B12+B6组合。
- **注意：** Hcy受遗传（MTHFR基因）影响，部分人需活性叶酸；具体补充方案建议医生/营养师指导。

### 8.1.8 蛋白质营养（白蛋白/前白蛋白）

| 指标 | 参考（大致） | 解读 |
|------|--------------|------|
| 血清白蛋白 ALB | 35~55 g/L | <30 显著降低；反映慢性蛋白状态 |
| 前白蛋白 PA | 0.2~0.4 g/L（200~400 mg/L） | 半衰期2~3天，**近期营养更敏感** |

- **用法：** 蛋白营养评估看"白蛋白+前白蛋白+总蛋白+小腿围+握力"组合，不单看一个。
- **警惕炎症干扰：** 炎症时白蛋白/前白蛋白都会降（急性期反应），所以低值要先排除炎症因素。

# 九、综合读单流程

## 9.1 营养师版读单七步法

拿到一份完整体检报告，按固定顺序过一遍，保证不遗漏：

```
第一步：看血糖 + 血脂 + 尿酸 → 代谢状态画像
  （空腹血糖/HbA1c/HOMA-IR、TC/TG/LDL/HDL、UA）
  → 有没有"代谢综合征"影子？

第二步：看肝功能 → 脂肪肝线索
  （ALT/AST/GGT、AST:ALT比值）
  → 结合腰围、血脂判断脂肪肝可能？

第三步：看肾功能 → 分期
  （肌酐/eGFR/尿蛋白/尿酸）
  → CKD几期？蛋白要不要管理？（遵医嘱）

第四步：看血常规 → 贫血分型
  （Hb→MCV→MCH/MCHC→铁蛋白）
  → 缺铁？巨幼？慢病？地贫？别补错方向

第五步：看白蛋白/前白蛋白 → 蛋白营养
  → 近期/慢性蛋白状态，结合小腿围、握力

第六步：看铁蛋白/维D/B12/叶酸/镁 → 微量营养
  → 缺口在哪几项？与饮食问卷对得上吗？

第七步：看甲状腺 → 代谢率
  → TSH+FT3/FT4+抗体；甲减甲亢方向？
  → 体重难控先看甲功稳没稳

综合：把所有异常项串成一张"代谢综合征/营养缺乏"图谱，
     标出：哪些是医生的事（诊断）→ 哪些是营养的活（缺口）→ 哪些是生活习惯（运动/睡眠/烟酒）
```

## 9.2 异常指标归口（营养师内心分类表）

| 类别 | 指标示例 | 归口 |
|------|----------|------|
| **营养缺口型**（营养师主战场） | 铁蛋白↓、维D↓、B12↓、叶酸↓、白蛋白↓、MCV↑/↓ | 营养评估+饮食干预 |
| **代谢失衡型**（营养+生活方式双管） | 空腹血糖↑、HbA1c↑、TG↑、LDL↑、ALT轻中↑（脂肪肝）、尿酸↑、HOMA-IR↑ | 生活方式干预+建议就医评估 |
| **器官功能型**（必须医生诊断） | 转氨酶显著↑、胆红素↑、肌酐↑、eGFR<60、尿蛋白+、TSH/FT3/FT4异常、WBC极异常 | 建议就医，营养只做辅助支持 |
| **急症红旗型**（立即就医） | Hb<60、WBC极低/极高、黑便、胸痛、严重水肿 | 不做任何营养干预，立即就医 |

## 9.3 异常→行动（营养师话术模板）

| 情况 | 话术模板（可直接用，注意语气温和、不下诊断） |
|------|-----------------------------------------------|
| **指标异常（通用）** | "这个指标确实需要医生看一眼确认原因，我不替医生下诊断。不过在饮食上，我们可以先做几件事，方向上是安全的……" |
| **血糖偏高（边缘）** | "血糖已经到'该注意'的区间了。第一步建议你找医生做个正规评估（比如糖耐量试验）。同时饮食上，这三个月我们可以先做：把白米饭换成一半粗粮、戒掉含糖饮料、每餐先吃菜再吃肉最后吃饭。" |
| **血脂异常** | "血脂里的甘油三酯偏高，和甜食、酒、精制主食关系最大；LDL偏高和饱和脂肪关系最大。先找医生看要不要用药评估，饮食上我们同步把'肥肉、油炸、糕点点心'先减下来。" |
| **脂肪肝（ALT轻度高）** | "ALT轻度升高+超声脂肪肝，最常见的是'吃出来的'。好消息是早期脂肪肝可逆，减重7~10%是证据最强的做法。建议配合医生复查，我们先把减重计划定起来。" |
| **贫血（缺铁型）** | "血红蛋白偏低、铁蛋白也低，方向上是缺铁。建议医生确认一下贫血原因（排除失血等）。饮食上我们先把血红素铁（瘦红肉、动物血、肝脏）和维C搭起来，浓茶咖啡和铁餐错开。" |
| **维生素D缺乏** | "维D已经到缺乏区间了，这和日晒少、户外活动少关系最大。建议在医生/营养师指导下按剂量补充，同时增加户外日晒和富脂鱼、蛋黄这些来源。" |
| **蛋白偏低（白蛋白低）** | "白蛋白偏低要先请医生排除肝、肾、炎症这些原因。如果确实是吃得不够，我们重点把每餐的优质蛋白（蛋、奶、鱼、瘦肉、豆）做足，配合运动保住肌肉。" |
| **甲状腺异常** | "TSH/甲功有异常，这个一定要内分泌科医生确诊用药，别拖。营养上我们能配合的是：保证硒和蛋白，桥本的话碘别过量，用药期间铁钙补充要和优甲乐错开时间。" |
| **指标正常** | "指标都正常，说明你目前基础很好。'正常'不是终点，我们把它保持住——睡眠、运动、饮食结构这三样别松懈。另外很多慢性病的指标是慢慢爬上去的，建议每年体检一次，我们对比趋势。" |
| **营养缺乏（多个）** | "结合你的饮食问卷和这次指标，缺口主要在铁、维D和B族这三块。它们往往是连在一起的（比如素食+少日晒），我们按'食物优先、必要时补充'的思路，一步步补，不要一把抓。" |
| **顾客问"要不要吃XX营养素"** | "营养素补充剂不是越多越好，铁、硒、维D补过量都有风险。建议按化验缺口来补，剂量在医生/营养师指导下定，食物永远是第一位的。" |

## 9.4 与医生协作的话术

- **对顾客：** "我做的这些是营养评估和饮食支持，诊断和治疗一定要以医生的为准。你可以带着这张单子和我的饮食建议，一起去给医生看，医生定方案，我们做配合。"
- **转介标准（营养师主动转介医生）：** 任何红旗信号（Hb极低、黑便、胸痛、剧烈消瘦、黄疸）、任何"器官功能型"指标异常、需要处方的营养素方案、孕妇/儿童/慢病多重用药者的复杂营养问题。

## 9.5 解读化验单的"三不三要"

| 三不（红线） | 三要（原则） |
|--------------|--------------|
| 不诊断疾病 | 要强调"以报告单参考范围为准" |
| 不开处方药/营养素剂量（除营养评估范畴内常识建议） | 要以"营养缺口+生活方式"为视角 |
| 不承诺疗效 | 要与医生方案衔接、建议就医确诊 |

# 十、化验单常见问题 FAQ

### Q1：同一指标，这家医院和那家医院参考范围不一样，为什么？
不同医院检验仪器、试剂、方法学、单位换算不同，参考范围来自各自实验室的人群统计。**所以永远以报告单上的参考范围为准**，跨医院对比要小心（最好同院对比趋势）。

### Q2：结果比参考范围高一点点，要紧吗？
"边缘性升高/降低"很常见（如总胆红素、尿酸、ALT轻度偏高），可能是生理波动（空腹没控好、劳累、近期饮食）。**处理原则：复查一次看趋势**，趋势稳定就观察，趋势上升就要重视+就医。

### Q3：抽血前要注意什么？
空腹8~12小时（血糖血脂要求空腹）、前一天避免大量饮酒和油腻大餐、避免剧烈运动、告知正在服用的药物（有些药影响化验）。女性月经期查血常规/铁可能受影响，可择期复查。

### Q4：营养素检测能一次全查吗？
不能也不需要。铁蛋白/维D/B12/叶酸/镁/锌/硒各有适用人群与时机，过度检查既花钱又可能造成焦虑。**按症状+风险人群+体检异常定向查**（比如贫血查铁代谢+B12/叶酸；骨松风险查维D+钙；素食查B12+铁）。

### Q5：为什么我吃得很素，血脂还是高？
素食者也可能高血脂，原因常是：精制碳水（米面糖）过多→TG高；植物油/坚果过量；坚果和椰子油等高饱和植物脂肪；加上运动不足。**"素"不等于"健康"，关键看整体结构。**

### Q6：补铁后多久能见效？
补铁后 Hb 一般4周左右开始回升，2~3个月多数可恢复；但**铁蛋白（储备）需要补足3~6个月**。所以别见Hb正常就停药，要复查铁蛋白。若补铁3个月Hb无改善→就医找原因（可能不是缺铁，或存在持续失血/吸收问题）。

### Q7：维生素D晒了太阳还缺，正常吗？
正常。纬度、季节、防晒霜、深肤色、穿长衣、室内工作都会影响合成。城市人群维D不足率很高，**食物+日晒+必要时补充**三管齐下，以化验为金标准。

### Q8：尿酸高但是不痛，要不要管？
要管。高尿酸不只是"会痛风"的问题，长期高尿酸与肾损伤、高血压、心血管病相关。无症状高尿酸也要生活方式干预（限酒、限果糖、多喝水、控制体重），是否需要药物由医生评估。

### Q9：血脂正常的人需要担心心血管吗？
需要看整体危险分层。血脂只是拼图一块，血压、血糖、吸烟、肥胖、家族史都在里面。**危险分层做出来是"高危"，血脂'正常'也可能要求LDL降得更低。** 请医生做整体风险评估。

### Q10：营养师推荐的饮食和医生的药冲突怎么办？
不冲突。营养方案是"辅助支持"，药物是"治疗"，两者并行。但**具体用药调整只由医生做**；营养师方案与医生方案有疑问时，以医生医嘱优先，并与医生沟通。

## ⚠️ 重要提醒（写进日常工作的三条铁律）

1. **化验参考范围各医院不一，以报告单标注为准。** 本文所有数值为"通用大致值"，供学习与沟通参考，不替代报告单。
2. **营养师解读化验单 = 营养评估辅助，诊断必须由医生完成。** 营养师的价值是"读趋势、找缺口、给饮食方案"，不是"下诊断、开治疗"。
3. **合规边界：** 营养健康类内容只做健康科普，不构成诊疗建议；异常指标请建议就医，个体情况请咨询专业医师。不引导问诊、不收集病情做线上诊断、不承诺疗效。

> **结束语：** 化验单是身体的"仪表盘"，营养师要学会读懂它，但更要懂得**界限**——把"找病"留给医生，把"找缺口、给方案"做好，才是真正的专业与安全。诊断学这门课，营养师学的是"看见"，医生练的是"确诊"，两者配合，顾客才最受益。
