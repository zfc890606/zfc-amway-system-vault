## 一、微生物学基础

### 1. 什么是微生物

微生物（Microorganism）是肉眼看不见或看不清、需借助显微镜才能观察的微小生物的总称。它们**无处不在**：空气、水、土壤、食物，以及人和动物体表与体内。

微生物的特点：

```
体积小、结构简单
   ├─ 种类多、数量大
   ├─ 繁殖快
   ├─ 分布广
   └─ 易变异（尤其病毒）
```

### 2. 微生物分类

#### 2.1 三大类（按细胞结构）

| 大类 | 细胞结构 | 代表 | 举例 |
|------|---------|------|------|
| **非细胞型微生物** | 无细胞结构，只有核酸+蛋白 | 病毒、朊粒 | 流感病毒、乙肝病毒 |
| **原核细胞型微生物** | 无核膜、无细胞器 | 细菌、支原体、衣原体、立克次体、螺旋体 | 大肠杆菌、肺炎支原体 |
| **真核细胞型微生物** | 有核膜、有细胞器 | 真菌 | 念珠菌、曲霉 |

#### 2.2 微生物分类详细表

| 类型 | 结构特点 | 大小 | 繁殖方式 | 与健康关系 |
|------|---------|------|---------|-----------|
| **细菌** | 原核单细胞，有细胞壁（肽聚糖） | 0.5-5μm | 二分裂 | 致病菌（沙门氏菌、结核杆菌）+ 益生菌（乳酸菌、双歧杆菌） |
| **支原体** | 无细胞壁（天然耐药） | 最小可独立生活的原核 | 二分裂 | 支原体肺炎 |
| **衣原体** | 专性细胞内寄生 | 0.2-0.5μm | 发育周期 | 沙眼、肺炎衣原体 |
| **立克次体** | 专性细胞内寄生（经节肢动物传播） | 0.3-0.6μm | 二分裂 | 斑疹伤寒 |
| **螺旋体** | 细长螺旋形 | 5-250μm | 二分裂 | 梅毒（苍白密螺旋体）、钩端螺旋体 |
| **真菌** | 真核，有细胞壁（几丁质） | 数μm-数cm | 出芽/产孢 | 念珠菌、皮肤癣菌、曲霉 |
| **病毒** | 无细胞，核酸+衣壳（可包膜） | 20-300nm | 复制（寄生于宿主细胞） | 感冒、流感、新冠、肝炎、艾滋病 |
| **朊粒** | 仅蛋白质（无核酸） | — | 异常折叠传染 | 疯牛病、克雅病 |

#### 2.3 微生物分类的记忆要点（营养师视角）

```
细菌 = "有细胞壁的独立小工厂"（多数，可被抗生素针对）
病毒 = "只有图纸和零件箱的寄生者"（必须劫持宿主细胞）
真菌 = "多细胞/单细胞真核"（人体感染多为条件致病）
```

### 3. 微生物与人类的关系（共生谱）

微生物与人类不是简单的"敌人"关系，而是**共生谱**：

```
致病菌（少数）  条件致病菌（多数）  正常菌群（绝大多数）
   可引起疾病      机会性感染          共生于体表/体内
```

| 关系 | 说明 | 例子 |
|------|------|------|
| **共生（互利）** | 双方受益 | 肠道菌群帮我们消化纤维、合成维K，我们提供栖息地 |
| **共栖（无害）** | 一方受益、一方不受影响 | 皮肤葡萄球菌 |
| **寄生（致病）** | 病原体伤害宿主 | 霍乱弧菌、伤寒杆菌 |
| **条件致病** | 正常状态下不致病，条件改变时致病 | 免疫低下时肠道大肠杆菌移位入血 |

> 微生物学第9版核心观点：**人体携带的绝大多数微生物是"朋友"或"中立者"，只有少数是"敌人"。** 营养师的目标不是"杀菌"，而是"养好菌、防坏菌"。

### 4. 人体正常菌群

#### 4.1 概念与数量

- **正常菌群（Normal Flora）**：长期定居在人体体表和与外界相通的腔道（肠道、口腔、呼吸道、泌尿生殖道、皮肤）中的微生物群落。
- **数量**：人体携带的微生物细胞约**38万亿**，与人体自身细胞数量大致相当（近年研究修正为接近1:1或略多）。
- **基因量**：肠道菌群的基因总数（"微生物组"）比人类基因组大100倍以上——所以菌群又被称为"**第二基因组**"。

#### 4.2 各部位正常菌群分布

| 部位 | 主要菌群 | 营养/健康意义 |
|------|---------|--------------|
| **肠道** | 拟杆菌门、厚壁菌门为主（占95%以上），另有放线菌门、变形菌门 | 最庞大最重要的菌群 |
| **皮肤** | 葡萄球菌、棒状杆菌、丙酸杆菌 | 屏障防御 |
| **口腔** | 链球菌、奈瑟菌、厌氧菌 | 口腔健康与心血管（牙周菌） |
| **呼吸道** | 链球菌、葡萄球菌、莫拉菌 | 上呼吸道定植 |
| **泌尿生殖道** | 乳杆菌（阴道优势菌） | ★阴道微生态与乳杆菌 |
| **胃** | 数量少（酸环境） | 幽门螺杆菌为病原 |

#### 4.3 正常菌群的生理作用（四大防线）

| 作用 | 机制 | 营养关联 |
|------|------|---------|
| **生物屏障（占位效应）** | 正常菌群占据黏膜结合位点，阻止致病菌定植 | 菌群失调→致病菌乘虚而入 |
| **营养作用** | 合成维K、部分B族维生素；发酵纤维产SCFA | ★膳食纤维→SCFA |
| **免疫训练** | 持续刺激肠道免疫系统成熟（"磨刀"） | 无菌动物免疫发育不全 |
| **抗肿瘤/代谢作用** | 降解有害物质、调节代谢 | 菌群与结直肠癌、肥胖 |

> **一句话：正常菌群是我们的"定居边防军"——占着位置、产着养分、练着免疫。** 这就是为什么"养菌"（益生元）比"杀菌"重要。

#### 4.4 正常菌群失调（Dysbiosis）

菌群失调 = 正常菌群的**种类、数量、比例**异常改变。

| 失调类型 | 表现 | 常见原因 |
|---------|------|---------|
| 比例失调 | 优势菌被抑制，劣势菌增多 | 抗生素、腹泻 |
| 定位转移 | 肠道菌跑到不该去的地方 | 肠屏障受损→菌入血 |
| 自身感染 | 正常菌变致病 | 免疫低下 |

> 营养师关联：**菌群失调的三大推手——抗生素、高糖高脂低纤维饮食、长期压力/睡眠差。**

### 5. 条件致病菌（机会性病原体）

- 定义：**正常时不致病，但特定条件下致病的微生物。**
- 三个促成条件：
  ```
  ① 寄居部位改变（如大肠杆菌跑到尿道→尿路感染）
  ② 宿主免疫功能低下（化疗、艾滋、老年、营养不良）
  ③ 菌群失调（抗生素后，耐药的艰难梭菌过度生长）
  ```

> 例子：肠道大肠杆菌→尿路感染；口腔链球菌→感染性心内膜炎；抗生素后→艰难梭菌肠炎。**营养师要讲：营养良好+菌群平衡=条件致病菌"没机会"。**

### 6. 益生菌（Probiotics）

#### 6.1 定义（WHO/FAO 2001）

> 益生菌是**活的微生物**，当**给予足够数量**时，能对宿主健康产生益处。

三个关键词缺一不可：**①活的 ②足够数量 ③健康益处**。

#### 6.2 常见益生菌菌株与证据（详细表）

| 菌株 | 常见商品名/来源 | 有证据的作用 | 证据等级 |
|------|----------------|-------------|---------|
| **双歧杆菌属** Bifidobacterium（长双歧、动物双歧/乳双歧、婴儿双歧） | 酸奶/补充剂 | 便秘调节；抗生素相关腹泻减轻；调节肠道菌群 | 中-强 |
| **乳酸杆菌属** Lactobacillus（嗜酸乳杆菌、鼠李糖乳杆菌GG、罗伊氏乳杆菌、干酪乳杆菌） | 酸奶/补充剂 | 感染性腹泻缩短；抗生素相关腹泻；LGG预防儿童腹泻；阴道健康（鼠李糖/罗伊氏） | 中-强 |
| **布拉氏酵母菌** Saccharomyces boulardii | 补充剂 | **抗生素相关腹泻（AAD）预防**；旅行者腹泻 | 强（meta分析） |
| **嗜酸乳杆菌** | 酸奶 | 乳糖不耐受辅助（产β-半乳糖苷酶） | 中 |
| **嗜热链球菌** | 酸奶发酵菌 | 乳糖消化辅助 | 中 |
| **凝结芽孢杆菌** | 补充剂 | 便秘/腹泻（芽孢耐胃酸） | 中 |

#### 6.3 益生菌的"菌株特异性"（必讲）

> **铁律：益生菌作用是"菌株特异性"的——某一个菌株有效，不代表同属其他菌株、更不代表"所有益生菌"有效。**

```
"益生菌"是一个类别（像"蔬菜"）
不同菌株 = 不同蔬菜
"吃蔬菜健康"≠"吃特定某款就能解决特定问题"
某一菌株对A有效 ≠ 对B也有效 ≠ 同一个菌对所有人都有效
```

**选益生菌的四个"够不够"（营养师可用）：**

| 维度 | 标准 | 说明 |
|------|------|------|
| 活的 | 冷链/微胶囊/芽孢菌 | 死的没意义（后生元另说） |
| 足量 | ≥10⁸-10⁹ CFU/日（常见有效剂量） | 剂量不足=无效 |
| 定植/持续 | 需连续补充 | 多数菌株不长期定植，停后渐退 |
| 对症 | 选对菌株（看证据） | 不同问题选不同菌株 |

#### 6.4 益生菌的安全边界

- **健康人群**：总体安全（轻度腹胀一过性）。
- **重症/免疫缺陷人群**（深静脉置管、重症胰腺炎、严重免疫缺陷）：**需谨慎**——有报道益生菌菌血症/真菌血症，应在医生指导下使用。
- **不耐受/过敏**：牛奶蛋白过敏者注意载体。

#### 6.5 益生菌 vs 益生元 vs 合生元 vs 后生元（概念辨析）

| 概念 | 定义 | 例子 |
|------|------|------|
| **益生菌** Probiotics | 活的、足量、有益健康的微生物 | 双歧杆菌、乳酸杆菌 |
| **益生元** Prebiotics | 选择性被宿主微生物利用、产生健康益处的底物 | 低聚果糖、菊粉、抗性淀粉、母乳低聚糖 |
| **合生元** Synbiotics | 益生菌+益生元组合 | 益生菌+菊粉 |
| **后生元** Postbiotics | 灭活的菌体或菌体代谢产物 | 丁酸、灭活菌 |

> 营养师定位：**对大多数人，先喂好菌（益生元=吃纤维）比直接补菌（益生菌）更根本、更经济、更持久。**

| 知识点 | 讲给顾客听 |
|--------|-----------|
| 微生物分类 | "病毒只有图纸和零件，必须借你细胞的工厂来复制；细菌是有细胞壁的独立小工厂" |

## 二、肠道菌群（营养师热点）

### 1. 为什么肠道菌群是"热点"

```
肠道菌群
   ├─ 数量最庞大（10¹³-10¹⁴个，占人体微生物90%以上）
   ├─ 代谢最活跃（发酵纤维、产SCFA、合成维生素）
   ├─ 与免疫直接对话（肠道相关淋巴组织GALT=人体最大免疫器官）
   ├─ 通过肠-脑轴/肠-肝轴/肠-肺轴影响全身
   └─ 与代谢病/免疫病/神经疾病均有观察性关联
```

### 2. 肠道菌群的组成

#### 2.1 主要门类（成人健康菌群）

| 门 | 占比 | 代表属 | 作用 |
|----|------|--------|------|
| **厚壁菌门** Firmicutes | ~50-60% | 粪杆菌属（产丁酸）、乳杆菌、梭菌 | 纤维发酵、SCFA |
| **拟杆菌门** Bacteroidetes | ~20-40% | 拟杆菌属 | 降解多糖、免疫调节 |
| **放线菌门** Actinobacteria | 少数 | 双歧杆菌属 | 益生菌核心成员 |
| **变形菌门** Proteobacteria | 少数 | 大肠杆菌 | 数量↑常提示菌群失调（"预警"） |
| 疣微菌门 | 少数 | 阿克曼菌 | 与瘦、代谢健康相关（研究热点） |

> 经典的"厚壁菌门/拟杆菌门比值（F/B比）"与肥胖的关系**证据有争议**，营养师**不宜用单一比值给顾客下结论**。更可靠的是"多样性↑=更健康"的方向性表述。

#### 2.2 菌群多样性的意义

- **多样性高** = 菌群"抗打击能力强"（更像健康的热带雨林）。
- **多样性低** = 菌群脆弱（更像单一物种的农田，一场病就崩）。
- 现代生活方式（高加工饮食、抗生素、卫生条件）普遍降低菌群多样性。

### 3. 肠道菌群的功能（功能总表）

| 功能 | 具体内容 | 营养关联 |
|------|---------|---------|
| **发酵膳食纤维** | 产生**短链脂肪酸SCFA**（乙酸、丙酸、丁酸） | ★丁酸=结肠细胞主要燃料，抗炎 |
| **合成维生素** | 维K、部分B族（B12、叶酸、B7） | 长期广谱抗生素者可能缺乏 |
| **能量与代谢调节** | 影响能量提取、脂肪储存、胰岛素敏感性 | 菌群与肥胖/糖尿病 |
| **免疫调节** | 训练肠道免疫、诱导Treg（抗炎）、维持免疫耐受 | "肠道是最大免疫器官" |
| **黏膜屏障保护** | 加强肠上皮紧密连接、占位防定植 | 屏障功能与"肠漏"相关 |
| **生物转化** | 代谢胆汁酸、药物、外源物 | 影响血脂与药物 |
| **肠-脑轴** | 通过迷走神经/神经递质（5-HT、GABA）影响脑 | 菌群与情绪/认知（观察性） |
| **肠-肝轴** | 门静脉把菌群代谢物送肝 | 菌群与脂肪肝 |
| **抗病原** | 产抗菌物质、竞争营养 | 防感染性腹泻 |

#### 短链脂肪酸（SCFA）——营养师必讲

| SCFA | 主要作用 |
|------|---------|
| **丁酸**（Butyrate） | 结肠细胞主要燃料；抗炎（抑制NF-κB）；增强屏障；诱导Treg |
| 丙酸 | 肝脏糖异生底物；调节食欲（观察） |
| 乙酸 | 脂肪合成底物；肌肉/外周代谢底物 |

> SCFA是"纤维→好菌→健康"链条的核心中间产物：**吃纤维→菌群发酵→SCFA→抗炎+养肠+护代谢。**

### 4. 肠道菌群的建立与发育

| 阶段 | 影响因素 | 后果 |
|------|---------|------|
| **宫内/出生** | 分娩方式：顺产（获得母亲阴道/粪便菌）vs **剖宫产**（皮肤/环境菌） | 剖宫产婴儿早期菌群差异，与部分免疫/代谢风险关联（观察性，非因果） |
| **哺乳期** | **母乳**含母乳低聚糖（HMO，天然的益生元）+ 母乳菌群 | 双歧杆菌占优（"双歧杆菌期"） |
| **辅食期** | 引入固体食物、多样化 | 菌群向成人型过渡 |
| **儿童-成人** | 饮食、抗生素、生活方式 | 逐步稳定，但抗生素会反复冲击 |
| **老年** | 多样性下降、炎症↑ | 与衰弱/慢病相关 |

> 严谨表述：剖宫产/配方奶与菌群差异是**观察性关联**，不能直接说"剖宫产=菌群坏=必得病"。营养师可讲"早期菌群差异"，但**不做因果恐吓**。

### 5. 影响肠道菌群的因素（因素总表）

| 因素 | 影响方向 | 营养干预可行性 |
|------|---------|---------------|
| **饮食结构（最重要）** | 高纤维→好菌↑；高脂高糖低纤维→坏菌↑、多样性↓ | ★★★★★ |
| **抗生素** | 多样性骤降，致病菌/艰难梭菌趁虚而入 | 必要时补充益生菌（辅助） |
| **益生菌/益生元** | 定向补充/喂养 | ★★★★ |
| **膳食模式** | 地中海饮食/植物性饮食→多样性↑；西式高加工→多样性↓ | ★★★★★ |
| **运动** | 适度运动与多样性↑相关（观察） | ★★★ |
| **压力/睡眠** | 通过肠-脑轴影响菌群 | ★★★ |
| **剖宫产/母乳** | 早期定植差异 | 生命早期 |
| **年龄** | 老年多样性↓ | 长期饮食 |
| **药物** | 抗生素、质子泵抑制剂、部分降糖药 | 遵医嘱 |
| **吸烟/酒精** | 多样性↓ | ★★★ |

### 6. 益生元（养菌的食物）——营养师核心工具

#### 6.1 定义与机制

益生元 = 不被宿主消化吸收、但能被肠道有益菌选择性利用、产生健康益处的**膳食成分**（主要是膳食纤维）。

```
益生元（纤维）→ 进入结肠 → 好菌发酵 → SCFA + 好菌增殖 → 健康益处
```

#### 6.2 常见益生元种类

| 益生元 | 食物来源 | 说明 |
|--------|---------|------|
| **低聚果糖（FOS）** | 洋葱、大蒜、芦笋、香蕉、菊芋 | 经典益生元 |
| **菊粉（Inulin）** | 菊苣、大蒜、洋葱 | 双歧杆菌增殖 |
| **低聚半乳糖（GOS）** | 豆类、母乳（HMO） | 双歧杆菌 |
| **抗性淀粉** | 冷却的米饭/土豆、生燕麦、青香蕉 | 丁酸产生菌 |
| **β-葡聚糖** | 燕麦、大麦 | 兼有降脂作用 |
| **木质素/纤维素** | 全谷物、蔬菜 | 增加粪便体积 |

#### 6.3 膳食纤维总建议

| 机构 | 建议 |
|------|------|
| 中国营养学会 | 膳食纤维 **25-30 g/日** |
| 美国膳食指南 | 14g/1000 kcal |
| 实际摄入 | 中国居民多数 **<15 g/日**（普遍不足） |

> 营养师行动项：**绝大多数人缺的不是益生菌，是给益生菌吃的"饭"（纤维）。** 先吃够25-30g纤维（全谷物、豆类、蔬菜、水果、坚果），再谈补菌。

#### 6.4 增加纤维的注意事项

- **循序渐进**：突然大量纤维→腹胀/排气（菌群需要适应期）。
- **同时足量饮水**：纤维需要水"发开"。
- **特殊人群**：肠易激综合征（IBS）部分人需低FODMAP，纤维要个体化（遵医嘱/营养师指导）。

### 7. 菌群与慢病（有证据的关联）

#### 7.1 菌群与慢病关联总表

| 疾病 | 菌群改变（观察） | 因果程度 | 营养师怎么讲 |
|------|----------------|---------|-------------|
| **肥胖/2型糖尿病** | 多样性↓、特定菌改变、产SCFA菌↓ | 有动物因果证据；人体多为关联 | "菌群和代谢互相影响" |
| **炎症性肠病（IBD）** | 菌群失调、丁酸菌↓ | 有作用，但病因复杂（遗传+免疫+菌群） | 不能替代治疗 |
| **结直肠癌** | 特定菌（如具核梭杆菌）↑ | 关联 | 纤维防癌有充分证据 |
| **心血管病** | 肠道菌代谢胆碱/肉碱→TMAO（氧化三甲胺） | 观察+机制研究 | 红肉与TMAO（注意严谨） |
| **神经疾病（帕金森、阿尔茨海默、抑郁）** | 菌群改变（肠-脑轴） | 多为早期/观察性 | "肠-脑轴很热，但仍是研究前沿" |
| **过敏/哮喘** | 早期菌群多样性与过敏 | 关联，混杂多 | 多样饮食 |
| **非酒精性脂肪肝** | 菌群改变、肠-肝轴 | 关联+机制 | 控代谢+纤维 |

#### 7.2 科学 vs 炒作的边界（核心立场）

```
✅ 有较强证据：
   - 抗生素相关腹泻 → 布拉氏酵母菌/部分乳杆菌预防（meta分析）
   - 感染性/旅行者腹泻 → 部分菌株缩短病程
   - 便秘 → 部分双歧杆菌/乳杆菌改善
   - 膳食纤维 → 养菌+代谢+结直肠癌保护（充分证据）

⚠️ 关联性证据（不能承诺疗效）：
   - 肥胖/糖尿病"调菌减肥/控糖"
   - 焦虑抑郁"益生菌抗抑郁"
   - "调节菌群治XX"

❌ 无证据/夸大：
   - "排毒""宿便""全身清肠"
   - "某个菌株包治百病"
   - "益生菌=药"
```

> **铁律：证据是关联性，不是因果性。** 菌群与慢病的关系，绝大多数是"相关联"而非"调整菌群就能治愈"。营养师要讲"养菌是健康生活方式的一部分"，**不能承诺"吃某种菌/菌群调整能治病"。**

### 8. 关于"肠漏"（Leaky Gut）——必须严谨

#### 8.1 真实存在的生理概念

- **肠黏膜屏障**：由肠上皮细胞+紧密连接+黏液层+肠道免疫构成，正常情况下**选择性通透**（吸收营养、挡住大分子和细菌）。
- **肠道通透性增加**：紧密连接松动→大分子/细菌产物（如内毒素LPS）更多进入固有层和血液——这是一个**真实、可测量的生理现象**（可通过乳果糖/甘露醇比值等检测）。
- 与**炎症性肠病、乳糜泻**等**明确相关**（这些疾病存在屏障破坏）。

#### 8.2 商业炒作 vs 科学

| 说法 | 判断 | 说明 |
|------|------|------|
| "肠漏是一种明确诊断的疾病" | ❌ | **现代医学没有"肠漏症（leaky gut syndrome）"这个正式诊断** |
| "肠漏导致全身所有病" | ❌ | 夸大一因多果 |
| "肠道通透性增加是真实生理现象" | ✅ | 有科学基础 |
| "某些疾病存在屏障功能受损" | ✅ | IBD、乳糜泻、重症、部分代谢病研究 |
| "多吃XX产品能"治好"肠漏" | ❌ | 无循证"肠漏治疗"产品 |
| "纤维/益生元/健康饮食支持肠道屏障" | ✅ | 有合理机制（SCFA养上皮、丁酸强化紧密连接） |

#### 8.3 营养师严谨话术

> **讲"肠道屏障功能"比讲"肠漏"更严谨。** 可以这样说：
>
> - "肠道有一道'选择性门卫'（屏障），正常情况下只放进该放的小分子营养，挡住不该进的大分子和细菌。"
> - "有些疾病状态下这道'门'会松一些（通透性增加），我们叫屏障功能受损。"
> - "保持肠道屏障健康的生活方式：膳食纤维养菌产丁酸、均衡营养、少酒精、管理压力。"
> - **不承诺**"吃XX能'治'肠漏"、"肠漏是XX病的根因"、"每个人都该测肠漏"。

> ⚠️ **合规与伦理铁律：** 不贩卖"肠漏"焦虑；不推荐"排毒/清肠"产品；不引导顾客"把症状发我帮你判断是不是肠漏"（不引导问诊）。

## 三、免疫学基础

### 1. 免疫系统的"双轨制"（固有 vs 适应性）

#### 1.1 总览

```
免疫系统（Immune System）
   │
   ├─ 固有免疫（先天免疫 Innate Immunity）
   │    ├─ 特点：快（小时级）、非特异性、无免疫记忆
   │    ├─ 组成：皮肤黏膜屏障、吞噬细胞（巨噬细胞/中性粒细胞）、
   │    │       NK细胞、补体、模式识别受体（PRR）
   │    └─ 作用：第一时间清除大部分病原，并"报告敌情"
   │
   └─ 适应性免疫（获得性免疫 Adaptive Immunity）
        ├─ 特点：慢（首次需数天）、特异性强、有免疫记忆
        ├─ 组成：T细胞（细胞免疫）、B细胞/抗体（体液免疫）
        └─ 作用：精准清除特异性病原，下次快速响应（记忆）
```

#### 1.2 固有免疫 vs 适应性免疫对比表

| 特征 | 固有免疫 | 适应性免疫 |
|------|---------|-----------|
| 出现时间 | 出生即有 | 接触抗原后获得 |
| 响应速度 | 快（数分钟-数小时） | 慢（首次数天） |
| 特异性 | 低（识别"共有的危险信号"） | 高（识别"特定的抗原决定簇"） |
| 记忆性 | 无 | **有**（免疫记忆） |
| 主要成分 | 屏障、吞噬细胞、NK、补体 | T细胞、B细胞/抗体 |
| 应答特点 | 固定模式 | 可增强、可调节 |
| 与营养关系 | 屏障（蛋白/维A/维C/锌） | 免疫细胞生成（蛋白/锌/铁/维D） |

#### 1.3 免疫系统的"三道防线"

```
第一道：物理/化学屏障
   皮肤、黏膜、纤毛、胃酸、溶菌酶、正常菌群
   ↓（病原突破）
第二道：固有免疫
   吞噬细胞、NK细胞、补体、炎症反应
   ↓（病原突破）
第三道：适应性免疫
   T细胞（细胞免疫）+ B细胞/抗体（体液免疫）→ 免疫记忆
```

> 营养师要讲：**"免疫力"= 三道防线一起在线。** 任何一道薄弱（皮肤破损、黏膜屏障差、免疫细胞生成原料不足）都会影响整体。

### 2. 免疫器官（免疫系统的"军营"）

#### 2.1 中枢免疫器官（免疫细胞"诞生/培训地"）

| 器官 | 位置 | 功能 | 营养相关 |
|------|------|------|---------|
| **骨髓**（Bone Marrow） | 长骨、扁骨 | 造血干细胞→各类血细胞；**B细胞在此成熟** | 蛋白/铁/叶酸/B12——造血原料 |
| **胸腺**（Thymus） | 前上纵隔 | **T细胞在此成熟**、教育（阳性/阴性选择）；随年龄萎缩 | ★蛋白质-能量营养不良→胸腺萎缩 |

> ★关键：**蛋白质-能量营养不良导致胸腺萎缩、T细胞生成减少**——这是"吃不够蛋白→免疫力下降"最直接的病理学证据。

#### 2.2 外周免疫器官（免疫应答"战场"）

| 器官 | 功能 |
|------|------|
| **淋巴结** | T/B细胞聚集地；过滤淋巴液 |
| **脾脏** | 过滤血液；清除衰老红细胞/病原 |
| **黏膜相关淋巴组织（MALT）** | 肠道GALT、呼吸道BALT——**肠道是最大免疫器官** |
| 扁桃体 | 口咽部防线 |

> 营养师要讲：**肠道相关淋巴组织（GALT）是人体最大的免疫器官**——人体约70-80%的免疫细胞分布在肠道。所以"养肠道=养免疫"是有解剖学基础的。

### 3. 免疫反应过程（从入侵到清除）

#### 3.1 完整链条（营养师可讲版）

```
① 病原入侵 → 突破第一道（皮肤黏膜）
   ↓
② 固有免疫"报警+初战"
   巨噬细胞/树突状细胞识别（PRR）→ 吞噬 → 分泌细胞因子
   → 炎症反应（红热肿痛）→ 招募更多免疫细胞
   ↓
③ 抗原呈递（"通报敌情"）
   树突状细胞携带抗原 → 到淋巴结 → 呈递给T细胞
   ↓
④ 适应性免疫激活（"精准打击部队"）
   CD4+ T辅助细胞 → 指挥
   ├─ CD8+ T细胞 → 杀伤被感染细胞/肿瘤细胞（细胞免疫）
   └─ B细胞 → 浆细胞 → 产生抗体（体液免疫）
   ↓
⑤ 清除病原（抗体中和/吞噬细胞清除/CTL杀伤）
   ↓
⑥ 免疫记忆（"记住敌人"）
   记忆T细胞/记忆B细胞 → 下次快速、更强的应答
```

#### 3.2 疫苗为什么有效（免疫记忆的应用）

```
疫苗 = 人为输入"无害的敌人"（灭活/减毒/重组抗原/mRNA）
   ↓
不致病，但训练免疫系统产生记忆
   ↓
真的病原入侵时 → 记忆细胞快速响应 → 病毒还没站稳就被清除
```

> 营养师要讲：**疫苗是"训练免疫记忆"，营养是"提供训练和打仗的原料"——两者不冲突，相辅相成。**

### 4. 免疫细胞全表（免疫学第9版）

| 细胞 | 属于 | 主要功能 | 营养相关 |
|------|------|---------|---------|

#### 免疫细胞记忆要点

```
免疫细胞 = "军队编制"
   ├─ 中性粒细胞 = 前线快速反应部队（最多）
   ├─ 巨噬细胞 = 巡逻+清道夫+情报员
   ├─ 树突状细胞 = 情报官（把敌人特征报告给T）
   ├─ CD4 T = 指挥官
   ├─ CD8 T = 特种兵（精确打击）
   ├─ B/浆细胞 = 兵工厂（造抗体弹药）
   └─ NK细胞 = 夜间巡逻队（不挑食，见异常就杀）
```

### 5. 抗体与体液免疫

#### 5.1 抗体（免疫球蛋白 Ig）五大类

| 类别 | 特点 | 作用 |
|------|------|------|
| **IgG** | 血清中最多（约75%）；唯一能过胎盘 | 二次应答主力；中和毒素/病毒 |
| **IgA** | 分泌型（sIgA）在黏膜表面 | ★黏膜第一道抗体防线（肠道/呼吸道） |
| **IgM** | 最早出现（初次应答） | 感染早期标志 |
| **IgE** | 与过敏相关 | 肥大细胞脱颗粒→过敏反应 |
| **IgD** | B细胞表面受体 | — |

> 营养关联：**sIgA（分泌型IgA）是肠道/呼吸道黏膜的"哨兵抗体"，蛋白质营养充足→sIgA合成正常。** 蛋白缺乏→黏膜抗体减少→呼吸道/肠道感染风险↑。

#### 5.2 抗体作用方式

```
抗体中和病原/毒素
   ├─ 中和病毒（阻止进入细胞）
   ├─ 中和毒素
   ├─ 调理作用（标记病原→促吞噬）
   ├─ 激活补体（溶菌）
   └─ 阻止病原黏附黏膜
```

### 6. 免疫记忆与二次应答

| 特征 | 初次应答 | 二次应答 |
|------|---------|---------|
| 潜伏期 | 长（数天） | 短（数小时-1天） |
| 抗体峰值 | 低 | **高**（数十倍） |
| 抗体类型 | 主要为IgM | 主要为IgG |
| 持续时间 | 短 | 长 |
| 意义 | 首次感染 | 疫苗效果、再次感染快速清除 |

> 这就是为什么"打过疫苗/得过一次，再遇到同一种病原就不那么怕"——免疫系统记得它。

### 7. 免疫耐受、自身免疫与超敏反应（营养师要懂边界）

#### 7.1 免疫耐受与自身免疫

- **免疫耐受**：免疫系统对"自己"不攻击（中枢+外周耐受机制）。
- **自身免疫病**：耐受被打破→攻击自身组织（1型糖尿病、类风湿、桥本甲状腺炎、系统性红斑狼疮）。
- **营养关联**：维D缺乏与自身免疫风险（观察）；n-3抗炎可能改善部分炎症性自身免疫病症状（辅助，非治疗）。

#### 7.2 超敏反应（过敏）四型

| 型 | 名称 | 机制 | 例子 | 营养关联 |
|----|------|------|------|---------|
| **I型** | 速发型 | IgE+肥大细胞脱颗粒 | 花粉、食物过敏、过敏性鼻炎、哮喘 | 母乳喂养与早期过敏（观察）；维D与过敏（证据不一） |
| **II型** | 细胞毒型 | 抗体攻击细胞 | 溶血性贫血 | — |
| **III型** | 免疫复合物型 | 抗原抗体复合物沉积 | 狼疮肾炎 | — |
| **IV型** | 迟发型 | T细胞介导 | 接触性皮炎、结核肉芽肿 | — |

> ⚠️ **营养师边界：** 食物过敏/食物不耐受是两回事，要分清（详见下），**不做食物过敏的自行诊断**，引导就医明确。

| 概念 | 本质 | 例子 |
|------|------|------|
| **食物过敏** | 免疫介导（IgE为主） | 花生、牛奶蛋白、虾 |
| **食物不耐受** | 非免疫（酶缺乏等） | 乳糖不耐受（乳糖酶缺乏） |
| **乳糜泻** | 自身免疫（麸质） | 需严格无麸质饮食（医疗诊断） |

## 四、营养与免疫（免疫营养学）

### 1. 营养不良与免疫（经典免疫营养学）

#### 1.1 蛋白质-能量营养不良（PEM）与免疫

**这是营养与免疫关系中最确凿的证据基础：**

```
蛋白质-能量营养不良
   ├─ 胸腺萎缩（T细胞训练基地变小）
   ├─ 淋巴细胞总数↓（尤其T细胞）
   ├─ 细胞免疫功能↓（迟发型超敏反应减弱）
   ├─ 分泌型IgA↓（黏膜防线变弱）
   ├─ 补体成分↓（C3等）
   ├─ 吞噬细胞功能↓（杀菌能力下降）
   └─ 疫苗应答减弱（接种后抗体滴度低）
```

**结果：** 严重营养不良者**感染风险显著升高、感染更重、病程更长**。这是全球儿童死亡的重要原因（营养-感染恶性循环）。

```
营养不良 → 免疫力↓ → 感染↑ → 感染消耗营养 → 营养不良加重（恶性循环）
```

> 营养师讲法："吃不够蛋白→免疫部队'没兵没弹药'→容易生病；生病又消耗蛋白→更虚。这个恶性循环要打破。"

#### 1.2 微量营养素缺乏与免疫

| 营养素缺乏 | 免疫后果 |
|-----------|---------|
| 锌缺乏 | 胸腺萎缩、T细胞减少、伤口不愈、腹泻↑ |
| 铁缺乏 | 免疫细胞增殖受影响（淋巴细胞增殖需铁）；**注意：铁过载也有害** |
| 维A缺乏 | 黏膜屏障受损、感染风险↑（儿童尤甚） |
| 维D缺乏 | 固有/适应性免疫调节受损；呼吸道感染风险（观察+部分RCT） |
| 维C缺乏 | 免疫细胞抗氧化能力↓、皮肤屏障受损 |
| 硒缺乏 | 谷胱甘肽过氧化物酶活性↓；病毒感染（观察） |
| B族（B6/B12/叶酸）缺乏 | 免疫细胞增殖/抗体合成原料不足 |

#### 关键结论（营养师必背）

```
① 蛋白质是免疫的"第一原料"——抗体、补体、免疫细胞都是蛋白。
② 微量营养素是"辅料/催化剂"——锌、铁、维A、维D、维C、B族。
③ 膳食纤维养菌是"养免疫的后勤线"——肠道免疫70%。
④ 没有任何单一营养素能"单独提升免疫力"——要整体均衡。
```

### 4. 提高免疫的正确 vs 错误说法

#### 4.1 有证据 vs 无证据对照表

| ✅ 有证据/合理 | ❌ 不科学/夸大 |
|---------------|--------------|
| 均衡营养（蛋白质+微量营养素+纤维） | "XX一吃免疫力暴涨" |

| **疫苗（预防感染最有效的措施）** | "营养到位就不用打疫苗" |
| 戒烟限酒 | 吸烟酗酒+狂补营养 |

#### 4.2 睡眠、运动、压力与免疫（生活方式三角）

| 因素 | 免疫影响 | 证据 |
|------|---------|------|
| **睡眠不足** | 感染风险↑（睡眠<6h vs 7-8h 感冒风险升高）；疫苗应答↓ | 观察+RCT（部分） |
| **适度运动** | 增强免疫监视、降低上呼吸道感染风险（规律中等强度） | 观察+meta |

| **慢性压力** | 皮质醇持续升高→免疫抑制 | 机制+观察 |
| **积极心态/社交** | 与健康相关（混杂多） | 观察 |

> **核心话术：** "免疫力不是补出来的，是养出来的——睡够、吃均衡、动起来、管好压力、打疫苗。"

#### 4.3 "提升免疫力"的正确表述框架

```
"免疫力"不是越高越好（过高=自身免疫/过敏）
→ 正确表述："免疫平衡"（不强不弱，能打能收）
→ 营养目标：提供免疫系统正常运转的原料，让它在需要时能快速响应
→ 生活方式：睡眠+运动+压力管理+疫苗
```

> 讲给顾客：**我们要的不是"免疫亢进"，是"免疫在线且不误伤自己"。** 过度宣传"猛提免疫"既不科学也危险（可能诱导过度免疫）。

## 五、感染与营养

### 1. 感染期的代谢变化（为什么感染要"吃好"）

```
感染/发热
   ├─ 体温每升高1℃ → 基础代谢率约↑13%
   ├─ 炎症因子（IL-1、IL-6、TNF）→ 肌肉蛋白分解↑（供氨基酸做免疫原料）
   ├─ 糖异生↑、脂肪动员↑
   ├─ 食欲↓（中枢机制）
   └─ 抗氧化需求↑（炎症产生ROS）
```

**净效应：** 感染期是**高分解、高消耗**状态——能量和蛋白质的需求都上升，而食欲往往下降。这正是感染期营养支持的病理逻辑。

### 2. 感染期营养原则

| 原则 | 说明 | 依据 |
|------|------|------|
| **能量充足** | 满足高代谢需求，避免负平衡 | 代谢↑ |
| **高蛋白** | 1.2-1.5 g/kg/d（重症遵医嘱更高），对抗分解、供免疫原料 | 肌肉分解↑、抗体合成 |
| **易消化** | 软食、半流质、少量多餐 | 食欲差、消化功能↓ |
| **充足饮水** | 发热出汗丢失、稀释分泌物 | 水合状态 |
| **补维C/锌** | 部分研究缩短感冒病程（非预防） | 证据中等 |
| **口服营养补充（必要时）** | 经口不足时ONS/管饲 | 防摄入不足 |
| **肠道微生态** | 益生菌可能减少抗生素相关腹泻（特定菌株） | meta证据 |

### 3. 常见感染场景的营养对策

#### 3.1 普通感冒/呼吸道感染

| 误区 | 真相 |
|------|------|
| "感冒忌口鸡蛋/肉/海鲜" | ❌ 无科学依据；**反而需要优质蛋白**（免疫原料） |
| "发烧饿治（饿一顿就好）" | ❌ 能量不足拖恢复 |
| "大剂量维C治感冒" | ⚠️ 不能治愈；**补充维C（每日<1g）可能使病程略缩短（数小时-半天），不能预防** |
| "补锌狂吃" | 锌含片在**早期**（<24h）可能缩短病程（部分研究）；长期大量有害 |
| "抗生素当消炎药" | ❌ 抗生素只对细菌，感冒多为病毒 |

> 维C与锌的严谨表述：meta分析显示规律补充维C对普通人群感冒预防**无显著获益**（马拉松等特殊人群除外），但可轻微缩短病程；锌含片早期使用可能缩短病程。**讲"可能缩短一点、不能预防、别过量"。**

#### 3.2 胃肠感染（腹泻）

| 原则 | 说明 |
|------|------|
| **补液第一** | 口服补液盐（ORS）是关键（WHO）——脱水是最大危险 |
| 益生菌 | 特定菌株（鼠李糖乳杆菌GG、布拉氏酵母菌）缩短感染性腹泻病程（有meta证据） |
| 补锌 | 儿童急性腹泻补锌缩短病程（WHO推荐，10-14天） |
| 饮食 | 易消化、低纤维、少量多餐；**避免高纤维/奶制品（乳糖不耐受风险）** |
| 误区 | "腹泻就要禁食" ❌——现在主张尽早恢复进食 |

#### 3.3 发热患者

| 要点 | 说明 |
|------|------|
| 补水 | 每发热1℃需增加水分 |
| 能量蛋白 | 高能量高蛋白易消化 |
| 少量多餐 | 克服食欲差 |
| 不要"捂汗/饿治" | 捂汗有风险，饿治无依据 |

### 4. 感染期营养的常见误区（总表）

| 误区 | 纠正 |
|------|------|
| "感冒忌口发物（鸡蛋、肉、海鲜）" | 无依据；需优质蛋白 |
| "发烧饿治" | 能量不足拖恢复 |
| "生病要多补维生素丸" | 均衡优先，勿超大剂量 |
| "抗生素=消炎药，感冒也吃" | 抗生素只对细菌 |
| "腹泻就禁食" | 尽早恢复进食，补液优先 |
| "越补免疫力越快好" | 营养是支持，不是"直接杀病毒"的药 |
| "喝浓茶/咖啡提神恢复" | 咖啡因+脱水+影响休息 |

> **营养师定位：** 感染期营养是"给免疫系统送弹药、给身体供能量"，**不是直接抗感染的"药"。** 重症感染必须就医，营养支持是辅助不是替代。
