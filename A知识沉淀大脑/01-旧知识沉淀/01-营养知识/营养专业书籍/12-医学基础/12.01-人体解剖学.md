# 12.01 · 人体解剖学

> **一句话定位：** 人体结构地图。营养师不要求做手术解剖，但要懂：食物走的路线（消化系统）、内分泌腺的位置（激素）、代谢器官（肝胰肾）——这样讲"营养素去哪、为什么这里出问题"才有据可依。
>
> **本册目标：** 学完你能不看图画出消化管走向、说出消化腺三大件、指出胰岛α/β细胞、讲清肝脏胆汁胆道关系、理解肾单位滤过重吸收——并且每个结构都能接一句"所以营养上该注意什么"。
>
> **依据教材：** 人民卫生出版社《人体解剖学》第9版 / 《系统解剖学》规划教材。数字以教材为准，个别参考区间以临床指南为准。

## 序 · 解剖学的术语与基本方位

### 1. 为什么要先学几个术语

营养师不需要做手术，但看资料、听医生讲、查文献时，会遇到一套方位术语。掌握最常用的几个，能让你"读得懂位置描述"。

| 术语 | 含义 | 例子 |
|------|------|------|
| 上/下 | 靠近头顶/靠近足底 | 肝脏在胃的**上方** |
| 前/后 | 靠腹侧/靠背侧 | 胃在脊柱的**前方** |
| 内侧/外侧 | 靠近正中线/远离正中线 | 十二指肠在胃的**下方偏后** |
| 近端/远端 | 离躯干近/远 | 空肠近端连着十二指肠 |
| 深/浅 | 离体表远/近 | 胰腺位置**深**，在胃的后方 |

### 2. 人体常用切面（了解即可）

| 切面 | 说明 |
|------|------|
| 矢状面 | 前后方向，把身体分成左右 |
| 冠状面（额状面） | 左右方向，把身体分成前后 |
| 水平面（横断面） | 把身体分成上下 |

### 3. 体腔与内脏位置（营养师认路用）

```
体腔分为两大腔：
① 背侧体腔：颅腔（脑）、椎管（脊髓）
② 腹侧体腔：胸腔（心、肺、大血管）、腹腔（消化器官、肝、脾、胰、肾）、盆腔（膀胱、直肠、生殖器）
```

| 器官 | 位置（营养师认路版本） | 营养意义 |
|------|----------------------|---------|
| 肝脏 | 右上腹，膈下方 | 最大代谢器官，受膈肌保护 |
| 胆囊 | 肝脏下方，贴附肝 | 储存胆汁 |
| 胃 | 左上腹 | 食物暂时储存与初步消化 |
| 胰腺 | 胃的后方，横跨腹后壁 | 位置深，外伤/炎症隐蔽 |
| 脾 | 左上腹，胃的后外侧 | 免疫器官，不参与消化 |
| 双肾 | 腹后壁，脊柱两侧（腹膜后） | 滤过与内分泌 |
| 小肠 | 腹腔中部 | 主要吸收部位 |
| 大肠 | 环绕小肠四周 | 水吸收与粪便形成 |

## 一、人体九大系统速览

### 1. 九大系统总表

| 系统 | 主要结构 | 营养师关注点 | 对应营养素 |
|------|---------|-------------|-----------|
| 运动系统 | 骨、关节、骨骼肌 | 钙/蛋白/维D→骨与肌 | 钙、磷、维D、维K、蛋白质 |
| 消化系统 | 口腔→食管→胃→小肠→大肠 + 肝胆胰 | **营养吸收全在这** | 各类营养素 |
| 呼吸系统 | 鼻咽喉气管支气管肺 | 慢阻肺营养 | 抗氧化营养素 |
| 泌尿系统 | 肾、输尿管、膀胱、尿道 | 肾病限蛋白钾磷 | 蛋白质、钾、磷 |
| 生殖系统 | 性腺（睾丸/卵巢）及管道 | 备孕营养 | 叶酸、锌、铁 |
| 内分泌系统 | 甲状腺、胰腺、肾上腺、性腺、垂体 | **代谢调节核心** | 碘、锌、铬、蛋白 |
| 循环系统 | 心、动脉、毛细血管、静脉 | 心血管营养 | n-3、钾、膳食纤维 |
| 神经系统 | 脑、脊髓、神经 | DHA/镁/B族 | DHA、镁、维B族 |
| 淋巴/免疫系统 | 淋巴结、脾、胸腺、扁桃体、淋巴管 | 免疫营养 | 蛋白、锌、维A/C/D |

### 2. 从"食物进 → 食物出"看人体系统协同

营养师理解人体，最顺的主线就是"一粒食物"的旅程：

```
进嘴（消化系统：口腔）
   │
   ▼ 咀嚼、唾液淀粉酶
食管（消化系统：输送）
   │
   ▼
胃（消化系统：胃酸+胃蛋白酶，灭菌+初步消化）
   │
   ▼
十二指肠（消化系统：胆总管+胰管汇入 → 化学消化核心）
   │
   ▼
空肠/回肠（消化系统：小肠绒毛吸收 → 营养素入血/入淋巴）
   │
   ▼
血液/淋巴（循环系统：运输到全身）
   │
   ▼
肝脏（消化系统+代谢：门静脉首站，加工/储存/解毒）
   │
   ▼
组织细胞（运动/神经/免疫等各系统利用）
   │
   ▼
代谢废物（泌尿系统排尿素/尿酸/多余离子；呼吸系统排CO₂；皮肤排汗）
```

> 这条主线把九大系统串成一个整体：**消化→吸收→运输→代谢→利用→排泄**。任何环节出问题，都可能是"营养问题"的表现，也可能反过来影响营养状态。

### 3. 营养师学解剖的顺序建议

| 优先级 | 系统 | 理由 |
|--------|------|------|
| 第一优先 | 消化系统 | 营养吸收的全部通道 |
| 第二优先 | 内分泌系统 | 代谢调节核心（血糖等） |
| 第三优先 | 循环系统 + 泌尿系统 | 运输与排泄，慢病高发区 |
| 第四优先 | 神经系统 + 运动系统 | 脑营养、骨骼肌健康 |
| 泛读 | 呼吸、生殖、淋巴 | 够用即可，特殊人群再深入 |

## 二、消化系统详解（营养师第一重点）

### 2.0 消化系统总览

消化系统由**消化管**和**消化腺**两部分组成：

- **消化管**：口腔 → 咽 → 食管 → 胃 → 小肠（十二指肠→空肠→回肠）→ 大肠（盲肠→结肠→直肠）→ 肛门。全长约 8~10 米。
- **消化腺**：大消化腺（唾液腺、肝脏、胰腺）+ 小消化腺（胃肠黏膜内的腺体）。

| 部位 | 主要消化活动 | 吸收内容 |
|------|-------------|---------|
| 口腔 | 咀嚼、唾液淀粉酶分解淀粉 | 极少（酒精、部分药物） |
| 食管 | 输送 | 无 |
| 胃 | 胃酸+胃蛋白酶（蛋白初步消化）、机械研磨 | 酒精、部分水分 |
| 十二指肠 | 胆汁乳化脂肪、胰酶消化三大营养素 | 铁、钙等部分矿物质 |
| 空肠 | 多种酶消化 + 吸收 | **吸收主力**：糖、氨基酸、脂肪酸、大部分维生素矿物质 |
| 回肠 | 吸收延续 | 维生素B12、胆汁酸（肠肝循环） |
| 结肠 | 水与电解质重吸收、菌群发酵 | 水、钠、短链脂肪酸（少量） |

### 2.1 消化管走向（记死这张图）

```
口腔 → 咽 → 食管 → 胃 → 十二指肠 → 空肠 → 回肠 → 盲肠 → 结肠 → 直肠 → 肛门
        │        │     │            └─────── 小肠（约5~7m）───────┘
        │        │     │
        │        │     └──────── 消化腺汇入处（胆总管/胰管开口）
        │        └──────────── 长约25cm，三段生理狭窄
        └──────────────────── 咽为消化与呼吸共用通道
```

> 口诀：**"口咽食管胃，十空回盲结直肛"**。营养师讲"消化吸收"，先有这条线，再谈每段干什么。

### 2.2 口腔

#### 结构

| 结构 | 功能 |
|------|------|
| 牙齿 | 切割、撕裂、研磨食物 |
| 舌 | 搅拌、推送食物、感受味觉 |
| 唾液腺（三大对） | 分泌唾液 |
| 口腔黏膜 | 保护、湿润 |

#### 唾液腺三大对

| 腺体 | 位置 | 分泌特点 |
|------|------|---------|
| 腮腺 | 耳前下方 | 最大，分泌稀薄唾液 |
| 下颌下腺 | 下颌骨内侧 | 分泌较多黏液 |
| 舌下腺 | 舌下方 | 最小，以黏液为主 |

#### 唾液的作用（营养相关）

- 唾液淀粉酶开始分解淀粉（口腔内的化学消化）。
- 湿润、润滑食物，利于吞咽。
- 溶菌酶等有轻度抗菌作用。

> **与营养的关系**：①咀嚼不充分 → 唾液淀粉酶作用时间短 → 淀粉到胃里继续（胃酸会抑制唾液淀粉酶，故咀嚼很重要）。②口干（如某些药物副作用）→ 影响进食体验与食团形成，需注意食物性状调整。

### 2.3 咽与食管

#### 咽（口腔→食管/气管的交叉口）

- 咽是消化与呼吸的共用通道：食物经咽进入食管，空气经咽进入喉。
- **吞咽反射**保护：会厌软骨在吞咽时盖住喉口，防止食物误入气管。

#### 食管

- 长约 25cm，是连接咽与胃的肌性管道。
- **三个生理狭窄**（异物容易卡住、也是营养师理解"食管癌高发位置"的解剖基础）：
  1. 食管起始处（平第6颈椎）
  2. 左主支气管跨越处（平第4/5胸椎）
  3. 穿膈肌食管裂孔处（平第10胸椎）
- 食管下端有**下食管括约肌**（食管胃连接处），防止胃内容物反流。

> **与营养的关系**：①胃食管反流病（烧心）与下食管括约肌功能减弱有关——肥胖（腹压升高）、高脂饮食、饮酒、咖啡等可加重。②吞咽困难（进行性）是红旗信号，需及时就医排查。

### 2.4 胃

#### 位置与形态

- 位于左上腹，上接食管（贲门），下接十二指肠（幽门）。
- 分四部：贲门部、胃底、胃体、幽门部（胃窦）。
- 容量：成人空腹约 50ml，进食后可达 1~2L。

#### 胃壁分层（记住四层，营养师至少知道黏膜层）

| 层次 | 由内到外 | 作用 |
|------|---------|------|
| 黏膜层 | 最内层 | 分泌胃液，**营养吸收极少** |
| 黏膜下层 | 结缔组织+血管神经 | 营养供给 |
| 肌层 | 平滑肌 | 研磨、排空 |
| 外膜 | 最外层 | 保护 |

#### 胃腺细胞（关键）

| 细胞 | 分泌 | 功能 |
|------|------|------|
| 主细胞 | 胃蛋白酶原 | 被胃酸激活为胃蛋白酶 → 蛋白质初步消化 |
| 壁细胞 | 胃酸（HCl）+ 内因子 | 杀菌、激活胃蛋白酶原；内因子帮助维生素B12吸收 |
| 颈黏液细胞 | 黏液 | 保护胃黏膜 |

> **与营养的关系**（营养师重点）：
> 1. 胃的**吸收功能很弱**，只吸收酒精和少量水——"吃进去的营养主要靠小肠吸收"。
> 2. 壁细胞分泌**内因子**：维生素B12 需要内因子才能在回肠吸收。长期胃病/胃大部切除/萎缩性胃炎 → 内因子不足 → 维生素B12缺乏 → 巨幼细胞性贫血。这是"胃与营养"的经典连接点。
> 3. 胃酸不足（老年人、部分药物）→ 蛋白质消化下降、部分矿物质（铁、钙、B12）吸收减少。
> 4. 胃排空速度影响饱腹感：蛋白质和脂肪延缓排空，精制碳水排空快 → 饿得快。

### 2.5 十二指肠

#### 位置与形态

- 小肠起始段，长约 25cm，呈"C"形包绕胰头。
- 分四部：上部（球部）、降部、水平部、升部。
- **降部有十二指肠大乳头**：胆总管与主胰管共同开口处（部分人有副胰管开口于副乳头）。

#### 为什么叫"化学消化核心"

```
胃内食糜（酸性）→ 进入十二指肠
   │
   ▼
胆囊收缩排出胆汁（乳化脂肪）
   │
   ▼
胰腺分泌胰液（碳酸氢盐中和胃酸 + 多种消化酶）
   │
   ▼
三大营养素在此开始大规模化学消化
```

> **与营养的关系**：①十二指肠是**胆胰管开口**所在地，胆道或胰腺问题会影响此处消化。②十二指肠溃疡好发于球部（与胃酸/幽门螺杆菌相关），患者进食可能诱发疼痛。③此处也是部分矿物质（铁、钙）吸收的重要部位。

### 2.6 空肠与回肠（小肠主体）

#### 基本数据

- 小肠全长约 5~7m（个体差异大），盘曲于腹腔中部。
- **空肠**：占近端约 2/5，位于左上腹，管壁较厚、血供丰富、黏膜环状襞密集。
- **回肠**：占远端约 3/5，位于右下腹，管壁较薄、环状襞较少，含**派尔集合淋巴结**。

#### 吸收分工（营养师必记）

| 吸收内容 | 主要部位 | 备注 |
|---------|---------|------|
| 单糖（葡萄糖、果糖、半乳糖） | 空肠为主 | 碳水消化终产物 |
| 氨基酸、小肽 | 空肠为主 | 蛋白质消化终产物 |
| 脂肪酸、甘油一酯 | 空肠为主 | 脂肪吸收后入乳糜管（淋巴） |
| 铁 | 十二指肠、空肠上部 | 血红素铁吸收较好 |
| 钙 | 十二指肠、空肠上部 | 需维生素D（活性） |
| 叶酸 | 空肠上部 | 食物叶酸需水解 |
| 维生素B12 | **回肠末端** | 需内因子；回肠切除→B12缺乏 |
| 胆汁酸 | 回肠末端 | 肠肝循环重吸收 |

> **与营养的关系**：
> 1. 小肠是**吸收主力**，尤其是空肠。小肠黏膜受损（如乳糜泻、克罗恩病、化疗后）→ 广泛吸收不良 → 消瘦、贫血、微量营养素缺乏。
> 2. **回肠末端吸收维生素B12**：回肠疾病/切除 → B12缺乏（巨幼细胞性贫血、神经症状）。
> 3. 脂肪吸收走**淋巴（乳糜管）**，而非直接入血——这是"脂肪吸收慢、影响血脂"的解剖基础之一。

### 2.7 小肠绒毛（吸收表面积的关键）

#### 结构（三层放大）

```
小肠黏膜
   │
   ▼
皱襞（环状襞，肉眼可见的环形隆起）
   │
   ▼
绒毛（黏膜表面的指状突起，高约0.5~1.5mm）
   │
   ▼
微绒毛（绒毛上皮细胞顶端的细小突起，形成"刷状缘"）
```

- 小肠因皱襞 + 绒毛 + 微绒毛三级结构，吸收表面积扩大到约 **200~250m²**（约等于一个网球场）。
- 每个绒毛内有：**中央乳糜管**（毛细淋巴管）+ **毛细血管网** + 平滑肌纤维（帮助绒毛伸缩）。

| 绒毛内结构 | 吸收什么 | 去向 |
|-----------|---------|------|
| 毛细血管 | 单糖、氨基酸、水溶性维生素、短中链脂肪酸 | 入门静脉→肝 |
| 中央乳糜管（淋巴管） | 长链脂肪酸、脂溶性维生素（乳糜微粒） | 经淋巴→胸导管→入血 |

> **与营养的关系**：
> 1. 绒毛是"吸收工厂"。肠绒毛萎缩（如严重营养不良、乳糜泻、肠道感染）→ 吸收不良 → 营养不良恶性循环。
> 2. 刷状缘（微绒毛）含**双糖酶**（乳糖酶等）：乳糖不耐受 = 乳糖酶不足 → 乳糖未被分解 → 发酵产气、腹泻。
> 3. 脂肪与脂溶性维生素走淋巴路径——因此**胆道梗阻/胰腺功能不全 → 脂肪泻 → 脂溶性维生素（A、D、E、K）缺乏**。

### 2.8 结肠（大肠）

#### 结构与分部

- 大肠全长约 1.5m，呈"门"字形环绕小肠。
- 分部：盲肠（含阑尾）→ 升结肠 → 横结肠 → 降结肠 → 乙状结肠 → 直肠。
- 特征结构：结肠带（三条纵行肌带）、结肠袋（带间袋状膨隆）、肠脂垂（脂肪小突起）。

| 部位 | 特点 | 功能 |
|------|------|------|
| 盲肠 | 回盲瓣开口处 | 防止大肠内容物反流回小肠 |
| 阑尾 | 盲肠下端蚯蚓样突起 | 淋巴组织丰富，发炎为阑尾炎 |
| 升/横/降/乙状结肠 | 结肠带/袋/脂垂 | 水电解质重吸收、粪便推进 |
| 直肠 | 长约12~15cm | 储存粪便 |
| 肛管/肛门 | 内外括约肌 | 控制排便 |

#### 结肠的功能（营养相关）

- **重吸收水分与电解质**（钠、氯）：每天进入结肠约 1~1.5L 液体，大部分被重吸收。
- **菌群发酵**：结肠栖息着大量肠道菌群，发酵膳食纤维 → 短链脂肪酸（乙酸、丙酸、丁酸）。
- 丁酸是结肠上皮细胞的重要能量来源，并有抗炎、维护肠屏障作用。
- 粪便形成与排出。

> **与营养的关系**：
> 1. 膳食纤维是结肠菌群的"食物"（益生元），发酵产短链脂肪酸——这是"多吃蔬菜全谷物养肠道"的解剖/微生物基础。
> 2. 慢性便秘常见原因之一：纤维不足 + 饮水不足 + 运动不足。但**纤维要配合充足水分**，否则可能加重便秘。
> 3. 长期腹泻/结肠切除 → 水电解质紊乱风险，需关注钠钾补充（遵医嘱）。
> 4. 结肠癌筛查相关：血便、排便习惯改变是红旗信号，需就医。

### 2.9 直肠与肛门

- 直肠前邻膀胱/子宫等，后方是骶骨。
- 肛门内外括约肌协同控制排便。
- 痔是肛管静脉丛曲张，与久坐、便秘、腹压增高（如肥胖、妊娠）相关。

> **与营养的关系**：①便秘防治与纤维、水分、运动有关。②痔发作期饮食宜高纤维软食。③排便习惯改变/便血是红旗信号。

### 2.10 消化腺三大件（一）：唾液腺

见 2.2 口腔部分。唾液腺是唯一在口腔工作的大消化腺，每日分泌唾液约 1~1.5L。

### 2.11 消化腺三大件（二）：肝脏与胆道系统

#### 肝脏（人体最大实质器官）

| 项目 | 数据/说明 |
|------|----------|
| 重量 | 成人约 1.3~1.5kg |
| 位置 | 右上腹，大部分被肋弓遮盖 |
| 血液供应 | 双重供血：肝动脉（供氧）+ 门静脉（**携带肠道吸收的营养素**） |
| 胆汁分泌 | 每天约 600~1000ml |

#### 门静脉系统：为什么"吃进去的先过肝"

```
肠道吸收的营养素 → 肠系膜静脉 → 门静脉 → 肝脏 → 加工/储存/解毒 → 肝静脉 → 下腔静脉 → 全身
```

> 这就是"肝脏是营养代谢中枢"的解剖基础：**几乎所有从肠道吸收的营养物质都先到肝脏**，肝脏决定它们是进入循环、储存（糖原/脂肪/维生素）还是转化。

#### 肝脏的功能（营养师版速记）

| 功能 | 营养相关例子 |
|------|-------------|
| 糖代谢 | 糖原合成与分解、糖异生（维持血糖） |
| 脂代谢 | 合成脂蛋白、胆固醇、胆汁酸 |
| 蛋白代谢 | 合成白蛋白、凝血因子、转运蛋白 |
| 解毒 | 酒精、药物、代谢废物（氨→尿素） |
| 储存 | 糖原、脂溶性维生素（A、D、E、K）、铁（铁蛋白） |
| 胆汁 | 分泌胆汁，乳化脂肪 |
| 免疫 | 库普弗细胞（吞噬） |

#### 胆道系统与胆囊

```
肝细胞分泌胆汁
   │
   ▼
肝内胆小管 → 肝左右管 → 肝总管
   │                            │
   └── 胆囊管 ←───────────────┘（胆囊储存浓缩胆汁，约40~60ml）
   │
   ▼
胆总管
   │
   ▼
十二指肠大乳头（与主胰管汇合）
```

- **胆囊**：储存和浓缩胆汁（进食时排出）。
- **胆汁**：由肝细胞分泌，含胆汁酸、胆红素、胆固醇等；作用是把大脂肪滴乳化成小脂肪滴（乳化），利于胰脂肪酶分解。
- **胆结石/胆道梗阻** → 胆汁排出受阻 → 脂肪消化下降 → **脂肪泻、脂溶性维生素（A/D/E/K）缺乏**。

> **与营养的关系**（营养师重点）：
> 1. 护肝营养要点：**少果糖/少酒精/足蛋白**（蛋白供肝合成与修复）、控制体重（防脂肪肝）。
> 2. 非酒精性脂肪肝（NAFLD）与内脏脂肪、胰岛素抵抗密切相关——"护肝 = 控代谢"。
> 3. 胆囊切除术后：胆汁无法按需浓缩储存，高脂餐后可能出现腹泻——建议少食多餐、中低脂。
> 4. 长期严格限制脂肪或胆道疾病 → 警惕脂溶性维生素缺乏。

### 2.12 消化腺三大件（三）：胰腺

#### 位置与分部

- 胰腺位于**胃的后方**，横卧于腹后壁，属腹膜外位器官。
- 分三部：胰头（被十二指肠C形包绕）、胰体、胰尾（靠近脾）。

#### 外分泌部与内分泌部

| 部分 | 结构 | 产物 | 功能 |
|------|------|------|------|
| 外分泌部 | 腺泡 | 胰液（每天约1~2L） | 消化三大营养素 |
| 内分泌部 | 胰岛 | 胰岛素、胰高血糖素等 | 调节血糖 |

#### 胰液成分与作用（消化核心）

| 胰液成分 | 作用 |
|---------|------|
| 胰淀粉酶 | 分解淀粉 → 麦芽糖等 |
| 胰蛋白酶原/糜蛋白酶原 | 被激活后分解蛋白质 |
| 胰脂肪酶 | 分解脂肪 → 脂肪酸+甘油一酯 |
| 核酸酶 | 分解核酸 |
| 碳酸氢盐 | 中和胃酸，为胰酶提供碱性环境 |

> **与营养的关系**（营养师重点）：
> 1. **胰腺是三大营养素消化的主力**。慢性胰腺炎/胰腺功能不全 → 消化酶不足 → 脂肪泻、消瘦、脂溶性维生素缺乏。
> 2. **胰液呈碱性**，中和胃酸——胃酸过多/十二指肠溃疡患者的进食节奏与此相关。
> 3. 急性胰腺炎时需禁食/低脂，营养支持需专业团队指导（营养师不越界干预急性期）。
> 4. 胰岛 β细胞（见内分泌章）是"血糖调控核心"，保护 β细胞 = 控糖抗炎减重。

### 2.13 肠道相关淋巴组织（GALT）——70%免疫在肠道

#### 结构

- 肠道相关淋巴组织（Gut-Associated Lymphoid Tissue, GALT）包括：
  - 派尔集合淋巴结（Peyer patches，主要见于回肠）
  - 孤立淋巴滤泡
  - 肠系膜淋巴结
  - 黏膜内弥散的淋巴细胞、浆细胞
  - 阑尾（含丰富淋巴组织）

#### 功能

- 识别并应答肠腔内的抗原（食物蛋白、菌群、病原体）。
- 分泌分泌型IgA（sIgA），构成肠道"第一道防线"。
- 维持对"食物成分和共生菌"的免疫耐受（失衡 → 食物过敏/炎症性肠病方向）。

> **与营养的关系**：
> 1. **肠道是人体最大的免疫器官**——约 70% 免疫细胞在肠道。营养支持"肠"就是支持"免疫"。
> 2. 肠屏障（肠黏膜+紧密连接+sIgA）依赖：谷氨酰胺、锌、优质蛋白、维生素A/D 等。
> 3. 膳食纤维喂养有益菌 → 短链脂肪酸 → 维护肠屏障与免疫稳态。
> 4. "肠漏"（肠屏障通透性增加）是研究热点，但营养师表述应谨慎，不做绝对化结论。

### 2.14 消化系统营养应用小结

| 解剖结构 | 营养工作含义 |
|---------|-------------|
| 口腔/唾液 | 咀嚼充分→淀粉消化好；口干→调整食物性状 |
| 食管 | 下括约肌松弛→反流管理（体重/高脂/咖啡因/酒） |
| 胃 | 内因子+B12；胃酸不足→蛋白/铁/钙/B12吸收下降 |
| 十二指肠 | 胆胰管开口；球部溃疡→进食节奏 |
| 空肠 | 主要吸收部位；黏膜受损→广泛吸收不良 |
| 回肠 | B12 吸收；回肠切除→B12缺乏 |
| 小肠绒毛/微绒毛 | 乳糖酶缺乏→乳糖不耐受；绒毛萎缩→吸收不良 |
| 结肠/菌群 | 纤维→短链脂肪酸→养肠抗炎；水电解质重吸收 |
| 肝脏 | 代谢中枢；少果糖少酒足蛋白；脂肪肝→控代谢 |
| 胆囊/胆道 | 胆道梗阻→脂肪泻→脂溶性维生素缺乏 |
| 胰腺 | 三大营养素消化主力；功能不全→消化酶不足 |
| 肠道淋巴组织 | 70%免疫在肠道；养肠=养免疫 |

## 三、内分泌系统（代谢调控中枢）

### 3.0 内分泌系统总览

内分泌系统由内分泌腺和散在的内分泌细胞组成，分泌**激素**经血液运输到全身，调节代谢、生长发育、生殖、水盐平衡等。

| 内分泌腺 | 位置 | 主要激素 | 营养关联 |
|---------|------|---------|---------|
| 垂体 | 颅底蝶鞍内 | GH、TSH、ACTH、FSH、LH、PRL、ADH、催产素 | 总指挥 |
| 甲状腺 | 颈前部 | T3、T4、降钙素 | 碘、代谢率 |
| 甲状旁腺 | 甲状腺后方 | PTH | 钙磷代谢 |
| 肾上腺 | 双肾上方 | 皮质醇、醛固酮、肾上腺素等 | 应激、血压、糖 |
| 胰岛 | 胰腺内 | 胰岛素、胰高血糖素 | 血糖调控核心 |
| 性腺 | 睾丸/卵巢 | 睾酮、雌激素、孕激素 | 生殖、骨骼 |
| 胸腺 | 胸骨后 | 胸腺素 | 免疫发育（儿童） |

### 3.1 垂体（总指挥）

- 位于颅底蝶鞍内，重约 0.5g，是"内分泌腺之首"。
- 分**腺垂体**（前叶）和**神经垂体**（后叶）。

| 部分 | 分泌/释放的激素 | 作用 |
|------|---------------|------|
| 腺垂体 | 生长激素（GH） | 促进生长、蛋白质合成 |
| 腺垂体 | 促甲状腺激素（TSH） | 促甲状腺分泌 |
| 腺垂体 | 促肾上腺皮质激素（ACTH） | 促肾上腺皮质分泌 |
| 腺垂体 | 促性腺激素（FSH/LH） | 促性腺功能 |
| 腺垂体 | 催乳素（PRL） | 泌乳 |
| 神经垂体 | 抗利尿激素（ADH） | 保水、浓缩尿 |
| 神经垂体 | 催产素 | 分娩、射乳 |

> **与营养的关系**：①儿童生长需要 GH + 充足营养（蛋白、钙、维D、锌）。②ADH 与水盐平衡相关，影响饮水与脱水判断。③TSH 是体检甲状腺功能的首查指标。

### 3.2 甲状腺

#### 位置与结构

- 位于颈前部，喉结下方，呈"H"形（两叶+峡部）。
- 成人重约 20~25g。
- 滤泡上皮细胞合成甲状腺激素（T4、T3）；滤泡旁细胞（C细胞）分泌降钙素。

| 激素 | 作用 |
|------|------|
| T3（三碘甲状腺原氨酸）/T4（甲状腺素） | 提高基础代谢率、促进生长发育、调节产热 |
| 降钙素 | 降低血钙（与PTH拮抗） |

#### 甲状腺激素与营养的关系

| 营养要素 | 关系 |
|---------|------|
| 碘 | 甲状腺激素合成的必需原料；缺碘→甲状腺肿；过量也有风险 |
| 硒 | 参与甲状腺激素代谢（脱碘酶） |
| 铁、锌 | 参与甲状腺激素合成与作用 |
| 蛋白质 | 激素的转运蛋白载体 |

> **与营养的关系**（营养师重点）：
> 1. 甲亢 → 代谢亢进 → 消瘦、怕热、心悸 → 营养上需高能量、足蛋白，限制咖啡因；避免过量补碘。
> 2. 甲减 → 代谢低下 → 怕冷、体重增加倾向 → 控制能量、均衡碘摄入（遵医嘱）。
> 3. **碘是双刃剑**：不足与过多都可能伤甲状腺。用碘盐是主流策略，补碘补剂需谨慎。
> 4. 体检 TSH 异常是线索，**确诊由医生**，营养师配合生活方式。

### 3.3 甲状旁腺

- 通常 4 个，绿豆大小，贴附于甲状腺后面。
- 分泌**甲状旁腺激素（PTH）**：升血钙、降血磷。

| PTH 作用靶点 | 效果 |
|-------------|------|
| 骨骼 | 促进骨吸收，释放钙磷 |
| 肾脏 | 促进钙重吸收，促进磷排出；促进活性维生素D生成 |
| 肠道（间接） | 经活性维D促进钙吸收 |

> **与营养的关系**：①血钙调节是"骨、肠、肾"三器官联动，维生素D 在其中至关重要。②长期维D缺乏 → 血钙偏低 → PTH 代偿升高 → 骨量流失。③营养师谈钙，永远要带上维D和蛋白质。

### 3.4 肾上腺

#### 位置与结构

- 位于双肾上方，左右各一，重约 5~10g。
- 分两部分：**皮质**（外）与**髓质**（内）。

#### 肾上腺皮质（分泌类固醇激素）

| 层次 | 分泌激素 | 作用 |
|------|---------|------|
| 球状带 | 醛固酮 | 保钠排钾，调节血压与电解质 |
| 束状带 | 皮质醇（糖皮质激素） | 应激、升血糖、抗炎、影响脂肪分布 |
| 网状带 | 弱雄激素 | 参与性征（次要） |

#### 肾上腺髓质

- 分泌**肾上腺素、去甲肾上腺素**：应激时"战斗或逃跑"，升心率、升血压、升血糖。

> **与营养的关系**（营养师重点）：
> 1. **长期压力 → 皮质醇持续偏高 → 血糖升高、向心性肥胖（腹型）**。这是"压力肥"的解剖-内分泌基础。
> 2. 皮质醇促分解代谢：长期高皮质醇 → 肌肉流失、腹部脂肪堆积。
> 3. 醛固酮影响钠钾：**限钠**对血压管理的重要性，在解剖上就"有据"。
> 4. 营养师动作：管理压力、睡眠、咖啡因；规律运动；均衡矿物质（钠钾镁）。

### 3.5 胰腺胰岛（血糖调控核心，营养师必精）

#### 结构

- 胰岛是胰腺内分泌部，散布于腺泡之间，总数约数十万~百万个，胰尾部较多。
- 主要细胞类型：

| 细胞 | 分泌激素 | 作用 | 营养意义 |
|------|---------|------|---------|
| **α细胞** | 胰高血糖素 | 升血糖（肝糖原分解、糖异生） | 与胰岛素拮抗 |
| **β细胞** | 胰岛素 | 降血糖（促摄取、促合成） | **2型糖尿病核心** |
| δ细胞 | 生长抑素 | 抑制 α、β 细胞分泌 | 局部调节 |
| PP细胞 | 胰多肽 | 调节消化分泌 | 作用较次要 |

#### 胰岛素（降糖激素）

- 由 β细胞分泌，是人体**唯一主要降血糖激素**。
- 作用：促进肌肉/脂肪/肝细胞摄取葡萄糖；促糖原合成、脂肪合成、蛋白质合成；抑制糖异生和脂肪分解。

#### 胰高血糖素（升糖激素）

- 由 α细胞分泌，作用与胰岛素相反：促肝糖原分解、糖异生 → 升血糖。

#### 2型糖尿病的解剖-功能概念

```
β细胞功能受损（分泌不足）+ 胰岛素抵抗（细胞不敏感）
   = 血糖调控失衡 → 高血糖
```

> **与营养的关系**（营养师最核心的知识点之一）：
> 1. **保护 β细胞** = 控糖、抗炎、减重、规律进餐。血糖长期过高 → β细胞"过劳"→ 功能衰退。
> 2. **胰岛素抵抗**与内脏脂肪、慢性炎症、精制碳水过量相关。
> 3. 营养策略：低升糖负荷饮食、保证纤维与蛋白质、规律进餐、控制体重——都是"给 β细胞减负"。
> 4. 1型糖尿病是 β细胞被自身免疫破坏，需胰岛素治疗（营养师配合，不替代）。

### 3.6 性腺

- **睾丸**：分泌睾酮（雄激素），促精子生成、蛋白合成、骨量维持。
- **卵巢**：分泌雌激素、孕激素，调节月经周期、维持骨量。

| 激素 | 营养相关 |
|------|---------|
| 睾酮 | 蛋白合成、肌肉、骨量；需锌、足够能量与蛋白 |
| 雌激素 | 骨保护；围绝经期雌激素下降 → 骨量流失加速 |
| 孕激素 | 月经周期调节 |

> **与营养的关系**：①备孕营养：叶酸、铁、锌、均衡膳食。②围绝经期/绝经后：钙+维D+蛋白 → 骨健康；植物化学物（大豆异黄酮）是研究话题，不夸大。③男性睾酮与肥胖、睡眠、运动相关。

### 3.7 内分泌系统营养应用小结

| 内分泌结构 | 激素 | 营养工作含义 |
|-----------|------|-------------|
| 胰岛β细胞 | 胰岛素 | 保护β细胞=控糖抗炎减重 |
| 胰岛α细胞 | 胰高血糖素 | 升糖与胰岛素拮抗（低血糖风险） |
| 甲状腺 | T3/T4 | 碘双刃剑；甲亢/甲减营养对策 |
| 甲状旁腺 | PTH | 钙磷调节；维D至关重要 |
| 肾上腺皮质 | 皮质醇 | 压力→腹型肥胖→代谢综合征 |
| 肾上腺髓质 | 肾上腺素 | 应激升糖升压；咖啡因与睡眠 |
| 垂体 | GH/TSH/ADH等 | 总指挥；儿童生长营养 |
| 性腺 | 睾酮/雌激素 | 备孕、骨量、围绝经期 |

## 四、循环系统

### 4.0 循环系统总览

循环系统由**心血管系统**（心、动脉、毛细血管、静脉）和**淋巴系统**组成。功能：运输氧、营养素、激素、代谢废物，维持内环境稳定。

### 4.1 心脏结构

#### 位置与外形

- 位于胸腔纵隔内，约 2/3 在正中线左侧。
- 大小约如本人拳头，重约 250~300g。

#### 四腔结构

| 腔室 | 接受血液 | 泵出到 |
|------|---------|--------|
| 右心房 | 上/下腔静脉（全身静脉血） | 右心室 |
| 右心室 | 右心房 | 肺动脉（肺循环） |
| 左心房 | 肺静脉（肺内氧合血） | 左心室 |
| 左心室 | 左心房 | 主动脉（体循环） |

- **左心室壁最厚**：因为要把血液泵到全身（压力最高）。
- 房室之间有房室瓣（三尖瓣/二尖瓣），心室与动脉之间有动脉瓣（肺动脉瓣/主动脉瓣），防止血液倒流。

#### 心壁三层

| 层次 | 结构 | 功能 |
|------|------|------|
| 心内膜 | 内皮+结缔组织 | 与血管内表面延续 |
| 心肌层 | 心肌纤维 | 收缩泵血（最厚） |
| 心外膜 | 浆膜 | 保护 |

#### 心的营养供应：冠状动脉

- 心脏自身由**冠状动脉**供血，起自主动脉根部。
- 冠状动脉粥样硬化 → 管腔狭窄 → 心肌缺血（心绞痛）；完全堵塞 → 心肌梗死。

> **与营养的关系**：心脏本身也需要营养（冠脉供血）。**护冠脉 = 护血脂 + 护内皮 + 控血压 + 控糖**。运动、抗炎饮食、控饱和/反式脂肪是冠脉健康基础。

### 4.2 血管类型

| 血管类型 | 结构特点 | 功能 | 营养相关 |
|---------|---------|------|---------|
| 动脉 | 管壁厚、弹性大；分弹性动脉/肌性动脉 | 将血液从心脏运出；弹性缓冲血压 | 硬化时弹性下降（血压升高） |
| 毛细血管 | 单层内皮，极薄 | **物质交换场所** | 营养素/气体/废物交换处 |
| 静脉 | 管壁薄、管腔大；四肢静脉有静脉瓣 | 将血液送回心脏 | 静脉回流受重力影响 |

#### 动脉粥样硬化的解剖基础（营养师必须会讲）

```
血管内皮损伤（高血压/高糖/吸烟/氧化）
   │
   ▼
LDL 渗入内膜下并被氧化（ox-LDL）
   │
   ▼
单核细胞进入内膜 → 转化为巨噬细胞 → 吞噬 ox-LDL → 泡沫细胞
   │
   ▼
脂质条纹（早期病变）→ 纤维斑块 → 粥样斑块（脂质核心+纤维帽）
   │
   ▼
斑块破裂 → 血栓 → 心肌梗死/脑卒中
```

| 病变阶段 | 营养对策方向 |
|---------|-------------|
| 内皮损伤 | 控血压、控糖、戒烟、抗氧化食物 |
| 血脂异常 | 控饱和脂肪/反式脂肪、适量 n-3、可溶性纤维 |
| 炎症 | 抗炎饮食（n-3、多酚、纤维） |
| 斑块稳定 | 控血脂、遵医嘱用药、运动 |

> **与营养的关系**（营养师重点）：动脉粥样硬化不是"胆固醇长在血管里"这么简单，而是**内皮损伤 + 脂质沉积 + 炎症**的综合过程。营养干预的方向是：控脂质来源（饮食脂肪质量）、控内皮损伤因素（血压血糖）、抗炎（膳食模式）。

### 4.3 毛细血管交换

- 毛细血管壁为单层内皮，是血液与组织液交换的场所。
- 交换方式：弥散（氧、CO₂、小分子）、滤过/重吸收（水）、胞吞（大分子）。

| 交换物质 | 方向 | 说明 |
|---------|------|------|
| 氧 | 血液→组织 | 供细胞代谢 |
| CO₂ | 组织→血液 | 废物排出 |
| 葡萄糖、氨基酸 | 血液→组织 | 供能/合成 |
| 脂肪酸 | 血液→组织 | 脂质利用 |
| 水 | 双向 | 受渗透压/血压调节 |

### 4.4 血液循环路径（体循环+肺循环）

```
【肺循环（小循环）】
右心室 → 肺动脉 → 肺毛细血管（气体交换：CO₂出、O₂入）→ 肺静脉 → 左心房

【体循环（大循环）】
左心室 → 主动脉 → 全身动脉 → 毛细血管（营养/气体交换）→ 静脉 → 上/下腔静脉 → 右心房
```

> 营养师要能讲清：**营养素从肠道吸收入门静脉→肝→下腔静脉→心脏→肺→左心→主动脉→全身组织**。这条"营养素运输线"是循环与消化的连接点。

### 4.5 淋巴系统（补充）

- 淋巴管收集组织液 → 淋巴 → 淋巴结（过滤）→ 胸导管/右淋巴导管 → 汇入静脉。
- **乳糜管**（小肠绒毛内）吸收脂肪 → 淋巴 → 胸导管 → 入血。这是脂肪运输的"旁路"。

### 4.6 循环系统营养应用小结

| 解剖结构 | 营养工作含义 |
|---------|-------------|
| 左心室 | 泵血主力；控制高血压负担 |
| 冠状动脉 | 护冠脉=控血脂血压血糖 |
| 血管内皮 | 抗氧化、控糖、控血压 |
| 毛细血管 | 营养素交换场所；微循环 |
| 动脉弹性 | 动脉硬化→血压升高；限盐、钾、运动 |
| 乳糜管 | 脂肪吸收走淋巴→血脂代谢 |
| 淋巴系统 | 免疫+脂肪运输 |

## 五、泌尿系统

### 5.0 泌尿系统总览

泌尿系统由**肾、输尿管、膀胱、尿道**组成。功能：排出代谢废物、调节水盐平衡、调节酸碱、内分泌。

### 5.1 肾脏大体结构

| 项目 | 数据/说明 |
|------|----------|
| 位置 | 腹后壁，脊柱两侧，约 T12~L3 高度（右肾略低） |
| 大小 | 长约 10~12cm，重约 120~150g |
| 形态 | 蚕豆形；内侧凹陷为肾门（肾动脉、肾静脉、输尿管出入） |
| 内部 | 皮质（外层）→ 髓质（内层，含肾锥体）→ 肾盂（收集尿液→输尿管） |

### 5.2 肾单位（肾脏功能的基本单位）

- 每个肾约含 **100 万个肾单位**。
- 一个肾单位 = **肾小体（肾小球+肾小囊）+ 肾小管（近端小管、髓袢、远端小管）**。

```
肾小体（滤过）
  ├── 肾小球：一团毛细血管（滤过血液）
  └── 肾小囊（鲍曼囊）：包裹肾小球，收集滤液
   │
   ▼
肾小管（重吸收+分泌）
  ├── 近端小管：重吸收大部分水、全部葡萄糖/氨基酸、大部分电解质
  ├── 髓袢：浓缩机制（逆流倍增）
  └── 远端小管：受醛固酮/ADH调节，精细调节水盐
   │
   ▼
集合管 → 肾盏 → 肾盂 → 输尿管
```

### 5.3 肾小球：滤过

- 肾小球是毛细血管团，滤过膜三层：内皮细胞、基膜、足细胞裂孔。
- **滤过压**驱动血浆滤过形成**原尿**。
- 数据：每天约滤过 **180L** 原尿，但排出终尿仅 **1~2L**——**99% 被重吸收**。

| 滤过膜特点 | 意义 |
|-----------|------|
| 有孔内皮 | 允许水和溶质通过 |
| 基膜 | 屏障带负电荷，阻大分子蛋白 |
| 足细胞裂孔 | 最后一道选择性屏障 |

> **与营养的关系**：肾小球滤过率（eGFR）是体检肾功能的重要指标。**蛋白质（尤其白蛋白）大量漏入尿中（蛋白尿）是肾损伤线索**，需就医。

### 5.4 肾小管：重吸收与分泌

| 肾小管段 | 重吸收 | 分泌 |
|---------|--------|------|
| 近端小管 | 约65~70%水、几乎全部葡萄糖和氨基酸、大部分Na⁺/Cl⁻/HCO₃⁻/K⁺ | 氢离子、有机酸/碱 |
| 髓袢 | 水、Na⁺、Cl⁻ | — |
| 远端小管 | 受醛固酮调节的Na⁺ | K⁺、H⁺ |
| 集合管 | 受ADH调节的水重吸收 | — |

> 知识点：正常尿中**不应有葡萄糖**。尿糖出现 → 血糖超过肾糖阈（约 10 mmol/L 左右）→ 提示血糖很高，是糖尿病线索（需医生确诊）。

### 5.5 肾脏的内分泌功能（营养师必知）

| 内分泌产物 | 作用 | 营养相关 |
|-----------|------|---------|
| 促红细胞生成素（EPO） | 促进红系造血 | 肾病→EPO不足→贫血（肾性贫血） |
| 活性维生素D（1,25-(OH)₂D） | 促进钙吸收、骨矿化 | 肾病→维D活化障碍→骨病 |
| 肾素 | 激活肾素-血管紧张素系统→升血压 | 与限钠相关 |

> **与营养的关系**（营养师重点）：
> 1. **慢性肾病（CKD）营养管理**：限蛋白（减尿素氮负担）、限钾磷（排泄能力下降）、限钠（血压）、适量优质蛋白避免营养不良——但**具体方案必须结合肾功能分期由医生/临床营养师制定**。
> 2. 肾病 → 贫血：关注铁、叶酸、B12 及 EPO 治疗（遵医嘱）。
> 3. 肾病 → 维D活化障碍：监测 25-羟维D与骨代谢，遵医嘱补充活性维D。

### 5.6 泌尿系统营养应用小结

| 解剖结构 | 功能 | 营养工作含义 |
|---------|------|-------------|
| 肾小球 | 滤过 | eGFR下降→肾损伤线索；蛋白尿→就医 |
| 近端小管 | 重吸收葡萄糖/氨基酸/水 | 尿糖→血糖线索 |
| 髓袢/集合管 | 浓缩尿液 | 饮水、脱水利尿 |
| 肾脏内分泌 | EPO、活性维D、肾素 | 肾性贫血、骨代谢、血压 |
| 输尿管/膀胱 | 输送/储存尿液 | 泌尿系感染、结石与水摄入 |

## 六、神经系统

### 6.0 神经系统总览

神经系统分中枢（脑、脊髓）和周围（脑神经、脊神经、自主神经）。功能：感受、整合、指令、调节。

### 6.1 神经元（基本单位）

```
神经元 = 胞体 + 树突（接收）+ 轴突（传出）
   │
   ▼
轴突末端 → 突触 → 与下一个神经元/肌肉/腺体连接
```

| 结构 | 功能 |
|------|------|
| 胞体 | 代谢中心，含细胞核 |
| 树突 | 接收信号 |
| 轴突 | 传导信号（神经冲动） |
| 突触 | 信号传递（化学递质） |

> **与营养的关系**：神经元代谢活跃、需要持续葡萄糖供能；但神经元不能储存糖原，依赖血糖稳定——**低血糖对大脑影响快速且明显**（心慌、出汗、注意力下降）。

### 6.2 神经胶质细胞（营养师了解）

| 细胞 | 功能 |
|------|------|
| 星形胶质细胞 | 支持、营养神经元、参与血脑屏障、离子缓冲 |
| 少突胶质细胞（中枢） | 形成髓鞘 |
| 施万细胞（周围） | 形成髓鞘 |
| 小胶质细胞 | 免疫监视 |

### 6.3 髓鞘（营养师重点）

- 髓鞘是包裹轴突的绝缘"电缆皮"，由**少突胶质细胞**（中枢）/ **施万细胞**（周围）形成。
- 作用：绝缘、**加快神经冲动传导**（跳跃式传导）。
- 髓鞘损伤 → 传导减慢/中断（如多发性硬化）。

> **与营养的关系**：
> 1. 髓鞘的主要成分是脂质和蛋白质——**必需脂肪酸（n-3）**对神经结构重要。
> 2. **维生素B12**参与髓鞘形成与维护；B12缺乏 → 神经症状（麻木、刺痛）+ 巨幼细胞性贫血。
> 3. 神经髓鞘"发育期"（孕期/婴幼儿）尤其需要 DHA、蛋白、B族。

### 6.4 血脑屏障（BBB）

- 结构：脑毛细血管内皮细胞**紧密连接** + 基膜 + 星形胶质细胞足突 + 周细胞。
- 作用：**选择性**让物质进出脑组织——允许氧、葡萄糖、部分脂溶性物质/氨基酸通过；阻挡大分子、毒素、多数药物。

| 能通过血脑屏障 | 受限 |
|--------------|------|
| 氧、CO₂ | 大分子蛋白 |
| 葡萄糖（经转运体） | 多数药物 |
| 必需氨基酸（经转运体） | 毒素、病原体 |
| 脂溶性小分子（部分） | 水溶性大分子 |

> **与营养的关系**：
> 1. 大脑首选能源是**葡萄糖**（经转运体入脑）——"脑要糖"。
> 2. 脂溶性物质（如部分脂溶性维生素、n-3）更容易入脑，这是 DHA 对脑结构重要的解剖基础之一。
> 3. 慢性炎症可破坏血脑屏障完整性（研究热点）。

### 6.5 神经递质（营养师重点）

| 神经递质 | 作用 | 营养前体/相关营养素 |
|---------|------|--------------------|
| 乙酰胆碱 | 记忆、肌肉 | 胆碱（卵磷脂） |
| 多巴胺 | 奖赏、运动、动机 | 酪氨酸 |
| 去甲肾上腺素 | 觉醒、应激 | 酪氨酸 |
| 5-HT（血清素） | 情绪、食欲、睡眠 | 色氨酸（+B6、碳水促进入脑） |
| GABA | 抑制、放松 | 谷氨酸→GABA（需B6） |
| 谷氨酸 | 兴奋 | 蛋白质代谢相关 |

> **与营养的关系**（营养师可讲、但不过度承诺）：
> 1. 蛋白质提供**色氨酸/酪氨酸**——神经递质前体。"吃蛋白 → 情绪/注意力"有其生化基础，但**个体效果因人而异**，不夸大。
> 2. 维生素B6 参与多种递质合成。
> 3. 血清素合成与碳水促胰岛素→促色氨酸入脑有关——"高碳水让人放松"的生化解释之一。
> 4. 酒精、药物影响递质系统，营养师不处理药物相关问题。

### 6.6 神经系统营养应用小结

| 解剖结构 | 营养工作含义 |
|---------|-------------|
| 神经元 | 需持续葡萄糖供能；低血糖影响大脑 |
| 髓鞘 | B12、n-3、必需脂肪酸 |
| 血脑屏障 | 脂溶性/特定氨基酸入脑；葡萄糖首选供能 |
| 神经递质 | 色氨酸/酪氨酸/B6/胆碱 |
| 自主神经 | 压力/放松与迷走神经、消化 |

## 七、运动系统

### 7.0 运动系统总览

运动系统由**骨、骨连结（关节）、骨骼肌**组成。功能：支撑、运动、保护内脏、造血（骨髓）、储存钙磷。

### 7.1 骨

#### 基本数据

- 成人共有骨 **206 块**（含听小骨）。
- 按形态分：长骨（肱骨、股骨）、短骨（腕骨）、扁骨（颅骨、肩胛骨）、不规则骨（椎骨）。

#### 骨组织的成分（营养师重点）

| 成分 | 比例 | 作用 |
|------|------|------|
| 有机质（胶原蛋白、蛋白多糖） | 约1/3 | 韧性、弹性 |
| 无机质（羟基磷灰石：钙磷结晶） | 约2/3 | 硬度、强度 |

> 儿童有机质多→骨柔韧不易折；老人无机质比例高→骨脆易折。

#### 骨的营养相关功能

- 骨是**钙磷储存库**（占体内钙约99%）。
- 红骨髓造血（成人主要在扁骨）。
- 骨是"矿物质的银行"：血钙偏低时，PTH 促进骨释放钙维持血钙。

> **与营养的关系**（营养师重点）：
> 1. 骨量（bone mass）在青少年达到峰值，之后逐渐下降。**峰值骨量最大化**（青少年期钙+维D+蛋白+运动）是终身骨骼健康的关键窗口。
> 2. 钙 + 维生素D + 蛋白质 + 维生素K 协同。光补钙不补维D，吸收有限。
> 3. 骨质疏松：骨量减少、微结构破坏、脆性骨折风险增加。女性绝经后（雌激素下降）风险升高。
> 4. 激素（PTH、雌激素、睾酮、甲状腺素）都影响骨代谢——内分泌与骨骼紧密相连。

### 7.2 骨骼肌

- 人体有 600 多块骨骼肌，占体重约 40%（男性常更高）。
- 结构：肌纤维（肌细胞）→ 肌原纤维（肌动蛋白+肌球蛋白）→ 收缩单位肌节。
- 收缩需要：ATP（能量）+ 钙离子 + 神经支配。

| 营养要素 | 与肌肉的关系 |
|---------|-------------|
| 蛋白质/氨基酸 | 肌肉合成的原料；亮氨酸等刺激肌肉蛋白合成 |
| 能量（碳水） | 运动燃料 |
| 肌酸 | 供能系统辅助（研究热点） |
| 维生素D | 肌肉功能 |
| 镁/钾 | 肌肉收缩与神经传导 |

> **与营养的关系**（营养师重点）：
> 1. **肌少症（Sarcopenia）**：与年龄相关的肌肉量/力量/功能下降。对策：足量优质蛋白 + **规律抗阻训练** + 维D。
> 2. 蛋白摄入"分散到三餐"优于一顿猛吃（每餐约20~30g优质蛋白对多数成人是合理目标）。
> 3. 减重期要"保肌减脂"：保证蛋白、配合抗阻训练，避免纯节食。

### 7.3 关节

#### 结构（以滑膜关节为例）

| 结构 | 说明 |
|------|------|
| 关节面 | 覆盖关节软骨（透明软骨） |
| 关节囊 | 纤维囊+滑膜 |
| 关节腔 | 含滑液（润滑、减震） |
| 辅助结构 | 韧带、半月板（膝关节）等 |

#### 关节软骨的特点

- 无血管、无神经，营养来自滑液扩散。
- 软骨细胞更新慢——**一旦磨损，修复能力有限**。
- 骨关节炎（OA）：软骨磨损 + 炎症 + 骨质增生。

> **与营养的关系**：
> 1. **骨关节炎的营养支持**：控制体重（减重显著减轻关节负荷）、抗炎饮食（n-3）、充足蛋白。体重每减1kg，膝关节负荷约减3~4倍（步行时）。
> 2. 葡萄糖胺/硫酸软骨素研究证据不一致（部分研究有效、部分无效）——营养师表述应客观，不夸大。
> 3. 关节痛持续/红肿热 → 就医排查。

### 7.4 运动系统营养应用小结

| 解剖结构 | 营养工作含义 |
|---------|-------------|
| 骨（钙磷库） | 钙+维D+蛋白+维K；峰值骨量窗口 |
| 骨髓 | 造血；与铁/叶酸/B12相关 |
| 骨骼肌 | 蛋白+抗阻训练；肌少症对策 |
| 关节软骨 | 减重减压+抗炎饮食 |
| 肌腱/韧带 | 蛋白、胶原合成原料（维C） |

## 八、其他系统补充（营养师泛读）

### 8.1 呼吸系统

- 组成：鼻、咽、喉、气管、支气管、肺。
- 肺泡是气体交换场所（表面积大，约70~100m²）。
- 呼吸功能：摄氧、排CO₂、调节酸碱（呼吸性）。

> **营养相关**：①慢阻肺（COPD）患者常伴营养不良（呼吸耗能高、食欲差）→ 需营养支持（充足能量蛋白）。②抗氧化营养素（维C、维E、类胡萝卜素）对肺健康是研究话题。③"吸烟伤肺+营养补救"是错误观念——戒烟才是根本。

### 8.2 生殖系统

- 男性：睾丸、附睾、输精管、前列腺等。
- 女性：卵巢、输卵管、子宫、阴道等。
- 功能：产生生殖细胞、性激素、孕育。

> **营养相关**：①备孕：叶酸（神经管畸形预防，备孕前3个月开始遵医嘱补充）、铁、锌、均衡膳食。②孕期体重管理、铁/钙/碘/叶酸需要量增加。③围绝经期：钙+维D+蛋白护骨。

### 8.3 淋巴/免疫系统

- 组成：淋巴管、淋巴结、脾、胸腺、扁桃体、骨髓。
- 脾：最大的淋巴器官，过滤血液、储血、免疫。
- 胸腺：T细胞成熟场所，随年龄退化。

> **营养相关**：①免疫营养：蛋白、锌、维A/C/D、n-3。②脾切除后感染风险增加，需遵医嘱疫苗接种等（营养师不处理）。③肠道是最大免疫器官（见消化章）。

## 九、解剖学 → 营养应用速查

### 9.1 总速查表

| 解剖结构 | 营养工作含义 |
|---------|-------------|
| 小肠绒毛 | 肠粘膜损伤→营养吸收差→修复需谷氨酰胺/锌/优质蛋白 |
| 胰岛β细胞 | 保护β细胞→控糖抗炎 |
| 肝脏 | 代谢中枢→护肝=少果糖/少酒/足蛋白 |
| 肾脏 | 排泄→肾病人限蛋白钾磷（遵医嘱分期） |
| 肠道淋巴组织 | 70%免疫→肠道即免疫前线 |
| 血脑屏障 | 大脑营养的特殊通道 |
| 甲状腺 | 碘双刃剑→均衡碘摄入 |
| 骨 | 钙+维D+蛋白+维K→峰值骨量 |
| 骨骼肌 | 蛋白+抗阻训练→防肌少症 |
| 冠状动脉 | 护冠脉=控血脂血压血糖 |

### 9.2 常见营养场景的解剖依据

| 场景 | 解剖依据 |
|------|---------|
| "为什么一吃油腻就拉肚子" | 胆道/胰腺功能→脂肪消化吸收；脂肪吸收走乳糜管 |
| "为什么光补钙不补维D没用" | 钙吸收需活性维D（十二指肠/空肠）；PTH调节血钙 |
| "为什么血糖忽高忽低要规律进餐" | 胰岛素/胰高血糖素调节；胰岛β细胞负担 |
| "为什么减重要同时做力量训练" | 骨骼肌是最大"糖库"和蛋白库；保肌减脂 |
| "为什么膳食纤维养肠道" | 结肠菌群发酵纤维→短链脂肪酸→养肠屏障 |
| "为什么压力大肚子大" | 肾上腺皮质→皮质醇→向心性肥胖 |
| "为什么肾病人要限钾" | 肾小管排钾能力下降→血钾升高风险 |
| "为什么贫血要查B12" | 回肠吸收B12需内因子（胃壁细胞） |
