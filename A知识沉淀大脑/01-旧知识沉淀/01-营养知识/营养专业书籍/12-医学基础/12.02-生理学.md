# 12.02 · 生理学（小书版）

> **一句话定位：** 人体功能学。营养师最常用的生理学：消化吸收生理、血糖调节、血压调节、水盐平衡、神经体液调节——这是"为什么这么吃"的科学底座。
>
> **本版说明：** 由知识卡片扩展为"书本级"参考文档，按人卫社《生理学》第9版体系深化。每章末尾配「营养应用」，供营养咨询、健康科普、脚本写作取材。全文为教育性内容，不构成诊疗建议。

## 〇、阅读指南

### 1. 这门学科解决什么问题

生理学（Physiology）研究**人体正常生命活动及其规律**——细胞怎么工作、器官怎么协同、全身怎么维持稳定。营养师看生理学，重点不是背名词，而是建立一条"营养素 → 生理过程 → 健康结局"的因果链。

| 营养师的问题 | 对应的生理学章节 |
|------------|----------------|
| 为什么吃高蛋白更容易饱？ | 消化吸收（CCK/GLP-1、胃排空） |
| 为什么血糖会忽高忽低？ | 血糖调节、胰岛素/胰高血糖素 |
| 为什么限盐能降血压？ | 循环与血压、钠水潴留 |
| 为什么一天要喝 1500~1700ml 水？ | 泌尿与水盐平衡 |
| 为什么压力大容易胖？ | 皮质醇、摄食调节 |
| 为什么人瘦不下来？ | 能量代谢、摄食中枢 |

### 2. 与《生物化学》的分工

| 学科 | 看什么 | 举例 |
|------|--------|------|
| 生理学 | 器官与系统功能、调节机制 | 胰岛素怎么指挥细胞 |
| 生物化学 | 分子层面的化学反应 | 糖在细胞里怎么一步步变 ATP |

- 第一遍：只看每章首段的「一句话」和末尾「营养应用」表。
- 第二遍：精读重点章节（二章消化吸收、三章能量代谢、四章循环、七章激素表）。

## 一、生理学总论：内环境与稳态

### 1. 核心概念：内环境

人体内绝大多数细胞并不直接接触外界环境，而是生活在**细胞外液**之中。这个细胞外液就是**内环境**（internal environment）。

```
内环境 = 细胞外液
        ├── 血浆（血管内）——约 5% 体重
        ├── 组织液（细胞间隙）——约 15% 体重
        └── 淋巴（淋巴管内）——组织液的回流通道
```

| 体液分区 | 占体重比例 | 主要作用 |
|---------|-----------|---------|
| 细胞内液 | 约 40% | 细胞代谢活动场所 |
| 细胞外液（血浆） | 约 5% | 运输、缓冲、免疫 |
| 细胞外液（组织液） | 约 15% | 细胞与血浆交换中介 |
| 细胞外液（淋巴） | 少量 | 组织液回流、免疫监视 |

> **一句话：** 内环境是"细胞的家"，家里任何指标乱了，细胞就生病。营养素的摄入、代谢产物的排出，本质上都是在维持这个"家"的秩序。

### 2. 内环境各指标的"正常范围"

稳态不是固定不变，而是在一定范围内动态波动。营养师常用到的几个关键指标：

| 指标 | 正常范围（成人静息） | 营养相关变量 |
|------|---------------------|-------------|
| 体温 | 腋温 36.0~37.0℃ | 蛋白质、甲状腺激素 |
| 血糖（空腹） | 3.9~6.1 mmol/L | 碳水、胰岛素敏感性 |
| 血浆 pH | 7.35~7.45 | 酮体、蛋白质缓冲 |
| 血浆渗透压 | 约 280~310 mOsm/L | 钠、水 |
| 血钠 | 135~145 mmol/L | 盐 |
| 血钾 | 3.5~5.5 mmol/L | 果蔬、肾脏 |
| 血钙 | 2.25~2.75 mmol/L | 维生素D、蛋白 |
| 血镁 | 0.75~1.25 mmol/L | 镁摄入、肾脏 |

### 3. 稳态（Homeostasis）——生理学的第一定律

**稳态**指内环境理化性质保持相对恒定的状态。这个"恒定"是**动态的**，靠不断调节来维持：

```
外界变化（气温、进食、运动）
        ↓
机体感受 + 调节
        ↓
内环境指标小幅波动后回到正常范围
        ↓
细胞正常工作
```

> **营养师视角：** 减肥、控糖、降血压，本质上都是帮助机体恢复或维持稳态。所以任何方案都要"可持续"，不能靠极端手段打破稳态。

### 4. 三大调节系统

人体有三大调节系统协同维持稳态，营养师要理解的是"各管什么、速度多快"：

| 调节系统 | 速度 | 作用时间 | 举例 |
|---------|------|---------|------|
| 神经调节 | 毫秒~秒级（最快） | 短 | 看到食物分泌唾液 |
| 体液调节 | 秒~分钟级 | 长 | 进食后胰岛素升高 |
| 自身调节 | 局部、即时 | 短 | 局部血流自动调节 |

```
神经系统（中枢神经）——秒级响应
   +
内分泌系统（激素）——分钟级
   +
免疫系统（细胞因子）——持续维护
= 维持稳态的铁三角
```

> **营养缺了任何一环的"原料"，稳态就出问题。** 例如：
> - 神经系统需要 B1/B12、镁、钙 → 缺了神经传导乱
> - 内分泌系统需要碘（甲状腺）、锌（胰岛素合成）、蛋白质（激素本身就是蛋白或多肽）
> - 免疫系统需要蛋白质、锌、硒、维生素A/C/D

### 5. 反馈与前馈调节

| 类型 | 机制 | 例子 | 营养相关例子 |
|------|------|------|-------------|
| 负反馈 | 输出抑制输入，使指标回归 | 血糖高→胰岛素升→血糖降 | 减肥平台期（体重下降→代谢下调） |
| 正反馈 | 输出增强输入，放大过程 | 分娩宫缩、凝血级联 | 脂肪肝→炎症→更多脂肪堆积 |
| 前馈 | 提前预判调节 | 饭前胰岛素预分泌 | "生物钟进食法"的依据之一 |

> **关键认知：** 机体绝大多数调节是负反馈。所以"节食减重"会触发一系列反抗（饥饿素升高、代谢率下降）——这是生理本能，不是意志力问题。

### 6. 营养应用

| 生理概念 | 营养方案依据 |
|---------|-------------|
| 稳态需要"原料" | 均衡摄入宏量+微量营养素，勿长期极端饮食 |
| 负反馈主导 | 减重要"温和可持续"，避免触发强烈的代谢抵抗 |
| 前馈调节 | 规律作息、规律进餐，让激素"有预期"地工作 |
| 铁三角协同 | 好睡眠（神经）+均衡营养（内分泌）+运动（免疫/代谢） |

## 二、消化与吸收生理

### 1. 消化系统概述

消化系统 = 消化道 + 消化腺。营养素的"入口关"全在这里：

```
口腔 → 咽 → 食管 → 胃 → 小肠（十二指肠/空肠/回肠） → 大肠 → 肛门
         ↑                          ↑
     唾液腺、胃腺            胰腺、肝（胆汁）、小肠腺
```

| 部位 | 主要消化液/酶 | 作用 |
|------|--------------|------|
| 口腔 | 唾液淀粉酶 | 淀粉初步水解 |
| 胃 | 胃酸、胃蛋白酶 | 蛋白质初步水解、杀菌 |
| 小肠 | 胰液、胆汁、小肠液 | 三大营养素几乎全部在此消化吸收 |
| 大肠 | 肠道菌群 | 纤维发酵、水分回收 |

### 2. 两种消化方式

| 方式 | 内容 | 部位 | 特点 |
|------|------|------|------|
| 机械性消化 | 咀嚼、胃蠕动、小肠分节运动 | 口腔、胃、小肠 | 把大块食物变成食糜，增大接触面 |
| 化学性消化 | 消化酶把大分子分解为小分子 | 口腔、胃、小肠 | 真正的"拆分子" |

```
机械消化（物理变碎）
    ↓
化学消化（酶拆分子）
    ↓
可吸收小分子 → 进入血液/淋巴
```

> **营养师视角：** "细嚼慢咽"不仅是礼仪——充分咀嚼能减少胃肠负担，还让唾液淀粉酶更早工作。

### 3. 化学性消化：三大营养素的"拆迁路线"

| 营养素 | 起始部位 | 主要酶 | 终产物 |
|--------|---------|--------|--------|
| 碳水（淀粉） | 口腔（少量）、小肠（主力） | 唾液淀粉酶、胰淀粉酶、麦芽糖酶 | 葡萄糖、果糖、半乳糖 |
| 蛋白质 | 胃（初步）、小肠（主力） | 胃蛋白酶、胰蛋白酶、糜蛋白酶、肽酶 | 氨基酸、二肽、三肽 |
| 脂肪 | 小肠 | 胰脂肪酶（需胆汁乳化） | 甘油一酯、游离脂肪酸、甘油 |

### 4. 吸收：营养从哪里进血液

| 营养素 | 吸收方式 | 去向 |
|--------|---------|------|
| 葡萄糖/半乳糖 | 主动转运（SGLT1，需钠） | 血液 → 门静脉 → 肝 |
| 果糖 | 易化扩散（GLUT5） | 血液 → 门静脉 → 肝 |
| 氨基酸/小肽 | 主动转运（多种载体） | 血液 → 门静脉 → 肝 |
| 短/中链脂肪酸 | 直接扩散 | 血液 → 门静脉 |
| 长链脂肪酸+甘油一酯 | 先乳化成微胶粒 → 乳糜微粒 | 淋巴管 → 胸导管 → 血液 |
| 维生素 | 脂溶性（随脂肪）、水溶性（扩散/转运） | 血液 |
| 矿物质 | 主动转运或扩散，互相竞争 | 血液 |

> **关键点：** 脂肪走"淋巴慢车道"，所以高脂餐后血脂高峰来得晚、持续时间长；胆道疾病患者脂肪吸收差，可导致脂溶性维生素（A/D/E/K）缺乏。

### 5. 胃排空——决定"饱多久"的开关

**胃排空**指食糜从胃进入十二指肠的过程。排空速度与食物成分密切相关：

| 食物成分 | 排空速度 | 饱腹感 |
|---------|---------|--------|
| 液体/糖类 | 最快（约 1~2 小时） | 短 |
| 蛋白质 | 中等 | 中 |
| 脂肪 | 最慢（可 4~6 小时以上） | 长 |
| 膳食纤维 | 延缓整体排空 | 长 |

**影响胃排空的因素：**

| 因素 | 效应 |
|------|------|
| 胃内容物量 | 量越大，排空越快 |
| 十二指肠内酸 | 抑制排空（防止伤肠） |
| 十二指肠内脂肪 | 抑制排空（最强调节） |
| 十二指肠内高渗 | 抑制排空 |
| 迷走神经 | 促进排空 |

> **营养应用：** 想延长饱腹感 → 高蛋白+适量脂肪+纤维；想快速补能（运动后）→ 选容易排空的碳水为主。

### 6. 胆汁乳化——脂肪消化的"洗洁精"

- 胆汁由**肝细胞**分泌，在**胆囊**浓缩储存，进食后排放到十二指肠。
- 胆汁不含消化酶，核心成分是**胆盐**。
- **乳化**：胆盐把大脂肪滴打散成微小脂肪滴，增大与胰脂肪酶的接触面积。

```
大脂肪滴
    ↓（胆盐乳化）
微小脂肪滴
    ↓（胰脂肪酶）
甘油一酯 + 游离脂肪酸 + 甘油
    ↓（胆盐形成微胶粒）
小肠黏膜吸收
```

**胆盐的肠肝循环：**

```
肝合成胆盐 → 胆囊 → 小肠（乳化脂肪后）→ 回肠重吸收 → 门静脉回肝 → 再分泌
```

> **营养关联：**
> - 膳食纤维可结合胆盐 → 促进胆盐从粪便排出 → 肝脏被迫消耗胆固醇合成新胆盐 → 一定程度降低血胆固醇（限胆固醇合成来源的原理之一）。
> - 胆囊切除术后患者，胆汁持续缓慢排放、浓度下降，高脂餐后易腹泻、脂肪吸收下降 → 建议少食多餐、控制单次脂肪量。

### 7. 肠道菌群与发酵——被忽视的"消化器官"

人体肠道内寄生约 10^13~10^14 个细菌，被称为"第二基因组"。它们参与：

| 功能 | 机制 | 营养意义 |
|------|------|---------|
| 发酵膳食纤维 | 产短链脂肪酸（乙酸、丙酸、丁酸） | 丁酸是结肠上皮细胞主要能量来源 |
| 合成维生素 | 维生素K、部分B族维生素 | 长期广谱抗生素后需关注 |
| 抑制致病菌 | 占位效应、产抑菌物质 | 维持肠屏障 |
| 影响代谢 | 影响能量提取、血糖、炎症 | 菌群失调与肥胖、胰岛素抵抗相关 |

**短链脂肪酸（SCFA）的生理作用：**

| SCFA | 占比例 | 主要作用 |
|------|--------|---------|
| 乙酸 | 约 60% | 供能、脂质合成底物 |
| 丙酸 | 约 20% | 肝糖异生、抑制胆固醇合成 |
| 丁酸 | 约 20% | 结肠细胞能源、抗炎、肠屏障 |

> **营养应用：**
> - 吃"菌群的饭"（益生元）→ 膳食纤维（菊粉、低聚果糖、抗性淀粉）。
> - 补充"菌群本身"（益生菌）→ 酸奶、发酵食品（注意糖含量）。
> - 高脂高糖低纤维饮食 → 菌群多样性下降 → 肠道屏障受损 → 全身炎症。这是"肠-脑轴""肠-代谢轴"的生理基础。

### 8. 血糖调节生理（重点！）

血糖的来源与去路构成一个精密平衡系统：

```
血糖来源                    血糖去路
├── 食物碳水（外源）         ├── 氧化供能（主要）
├── 肝糖原分解               ├── 合成糖原（肝/肌）
├── 糖异生（非糖→糖）        ├── 合成脂肪（过剩时）
└── 其他单糖转化             └── 其他糖/氨基酸转化
```

**正常血糖的维持靠一对"油门和刹车"：**

```
进食 → 血糖↑ → 胰岛素分泌↑（β细胞）
   → 促进葡萄糖进细胞 / 合成糖原 / 合成脂肪 → 血糖↓

空腹/运动 → 血糖↓ → 胰高血糖素↑（α细胞）
   → 肝糖原分解 / 糖异生 → 血糖↑
```

| 激素 | 分泌细胞 | 主要作用 | 触发 |
|------|---------|---------|------|
| 胰岛素 | 胰岛β细胞 | 降血糖；促合成（糖原、脂肪、蛋白） | 血糖↑、氨基酸↑、GLP-1 |
| 胰高血糖素 | 胰岛α细胞 | 升血糖；促糖原分解、糖异生 | 血糖↓、蛋白质餐、运动 |

**其他升糖激素（对抗胰岛素）：**

| 激素 | 升糖方式 |
|------|---------|
| 肾上腺素 | 快速促糖原分解（应激） |
| 皮质醇 | 促糖异生、减少外周利用（慢性） |
| 生长激素 | 拮抗胰岛素、促脂解 |
| 甲状腺激素 | 增加代谢率、促糖吸收 |

> **营养师核心认知：** 血糖不是越低越好，也绝不是"波动越小越好"。目标是让血糖在正常范围内**平缓波动**，避免大幅陡升陡降。这比单纯看某一个点的数值更有意义。

### 9. 胰岛素抵抗机制（现代慢病核心概念）

**胰岛素抵抗（IR）**：靶细胞（肝、肌肉、脂肪）对胰岛素的敏感性/反应性下降——胰岛素"敲门"，细胞却"不开门"。

```
胰岛素抵抗的恶性循环
      ↓
细胞对胰岛素不敏感（尤其肌肉/肝/脂肪）
      ↓
β细胞代偿性分泌更多胰岛素 → 高胰岛素血症
      ↓
长期代偿 → β细胞功能逐渐衰退
      ↓
血糖失控 → 2型糖尿病
```

| 环节 | 说明 |
|------|------|
| 受体前 | 胰岛素自身异常（罕见） |
| 受体水平 | 受体数量↓、亲和力↓ |
| 受体后（最常见） | 信号传导障碍（PI3K/Akt通路受阻、GLUT4转位减少） |
| 细胞因子 | 脂肪组织释放游离脂肪酸、TNF-α、抵抗素 → 干扰信号 |

**与胰岛素抵抗高度相关的因素：**

| 因素 | 机制 |
|------|------|
| 腹型肥胖 | 内脏脂肪释放游离脂肪酸↑ → 脂毒性 |
| 缺乏运动 | 肌肉GLUT4转位减少、线粒体功能下降 |
| 高糖/高精制碳水 | 反复高血糖 → 氧化应激 → 信号受损 |
| 慢性炎症 | NF-κB通路激活 → 干扰胰岛素信号 |
| 睡眠不足/压力 | 皮质醇↑ → 拮抗胰岛素 |
| 遗传 | 家族史、相关SNP |

> **营养应用：** 改善胰岛素抵抗的核心不是"饿"，而是：减内脏脂肪 + 规律运动 + 低GI碳水 + 足量蛋白质 + 好睡眠。运动提升GLUT4转运是"免费降糖药"。

### 10. 进食后血糖的三道防线（理解控糖的关键）

```
第一道：胰岛素快速相分泌（β细胞预先储备）→ 几分钟内压住血糖峰值
第二道：胰岛素缓慢相分泌（新合成）→ 维持后续
第三道：肝糖原合成 + 外周利用 ↑ → 血糖回落到正常
```

> **营养师提示：** 这就是为什么"餐后散步"效果好——肌肉一活动就消耗血糖，相当于给第二、三道防线"加外援"。

### 11. 营养应用

| 生理机制 | 营养方案依据 |
|---------|-------------|
| 胃排空速度 | 高蛋白+纤维延缓排空 → 平稳血糖、增饱腹 |
| 胆汁乳化 | 胆道术后/胆囊切除 → 控制单次脂肪量、少食多餐 |
| 肠道菌群发酵 | 膳食纤维 → SCFA → 肠屏障+代谢健康 |
| 胰岛素分泌 | 低GI/低GL → 减少血糖陡升，减轻β细胞负担 |
| 胰岛素抵抗 | 减内脏脂肪+运动+优质碳水+睡眠 |
| 脂肪淋巴吸收 | 高脂餐后血脂峰值延迟 → 有心脑血管风险者控制晚餐脂肪 |

## 三、能量代谢生理

### 1. 能量来源与去路

人体唯一能"用"的能量来自三大营养素（及酒精）：

| 营养素 | 产能系数（生理热价） | 备注 |
|--------|---------------------|------|
| 糖类 | 约 4 kcal/g（17 kJ/g） | 主要供能，优先 |
| 蛋白质 | 约 4 kcal/g（17 kJ/g） | 一般不作为主要燃料 |
| 脂肪 | 约 9 kcal/g（38 kJ/g） | 密度最高，储存形式 |
| 酒精 | 约 7 kcal/g（29 kJ/g） | "空热量"，无必需营养素 |

**能量守恒公式：**

```
能量摄入（食物）= 能量储存（糖原/脂肪/蛋白）+ 能量消耗（BMR + TEF + 活动 + 适应性产热）
```

| 消耗途径 | 占每日总消耗比例（约） | 可控性 |
|---------|----------------------|--------|
| 基础代谢率 BMR | 60~75% | 低（受肌肉量/激素影响） |
| 身体活动 | 15~30% | 高（运动量可控） |
| 食物热效应 TEF | 约 10% | 中（受食物构成影响） |
| 适应性产热 | 5%左右 | 低（受温度/能量状态影响） |

> **一句话：** 减重的本质是让"摄入 < 消耗"，但"消耗"里最大的盘子是基础代谢——所以保住肌肉、避免过度节食，比单纯少吃更重要。

### 2. 能量平衡的计算（营养师基本功）

**体重变化 ≈ 累计能量盈余/亏空 ÷ 7700 kcal/kg**

| 情景 | 说明 |
|------|------|
| 能量正平衡 | 摄入 > 消耗 → 多余能量以脂肪为主储存 |
| 能量负平衡 | 摄入 < 消耗 → 动用糖原、脂肪、蛋白 |
| 减重约 1kg 脂肪 | 约需累计亏空 7000~7700 kcal |

**估算每日总消耗（TDEE）：**

```
TDEE = BMR × 活动系数

活动系数：
久坐（办公室）= 1.2
轻度活动（每周1-3次运动）= 1.375
中度活动（每周3-5次）= 1.55
高度活动（每周6-7次）= 1.725
```

> **注意：** 公式只是估算起点，个体差异大（肌肉量、甲状腺状态、肠道菌群、药物都影响）。

### 3. 基础代谢率（BMR）与影响因素

**基础代谢**指清醒、静卧、空腹（12小时以上）、环境舒适安静状态下维持生命的最低能量消耗。**基础代谢率（BMR）** 是单位时间的基础代谢。

| 影响因素 | 对 BMR 的影响 |
|---------|--------------|
| 体表面积 | 正比（瘦高者相对高） |
| 性别 | 男性高于女性（约 5~10%） |
| 年龄 | 随年龄下降（肌肉量减少） |
| 甲状腺激素 | 显著影响（甲亢↑、甲减↓） |
| 肌肉量 | 肌肉多则 BMR 高 |
| 体温/环境温度 | 过冷过热都升高 |
| 能量摄入 | 长期节食 → BMR 代偿性下降 |

> **营养应用：** 这就是为什么"极端节食"会反弹——BMR 下降了，一旦恢复正常饮食就会迅速囤脂。保护 BMR：蛋白质足量、力量训练、避免长期大热量缺口。

### 4. 食物热效应（TEF）——"消化也要花钱"

**食物热效应**指进食后额外消耗的能量（用于消化吸收、代谢转化）。

| 营养素 | 食物热效应 | 说明 |
|--------|-----------|------|
| 蛋白质 | 约 20~30%（最高） | 转氨基/尿素合成耗能 |
| 碳水化合物 | 约 5~10% | 消化吸收转化 |
| 脂肪 | 约 0~3%（最低） | 几乎"吃多少存多少" |

> **营养应用：** 高蛋白饮食的"额外热量消耗"比高碳/高脂高，这是"高蛋白减重"的生理依据之一。但不要夸大——TEF 只占总消耗约 10%，不能替代热量总量控制。

### 5. 体温调节

**正常体温与波动：**

| 部位 | 正常范围 |
|------|---------|
| 腋温 | 36.0~37.0℃ |
| 口腔温度 | 36.3~37.2℃ |
| 直肠温度 | 36.5~37.7℃ |

昼夜节律：清晨最低，下午 4~6 点最高，波动一般 <1℃。女性排卵后体温轻度升高（孕酮作用）。

**产热与散热：**

| 方式 | 机制 | 占散热比例（安静时） |
|------|------|---------------------|
| 产热：战栗产热 | 骨骼肌不自主收缩 | — |
| 产热：非战栗产热 | 棕色脂肪、代谢 | — |
| 散热：辐射 | 红外线 | 约 60% |
| 散热：传导对流 | 接触/空气流动 | 约 15% |
| 散热：蒸发 | 出汗、不感蒸发 | 约 25% |

**营养关联：**
- 甲状腺激素 ↑ → 代谢率↑ → 产热↑（甲亢怕热、消瘦）。
- 蛋白质摄入高 → 食物热效应高 → 产热略多。
- 体温过低（如长期饥饿）→ 代谢代偿性下调 → 保温、保能量。

### 6. 摄食调节——"为什么你饿了/饱了"

摄食行为主要由**下丘脑**整合外周饥饿/饱腹信号：

```
外周信号（Ghrelin / Leptin / 血糖 / CCK / GLP-1 / 胃扩张）
        ↓
下丘脑弓状核
   ├── 促食欲神经元（NPY / AgRP）
   └── 抑食欲神经元（POMC / CART）
        ↓
食欲行为 / 自主神经 / 能量代谢
```

| 中枢 | 功能 |
|------|------|
| 下丘脑外侧区（摄食中枢） | 刺激摄食 |
| 下丘脑腹内侧核（饱中枢） | 抑制摄食 |
| 弓状核 | 整合外周激素信号 |

### 7. 关键摄食调节因子详解

| 因子 | 来源 | 作用 | 变化 |
|------|------|------|------|
| 胃饥饿素 Ghrelin | 胃黏膜 P/D1 样细胞 | 促食欲、促胃酸分泌 | 空腹↑、餐后↓；节食时↑ |
| 瘦素 Leptin | 脂肪细胞 | 抑制食欲、促能量消耗 | 脂肪多→高；肥胖者存在瘦素抵抗 |
| 胰岛素 | 胰岛β细胞 | 抑制食欲（中枢）、促储存 | 餐后↑；慢性高胰岛素血症抑制减弱 |
| 胆囊收缩素 CCK | 十二指肠/空肠 I 细胞 | 促饱感、促胆囊收缩、促胰酶 | 脂肪/蛋白→↑ |
| GLP-1 | 回肠/结肠 L 细胞 | 促胰岛素、抑胰高血糖素、延缓胃排空、中枢抑食欲 | 进食→↑；被 DPP-4 快速降解 |
| 肽YY（PYY） | L 细胞 | 抑食欲 | 进食→↑ |
| 血糖 | — | 低血糖→促食欲 | 波动 |

**三种"抵抗"概念（营养师高频）：**

| 概念 | 机制 | 结果 |
|------|------|------|
| 瘦素抵抗 | 血瘦素高但下丘脑不敏感 | 饱腹信号失灵→难减重 |
| 胰岛素抵抗 | 靶细胞对胰岛素不敏感 | 高胰岛素血症→2型糖尿病 |
| 肠促胰素效应减弱 | GLP-1 分泌/效应下降 | 餐后胰岛素不足→血糖不稳 |

> **营养应用：** 高蛋白+高纤维 → 促进 CCK/GLP-1 → 饱腹、减重。规律睡眠和运动可改善瘦素敏感性。避免高糖饮料（液体热量绕过饱腹信号）。

### 8. 棕色脂肪与"产热减肥"

- **白色脂肪**：储存能量。
- **棕色脂肪**：含大量线粒体和 UCP1（解偶联蛋白），把能量直接变成热。
- 寒冷暴露、运动可激活棕色脂肪产热（产热效应）。
- **营养关联：** 辣椒素（辣椒）、茶多酚、咖啡因等被认为可轻度激活产热，但效果有限，不能替代热量控制。

### 9. 营养应用

| 生理机制 | 营养方案依据 |
|---------|-------------|
| 能量守恒 | 减重=热量缺口，但不可极端 |
| BMR | 保肌肉（蛋白质+力量训练）防 BMR 下降 |
| 食物热效应 | 高蛋白增加 TEF，辅助减重 |
| 胃饥饿素 | 节食后 Ghrelin↑→难扛饿→要"饿得聪明"（高体积低热量） |
| 瘦素 | 好睡眠+运动改善瘦素敏感性 |
| CCK/GLP-1 | 蛋白质+纤维促饱腹 |
| 棕色脂肪 | 运动/寒冷/辣椒素轻度辅助 |

## 四、循环与血压调节

### 1. 血压的构成与决定因素

**血压**是血液对血管壁的侧压力，通常指动脉血压。

```
血压 = 心输出量 × 外周阻力
心输出量 = 心率 × 每搏输出量
```

| 决定因素 | 影响 |
|---------|------|
| 每搏输出量 | 越大，收缩压越高（脉压大） |
| 心率 | 越快，舒张压相对升高 |
| 外周阻力 | 越大，舒张压越高（主要决定舒张压） |
| 大动脉弹性 | 弹性差 → 收缩压高、脉压大（动脉硬化） |
| 循环血量/血容量 | 增多 → 血压升高（钠水潴留） |

### 2. 正常血压参考

| 分类（成人） | 收缩压 | 舒张压 |
|-------------|--------|--------|
| 正常血压 | <120 | 且 <80 |
| 正常高值 | 120~139 | 或 80~89 |
| 高血压 1 级 | 140~159 | 或 90~99 |
| 高血压 2 级 | ≥160 | 或 ≥100 |

（依据《中国高血压防治指南》，具体诊断需多次测量+专业评估，本文仅作知识参考）

### 3. 快速调节：神经调节

| 机制 | 感受器 | 反应 | 时间 |
|------|--------|------|------|
| 压力感受器反射 | 颈动脉窦、主动脉弓 | 血压↑→心率↓、血管扩张→血压回落 | 秒级 |
| 化学感受器反射 | 颈动脉体、主动脉体 | 缺氧/CO₂↑→升压 | 秒级 |
| 交感缩血管紧张 | 中枢 | 持续维持血管张力 | 持续 |

> **营养关联：** 咖啡因、酒精、压力通过交感激活使血压升高——这就是"饮酒后血压可能先降后升""压力大血压高"的生理机制。

### 4. 中期调节：RAAS 系统

**肾素-血管紧张素-醛固酮系统（RAAS）** 是血压和水钠平衡的核心激素系统：

```
血容量↓ / 肾灌注↓ / 交感↑
        ↓
肾素（肾近球细胞分泌）
        ↓
血管紧张素原 → 血管紧张素Ⅰ →（ACE）→ 血管紧张素Ⅱ
                                          ↓
                ┌─────────────────────────┤
                ↓                         ↓
        强效缩血管                    刺激醛固酮分泌
        （外周阻力↑、血压↑）           （保钠排钾、水重吸收↑、血容量↑）
                                          ↓
                                      血压进一步升高
```

| 成分 | 作用 |
|------|------|
| 肾素 | 由肾近球细胞分泌；把血管紧张素原变血管紧张素Ⅰ |
| ACE | 血管紧张素转换酶；Ⅰ→Ⅱ（血管紧张素Ⅱ是强效升压物） |
| 血管紧张素Ⅱ | 缩血管、促醛固酮、促ADH、促渴觉、促交感 |
| 醛固酮 | 远曲小管保钠排钾 → 水钠潴留 → 升压 |

> **营养关联：** RAAS 过度激活 → 钠水潴留 → 血压↑。这正是"限钠降压"的生理逻辑；也是降压药（ACEI/ARB、利尿剂）的作用靶点。

### 5. 心房钠尿肽（ANP）——身体的"排钠减压阀"

| 项目 | 内容 |
|------|------|
| 分泌部位 | 心房肌细胞 |
| 释放刺激 | 心房牵张（血容量↑、钠负荷↑） |
| 作用 | 排钠利尿、扩血管、抑制肾素和醛固酮、抑制ADH |
| 净效应 | 降低血容量 → 降血压 |

```
血容量↑ → 心房牵张 → ANP↑ → 排钠利尿 → 血容量↓ → 血压↓
```

> **营养关联：** 高血压时体内 ANP 代偿升高，但长期"钠负荷"超过代偿能力 → 血压仍升高。高钾食物促进排钠，相当于帮 ANP"搭把手"。

### 6. 钠水潴留与高血压——营养师最该讲清楚的一条链

```
长期高钠饮食
    ↓
肾排钠能力有限 → 钠潴留
    ↓
水被"拉"住 → 血容量↑
    ↓
心输出量↑ + 血管反应性改变 → 血压↑
    ↓
长期 → 血管硬化、肾损伤 → 血压更顽固
```

| 钠的"帮凶" | 机制 |
|-----------|------|
| 高盐加工食品 | 隐形钠主要来源 |
| 高血糖/胰岛素抵抗 | 肾保钠↑（胰岛素促钠重吸收） |
| 交感兴奋 | 肾血管收缩 → 排钠↓ |
| 睡眠不足 | 皮质醇/交感↑ → 保钠 |

> **营养师提醒：** 限钠不只"少放盐"，更要盯住加工食品里的隐形钠（酱油、咸菜、腊肉、薯片、挂面、面包都含钠）。WHO 建议成人每日食盐 <5g（约合钠 <2000mg）。

### 7. 营养应用

| 生理机制 | 营养方案依据 |
|---------|-------------|
| 血容量↑→血压↑ | 限钠（<5g盐/天） |
| 钾促排钠 | 多吃蔬果（DASH 高钾原理） |
| RAAS 激活 | 限钠+体重管理，减少系统激活 |
| 交感兴奋 | 控咖啡因、限酒、减压、好睡眠 |
| ANP | 规律有氧运动促进循环健康 |
| 肥胖相关高血压 | 减重（每减 1kg 体重血压约降 1mmHg） |

## 五、泌尿与水盐平衡

### 1. 肾单位——肾脏的"最小工作单元"

```
肾单位 = 肾小球 + 肾小管
每个肾脏约 100 万个肾单位

肾小球（滤过）
   ↓ 原尿
肾小管（重吸收 + 分泌）
   ↓
终尿
```

| 肾单位结构 | 功能 |
|-----------|------|
| 肾小球 | 血浆滤过形成原尿（血细胞和大分子蛋白不过） |
| 近端小管 | 重吸收大部分水、钠、葡萄糖、氨基酸、碳酸氢盐 |
| 髓袢 | 建立髓质高渗（浓缩尿） |
| 远曲小管 | 醛固酮/ADH 作用位点 |
| 集合管 | ADH 作用位点，决定最终尿浓度 |

### 2. 肾小球滤过——"180L 的滤过，99% 回收"

| 指标 | 正常值 | 说明 |
|------|--------|------|
| 肾小球滤过率 GFR | 约 125 ml/min | 每昼夜约 180L |
| 滤过分数 | 约 19% | 肾血浆流量中滤过的比例 |
| 每日原尿 | 约 180L | 相当于每天"洗"一遍全身体液 |
| 每日终尿 | 约 1~2L | 99% 的水被重吸收 |

> **营养关联：** 蛋白质摄入过多 → 含氮废物（尿素）生成多 → 肾小管需排更多溶质 → 肾负担增加。**已有肾功能下降者**需限制蛋白质（具体遵医嘱）；健康肾则能正常代偿。

### 3. 肾小管重吸收——"好管家"回收利用

| 物质 | 重吸收特点 | 说明 |
|------|-----------|------|
| 葡萄糖 | 近端小管全部重吸收（有饱和上限） | 血糖 >10mmol/L 左右超出肾糖阈 → 尿糖 |
| 氨基酸 | 近端小管几乎全部 | 需多种载体 |
| 钠 | 近端 65%、髓袢 25%、远端调节 | 醛固酮调节远端 |
| 水 | 随溶质被动吸收 + ADH 调节 | 渗透压关键 |
| 钾 | 远端可排可吸 | 醛固酮排钾 |
| 蛋白质 | 正常几乎不过滤 | 蛋白尿=滤过膜受损信号 |

### 4. 抗利尿激素（ADH / 血管升压素）——"身体的节水开关"

| 项目 | 内容 |
|------|------|
| 合成 | 下丘脑视上核、室旁核 |
| 储存释放 | 垂体后叶 |
| 释放刺激 | 血浆渗透压↑（>280mOsm/L）、血容量↓ |
| 作用部位 | 集合管 V2 受体 |
| 机制 | 使水通道蛋白 AQP2 插入管腔膜 → 水重吸收↑ |
| 净效应 | 尿量↓、尿液浓缩 |

```
缺水 → 渗透压↑ → ADH↑ → 集合管多吸水 → 尿少、尿浓
多水 → 渗透压↓ → ADH↓ → 尿多、尿稀
```

> **营养关联：** 过量饮水 → 稀释性低钠血症（水中毒）——大量出汗后只补纯水不补电解质尤其危险；运动补水建议含少量钠。

### 5. 醛固酮——"保钠排钾"的管家

| 项目 | 内容 |
|------|------|
| 分泌 | 肾上腺皮质球状带 |
| 刺激 | 血管紧张素Ⅱ（主要）、血钾↑、血钠↓、ACTH |
| 作用 | 远曲小管/集合管保钠排钾排氢 |
| 净效应 | 保水（钠吸住水）、血容量↑、血压↑ |

> **营养关联：** 高钾血症可刺激醛固酮排钾；肾衰时钾排出障碍 → 高钾 → 需限钾（含钾高的水果蔬菜需遵医嘱控制）。反过来，长期大量利尿可致低钾。

### 6. 水盐调节激素总结

| 激素 | 对钠 | 对水 | 对钾 | 总效应 |
|------|------|------|------|--------|
| ADH | — | 重吸收↑ | — | 保水、浓缩尿 |
| 醛固酮 | 重吸收↑ | 间接↑ | 排出↑ | 保钠排钾、升压 |
| ANP | 排出↑ | 排出↑ | 保钾 | 排钠利尿、降压 |
| 糖皮质激素（皮质醇） | 少量保钠 | — | — | 应激时水盐协同 |

## 六、神经生理

### 1. 神经元与神经胶质

```
神经元 = 胞体 + 树突（接收信号）+ 轴突（传出信号）
信号传导方向：树突 → 胞体 → 轴突 → 突触 → 下一个神经元
```

| 细胞 | 作用 |
|------|------|
| 神经元 | 接收、整合、传递信号 |
| 星形胶质细胞 | 支持、营养（为神经元供乳酸）、血脑屏障 |
| 少突胶质细胞/施万细胞 | 形成髓鞘（绝缘、加速传导） |

> **营养关联：** 髓鞘主要由脂质（鞘磷脂）和蛋白质构成 → 需要适量优质脂肪；B12 缺乏可损害髓鞘（脊髓亚急性联合变性）。

### 2. 静息电位与动作电位

**静息电位**：约 -70mV（细胞膜内负外正）。基础是 K⁺ 外流（膜对 K⁺ 通透性高）。

**动作电位**：神经信号的"数字信号"。

```
静息（-70mV）
   ↓ 刺激达阈强度
去极化：Na⁺ 内流 → 电位升至约 +30mV
   ↓
复极化：K⁺ 外流 → 回到静息
   ↓
超极化后恢复（钠钾泵把离子泵回去）
```

| 阶段 | 离子 | 方向 |
|------|------|------|
| 去极化 | Na⁺ | 内流 |
| 复极化 | K⁺ | 外流 |
| 恢复 | Na⁺/K⁺-ATP酶 | 泵回 Na⁺、K⁺ |

**特性：** 全或无、可传导、不应期（不能连续高频刺激）。

> **营养关联：** 钠钾泵是"耗电大户"，需要 ATP（→ 糖/脂肪供能 + B族维生素协助产 ATP）。钠、钾、钙、镁共同决定神经肌肉兴奋性：低钙→抽搐，低镁→兴奋性增高、手颤。

### 3. 突触传递

突触是神经元之间或神经元与效应器之间的连接点，主要靠**神经递质**传递：

```
动作电位 → 突触前膜 → Ca²⁺内流 → 递质囊泡释放 → 递质过突触间隙
   → 与突触后膜受体结合 → 后膜电位变化（兴奋或抑制） → 递质被降解/回收
```

| 递质 | 主要作用 | 营养关联 |
|------|---------|---------|
| 乙酰胆碱 | 兴奋性（神经-肌肉接头、副交感） | 胆碱（卵磷脂）；B族 |
| 去甲肾上腺素/肾上腺素 | 交感兴奋 | 酪氨酸（蛋白）；维生素C（合成辅助） |
| 多巴胺 | 奖赏、运动 | 酪氨酸；铁 |
| 5-羟色胺（血清素） | 情绪、睡眠、饱感 | 色氨酸（蛋白）、B6、镁 |
| GABA | 抑制性（放松） | B6（合成辅酶）、镁 |
| 谷氨酸 | 兴奋性（学习记忆） | 谷氨酰胺 |

> **营养关联：** "肠脑轴"——5-羟色胺约 90% 在肠道合成，肠道菌群和色氨酸供给影响情绪。这就是"肠子决定心情"的生理解释。

### 4. 自主神经——"战斗"还是"休息"

自主神经系统（植物神经）分交感和副交感两支，多数器官受双重支配：

| 项目 | 交感神经（战斗/逃跑） | 副交感神经（休息/消化） |
|------|---------------------|------------------------|
| 心率 | 加快 | 减慢 |
| 支气管 | 扩张 | 收缩 |
| 胃肠 | 抑制蠕动 | 促进蠕动 |
| 消化腺 | 抑制分泌 | 促进分泌 |
| 瞳孔 | 扩大 | 缩小 |
| 血糖 | 升高 | — |
| 部位 | 胸腰段（T1~L3） | 脑干+骶段 |

```
应激/压力/咖啡因 → 交感↑ → 心率↑、血压↑、血糖↑、胃肠↓
放松/睡眠/餐后  → 副交感↑ → 心率↓、消化↑、储存↑
```

> **营养关联：** 慢性压力 = 长期交感兴奋 + 皮质醇升高 → 血糖高、内脏脂肪堆积、消化差。对策：规律进餐、充足睡眠、镁和 B 族支持、规律运动（运动本身先升交感、后促副交感恢复）。

### 5. 神经-肌肉接头与营养

- 接头处递质为**乙酰胆碱**，释放依赖 Ca²⁺。
- 镁与钙在神经肌肉兴奋性上相互拮抗（镁离子可"放松"）。
- 低镁 → 肌肉痉挛、手抖；低钾 → 肌无力；低钙 → 手足搐搦。

### 6. 营养应用

| 生理机制 | 营养方案依据 |
|---------|-------------|
| 髓鞘 | B12+优质脂肪（神经"绝缘层"） |
| 钠钾泵/ATP | 糖+脂肪供能、B1/B2/B3 参与产 ATP |
| 神经肌肉兴奋 | 镁/钙/钾平衡；镁助放松 |
| 5-羟色胺 | 色氨酸（蛋白）+B6；肠道菌群 |
| 交感/副交感 | 咖啡因适量、减压、好睡眠 |

## 七、内分泌系统与主要激素生理全表

### 1. 内分泌系统概述

内分泌系统由内分泌腺和散在的内分泌细胞构成，通过**激素**作用于靶细胞：

| 内分泌器官 | 主要激素 |
|-----------|---------|
| 下丘脑 | 释放激素/抑制激素 |
| 垂体前叶 | 生长激素、促激素 |
| 垂体后叶 | ADH、催产素 |
| 甲状腺 | T3、T4、降钙素 |
| 甲状旁腺 | PTH |
| 肾上腺皮质 | 皮质醇、醛固酮、雄激素 |
| 肾上腺髓质 | 肾上腺素、去甲肾上腺素 |
| 胰岛 | 胰岛素、胰高血糖素 |
| 性腺 | 雌激素/孕激素、睾酮 |
| 脂肪组织 | 瘦素、脂联素 |
| 肠道L细胞 | GLP-1、PYY |
| 肾脏 | 促红细胞生成素 EPO、活性维生素D |

### 2. 激素的作用方式与调节

| 激素化学本质 | 举例 | 作用方式 | 受体位置 |
|-------------|------|---------|---------|
| 多肽/蛋白 | 胰岛素、生长激素、瘦素、GLP-1 | 第二信使（通常） | 细胞膜 |
| 胺类 | 甲状腺激素、儿茶酚胺 | 儿茶酚胺经膜受体；甲状腺激素经核受体 | 两者都有 |
| 类固醇 | 皮质醇、醛固酮、性激素 | 直接调节基因转录 | 胞内/核内 |

**激素分泌的调节：**
- 下丘脑-垂体-靶腺轴（甲状腺、肾上腺皮质、性腺）
- 负反馈（最常见）
- 底物浓度（血糖→胰岛素；血钙→PTH）

### 3. 主要激素生理全表（营养师版·每个：作用/异常/营养关联）

#### ① 胰岛素

| 项目 | 内容 |
|------|------|
| 分泌 | 胰岛β细胞 |
| 作用 | 降血糖；促糖原/脂肪/蛋白质合成；促 K⁺ 进细胞 |
| 异常（不足/抵抗） | 1型糖尿病（绝对缺乏）、2型糖尿病（相对不足+抵抗） |
| 营养关联 | 铬/镁/锌参与糖代谢；低GI+运动提敏感；高蛋白促GLP-1 |

#### ② 胰高血糖素

| 项目 | 内容 |
|------|------|
| 分泌 | 胰岛α细胞 |
| 作用 | 升血糖；促肝糖原分解、糖异生 |
| 异常 | 胰高血糖素瘤罕见；糖尿病时α细胞功能也失调 |
| 营养关联 | 蛋白质餐可刺激分泌（蛋白质的"稳糖"作用之一）；低血糖时升糖激素全面动员 |

#### ③ 皮质醇

| 项目 | 内容 |
|------|------|
| 分泌 | 肾上腺皮质束状带（受 ACTH 调控，有昼夜节律：晨高晚低） |
| 作用 | 应激激素：升血糖（糖异生）、促分解（肌肉/脂肪）、抗炎、免疫抑制 |
| 异常 | 过高→库欣综合征（向心性肥胖、满月脸）；过低→艾迪生病 |
| 营养关联 | 慢性压力/慢性高皮质醇 → 腹型肥胖+肌肉流失+血糖↑；镁和 B 族助抗压；规律作息稳节律 |

#### ④ 甲状腺激素（T3/T4）

| 项目 | 内容 |
|------|------|
| 分泌 | 甲状腺（受 TSH 调控）；T4→T3 靠脱碘酶 |
| 作用 | 提高基础代谢率、产热；促生长发育（尤其脑/骨）；增强交感敏感性 |
| 异常 | 甲亢（代谢↑、消瘦、心慌、怕热）；甲减（代谢↓、胖、怕冷、乏力） |
| 营养关联 | 碘（合成原料）；硒（脱碘酶）；缺碘→甲减/甲状腺肿；甲亢耗能大需充足热量蛋白 |

#### ⑤ 生长激素（GH）

| 项目 | 内容 |
|------|------|
| 分泌 | 垂体前叶（睡眠深睡期脉冲分泌） |
| 作用 | 促生长（骨/肌肉）、促脂解、拮抗胰岛素 |
| 异常 | 儿童缺乏→矮小；过多→巨人症/肢端肥大症 |
| 营养关联 | 蛋白质+锌+精氨酸促分泌；好睡眠（尤其深睡眠）；运动（尤其高强度）刺激分泌 |

#### ⑥ 性激素（雌激素/孕激素/睾酮）

| 项目 | 内容 |
|------|------|
| 分泌 | 卵巢（雌激素/孕激素）、睾丸（睾酮）、肾上腺（少量雄激素） |
| 作用 | 生殖；雌激素保骨、保心、促蛋白合成；睾酮促肌肉、促骨、促性欲 |
| 异常 | 绝经后雌激素↓→骨流失↑；男性低睾酮→肌肉↓、疲劳 |
| 营养关联 | 绝经后：钙+维生素D+蛋白质防骨流失；男性：蛋白质+锌+运动维持睾酮；肥胖→雄激素芳香化→雌激素↑（男） |

#### ⑦ 瘦素（Leptin）

| 项目 | 内容 |
|------|------|
| 分泌 | 脂肪细胞（白色脂肪） |
| 作用 | 作用于下丘脑→抑制食欲、促能量消耗；反映脂肪储量 |
| 异常 | 先天性瘦素缺乏极罕见（极度肥胖）；更常见的是瘦素抵抗 |
| 营养关联 | 睡眠不足→瘦素↓、饥饿素↑→易饿；减重后瘦素↓→更难减（生理反抗）；运动改善敏感性 |

#### ⑧ GLP-1（胰高血糖素样肽-1）

| 项目 | 内容 |
|------|------|
| 分泌 | 回肠/结肠 L 细胞（进食后分泌，被 DPP-4 快速降解，半衰期仅 1~2 分钟） |
| 作用 | 葡萄糖依赖性促胰岛素；抑胰高血糖素；延缓胃排空；中枢抑食欲 |
| 异常 | 2型糖尿病患者肠促胰素效应减弱 |
| 营养关联 | 膳食纤维和蛋白质促进内源 GLP-1；"肠促胰素类药物"（司美格鲁肽等）即模拟该通路——须遵医嘱 |

### 4. 激素间的相互作用（营养师要懂的"主角团关系"）

| 关系 | 说明 |
|------|------|
| 胰岛素 vs 胰高血糖素 | 一对"油门/刹车"，共同维持血糖 |
| 胰岛素 vs 皮质醇/GH | 拮抗；慢性压力/GH 高 → 胰岛素抵抗↑ |
| 胰岛素 vs 瘦素 | 胰岛素促脂肪储存→瘦素↑→正常情况下抑食欲 |
| GLP-1 vs 胰高血糖素 | GLP-1 抑胰高血糖素 |
| 甲状腺激素 vs 代谢 | 决定"基础油耗"高低 |
| 皮质醇昼夜节律 | 晨高晚低；节律紊乱→代谢紊乱 |

### 5. 营养应用

| 激素 | 营养支持方向 |
|------|-------------|
| 胰岛素 | 低GI、足量蛋白、运动、控内脏脂肪 |
| 胰高血糖素 | 蛋白质餐、避免长时间空腹低血糖 |
| 皮质醇 | 抗压、镁/B族、规律睡眠、避免过度节食 |
| 甲状腺激素 | 碘、硒；甲亢/甲减遵医嘱 |
| 生长激素 | 深睡眠、蛋白质、锌、运动 |

## 九、常见问题速查（营养咨询高频）

### Q1：为什么我少吃还胖？
可能原因：基础代谢代偿性下降（长期节食）、肌肉量低、睡眠差（瘦素↓饥饿素↑）、慢性压力（皮质醇↑促腹胖）、隐性热量（酱料/饮料）。生理学答案在"能量代谢 + 摄食调节"两章。

### Q2：为什么餐后犯困？
可能原因：高碳水餐 → 血糖快速升降 → 胰岛素大量分泌；交感→副交感切换；血流量向胃肠道集中。对策：碳水+蛋白+纤维混合、控制精制糖。

### Q3：为什么一紧张就胃不舒服？
交感兴奋 → 胃肠蠕动抑制 + 胃酸分泌异常 + 内脏血流减少。对策：腹式呼吸、规律进餐、减压。

### Q4：为什么运动后胃口反而变好？
运动消耗能量 → 饥饿素上升、代谢率提高；但规律运动长期看改善瘦素敏感性。对策：运动后合理补充蛋白质+适量碳水。

### Q5：为什么睡前吃太饱睡不着？
胃排空慢（脂肪尤其）→ 胃内容物反流 + 副交感应主导的夜间被进食打断 + 血糖波动。对策：晚餐早吃、清淡、睡前2-3小时不进食。
