# AI创业系统 · 本地部署全流程

> 从零搭建安利AI创业系统的完整步骤。按顺序走，半小时搞定。

---

## 第一步：梯子（网络环境）

很多 AI 工具需要境外网络访问，先解决梯子问题：

1. **注册账号** → [mojie.app/register](https://mojie.app/register)
2. **购买订阅** → 看站内"使用文档"，买最便宜的套餐（**1元试用**即可）
3. **配置客户端** → 按文档指引下载客户端，导入订阅链接
4. **验证** → 打开 google.com，能访问即成功

> 注意：梯子是基础设施，后续所有 AI 工具都依赖它。如果后面步骤卡住，先检查梯子是否开着。

---

## 第二步：Workbuudy · AI 模型调用

Claude Code 本地运行需要调用大模型 API，走 Workbuudy 中转 DeepSeek V4 Pro：

### 2.1 注册 & 领积分
1. **注册 Workbuudy** → 平台注册账号
2. **下载客户端 / 领取积分** → 新用户有免费额度，下载后先领了跑通流程

### 2.2 部署 Claude Code（两步指令法）
> 严格按顺序，不要提前做多余操作。

**① 先发第一条指令（仅安装）**
```
帮我本地部署 claude code，仅仅安装不要做其他任何动作
```
→ 系统自动执行安装，安装完成后停下来等你

**② 安装完成后，再发第二条指令（配模型）**
```
帮我用 claude code 调用 deepseek v4pro 的模型
```
→ 系统提示需要 API Key

### 2.3 充值 & 配置 API Key
1. **去 DeepSeek 官网** → 注册/登录 → **充值 10 元**（启动资金，够用很久）
2. **拿到 API Key** → 复制你的 DeepSeek API 密钥
3. **交给 Workbuudy** → 把 API Key 配置到 Workbuudy 的接口设置中

### 2.4 终端验证
打开终端（Terminal），输入以下命令验证：

```bash
# Mac 用户：直接打开终端
# Windows 用户：Win+R → 输入 cmd 或 terminal → 回车

# 确认 Claude Code 已安装
claude code

# 如果显示欢迎/对话界面，说明安装成功 ✅
```

> 验证时看到 Claude Code 正常启动并能对话，即表示第二步完成。

> 这里 10 元是启动资金，后续根据使用量补充，调用 DeepSeek V4 Pro 成本很低。

## 第三步：Obsidian · Claudian 插件 + 知识库安装

AI 助手接入你日常使用的 Obsidian 笔记系统，同时安装"超级大脑"知识库。

### 3.1 安装 Obsidian
1. 去 [Obsidian 官网](https://obsidian.md) 下载并安装 Obsidian
2. 打开 Obsidian，创建一个新 vault（或打开已有 vault）

### 3.2 安装 Claudian 插件
1. Obsidian → 设置（左下角齿轮）→ **第三方插件** → **社区插件市场**
2. 搜索 **`claudian`**（注意拼写）
3. 点击安装 → 安装完成后点击启用
4. Claudian 插件即配置完成，无需额外设置

### 3.3 安装"超级大脑"知识库（amway-knowledge-vault）
1. 打开浏览器，去 **GitHub** 搜索 **`amway-knowledge-vault`**
2. 进入仓库主页 → 复制仓库 URL（HTTPS 链接）
3. 回到 Obsidian，向 **Claudian 插件发送该网址**
4. 告诉它：**"帮我安装这个知识库"**
5. 等待自动安装完成

> 安装完成后，你的 Obsidian 就接上了安利AI创业系统的完整知识库。

## 第四步：安装 Skill · 安利AI创业系统

核心系统安装，从 GitHub 拉下来，接上你常用的两个外部平台：

### 4.1 安装系统
- 从 GitHub 上 **安利AI创业系统** 仓库下载/克隆
- 按仓库 README 指引，把文件放到 Obsidian vault 中对应的位置
- 确认技能（Skills）目录被正确加载

### 4.2 跑通飞书接口（录音处理）
- 飞书开发者后台建一个自建应用 → 获取 App ID + App Secret
- 在本地配置飞书 API 凭证
- 配置录音同步的目标文件夹（日记目录）
- **验证** → 说"帮我拉一下飞书的录音"，看能不能正常拉取并走完知识卡/洞见卡流程

### 4.3 跑通微信公众号接口（文章发布）
- 微信公众号后台 → 开发 → 获取开发者 ID 和 API Key
- 在系统中配置公众号 API 凭证
- **验证** → 说"发公众号"，看能不能正常推文到草稿箱

### 4.4 全流程跑通检查
逐条测试以下命令，确认每个环节都正常：
- "帮我拉飞书录音" → 录音下载 → 知识卡/洞见卡生成
- "根据痛点排行写脚本" → 脚本生成
- "指定脚本发公众号" → 公众号草稿箱
- "今日复盘" → 复盘输出

## 第五步：安装 Karpathy 工作准则

Claude Code 的行为准则，源自 [Andrej Karpathy 对 LLM 编程陷阱的观察](https://x.com/karpathy/status/2015883857489522876)。确保 AI 助手不写多余代码、不搞砸已有内容。

### 5.1 安装技能
```bash
# 本系统已内置，只需创建符号链接：
ln -s /Users/mac/Documents/.claude/skills/karpathy-guidelines ~/.claude/skills/karpathy-guidelines
```

### 5.2 四大准则（AI 助手自动遵循）

| 准则 | 核心要求 |
|------|---------|
| **先想再写** | 不假设、不隐藏疑惑、摆出权衡。不清楚就停下来问 |
| **简单第一** | 最少代码解决问题。不加没被要求的功能 |
| **外科手术式改动** | 只动必须动的。每一行改动都能追溯到用户请求 |
| **目标驱动** | 定义成功标准，循环直到验证通过 |

### 5.3 验证
- 说"帮我写脚本" → 看 AI 是否自动按四条准则工作（先调研、不写多余功能、只改对应行、定义目标）
- 日常使用中如果 AI 写得太啰嗦或改多了，提醒它"遵循 Karpathy 准则"

> 这步装好后不需要手动操作——AI 会自动遵守。如果感觉 AI 发挥不稳定，回来检查这条是否启用。

## 第六步：选题调研 · 评论区挖需求

系统搭好后，日常主动找选题的方法：

1. **锁定领域大博主** → 你的目标领域（安利/创业/大健康/营养）头部账号
2. **翻评论区** → 看粉丝在问什么、抱怨什么、卡在哪里
3. **多个平台都翻** → 小红书、视频号、抖音、B站，每个平台的评论区画风不同
4. **记下来** → 把高频问题/痛点录入痛点排行榜，下次写脚本直接用

> 这步没有固定频率——有空就翻，翻到了就入库。

## 第七步：每日指令速查

系统跑通后，日常就靠这几条指令驱动。贴在 Obsidian 里，随时用：

| 你说 | 系统自动执行 |
|------|------------|
| **任何信息帮我跑流程** | 沉淀知识卡片、洞见卡，更新选题库 |
| **根据痛点排行写脚本** | 安利类给口播脚本，AI 类同时给出字幕条 |
| **指定脚本写公众号** | 口播稿→公众号文章→推送到草稿箱 |
| **指定脚本写朋友圈** | 出文案 + Gemini 配图 |
| **我要做 PPT / 微课堂** | 调用 PPT 生成工具出课件 |
| **我要做一场直播** | 打开直播框架，辅助写直播稿 |
| **今日复盘** | 跑复盘管线，分析数据 |
| **怎么突破业绩** | 读业绩突破导航→诊断部门→出突破策略 |
