# 安利企业文化

> 一句话：两位创办人创办安利至今，**核心价值观从未改变**——它是安利事业发展必需且永恒不变的基本理念。

## 一、六大核心价值观（Values）

1. **伙伴关系（Partnership）**：安利建立在创办人伙伴关系基础上，为合作伙伴长远利益努力，增进相互信任。
2. **诚信（Integrity）**：言必信、行必正；信任像精致瓷器，碎了裂痕永远都在。
3. **个人价值（Personal Worth）**：尊重并肯定每个人的独特性，人人有发挥潜能达致成功的机会。
4. **成就（Achievement）**：自强不息、激励他人、追求卓越、洞悉潮流迅速行动。
5. **个人责任（Personal Responsibility）**：尽力尽责实现自己目标，助人自助；做优秀社会公民。
6. **自由企业（Free Enterprise）**：在市场经济中实现最大发展；不问出身，人人可建立自己的事业。

## 二、四大基石

1. **自由**：人类最自然的状态，推崇选择的自由，助人拓展更广泛的自由。
2. **家庭**：社会最基本单位，给予爱、关怀和传统。
3. **希望**：赋予力量改变命运，憧憬未来、订立目标、取得伟大成就。
4. **奖励**：施与受、尊重爱护、嘉许承担责任者、提高生产力。

## 三、五大收入

1. 灵活就业的收入（不限时间地点）
2. 被动的收入（市场自动生命力，退休仍有）
3. 没有上限的收入（由自己决定）
4. 全球化事业收入（没有地域限制）
5. 世袭收入（市场可转给子女，保障性财富起点）

## 四、六大价值

1. 经济自由
2. 时间自由
3. 广交朋友（传统行业踩伙伴、诋毁竞争者；安利团结互助）
4. 自我成长（通过教育培训、学习开会成长）
5. 海外旅游（每年国外免费旅游）
6. 认可和尊重（有舞台阐述成功故事，自我价值延伸）
