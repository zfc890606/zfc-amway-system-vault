> 以下模型均提炼自经典管理框架，可直接用于团队培训、伙伴辅导、知识卡片素材。

---

## 一、卡茨管理技能模型 — 管理者的三大能力

```
              高层管理者
           ┌─────────────┐
           │  概念技能    │ ← 抽象思维、全局观、长期规划
           │  (最重要)    │
     中层  ├─────────────┤
           │  人际技能    │ ← 表达自我、理解他人、处理冲突
           │  (始终重要)  │
     基层  ├─────────────┤
           │  技术技能    │ ← 具体业务执行能力
           │  (基础)      │
           └─────────────┘
```

**带团队启示**：
- 培养伙伴要从"技术技能"（产品知识/营养知识）起步
- 进阶到"人际技能"（沟通/连接/服务）
- 高阶 leader 必须有"概念技能"（战略眼光/系统思维）

## 二、猴子管理法则 — 责任要分明

> **"猴子" = 问题和任务的责任**

| 层级 | 核心 | 关键动作 |
|------|------|---------|
| 🐒 个人层面 | 完成任务 | 教会伙伴"照顾好自己的猴子"，主动解决问题 |
| 🐒🐒 团队层面 | 完成目标 | 建立工作流程和沟通机制，协同推进 |
| 🐒🐒🐒 组织层面 | 制定规则 | 建立文化体系、培训机制、激励评价 |

**带团队启示**：
- 不要做伙伴的"猴子保姆"——你背的猴子越多，团队越弱
- 核心是教会伙伴"如何自己养猴子"，而不是替他们养

## 三、领导力梯队 — 分阶段领导力发展

```
                    ┌──────────┐
                    │ 集团高管  │ ← 战略规划、评估业务、调配资源、培养下属
                    ├──────────┤
                    │ 首席执行官│ ← 洞察机遇、平衡利益、权衡取舍、培养人才
                    ├──────────┤
                    │事业部总经理│ ← 工作理念、时间管理、领导技能
                    ├──────────┤
                    │管理职能部门│ ← 制定战略、部门协同、争夺资源、适当授权
                    ├──────────┤
                    │ 管理经理人员│ ← 选拔人才、分配工作（纯管理工作）
                    ├──────────┤
                    │  管理他人  │ ← 工作计划、教练辅导、知人善任、绩效评估
                    └──────────┘
```

**带团队启示**：
- 安利团队的成长也遵循梯队逻辑：自用→分享→带领小组→培养领导者
- 每个阶段的能力要求不同，需要不同的辅导方式

## 四、管理4C模型 — 提升执行力

```
┌──────────────────────────────────────────────────────────┐
│  ① Clarity（清晰）                                       │
│  → 布置任务时要确保清晰明确，让伙伴100%理解               │
├──────────────────────────────────────────────────────────┤
│  ② Commitment（承诺）                                    │
│  → 承诺要真心，发自内心的承诺才有执行力                   │
├──────────────────────────────────────────────────────────┤
│  ③ Competence（胜任）                                    │
│  → 不仅是能力，还有态度；两者缺一不可                      │
├──────────────────────────────────────────────────────────┤
│  ④ Control（控制）                                       │
│  → 事前、事中、事后的全面控制，不是微管理                  │
└──────────────────────────────────────────────────────────┘
```

## 五、TOPIC模型 — 管理5要素

| 要素 | 英文 | 关键动作 |
|------|------|---------|
| 🤝 **信任** | Trust | 言行一致、共赢思维、公开透明 |
| 🎯 **目标** | Objective | 目标明确、达成共识、定期回顾 |
| 🔄 **流程** | Process | 合理流程、持续优化、共同遵守 |
| 👊 **承担** | Commitment | 责任共担、分工协作、互帮互助 |
| 💬 **沟通** | Communication | 有效沟通、言路通畅、及时反馈 |

> 这是团队管理的"五大支柱"，缺一不可。

## 六、情景领导力模型 — 教练型领导

```
员工状态        →        最合适的领导风格
─────────────────────────────────────────
D1 低能力高承诺  →  S1 指导为主（教他怎么做）
D2 低能力低承诺  →  S2 教练型（指导+支持）
D3 高能力低承诺  →  S3 支持型（放手+鼓励）
D4 高能力高承诺  →  S4 授权型（完全授权）
```

**带团队启示**：
- 新人（D1）：热情高但不懂 → 手把手教，给标准动作
- 成长中（D2-D3）：能力有但信心波动 → 多鼓励、少批评
- 成熟伙伴（D4）：能力和信心都够 → 放手让他飞

## 七、POA行动模型 — 提高行动力

```
    目标 O（Objective）
        ↑
  伙伴 P（Partner） → → 方法 A（Acceleration）
                          （加速度）
```

**公式**：行动力 = (伙伴 × 方法) / 目标

- **伙伴（P）**：找到志同道合的人
- **目标（O）**：目标要单一、明确
- **方法（A）**：方向与目标一致才能加速

> **带团队就是要找到更多伙伴，用更有效的方法，朝同一个目标前进。**

---

## 八、可复制化思维 — 让成果无限放大

```
学习 → 提炼 → 方法论 → 实践 → 反馈 → 迁移
  ↑_______________________________↓
             持续循环
```

**带团队启示**：
- 你的成功经验必须能提炼成方法论
- 方法论必须能被伙伴复制
- 复制后还要能迁移到不同场景
- 这就是"做安利"的本质——可复制

## 九、马斯洛需求层次 — 读懂伙伴的需求

```
       自我实现  ← 实现梦想、发挥潜能
    尊重需求     ← 被认可、有价值
  爱与归属       ← 团队归属、情感连接
安全需求         ← 收入稳定、保障
生理需求         ← 基本生存
```

**带团队启示**：
- 不同阶段的伙伴，需求不同
- 新手需要"安全感"（有人带、有方法）
- 老手需要"尊重和认可"（被看见、有价值）
- 核心骨干需要"自我实现"（成就感和梦想）

## 十、决策工具

### DOCA（决策量化工具）
列出正价值/负价值 → 给候选方案打分 → 选最优

### 决策矩阵
确定评价标准 → 分配权重 → 打分 → 加权合计

### ABC分类法
- **A类（10-20%数量，70-80%价值）**：最重要，严格管理
- **B类（30%数量，15-25%价值）**：适中管理
- **C类（50%数量，5%价值）**：简化管理

---

## 十一、沉没成本理论

> 已经发生的、不可回收的支出（时间/金钱/精力），不应影响当前决策。

**带团队启示**：
- 带错了人？该放手就放手，别让沉没成本拖累团队
- 做错了项目？及时止损是最好的决策
