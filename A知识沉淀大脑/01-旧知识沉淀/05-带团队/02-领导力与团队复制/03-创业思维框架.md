## 一、麦肯锡三大基石（价值观层面）

```
┌─────────────────────────────────────────────┐
│          麦肯锡三大基石                       │
│                                             │
│  🏛️ 专业主义     📊 事实依据     🗼 高层观点   │
│  追根究底        提出有力证据    站在更高角度  │
│  亲临现场        不凭直觉妄断    俯瞰全局     │
│  不自大吹嘘      弥补猜测不足    力求公正     │
└─────────────────────────────────────────────┘
```

### 面对问题的9个客观指数（自检清单）

1. 是否实事求是，而非根据猜测？
2. 能否接纳别人不同的意见？
3. 能否采取不喜欢但有事实根据的行动？
4. 找不到症结时，是否先弄清楚再行动？
5. 是否等充分事实后再做决定？
6. 下属提出正确但你不同意的方案，能接受吗？
7. 能否根据团队利益而非个人好恶行动？
8. 处理人事问题时，能不掺杂个人成见吗？
9. 是否了解清楚后再下结论？

> **带团队启示**：这9个问题是团队领导者每日自检的"客观指数"。

## 二、麦肯锡问题解决三大步骤

```
① 以事实为基础
   → 收集足够事实，作为解决问题起点
   
② 严谨的结构（MECE原则）
   → 相互独立、完全穷尽
   → 确认议题没有遗漏、没有重叠
   
③ 假设导向
   → 先设想解决方法 → 引导方向 → 验证假设
```

**应用场景**：团队遇到瓶颈时，用这三步帮伙伴理清问题。

## 三、麦肯锡四大思维方式

### Ⅰ 零基准思考
> 以零基准思考事物，拆掉所有框架

**常规问题** → 用既有框架解决
**非常规问题** → 必须跳出框架，从零思考

> 带团队时，不要被"以前都是这么做的"限制住。

### Ⅱ 逻辑思考
- 把复杂问题拆解成可验证的假设
- 用事实和数据检验每一步

### Ⅲ 议题思考
- 先问"真正的问题是什么"
- 不要急着找答案，先确认问题

### Ⅳ 假设思考
- 先提出假设 → 快速验证 → 修正或推翻
- 比"慢慢分析再行动"更高效

## 四、冯唐战略思维（普通人方法论）

### 3C原则（做选择的框架）

```
看自身（Company）    看对手（Competitor）    看需求（Customer）
     │                      │                      │
     └──────────────────┬──────────────────────────┘
                        ▼
                做出最优选择
```

### 二八原则（取舍的智慧）
> 20%的事能带来80%的价值，其余多是消耗。

**带团队启示**：
- 帮伙伴找到TA最重要的20%动作
- 砍掉无意义的80%消耗
- 聚焦核心，而不是面面俱到

### 战略复盘（冯唐五道之一）
> 定期回头看：哪些做对了？哪些做错了？下次怎么调整？

### 逆境不慌的底气
> 战略思维不是"逆境必胜"的保证，而是"逆境不慌"的底气。
> 它让你知道，哪怕眼前再难，只要想清楚"何处竞争、何时竞争、如何竞争"，就总有破局的机会。

## 五、微信产品观的用户思维（适用于"伙伴思维"）

张小龙的产品哲学，同样适用于 "把伙伴当作用户"：

| 产品思维 | → 带团队迁移 |
|---------|------------|
| 用户需要什么？ | 伙伴在哪个阶段？需要什么支持？ |
| 用户体验至上 | 让伙伴觉得"被重视、被帮助" |
| 简洁就是美 | 方法要简单可复制，别搞复杂 |
| 用完即走 | 帮伙伴快速拿到结果，而不是耗在过程中 |
| 让用户主动分享 | 让伙伴发自内心想推荐给更多人 |

### 带团队启示

```
做产品 → 关注用户需求
带团队 → 关注伙伴需求

做产品 → 降低使用门槛
带团队 → 降低复制难度

做产品 → 让用户"爽"
带团队 → 让伙伴"有成就感"
```

## 六、麦肯锡的管理篇精华

### 专业主义的核心
- **客户放第一**：客户 → 公司 → 个人（排序）
- **到现场去感同身受**，不仅仅是道听途说
- **诚信做人**：对客户、对组员、对自己

### 沟通篇（简版）
- 结论先行
- 数据支撑
- 简洁明了
