# 健康管理实战班·复盘会（Dr.zhang）

> 一句话：**CDD 去中心化模式**——核心技术公开赋能CHO，经营者零门槛成功；外品牌是中心化，CDD让客户受益。

## 一、定位

1. 大健康时代赋予我们的使命
2. 医生营养师社群的使命与价值

- 慢病数据（脂肪肝1.2亿/血脂1.6亿/高血压2.7亿/超重3.4亿/肥胖1.64亿/糖尿病1.19亿）；疾病谱改变；健康第一责任人是自己（2020《卫生健康法》）。
- **营养是目前慢性病最重要的干预调控点**；全营养轻断食的饮食模式适合当代人群健康管理。

## 二、CDD vs 外品牌（中心化 vs 去中心化）

| | 外品牌（中心化） | CDD（去中心化） |
|---|---|---|
| 结构 | A/B/C经营者各带客户 | CHO1/2/3各带客户 |
| 特点1 | 客户受益 | 客户受益 |
| 特点2 | 品牌核心不公开 | 核心技术公开赋能CHO |
| 特点3 | 经营者高门槛，品牌成功 | 经营者零门槛成功 |

## 三、知识复盘（轻断食核心）

- 单室模型（能量存耗CICO）vs 双室模型（肝糖原→体脂肪，胰岛素低水平优先）。
- 断食→胰岛素下降→①脂肪消耗供能 ②胰岛素敏感性提高。
- 知识总结：①轻断食为什么可以减脂？②全营养对均衡营养的重要性？③轻断食执行的要点和疑点。

2. 掌握各类慢病的健康管理整体解决方案
3. 讲解答疑、实践实操、服务辅导、健康教育
