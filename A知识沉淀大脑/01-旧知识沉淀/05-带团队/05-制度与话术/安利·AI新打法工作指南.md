```
服务对象：安利创业者 · 目标 FC 皇冠大使
    │
    ├─ 两大价值 ─────────────────────┐
    │  ① 营养专业（抓顾客）           │
    │  ② AI互联网安利打法（抓合作伙伴）│

    ├─ 三件专注事 ────────────────────┤
    │  ① 知识整理 → ② 自媒体输出      │
```

### 为什么是"AI新打法"？

**传统安利打法的困境：**

| 维度 | 传统打法 | 痛点 |
|------|---------|------|
| 找人 | 扫街、陌拜、熟人推荐 | 效率低、面子成本高 |
| 学习 | 线下会议、录音带、翻资料 | 信息碎片、学了就忘 |
| 跟进 | 电话+上门+约茶 | 时间成本高、覆盖有限 |
| 复制 | 师徒口传心授 | 周期长、难规模化 |
| 信任 | 靠见面建立 | 流量触达有限 |

**AI新打法怎么破局：**

```
你今天学到的东西
    ↓
存入第二大脑（知识库）
    ↓
AI帮你去AI味 → 变成口语化脚本
    ↓
发到视频号 → 公域流量 → 有人看到 → 信任前置
    ↓
主动私信你 → 你已经是"那个懂营养/懂创业的博主"
    ↓
约聊 → 长客会 → 裂变 → 管道收入
```

**核心差异：** 以前你找人，现在人找你。以前靠勤奋堆时间，现在靠系统放大效率。

### 一句话说清楚"AI新打法"

> **用第二大脑沉淀认知 → 用自媒体放大价值 → 用长客会裂变市场**
>
> AI 不是替代你，而是让你不再重复造轮子——把时间花在"人"身上。

## 二、一个系统：本地知识库 · 构建第二大脑

### 2.1 什么是第二大脑？

> 第二大脑是一个**外化**的知识系统——把你看到、学到、想到的所有有价值的信息，用一套方法存入你专属的本地知识库。

它不是文件夹，不是笔记堆，而是一个**可检索、可连接、可输出的智能知识网络**。

**类比理解：**

```
你的大脑 = 内存（读写快、容量小、会忘）
第二大脑 = 硬盘（读写慢一点、容量无限、永久存储）
AI 助手  = CPU（帮你处理、提取、生成）
```

三者配合，你的认知效率放大 10 倍。

### 2.2 为什么安利创业者必须建？

| 场景 | 没有第二大脑 | 有了第二大脑 |
|------|------------|------------|
| 客户问一个健康问题 | 凭记忆回答，可能不准确，回答完就没了 | 调出知识卡片 → 专业回答 → 存入对话记录 |
| 想发一条短视频 | 憋半天想不出选题，灵感来了又没抓住 | 打开知识库 → 今天沉淀了什么 → 直接成稿 |
| 新人伙伴加入 | "你先自己学，不懂问我"（散养） | "这是系统，你照做"（复制） |
| 三个月后 | 学了不少但说不清"我的体系" | 知识库就是你的体系，随时展示 |
| 一年后 | 知识在脑子里，但带不动团队 | 系统在手，新伙伴三天上手 |

**一句话：** 第二大脑是你事业的"固定资产"——你越用它越值钱，而且可以传给伙伴。

### 2.4 两种知识卡片——从灵感到体系

#### 📇 洞见卡（DJ-*）— 金句存这里

一句话金句 + 即刻可用的方法。

**格式：**

```
---
卡片ID: DJ-创业-001
类型: 洞见卡
板块: 创业认知
来源: 日常思考/课程/读书
---

**标题：安利不是销售，是赋能**

金句：你不是在卖产品，你是在帮人建立一种更健康的生活方式。

即刻可用：
① 客户拒绝时，不要觉得"我又被拒绝了"
② 换成"他还没准备好接受健康"
③ 先服务，后成交——服务本身就是最好的销售
```

**什么时候写洞见卡：** 任何时刻，你听到/想到一句让你"叮"一下的话，马上写。30 秒搞定。

#### 🃏 知识卡片（KC-*）— 4K完整框架

一个知识点，展开成结构化卡片。

**模板（4K框架）：**

```
---
卡片ID: KC-营养-001
类型: 知识卡片
板块: 营养解决方案
来源: 《隐形饥饿》/ 课程笔记

# 隐性饥饿

## ① 概念（What）
吃撑了但没吃对——热量过剩，微量营养素（维生素、矿物质）不足。

## ② 拆解（Why）
- 精加工食品多 → 营养素流失
- 土壤贫瘠 → 食物本营养下降
- 现代人消耗大 → 需求增加

## ③ 案例（Example）
李姐，35岁，每天吃外卖，体重正常但总是疲劳、
口腔溃疡反复。→ 补充B族+VC → 2周改善。

## ④ 行动（How）
跟客户聊的时候，问三个问题：
1. "你平时三餐怎么吃？"
2. "有没有总觉得累？"
3. "口腔溃疡频繁吗？"
→ 三个问题挖出隐性饥饿 → 引出营养方案
```

**什么时候写知识卡片：** 一个知识点你反复用到、或者值得深入研究时，花 15-20 分钟写成 4K 卡片。

### 2.5 每日沉淀的操作流程

```
每天 15-30 分钟
    ↓

    ↓
三个动作选一个：
    ├─ 写一张洞见卡（30秒-2分钟）
    ├─ 写一张知识卡片（15-20分钟）
    └─ 整理素材进对应板块（5分钟）
    ↓
打标签 → 建链接 → 关联已有卡片
    ↓
✅ 完成
```

**核心习惯：** 每天至少写一张洞见卡——不中断比写多少重要。

## 三、两个基本功

这两个基本功，一个是**抓顾客**，一个是**抓合作伙伴**。缺一个，都不完整。

```
基本功①：营养处方长客会
    └─ 解决：客户为什么要跟你买？（因为你专业）
    
基本功②：长客会裂变百万年薪
    └─ 解决：伙伴为什么要跟你做？（因为你能带他赚钱）
```

### 基本功①：营养处方长客会

#### 3.1.1 核心认知

> **你不是在卖产品，你是在给客户的健康开"处方"。**

普通销售和专业的区别：

| | 普通销售 | 营养专业顾问 |
|--|---------|------------|
| 开口 | "这个产品很好，你试试" | "你最近哪里不舒服？" |
| 方式 | 推销产品 | 诊断需求 |
| 客户感觉 | 她想赚我钱 | 她真的关心我 |
| 结果 | 比价格、犹豫 | 信任、买单、转介绍 |
| 持续性 | 一锤子买卖 | 长客会长期复购 |

#### 3.1.2 营养专业需要掌握的知识体系

**三层能力模型：**

```
第三层：个性化调理方案设计
    ↑
第二层：慢病底层逻辑与营养干预
    ↑
第一层：基础营养学 + 产品知识
```

**第一层——基础（人人必修）：**
- 人体七大营养素（蛋白质、脂肪、碳水、维生素、矿物质、纤维素、水）
- 隐性饥饿的概念（吃饱≠吃好）
- 纽崔莱核心产品线及对应营养素
- 日常保健搭配方案（基础三件套：蛋白粉+B族+VC）

**第二层——进阶（让你和别人不一样）：**
- 慢病底层逻辑：炎症、氧化应激、代谢紊乱
- 常见慢病与营养关系：
  - 糖尿病 → 血糖代谢 + 胰腺营养
  - 高血压 → 血管弹性 + 钠钾平衡
  - 脂肪肝 → 肝脏代谢 + 脂溶性维生素
  - 肠胃问题 → 肠道菌群 + 消化酶
- 营养调理的基本原则：先排后补、循序渐进

**第三层——高阶（专家级）：**
- 个性化健康评估（体质分析、生活习惯问诊）
- 长客会方案设计（3个月/6个月/12个月搭配）
- 不同人群的营养方案差异（中老年/年轻人/儿童）
- 协同调理：营养+运动+睡眠+情绪

#### 3.1.3 营养处方的四步流程

**第一步：问诊——挖出真实需求（15-20分钟）**

关键不是介绍产品，而是**让客户说出自己的问题**。

```
开场白（不要一上来就推产品）：
"姐/哥，你最近是不是觉得……（某个常见问题）？最近很多人都有这个情况。"

四类问题清单：
├─ 健康状况：
│  "你平时睡眠怎么样？"
│  "有没有总觉得累、精力不够？"
│  "肠胃怎么样？容易胀气/便秘吗？"
│
├─ 饮食习惯：
│  "一日三餐怎么吃？自己做饭还是外卖多？"
│  "水果蔬菜吃得多吗？"
│  "平时喝水多吗？"
│
├─ 身体信号：
│  "口腔溃疡频繁吗？"
│  "指甲有没有竖纹/脆？"
│  "换季容易感冒吗？"
│  "皮肤干燥/头发掉得多吗？"
│
└─ 已有行动：
   "之前用过什么保健品吗？感觉怎么样？"
   "有没有在吃其他的营养补充？"
```

**第二步：分析——帮客户"看见"问题**

不要直接说"你缺这个"，而是让客户自己意识到：

```
话术示范：
"姐，你刚才说你总感觉累、睡不好、还容易口腔溃疡，
这三个信号放在一起，很可能就是B族维生素摄入不够。
不是说吃饭没吃饱——是'隐性饥饿'，就是热量够但微量营养不够。
现在点外卖多的人，十个里有八个都有这个问题。"

（客户：对对对，我就是这样！）
```

**第三步：开方——给出方案而不是产品**

```
不是推销："这个B族维生素很好你要不要买？"
而是开方："针对你现在的情况，我建议你先从三个基础入手：
1. 早上一勺蛋白粉+全麦面包（补充蛋白质，撑到中午不饿）
2. 随餐B族维生素（针对疲劳和口腔溃疡）
3. 晚上一片VC（帮助修复，提高免疫力）
你先试两周，两周后我问问你感觉怎么样。"
```

**第四步：跟进——长客会的核心**

长客会的本质：**你跟进的是客户的健康结果，不是他的钱包。**

```
跟进节奏：
├─ 第3天：问候一下，"开始吃了吗？有没有什么感觉？"
├─ 第7天：简单回访，"怎么样？睡眠有好一点吗？"
├─ 第14天：正式回访 + 调整方案/加单
├─ 第30天：复查 + 进入下一个月长客会
└─ 持续：节气的健康提醒、季节调理建议、健康科普推送
```

**客户说"太贵了"怎么接：**

```
"姐，我理解你。但你算算账——
一包烟20块，一天一包，一个月600块，伤肺。
一盒B族维生素180块，能吃两个月，一个月才90块，
你少抽几天烟，身体变好了，哪个划算？"

或者：
"你想想，你去医院挂个号多少钱？
做一次体检多少钱？
真等出问题再治，花的钱是这个的100倍。"
```

#### 3.1.4 常见客户类型与应对策略

| 客户类型 | 特征 | 切入方式 | 跟进重点 |
|---------|------|---------|---------|
| **亚健康型** | 累、睡不好、精力差 | 从疲劳切入→隐性饥饿概念 | 2周见效果→续长客 |
| **慢病型** | 三高、糖尿病、脂肪肝 | 从体检报告切入→营养干预 | 长期调理+定期复查 |
| **宝妈型** | 关注孩子健康、全家饮食 | 从孩子抵抗力切入→家庭营养 | 全家方案+转介绍妈妈群 |
| **中老年型** | 各种小毛病、怕生病 | 从养生切入→预防大于治疗 | 稳定长客+子女转介绍 |
| **年轻型** | 熬夜、外卖、脱发 | 从颜值/精力切入→隐形饥饿 | 单品切入→逐步升级 |

### 基本功②：长客会裂变百万年薪

#### 3.2.1 核心认知

> **你帮一个人健康，赚一份收入。**
> **你帮一群人学会帮别人健康，赚管道收入。**

安利奖金制度的魅力不在"卖产品赚差价"，而在**市场计划的裂变效应**。

#### 3.2.2 百万年薪的底层逻辑——用一张图讲清楚

```
你的客户 → 效果好 → 转介绍 → 新客户
                                ↓
                          有人想了解这个事业
                                ↓
                          你带他 → 他学会营养+销售
                                ↓
                          他也开始服务客户、发展团队
                                ↓
                        市场倍增 → 管道收入 → 百万年薪
```

**关键认知：** 百万年薪不是靠你一个人卖货卖出来的，而是靠**市场裂变**——你培养的人也在培养人，你的收入来自整个市场的总业绩。

#### 3.2.3 安利奖金制度的简易解读（给伙伴讲的版本）

**不需要讲复杂公式，用三句话说清楚：**

```
第一句：安利不是直销，是"消费商"
    → 你换个品牌用，省下来的钱就是赚的
    → 你觉得好分享给别人，别人买了你有报酬

第二句：你努力一阵子，收获一辈子
    → 当你做到一定级别，你的市场持续产生业绩
    → 你每个月都有收入，哪怕这个月没有新开发

第三句：你帮人成功，你更成功
    → 你的收入取决于你帮助了多少人做到他们的目标
    → 这是"助人自助"的制度设计
```

**更深一步（当伙伴有兴趣时）：**

```
安利收入有四个阶段：

阶段① 消费者阶段（0-1000/月）
    └─ 自己用产品，分享给几个朋友

阶段② 经销商阶段（3000-2万/月）
    └─ 有了稳定客户群，开始带1-3个伙伴

阶段③ 领导人阶段（5万-10万/月）
    └─ 市场有几十人，你主要做赋能和带动

阶段④ 皇冠大使阶段（50万+/月）
    └─ 市场几千人，管道收入稳定增长
```

> **核心话术：** "你现在看到我做这个，不是说马上能做到多高。但你想想——如果这条路走得通，未来3-5年你想过什么样的生活？"

#### 3.2.4 如何找到想合作的伙伴

**不是每个人都适合——你需要辨认：**

| 特征 | 适合做客户（长客会） | 适合做伙伴（裂变） |
|------|-------------------|------------------|
| 对健康的关注 | 很在意自己健康 | 在意健康 + 也想帮别人 |
| 经济状况 | 有消费能力，比价格 | 有赚钱需求或副业想法 |
| 性格 | 配合型 | 主动型、有影响力 |
| 时间 | 只需要被服务 | 愿意投入时间学习 |
| 社交圈 | 窄 | 宽或在拓展 |

**从哪里找伙伴：**

1. **你的客户转介绍** — 客户效果好，问他"你身边有没有跟你一样有健康困扰的朋友？"
2. **短视频私信** — 有人问"怎么做的？" → 这就是信号
3. **朋友圈/社群** — 持续输出你的专业内容，想改变的人会主动靠过来
4. **线下社交** — 朋友聚会、家长群、兴趣群，聊到副业时自然带出

#### 3.2.5 跟潜在伙伴的四步沟通法

**第一步：建立信任（不要上来就讲事业）**

```
"你先用产品感受一下，你觉得好再了解。"
"你先看看我每天发的，如果你也觉得这些东西有价值，我们再聊。"
```

**时间：** 1周到1个月不等。让他看到你的专业和结果。

**第二步：抛钩子（当他主动问"你怎么做的"时）**

```
"其实很简单，我现在主要做三件事——
每天花15分钟学习健康知识，存到我的知识库；
每天拍一条短视频发到视频号；
每周跟团队复盘一次。
有系统带着，不复杂。"
```

**第三步：讲市场计划（不要半小时，只要5分钟）**

```
"安利怎么赚钱？我简单说——
第一，你换个品牌用，省下来的钱。
第二，你分享给朋友，他们有消费你有报酬。
第三，你教别人也这么做，你的市场在变大。
具体数字，我们有完整培训，你进来系统会带你走一遍。"
```

**第四步：给进入路径（低门槛、清晰）**

```
"你先做三件事：
1. 办一张安利卡（自己用产品，感受品质）
2. 进我们的群，每天跟着学15分钟
3. 先服务3个客户，把基本功练熟

后面的事，系统会带你走。"
```

#### 3.2.6 裂变的核心——可复制的系统

**为什么伙伴跟着你能做起来？因为你有系统。**

| 你的系统 | 伙伴得到什么 |
|---------|------------|
| 第二大脑知识库 | 营养知识不用从头学，直接调卡片 |
| 脚本库 | 不知道怎么拍？模板直接套 |
| 长客会SOP | 不知道怎么跟进？每一步都写好了 |
| 培训体系 | 每周在线培训 + 一对一辅导 |

**这就是你的差异化——不是在拉人，是在赋能人。**

## 四、四个工作流（每日循环 + 每周节奏）

每天四件事——三件个人修炼，一件带动团队。

```
┌───────────────────────────────────────────────┐
│          每日核心循环 + 每周节奏                  │
│                                                 │
│  ① 每日沉淀（15-30分钟） —— 知识内化             │
│      ↓                                         │
│  ② 自媒体输出（30-60分钟）—— 价值外化            │
│      ↓                                         │
│  ③ 复盘迭代（5-15分钟）  —— 校准方向             │
│      ↓                                         │
│  ─── 日循环以上，周循环以下 ───                  │
│      ↓                                         │
│  ④ 业绩突破（每周节奏）  —— 带部门冲业绩          │

└───────────────────────────────────────────────┘
```

> **①②③是每天的个人修炼，④是每周的团队领导——两手都要抓。**

### 工作流①：每日沉淀 — 知识内化

**目标：** 让认知每天进步一点点
**时间：** 每天 15-30 分钟
**工具：** Obsidian（或其他本地知识库工具）

#### 具体做什么

**选项 A：写一张洞见卡（2-5 分钟）**

今天有什么让你"叮"一下的？写下来。

```
示例：
---
卡片ID: DJ-创业-005
来源: 今天跟客户聊天
---
客户说："你们这个好是好，但我怕坚持不下来。"
我的回答："不是你坚持不了，是你还没看到变化。
先试两周，看到变化了，你自然就坚持了。"
金句：不是坚持难，是看不到反馈的坚持才难。
```

**选项 B：写一张知识卡片（15-20 分钟）**

一个值得深挖的知识点，用 4K 框架写完整。

**选项 C：整理素材入库（5-10 分钟）**

- 收藏的文章 → 提炼 3 个要点 → 存对应板块
- 飞书的录音笔记 → 提炼金句
- 今天跟客户聊的关键信息 → 写一条洞见卡

#### 检验标准

> 今天有没有一个认知，是昨天的你没有的？
> 哪怕只是一句话。

#### 持续的力量

```
第1天 → 第一张洞见卡（很慢）
第7天 → 有了7个知识点
第30天 → 30张卡，开始互相连接
第90天 → 你已经成为某个领域的"小专家"
第365天 → 你的知识库就是一座宝藏
```

### 工作流②：自媒体输出 — 价值外化

**目标：** 让你的认知价值被更多人看见
**时间：** 每天 30-60 分钟
**核心阵地：** 视频号（同步抖音/小红书）
**频率：** 每周至少 3-5 条（最好日更）

#### 为什么选视频号？

| 平台 | 优势 | 适合安利的原因 |
|------|------|-------------|
| 视频号 | 微信生态、熟人裂变、信任基础好 | 安利本质是信任生意 |
| 抖音 | 流量大、算法精准 | 适合引流到私域 |
| 小红书 | 女性用户多、专业知识认可度高 | 营养健康内容天然匹配 |

**策略：** 以视频号为核心，内容同步发到其他平台。

#### 一条短视频的完整制作流程

**Step 1：选题（5 分钟）**

从知识库里找——今天沉淀了什么？那个点能不能做成视频？

```
选题来源：
├─ 洞见卡 → 一句话金句 → 做成开头钩子
├─ 知识卡片 → 四个部分 → 拆成4条视频
├─ 客户问题 → "今天有人问我……" → 有共鸣
└─ 热点话题 → 结合你的专业角度切入
```

**Step 2：写脚本（10-15 分钟）**

遵循**嘴替写作法**——口语化、有节奏、有缺口。

```
脚本结构：
├─ 开头3秒钩子（九大人性钩子之一）
│  └─ 赚钱、恐惧、好奇、反差、共鸣……
├─ 正文讲故事/举例子（不要讲道理）
├─ 结尾给价值 + 引导互动
└─ 全程：不要教学感、不要书面语、留缺口

嘴替铁律：
├─ 写完了读出声 —— 读不顺的改成顺的
├─ 删掉"我们来……""首先……其次……" —— 删掉教学感
├─ 每段留个缺口 ——"你有没有这种经历？"
└─ 加一粒沙子 —— 一个真实细节（具体时间/地点/人名/数字）
```

**九大人性钩子（开头用）：**

| 钩子类型 | 示例开头 |
|---------|---------|
| 🔥 **赚钱** | "做安利三个月，收入超过主业是什么体验？" |
| 😱 **恐惧** | "你的脂肪肝，可能在十年前就埋下隐患了。" |
| 🤔 **好奇** | "做安利的人那么多，为什么99%的人做不起来？" |
| 🔄 **反差** | "我985毕业，最后选择了做安利。" |
| 😡 **愤怒** | "别再被骗了！某某方法根本没用。" |
| 💬 **共鸣** | "你是不是也觉得，身体越来越不如从前了？" |
| 🏆 **成就** | "一个月帮10个家庭改善了健康，我做了什么？" |
| ❤️ **情感** | "妈妈的身体，别等到出问题才重视。" |
| 🤯 **认知颠覆** | "你每天吃的饭，可能正在让你变胖。" |

**Step 3：拍摄（10-15 分钟）**

```
设备：手机 + 支架 + 自然光（不需要专业设备）
时间：选光线好的时候（上午/下午自然光最好）
心态：不要追求完美——"像跟朋友聊天一样"
技巧：
├─ 看镜头 = 看着朋友的眼睛
├─ 不要背稿 → 记关键词 + 自由发挥
├─ 出错没关系 → 剪掉就好
└─ 一条 1-2 分钟就够了
```

**Step 4：发布（5 分钟）**

```
标题：起一个有吸引力的标题（包含关键词）
封面：干净整洁、突出主题
话题标签：#安利 #AI新打法 #营养健康 #副业
发布时间：建议晚上 7-10 点（大家刷手机的时间）
```

#### 内容日历（建议每周混搭）

| 星期 | 内容方向 | 选题示例 |
|------|---------|---------|
| 周一 | 营养科普 | "有一种累，叫B族不够" |
| 周二 | 创业认知 | "做安利为什么要有自己的系统？" |
| 周三 | 客户案例 | "我帮李姐调理了三个月，她的变化……" |
| 周四 | AI工具 | "我是怎么用AI写脚本的？" |
| 周五 | 观点输出 | "你为什么做不起来？不是能力问题。" |
| 周六 | 生活/随感 | "今天跟伙伴开会的三个收获" |
| 周日 | 复盘/干货汇总 | "这周最受关注的3条内容" |

> **核心心法：** 哪怕今天只发了一条 30 秒的视频，也比"等我想好再发"强 100 倍。持续 > 完美。

#### 如何应对"没人看"的阶段

```
第1个月：0-50播放量
    → 正常。系统在测试你的内容标签。继续发。

第2个月：50-500播放量
    → 找到1-2条播放量高的，分析为什么——这个方向对了。

第3个月：出现1000+甚至破万
    → 这是拐点。重复那个方向的选题。

核心：前3个月不追求数据，只追求"每周至少3条不断更"。
```

## 五、财富的本质

### 5.1 财富公式

> **你的收入 = 你的认知信息价值 × 你影响的人数**

这两项都是可以持续增长的：

```
认知信息价值 —— 来自：学习 × 思考 × 实践 × 沉淀
    ↑
    └─ 读书、听课、跟高手交流、自己做事复盘
    
影响的人数 —— 来自：内容输出 × 社交裂变 × 时间积累
    ↑
    └─ 短视频、口口相传、团队复制
```

### 5.2 安利事业的两大价值创造

| 价值来源 | 你做什么 | 别人得到什么 | 你的收入来源 |
|---------|---------|------------|------------|
| **① 帮助别人健康** | 用营养专业知识解决健康问题 | 身体变好、生活质量提升 | 产品销售 × 长客会复购 |
| **② 帮助别人创造财富** | 借助安利平台，分享创业方法论 | 多一份收入、多一条人生选择 | 市场裂变 × 管道收入 |

### 5.3 普通人和高手的区别

```
普通人：关注"我怎么做才能赚更多钱？"
    ↓
    推产品、比价格、追着人成交
    ↓
    越做越累、越来越焦虑

高手：关注"我怎么能帮更多人？"
    ↓
    提升专业、输出价值、建立系统
    ↓
    钱是帮人后的自然结果
```

### 5.4 为什么说"安利是认知生意"

```
一个客户每个月在你这里消费1000元
你有100个这样的客户
→ 月收入10万
    ↓
问题来了：你怎么获得这100个客户？
    ↓
路径一：每天见10个人，全年无休
    → 体力活，天花板低
    
路径二：通过内容让10000人看到你，1%转化
    → 认知活，天花板高
    → 这就是AI新打法的逻辑
```

### 5.5 财富认知进阶

| 阶段 | 认知状态 | 收入状态 |
|------|---------|---------|
| 第一层 | 我卖货赚钱 | 不稳定、天花板低 |
| 第二层 | 我帮人解决问题 | 稳定增长 |
| 第三层 | 我帮人学会解决问题 | 倍速增长 |
| 第四层 | 我建系统让更多人帮更多人解决问题 | 管道收入、持续增长 |

**AI新打法就是帮你从第一层快速跳到第四层的工具。**

## 六、每日行动清单与时间配置

### 6.1 每日三问（睡前自检）

```

   → 往第二大脑里存了什么？
   
✅ 今天有没有输出？
   → 发了内容？还是跟客户/伙伴深度沟通了？

✅ 今天有没有复盘？
   → 对照目标，今天偏离了没有？
```
