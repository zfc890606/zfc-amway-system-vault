## 📱 贴图浅版（自动附带 · 同主题双发 · 2026-09-04）

> **触发：** 走完整公众号管线推长文草稿时，默认同步做 1 组同主题贴图浅版草稿，不再询问。用户说 **"不要贴图"** 才跳过；"先看看/先别发" = 长文 + 贴图都不推。方法论 → [[公众号贴图（小绿书）方法论]]。

### 产物规格（微信 newspic · 小绿书 3:4 横滑卡）

| 项 | 规格 |
|----|------|
| 类型 | `article_type=newspic`（小红书式 3:4 横滑卡，微信官方"贴图"） |
| 图片 | **3-5 张**，第一张 = 封面；默认本地 **xhs-note-creator 3:4 卡**（`zhangshi-medical` 医养风·免费·中文不出错）；食谱/食物类第 2-3 张可换豆包 3:4 无文字实景图 |
| 标题 | **≤32 字**（钩子式，从长文已过合规的标题裁剪，不新造医疗承诺） |
| 配文 | **≤150 字**（接口上限 1000）：1-2 句承接图意 + 引导看完整版 |
| 收尾引导 | 末张卡 + 配文引导：**"完整版已发同名公众号（搜《长文标题》）"**· 不引平台外、不违规导流 |

### 卡脚本（3-5 张默认结构）

1. **封面**：大钩子标题（≤16 字）+ 一句痛点/收获
2. **场景/痛点**：让目标人群觉得"说的就是我"
3. **干货 ①**：一个核心结论大字 + 一句大白话解释
4. **干货 ②**（可选）：第 2 个要点 / 清单（营养类可用食谱/对比图）
5. **CTA 末卡**：想看完整版 → 同名公众号搜长文标题

> 医疗合规与长文同一套：不写功效/绝对化/承诺词，用生活化表达（见 [[公众号写作规则系统]]「十、合规红线」）。

### 执行命令（每篇自动执行）

```bash
# ① 每张卡一个 markdown → 渲染 3:4 PNG（1080×1440·zhangshi-medical）
python3 ~/.claude/skills/xhs-note-creator/scripts/render_xhs.py tt-01.md -t zhangshi-medical -m auto-fit -w 1080 -h 1440 --dpr 2 -o /tmp/wx-tietu/
# ② 推贴图草稿（第一张=封面；配文引导看长文）
wewrite image-post -t "贴图标题（≤32字）" -c "配文（≤150字）" /tmp/wx-tietu/tt-01.png /tmp/wx-tietu/tt-02.png /tmp/wx-tietu/tt-03.png ...
```

### 交付提醒
长文 + 贴图都推完后：**提醒张医生：mp.weixin.qq.com → 草稿箱里有两件（长文草稿 + 贴图草稿），分别检查后再发布**。

## 常见问题

### Q：图片怎么办？
需要手动上传到公众号素材库。API 上传只传文字内容，封面图和文中图片需到后台补充。

### Q：WeWrite 是什么？
WeWrite 是 Claude Code 的一套公众号写作 skill，包含写作人格、审稿评分、历史封存等完整流程。运行管线时会自动调用。

### Q：格式乱了怎么办？
检查 Markdown 文件是否使用了模板中规定的格式（H1/H2/引用/加粗/列表）。如果部分样式丢失，在公众号编辑器中手动调整。

### Q：如何更新已发布的文章？
公众号已发布文章无法修改正文（只能改最多 20 字）。需要更新内容的话：
1. 在 Obsidian 中修改文章
2. 重新发布为**新文章**
3. 在新文章中注明更新说明

### Q：没有 API 配置怎么办？
如果没有配置 AppID/AppSecret，管线会完成 Phase 1+2 后，将 HTML 复制到剪贴板，指导你手动粘贴到公众号后台。
