# 🎨 小红书配图工作流（张医生版）

> **一句话：** 小红书图文 = 一组图（封面 + 内页 + 点缀），不是一张图。**封面用排版卡（点击），内页用要点卡（收藏），照片感用豆包点缀（信任），实拍是底牌（这个人）。**
> **工具分工：** `xhs-note-creator`（免费·排版文字卡）+ 豆包（按量·AI照片）+ 手机实拍（免费·信任）。
> **配套：** 战略见 [[小红书商业定位]]；运营见 [[小红书方法规则]]；本卡只定"图怎么做"。

---

## 一、小红书图文图片构成

每条图文笔记 = **1 张封面 + 2~9 张内页**（滑动式）：

| 图 | 作用 | 做不好会怎样 |
|----|------|------------|
| **封面**（第1张） | **决定点不点** → 点击率 → 进不进流量池 | 封面丑 = 内容再好没人点 |
| **内页**（第2~9张） | **决定留不留** → 收藏/关注 | 内页乱 = 收藏率低 |
| **点缀**（可选） | **决定像不像"人"** → 信任感 | 全AI图 = 没真实感 |

> **关键认知：小红书图文 90% 是"文字卡片"，不是照片。** 干货/避坑/清单类，观众要的是"信息排得舒服"。

## 三、6 个优化点（对爆款逻辑的落地）

### ① 封面文字 = 情绪钩子，不写"主题名"
- ❌ 平铺词：「营养素避坑」
- ✅ 爆款词根式：「别再交了」「智商税？」「3个真相」「都看错了」（≤5字，情绪化）
- 主题名交给正文标题（15-20字管搜索）

### ② 封面要"视觉主体"
方法规则封面 4 要素含「主体突出（主体偏右1/3）」。纯字卡辨识度不够。
**封面 = 大字钩子 + 一个主体**：实拍/豆包图作底 → 右侧大字 → 左侧留白。

### ③ 内页 7:3 混图，刷着不累
- 7 成 要点卡（信息） + 3 成 实拍/豆包图（喘息+真实感）

### ④ 图片文字埋搜索词（OCR · 第5维SEO）
小红书会识别图片文字参与搜索。**内页卡小标题用长尾词**（"药店鱼油 vs 200多差在哪"）→ 图片文字免费帮排名。文字卡独有优势，豆包图做不到。

### ⑤ AI 图 3 条合规线
- 不出现品牌 logo 混淆（别生成像"纽崔莱/安利"的包装）
- 不出现白大褂医生形象（与"假扮在职医生"红线同源）
- 不出现功效暗示（"吃了年轻10岁"类文字/对比）
- 2026 平台要求 AI 内容标注 → AI 图控制占比，避免信任反噬

### ⑥ 封面模板锁死 = 个人 IP
封面固定 1-2 套模板（字体/配色/大字位置固定），刷到就认出你。**已锁定：xhs-note-creator「zhangshi-medical 张医生医养风」主题**。

## 五、完整配图流程

```
封面 = 实拍/豆包主体(右1/3) + 排版大字情绪钩子(≤5字) + 统一模板(zhangshi-medical)
内页 = 7成要点卡(埋长尾词) + 3成实拍/豆包图
点缀 = 豆包图最多2张(合规+标注) · 实拍是信任底牌
SEO = 图片文字也埋词（标题/首段/标签/自评 之外的第5维）
```

1. **封面默认锁 `zhangshi-medical`** —— 你的 IP 识别色，刷到就认出你；
2. **允许偶尔换主题**（<20% 比例）：身份故事 → `retro`（怀旧感）、AI 向内容 → `terminal`、生活方式 → `botanical`；
3. **禁止每篇换皮肤** —— 封面不统一 = 没有 IP 识别；
4. 换主题只换"排版氛围"，**大字情绪钩子 + 统一构图逻辑不变**。
