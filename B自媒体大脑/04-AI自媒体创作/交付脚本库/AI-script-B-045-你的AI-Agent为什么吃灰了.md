# AI-script-B-045 · 你装的AI Agent，是不是也在吃灰？

【录屏：小窗人像，字幕"你装的AI Agent，是不是也在吃灰？"】
OpenClaw（小龙虾）去年火遍全网，现在热度跌到高峰期的 3%——为什么？因为"装完即吃灰"。

【录屏：展示"龙虾悖论"图示/文字】
核心是个悖论：想让它干的越多，给的权限越大；权限越大，风险越高。调研显示八成的年轻人担心隐私，三千多个插件里一成多带恶意代码。

【录屏：展示"三个错位"清单】
大多数人的 Agent 吃灰，是三个错位：一是期望错位——以为"交给 AI 就完事"，实际要盯着它；二是成本错位——7×24 小时跑，Token 账单吓人；三是权限错位——一兴奋就交出全部权限。

【录屏：小窗放大，Recap + 预告】
记住：Agent 不是"替你干"，是"陪你干"。想清楚有没有重复性工作，再装。下集我教你"AI 整理聊天记录成档案表"，关注了才能刷到。
