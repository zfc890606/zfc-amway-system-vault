### 🏆 已验证爆款公式（001-018 全库 15 条共同规律 · v1.36 写稿默认照此走）

**一句话公式：** `身份独占选题 + 第一人称（转变叙事优先；⚠️ 健康观念线：从医经历只当人生故事·铁律18）+ 认知递进或分装式并列 + 强比喻／数字模型传播原子 + 多重权威背书 + 零产品 + 自白型互动钩子`

| 要素   | 爆款做法                                             | 验证                                     |
| ---- | ------------------------------------------------ | -------------------------------------- |
| 选题   | 用户正在搜的问题 / 得罪人拆解具体商品                             | "是不是智商税"=全网最大搜索词；燕窝/阿胶/虫草/鹿茸具体靶子       |
| 开头3秒 | 身份+惊人事实双钩（场景嵌入，不硬说"我是医生"）                        | 059："考执医那年，几千页教材营养学不到20页"              |
| 身份用法 | 转变叙事 > 权威背书（"我以前也信过"）｜⚠️ 无认证期：从医经历=人生故事≠专业背书（见④） | 006："我也曾经信营养素没用，研究了三年想通"               |

| 权威背书 | 每个核心观点≥1个官方出处                                    | 070背书×5 → 转发率11.75%全库第一                |

| 传播原子 | ≥2个，每个有明确转发对象                                    | 059有3个→转发26,716；036有0个→转发6             |

| **数字模型**（v1.36 新增） | 把抽象观念做成"可复述的分数/百分比" | 122「健康100分：遗传15／环境8／医疗8／生活方式60」→ **转发率10.72%全库第二 · 裂变系数1.74全库第一** |
| **拆情绪 > 拆商品**（v1.36 新增） | 拆"反感／逃跑"这种情绪，不拆具体商品 | 084→转发8.18%；107→24,887播放 · 均观看超89.84%同类（人群更宽、完播更高） |
| **朋友圈之王结构**（v1.36 新增） | 文化母题 × 健康提醒 × **转发对象写进文案** | 116「上医治未病」→ **朋友圈占比11.18%全库第一** |

**三条新规律（v1.36 · 全库 15 条数据验证）：**

- **规律A · 分装式并列 > 单一递进** —— 同题材同人群，070 分装式转发率 **11.75%** vs 107 叙事流 **4.84%**（差近一倍）。叙事流吃"均观看"，分装式吃"转发率"。**最优解：开头用画面感场景，结构用分装式并列，两全。**
- **规律B · 低完播 × 高转化** —— 059 / 107 / 122 的完播率都被平台标"低"，但全是爆款。视频号算法对"分享 + 关注"的权重远大于完播率。**认知类不追完播绝对分，盯转发率 + 涨粉转化。**
- **规律C · 切口决定侧重** —— 同系列不同切口，指标天差地别。"学／开"（知识·制度）＝**涨粉型**（059→涨粉5,671）；"治／看／教"（场景·机制）＝**转发型**（082→转发率9.08%）。**预测涨粉要按切口判断，不要按系列判断**（082 曾预测涨粉 3,000+，实为 225）。

> ⚠️ **「高配非爆款」警告（079 / 124）**：内容指标（均观看／完播／3s率）全部顶级，播放仍然垫底——**说明脚本能力不是瓶颈，选题才是**。**处置：保留脚本、换选题重拍，不要改写法。**

# 📋 写稿流程·八步（从选题到交付——写每条脚本照此走）

> **总原则：先想清楚"这条给谁看、要什么数据"，再动笔。** 下面 8 步把写稿拆到底，每步标注了要看哪个小节。卡在哪一步，翻对应小节。
> **爆款思维贯穿：③ 写前设计 7 要素 → ⑦ 写后复核 6 要素（涨粉复核），双保险。**

```
🚧 0 无认证期选题落点闸门（强制·一票否决·不过不进①·细则见下方）───
   判定：选题核心靶子属于哪边？
     ✅ 可写：行业认知 / 职业定位 / 个人经历 / 创业打法·AI系统 / 价值观
     ❌ 不写：营养素功效 / 缺了会得病 / 慢病调理·疾病机理 / 体检指标解读 / 点对点调理方案
   落点在 ❌ → 直接换题，不进入写稿
   （白名单对照：[[B自媒体大脑/01-视频号创作/创作脚本规则/视频号风控总表|风控总表 · 四、无认证期发布风控总表]]）

① 定选题 ─────────────────────────────────────────
   第1步 选来源（4入口）：
     · 痛点排行榜 → TOP痛点（大众在搜的，优先；题源方法见二十二、评论区选题挖掘法）
     · AI选题库 → AI×安利主线
     · 海外信息差库 → 独家稀缺（详细见第3步）
     · 你直接指定主题
   第2步 对方向（线别）：
     · 营养线（留人）还是创业线（涨粉）？内容类型是什么？
     · 按配比查：这条该不该现在做？同类型是否扎堆？
   第3步 海外信息差·唯一信息（走入口③时）：
     · 扫海外源 → 让AI翻译+口语化提炼 → 入库 → 选1条
     · 检查：国内没人讲过（唯一）？切国内痛点？有原始出处（文献可查）？
     · 出口：海外唯一信息 + 反常识观点开头（②）→ 天然稀缺组合
   第4步 定元素 → 变换词根 → 定选题（v1.29·必走，细则见 KC-视频-005「爆款词根库」）：
     · 定元素：从下面 9 个「已验证爆款元素」里选 1 个（元素由爆款视频验证·固定不换）
     · 变换词根：基于这个元素变换词根（说法）→ 定选题/定标题（一个元素可换多个词根 = 多个选题候选）
     · 出候选：2-3 个爆款候选（选题生成器，不等灵感），每个先想好「转发对象」（转给谁）再进决策卡
     · 已验证爆款元素（9个·固定）：猎奇·行业揭秘 / 反差+最差·得罪人拆解 / 争议·全民疑问 / 争议·第三视角 / 成本·价格对比 / 猎奇·机制揭秘 / 人群·拆情绪 / 反差+怀旧·个人叙事 / 拷问·灵魂拷问
     · 词根不背固定清单：同元素换新说法；同一说法用≥5次显疲劳就换
       （例·猎奇·行业揭秘：基础题「医生为什么不学营养」已验证 → 变换词根 →「医院为什么不设营养科」→ 再变 →「体检报告为什么不查这项」）
     · 出口：2-3个候选 → 第5步决策卡筛出最高分 1 个
   第5步 选题决策卡（定死规则·必过，细则见「🎯 选题决策卡」）：
     第0关 变现定位对位（v1.32新增·一票否决2问，不过 = 换方向）：
       ① 为谁做？（人群付费能力）→ 吸引来的人付得起你的客单价吗？讨好底层 = 爆了也变现弱
       ② 服务定位吗？（定位决定内容）→ 从高变现定位长出来的，还是随手蹭的流量？
     第一关 一票否决4问（任一不过 = 换题）：
       ① 用户在问吗？（答案焦虑）→ 标题是用户心里的问题，不是你的感慨
       ② 只有你能讲吗？（删我测试）→ 换个博主这条还成立吗？
       ③ 有人搜吗？（搜索词验证）→ 微信搜一搜/小红书有海量同类问题吗？
       ④ 题目把答案说完了吗？（结论前置检测·v1.25新增）→ 说完=观众不用点进来=换
     第二关 天花板打分8项（每项1分，满分8）：
       人群宽度 / 争议性·对立冲突 / 具体靶子 / 转发对象 / 朋友圈友好度 / 权威背书 / 传播原子 / 爆点叠加·感人共鸣
       判定：≥7 值得拍 → 5-6 改造后拍 → ≤4 换题
   第6步 定测试变量：固定=涨粉（唯一变量·定死，不再询问），自动做预测
   卡住看：🎯 选题决策卡 + KC-视频-005爆款词根库 + KC-视频-006选题变现双层门 + 创作本质（〇）+ 海外信息差选题法（〇）

② 开场（v1.31定死：内容定句式·句式必轮换）────────────────────
   第一步 词根定钩子：这条选题属于哪个已验证元素 → 查「🎯 开头句式选择规则」映射表选句式
     （猎奇·行业揭秘→身份得罪人 / 价格对比→设问悬念 / 拆情绪→场景代入 / 个人叙事→反差直给…）
   第二步 数据定微调：要完播→结果前置 / 要互动→痛点问句 / 要转发→得罪人
   第三步 轮换检查（强制）：上一条同句式？连续≥2条同句式→换；去掉前两句受影响吗？→重写
   原则不变：重点前置 + 身份独占 + "XX不是XX"反常识（见五·反常识观点开头）
   ⚠️ "我告诉你"只是句式之一，不是默认开头
   卡住看：🎯 开头句式选择规则（五）· 开头钩子公式库（五）

③ 爆款设计（★动笔前先把 7 要素定下来 · 与 ⑦「涨粉复核6要素」一一对应）────
   ① 涨粉点（身份独占·删我测试）：只有我能讲的视角是啥？删掉"我"还剩什么？
   ② 转发点（转发对象）：想让观众转给谁？每个传播原子都想好"转给谁"
   ③ 传播原子 ≥2 个：至少 2 个能一句话转述的原子（比喻/数据/金句）
   ④ 人设弧线（成长弧线）：有"暴露→补位"的成长弧线吗？
   ⑤ 零产品：产品名/推销暗示 → 删（零产品铁律）
   ⑥ 下一集测试（价值锚定）：观众看完会期待你的下一条吗？
   ⑦ 个人味道（v1.26新增·强制）：从 [[B自媒体大脑/01-视频号创作/创作脚本规则/张医生个人味道库|张医生个人味道库]] 选 1-2个身份故事 + 1个价值观锚点 + 至少1个说话指纹——按线别取（营养线取学医组 / 创业线取转型组+农村组），删我测试延伸为"删掉张医生要素还剩什么"
   ⚠️ 身份安全线（v1.34·铁律18）：亮身份 = 亮"人生故事"，不是亮"专业背书"
   卡住看：八、涨粉复核6要素 + 八、个人味道嵌入 + [[B自媒体大脑/01-视频号创作/创作脚本规则/张医生个人味道库|张医生个人味道库]]

④ 选内容类型 → 套模板 ─────────────────────────────
   ⚠️ v1.21 定死：一律走 张医生式笃定（扎一刀→再扎一刀→继续扎→"这点小事不难"）+ 推进信息密度。
   直接亮身份、直接给结果，不绕弯。⚠️ 亮身份=亮人生故事（"我在医院干过""我为什么出来做这个"），不是亮专业背书（"以我的经验你应该…"）——无认证期安全线，详见表格「身份用法」

⑤ 写正文（默认：张医生式笃定 + 推进信息密度 · v1.21）────────
   · 笃定感：扎一刀→再扎一刀→继续扎→"这点小事不难"（张医生式·默认）
   · 自信感：笃定结论，不端不装（支柱②）
   · 信息密度：信息冲击→强比喻→权威数据→金句，每15秒一个新认知（059/070验证）
   · 真实感：读出声、删"第一第二"、留缺口、加一粒沙子（十二）
   · 嘴替感（仅辅助·已降级）：需要拉近距离时再用（支柱①）
   同时嵌入：洞见卡金句 + 权威背书（铁律13）+ 文献价值锚点（铁律14）+ 传播原子≥2个 + **个人味道（身份故事+价值观锚点+说话指纹·v1.26强制·见 [[B自媒体大脑/01-视频号创作/创作脚本规则/张医生个人味道库|张医生个人味道库]]）**
   海外信息差专属三层结构（走海外选题时）：
     第1层 反常识观点开头（已定死，见②）
     第2层 甩一手信息：原始出处/论文/数据 **· 必须"点名"**（讲出机构/期刊/报告名：世界卫生组织 / 中国营养学会 / 美国 CDC / 《柳叶刀》 / 《健康中国行动》…；❌"有研究显示""数据表明"不点名=等于没出处）（信息差·唯一）
     第3层 降维打击：为什么 + 临床真实代价 + 算账法（认知深+身份独+表达狠）
     ＋每个核心观点挂一个文献锚点（铁律14·强制）——"数据+出处"才是深度
   ⚠️ 正文文献嵌入（强制·v1.35·2026-09-11）：写正文时就**必须把 ≥2 条权威文献"嵌进正文"**（不是只列文末清单），且**"国外权威 + 国内权威"并存**——① **国外权威 ≥1**：海外一手数据/论文/官方报告（CDC/WHO/Lancet/NIH/NEJM…），把"数字+出处"直接写进口播；② **国内权威 ≥1**：国内可查权威出处（国家卫健委/中国营养学会/中华医学会指南/中国疾控中心/权威期刊…）；③ 动笔前**主动搜 1 条最新一手文献**，核验后插入（先搜后写，不搬旧料）。**两条具体配谁 = 按内容你自己配好**。出处口播可口语化但**必须"点名"**——讲出机构/期刊/报告名（"世界卫生组织的数据""中国营养学会《中国居民膳食指南》""美国 CDC 的数据""《柳叶刀》子刊2022年发的…"），❌"有研究显示""数据表明"（不点名=等于没出处）；完整出处+可点击链接落到文末「权威文献锚点」。搜不到可查证的 → 换，宁缺毋滥，不编。
```

### 🚧 0号闸门·细则：无认证期「健康观念科普」安全边界（2026-08-21 锁死·账号方向已锁定）

> （2026-08-21 限流教训：113/102/103 被点，全是因为把「疾病 / 症状 / 指标 / 效果」当论点主体，不是"观念"本身。）

**🟢 可写（观念层·安全区）**
- 健康观念：体检正常 ≠ 健康、健康是自己的事、生活方式决定健康大头
- 营养观念：营养素 ≠ 保健品的认知纠偏（只讲观念，不展开"缺了会得病"）
- 生活方式观念：怎么吃 / 怎么睡 / 怎么动 / 怎么管情绪（普适说法，不点对点）
- 行业认知：智商税争议、为什么一提营养素人跑
- 医生身份当人生故事（从医经历 → 讲到"为什么离开医院"打住）

**🔴 禁写（一票否决 · 出现即重写）**
1. **疾病名 / 症状 / 指标**：血糖 血压 血脂 脂肪肝 糖尿病 心梗 胆固醇 慢性病 炎症 心血管…标题/正文/简介/标签/朋友圈全算，**当论据也不行**（113 教训：血脂血糖只是"论据"也被点）
2. **营养功效 / 效果故事**："补了维生素D，睡得着了、爬楼不喘了""指标变了、精神好了"——个人案例带健康成果 = 变健康科普
3. **点对点调理**："我帮你 / 给你调理XX病·指标""你这个情况应该…"
4. **医疗身份背书**："我在手术台见过…所以你要…""以我从医十年的经验…"
5. **健康焦虑 + 产品**："你的细胞在饿""悄悄毁掉你的健康" + 推营养素（"隐性饥饿"等制造焦虑概念词慎用）
6. **医疗隐喻**："给健康开处方 / 一张方子 / 把病调回去 / 营养修复慢病"

**✅ 安全写法（必须同时满足）**
- 讲**观念**，数据只当**论据**（保守表述 + 权威出处 + 结尾口播+简介双免责）
- 讲**选择**，用对比（两种健康观），不评价个体
- 讲**故事**，用人生经历（不涉疾病 / 不涉客户健康成果）
- 结尾**纯认知互动**（"你怎么看？评论区聊聊"），不引导问诊 / 不谈病情

## 〇、创作本质：创造稀缺 × 放大情绪

> **短视频文案核心就两件事：创造稀缺（观点别人没说过）+ 放大情绪（把情绪推到顶点）。**
> 内容基本定律（v1.25）：一条内容要么引发冲突，要么引发思考——打动的不是猎奇心，是他心里那个还没得到答案的问题。

### 创造稀缺

| 维度 | 做法 | ❌ 平庸 | ✅ 稀缺 |
|------|------|--------|---------|
| **信息差** | 讲别人不知道的事实 | "吃蛋白粉对身体好" | "你每天需要73g蛋白质，早餐那点才10g——天天在缺" |
| **视角差** | 用观众没想过的角度 | "被拒绝很正常" | "你怕的不是被拒绝，是那个被拒绝之后的自己" |
| **体验差** | 讲你做到的结果 | "坚持就有结果" | "我签了50个长客会，续约率80%——做对了三件事" |
| **冲突差** | 说别人不敢说的 | "安利容易被误解" | "90%的人做安利搞反了顺序——先买产品再找客户" |
| **表达差** | 同样道理说得更狠更准 | "被拒绝要调整心态" | "手机拿起来又放下。编辑好的消息看了又看。最后锁屏。" |

**核心技法·算账法（让他自己说服自己）**：① 抛公式（"你每天需要73g蛋白质"）→ ② 代入算（"早餐10g + 午餐15-20g + 晚餐20g = 45-50g"）→ ③ 揭缺口（"离73g差一大截，一年365天都在缺"）。结论是他自己算出来的，他没法反驳——缺口本身就是焦虑制造。

**写每句都问：这句话观众能在别处听到吗？能 → 删了重写；不能 → 这就是你的稀缺性。**

### 海外信息差 — 别人偷不走的稀缺

> 你人在海外，能看到国内创作者看不到的一手信息。把海外前沿用中文口语化转述 = 选题本身稀缺。

| 领域 | 海外来源 | 变成中文内容 |
|------|---------|-------------|
| 🥗 营养线 | PubMed / WHO / FDA / NEJM / 梅奥 / 哈佛营养系 | "美国刚发的10万人追踪20年研究——" |
| 🚀 创业线 | 硅谷动态 / YouTube创业者 / 海外播客 | "我在海外看到的一种新打法——" |
| 🤖 AI线 | OpenAI/Google / ArXiv / 海外AI工具 | "国外刚出的AI工具，国内还没人讲——" |

**流水线（30分钟/周）**：扫3个海外源 → 挑1-2条"国内没人讲 + 切国内痛点" → AI翻译+口语化提炼 → 入库 → 写稿用反常识观点开头。
**降维打击（第二层壁垒）**：信息降维（讲海外一手源头）× 认知降维（讲为什么/机制）× 身份降维（结合经历解读）× 表达降维（算账法）。检验：同赛道博主能1:1复制吗？能 → 不够深。
**⚠️ 边界**：海外信息 ≠ 免检——数字/结论必须溯源原始出处，过科学事实核验，不夸大，营养类加免责。

### 放大情绪

| 步骤 | 做法 | 示例 |
|------|------|------|
| ① 识别情绪 | 焦虑/委屈/愤怒/不甘？ | "你是不是特别憋屈？明明很努力了" |
| ② 具象化 | 说具体场景，不说抽象词 | "被拒绝很难受" → "手机拿起来又放下…最后锁屏" |
| ③ 推高点 | 扎心话、狠话推到顶点 | "你怕的不是被拒绝，是那个无能的自己" |
| ④ 给出口 | 给解法让情绪释放 | "真正的问题不是该不该开口，是怎么开口" |
| ⑤ 拉回来 | 结尾收住（⚠️ 禁"我帮你分析"·铁律15） | "卡在哪一步？评论区聊聊——卡住不是你的问题" |

> **口诀：先让他不舒服，再帮他舒服。**

### 反差人设

| 反差 | 做法 | 示例 |
|------|------|------|
| 身份反差 | 形象与说话方式对比 | 看着像专家，说话像隔壁老张 |
| 认知反差 | 以为说A，结果说B | "做安利最重要的是口才？——是耳朵。" |
| 经历反差 | 现在行，以前也惨 | "我团队现在50人，三年前一个客户都留不住" |
| 态度反差 | 对熟人和对原则两个态度 | "我平时好说话，但这件事寸步不让" |

**一条文案自检**：□ 观众会不会觉得"这观点我第一次听到"？□ 看完心里会不会"咯噔"一下？

## 一、核心理念

```
一条好脚本 = 创造稀缺（你的观点别人没说过）
             + 放大情绪（把观众的情绪推到顶点）
             + 反差人设（让观众猜不透你）
             + 嘴替感（替他说出心里话）
             + 自信感（不端不装，娓娓道来）
             + 情绪感（起伏变化，敢爱敢恨）
```

**为什么是"嘴替"？**
- 观众刷到你的视频，前3秒的判断标准是：**"这人说的是不是我？"**
- 你说出了他想说但说不出口的话，他就觉得你懂他
- 他觉得你懂他，才会听你继续说下去

**为什么"创造稀缺"是第一条？**
- 你说的话他在别处也能听到 → 他为什么要看你？
- 只有你能讲、你敢讲、你讲得不一样 → 他才会留下来

**为什么"放大情绪"是第二条？**
- 信息他记不住，感受他忘不了
- 先让他不舒服，再帮他不舒服——他就记住你了

| 维度 | 做法 | 错误示范 | 正确示范 |
|------|------|---------|---------|

**嘴替公式：**
> "你是不是也[具体场景]？" + "我心里知道你在想什么：" + [具象化他内心的声音]

### 支柱②：博主式自信自然 — "不端不装，娓娓道来"

| 维度 | 做法 | 错误示范 | 正确示范 |
|------|------|---------|---------|
| **算账式说服** | 用具体数字让人对号入座 | "坚持吃产品对身体好" | "你每天需要73g蛋白质，早餐那点东西才10g，天天缺" |
| **具体案例** | 讲具体的人、具体的对话 | "我们有个客户吃了以后效果不错" | "我说张姐，你脂肪肝偏高对吧？你每天早晚两勺，三个月指标肯定不一样" |
| **不端不装** | 承认自己踩过坑 | "做安利要用正确的方法" | "我以前也是，签了十几个客户，续约的不到一半" |
| **娓娓道来** | 语速适中，不赶不拖，留白 | "第一第二第三"快速罗列 | 先用故事引出问题，再给方法，给完方法再补充一句"你想想是不是这个道理" |
| **自信但不傲慢** | 笃定地说出结论，不加修饰语 | "可能这个方法会比较好" | "我告诉你，你这么搞不行。换我来教你。" |

**博主式自信公式：**
> "我跟你讲个事" / "我告诉你" + [笃定的结论] + "是不是这个道理？"

### 支柱③：姜胡说式情绪表现力 — "情绪有起伏，节奏有变化"

| 维度 | 做法 | 错误示范 | 正确示范 |
|------|------|---------|---------|
| **情绪曲线** | 一条脚本内情绪有起有伏 | 全程同一语调 | 扎心开场 → 否定认知 → 给解法 → 再扎 → 拉起来 |
| **节奏变化** | 短句和长句交替，快慢结合 | 全是平均长度的句子 | "你不是怕被拒绝。不对。你怕的是那个被拒绝之后的自己。" |
| **敢表达真实情绪** | 敢说狠话、敢表达愤怒和委屈 | "被拒绝也是成长的一部分" | "我当时就傻了。你知道吗？签完我以为完事了。" |
| **留白和停顿** | 关键句说完停一下，让观众消化 | 一口气说完不带喘 | "但今天我要跟你说一个真相——（停顿）可能会让你不舒服" |
| **真诚 > 完美** | 说得不好没关系，但要说真话 | 听起来像背稿子 | "我跟你讲……嗯……这个事情我想了很久" |

**姜胡说式情绪曲线口诀：**
> **开头扎一刀，中间揉一揉，结尾拉一把。**
> 别怕让观众不舒服，先让他不舒服，再帮他舒服。

- ✅ "朋友圈发了没人理，身边的人看到你就躲"

### 🧠 中间：结构要活

**铁律4：用"否定→打破→重建"替代平铺直叙**
- ❌ "被拒绝的时候，你可以换个角度想"
- ✅ "你以为你怕的是被拒绝？不对。你怕的是那个被拒绝之后的自己。"

**铁律5：每30秒让观众内心产生一次"嗯？"**
- 每一个小段落都要有一个认知翻转或一个具体场景
- 从头到尾都讲一个道理，观众就跑了

**铁律6：三个观点不要并列，要递进**
- ❌ "第一…第二…第三…"（并列，没推背感）
- ✅ "先说你踩的第一个坑→然后说你以为踩完了其实还有第二个→最后告诉你最狠的那个"

**铁律7：多用对话，少讲道理**
- ❌ "要跟客户建立信任关系"
- ✅ "我说张姐，你脂肪肝偏高对吧？每天早晚两勺，三个月指标肯定不一样"

**铁律8：敢说狠话**
- ❌ "可能这个方法会比较好"
- ✅ "我告诉你，你这么搞不行。错得很离谱。"

### 💥 结尾：收得住，有回响

**铁律9：结尾不要煽情，要笃定**
- ❌ "希望这条视频对你有帮助~"
- ✅ "你不是不行，你是没搞懂原理。这条说的情况你遇到过吗？评论区聊聊你的看法。"（纯认知互动·禁问诊·铁律15）

**铁律10：每条结尾的CTA不一样，不要重复同一句话**
- ✅ ②呼吁 / ③真心话每条都换新说法（不重复）；④追更钩永远是固定那一句

**铁律11：不要"所以"开头**
- ❌ "所以记住一句话"
- ✅ "先让自己成为答案，别人自然来找你"（直接说，不加引导）

### 🎯 全局

**铁律12：写完读一遍——像不像人说的话？**
- 读出声来。如果读起来不像你跟朋友聊天，删了重写。
- 检验标准：**"我朋友会这么跟我说话吗？"**

**铁律13：核心观点必须有权威背书（强制）**
- 讲营养/健康/效果，必须给核心观点配权威来源支撑（官方数据/医学指南/国家政策/专家共识）
- ❌ "有人说吃营养素对身体好"（无出处，转出去会被反驳）
- ✅ "中国疾控中心数据：十个中国人九个半钙没吃够"（有理有据）
- ✅ "中华医学会指南白纸黑字：微营养素是人体代谢'不可或缺'的，专家一致率100%"
- 目的：**让转发者"有理有据"，降低转发社交风险**——观众转发的不只是观点，是有底气的立场
- 已验证：070营养素≠保健品"权威背书×5" → 转发率11.75%全库第一

**铁律14：核心观点必须有「文献价值锚点」（强制·2026-08-05新增）**
> 深度 = 可查证。每个核心观点，最好挂一个"国外研究/权威数据"锚点——观众转发时"有理有据"，你的内容也因此有别人抄不走的深度。
> 和铁律13的分工：**铁律13管"有没有出处"（防反驳），铁律14管"深度和信息差"（防同质）**——国外一手文献/数据是价值锚点里含金量最高的。

| 锚点类型 | 例子 | 观众感受 |
|---------|------|---------|
| **国外权威数据** | "美国60%成年人在吃营养素"（CDC NHANES） | 信息差，国内没人讲 |
| **权威期刊研究** | "《柳叶刀》子刊2022：每2个学龄前儿童1个缺微量营养素" | 深度，转得起 |
| **官方概念/报告** | "隐性饥饿"是WHO/联合国粮农组织官方概念，全球超20亿人 | 权威，不怕被反驳 |
| **前沿方向** | "精准营养"，美国NIH专门立项 | 稀缺，别人跟不上 |

**铁律16：观点包装在故事里——"讲故事"比"讲道理"好一百倍（李尚龙对标·v1.30新增）**

> 来源：李尚龙混沌大学《弱传播方法》："这个时代从来不缺讲道理的人，缺的是讲故事的人。"
> 一上来"一二三"讲道理，观众多半划走；把观点**包装在故事里**，才有人看完。
> **笃定是语气，故事是载体，两者叠加最强**——059/070 的"案例见证"本质就是故事，这里把它从"感觉"升级成"公式"。

**故事四要素**：

| 要素 | 含义 | 例子 |
|------|------|------|
| ① 人物要有变化 | 开头和结尾的人物必须发生巨大变化（不变=没故事） | 顾客从"指标爆表"→"指标回落" |
| ② 连贯性与因果关系 | "国王死了，王后死了"不是故事；"国王死了，王后悲痛欲绝，所以死了"才是故事 | 不写流水账，每一步都有"所以" |
| ③ 升华到主题 | 普通故事往上走一步=主题 | 个人逆转 → "营养是能改命的" |
| ④ 注入价值观 | 没有价值观的故事不成立 | 健康是自己的事 / 身体是1其他是0 |

**万能故事公式**：
> `目标 + 困难 + 努力 + 结果 + 意外 + 第二次努力 + 结局`

**例（顾客逆转脂肪肝）**：目标(降指标) → 困难(应酬多/管不住嘴) → 努力(营养方案) → 意外(复查数值反复) → 第二次努力(调整方案) → 结局(指标回落)。这条弧线本身就是完整故事，自带传播力。

**检验（写完自问）**：这条脚本里有没有一个"有目标、有困难、有变化"的具体人物？
- 没有 → 补一个故事再写，别干讲道理

### 反常识观点开头 — 前3秒定生死

> **开头总原则：重点前置** — 第一句 = 整条视频最核心、最有冲击力的一句话（观点/结果/结论），绝不铺垫、绝不自我介绍、绝不"今天聊聊"。
> - **反常识观点开头** = 重点前置的最佳载体：用"XX不是XX"把核心观点直接甩出来
> - **结果前置（C）** = 同原则的另一载体：用"我做了XX，结果XX"把结果甩出来
> - **身份独占** = 给前置的这个观点"上保险"：确保它只有你能讲

> 核心：开场不是自我介绍，是**观点炸弹**——第一句话甩一个和大众认知对着干的判断，制造认知冲突，逼观众停下来。
> 核心法则："前3秒定生死。3秒留不住人，后面写得再好也没人看到。"

| 要素 | 做法 | 反例（平庸） | 正例 |
|------|------|------------|----------------|
| **反常识判断** | 第一句就是"XX不是XX"式结论 | "今天聊聊营养素的重要性" | "很多医生反对营养素，但我在三甲干了X年，我劝你……" |
| **身份独占/反差** | 用你的身份制造反差（"医生却反对同行"）——重点是**只有你能讲** | "我是张医生" | "我是个医生，但我要说句得罪同行的话……" |
| **戳痛点** | 反常识要长在观众的真实痛点上 | 纯抖机灵 | 反常识观点 + 观众正痛的那个问题 |

**公式：** `我告诉你 + [反常识判断] + [身份背书/自嘲]`（⚠️ "我告诉你"只是句式之一，不是默认开头——连续≥2条用同一句式 → 换，见「🎯 开头句式选择规则」）

**身份独占检查（强制·开头就卡）：** 开头是身份独占最关键的一道关——3秒留人靠的就是"这句话只有你能讲"。写完开头逐条过：
- [ ] **① 换人测试**：这个反常识观点，换成别的医生/营养师能讲吗？能 → 不够独占，换或加独家视角
- [ ] **② 删我测试**：删掉开头的"我"和身份词，还剩什么？剩不下=身份即内容=过关；删了还成立=换个博主也能讲
- [ ] **③ 补独家**：不够独占时，用你的独家经历补位——三甲麻醉 / 农村娃考医学院 / 开店亏光（059验证：删掉"我考执业医师/在医院轮转"就只剩"营养学很重要"）

**适用：** 认知颠覆型 / 个人叙事型 / 涨粉型内容——最狠、最反常识，但别硬套，观点必须你真信。

**黄金开头公式：**
> 选题爆款（痛点TOP级） + 开头抢（九大人性钩子选一个 / 或 反常识观点开头） + 第一句就是嘴替

**使用建议：**
- 不要硬套——钩子要和内容真实相关，不然观众感觉被骗就会划走
- 同一条视频可以用2个钩子叠加（比如"视觉刺激+高价值"）
- 测试阶段每条视频换不同钩子，看哪种数据最好

### 成交型破题开头（30%成交转化型专用）— 第一句让"对的人"认出自己

> **心法**：流量型开头抓眼球，成交型开头做筛选。破题 = 点名"愿意付钱的那个人"，让他对号入座；错的人划走 = 筛选器在工作，不是失败。
> 落地验证：script-080 重写为破题版（点人/点事/点钱），预测2秒跳出率 38% → 30%。

**三层点名法** —— 一句话点得越狠，破题越到位：

| 层 | 点的是什么 | 示例（script-080） |
|---|---|---|
| ① 点「人」 | 目标客户的身份标签/处境 | "你朋友圈里有没有这种人——体检报告一堆箭头，天天问'我到底该吃啥'" |
| ② 点「事」 | 他正在经历的糟糕结果 | "你回一句'要不吃点蛋白粉'，然后就没下文了" |
| ③ 点「钱」 | 他花的冤枉钱 / 丢掉的收益 | "不是你产品不行，是你给不出方案" |

**成交型破题公式库：**

| 公式 | 结构 | 示例 |
|------|------|------|
| 指标点名 | "你[指标]上如果有[XX]，[一句扎心后果]" | "体检报告上如果有'脂肪肝'三个字，医生只会让你少吃油——可你没少吃吧？" |
| 症状处境 | "你是不是[具体处境]，[结果]" | "你是不是每年体检血脂都偏高，回来照样该吃吃该喝喝，然后等着它变成每天吃降压药？" |

| 客户处境 | "你手上有没有[这种客户]，[你的尴尬]" | "你朋友圈有没有那种人——天天喊'我到底该吃啥'，你回一句'吃点蛋白粉'，就没下文了？" |

**破题3问（成交型写完逐条过）：**

- 第一句里有没有"愿意付钱的问题"？没有 → 只是共鸣不是成交
- 错的人听完会不会划走？不会 → 太泛，筛选器失效

## 六、结尾钩子公式库

> **v1.33 定死：结尾固定四段式——不戛然而止。** 正文写完不算完，结尾必须走完四拍：**① 金句总结 → ② 呼吁 → ③ 真心话 → ④ 追更钩（固定最后一句）**。四拍连起来，观众才会"看完 → 记住 → 想说 → 关注"。

### 四段式结尾模板

| 拍 | 做什么 | 示例（script-118） | 要求 |
|:--:|------|------|------|
| ① **金句总结** | 用一句金句/传播原子收全文，别写完就停 | "有钱人不是在为'贵'买单，是在为'早'买单" | 一句话能转述、能当传播原子 |
| ② **呼吁** | 转给谁 / 对自己好一点 / 评论区聊聊（互动钩子放这） | "你身边有没有年年体检却说不出哪里不对的人？评论区聊聊你的看法" | 纯认知互动（医疗合规·见铁律15） |
| ③ **真心话** | 掏心窝，说句最真的话 | "我不是让你羡慕有钱人，我是想说，这件事不需要你有钱" | 真诚·自曝·像朋友说话（059式认知收尾） |
| ④ **追更钩** | 最后一句固定不变 | "关注我，分享更多有价值的内容" | **固定不变·永远是最后一句** |

### ②呼吁可选用的互动钩子

| 公式 | 效果 | 示例 |
|------|------|------|
| **互动式** "你现在卡在哪？评论区告诉我" | 收集评论区素材 | "这条说的情况你遇到过吗？评论区聊聊你的看法" |
| **反问式** "你被问过吗？你是怎么回的？" | 引发评论区讨论 | "你被问过这个问题吗？你是怎么回的？评论区聊聊" |
| **转给式** "转给___的人" | 提高转发率 | "转给那个年年体检却总喊累的人" |
| **追更钩（固定·最后一句·永不变）** | 提高关注率 | "关注我，分享更多有价值的内容"（永远原样） |

> ⚠️ **医疗/营养类内容注意（2026-08-09 账号限流教训）：** ②呼吁的互动钩子禁止"我帮你分析 / 把你的情况发我 / 评论区说你的病"——引导问诊会被限流。医疗类一律用**纯认知互动**（"你怎么看？评论区聊聊"）+ 结尾加免责。细则见铁律15。

## 十、参考对标：张医生式笃定风格

> v1.21 定死：你本身就是 IP，观众是来看你判断的。这就是全部内容的默认风格。

|------|------|
| **0否定词** | 不用"可能/也许/还可以/我觉得"——写完全文搜否定词，全部删 |

## 十二、真实感写作法 — "像在聊天，不是在讲"

> 最高级的文案，是让人感觉不到"这是写好的"。

**四步写出聊天感：**
1. **读出声来** — 问自己"我朋友会这么跟我说话吗？"不会 → 太书面，改。
2. **教学感 → 分享感**：❌"我今天给你拆三个坑 / 第一点 / 为什么会这样？因为…" → ✅"我后来发现一个事 / 先说一个最离谱的 / 我当时也纳闷——后来才搞明白"。
3. **每30秒埋一个"然后呢？"** — 每段最后一句让观众想知道下一句（留缺口）。技巧："我说了一句话——他当场愣住了。你猜我说了什么？"
4. **加一粒"沙子"** — 一句真实得没必要说的话（自嘲 / 犹豫 / 细节场景 / 承认不懂 / 小吐槽）。例：❌"我以前也特别难，三个月没出单" → ✅"我以前也特别难——说出来不怕你笑，三个月没出单，我老婆说你到底行不行啊"。

**一步一步戳（别一次说完）**：先说事实 → 推翻它 → 揭答案 → 给验证，每步都踩在他"下一句想问什么"的点上。

**⚠️ 节奏控制·快进慢出**：聊天感 ≠ 绕弯子。开头（快）两句内进核心痛点 → 中间（慢）展开情绪、一步步戳 → 结尾（收）不拖沓。**检验：去掉前两句，内容不受影响 → 说明是废话，删。**

**自检追加**：□ 读出声像不像跟朋友说话？□ 有"第一/第二/所以/因此"教学感过渡词吗？→ 删 □ 前两句内进核心痛点了吗？

### 模板七：Problem→Solution 极简结构（姜胡说式）

> **来源**：[[姜胡说-评论区问题分析]] — 博主原话："问题解决方案，问题解决方案，最后一句总结，完事了"
> **核心原则**：结构越简单，执行越容易。不用花里胡哨的开头，痛点到、方案给、收尾走。

#### 信息
- **时长**：45-90秒
- **对应情绪曲线**：无刻意曲线 — 靠"痛点够痛"带情绪，不是靠表演带情绪
- **嘴替重点**：第一句话必须是观众心里正在想的那个问题
- **自信锚点**：方案要笃定，不要说"我觉得""可以试试"，要说"我告诉你"
- **适用场景**：教程类、方法类、答疑类、知识分享类
- **核心记忆**：不要讲道理，直接给方案

#### 结构

```
🎬 【0:00-0:05】 痛点直击（嘴替——替他说出心里话）
   不要铺垫，不要"今天给大家分享一个……"
   直接说：
   "你是不是[具体问题]？"
   "你是不是也[具体困境]？"
   "[最怕被问的问题]……"

🎬 【0:05-0:10】 方案承诺（自信——给出明确答案方向）
   "我告诉你，真正有用的方法就3步"
   "很多人搞错了，其实应该这么做——"
   "很简单，你只需要做三件事……"

🎬 【0:10-0:50】 3-5步解决方案（干货——每步要具体到能跟着做）
   博主原话："问题解决方案，一二三四五"

   "第一步：[做什么]"
   "第二步：[做什么]"
   "第三步：[做什么]"

   要点：
   √ 每步说清楚"做什么"+"为什么这么做"
   √ 用具体例子，不要讲抽象道理
   × 不要并列三点没有递进

🎬 【0:50-1:00】 [可选] 为什么很多人做不到（⚠️ 过滤层）
   博主原话："我如果讲道理播放量会低，但我要过滤"
   "为什么很多人卡在这？因为……"

   ⚠️ 加这层 = 牺牲播放量，换精准粉丝
   ⚠️ 不加这层 = 播放量更高，但用户没那么精准
   ⚠️ 想清楚你要什么，再决定加不加

🎬 【1:00-1:05】 一句话总结
   博主原话："最后一句总结"
   "所以记住——[核心结论/金句]"
   "就这么简单。"
```

#### 博主亲述（来自视频原文）

> "拍短视频很简单吧，搜集问题，尤其是付费的问题。他就能直接命中用户的痛点...人们听的就是我想要的东西...你有什么问题吗？我告诉你解决方案12345步，一句话总结，完事了。"

#### 这个模板和前面6个模板的区别

| 维度 | 模板一~六 | 模板七（姜胡说式） |
|------|----------|------------------|
| **情绪设计** | 有预设情绪曲线 | 不刻意设计，靠痛点带情绪 |
| **共情环节** | 专设共情段落 | 不要共情，直接给方案 |
| **原因解释** | 放结构里默认有 | 标为"可选"且说明是过滤层 |
| **拍摄难度** | 需要表演能力 | 会说人话就能拍 |
| **流量特性** | 推送型（算法推荐） | **搜索型（长尾资产）** |
| **语言风格** | 按风格系统定调 | 人们怎么说你就怎么说 |
| **适合谁** | 有表演基础/想打造人设 | 只想**解决问题、积累资产** |

#### 💡 使用建议

1. **先用模板七拍前10条** — 成本最低、最容易坚持
2. **每条开头前3秒必须是"你是不是[具体问题]"**
3. **语言检测**：读出来，像不像你跟朋友说话？不像就重写
4. **搜得到吗？** 标题和文案要用"人们搜问题时打的字"，不要用专业术语
5. **[可选]过滤层什么时候加？** — 你已经有一批基础粉丝了，想筛选出高质量粉丝时加
6. **这个模板拍的视频** — 刚开始没流量很正常，博主说了：推送流量半个月没了，**搜索流量一直有**

### 模板八：个人叙事型 / 身份IP型

> **来源：** 基于你的爆款视频（7000播放/364转发/146关注）提炼——这是你所有内容里**涨粉效率最高**的类型。
> **核心逻辑：** 观众看完不是学到了方法，而是**认识了"你是这样的人"**。

#### 信息
- **时长**：90-150秒（叙事型需要比操作型更长）
- **对应情绪曲线**：曲线G（好奇→共鸣→认知升级→信任→使命）
- **嘴替重点**：替他说出"我也想成为那样的人"
- **自信锚点**：你的经历本身就是最强的自信——不需要"我告诉你"，只需要"我走过来了"
- **适用场景**：
  - 涨粉期——让新粉快速建立对你的认知
  - 里程碑分享——有了新成就/新身份
  - 每5-10条实操内容插1条——调节节奏，拉近关系
- **核心原则**：不是"展示我很牛"，是"**我走过你正在走的路，这是我想明白的事**"

#### 结构

```
🎬 【0:00-0:20】 身份时间线开场
   开场法：用开场三模式中的模式B（身份时间线型）
   目标：触发"他怎么做到的？"的好奇心

   "[具体年份] + [从哪起步] + [关键转变] + [现在的反差结果]"

   要点：
   √ 必须有具体时间锚点（"2017年"不是"以前"）
   √ 起点要平凡（兼职、晚上、周末）→ 让观众代入
   √ 转变要反差大（辞掉三甲医院 → 6年没上班）
   √ 用自问自答接住好奇心："很多人问我怎么做到的？今天跟你聊聊"

🎬 【0:20-1:30】 N个顿悟/认知（2-3个）
   结构法：不是教步骤，是"这些年我想明白的事"
   每个顿悟的结构：

   "第X件事……[想通了什么]……[用了一个比喻/场景/数据]……[这让我的做法变了什么]……"

   顿悟设计要点：
   · 每个顿悟必须配一个生活化的比喻（如"挑水vs管道"）
   · 比喻 = 观众能转述给别人的传播引擎
   · 顿悟之间要有递进感（不是并列三个道理）
   · 最打动人的顿悟往往涉及"身份认知转变"（如"从开药到给方案"）

🎬 【1:30-1:50】 价值观表达 / 反行业叙事
   信任法：敢于批评自己行业的乱象，建立深度信任

   "我也得说句实话……[很多人把XX搞坏了]……[但我怎么看]……"

   要点：
   √ 批评的是"乱象"不是"行业本身" → 你是在正名
   √ 给出的价值观要简单有力（"安利是一个工具"）
   √ 这段是"信任高潮"——观众最想转发的往往就是这段

🎬 【1:50-2:15】 桥段：过渡到当前使命
   承接法：从过去的经验自然过渡到现在在做什么

   "[一个当前趋势/变化]……[但我的看法不太一样]……[引用一本书/一个实验/一个数据]……[基于我的经验，我判断……]"

   要点：
   √ 不要生硬转折（"说完了过去，现在讲讲AI"→ ❌）
   √ 用"书/实验/数据"做锚点增加深度
   √ 把"你的经验"和"时代趋势"连接起来

🎬 【2:15-2:30】 当前使命 + 双钩结尾
   "我想干的事很简单——[一句话说清你的使命]……[你的系统已经跑通了]……"

   评论钩：
   "你也在[做同一件事]吗？你以前[做过什么]？评论区可以聊一聊"
   或 "如果你也[某个状态]，评论区打个'1'"

   追更钩：
   "关注我，分享更多有价值的内容"
```

#### 种子钩子策略（重要）

这条模板的**种子要提前埋进视频**（结尾不预告下一条，只留空白让观众好奇）：

```
第1次出现：在第一个洞察中提一句"后来我养成了一个习惯……"
第2次出现：在第二个洞察中点明"我的XX一直在替我干活"
第3次出现：在结尾②呼吁/③真心话里点一下"这件事我一直在做"（不预告下一条）

这样结尾就不是"随便说的"，而是观众心里已经好奇了三次的事情。
```

### ① 结论前置检测（一票否决 · 2026-08-12 新增）

> **来源：** 老板IP方法论——"富人家的孩子都在转运动"= 结论已给完，观众不用点开；改成"富人和中产的孩子，10年后谁更惨？"= 悬念 + 三重爆点，才有人点。
> **一句话：** 标题如果已经把答案说完了，观众知道结果，点不点都行——**别替观众把视频看完。**

|  #  | 检验                 | ❌ 结论前置（重写）          | ✅ 保留悬念（参考）                    |
| :-: | ------------------ | ------------------- | ----------------------------- |
|  ①  | **答案是否说完？**        | "鱼油不是智商税，你买鱼油的方式才是" | "鱼油是不是智商税？90%的人买鱼油的方式，都是____" |
|  ②  | **有没有留扣子？**        | "富人的孩子都在转运动"        | "富人和中产的孩子，10年后谁更惨？"           |
|  ③  | **是不是观众心里没答案的问题？** | 一句感慨（"营销套路遍地都是"）    | "买鱼油前先看这 3 个数，多数人买错了还天天吃"     |

> ⚠️ **反认知标题是特例**："XX不是XX"本身就给了反常识答案，但它留了"凭什么？"的张力——所以反认知标题**不要连理由一起说完**。例：092 标题"鱼油是不是智商税？我告诉你：鱼油不是，你买鱼油的方式才是"——"买的方式才是"把理由也说了，观众就不用看了；应删成"鱼油是不是智商税？我告诉你，90%的人买法都错了"。

### ③ 观看理由二选一（避坑 / 得利）

> **来源：** 老板IP方法论——"标题的核心，是把观看理由说清楚。观众第一眼看到标题，就要知道：我能避开什么坑，或我能得到什么好处。"
> **一句话：** 标题里必须藏一个"关我什么事"——没有理由，划走。

| 驱动 | 观众心理 | 标题公式 | 示例 |
|------|---------|---------|------|
| **避坑驱动** | "我可能正在踩坑" | "买/做/用 X 前先看这 N 个____，多数人____" | "买鱼油前先看这 3 个数，90%的人买错了还天天吃" |
| **得利驱动** | "我能得到好处" | "普通人也能____的 N 个方法" | "一个方法，普通人也能给自己定营养方案" |

> 自检：标题去掉具体利益/坑，还剩什么？剩不下 = 观看理由说清了。

### ④ 选公式（10 大公式 → 张医生优先级 + 爆点叠加）

> 沿用 [[公众号标题决策卡]] 的 10 大公式，短视频版补一条：**标题最好叠加 2 重以上"人性力"**（对比/焦虑/好奇/利益/恐惧）——如"富人和中产的孩子，10年后谁更惨？"= 阶层对比 + 代际焦虑 + 结果危机感。

| 优先级 | 公式 | 一句话说明 | 营养线示例 | 创业线示例 |
|:--:|------|-----------|-----------|-----------|
| 🥇 | **反认知** | 颠覆常识（留"凭什么"张力，别说完理由） | "医生为什么不给你开营养素处方？" | "做安利 6 年没上过班，我悟了 3 件事" |
| 🥇 | **对比** | 制造价格/认知反差，天然带张力 | "药店 9 块 9 vs 两百多的营养素，差在哪？" | "打工月薪 5 千 vs 自己做 5 万，差的不是努力" |
| 🥈 | **悬念问句** | 留一个观众心里没答案的问题 | "富人和中产的孩子，10年后谁更惨？" | "AI时代，普通人还有没有机会？" |
| 🥈 | **共鸣话题** | 替读者说出心声 | "体检报告正常，但你就是不舒服，对吗？" | "做过安利没做起来，不是你不行" |
| 🥈 | **数字+利益** | 具体可感 + 观看理由 | "慢病人群最容易忽略的 3 个营养素" | "新安利打法：一部手机 3 件事就够了" |
| 🥉 | **俏皮话/比喻** | 你的强项（土味比喻） | "把营养素当保健品，等于把汽油当香水" | "别再做搬运工，做管道工" |
| 🥉 | **拟人化** | 物当人说，有温度 | "你的肝在喊：换个方式对我" | "你的能力在报警：别光挂一档" |
| 🥉 | **修饰词** | 加情绪强化 | "这是医生最想让你知道的 1 个真相" | "这是我踩过最贵的坑，希望你别踩" |
| ⚠️ | **热点代入** | 蹭热点，但要合规 | "世界肝炎日，医生想跟你说句实话" | "AI 时代，普通人还有没有机会？" |
| ⚠️ | **负面词汇** | 损失感驱动，易踩恐吓红线 | 慎用，只用温和版 | "别再做无用功：很多人第一步就搞反了" |
| ⚠️ | **速成** | 给快速结果，易虚假承诺 | ❌ 营养类禁用 | "3 个方法，普通人也能上手 AI 安利" |

> **优先级规则：** 优先 🥇🥈（反认知/对比/悬念/共鸣/数字），🥉 调味，⚠️ 慎用（过第②关）。**短视频优先「反认知 / 对比 / 悬念」**——它们自带点击理由。

### ⑤ 三要素检验（≥2 分过关）

| 要素 | 检验问题 | 得分 |
|------|---------|:---:|
| **身份独占** | 标题里有"医生/三甲"的独特视角吗？去掉身份还成立吗？ | 0/1 |
| **利益点 / 观看理由** | 观众第一眼知道"避开什么坑"或"得到什么好处"吗？ | 0/1 |
| **好奇心** | 有没有悬念，让人不点开难受？ | 0/1 |

> 身份独占是关键项——已验证：**身份独占 = 涨粉天花板**（059"医生不学营养"373K 播放）。

### ⑥ 搜一搜测试

### 🦴 脚本正文骨架（写稿只填肉·不重读知识库）

**开场（3秒亮牌）**——反常识观点/身份反差/具体问题，一句话甩核心观点：
`「XX不是XX」` 或 `「我是[身份]，[具体问题/反差]」`

**正文 = 2-4 个转发分装包（每包独立成立）**，每包三件套：
`[具体靶子/场景] + [核心观点+权威背书] + [转发对象：转给____]`
- 包1（hook）：最扎心/最反常识的先讲
- 包2（立论）：权威背书最重的一个（数据/指南/政策）
- 包3（软化/价值观）：个人味道/价值观锚点，共情"不是怪谁"
- 包4（可选·叙事）：个人经历顿悟，埋种子关键词

**结尾（v1.33 定死·四段式·不戛然而止）**：
`① 金句/传播原子总结 → ② 呼吁（互动钩子·随口能答·纯认知互动） → ③ 真心话（"我不是让你XX，我是想说XX"） → ④ 追更钩`
- ④ 追更钩 = **最后一句固定不变**：`关注我，分享更多有价值的内容`（永远原样·不换）
- [营养类]免责单独一行收尾（口播+简介双免责）

**个人叙事型骨架**：身份时间线开场 → N个顿悟 → 价值观表达 → 使命收尾（种子≥2次·结尾不预告）
**方法教学型骨架**：痛点共鸣 → 步骤1/2/3 → 常见坑 → 互动钩子

> 写稿按骨架填，知识库/痛点榜只在卡壳或查数据时定向读。
