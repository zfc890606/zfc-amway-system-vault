## 改动 4 · 已验证爆款公式 v1.21 → v1.36（改动最大的一处）

**位置：** `🏆 已验证爆款公式（059/070/006 共同规律 · v1.21）`

### 4-1 一句话公式
**改前：**
```
身份独占选题 + 医生第一人称（转变叙事优先）+ 认知递进或分装式并列 + 强比喻传播原子 + 多重权威背书 + 零产品 + 自白型互动钩子
```
**改后：**
```
身份独占选题 + 第一人称（转变叙事优先；⚠️ 健康观念线：从医经历只当人生故事·铁律18）+ 认知递进或分装式并列 + 强比喻／数字模型传播原子 + 多重权威背书 + 零产品 + 自白型互动钩子
```

### 4-2 表格新增 3 行

| 要素 | 爆款做法 | 验证 |
| ---- | -------- | ---- |
| **数字模型**（新增） | 把抽象观念做成"可复述的分数/百分比" | 122「健康100分」→ **转发率10.72%全库第二 · 裂变系数1.74全库第一** |
| **拆情绪 > 拆商品**（新增） | 拆"反感／逃跑"这种情绪，不拆具体商品 | 084→转发8.18%；107→24,887播放 · 均观看超89.84%同类（人群更宽、完播更高） |
| **朋友圈之王结构**（新增） | 文化母题 × 健康提醒 × **转发对象写进文案** | 116「上医治未病」→ **朋友圈占比11.18%全库第一** |

### 4-3 表格下新增 3 条规律

```
**规律A · 分装式并列 > 单一递进**——同题材同人群，070 分装式转发率 11.75% vs 107 叙事流 4.84%（差近一倍）。
→ 叙事流吃"均观看"，分装式吃"转发率"。**最优解：开头用画面感场景，结构用分装式并列，两全。**

**规律B · 低完播 × 高转化**——059 / 107 / 122 的完播率都被平台标"低"，但全是爆款。
→ 视频号算法对"分享 + 关注"的权重远大于完播率。**认知类不追完播绝对分**，盯转发率 + 涨粉转化。

**规律C · 切口决定侧重**——同一个系列，切口不同，指标天差地别。
→ "学／开"（知识·制度）＝**涨粉型**（059→涨粉5,671）；"治／看／教"（场景·机制）＝**转发型**（082→转发率9.08%）。
→ **预测涨粉要按切口判断，不要按系列判断**（082 曾预测涨粉 3,000+，实为 225）。
```

### 4-4 新增警告块

```
> ⚠️ **「高配非爆款」警告（079 / 124）**：内容指标（均观看／完播／3s率）全部顶级，播放仍然垫底——**说明脚本能力不是瓶颈，选题才是**。
> **处置：保留脚本、换选题重拍。不要改写法。**
```
