### 〇、医疗问诊合规（🔴 最高红线 · 2026-08-09 新增 · 账号已因此限流）

> **违规定性（视频号官方）：** 医疗/大健康账号出现"疑似引导用户进行线上讨论/线下问诊/医疗教学"，判定存在不可控风险 → 禁止传播/限流，可申诉。
> **原因复盘：** 脚本里的互动钩子/CTA 用了"评论区告诉我，我帮你看看""把你的情况发我""私信我给你方案"这类话术——被判定为**引导问诊**。
> **后果：** 账号已限流，多条视频被拒。

#### 三条红线（一条都不能碰）

| # | 红线 | 典型违规话术（❌） | 安全说法（✅） |
|:-:|------|------------------|--------------|
| 1 | **不引导线上/线下问诊** | "评论区留下你的情况，我帮你看看""私信我，把体检报告发我""想调理的来找我" | 只讲通用营养学常识与个人经验，不点对点给方案 |
| 2 | **不引导评论区公开讨论病情** | "你什么症状？评论区说说""你血糖多少？评论区告诉我" | "这条讲的是不是你的困惑？评论区聊聊你的看法" |
| 3 | **不引导平台外学医/领资料/收徒** | "加我微信领健康资料""关注公众号学调理方法""来跟我学中医" | "关注我，主页有更多健康科普"（留在平台内） |

#### 不可留下联系信息的位置（全账号级 · 不只是视频正文）

> 账号头像 · 账号签名 · 账号简介 · 公众号名字 · 视频标题 · 视频定位 · 活动标题 · 直播预约标题 · 评论 · 音频标题 · 合集标题

#### 脚本写稿四不

1. **不索要病情信息**：体检报告、指标、症状、用药情况——一律不主动要。
2. **不点对点给方案**："你这种情况应该…" → 改成"这种情况，日常可以参考…"（普适 + 免责）。
3. **不引导私信看诊**：医疗/营养内容里，"私信我"都别用，互动留在平台内。
4. **不加医疗资料钩子**："领资料"只可用于创业/AI类非医疗内容，医疗内容一律不用。

#### 互动钩子安全替换表（写结尾前对照）

| 场合 | ❌ 违规（引导问诊/谈病情） | ✅ 安全（纯认知互动） |
|------|------------------------|---------------------|
| 结尾互动 | "你卡在哪一步？评论区告诉我，我帮你分析" | "这条说的情况你遇到过吗？评论区聊聊看法" |
| 结尾互动 | "把你的情况发我，我帮你看看" | "你怎么看？评论区聊聊" |
| 结尾互动 | "评论区说说你的病/你的指标" | "健康科普仅供参考，个体情况请咨询专业医师" |
| 追更 | "关注我，私信我教你" | "关注我，下条继续拆" |
| 领资料 | "加微信领健康资料" | "关注我，主页有更多分享"（医疗内容不挂领资料） |

#### 免责声明（营养/健康类结尾强制）

> 口播 + 简介都要有："以上是个人经验与健康科普分享，不构成诊疗建议，个体情况请咨询专业医师。"

### 〇·1、医疗/健康账号资质认证（🔴 账号存活前提 · 2026-08-09 新增）

> **核心原则：无资质不科普。** 视频号官方 + 国家四部门（2025-08）联合要求：发布专业医疗健康内容，或账号名称/简介/背景图自称"医生""老中医"等职业身份的账号，**必须完成职业认证**——否则账号本身即处于"无资质医疗科普"高危状态（这正是反复被判定"医疗教学"的深层原因，比单条话术更治本）。

| 要求 | 内容 |
|------|------|
| **认证主体** | 个人：医生 / 医学教授 / 护士 / 药师等职业认证；机构：公立/民营医院机构认证 |
| **认证材料** | 医师资格证 + 医师执业证 + 医院在职证明（具体到科室）；平台通过**卫健委官方渠道核验** |
| **身份一致性** | 出镜人 = 认证人 = 证照信息，三者必须一致；严禁资质出借/转让/买卖/挂靠 |
| **存量账号** | 未认证账号须在 2 个月内完成认证（四部门通知 2025-08） |
| **新账号** | 不经医疗资质认证不得发布专业医疗科普内容 |
| **直播额外要求** | 健康科普直播需准入申请（有效期1年），直播间显著标明：①真实姓名 ②职称 ③执业证书编号 ④所在机构 |

> **✅ 张医生情况：** 三甲医院麻醉医生出身，具备认证资格 → 优先完成视频号职业认证，从根上解除"无资质医疗科普"风险。

### 一、健康功效类（⚠️ 最高风险区）

视频号2026年重点打击的就是**虚假宣传功效**，这是红线中的红线。

#### ❌ 绝对不能说

| 违规类型 | 典型违规词 | 风险等级 |
|---------|-----------|:-------:|
| **宣称医疗功效** | 治病、消炎、降压、降糖、治疗、根治、痊愈、预防疾病、代替药品 | 🔴 封号 |
| **宣称保健功效（超出批准范围）** | 减肥、瘦身、排毒、抗癌、疏通血管、修复细胞、改善睡眠（普通食品说这些不行） | 🔴 封号 |
| **绝对化功效承诺** | 100%有效、奇效、一吃见效、三天见效、无效退款 | 🟠 限流/下架 |
| **制造健康焦虑** | "你的细胞在饿""隐性饥饿""悄悄毁掉你的健康"——这类话术需谨慎，可能被判定为制造焦虑 | 🟠 限流 |
| **代替药物暗示** | "吃了就不用吃药了""比吃药安全" | 🔴 封号 |

#### ✅ 安全说法

| ❌ 危险 | ✅ 安全 |
|--------|--------|
| "降血糖降血压" | "日常饮食搭配参考" |
| "排毒减肥" | "体重管理、均衡膳食" |
| "调理身体"（普通食品慎用） | "日常保养、营养补充" |
| "治愈了我的XX病" | "我自己吃了之后感觉精力好了很多"（只讲个人感受，不承诺疗效） |
| "蛋白质能修复细胞"（可能被判定为伪医学） | "蛋白质是人体必需的营养素之一"（讲通用营养学常识） |

#### 安全区指南

```
✅ 可以说：
  - 通用营养学常识（"蛋白质是人体必需的七大营养素之一"）
  - 个人使用感受（"我吃了之后感觉精力好了"）
  - 产品成分介绍（但不与疾病关联）

❌ 不能说：
  - 任何与"治疗疾病"挂钩的表述
  - 暗示产品可以代替药物
  - 制造健康焦虑后立即推荐产品（会被判定为违规营销）
```

### 三、收入承诺类（直销/创业类内容的重灾区）

你的内容涉及"创业""副业""收入"，这是视频号金融类规则的敏感区。

#### ❌ 绝对不能说

| 违规类型 | 典型违规词 | 风险 |
|---------|-----------|:----:|
| **收入承诺** | 月入过万、月入五万、年入百万、轻松月入 | 🟠 限流/下架 |
| **稳赚不赔** | 稳赚、躺赚、保本、零风险、只赚不赔 | 🔴 封号 |
| **暴富诱导** | 暴富、一夜暴富、财富自由、快速致富 | 🟠 限流 |
| **诱导加盟** | 跟我干月入XX、招代理、拉人头 | 🔴 封号 |

#### ✅ 安全说法

| ❌ 危险 | ✅ 安全 |
|--------|--------|
| "我做安利月入三万" | "这是我个人的经历分享"（加声明） |
| "跟我做，月入过万不是梦" | "我把我的方法分享给你，你可以参考" |
| "稳赚不赔的副业" | "一个值得了解的创业机会" |
| "年入百万"（具体数字） | "收入上了一个新台阶"（模糊表述） |

#### 安全话术指南

```
❌ "我团队里那些月入5万的人" → 可能被判定为诱导收入承诺
✅ "我团队里那些做得不错的人，他们的方法有一个共同点"

❌ "做安利不用囤货不用刷屏，一个月多赚5000" → 具体收入数字
✅ "做安利不用囤货不用刷屏，做好了自己能看得到回报"

核心原则：不讲具体收入数字，不讲"保证你能赚多少"
```
