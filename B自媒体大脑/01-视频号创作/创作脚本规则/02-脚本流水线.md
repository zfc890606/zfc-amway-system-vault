## 写脚本全流程（八步铁律）

**🚧 0无认证期选题落点闸门（强制·一票否决·2026-08-21锁死）**：先判定落点——
- 核心靶子属行业认知/职业定位/个人经历/创业打法·AI系统/价值观 = **可写**
- 营养观念/健康观念科普 = 可写但必须过0号闸门·细则「健康观念科普安全边界」（只讲观念不碰疾病：疾病词/效果故事/点对点调理/身份背书/医疗隐喻=一票否决）
- 属营养素功效/缺了会得病/慢病调理·疾病机理/体检指标解读/点对点调理 = **换题不写稿** · 白名单见 [[发布风控总表-无认证期]]

然后按 [[视频号脚本风格系统|视频号脚本风格系统v1.28]] 八步：
1. 读痛点排行榜 → 读知识库
2. **①定选题**：先选已验证爆款元素（9个锚点：猎奇·行业揭秘 / 反差+最差·得罪人拆解 / 争议·全民疑问 / 争议·第三视角 / 成本·价格对比 / 猎奇·机制揭秘 / 人群·拆情绪 / 反差+怀旧·个人叙事 / 拷问·灵魂拷问）→ 按元素变换词根出2-3候选 → 选题决策卡筛最高分（现成候选到 [[B自媒体大脑/01-视频号创作/交付脚本库/爆款素材库/012-词根化选题刷新：已验证爆款公式×词根再产|012选题刷新池]]）
3. **反常识观点开头**（重点前置+身份独占；特殊情况才换 A痛点问句/C结果前置/B时间线/D成交破题）→ **文献价值锚点**（铁律14·强制：观点挂数据+权威出处，国外一手信息优先）→ 选内容类型（痛点共鸣/方法教学/个人叙事[模板八]/行业揭秘/认知颠覆/营养科普）→ 按类型关注指标（方法教学盯完播率，个人叙事盯关注转化+分享率）
4. **选题决策卡**（快筛4问+打分8项·定死规则）→ **涨粉复核6要素**（零产品/转发对象/删我测试/下一集测试/成长弧线/≥2传播原子）→ **个人味道嵌入**（v1.26强制·身份故事+价值观锚点+说话指纹·按线别取 [[张医生个人味道库]]）
5. **四支柱风格写稿**（选题驱动×嘴替感×自信自然×真实感）→ 老师式表达（允许废话/跑题/自曝其短）→ 价值观锚点（每5-10条插1条反行业叙事）→ 权威背书（强制·涨粉型≥1/转发型≥2-5）→ 种子钩子策略（个人叙事强制）→ 洞见卡匹配 → 真实感写作法（读出声→删教学过渡词→留缺口→加一粒沙子）→ **纯文案格式**（连续段落，不拆单行）
6. 自检：☐开头3秒亮牌 + ☐医生身份用法（①身份反差 ②拉近距离 ③硬核背书 ④转变叙事[优先]）→ 风格自检 → 老师式终极检验（被朋友看到会尴尬吗？会就对了）
7. **质检（强制·不可跳过）**：查重网关 → humanizer-zh去AI味 → content-risk-detector → 视频号7类风险排查 → 医疗合规三条红线（见 `01-合规网关.md` 0b）→ 星光违规解密质检（见 `01` 0c）→ 小红书风险排查 → ai-detector复核 → 传播原子检验（观众一句话能转述？不能→重写金句）→ 互动钩子具体化（随口能答）→ 分享潜力检查（三触发器）→ 行业对抗检查（批评归因系统而非个人·共情前置"我不是怪医生"）→ 科学事实核验（具体数字/概念/历史成就交付前主动核实，不等用户纠错）→ **风险项全部清零才交付**
8. 交付（只输出固定板块，见下）→ **标题过卡**（📌短视频标题决策卡：观看理由+结论前置检测→3备选选1填进三件套）→ **🎯 设定测试变量**（定死=涨粉·2026-08-05；自动预测2秒跳出率/5秒完播率/关注转化率）→ 存 `安利选题脚本库/script-NNN-` 或 `AI选题脚本库/AI-script-X-NNN-xxx`（末尾加测试标记+权威文献锚点·附链接）→ 更新选题库标记 → **🎬 章节进度条生成** → **🖼 AI脚本自动出封面提示词**（gbro 3:4·按内容选风格·随脚本交付·不自动生图；见 [[B自媒体大脑/04-AI自媒体创作/创作脚本规则/AI录屏演示账号·口播配合录屏写作规则]]「十、封面提示词自动化」）

> **AI脚本特殊**：视频号·AI应用号 + 抖音·AI号 同稿双发（2026-08-25·不另建抖音脚本库）；个人味道嵌入不强制；落点健康科普同样换题。

## 🦴 脚本正文骨架（写稿只填肉·不重读知识库）

**开场（3秒亮牌）**——反常识观点/身份反差/具体问题，一句话甩核心观点：
`「XX不是XX」` 或 `「我是[身份]，[具体问题/反差]」`

**正文 = 2-4 个转发分装包（每包独立成立）**，每包三件套：
`[具体靶子/场景] + [核心观点+权威背书] + [转发对象：转给____]`
- 包1（hook）：最扎心/最反常识的先讲
- 包2（立论）：权威背书最重的一个（数据/指南/政策）
- 包3（软化/价值观）：个人味道/价值观锚点，共情"不是怪谁"
- 包4（可选·叙事）：个人经历顿悟，埋种子关键词

**结尾**：互动钩子（随口能答）+ 种子预告 + [营养类]免责

**个人叙事型骨架**：身份时间线开场 → N个顿悟 → 价值观表达 → 使命收尾（种子≥2次再预告）
**方法教学型骨架**：痛点共鸣 → 步骤1/2/3 → 常见坑 → 互动钩子

> 写稿按骨架填，知识库/痛点榜只在卡壳或查数据时定向读。
