# 📖 「我的十年」个人IP短视频 · 辅导SOP

> **用途**：帮助伙伴拍「我的十年 / 一个普通男孩的十年」个人IP短视频的完整辅导手册。
> **服务对象**：张医生团队（营养线 + 创业线双线伙伴）
> **一句话**：陪伙伴把人生讲完，让他重新信他自己一次。

---

## 一、什么是"十年体" & 为什么值得辅导伙伴拍

### 什么是"十年体"
用**十年时间线**串联成长故事的短视频模板。核心叙事：普通人→低谷→坚持→逆袭，给观众一个"这个人值得信任、值得跟随"的理由。它是个人IP的**信任名片**，很多博主把它置顶当"自我介绍"。

### 爆款数据（说服伙伴用）
| 案例 | 数据 | 故事线 |
|------|------|--------|
| 陈希东（国考上岸） | **450万+阅读，16万+赞** | 高考失利→读专科→专升本→考证→国考上岸 |
| 粥左罗（北漂买房） | **1600万+播放，近30万赞，8万涨粉** | 地下室蜗居→北京买房，30岁生日发布 |
| 英语雪梨老师 | **10万+赞** | 不服输女孩的十年 |
| 张德胜教授 | 首条作品即《一个普通男孩的十年》 | 从此开启短视频IP之路 |

### 为什么有效（四大底层逻辑）
1. **建立信任**：观众只看到你成功的一面，讲过去让IP真实、饱满、可信
2. **激发共鸣**：普通人逆袭的故事人人有代入感，容易转发裂变
3. **差异化**：真实人生经历无法复制，天然形成内容壁垒
4. **身份锚定**：讲清楚"我从哪来"，观众才信"我要去哪"

### 核心金句（辅导时讲给伙伴听）
> "一个人只有讲清楚自己从哪来，才知道要去哪。"
> "拍十年体不是为了爆，是帮IP重新信他自己一次。"
> "你帮IP拍了来时路，他才带你走未来路。"

## 二、标杆与方法（谁在教，怎么教）

### 1️⃣ 粥左罗方法论（最完整，直接抄作业）
粥左罗的"北漂七年买房"爆款，他公开拆解过完整打法：

| 维度 | 做法 |
|------|------|
| **找对标** | 拆解英语雪梨老师、陈诗远等爆款：主题/文案结构/线索/字数节奏 |
| **照片量** | 用了**97张照片 + 5段视频**，翻遍QQ空间、微博、朋友圈，让**每句文案配到最合适的图** |
| **选照片原则** | 真实、不美化；宁要真实旧照，不要精致摆拍 |
| **音乐** | 用被反复验证的"超级符号"音乐：《我要的飞翔》《和你一样》——触发观众"有动人故事要来"的条件反射 |
| **包装** | 封面/标题/字幕用最方正字体、尽量大字号，一目了然 |
| **发布时机** | 选生日、纪念日等特殊时间节点发布 |
| **运营** | 评论区主动留言，引导关注、触发点赞分享 |
| **态度** | 花2周精雕细琢、剪到天亮；技巧都围绕"呈现一份感动、力量和温暖" |

> 粥左罗提醒：**先把该做的都做到，再谈创新**；核心故事做不好，包装运营都没用。

### 2️⃣ 操盘手"陪IP拍十年体"三步法（小红书操盘手圈，最贴辅导场景）
1. **访谈+录音，拉出大事记**：像记者/编剧一样，从出生聊到今天
2. **挑5个高共鸣节点**：人设类（逆袭/转型/低谷）+ 专业类（案例/逆转/成交）
3. **转化为"故事结构脚本"**：套用现成模板，填上自己的故事

操盘手进化三步：**剪辑执行 → 共创者 → 内容伴侣**，关注点从"剪什么→讲什么→他是谁"。
判断一个操盘手能不能走远，就看**有没有能力陪一个人把人生讲完**。

### 3️⃣ 张德胜教授三阶段（IP成长路径）
试水期（接地气、有网感）→ 探索期（现场短视频意外出圈）→ 担当期（确立专业人设）。
涨粉三秘诀：**现场感、独家性、愤怒优先**。

### 4️⃣ 十年体线下课（创女团/林林工作坊，可借鉴的课程结构）
- 🎬 底层逻辑：为什么"十年体"能瞬间建立深度信任和超强吸引力
- 🎬 挖掘亮点：如何从"平凡"经历中挖出闪闪发光的金矿
- 🎬 结构公式：获得现成框架，直接填上自己的故事即可使用

## 三、辅导五步法（核心SOP）

### Step 0：启动与目标对齐（15分钟）
辅导前先帮伙伴想清楚三件事：

| 问题 | 要问清楚的 |
|------|-----------|
| **给谁看？** | 潜在顾客？潜在合作伙伴？还是老朋友？决定故事取舍 |
| **要达到什么？** | 信任（营养线）？招商（创业线）？涨粉？决定内容侧重 |
| **适不适合拍十年体？** | 有无真实逆袭弧线 + 有无存量老照片？两者都没有→不建议硬拍 |

> **判断门槛**：十年体 = 逆袭弧线 × 老照片存量。缺照片可用场景补，缺弧线则改拍"身份转变叙事"（我为什么从A变成了B）。

### Step 1：访谈+录音，拉出大事记（1次访谈，1小时+）

**辅导者角色切换**：不是导师，是**记者+编剧+情人**——
> "你不说，他问；他说了，你懂；他说一半，你补。"

**访谈问题清单**（照着问，录音，逐条记）：
1. **出生**：你出生在哪？家里什么条件？小时候印象最深的一件事？
2. **家庭**：爸妈是做什么的？他们对你影响最大的一句话？
3. **学校**：读书时成绩怎么样？有没有被看不起/被夸耀的时刻？
4. **转折**：人生第一次大转折是什么？当时发生了什么？
5. **失败**：你最惨的时候是什么样的？账上还剩多少钱？那段怎么熬过来的？
6. **野心**：为什么你想改变？当时羡慕谁？想过要成为什么样的人？
7. **贵人**：谁在最难的时候拉了你一把？他说了什么？
8. **顿悟**：哪个瞬间你突然想通了一件事？
9. **现在**：你现在在做什么？为什么做这个？
10. **未来**：十年后你想成为谁？你想带多少人一起变好？

**追问技巧**（把"简历"变成"故事"）：
- 听完一个事实，追问："那一刻你什么感受？"
- 追问："如果没有那件事，你觉得你现在会在哪？"
- 追问："当时你心里最怕的是什么？"
- 把每个回答落到**人名、地点、画面、原话**。

### Step 2：挑5个高共鸣节点（30分钟）

从大事记里选**5个最能打动人的节点**，分两类：

| 类型 | 节点 | 例子 |
|------|------|------|
| **人设类** | 逆袭 / 转型 / 低谷 | 农村娃→考上医学院；亏30万→重新站起来 |
| **专业类** | 案例 / 逆转 / 成交 | 帮顾客调好指标；从被拒绝到被信任 |

每个节点拉出一个**故事稿**：人名 + 地点 + 画面 + 当时的原话。

### Step 3：套故事结构模板（给伙伴挑一个，直接填空）

**🅰 十年体九步结构（最常用，逆袭感最强）**
```
① 开头对比（现在 vs 十年/几年前，反差钩子）
② 我的家庭环境/背景铺垫
③ 我开始行动了（入行/转行/创业）
④ 小成功（有了点起色）
⑤ 大挫折（跌到谷底）
⑥ 我的努力（怎么熬过来的）
⑦ 我经历的困难（细节+画面）
⑧ 现在重新出发
⑨ 获得什么 + 一句话升华（价值观收尾）
```

**🅱 电影式（口播感强）**
```
我以前……那时候……直到有天……现在我想说……
```

**🅲 纪录片式（配照片/旁白，最省事）**
```
第一张图（小时候）→ 第二张图（转折瞬间）→ 第三张图（现状）
旁白 + 画面，轨迹清晰
```

**🅳 经历共鸣型（提问开场，互动强）**
```
你是/相信/体验过XXX吗？
我是XXX，一个XXX的人。
XX年，我（原来是怎样的）；
XX年，我（克服了什么困难做现在的事）；
XX年，我（取得了什么成就）。
我是XXX，XXXXXX（一句话slogan）。
```

**🅴 英雄之旅压缩版（进阶，故事张力最强）**
```
正常世界（平凡起点）→ 冒险召唤（变故/召唤）→ 拒斥召唤（犹豫）→
遇见导师（贵人）→ 核心磨难（最低谷）→ 获得报酬（成长/成绩）→ 携宝归来（现在的使命）
```

> **核心原则**：讲故事不能只讲故事，要给故事套一个**价值观**，才立得住IP。

### Step 4：找照片素材（帮伙伴把图配齐）

**渠道优先序**（按命中率排）：
1. **QQ空间**（十年前的照片大头基本在这）
2. **微信朋友圈**（翻到最早那条）
3. **微博/旧手机/旧相机**（存卡里）
4. **家庭相册**（爸妈那里翻，翻拍/扫描）
5. **家人朋友**（让伙伴发群问："谁有我的老照片？"）

**找不到照片怎么办——"记忆线索法"**：别按时间翻，按**你能记住的线索**找：
- 人物（"和谁拍的"）
- 颜色（"那件红裙子"）
- 地点（"学校门口"）
- 场景（"过生日""军训"）
- 情绪（"刚领证那天"）

**AI工具**（对话式搜图，输入线索自动匹配）：
| 工具 | 平台 | 特点 |
|------|------|------|
| 一寸光阴 | iOS | 一句话搜图搜视频，深入视频内容定位，支持"往年今日" |
| 拾光相册 | Android | 完全离线，输"身份证/自拍/大合照/演唱会"即找图 |
| 忆图 | 各平台 | 用模糊记忆线索（人物/颜色/地点/场景组合）搜相册 |
| 相册"地图模式" | 手机自带 | 按地理位置看照片足迹，放大到记忆中的位置 |
| 相册恢复精灵 | 安卓 | 老照片修复、划痕修复、黑白上色（找不回的照片可修复） |

**数量标准**：粥左罗一条视频用了 **97张照片+5段视频**。让伙伴至少备 **30-50张**，做到"每句文案配到最合适的图"。

**选图三原则**：真实（不修脸不过度美化）→ 有故事（一张图能说一件事）→ 有反差（越落魄的旧照，越能衬出现在的成长）。

### Step 5：制作与发布（最后冲刺）

| 环节 | 要点 |
|------|------|
| **音乐** | 《我要的飞翔》《和你一样》等"超级符号"音乐，一秒唤起情绪 |
| **封面/标题/字幕** | 最方正字体、尽量大字号，手机小屏也看得清 |
| **节奏** | 文案字数÷4字/秒=口播秒数；照片切换跟着文案走 |
| **发布节点** | 生日、加入X周年、事业周年等特殊时间点，自带话题 |
| **发布后运营** | 评论区主动留言、回复，触发点赞转发 |
| **陪伴打磨** | 陪他改到满意为止——真诚大于技巧，先打动自己再打动别人 |

## 四、辅导者角色与心法

### 你的角色：不是"教拍摄"，是"陪他走一次人生"
> 操盘手最大的问题往往是"只会剪视频，不会陪人"。
> 真正的操盘手像记者、编剧、情人——他不说你问，他说了你懂，他说一半你补。

### 进化三步
| 阶段 | 关注点 | 输出 |
|------|--------|------|
| 剪辑执行 | 剪什么 | 把素材剪完 |
| 共创者 | 讲什么 | 一起定故事线 |
| 内容伴侣 | 他是谁 | 帮他确认身份与使命 |

### 辅导原则
1. **接受试错**：不要用单点干预击碎伙伴的系统，允许他犯低级错误
2. **看见独特**：每个伙伴都有别人没有的经历，帮他把"平凡"挖成"金矿"
3. **先确认后动手**：让伙伴自己决定讲哪些故事，你只负责追问和补全
4. **耐心陪跑**：爆款要2周打磨，别催伙伴一天出片

### 常见坑（辅导时避免）
- ❌ 只教剪辑技巧，不陪人梳理故事（本末倒置）
- ❌ 把自己的经历套在伙伴身上（每个IP的故事都是独家的）
- ❌ 流水账（"我做了什么什么"×10句）——每段经历要回答：**它改变了什么？形成了什么能力？**
- ❌ 苦情竞赛（比谁更惨）——保留脆弱，但落点必须是"重新出发"

## 五、反方观点与对策（平衡视角）

### 有人唱衰："十年体已过时"
操盘手"老尚"的观点：十年体是**2023-2024年上半年的玩法**，现在观众对"逆袭的、苦情的人设"已审美疲劳；置顶视频应围绕"销售一问、销售二问、销售三问"设计，先做定位再规划成交路线。

### 我们的对策（判断要不要拍、怎么拍差异化）
1. **定位**：把十年体当**信任名片/置顶内容**，不是全部内容——用它完成"这个人值得信"，再用专业内容完成"他真专业"
2. **差异化**：不拍纯苦情逆袭，拍**身份转变叙事**（"我为什么从XX变成XX"）——医生→AI营养师，比"穷→富"更有辨识度
3. **结合专业**：十年体负责立信任，专业知识负责建立权威，两条腿走路
4. **看数据**：伙伴若拍完一条数据惨淡，不要硬推第二条，改用问答型/案例型内容，把十年体留给有弧线、有照片的伙伴

> **判断口诀**：有真实逆袭弧线 + 有老照片存量 → 十年体值得拍；只有其一 → 改造后拍；都没有 → 换内容类型。

## 六、医疗合规适配（张医生团队·强制）

伙伴账号若涉及营养/健康内容，**拍十年体必须过以下红线**（2026-08-09 生效令，详见 [[视频号风险检测清单]]）：

- [ ] **0 账号认证**：营养/健康类账号先完成视频号职业认证，无资质科普=账号级风险
- [ ] **1 不引导问诊**：不出现"评论区告诉我，我帮你分析""把你的情况发我""私信我帮你调理"——改纯认知互动（"这种情况你遇到过吗？评论区聊聊看法"）
- [ ] **2 不引导评论区谈病情**："你什么病/指标？评论区说说"→改成"聊聊你的看法"
- [ ] **3 不引导平台外领资料/学医**：医疗内容不挂"加微信领资料"钩子
- [ ] **4 全账号不留联系信息**：头像/签名/简介/标题/评论区/合集等一律不留联系方式
- [ ] **5 结尾强制免责**："以上为健康科普分享，不构成诊疗建议，个体情况请咨询专业医师"

> **十年体常见合规雷区**：故事里提到"我帮顾客调好了XX病"→ 改"顾客跟我反馈指标好了很多"；"想调理的私信我"→ 删掉。具体细节 → [[视频号风险检测清单]]「〇、医疗问诊合规」。
