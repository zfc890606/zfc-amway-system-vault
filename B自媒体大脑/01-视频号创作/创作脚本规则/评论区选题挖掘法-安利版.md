# 安利赛道 · 评论区选题挖掘法

> **来源**：姜胡说原创方法论 → 本文件是安利赛道的适配版
> **核心原理**：选题不靠抄爆款，靠"偷听"——去用户聚集的地方听他们在问什么，什么问题被问得最多，什么就是最好的选题。
> **一句话**：评论区就是选题库，付费问题全是好选题。

---

## 🎯 为什么这个方法特别适合安利赛道？

| 安利赛道特性 | 为什么评论区挖掘法有效 |
|-------------|---------------------|
| ✅ **高争议性** | 传销联想、价值观冲突 → 评论区天然活跃，质疑和求助并存 |
| ✅ **高信息差** | 入行门槛低但做好难 → 问问题的人特别多 |
| ✅ **高焦虑感** | 做了没结果、被拒绝、家人反对 → 情绪驱动提问 |
| ✅ **高搜索量** | 用户搜"安利怎么做""安利是不是传销" → 评论区问题=搜索词 |

**博主原话**："我如果没人问我问题，我可以看别人的评论区。尤其像我的评论区的很多人问的问题其实就是选题，所以评论区就是选题。"

---

## 📋 三步骤操作法

### 第一步：锁定"偷听"渠道

在安利/直销/大健康赛道，你的目标用户聚集在这些地方：

| 渠道          | 重点关注对象                           | 挖什么问题                   | 频率  |
| ----------- | -------------------------------- | ----------------------- | :-: |
| **抖音**      | 自媒体教练、付后坚、**博主老师**、安利从业者博主、大健康博主 | 新人入门、方法困惑、心态问题          | 每周  |
| **小红书**     | 安利笔记、创业笔记、大健康笔记评论区（博主老师也活跃于此）    | 女性视角痛点、产品疑问、副业选择        | 每周  |
| **知乎**      | "安利是不是传销""怎么做安利"等问题下的评论区         | 理性质疑、深度分析、对比讨论          | 双周  |
| **视频号**     | 安利直播/短视频评论区（尤其是直播间）              | 实时互动问题、即时反应             | 每周  |
| **公众号**     | 自媒体教练、安利系统公众号文章留言区               | 深度问题、从业者真实困惑            | 双周  |
| **知识星球/社群** | ⭐ **付费社群内部提问（最高价值）**             | **最真实的卡点——付费问的问题才是真需求** | 每天  |
| **喜马拉雅**    | 博主老师等安利主播的音频专辑评论区                | 深度学习者的问题、营养知识需求         | 双周  |

> 🥇 **优先级排序**：付费社群 > 抖音评论区 > 小红书 > 视频号直播 > 知乎 > 公众号 > 喜马拉雅

### 第二步：高效提取问题

面对每个评论区，问自己三个问题：

```
① 这条内容下，什么类型的问题出现得最多？
   （求助类/质疑类/方法类/心态类？）
   
② 有没有同一个问题被不同人反复问？
   （同一个问题出现3次以上 → 这就是选题）
   
③ 有没有"没人问但所有人都想知道"的问题？
   （沉默痛点——别人不问不代表没有，是你没发现）
```

**博主原话印证**："我认认真真的回答，我会对这个问题进行统计。人们最近问的最多的问题是什么？这个问题有多少人问，那个问题有多少人问？我马上就会有一个痛点，有一个问题库。"

### 第三步：按频率排榜

收集到问题后，按以下规则排榜：

| 出现次数 | 评级 | 动作 |
|---------|:----:|------|
| ≥5次（或持续出现） | ⭐⭐⭐⭐⭐ **极高** | 立即加入痛点排行榜TOP10 → 优先写脚本 |
| 3-4次（或多人问相似问题） | ⭐⭐⭐⭐ **很高** | 加入痛点排行榜 → 安排写脚本 |
| 1-2次（但问题质量高） | ⭐⭐⭐ **高** | 记入选题储备池 → 观察是否反复出现 |
| 有深度但小众 | ⭐⭐ **中** | 记录但不排榜 → 后期做深度内容用 |

## 🎬 实操案例：安利赛道各渠道问题特征

### 抖音安利类评论区

**典型内容类型**："安利怎么做""安利新人避坑""大健康创业"

```
常见问题（高频率）：
├── "做安利第一步做什么？"           ⭐⭐⭐⭐⭐
├── "没有人脉可以做吗？"             ⭐⭐⭐⭐
├── "安利到底能不能赚钱？"           ⭐⭐⭐⭐
├── "家人反对怎么办？"              ⭐⭐⭐
├── "被拒绝好多次，还要坚持吗？"      ⭐⭐⭐
├── "长客会怎么推？"                ⭐⭐⭐
└── "新手要不要囤货？"              ⭐⭐⭐
```

**特点**：偏入门级、实操级，大量"怎么办"类问题

### 小红书安利类评论区

**典型内容类型**："女生做安利""全职妈妈副业""安利产品真实分享"

```
常见问题（高频率）：
├── "宝妈做安利能兼顾家庭吗？"       ⭐⭐⭐⭐
├── "安利产品真的好用吗？"           ⭐⭐⭐⭐
├── "怎么边带娃边做安利？"           ⭐⭐⭐
├── "老公不支持怎么办？"            ⭐⭐⭐
└── "怎么发朋友圈不招人烦？"         ⭐⭐⭐
```

**特点**：偏生活化、情感化，大量"能不能""值不值得"类问题

### 知乎安利话题下评论区

**典型内容类型**："安利是传销吗""做安利是什么体验""安利奖金制度"

```
常见问题（高频率）：
├── "安利和传销到底有什么区别？"     ⭐⭐⭐⭐⭐
├── "做安利的人后来都怎么样了？"     ⭐⭐⭐⭐
├── "安利的奖金制度到底是什么逻辑？"  ⭐⭐⭐
├── "安利的产品真的值那个价吗？"     ⭐⭐⭐
└── "为什么安利在中国招人反感？"     ⭐⭐⭐
```

**特点**：偏理性、质疑型，适合做"认知颠覆型"内容

### 视频号直播评论区

**典型内容类型**：安利创业直播、大健康讲座、产品分享

```
常见问题（即时互动）：
├── "现在开始还来得及吗？"          ⭐⭐⭐⭐
├── "怎么加入？有什么条件？"        ⭐⭐⭐⭐
├── "每天要花多少时间？"            ⭐⭐⭐
├── "我不太会说话能做吗？"          ⭐⭐⭐
└── "你做了多久做到现在的级别？"     ⭐⭐⭐
```

**特点**：即时反应、真实卡点，直播时的提问最真实

### 博主老师 · 抖音/小红书评论区 🆕

> **人物画像**：87年创业宝妈 · 15年安利经验 · 跑步教练 · 健康营养顾问
> **内容方向**：安利事业经营、个人成长、能量管理、专注力提升、长客会实战、上高级经理路径
> **平台**：抖音（主阵地）+ 小红书 + 喜马拉雅

**典型内容类型**："上高级经理的关键""做1200套长客会干货""能量管理""专注力训练"

```
常见问题（高频率）：
├── "做了这么久怎么保持状态/能量？"     ⭐⭐⭐⭐⭐
├── "长客会到底怎么推？客户哪里来？"     ⭐⭐⭐⭐⭐
├── "宝妈怎么平衡安利和家庭？"          ⭐⭐⭐⭐
├── "上高级经理最关键的一步是什么？"     ⭐⭐⭐⭐
├── "新人总是三分钟热度怎么办？"        ⭐⭐⭐⭐
├── "能量低的时候怎么调整？"            ⭐⭐⭐
├── "怎么带团队伙伴一起成长？"          ⭐⭐⭐
├── "做了几年还没结果，问题出在哪？"     ⭐⭐⭐
└── "专注力怎么练？总是被杂事带偏"      ⭐⭐⭐
```

**特点**：
- **人群偏"进阶型"** — 她的粉丝很多是做过一段时间的安利人，不是纯小白
- **痛点偏"能量/心态层"** — 不是"安利怎么做"，而是"怎么做得久、做得好"
- **适合你对标的方向**：博主老师的评论区问题 = 你做"方法教学型"+"痛点共鸣型"内容的直接素材
- **和自媒体教练的区别**：自媒体教练评论区偏"新人怎么起步"，博主老师评论区偏"老人怎么突破"

**对你最有价值的挖法**：
```
博主老师的评论区 → 关注两类问题 →
① "做了很久但卡住了"型 → 你的方法教学型脚本素材
② "能量不够/专注力不够"型 → 你的痛点共鸣型脚本素材
→ 这两类问题在她的评论区反复出现，说明是真实刚需
```

## 🔄 与现有系统的联动

### 更新痛点排行榜

每次评论区挖掘后，执行以下操作：

```
评论区挖掘
    ↓
提取高频问题（按第三步频率排榜）
    ↓
对照现有 [[安利选题库|痛点排行榜]] 
    ↓
判断：
├─ 新问题 → 加入排行榜（标注来源：xxx评论区）
├─ 已有问题但频率更高 → 上调排名
└─ 已有问题但频率稳定 → 保持，继续观察
```

### 脚本管线联动

痛点排行榜更新的同时，自动触发脚本管线：

```
评论区挖掘 → 痛点排榜更新 → 
   ├─ TOP 10 痛点 → 优先写脚本（用 [[视频号脚本模板#模板七|Problem→Solution极简模板]]）
   ├─ TOP 20 痛点 → 排入选题计划
   └─ 储备池 → 留作备选
```

## 📌 使用说明

1. **频率**：至少每两周做一次评论区挖掘（可以每次刷抖音时顺手收集）
2. **记录**：发现新问题直接加入 [[安利选题库|痛点排行榜]]，标注来源和频次
3. **验证**：「付费的问题 > 免费的问题」— 如果某个问题在付费社群也被问，优先级拉满
4. **不做什么**：不要只看一个博主的评论区 → 多平台交叉验证，频率才是真信号
5. **关联**：本文件是 [[姜胡说-评论区问题分析]] 的方法论 → 安利赛道的适配实施版
