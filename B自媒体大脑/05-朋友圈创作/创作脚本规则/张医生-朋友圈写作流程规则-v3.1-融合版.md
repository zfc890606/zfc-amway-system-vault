## 〇、我是谁（定位 + 文本人格）

**定位一句话**：会用 AI 的 AI营养师 · 农村娃逆袭的超级个体教练 · 目标皇冠大使

**身份线**：农村娃（放过牛）→ 省重点奥赛班 → 南昌大学医学院 → 三甲麻醉医生 → 辞职开店亏 30 多万 → AI营养师 → 皇冠大使

**数字武器**：近10年临床 · 安利创业近10年 · 26岁亏 30 多万 · 三甲医院 · 211医学院

**文本人格**（学超级个体教练——让每条圈有"人"的立场）：
- **外在姿态**：自信、强势、有原则。敢说"我只服务认真想改变的人"，敢拒绝不合适的顾客/伙伴——**筛选感**本身就是人设。
- **内在特质**：把"i人、安静、板着脸"当记忆点——"我不太会说场面话，但我把该做的都做在专业里。"
- **价值取向**：结果导向（"2026 不需要道理，需要结果"）+ "活成自己"是最高级的生意。

**价值观锚点**：
- "农村孩子向阳而生"
- "敢选敢闯敢负责"
- "普通人靠系统可以逆袭"
- "AI 把专业变成人话"
- "利他有底线，不为业绩强推"
- "一个人走得快，一群人走得远"

**对立统一人设**（张力 = 最抓人）：
- 理性 ↔ 感性：一边算 ROI 筛顾客，一边陪伙伴打电话到深夜
- 高冷 ↔ 亲近：规则上"只服务想改变的人"，交付中极度耐心
- 医生 ↔ 创业者：最懂身体的人，出来做最"虚"的知识生意

## 一、发什么（板块锁定 · 沿用 v2.0）

| 板块 | 内容 | 占比 |
|------|------|:---:|
| 🚀 **创业生活** | 创业经历 / 人设故事 / 团队动态 / 个人成长 / 生活切片 / 营养功效向专业切片 | 40% |
| 🤖 **AI操作** | AI怎么用 / 知识库 / AI做内容 / AI改变效率 | 30% |
| 🎯 **活动转化** | 直播预约 / 课程报名 / 陪跑营招募 / 发售节点 | 20% |
| 💬 **互动日常**（穿插） | 真实困惑拉互动 / 好物 / 热点点评 | 10% |

**铁律**：不做内容搬运（朋友圈≠视频脚本压缩版）；不天天卖货。

**⚠️ 2026-09-08 张医生定：营养/功效向可直发朋友圈**——免质检、免合规网关；功效/医疗体验/健康观念/直接营销都能写。视频号/公众号仍是科普主阵地，但朋友圈不再拦营养科普与功效向内容。

## 二、写之前的三道闸（先过再写）

1. **板块判定**：这条属哪块？🚀创业生活 / 🤖AI操作 / 🎯活动转化 / 💬互动日常——都不靠边 → 不发（营养/功效向归「创业生活 · 专业人设切片」，2026-09-08 起可发）。
2. **一条一点**：只讲一个核心点。塞了机制/术语/一堆干货 → 删。
3. **质检（2026-09-08 起 · 朋友圈免检）**：不挂免责、不走 01-合规网关 一票否决；功效/医疗体验/直接营销均可写。唯一语言底线：营养素（不叫保健品）。

## 三、写作风格系统（v3.0 新增 · v3.1 扩充 · 学超级个体教练）

### 1. 八种语气开关（每条圈至少带 1-2 个 · v3.1 由 5 种扩到 8 种）

| 招式 | 做法 | 张医生例句 |
|------|------|-----------|
| **暴论** | 开场甩反常识判断 | "做安利最大的误区，是先学卖货。先学 AI 的人，都跑在前面了。" |
| **等式** | 逻辑浓缩成公式 | "营养专业 × AI × 安利系统 = AI营养师。" |
| **自问自答** | 设问推进 | "为什么医生反而适合做 IP？因为我太懂什么叫'专业但说不出口'。" |
| **短句节奏** | 单句成段砸重点 | "方向不对。努力白费。这 30 万，我买的就是这个教训。" |
| **自我拆穿** | 强势后露软 | "我其实不太会说话。第一次直播，手都在抖。" |
| **归因共情**（v3.1） | **先替对方把行为合理化，再拆穿**——共情越准，刀越深 | "你之所以能忍受十年的重复，是因为它每个月都给你发工资。" |
| **对仗撕裂**（v3.1） | 二元对照，不是并列：`你对A有X，对B却只有Y` | "你对一份工作有无限耐心，对自己的账号却只有三分钟热度。" |
| **判词收尾**（v3.1） | 不下指令，下**定性**——把结论钉死 | "这是你活在21世纪最亏的一笔交易。" |

### 2. 内容生成六步（一条朋友圈从哪来）

```
观察/触发（客户案例、伙伴困惑、行业怪象）
  → 情绪/困惑（这事不对劲）
  → 深度归因（平台逻辑 / 人性弱点 / 时代变化）
  → 模型提炼（一句话公式或方法）
  → 自我投射（我也这样走过 → 验证）
  → 行动号召（评论区互动 / 来找我 / 预告）
```

**例**：看到伙伴不敢发圈 → 为什么？→ 因为没人教过"私域表达"，朋友圈被当成了广告位 → 模型：朋友圈不是卖货，是卖人设 → 我也从不敢发到现在一天 3 条 → 想学的评论区扣 1。

### 2.5 洞见四步（v3.1 新增 · 观点/认知型专用 · 对"你"下判断）

```
现象（大家都看见的）
  → 归因（机制层：为什么会这样？人性 / 系统 / 时代）
  → 命名（给这个说不清的痛起个名字）
  → 判词（定性收尾，不是给指令）
```

**例**（对标本人已验证样圈）：上班 vs 做号的耐心错配 → 因为上班每月发工资（即时反馈 / 确定性结算 / 看得见的安全感）→ 命名**「黑洞期」** → 判词**「这是你活在21世纪最亏的一笔交易」**。

**关键在第②步**：不骂"你懒"，而是**解释他为什么必然这样**。先把对方的行为合理化，再指出这个合理化正在杀死他——共情越准，刀越深。这是「认知暴击型」区别于普通鸡汤的唯一分水岭。

### 3. 观点三机制（让判断有立场）

- **反平均主义**：敢承认差距——"贫富差距存在，认知差距更存在。"
- **结构化**：第一、第二、第三，降理解门槛。
- **逆向思考**：把缺点变优势——"内向的人更适合做 IP，因为 ta 更会观察情绪。"

## 四、7大类型模板（v2.0 六类 + v3.1 新增「认知暴击型」）

| 类型 | 结构 | 叠加的招式 | 张医生素材 |
|------|------|-----------|-----------|
| **悬念钩子**（高打开） | 钩子句 → 留缺口 | 暴论 / 数字冲突 | "近10年三甲麻醉医生，辞职做安利。你猜我怎么活下来的？" |
| **痛点共鸣**（高互动） | 场景痛点 → 共情 → 给出路 | 自问自答 / 短句 | "想干点自己的事，项目看了一堆，还是没方向？我以前也是。" |
| **价值干货**（高信任） | 钩子 → 干货清单 → 态度收尾 | 等式 / 结构化 | 一鱼多吃、AI知识库、自媒体获客公式 |
| **客户证言**（高说服） | 成果前置 → 过程 → 价值观 | 数字具体 / 成果前置 | 伙伴/学员真实案例（需本人提供+授权） |
| **限时福利**（高转化·慎用） | 稀缺 → 紧迫 → 明确指令 | 筛选感 / 行动号召 | 直播/课程/陪跑营节点（不天天发） |
| **人设故事**（高亲和） | 真实故事 → 情感 → 价值观 | 自我拆穿 / 连续剧 | 辞职开店亏光→转型→AI营养师→皇冠大使 |
| **认知暴击**（高转发 · v3.1） | **洞见四步**：现象 → 归因 → 命名 → 判词 | 归因共情 / 对仗撕裂 / 判词收尾 | 上班 vs 做号的耐心错配、红利结束、执行力差距、旧世界 vs 新世界 |

> 详细模板与例句 → [[张医生-朋友圈写作模板与规则]]「四、6大类型模板」。

### 「认知暴击型」专用 · AI创业线角度库（v3.1 新增）

> 用于 🤖AI操作 / 🚀创业生活 两条线。每个角度都是一颗完整的种子：**暴论 + 归因 + 判词**。

| # | 角度（暴论开场） | 归因（机制层 · 刀在这里） | 判词 / 命名 |
|---|---|---|---|
| 1 | 不是能力问题，是**认知局限** | 上班每月发工资＝即时反馈＋确定性结算＋看得见的安全感；账号前半段只有低播放、试错、漫长黑洞期 | 「这是你活在21世纪最亏的一笔交易」·命名**黑洞期** |
| 2 | **自媒体红利结束了，这是一份职业** | 每份职业都会回归该有的收入水平；要提高收入，只能让能力达到卓越 | 「这是这个世界的底层规则，适用于任何行业」 |
| 3 | 人和人唯一的差距是**执行力** | 执行力跟不上认知，所有认知就变成精神内耗 | 「像从未赢过一样训练，像从未输过一样去竞争」 |
| 4 | **拿起手机做自媒体那一刻，你就已经赢了** | 赚大钱的逻辑跟学历/长相早脱钩了，只是大部分人还活在旧世界 | 「未来五年你会超越身边 99% 的人」 |

**⚠️ 角度 4 的硬伤（按本规则自查）**：「超越 99% 的人」「网红一年赚的比普通人一辈子多」属**无数据支撑的宏大叙事**，违反「风格 6 问」第 6 条。改写方向：换成可查的官方数字（对照已发样圈 `超重肥胖率2030七成`、`三个官方数字说的是同一句话` 的写法）。

## 五、万能结构 + 画面结构（沿用 v2.0）

```
【主标题】10-20 字（决定别人点不点开）
```

## 七、快速生产4法（沿用 v2.0 · 省力出圈）

1. **语音转文字**：有灵感立刻说，一气呵成，再删废话。
2. **卡片收集法**：关键词/句子收一起 → 反复读 → 提炼唯一主线 → 重组填肉。
3. **配图摘取法**：从配图文字做延展，或对话式直接摘取。
4. **多角度表达**：一件事 10 个角度花式呈现（一条直播 → 预告/现场/成果/学员反馈发多条）。

## 八、写作铁律（v3.1 融合版 · 15条）

1. **数字具体**：近10年临床/近10年安利/亏30多万/5000台手术，不写"很多""好久"。
2. **自曝其短**：允许累死、说错、手抖——别端着。
3. **信任公式**：推销感重 → 改写成价值表达。
4. **术语**：一律"营养素"，不写"保健品"。
5. **不挂免责**（朋友圈特例）；视频号脚本仍按视频号规则。
6. **免质检（2026-09-08 定）**：功效/医疗体验/健康观念可直写，营销可直接；只留自我保护底线——不虚构客户、不对具体个人承诺包治/包好（证言真实见 7）。
7. **证言真实**：真实 + 经授权 + 数字具体。
8. **一条一点**，不贪多。
9. **配图本人负责**，文案留【图】。
10. **连续剧感**：同一主题做系列，让人追更。
11. **朋友圈≠视频脚本压缩版**：口语聊天，不教学。
12. **判断强度 + 筛选感**（v3.0 新增）：每条要有观点/态度，拒绝信息搬运；不讨好所有人，敢亮门槛；结尾金句或行动指令二选一。
13. **金句密度**（v3.1 新增）：观点/认知型每条至少 **3 句**能独立摘出来转发的话（约每 1-2 段一句）。发之前数一遍——数不够就是在自嗨。
14. **通篇称"你"**（v3.1 新增）：观点/认知型全程对"你"说话，**不许出现"我们"**——不是说给自己听，是**指着对方说**。人设/故事型才用"我"。
15. **必修一个词**（v3.1 新增）：每条观点型带一个可被引用的**命名**（黑洞期 / 认知局限 / 精神内耗）。**命名＝转发理由**——读者转发是在展示"我懂了这个词"。

## 十一、出稿检查清单（融合版 · 全部过才发）

> （2026-09-08：本清单是**写作手感自检**，不是合规质检。朋友圈免质检，功效/医疗/营销表述不受 01-合规网关 约束；下面只查读起来像不像人话、够不够有力。）

**基础 4 问**（v2.0）：
- [ ] 只讲一个点吗？
- [ ] 读出来像跟朋友说话吗？（不像讲课）
- [ ] 开头 3 行有钩子吗？（暴论/数字/反差/痛点）
- [ ] 转发给谁，明确吗？

**风格 6 问**（v3.0 新增）：
- [ ] 有暴论/核心观点吗？（拒绝流水账）
- [ ] 有公式/模型/等式吗？（哪怕一句）
- [ ] 有"我"的真实体感和案例吗？
- [ ] 结尾有力吗？（金句 / 行动指令 / 判词，三选一）
- [ ] 有筛选感吗？（不讨好所有人）
- [ ] 避开了吗：书面词 / 空洞赞美 / 无数据支撑的宏大叙事？

**观点/认知型 4 问**（v3.1 新增 · 「认知暴击型」专用）：
- [ ] 有**归因**吗？（解释了对方"为什么必然这样"，而不是只骂）
- [ ] 有**命名**吗？（造了一个可被引用的词）
- [ ] 结尾是**判词**吗？（定性，而不是软绵绵的希望）
