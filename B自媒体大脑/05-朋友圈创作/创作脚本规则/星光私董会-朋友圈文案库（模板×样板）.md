## 〇、底层逻辑（每条发圈前先过）

- **AIDA**：注意→兴趣→欲望→行动（钩子→价值→案例/稀缺→指令）
- **3S**：Simple（3秒懂）/ Specific（数据细节）/ Story（故事颗粒度）
- **信任公式**：`信任 =（专业度 × 可信度 × 亲密度）÷ 自我推销感`
  - 推销感重 → 改写成价值表达
  - 专业度 = 干货/洞察/方法论 · 可信度 = 证言/数据/案例 · 亲密度 = 个人故事/日常

## 一、悬念钩子类（高打开率）

**核心逻辑**：好奇心让人忍不住点开全文。

**模板**：
- 数字冲突法："只有两个销售，如何做到一年千万业绩，靠的是…"
- 反常识法："90%的人认为……！其实，这才是让客户主动找你的3个方法"
- 结果前置法："一场直播，收获300+客资！"（配图：对比截图+关键信息）

**真实样板**（陈晶）：
- 🖼 ![[img02.png]] 数字冲突："我们自己只有两个销售，一年做**千万业绩**，靠的是我们梳理出来的IP型顾问式谈单10步法。为了让大家更有效利用直播间辛苦拿回来的客资，我们把谈单流程也公布出来，给winner磨课到11点半，累死。我明天还要改自己的ppt..救命…"
- 🖼 ![[img04.png]] 数字冲突："花了**100万**搞短视频团队，3个月做了**4个粉丝**。4个粉丝…短视频真的是很多老板韭菜的付费重灾区。"
- 🖼 ![[img06.png]] 结果前置："从一个月**20个线索**，到一天**269个线索**。0单是常态，1~3单是运气好，这样的直播他坚持了2年……我顺手抄起手机录了一段，视频果然爆了，拉了1000个预约直接开播，今晚收单**269单**。"
- 🖼 ![[img07.png]] 结果前置："「天津落户升学」这么小众的赛道，一场直播**117个客资**。开播获客，获客效率是线下和私域的10倍。"

**要点**：数字越具体越狠；反差越大越抓人；结尾留缺口（"明天讲""点开全文"）。

## 二、痛点共鸣类（高互动）

**核心逻辑**：戳中痛点，让用户觉得"这就是我！"，再给解法。

**模板**：
- 场景化痛点："每一个陪跑客户身上，都有无数拼搏的故事：一打开XXX，充斥着……有没有发现……"
- 对比法："我的XXX课，学员本来是抱着XXX心态去的，没想到……现在：一条朋友圈收单5W+，客户主动咨询，改变的关键，就在这3个技巧…"

**真实样板**（陈晶）：
- 🖼 ![[img09.png]] 场景化："**9个月孕妇拿开播了**。今天给她布置了一个作业：卖出5单。为啥敢接9个月孕妇，因为我太懂了，怀孕其实更容易焦虑，与其坐在家里焦虑，不如实际做点事情。只要每天看得到希望，那就充满了动力。"
- 🖼 ![[img12.png]] 对比法："我们前端的定位课，学员本来抱着'看看你怎么营销我'的心态点进去看，**没想到上了一节最贵的商业定位课，做了3页纸笔记，比高考还学得认真**……因为我不靠价格筛选人群，内容和价值观是最好的人群筛选器。"
- 🖼 ![[img18.png]] 场景化+报喜："私董会很多客户迈出了第一次直播的步伐，卖出了第一单……突破了**收钱羞耻**的卡点、**销售羞耻**的卡点、在公域直播的卡点、在大众面前说话的卡点、害怕别人评价的卡点。从内到外的蜕变，万事开头难，一单有了第一单，坚持复盘真的会越来越好！"

**要点**：替客户说出"说不出口的痛"；给出路；用"卡点突破"讲故事。

## 三、价值干货类（高信任）

**核心逻辑**：给可落地干货，建立"关注你有用"的专业形象。

**模板**：
- 钩子开头（疑问/冲突/数字）→ 痛点放大 → 解决方案
- 清单体：纯干货列举，作为价值输出记录

**真实样板**（陈晶）：
- 🖼 ![[img13.png]] 认知干货："这个视频比我昨晚说的更好。任何一个事情**一边干-一边记录-一边输出**，持续重复这个循环，直到形成自己的体系和框架，这就是一个人把自己产品化的过程。"
- 🖼 ![[img49.png]] 认知干货："如果你被竞争对手模仿了，你的客户就离你而去，那么你的公司就不该存在。**你要思考的不是怎么去搞死对手，而是如何提升客户的价值**，满足客户差异化的价值。……我只教我做过的，我是这么管理公司，我也是这么教学员，知行合一，自成体系。"
- 🖼 ![[img11.png]] 清单/认知："人与人的交往，给人**安全感和边界感**是一个非常重要的点位。很多人会忽略或者不重视这一项，所以在职场甚至合作中，怎么死的都不知道……一个细节，就有了结论。"

**要点**：一个认知讲透；给方法论；带自己的判断和态度（价值观夹带）。

## 四、客户证言类（高说服力）

**核心逻辑**：社会认同——让客户替你说服客户。

**模板**：
- 聊天记录+结果展示："恭喜@李** 学员！3天变现20W+！（配图：客户感谢聊天记录+收款截图）"
- 对比案例法："从X单到XXX单，她做对了什么？"

**真实样板**（陈晶）：
- 🖼 ![[img23.png]] 结果+定位："我们这个月陪跑的客户厉害了，**疗愈师的高客单商业教练，单场卖240单**。这个定位目前没有人在直播间做出来……6月因为有618整体流量低迷，在低迷的流量环境里仍然能单场做到200单以上，真的是「定位的胜利」。"
- 🖼 ![[img26.png]] 对比案例："今天赵园长团队突破**315单**啦！从30单到300单，花了半个月，做对了什么？……我和赵园长说，'你能播到300单，不是因为我妙手生花，而是你本来就应该是300单，我只是帮你去做到而已'。"
- 🖼 ![[img22.png]] 客户反向催涨价："'晶总，你赶紧把你的陪跑费用**涨价100万**'。每个客户都急吼吼让我涨价，不行，不能让别人也买得起！虽说是玩笑话，但是我想告诉大家，把业务做好，做扎实，啥行情，你都不应该缺客户。"

**要点**：真实数字+名字（经授权）；突出"客户的转变"而非"我的厉害"；反差反转更抓人。

## 五、限时福利类（高转化）

**核心逻辑**：稀缺性+紧迫感。

**模板**：
- 倒计时+名额："XX课席位告急，报名马上截止了！名额-1/-2/-3！"
- 赠品诱惑："今天下单《XXX课》，额外赠送：✅ 限时24小时，错过无！"

**真实样板**（陈晶）：
- 🖼 ![[img27.png]] "线下课**席位告急**，报名高峰期来了，马上截止了（配价格-12800.00）"
- 🖼 ![[img28.png]] "8月2号北京线下课**马上满课**（¥12797.96）"

**要点**：明确倒计时/剩余名额/价格锚点；不天天发，用在关键节点（发售/开课前）。

## 七、朋友圈画面结构（视觉模板）

🖼 ![[img53.png]] —— 陈晶朋友圈的排版公式：
- **主标题 10-20 字**（决定是否展开）
- 副标题
- 全文（前3行=核心，后面"是否展开全文"）
- 年度大事件 / 1张图占据版面最大
- #话题标签 收尾

🖼 ![[img54.png]] —— 头图/置顶公式：
- 关键信息（170万粉丝 / 5年投资人生涯 / 直播万人在线 / 陪跑20W / 课程1.28W）
- 置顶：生活+软价值（"在大连难得到海边，吹吹海风看看海浪"）

**硬性配置**：
- 图片：高清、有信息量（对比图/数据图/客户截图）
- 视频：15-60秒（口播干货/客户见证/幕后花絮）
- 排版：短文案6行内、核心前3行；用【】●→符号；标题10-20字
- 节奏：**每天≥3条**，早中晚，**22:30 后曝光率最高**

## 八、快速生产4法（陈晶也在用）

1. **语音转文字**：有灵感立刻说出来，一气呵成不修改，再删废话整理
2. **卡片收集法**：把弹出来的关键词/句子收一起→反复读→提炼唯一主线→重组填肉
3. **配图摘取法**：从配图里的文字片段做延展，或对话式直接摘取
4. **多角度表达**：一件事10个角度花式呈现，省力+素材多用+练基本功
