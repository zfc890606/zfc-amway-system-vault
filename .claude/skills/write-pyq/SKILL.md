# write-pyq — 张医生朋友圈出稿

## 0. 真源（每次现读，勿凭记忆）

**唯一权威规则**：
`B自媒体大脑/05-朋友圈创作/创作脚本规则/张医生-朋友圈写作流程规则-v3.1-融合版.md`

开工前**必须完整读一遍这个文件**（约 260 行，一次读完），严格按它的「**十、写朋友圈总流程**」执行。
**不要把规则复制进本文件**——规则以真源为准，本文件只写"怎么跑"。

配套（按需读，不预读）：

- 素材/身份：`A知识沉淀大脑/01-旧知识沉淀/05-带团队/04-人物档案/人物档案-张大侠.md`
- 现成句式：`B自媒体大脑/01-视频号创作/创作脚本规则/张医生个人味道库.md`
- 已有圈参考：`B自媒体大脑/05-朋友圈创作/交付脚本库/`（命名 `PYQ-YYYY-MM-DD-主题.md`）

## 1. 输入

| 用户给了什么 | 怎么做 |
|---|---|
| 明确主题 | 直接进流程 |
| 灵感 / 素材 / 一段话 | 提炼唯一主线（一条一点），进流程 |
| 什么都没有 | 用 AskUserQuestion 问 2 项：**板块**（创业生活 / AI操作 / 活动转化 / 互动日常）+ **主题**。不要瞎编 |

## 2. 执行流程（严格按真源「十」）

1. **三道闸** —— 板块判定 → 一条一点 → 质检（**免检**，唯一底线是术语"营养素"）
2. **定板块 + 定类型** —— 悬念钩子 / 痛点共鸣 / 价值干货 / 客户证言 / 限时福利 / 人设故事 / **认知暴击**
3. **套模板 + 叠招式** —— 八种语气开关（暴论 / 等式 / 自问自答 / 短句节奏 / 自我拆穿 / **归因共情 / 对仗撕裂 / 判词收尾**）里至少上 1-2 个
4. **填肉** —— 本人真实素材 + 数字武器（近10年临床 · 安利创业近10年 · 亏30多万 · 三甲 · 211）+ 等式库 + AI创业线角度库
5. **过清单** —— 基础 4 问 + 风格 6 问 +（观点型）观点 4 问。**有一条不过就重写，不许放过**
6. **输出**
7. **入库 + 同步飞书**

观点 / 认知型额外走「**洞见四步**」：`现象 → 归因（机制层）→ 命名 → 判词`。

## 3. 硬约束（违反即不合格）

- 术语一律 **营养素**，绝不写"保健品"（引用他人原话除外）
- **不挂免责**、不走 01-合规网关（朋友圈例外）
- **配图由本人负责** —— 文案里只留 `【图】` 占位
- 观点/认知型：**通篇称"你"**，不出现"我们"；结尾可以是判词
- 数字要具体；**不许无数据支撑的宏大叙事**（"超越 99% 的人"这类直接毙）

## 4. 输出格式

直接给最终文案：

```
【主标题】10-20 字
（正文，可直接复制发圈）
【图】
#标签（选加）
```

正文之外，另附 **3 行以内**说明：板块 / 类型 / 叠了哪几个招式，供本人复核。
**不要**输出过程记录，**不要**贴规则原文。

## 5. 入库（默认执行，免下指令）

写完自动落盘到 `B自媒体大脑/05-朋友圈创作/交付脚本库/PYQ-YYYY-MM-DD-主题.md`：

```
---
created: YYYY-MM-DD
type: PYQ
板块: <创业生活|AI操作|活动转化|互动日常>
tags:
  - 私域/朋友圈
  - ...
status: 待用
---

# <标题>

> 板块：<板块> · <类型>｜ 同步飞书
> 差异化：<与本库已有圈怎么错开，列 1-2 条相关圈>

<正文>

【图】
```

- **同主题更新不重建** —— 主题已存在就改那个文件，不新建
- 只有用户说"先别存"才跳过
- 写完提示「已存入 [[...]]」，并提醒**同步飞书**

## 6. 边界（不要越界）

营养 / 功效向**可直发朋友圈**（2026-09-08 起免质检），但**视频号 / 公众号仍是科普主阵地**。
用户要的是**脚本**或**公众号文章**时，**不要**用本 skill —— 转 `B自媒体大脑/01-视频号创作/创作脚本规则/视频号脚本风格系统` 或 `02-公众号创作/创作脚本规则/03-公众号流程.md`。
