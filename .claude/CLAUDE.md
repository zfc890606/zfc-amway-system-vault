## ⚡ Token 节省原则（常驻）

- 读文件优先**目标片段**（`vault_get_document_map` + 定向读取），不整篇拉取
- 能搜索/结构化工具解决就不全量读；能少行 Read 就不整读
- 能内联完成就不开子代理；独立操作批量并行
- 回答精炼，不输出过程记录/核对清单，不重复已给信息
- **规则文件只读一次**：`F技能库skill/运行规则/` 下文件读过即弃，后续只用编号/文件名，不重复重读重贴
- **任务单元制**：每个生产任务（写脚本/公众号/录音/打包）是独立单元，完成后主动建议 `/clear` 开新会话，防历史膨胀
- **工具输出只留结论**：bash 输出裁剪、搜索 `contextLength` 调小、PDF/附件按需读页
- **粘贴防护**：用户粘贴长文本时，提示改用文件路径+定向读

## 🛡️ API 风控防触发（2026-09-05 实测加入 · 常驻）

> 背景：本机 Claude Code 走 DeepSeek API，服务端内容风控命中即报 `API Error: 400 Content Exists Risk`。**400 不可重试**：风控审查的是整个请求体（含会话历史里所有已读入的文件内容），一旦历史里进了被拦截内容，之后每次请求都失败，会话等于作废。以下规则经 2026-09-05 逐段实测验证。

- **大文件禁止整读**：`B自媒体大脑/00-选题库/安利选题库.md`（184K字符/964行）及一切 >5万字符的文件，**禁止 Read 全文**。正确姿势：先 `grep -n "^## "` 拿章节目录 → 按行号区间定向 Read（offset+limit，单次 ≤300 行）。
- **高危章节只 grep 不整读**：`安利选题库.md` 原第 682 行起的「🌍 国际市场对标账号清单」已于 2026-09-05 拆分至 **`F技能库skill/国际对标库-反MLM调研.md`**——该新文件**本身整读也会触发风控**（已实测），只允许 grep 关键词定位 + 摘要概括，禁止整读，更禁止整段原样复述到输出里。一切涉及 **反MLM / 传销 / 退出MLM / 收入真相 / 虚假宣传** 的内容同理。
- **单次进上下文内容量 ≤3万字符**（实测 12 万字符可过，但叠加会话历史后逼近阈值，留余量）。
- **输出改写不复述**：涉及上述高危主题，用自己的话概括，不粘贴长段原文。
- **一旦报 `Content Exists Risk`**：① 立即停止重试（同请求重发再多次也是 400，换模型也没用，请求体没变）；② 告知用户本会话历史已被污染；③ 建议用户 `/clear` 新开会话，改用「grep 目录 → 定向小段读」重新开始；④ 今后同类任务主动按上面规则缩小读取范围。
