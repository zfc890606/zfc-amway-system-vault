# 06 · 飞书录音 & 朋友圈同步

## 飞书录音处理标准流程

用户每天在飞书录音，不要求后台自动处理。**只有用户主动说才跑**。用户说 **"帮我拉一下飞书的录音"** 或类似指令 → 自动执行全套：

① 运行同步脚本拉取最新录音 → ② 读取转写内容 → ③ 判断所属板块（创业/认知/营养/团队/视频）→ ④ 自动完成：
- 转录原文 → 追加到 `日记（飞书笔记存档）/飞书录音存档.md`（累积式，不再按条新建文档）
- 创建洞见卡（DJ-*）→ `00-灵感库/洞见卡/`；够深 → 知识卡片（KC-*）→ `00-灵感库/知识卡片/`
- 创业/认知/团队/生活类 → 同步生成朋友圈文案（PYQ-*）→ `00-灵感库/朋友圈文案库/` → 自动同步飞书（**营养科普类不配PYQ**）
- 适合短视频 → 自动更新到 [[安利选题库]]（不问用户，直接入库）→ 更新原始笔记状态 → 已处理

### 重要规则
- **🔒 锁死（2026-08-18）**：飞书录音同步落点强制 = `日记（飞书笔记存档）/`。同步脚本 `~/.scripts/feishu-sync/feishu-to-obsidian.py` 的 `Config.vault_path` 已加护栏：配置被改成其他路径（尤其 `日记（每日日记）`）会自动告警并纠正回飞书笔记存档。**禁止使用 `日记（每日日记）`**；config 文件：`~/.config/feishu-obsidian/config.json`。
- **不问用户**：拉录音后直接跑完整流程（洞见卡/知识卡片/朋友圈文案/选题更新全部自动，含朋友圈同步飞书），不需要问任何确认
- **不后台自动**：不做定时任务，不浪费 API 费用

## 📱 朋友圈文案 → 飞书自动同步

每次产出朋友圈文案卡（`PYQ-*`，无论来自知识加工还是飞书录音流程），**默认自动同步到飞书知识库「朋友圈文案库」**，不问用户：

```bash
python3 "/Users/mac/Documents/zfc最强大脑/99-独立内容/飞书文案库同步/sync_pyq_to_feishu.py"
```

- 工具目录：`99-独立内容/飞书文案库同步/`（复用「录音同步」应用，凭据自动读取）· 新卡自动建文档，改过的卡覆盖更新
- 同步失败时：提示跑 `reauthorize.py` 重新授权 · 说明文档：[[99-独立内容/飞书文案库同步/接入指引.md]]
