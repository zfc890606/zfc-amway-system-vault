# 03 · 公众号流程 — 写/发公众号时执行

> **适用**：用户说"写公众号"/"发公众号"/"把脚本X改成公众号"/"写一篇公众号，选题是XX"/"把痛点#XX写成公众号"/"发布文章"/"设置公众号风格"。固定流程，不再询问。

## 完整流程（8步·2026-08-27 总控台整合）

0. **先读《公众号创作总控台》**（2026-08-27 整合·唯一入口·8步全流程，每步工具都在总控台链接里·双脑分工定死）
1. 读《公众号写作规则系统》定线（涨粉线/守IP线）
2. **选题决策卡**（6问+8分+搜一搜 + 三价值检验+阅读动力+搜索词·见规则系统「选题升级」）
3. **标题决策卡**（结论前置→合规→观看理由→公式→三要素→搜一搜→3备选）
4. **写作**（阅读体 + 📚参考资料 + 免责声明）
5. **质检**：humanizer-zh → content-risk-detector → ai-detector → 医疗合规7条 → **2026新规避坑质检**（见 `01-合规网关.md` 0e：AI标注/AI辅助≠一键生成/无违规导流/不日更冲推荐）
6. **提取发布区**（`<!--PUBLISH:START-->`…`<!--PUBLISH:END-->`）
7. **配图**：豆包 Seedream 5.0 按内容生成 2-3 张（ep-20260803004905-lg9hc）+ **讲师照片至少 1-2 张**（张大侠讲师照片库·开头1张建立身份+结尾金句前1张）+ **封面单独生成**（2.35:1 有封面感·大留白·主视觉突出，不用正文图当封面）
8. **gzh-AI-Design 排版**（默认暖蓝医养主题·中老年友好17px）→ **推送草稿箱**（不再询问发布授权）→ **交付纯净版**（标题+正文+参考资料+免责声明，内部记录不展示）→ **存 00-灵感库/公众号草稿/**

**例外**：用户明确说"先看看/先别发"（不推草稿箱）或"不要配图"（跳过AI配图）。
