# 张医生 · 朋友圈写作流程规则（v3.0 · 融合版）

> **这是写朋友圈的总入口。** 以后写朋友圈，从这里开始。
>
> **组成**：v2.0 板块框架 + 6大模板 × 超级个体教练写作风格 × 你的素材人设 → 张医生专属朋友圈写作系统。
>
> **用法**：灵感进来 → 过三道闸 → 定板块类型 → 套模板+叠风格 → 素材填肉 → 过融合检查清单 → 输出。
>
> **底层方法**：[[张医生-朋友圈写作模板与规则]]（v2.0 详版）· **风格来源**：[[超级个体教练-朋友圈写作风格方法论]] · **模板来源**：[[星光私董会-朋友圈文案库（模板×样板）]]

## 〇、我是谁（定位 + 文本人格）

**定位一句话**：会用 AI 的 AI营养师 · 农村娃逆袭的超级个体教练 · 目标皇冠大使

**身份线**：农村娃（放过牛）→ 省重点奥赛班 → 南昌大学医学院 → 三甲麻醉医生 → 辞职开店亏 30 多万 → AI营养师 → 皇冠大使

**数字武器**：10年临床 · 6年安利 · 26岁亏 30 多万 · 三甲医院 · 211医学院

**文本人格**（学超级个体教练——让每条圈有"人"的立场）：
- **外在姿态**：自信、强势、有原则。敢说"我只服务认真想改变的人"，敢拒绝不合适的顾客/伙伴——**筛选感**本身就是人设。
- **内在特质**：把"i人、安静、板着脸"当记忆点——"我不太会说场面话，但我把该做的都做在专业里。"
- **价值取向**：结果导向（"2026 不需要道理，需要结果"）+ "活成自己"是最高级的生意。

**价值观锚点**：
- "农村孩子向阳而生"
- "敢选敢闯敢负责"
- "普通人靠系统可以逆袭"
- "AI 把专业变成人话"
- "利他有底线，不为业绩强推"
- "一个人走得快，一群人走得远"

**对立统一人设**（张力 = 最抓人）：
- 理性 ↔ 感性：一边算 ROI 筛顾客，一边陪伙伴打电话到深夜
- 高冷 ↔ 亲近：规则上"只服务想改变的人"，交付中极度耐心
- 医生 ↔ 创业者：最懂身体的人，出来做最"虚"的知识生意

## 一、发什么（板块锁定 · 沿用 v2.0）

| 板块 | 内容 | 占比 |
|------|------|:---:|
| 🚀 **创业生活** | 创业经历 / 人设故事 / 团队动态 / 个人成长 / 生活切片 | 40% |
| 🤖 **AI操作** | AI怎么用 / 知识库 / AI做内容 / AI改变效率 | 30% |
| 🎯 **活动转化** | 直播预约 / 课程报名 / 陪跑营招募 / 发售节点 | 20% |
| 💬 **互动日常**（穿插） | 真实困惑拉互动 / 好物 / 热点点评 | 10% |

**铁律**：不发营养科普干货（那是视频号/公众号营养线）；不做内容搬运（朋友圈≠视频脚本压缩版）；不天天卖货。

## 二、写之前的三道闸（先过再写）

1. **板块判定**：这条属于四大板块哪块？都不属于 → 不发。
2. **一条一点**：只讲一个核心点。塞了机制/术语/一堆干货 → 删。
3. **红线**：营养素（不叫保健品）· 不引导问诊/谈病情 · 不挂免责 · 不留联系方式当钩子 · 不承诺结果。

## 三、写作风格系统（v3.0 新增 · 学超级个体教练）

### 1. 五种语气开关（每条圈至少带 1-2 个）

| 招式 | 做法 | 张医生例句 |
|------|------|-----------|
| **暴论** | 开场甩反常识判断 | "做安利最大的误区，是先学卖货。先学 AI 的人，都跑在前面了。" |
| **等式** | 逻辑浓缩成公式 | "营养专业 × AI × 安利系统 = AI营养师。" |
| **自问自答** | 设问推进 | "为什么医生反而适合做 IP？因为我太懂什么叫'专业但说不出口'。" |
| **短句节奏** | 单句成段砸重点 | "方向不对。努力白费。这 30 万，我买的就是这个教训。" |
| **自我拆穿** | 强势后露软 | "我其实不太会说话。第一次直播，手都在抖。" |

### 2. 内容生成六步（一条朋友圈从哪来）

```
观察/触发（客户案例、伙伴困惑、行业怪象）
  → 情绪/困惑（这事不对劲）
  → 深度归因（平台逻辑 / 人性弱点 / 时代变化）
  → 模型提炼（一句话公式或方法）
  → 自我投射（我也这样走过 → 验证）
  → 行动号召（评论区互动 / 来找我 / 预告）
```

**例**：看到伙伴不敢发圈 → 为什么？→ 因为没人教过"私域表达"，朋友圈被当成了广告位 → 模型：朋友圈不是卖货，是卖人设 → 我也从不敢发到现在一天 3 条 → 想学的评论区扣 1。

### 3. 观点三机制（让判断有立场）

- **反平均主义**：敢承认差距——"贫富差距存在，认知差距更存在。"
- **结构化**：第一、第二、第三，降理解门槛。
- **逆向思考**：把缺点变优势——"内向的人更适合做 IP，因为 ta 更会观察情绪。"

## 四、6大类型模板（沿用 v2.0 · 叠加风格招式）

| 类型 | 结构 | 叠加的招式 | 张医生素材 |
|------|------|-----------|-----------|
| **悬念钩子**（高打开） | 钩子句 → 留缺口 | 暴论 / 数字冲突 | "10年三甲麻醉医生，辞职做安利。你猜我怎么活下来的？" |
| **痛点共鸣**（高互动） | 场景痛点 → 共情 → 给出路 | 自问自答 / 短句 | "想干点自己的事，项目看了一堆，还是没方向？我以前也是。" |
| **价值干货**（高信任） | 钩子 → 干货清单 → 态度收尾 | 等式 / 结构化 | 一鱼多吃、AI知识库、自媒体获客公式 |
| **客户证言**（高说服） | 成果前置 → 过程 → 价值观 | 数字具体 / 成果前置 | 伙伴/学员真实案例（需本人提供+授权） |
| **限时福利**（高转化·慎用） | 稀缺 → 紧迫 → 明确指令 | 筛选感 / 行动号召 | 直播/课程/陪跑营节点（不天天发） |
| **人设故事**（高亲和） | 真实故事 → 情感 → 价值观 | 自我拆穿 / 连续剧 | 辞职开店亏光→转型→AI营养师→皇冠大使 |

> 详细模板与例句 → [[张医生-朋友圈写作模板与规则]]「四、6大类型模板」。

## 五、万能结构 + 画面结构（沿用 v2.0）

```
【主标题】10-20 字（决定别人点不点开）
【前3行】核心钩子：暴论 / 数字 / 身份反差 / 痛点
【正文】痛点 → 故事 → 数据 → 方法 → 价值观
【结尾】①互动钩子（评论/预告）或 ②价值观金句（二选一，要有力）
【图】← 配图占位（本人负责）
【标签】#话题标签 收尾（选加）
```

**画面节奏**：配图高清有信息量（对比/数据/实拍）· 视频 15-60 秒 · **每天 ≥3 条**（早中晚，22:30 后曝光率最高）。

## 六、张医生等式库（你的标志性公式 · 可反复用）

- 营养专业 × AI × 安利系统 = **AI营养师**
- 1 个 IP + 1 个助理 + AI = **百万级轻运营**
- 一鱼多吃 = 一份功夫 × **四倍流量**
- 方向 × 系统 × 坚持 = **普通人的逆袭**
- 信任 =（专业度 × 可信度 × 亲密度）÷ **自我推销感**

---

## 七、快速生产4法（沿用 v2.0 · 省力出圈）

1. **语音转文字**：有灵感立刻说，一气呵成，再删废话。
2. **卡片收集法**：关键词/句子收一起 → 反复读 → 提炼唯一主线 → 重组填肉。
3. **配图摘取法**：从配图文字做延展，或对话式直接摘取。
4. **多角度表达**：一件事 10 个角度花式呈现（一条直播 → 预告/现场/成果/学员反馈发多条）。

---

## 八、写作铁律（v3.0 融合版 · 12条）

1. **数字具体**：10年/6年/30万/第7天，不写"很多""好久"。
2. **自曝其短**：允许累死、说错、手抖——别端着。
3. **信任公式**：推销感重 → 改写成价值表达。
4. **术语**：一律"营养素"，不写"保健品"。
5. **不挂免责**（朋友圈特例）；视频号脚本仍按视频号规则。
6. **医疗合规**：不引导问诊/谈病情、不留联系方式当钩子。
7. **证言真实**：真实 + 经授权 + 数字具体。
8. **一条一点**，不贪多。
9. **配图本人负责**，文案留【图】。
10. **连续剧感**：同一主题做系列，让人追更。
11. **朋友圈≠视频脚本压缩版**：口语聊天，不教学。
12. **判断强度 + 筛选感**（v3.0 新增）：每条要有观点/态度，拒绝信息搬运；不讨好所有人，敢亮门槛；结尾金句或行动指令二选一。

## 九、连续剧线（沿用 v2.0 · 可追更素材）

```
辞职开奶茶店 → 亏30多万 → 全职安利 → 学会AI → AI营养师 → 目标皇冠大使
```

每一格都能单独成圈。**AI 连续剧**：从不会 AI → 学 AI → 用 AI 干活 → AI 帮我带团队。可叠加"暴论系列"：每 5-10 条插一条反行业叙事（如"做安利别再卖货了"）。

## 十、写朋友圈总流程（从灵感到发布）

```
灵感 / 选题（创业 / AI / 活动 / 生活）
  ↓ ① 三道闸（板块？一点？红线？）
  ↓ ② 定板块 + 定类型（悬念/痛点/干货/证言/福利/人设）
  ↓ ③ 套对应模板 + 叠风格招式（暴论/等式/自问自答/短句/自我拆穿）
  ↓ ④ 用你的素材+数字武器填肉（AI类补一个"AI做了什么"的细节）
  ↓ ⑤ 过「融合检查清单」（下方）
  ↓ ⑥ 输出：可直接发圈文案（含【图】占位 + 可选#标签）
  ↓ ⑦ 配图你负责 → 发布（22:30 后佳）
```

## 十一、出稿检查清单（融合版 · 全部过才发）

**基础 4 问**（v2.0）：
- [ ] 只讲一个点吗？
- [ ] 读出来像跟朋友说话吗？（不像讲课）
- [ ] 开头 3 行有钩子吗？（暴论/数字/反差/痛点）
- [ ] 转发给谁，明确吗？

**风格 6 问**（v3.0 新增）：
- [ ] 有暴论/核心观点吗？（拒绝流水账）
- [ ] 有公式/模型/等式吗？（哪怕一句）
- [ ] 有"我"的真实体感和案例吗？
- [ ] 结尾有力吗？（金句 or 行动指令，二选一）
- [ ] 有筛选感吗？（不讨好所有人）
- [ ] 避开了吗：书面词 / 空洞赞美 / 无数据支撑的宏大叙事？

**有一条不过 → 重写再发。**
