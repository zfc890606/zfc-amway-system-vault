## 〇、朋友圈内容板块（发什么 · 2026-08-24 定）

朋友圈只发这**三大板块**，其他不上：

| 板块 | 内容 | 例子 | 占比建议 |
|------|------|------|:-------:|
| 🚀 **创业生活** | 创业经历 / 人设故事 / 团队动态 / 个人成长 / 生活切片 | 辞职开店亏光、放牛、爸妈、陪跑学员 | 40% |
| 🤖 **AI操作** | AI怎么用 / AI知识库 / AI做内容 / AI改变效率 | 一鱼多吃、AI写脚本、知识库调方案 | 30% |
| 🎯 **活动转化** | 直播预约 / 课程报名 / 陪跑营招募 / 发售节点 | 今晚直播、3天课早鸟、陪跑营名额 | 20% |
| 💬 **互动日常**（穿插） | 拉互动的真实困惑 / 好物分享 / 热点点评 | "你们觉得XX怎么选？" | 10% |

**铁律**：不发营养科普干货（体检指标/营养素功效/慢病机制）；不做内容搬运（朋友圈≠视频脚本压缩版）；不天天卖货。

## 一、人设锚点（写每条圈前先定位）

**身份线**：农村娃（放过牛）→ 省重点奥赛班 → 南昌大学医学院 → 三甲医院麻醉医生 → 辞职 → AI营养师

**数字武器**：10年临床 · 6年安利 · 26岁开奶茶店亏30多万 · 三甲医院 · 211医学院

**价值观锚点**（创业+真实生活向）：
- "农村孩子向阳而生"
- "敢选敢闯敢负责"
- "普通人靠系统可以逆袭"
- "AI把专业变成人话"
- "利他有底线，不为业绩强推"
- "一个人可以走得快，一群人走得远"

---

## 二、底层逻辑（每条发圈前先过）

- **AIDA**：注意（钩子）→ 兴趣（价值）→ 欲望（案例/稀缺）→ 行动（指令/互动）
- **3S**：Simple（3秒懂）/ Specific（数字细节）/ Story（故事颗粒度）
- **信任公式**：`信任 =（专业度 × 可信度 × 亲密度）÷ 自我推销感`
  - 推销感重 → 改写成价值表达
  - 专业度 = 干货/洞察/方法论 · 可信度 = 证言/数据/案例 · 亲密度 = 个人故事/日常

---

## 三、万能结构（每条圈按这个骨架）

```
【主标题】10-20字（决定别人点不点开）
【前3行】核心钩子：身份反差 / 数字 / 反常识 / 痛点
【正文】展开：痛点 → 故事 → 数据 → 方法 → 价值观
【结尾】①互动钩子（评论/预告） 或 ②价值观收尾
【图】← 配图位（本人负责）
【标签】#话题标签 收尾（选加）
```

**画面结构（视觉模板 · 学陈晶）**：
- 主标题 10-20 字，决定展开率
- 前 3 行 = 核心，后面靠"展开全文"
- 配图：高清、有信息量（对比图/数据图/客户截图/实拍）
- 视频：15-60 秒（口播干货/客户见证/幕后花絮）
- 节奏：**每天 ≥3 条**，早中晚，**22:30 后曝光率最高**

## 四、6大类型模板（全部换成张医生素材 · 创业+AI+活动向）

### 类型1 · 悬念钩子类（高打开率）
**结构**：钩子句（数字冲突/反常识/结果前置）→ 留缺口
**张医生素材**：
- 数字冲突："10年三甲麻醉医生，辞职做安利"
- 反常识："90%的人做安利从卖货开始，我反着来，先学AI"
- 结果前置："6年没上过一天班，全靠一部手机"
**示例**：
> 我，南昌大学医学院毕业，做了10年三甲医院麻醉医生。
> 然后辞职了。借了40万开店，亏光了。
> 现在我全职做安利，6年没上过一天班。
> 你猜我是怎么活下来的？【图】

### 类型2 · 痛点共鸣类（高互动）
**结构**：场景化痛点 → 共情 → 给出路
**张医生素材**：做安利做不起来 / 想转型不知从哪开始 / 副业做了一堆没结果 / 一个人单打独斗没系统 / 学了一堆记不住
**示例**：
> 你是不是也这样：想干点自己的事，项目看了一堆，钱花了不少，还是没方向？
> 我以前也是。开店亏30多万，才明白——方向不对，努力白费。
> 后来我找到一条普通人够得着的路。你想听吗？【图】

### 类型3 · 价值干货类（高信任）
**结构**：钩子开头 → 干货清单/认知 → 态度收尾
**张医生素材**：一鱼多吃（一套内容发全平台）· AI知识库让专业可复制 · 自媒体获客公式 · 团队带法（S2/S3/S4）· 用AI做脚本/做PPT/回客户
**示例**：
> 做自媒体的朋友，记住一个词：一鱼多吃。
> 同一个选题，视频号出视频、小红书出图文、公众号出长文、朋友圈出人设。
> 一份功夫，四倍流量。这是我这个月最大的效率提升。【图】

### 类型4 · 客户/学员证言类（高说服力）
**结构**：伙伴/学员成果前置 → 过程 → 价值观
**张医生素材**：真实伙伴/学员案例（需本人提供+授权，数字越具体越有力）
**示例**：
> 恭喜李哥！跟着陪跑营从0开始，第7天发出了第一条视频，今天来了第一个主动咨询的人。
> 不是我厉害，是他真的愿意为改变投入。
> 认真想改变的人，值得被看见。【图】
> ⚠️ 发前替换成真实案例（配聊天记录/截图，经伙伴同意）

### 类型5 · 限时福利类（高转化 · 慎用）
**结构**：稀缺 → 紧迫 → 明确指令
**张医生素材**：直播场次 / 课程名额 / 陪跑营名额 / 发售节点（本人给）
**示例**：
> 这周直播，3天AI营养师课的早鸟名额，还剩最后几个。
> 上期跟完的人，最常说的是"原来AI还能这么干"。
> 想了解的朋友，评论区扣个"1"，我发你详情。【图】
> ⚠️ 不天天发，只在直播/开课/发售节点用；不挂"领资料/私信调理"医疗钩子

### 类型6 · 人设故事类（高亲和力）
**结构**：真实故事/生活 → 情感 → 价值观
**张医生素材**：连续剧（辞职开店→亏光→转型→AI营养师→皇冠大使）· 农村爸妈亲情 · 放牛/插秧 · 团队故事 · AI带来的改变
**示例**：
> 我爸到现在还说："好好在医院待着不好吗？"
> 我说：爸，我在医院能帮100个人，走出来我能帮10000个人。
> 他没再说话。我知道他还不完全懂，但他在试着懂。【图】

## 六、快速生产4法（陈晶也在用 · 省力出圈）

1. **语音转文字**：有灵感立刻说出来，一气呵成不修改，再删废话整理
2. **卡片收集法**：把弹出来的关键词/句子收一起 → 反复读 → 提炼唯一主线 → 重组填肉
3. **配图摘取法**：从配图里的文字片段做延展，或对话式直接摘取
4. **多角度表达**：一件事10个角度花式呈现（一条直播 → 发预告/现场/成果/学员反馈多条），省力+素材多用

## 七、写作铁律（固定规则，每条例行）

1. **数字具体**：10年/6年/40万/第7天，不写"很多""好久"
2. **自曝其短**：允许累死、救命、说错重说——别端着
3. **信任公式**：推销感重 → 改写成价值表达
4. **术语**：一律写"营养素"，不写"保健品"
5. **朋友圈不挂免责**（2026-08-11 定）；视频号脚本仍按视频号规则加免责
6. **医疗合规**：不引导问诊（不写"私信我帮你分析/调理"）、不引导评论区谈病情、不留联系方式当钩子
7. **客户证言**：真实 + 经授权，数字具体
8. **一条一个核心点**，不贪多
9. **配图本人负责**，文案留【图】占位即可
10. **连续剧感**：同一主题可做系列，让人追更
11. **朋友圈≠视频脚本压缩版**（2026-08-11 定）：禁止把视频稿的机制/干货/术语整段搬进朋友圈。朋友圈只讲**一个点**，口语聊天，不教学。出圈前强制过「4问自检」：
   - ① 这条只讲一个点吗？（塞了机制/术语/一堆干货 → 删）
   - ② 读出来像跟朋友说话吗？（像讲课 → 重写）
   - ③ 开头3行有钩子吗？（身份反差/数字/反常识/痛点）
   - ④ 转发给谁，明确吗？（没人想转 → 重写）
   - 任何一条不过 → 重写再发
12. **定位强制（2026-08-24 定）**：**朋友圈只走「创业生活 + AI操作 + 活动转化」**。出现营养科普干货（体检指标/营养素功效/慢病机制等）→ 删/换题；那是视频号/小红书/公众号营养线的内容。营养类知识入库时**不自动配朋友圈文案**。

## 八、连续剧线（可追更素材）

```
辞职开奶茶店 → 亏30多万 → 全职安利 → 学会AI → AI营养师 → 目标皇冠大使
```

## 九、灵感 → 出圈流程

```
你给灵感/选题（创业/AI/活动/生活）
   ↓
我判断板块（创业生活 / AI操作 / 活动转化 / 互动日常）+ 类型（悬念/痛点/干货/证言/福利/人设）
   ↓

   ↓

   ↓

   ↓

```
