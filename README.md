## 📖 这是什么？

这是一个**不是用来囤知识、而是用来「运行」知识**的个人操作系统。它把营养学专业、AI 提效、内容创作和团队业务沉淀为一套可执行的第二大脑:

- 🧠 **知识沉淀**:洞见卡(DJ-*) + 知识卡片(KC-*)流水线,把每一次录音/读书/思考加工成可复用卡片
- 🎬 **自媒体创作**:视频号 / 公众号 / 小红书 / AI 录屏 / 朋友圈五大平台,选题→脚本→质检→交付全流程规则化
- 🤖 **AI 自动化**:规则 + Skill 驱动,写脚本、发公众号、同步飞书录音、自动复盘均有 SOP
- 👥 **团队与业务**:四大板块待办看板、业绩突破导航、社群微课工作流

> 核心理念:**知识不是用来囤的,是用来「运行」的。能运行的知识才是资产。**

## ⚡ 系统怎么「运行」

```
灵感/素材/录音
     │
     ▼  入盒 → 查重网关
     ├─ 有金句     → 洞见卡 DJ-*      ─┐
     ├─ 有认知框架 → 知识卡片 KC-*      ├─ 反哺
     ├─ 有选题价值 → 更新选题库         │
     └─ 有传播性   → 朋友圈文案 PYQ-*  ─┘
     │
     ▼
自媒体输出(4平台/5出口)→ 数据复盘 → 策略迭代
```
