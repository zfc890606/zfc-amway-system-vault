# 🤖 智能体系统使用指南（大白话版）

> 一句话：这个"智能体系统"就是**你的一人公司运营助理**。不用学任何软件操作，**用大白话吩咐它，它就把整套安利/营养师生意的活干了**。

---

## 一、它到底是什么

它是建在你 Obsidian 笔记库上的"AI 大脑"。里面存了两样东西：

1. **你的知识资产** — 医生专业、营养知识、创业认知、团队带法、爆款视频拆解，全部沉淀成一张张"卡片"
2. **你的自动化流水线** — 写脚本、发公众号、整理录音、做复盘、带部门，每一步怎么干都写成了"规章制度"

你说话 → 它读规则 → 自动干活。**就像请了个读过你全部手册的全职助理。**

---

## 二、怎么用：就跟助理说话一样

**不需要命令语法，不需要记关键词。** 你就说你想干嘛：

| 你说（大白话）                  | 它自动帮你做的事                                                                    |
| ------------------------ | --------------------------------------------------------------------------- |
| "帮我写个安利脚本，第3号痛点"         | 调研痛点 → 查重 → 写口播稿 → 过医疗合规/AI味/违规词检查 → 给你"标题+简介+朋友圈文案"三件套 → 存进脚本库 → 生成章节进度条预览 |
| "帮我把 script-072 改成公众号文章" | 口播体改成阅读体 → 配图 → 排版 → 推到公众号草稿箱                                               |
| "帮我拉一下飞书的录音"             | 拉录音 → 提炼金句成洞见卡 → 内容深再成知识卡片 → 顺手生成朋友圈文案 → 自动同步飞书                             |
| "帮我调研一下'中老年人补钙'，然后写条脚本"  | 先全网调研 → 更新痛点库 → 再走写脚本全流程                                                    |
| "帮我复盘一下最近数据"             | 拉数据 → 填复盘表 → 对比预测和实际 → 给出下次改进点                                              |
| "帮我带部门②冲业绩"              | 读你的业绩突破导航 → 按部门阶段（S2/S3/S4）出本周陪跑计划                                          |
| "整理脚本库，打包成docx"          | 收集脚本 → 去重 → 打包 → 存到归档区                                                      |
| "发公众号"                   | 跑完整公众号流水线 → 推到草稿箱                                                           |

> **核心心法：你说"要什么结果"，不用管"它怎么存、存在哪"。**

---

## 三、它最值钱的地方：每件产出都自动"过质检"

这系统不是写完就交，而是**强制过检查才给你**：

- **查重** — 写之前先查你库里有没有同款，避免自己抄自己
- **视频号医疗合规** — 不引导问诊、不引导评论区谈病情、不留联系方式（三条红线，一票否决）
- **违规词扫描** — 收入承诺、极限词、"招商"、"加微信"这类词自动拦下
- **去AI味** — 查完 AI 痕迹才让你发出去，不像机器人写的
- **科学事实核验** — 具体数据、医学概念交付前主动核对，不瞎编

> 这些规则全写死在手册里，等于你**最担心的"发出去违规""像AI写的""数据不实"**，它在交付前就替你排雷了。

---

## 四、知识会自己"长"成你的资产库

你丢进去的每样东西（录音、灵感、爆款视频、文章），它都按规矩归位：

- 一句话金句 → **洞见卡（DJ-\*）** — 以后写脚本时自动调用
- 完整方法论 → **知识卡片（KC-\*）** — 按四大板块分好（营养/创业/短视频/带团队）
- 朋友圈素材 → **朋友圈文案库（PYQ-\*）** — 生成后自动同步飞书
- 爆款视频 → **爆款视频库** — 记录完整数据+可复制经验

> 用得越久，你的"弹药库"越厚，写东西越来越快、越来越有底气。

---

## 五、新手最省心的三条建议

1. **别研究系统，直接提需求** — 上来就说"帮我写条视频脚本，主题是XXX"，它就跑起来了
2. **想省事就用它内置的高频指令** — 写脚本、写公众号、拉录音、复盘、带部门，这五件事是它最熟的
3. **不用怕说错** — 它每一步都有质检兜底，真有问题也会停下来问你，不会闷头乱改
