## 一、三天介绍课 — 详细内容

### 📅 第一天：AI本地知识库搭建

**主题**：你的第二大脑——为什么AI知识库是AI营养师的底牌

| 环节 | 内容 | 时长 | 目的 |
|:----:|------|:----:|:----:|
| 开场 | AI营养师全景介绍：这个身份是什么、为什么 | 15min | 建立认知框架 |
| 痛点 | "学了一堆记不住""做了内容没沉淀""经验传不下去" | 10min | 制造需求 |
| 展示 | 张医生的AI知识库长什么样（现场演示） | 15min | 视觉冲击 |
| 实操体验 | 现场让学员体验一次AI搜索：问一个营养问题→AI给答案 | 10min | 亲身感受 |
| 小结 | 知识库 = AI营养师的"大脑"，没有它你和其他人没区别 | 5min | 强化价值 |
| 预告 | 明天学营养基本功——有了知识库，里面装什么 | 5min | 留存 |

**关键话术**："过去你学东西，大脑记不住。现在有了AI知识库，你学一条存一条，越用越值钱。"

---

### 📅 第二天：营养基本功

**主题**：AI营养师的核心——能出营养方案才是真本事

|   环节   | 内容                      |  时长   |     目的     |
| :----: | ----------------------- | :---: | :--------: |
|  前情回顾  | 知识库装什么？——装的就是今天要讲的营养体系  | 5min  |    串起来     |
|  核心框架  | 从隐性饥饿→细胞修复→慢病逆转的一条逻辑链   | 15min |   建立营养思维   |
|  实操案例  | 用张医生的知识库现场查一个慢病案例（如糖尿病）  | 10min |   知识库怎么用   |
| 简易方案体验 | 学员跟着做一份基础营养建议（用AI辅助）    | 15min | 亲身体验"能出方案" |
|   小结   | 你不是医生，但AI让你能给出专业级建议     | 5min  |    建立信心    |
|   预告   | 明天学怎么用AI做内容——有了专业，怎么传出去 | 5min  |     留存     |

**关键话术**："你没读过医学院，但AI知识库里有58张营养卡片，等于一个医生团队在你背后。"

---

### 📅 第三天：AI自媒体创作

**主题**：用AI批量生产专业内容——你的价值被看见

| 环节 | 内容 | 时长 | 目的 |
|:----:|------|:----:|:----:|
| 前情回顾 | 有了知识库（装什么）+营养方案（会什么）=今天学传播 | 5min | 串起来 |
| 内容逻辑 | 做内容的本质不是拍视频，是"把你的专业变成别人能看到的价值" | 10min | 认知纠偏 |
| 实操① | 用AI写一条营养科普脚本（选一个主题） | 10min | 跟着做 |
| 实操② | 用AI检测脚本的人味+去AI味+风险排查 | 10min | 质量保障 |
| 实操③ | 现场拍一条（手机+自然光+交流感） | 15min | 降低心理门槛 |
| 全景总结 | 三天全景回顾：知识库+营养+内容=AI营养师 | 10min | 收网 |
| **转化** | **推实战实操落地系统：安利卡+200分俱乐部** | **10min** | **变现** |

**关键话术**："这三天你看到了全景、体验了工具、做出了内容。如果你说'我想真正干起来'——那才是真正开始的地方。"

## 二、后端：实战实操落地系统

### 进系统的两个条件

```
条件①：安利卡（身份门槛）
  为什么要有？——AI营养师最终要落在安利平台
  没有安利卡，无法签约长客会、无法建立管道
  没有安利卡，你学得再好也变不成收入

条件②：200分俱乐部（系统门槛）
  值多少钱？——200分 ≈ 约XXX元/月
  有什么权益？
  ├─ AI知识库全套使用权限（58张营养卡片+6类慢病方案库+持续更新）
  ├─ 手把手陪跑计划（从第1条视频到第1个顾客的完整流程）
  ├─ 200分俱乐部社群（每日打卡+每周答疑+同学互相激励）
  ├─ 张医生定期直播陪跑（实操演示+学员案例拆解+问题解答）
  └─ AI自媒体创作模板包（脚本模板30+条+发布日历+选题库）
```

### 为什么要有这两个条件

| 条件 | 作用 |
|:----:|------|
| **安利卡** | 过滤"只是看看"的人——有卡代表真的想做 |
| **200分俱乐部** | 过滤"不愿意投入"的人——愿意为自己投资的人才会认真学 |
| **两个都有** | 代表这个人既有身份又有意愿，值得你花时间带 |

## 三、短视频推广策略

### 短视频矩阵（引流到3天介绍课）

| 阶段 | 选题方向 | 示例 | 钩子 |
|:----:|---------|------|------|
| **认知型** | 引爆AI营养师这个概念 | "什么是AI营养师？" | "3分钟说清楚一个全新的身份" |
| **认知型** | 身份反差 | "医生为什么要换个title" | "我做了6年医生，现在叫自己AI营养师" |
| **痛点型** | 知识记不住的问题 | "学了一堆营养知识全忘了？" | "你不是记忆力差，是缺一个第二大脑" |
| **方法型** | AI知识库demo | "我的AI知识库长什么样" | "30秒调出一份慢病方案" |
| **方法型** | AI写脚本demo | "用AI写一条脚本有多快" | "1分钟搞定，你来试试" |
| **见证型** | 学员效果 | "他做了AI营养师第7天……" | "从0基础到发出第一条视频" |
| **转化型** | 直接推课 | "3天带你搞懂AI营养师" | "3天，3个板块，带你入门" |

### 发布节奏

| 时间 | 内容 | 频率 | 目标 |
|:----:|------|:----:|:----:|
| 蓄水期 | 认知型+痛点型 | 每天1条 | 建立概念认知 |
| 预热期（开课前3天） | 方法型+转化型 | 每天1-2条 | 报名3天课 |
| 开课期间 | 课程花絮+学员反馈 | 每天1-2条 | 营造氛围 |
| 结营后 | 见证型+实战系统介绍 | 隔天1条 | 推后端系统 |

## 四、直播策略

### 直播类型

| 类型 | 频率 | 内容 | 目标 |
|:----:|:----:|------|:----:|
| **理念直播** | 每周1场 | 讲AI营养师是什么+为什么是机会 | 涨粉+认知 |
| **demo直播** | 每周1场 | 现场演示AI知识库/写脚本/做方案 | 展示能力 |
| **招生直播** | 每期开课前3天 | 推3天介绍课 | 报名转化 |
| **结营直播** | 每期结营 | 三天总结+推实战系统 | 后端转化 |

### 招生直播标准流程

```
┌─ 开场（0-5min）────────────────────────────────────┐
│  "我最近在干一件新事情——AI营养师"                     │
│  → 一句话钩子，让人想听下去                           │
├─ 分享（5-20min）──────────────────────────────────┤
│  讲理念：人类简史+AI营养师是什么                      │
│  讲痛点：过去做安利难在哪                             │
│  讲解药：AI营养师的三板斧                            │
├─ demo（20-35min）─────────────────────────────────┤
│  现场演示一个环节（比如AI知识库搜索）                  │
│  让人看到"原来这么简单"                              │
├─ 推课（35-50min）─────────────────────────────────┤
│  "3天课讲什么、怎么参加、有什么收获"                   │
│  放报名方式（¥49直接购买）                           │
└─────────────────────────────────────────────────────┘
```
