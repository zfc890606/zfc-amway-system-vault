## 🥗🤖 二、双线结构（一鱼多吃）

```
                    自媒体平台矩阵
                           │
        ┌──────────────────┴──────────────────┐
        ▼                                      ▼
  🥗 营养线（留人型/抓顾客）              🤖 AI线（涨粉型/抓伙伴）
  ─────────────────────────              ─────────────────────────
  视频号·营养创业号                       视频号·AI应用号
  + 小红书  (关联分发)                    + 抖音    (关联分发)
  + 公众号  (关联分发)                    （录屏实操为主）
  一个选题 → 三个平台各出一版            一个AI主题 → 一条脚本 同稿双发
  = 一鱼多吃                             = 一鱼两吃
```

**规律**：每一条内容生产时，先出**母版脚本**（视频号为主），再按各平台爆款逻辑派生——视频号口播 / 小红书图文 / 公众号长文 / 抖音录屏。平台专属风格与创作流程后续逐平台定（见文末「待定项」）。

> **🔒 脚本库归属（2026-08-25 更新·同稿双发）**：
> - **视频号·AI应用号 + 抖音·AI号** → 共用 [[AI选题脚本库/]]（`AI-script-X-NNN`），选题来自 [[AI选题库]]
> - **同稿双发**：一条 AI 脚本同时发视频号 + 抖音，**不另建抖音脚本库**
> - 两平台内容同源同稿，各过各平台风控（抖音额外过 AI 内容标注）

## 🔗 四、与四条工作流路线的关系

```
路线① 知识沉淀 ──选题/金句──▶ 路线② 自媒体输出（本矩阵）
        │                                │
        │ 素材/方法论                     │ 内容沉淀
        ▼                                ▼
路线④ 业绩突破 ◀────资源/陪跑──── 路线③ 团队复盘
```

- **① 知识沉淀**（不变）：低知识沉淀 + 流水性知识沉淀，入盒成卡 → 反哺②③④
- **② 自媒体输出**（本矩阵）：5个出口按双线出内容
- **③ 团队复盘**（不变）：用②产出的内容做团队素材，沉淀带团队方法论
- **④ 业绩突破**（不变）：用①入库的创业/团队素材 + ②的获客能力，带部门冲业绩
