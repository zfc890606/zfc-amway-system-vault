# 📱 朋友圈文案库 · 索引

> 与 [[洞见卡]]、[[知识卡片]] 平行的日常产出库
> **规则**：每天知识入库时，除拆洞见卡/知识卡片外，同步按 [[张医生-朋友圈写作模板与规则]] 生成朋友圈文案，存本目录。

---

## 本目录用途

- 存放每日由知识拆解生成的朋友圈文案（`PYQ-日期-主题.md`）
- 一条知识 = 洞见卡 + 知识卡片 + 朋友圈文案 三件套

## 命名规则

```
PYQ-YYYY-MM-DD-主题.md
```

## 写作规则

- 依据 [[03-Resources（参考的资料）/03-短视频/朋友圈文案库/张医生-朋友圈写作模板与规则]]
- 6大类型：悬念钩子 / 痛点共鸣 / 价值干货 / 客户证言 / 限时福利 / 人设故事
- **不挂免责** · **配图本人负责**（文案留【图】占位）
