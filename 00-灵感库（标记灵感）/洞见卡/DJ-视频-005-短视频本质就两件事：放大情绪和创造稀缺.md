# DJ-视频-005 短视频本质就两件事：放大情绪 + 创造稀缺

> **一句话洞见**：一条视频要爆，不需要学几十种拍法——只做两件事：**创造稀缺性 + 放大情绪**。内容和情绪到位，方式不一定要跟别人一样。

---

## 🧩 因果 / 原理

**为什么大多数视频没人看？**
- 因为既没有新东西（不稀缺），也没有情绪（不打动人）
- 观众划走不是因为画面不够炫，是这两件事一件都没做到

**为什么有效？**
- **稀缺**让人"想看"：这条内容别处听不到 → 值得停下来
- **情绪**让人"看完 + 记住 + 分享"：被钩住才会停留，被打动才会转发
- 选题、人设、语言、结构、背书全部在服务这两个目标

**底层公式：**
```
爆款 = 创造稀缺性 × 放大情绪
         ↑          ↑
   别处听不到     心里咯噔一下
```

---

## 🛠 可用方法

### 最小行动
拍下一条视频前先回答两个问题：
1. 这条有什么是**别处听不到的**？（稀缺）
2. 观众看到**哪一句**会心里咯噔一下？（情绪）
两个都答不上 → 别拍，先改选题。

### 完整执行步骤
1. 选一个"别处听不到"的角度（制造稀缺）
2. 开头用高情绪钩子（放大情绪）
3. 正文反复自检：有没有新认知？有没有情绪起伏？
4. 结尾固定钩子："关注我，分享更多有价值的内容"

## 📍 适用场景

- **写脚本前自检**：一条脚本写完，用两件事检验值不值得拍
- **给伙伴点评视频**：点评时只盯两件事，别陷在细枝末节
