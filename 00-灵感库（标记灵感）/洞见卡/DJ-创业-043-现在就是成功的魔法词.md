# DJ-创业-043 · 现在就是成功的魔法词

> **一句话洞见**："现在"是成功的魔法词——"明天""下周""以后""有一天"都是失败的同义词。

---

## 🧩 因果 / 原理

舒瓦茨在第十章中一针见血：等条件完美再行动的那一天永远不会来。成功者和失败者的区别不在于能力，而在于**成功者现在就做**。当你想"等准备好了再……"——真相是你永远准备不好。行动本身就是最好的准备。

**在安利事业里，"等"是最隐蔽的杀手：**
- "等我有空再联系那个客户" → 永远不会联系
- "等我学好了AI再开始做内容" → 永远不会开始
- "等团队稳定了再冲DD" → 永远不会稳定

## 🛠 可用方法

1. **现在就打那个电话**——不要想"他会不会拒绝"，打了再说
2. **现在就写那条脚本**——不要想"够不够好"，写了再改
3. **现在就约部门陪跑**——不要想"等下周"，本周就约
4. **机械启动法**：不想做的时候，先坐下来动笔/动手——身体会带动大脑

## 📍 适用场景

- **脚本类型**：拖延症 / 行动力 / 创业心态 / 时间管理
- **位置建议**：结尾收束——用冲击力的话收尾："你今天不打这个电话，这个电话永远不会打出去"
- **适用部门**：部门③（~1万）→ 先让他现在就做一件事，而不是等"准备好"
