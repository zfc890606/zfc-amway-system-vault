# DJ-创业-039 · 借口症是失败病，不治永远做不大

> **一句话洞见**：借口是失败病（Excusitis）的症状——"我没文化""我不会""我不够聪明""我没时间"——每一个借口都在把目标推远一分。

---

## 🧩 因果 / 原理

舒瓦茨在第二章提出：失败者不是能力不够，而是"借口症"太重。四种最致命的借口症：

1. **健康借口症**："今天我状态不好"——不谈身体状况，你的身体会配合你的信念
2. **智力借口症**："我不够聪明"——大多数人犯两个错误：低估自己，高估别人
3. **年龄借口症**："我太老了/太年轻了"——年龄不是障碍，心态才是
4. **运气借口症**："别人运气好"——所谓好运=计划+准备+行动

**越做安利久的人，越容易得借口症**——因为行业被误解太多，外部环境容易让人找到"不做的理由"。

## 🛠 可用方法

1. **辨识自己的常用借口**——写下来，看看自己最常用哪个
2. **把"我不能"转成"我怎么才能"**
3. **给部门做"借口症自测"**——让他们写下自己最大的借口，然后逐个击破
4. **用AI打破智力借口**——"我不懂AI"已经不再是借口，你的AI新打法工作指南就在那里

## 📍 适用场景

- **脚本类型**：认知颠覆 / 创业心态 / 自我突破
- **位置建议**：中间翻转——观众刚在内心找借口，你直接戳破
- **适用对象**：新人（最容易有借口症）和卡在瓶颈的伙伴
