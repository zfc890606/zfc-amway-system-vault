# DJ-团队-024-ABC黄金法则：B把A推起来，让C想见A——新手借力成交

> **一句话洞见**：新手做安利个人品牌没起来时，别自己硬讲——用ABC黄金法则：A专家出方案、B桥梁组局、C顾客；B要做的是把A"推起来"（视觉化：照片、视频、战绩），让C主动想见A，成交就交给A。

**🎤 来源**：[[日记（飞书笔记存档）/2026-09-01-文字记录：大健康与安利合作模式及AI应用分享 2026年9月1日]]（张医生教伙伴第一步怎么找客户）

**💡 即用方法**：
- 早期打法：你身边有健康需求的人，先做"引导性沟通"（一句"吃药只是控症状，根子在生活方式"），不讲产品不讲安利
- 借力成交：把老师推出来（千人大课照片、视频号），发给他看，让他"想见老师"→ 拉三人群 → 约视频/见面 → 老师发力出方案
- 成长路径：做B借力，边做边学老师怎么沟通 → 慢慢自己变A → 你的伙伴又做B——整个团队都是围着ABC转
