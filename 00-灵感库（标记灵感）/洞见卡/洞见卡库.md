# 🗃️ 洞见卡库

> 所有短视频金句/洞察的存储地。代替原有的独立"金句素材库"文件。
> **每张金句 = 一张洞见卡**，格式统一、便于检索、即拿即用。

## 使用方式

**写脚本时**：按选题关键词在洞见卡里搜索 → 找到对应的金句 → 嵌入开头钩子或结尾收束

**新洞察进来时**流程：
```
新洞察/金句
    │
    ├─ 先 → 洞见卡（DJ-*） ← 金句就存在这里
    │
    ├─ 内容够深? → 知识卡片（KC-*）
    │
    └─ 适合短视频? → 更新选题库
```
