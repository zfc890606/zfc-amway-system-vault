# DJ-视频-007 选题决定流量，定位决定变现——讨好底层的爆款，爆了也白爆

> **一句话洞见**：一条视频能不能火，选题占 50%；但选题同时决定你**吸引谁**。讨好底层人群的选题，播放量可能很高，付费能力却弱——没有高变现定位，爆款也变不了现。**高端客户靠价值吸引，不靠流量吸引。**

---

## 🧩 因果 / 原理

- **选题是"人群筛选器"**：每条选题都在替你选粉丝——选的是付得起钱的人，还是看热闹的人。
- **定位决定内容**：没有高变现定位，选题只能东蹭西蹭；有了定位，选题自动长出来。
- **"美女只是底层社会的稀缺资源"为什么好？** = 阶级对立（流量）× 上层稀缺资源价值观（价值吸引）× 吸引同频高客（变现）——三条全中。

---

## 🛠 可用方法

### 最小行动
下一条选题拍前问一句：**这条爆了，涌进来的是付得起我钱的人，还是看热闹的人？**

### 完整执行步骤
1. 定定位（为谁服务 → 高变现定位）
2. 选题加对立冲突（男女 / 地域 / 中外 / 古今 / 穷富 / 阶级 / 婆媳）
3. 用"上层稀缺资源与价值观"代替"讨好底层"
4. 过选题决策卡 6问 + 8分

---

## 📍 适用场景

- 写脚本定选题前
- 发现选题全在"讨好底层"时
- 粉丝多但不变现时
