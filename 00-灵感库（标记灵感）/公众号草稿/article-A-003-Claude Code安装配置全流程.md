# Claude Code 安装配置全流程：从API到第一条指令

Claude Code下好了，打开终端敲`claude`，然后它说"没有这个命令"——有过吗？

我第一次就是这样。去官网下载了，装完了，以为直接就能用。结果它根本不认识我。

后来我才知道，装完只是第一步，还要配API key。

## 第一步：拿到API key

先去 console.anthropic.com 注册一个账号，拿到你的API key。这个key就是你的通行证，没有它Claude Code不搭理你。

## 第二步：配置环境变量

终端里输：
```
export ANTHROPIC_API_KEY=sk-ant-你的key
```

注意，这行命令只在当前终端窗口生效。关掉再打开又没了。所以最好写进配置文件里。

大部分人现在用zsh，编辑 `~/.zshrc`，在最底下加一行：
```
export ANTHROPIC_API_KEY="你的key"
```

保存之后，记得 `source ~/.zshrc` 或者新开一个终端窗口让配置生效。

我第一次忘了加引号，key里有个特殊字符，折腾了半天才查出来是引号的问题。你应该不会犯这个错，因为我已经犯过了。

## 第三步：验证

key配好了，再敲`claude`。你会看到终端出现一个对话界面，问你第一个问题。那一刻你就知道，配好了。

试一下：`claude "帮我看看当前目录有什么文件"`。它就会开始思考，然后回答你。

如果刚装好敲`claude`还是找不到命令，可能是安装路径没加到PATH里。重新安装一次，或者装完之后新开一个终端窗口试试。

装完Claude Code不是终点，是你和AI协作的起点。
