# 🚀 05-业绩突破导航 — 从两个5-8万部门到营销经理的路线图

> 
> 📍 **奖衔目标**：DD（125,000元 / 10,000分）→ 营销经理（3个DD市场，年入50~70万）→ FC
>
> 📍 **核心优势**：你已经有**两个准DD苗子**——这在安利里是最值钱的资产

## ════════ 🎯 第二步：突破策略——帮部门从5-8万跨到12.5万 ════════

### ⚡ 前提检查：先过"两关"再推策略

> 2026-07-25 新增：在你用任何策略之前，先确认你的部门伙伴**内心真信了**。
> 方法参考 → [[洞见卡/DJ-团队-009-培养自动播伙伴的两步根基：价值锚定+愿景强化|两步根基法]]

```
给部门推策略前，先问自己三个问题：
□ 他能不能自己说出"为什么非安利不可"？（价值锚定过关了吗？）
□ 他能不能清晰描述3年后想要的生活？（愿景强化过关了吗？）
□ 他会不会主动跟别人说"我在做安利"？（行动信号出现了吗？）

如果以上答案都是"否"——
先别急着推4步法，先回去补两关。
策略给一个内心没信的人，等于把工具给一个不想干活的人。
```

### 关键认知：5-8万到12.5万缺的不是能力，是"系统"

部门能做到5-8万，说明他们已经：
- ✅ 会卖产品 / 会服务客户
- ✅ 有一定的客户群
- ✅ 有基本的行动力

**他们卡在哪？**
```
5-8万瓶颈 = 靠"自己卖"能做到的上限
12.5万突破 = 必须开始"带人卖"

部门①/②现在卡的就是你之前的状态——
    自己能力强，但还没学会通过别人拿结果。
```

所以你的角色不是教他们怎么卖，而是**教他们怎么带人**。

### 🆕 AI新打法——让部门快速学会"带人"的系统

> 你现在手里有了[[03-Resources（参考素材资料）/02-创业/安利·AI新打法工作指南]]——这就是你给部门最好的"带人工具"。

这套工作指南把"带人"这件事变成了一个**可复制、可操作的系统**：

```
以前教部门带人：靠你口传心授，你讲一遍他听一遍，转头就忘
现在教部门带人：把工作指南给他，他照着做就行

三个直接可用的模块：
├─ 讲营养 → 把《细胞修复营养方案》PPT讲透（基本功①）
├─ 讲事业 → 用长客会裂变百万年薪的逻辑（基本功②）
└─ 做系统 → 知识沉淀→自媒体输出→复盘迭代（三个工作流）
```

**给部门的带法：**

| 部门        | 用AI新打法的哪部分   | 怎么用                             |
| :-------- | :----------- | :------------------------------ |
| 部门①（5-8万） | 整套系统         | 让他直接用工作指南带他自己的新人——他把"带人"变成"给系统" |
| 部门②（5-8万） | 基本功② + 三个工作流 | 帮他建立自己的内容输出节奏，通过自媒体吸引流量         |
| 部门③（~1万）  | 基本功①         | 先让他把《细胞修复营养方案》讲熟，服务好客户打好基础      |

> **核心转移：** 你不用再亲自教每个伙伴怎么做事，**把工作指南给他，他是照着系统做，不是照着你的记忆做。**

### 帮部门①/②跨过12.5万的4步法

参照 [[03-Resources（参考素材资料）/02-创业/安利与我/02-新人成长与团队复制|团队复制四步法]]：

```
第1步：帮他找到他的"A/B/C"（3个有潜力的种子）
  ↓
第2步：教会他用 [[03-Resources（参考素材资料）/02-创业/安利与我/04-目标路径|10分钟OPP]] 讲事业机会
  ↓
第3步：陪他跑一遍"带人"的全流程（你做给他看→他做你看→他独立做）
  ↓
第4步：他有了他的第一个小部门 → 你开始做他的"顾问"
```

**具体每周陪跑动作：**

| 周次 | 和你部门①/②的陪跑内容 |
|:----:|:---------------------|
| 第1周 | 一起列3个最有潜力的候选人，分析每个人的情况 |
| 第2周 | 你带他讲一遍OPP，他讲一遍给你听，纠偏 |
| 第3周 | 他约了人，你陪他去讲（你做他看） |
| 第4周 | 他自己去讲，讲完回来复盘（他做你看） |
| 第5周 | 他的第一个小部门启动，你教他怎么跟进 |
| 第6周+ | 他独立运作，你每周检查一次进度 |

### 部门③（~10,000）的带法——走另一条线

部门③还在10,000，说明还在"自己做"阶段。对他的带法不是冲12.5万，而是**先帮他稳在3-5万**：

```
├─ 帮他建立20个稳定客户（每月消耗）→ 业绩稳在3-5万
├─ 教他讲OPP → 开始发展他的第一个下线
└─ 基础稳了 → 再走部门①/②的路线
```

## ════════ 📋 第四步：你的每周节奏 ════════

### 每周固定的四件事

```
周一：定方向
  ├─ 部门①：这周他的1个关键动作是什么？（帮他找胜负手）
  ├─ 部门②：这周他的1个关键动作是什么？（帮他找卡点）
  └─ 部门③：约时间陪跑（他还在学基础）

周三：跟进度
  ├─ 部门①：微信/电话问一句"进展如何"
  ├─ 部门②：问"需要什么资源"
  └─ 部门③：检查动作是否到位

周五：做复盘
  ├─ 三个部门的数据变化
  ├─ 你自己这周的时间分配（多少在带人？多少在自己做？）
  └─ 如果"自己做"占比 > 50% → 下周强行压缩

周日：蓄能
  ├─ 读一篇知识卡片（[[00-灵感库（标记灵感）/知识卡片/KC-创业-019-项目打分模型：70分以下不做的决策框架\|KC-019 项目打分模型]] 等）
  ├─ 为下周三个部门准备1个可用素材（OPP话术/数据/案例）
  └─ 做下周计划
```

### 每天必盯四个数

```
① 三个部门今天有动作吗？（有/没有→为什么没有？）
② 你自己今天的时间花在哪？（做业绩 vs 带人）
③ 今天有没有解决一个部门的问题？
④ 今天有没有为下周蓄能？
```
