下载了个AI工具，打开教程发现第一行代码就报错，然后默默关掉。有过吗？

我上次就是这样。下载了OpenClaw，想着本地跑一跑看看效果。结果光配置环境就搞了两个小时。不是我不会装，是我电脑里Python是3.9，OpenClaw要3.10以上。死活跑不起来。

后来看报错才发现的。你先检查一下自己的Python版本。终端输python3 --version，如果是3.9或者更低，去Python官网下个3.11。别下3.13，有些包还不兼容。

版本对了，下一步装依赖。就一句pip install openclaw。但我劝你别直接pip，最好建个虚拟环境。我第一次直接pip，结果跟另一个项目冲突了，跑完OpenClaw，之前好好的一个工具废了。

你cd到项目文件夹，敲这几行：

python3 -m venv venv
source venv/bin/activate
pip install openclaw

看着进度条跑完，最难那关过去了。

然后输openclaw --version，能看到版本号就是装好了。我第一次看见版本号跳出来的时候，说实话，挺激动的。

后面就简单了。想用图形界面就openclaw gui，命令行就openclaw run。填上API key就能开始用。

还有，如果报什么"No module named"，别慌。大概率缺某个包，pip install 那个名字就行。我第一次报了个pydantic的错——我当时想，这是哪来的东西？上网一搜，pip install pydantic就搞定了。

装完之后你会发现，本地跑AI有一个好处网页版给不了——你随便折腾，不担心额度超了，也不用怕对话记录被别人看。

本地部署不是技术活。你能一路走到命令行跑出结果，已经赢了大部分人了。
