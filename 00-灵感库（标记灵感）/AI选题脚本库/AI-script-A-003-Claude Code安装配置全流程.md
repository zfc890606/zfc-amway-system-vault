Claude Code 下好了，打开终端敲claude，然后它说"没有这个命令"——有过吗？

我第一次就是这样。去官网下载了，装完了，以为直接就能用。结果它根本不认识我。

后来我才知道，装完只是第一步，你还要配API key。

先去console.anthropic.com注册一个账号，拿到你的API key。这个key就是你的通行证，没有它Claude Code不搭理你。

然后把key设成环境变量。终端里输：

export ANTHROPIC_API_KEY=sk-ant-你的key

注意，这行命令只在当前终端窗口生效。你关掉终端再打开，又没了。所以最好写进配置文件里。

用什么配置文件？看你用哪个shell。大部分人现在用zsh，你编辑~/.zshrc。在最底下加一行：

export ANTHROPIC_API_KEY="你的key"

保存之后，记得source ~/.zshrc或者新开一个终端窗口让配置生效。

我第一次忘了加引号，key里有个特殊字符，折腾了半天才查出来是引号的问题。你应该不会犯这个错，因为我已经犯过了。

key配好了，再敲claude。你会看到终端出现一个对话界面，问你第一个问题。那一刻你就知道，配好了。

你可以试一下：claude "帮我看看当前目录有什么文件"。它就会开始思考，然后回答你。

对了，刚装好如果敲claude还是找不到命令，可能是安装路径没加到PATH里。你重新安装一次，或者装完之后新开一个终端窗口试试。我第一次也在这卡了一下。

装完Claude Code不是终点，是你和AI协作的起点。
