# KC-营养-039-细胞修复每日营养数字账本

> **一句话本质**：一份精确到克/毫克的单日"营养收入 vs 修复标准"数字对账表，将日常膳食的纸面标称量、三重折损后的细胞真实到账、纽崔莱方案的产品纯利润与临床修复量进行1:1数字化对标，是慢病干预方案中可量化、可追踪、可验证的数据工具。

---

## 🧩 因果 / 原理

**测算基准**：60kg成年人（注：此处的60kg应为**去脂体重**或**理想体重**。如客户超重/肥胖，需先用校正体重法算出基数再套用本表，详见 [[KC-营养-059-蛋白质精准定量三阶梯与去脂体重修正法]]），6平勺植物蛋白粉 + 2包男士组合包 + 6粒新款高纯鱼油 + 1片天然B族 + 1片针叶樱桃VC

**三重折损设定**（与KC-营养-036一致）：
- 速生空心化：-20%
- 高温美拉德AGEs毒化：-30%
- 胃肠消化无能：-20%
- 综合折损：50%~70%

## 🛠 可执行方法

**使用方式**：
1. **方案设计**：用本表精确计算客户每日营养到账，对标修复需求量
2. **客户教育**：将"纸面标称量 vs 真实到账"的差异直观展示给客户
3. **方案调整**：根据客户体重、病情阶段调整剂量，用数字说话

**关键数字结论**（5产品简化版方案）：
- 蛋白质：膳食25~27g + 纽崔莱48g = 73~75g → 精准命中1.2~1.6g/kg修复带
- Omega-3：3.07g → 精准踩中3.0g临床抗炎红线
- 钙：795mg → 精准卡在慢病控钙线（重镁轻钙策略）
- 水飞蓟素：130mg → 临床护肝标准量

**使用铁律**：
- 每次调整方案后，对照本表验证全天总到账是否落入修复标准区间
- 遇到特殊人群（孕妇、胃酸不足、肠漏症），参考KC-营养-037的场景纠偏字典调整剂量
- 数据来源：中国营养学会DRIs 2023、国家卫健委慢病报告、石汉平教授临床营养阶梯

## 📍 场景与边界

**适用场景**：
- 知识库中第三板块（数据字典/落地工具）的精确对标参照表
- 为客户出具个性化营养方案时的数据支撑
- 解决"为什么要吃这么多"的量化说服

**注意事项**：
- 本表基于5产品简化版方案（蛋白粉6勺+男士组合2包+鱼油6粒+B族1片+VC1片）
- 2026年7月前执行的旧版方案（蛋白粉5勺+鱼油10粒+B族3片+钙镁3片+基源欣活2条等）数据不同，应使用KC-营养-037的旧版数据
- 钙镁在简化方案中由男士组合包自带的倍立健提供，无需单独补充钙镁片
- B族从3片减为1片，维C从4片减为1片——部分营养素仍低于修复峰值，属于"够用但不够治"的权衡
