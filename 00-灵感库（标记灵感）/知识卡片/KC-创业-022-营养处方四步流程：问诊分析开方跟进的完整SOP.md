# 营养处方四步流程：从问诊到长客会的完整SOP

> **核心认知**：你不是在卖产品，你是在给客户的健康开"处方"。普通销售推产品，专业顾问诊断需求。

---

## ① 概念（What）

营养处方是一套**把客户的需求挖掘→问题分析→方案建议→持续跟进**标准化的四步流程。核心是让客户自己意识到问题，而不是你告诉他"你缺这个"。

| 步骤 | 名称 | 目标 | 时长 |
|:----:|------|------|:----:|
| ① | 问诊 | 挖出真实需求 | 15-20分钟 |
| ② | 分析 | 帮客户"看见"问题 | 5分钟 |
| ③ | 开方 | 给方案而不是产品 | 5分钟 |
| ④ | 跟进 | 长客会的核心 | 持续 |

---

## ② 拆解（Why）

### 为什么要用"处方"思维，而不是"推销"思维？

| | 普通销售 | 营养专业顾问 |
|--|---------|------------|
| 开口 | "这个产品很好，你试试" | "你最近哪里不舒服？" |
| 方式 | 推销产品 | 诊断需求 |
| 客户感觉 | 她想赚我钱 | 她真的关心我 |
| 结果 | 比价格、犹豫 | 信任、买单、转介绍 |
| 持续性 | 一锤子买卖 | 长客会长期复购 |

### 底层逻辑

```
你帮客户解决一个具体问题
   → 客户信任你
   → 续费长客会
   → 转介绍新客户
   → 有人问"你怎么做的？"
   → 你有了带伙伴的机会
```

营养处方不仅是成交工具，更是**建立信任、筛选伙伴**的起点。

---

## ③ 案例（Example）

### 完整对话示例

**场景**：客户李姐，35岁，外卖多、总觉得累、口腔溃疡反复

**第一步·问诊：**
```
你："姐，你平时睡眠怎么样？"
李姐："不太好，睡醒了还是很累。"
你："肠胃呢？容易胀气吗？"
李姐："对！经常胀气。"
你："口腔溃疡频繁吗？"
李姐："哎你怎么知道？一个月要长两三次。"
```

**第二步·分析：**
```
你："姐，你刚才说总累、睡不好、口腔溃疡反复——
这三个信号放一起，很可能就是B族维生素摄入不够。
不是吃饭没吃饱，是'隐性饥饿'——热量够但微量营养不够。
现在点外卖多的人，十个里有八个都有这个问题。"
李姐："对对对，我就是这样！"
```

**第三步·开方：**
```
你："针对你现在的情况，我建议先从三个基础入手：
1. 早上一勺蛋白粉+全麦面包（补蛋白质缺口）
2. 随餐B族维生素（针对疲劳和口腔溃疡）
3. 晚上一片VC（帮助修复，提高免疫力）
你先试两周，两周后我问问你感觉怎么样。"
```

**第四步·跟进：**
```
第3天："姐，开始吃了吗？有没有什么感觉？"
第7天："怎么样？睡眠有好一点吗？"
第14天：正式回访 + 调整方案/加单
第30天：进入下一个月长客会
```

### 客户说"太贵了"怎么接

```
"姐，一包烟20块，一天一包，一个月600块，伤肺。
一盒B族维生素180块，能吃两个月，一个月才90块。
你少抽几天烟，身体变好了，哪个划算？"
```

## ④ 行动（How）

### 四类客户切入策略

| 客户类型 | 特征 | 切入方式 | 跟进重点 |
|---------|------|---------|---------|
| **亚健康型** | 累、睡不好、精力差 | 从疲劳切入→隐性饥饿概念 | 2周见效果→续长客 |
| **慢病型** | 三高、糖尿病、脂肪肝 | 从体检报告切入→营养干预 | 长期调理+定期复查 |
| **宝妈型** | 关注孩子健康、全家饮食 | 从孩子抵抗力切入→家庭营养 | 全家方案+转介绍妈妈群 |
| **中老年型** | 各种小毛病、怕生病 | 从养生切入→预防大于治疗 | 稳定长客+子女转介绍 |

### 跟进节奏模板

```
├─ 第3天：问候一下，"开始吃了吗？有没有什么感觉？"
├─ 第7天：简单回访，"怎么样？睡眠有好一点吗？"
├─ 第14天：正式回访 + 调整方案/加单
├─ 第30天：复查 + 进入下一个月长客会
└─ 持续：节气的健康提醒、季节调理建议、健康科普推送
```
