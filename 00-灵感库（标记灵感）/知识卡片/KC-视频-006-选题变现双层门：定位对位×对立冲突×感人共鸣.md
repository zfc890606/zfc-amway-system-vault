# 《选题变现双层门 — 定位对位 × 对立冲突 × 感人共鸣》

> **一句话本质**：一条视频爆不爆，选题占 50%；但选题不只决定流量，还决定你**吸引谁、能不能变现**。讨好底层的爆款，爆了也白爆——先过「变现定位对位」（第0门），再打「流量门」（对立冲突 × 感人共鸣 × 稀缺），才是一个完整的选题框架。
>
> **本卡用法**：选题卡壳 / 写脚本前 → 用第0门筛"该不该做这个方向"，再用第1门三件套检查"够不够爆"。已升级进 [[视频号脚本风格系统#🎯 选题决策卡|选题决策卡 v1.32]]（第0关 变现定位对位 + ⑤争议性·对立冲突 + ⑪爆点叠加·感人共鸣）。

---

## 🧩 因果 / 原理

**它解决了什么问题？**
- 原选题决策卡 100% 在打「流量天花板」（能不能爆），但**没看「变现天花板」**（吸引来的人付不付得起钱）——于是会出现"爆了但不变现"的尴尬。
- 博主 60 分案例：「富太太有哪些共同点」——看热闹的人多、付钱的人少，题材有流量但人群不值钱。

**为什么有效？**
- **定位决定内容**：内容不是从"什么火"长出来的，是从"我是谁、我为谁服务"长出来的。高变现定位 → 选题自动长出高客内容。
- **人群是筛出来的，不是碰出来的**：每条选题都在替你筛选粉丝。讨好底层 = 吸引低支付力人群；展示上层稀缺资源与价值观 = 吸引同频高客。
- **高端客户靠价值吸引，不靠流量吸引**：价格敏感人群用"便宜"打动，高客用"价值判断"吸引——所以高客选题要传递"上层稀缺资源和它的价值观"，不是讨好与迎合。
- **对立冲突是天然流量源**：男女/地域/中外/古今/穷富/阶级/婆媳，自带站队与辩论，平台会把"争执"当流量推。

**底层公式：**
```
爆款 × 变现 =（选题 50%）×（定位 + 内容 50%）
   ↑              ↑
 流量天花板     人群付费能力
选题同时决定两件事：爆不爆 + 吸引谁
```

## 🛠 可执行方法

### 最小行动（今天就能做）

拍下一条前，先回答博主式三问：
1. 这条吸引的人，付得起我的客单价吗？（人群付费能力）
2. 它是从"AI营养师·高变现定位"长出来的，还是随手蹭的流量？（定位对位）
3. 它里面有没有对立冲突 + 一个能让人"咯噔一下"的共鸣点？（流量三件套）

三个答不上 → 别拍，先改选题方向。

### 完整执行步骤（接入现有管线「①定选题」）

```
第0门 变现定位对位（一票否决·不过换方向）：
  ① 为谁做？→ 想象这条爆了，涌进来的 10 万粉丝是谁？
      付得起你 1000-5000 客单价的人多，还是来看热闹的人多？
  ② 服务定位吗？→ 它是"AI营养师·高客健康管理"的延伸，还是追热点的杂题？
      （定位 → 选题；没有高变现定位，先定定位再定选题）
  ③ 价值吸引还是流量吸引？→ 高客靠"稀缺资源 + 价值观"吸引，不靠"讨好 + 迎合"

第1门 流量门（三件套·对应选题决策卡打分项）：
  ① 对立冲突 → 题里有没有对立轴？（男女/地域/中外/古今/穷富/阶级/婆媳）
      勾到一个就有流量池；最高形态 = 阶级 + 稀缺资源价值观
  ② 感人共鸣 → 观众看到哪一句会"心里咯噔一下"？戳中哪种情绪？
      （不甘 / 向往 / 被看见 / 替父母心疼 / 替自己不值）
  ③ 稀缺 → 这个观点别处听得到吗？（身份独占 / 海外信息差 / 医生视角）
  三件套全中 → 高天花板；只中一个 → 可拍但要补；一个不中 → 换题
```

### 对立冲突矩阵（第1门①·可勾选）

| 对立轴 | 例子 | 张医生可用 |
|:---:|------|-----------|
| 男女 | 男人 vs 女人怎么想 | 老婆拉我做安利，我一开始是拒绝的（002 已验证） |
| 地域 | 北上广 vs 小县城 | 三甲医院 vs 县城诊所，看病差距在哪 |
| 中外 | 中国 vs 国外 | 国外医生开营养素处方，中国医生不开 |
| 古今 | 老一辈 vs 年轻人 | 老一辈不补营养素，身体反而好？ |
| 穷富 | 穷人 vs 富人 | 富人在为什么健康花钱？穷人在省什么钱 |
| 阶级 | 底层 vs 上层 | 美女只是底层社会的稀缺资源（博主案例） |
| 婆媳 | 两代人冲突 | 给婆婆买营养品，她嫌贵怎么办 |

> **最高形态：阶级 + 稀缺资源价值观** —— "美女只是底层社会的稀缺资源"：一边是阶级对立（天然流量），一边是上层稀缺资源与价值观（价值吸引）→ 流量和变现双收。映射到张医生 = 讲**医生世界的稀缺资源**（会看体检报告 / 懂分子营养 / 5000 台手术底子）和**皇冠大使 / 高客的价值观**（为健康花钱、长期主义、知识付费）。

### 张医生落地：把"上层稀缺资源"映射到 AI营养师定位

| 讨好底层（❌ 流量可能爆、变现弱） | 展示上层稀缺资源与价值观（✅ 同频高客） |
|------|------|
| 穷人不该乱买营养素 | 有钱人为什么都在补营养素？（富人在为什么花钱） |
| 便宜的药店钙片就行 | 三甲医生家庭，餐桌上的营养账本 |
| 安利是普通人翻身的机会 | 我服务的高客妈妈们，都在做同一件事 |
| 别交智商税 | 会看体检报告的人，看病少花冤枉钱 |

> **改造口诀：把"穷省钱"视角换成"富选价值"视角。** 同一件事，用底层视角是讨好，用上层视角是价值吸引。

## 📍 场景与边界

### 适用场景
- **写脚本前定方向**：先用第0门确认"为谁做"，避免拍一个"爆了也不变现"的题。
- **选题打分时**：第0门 = 一票否决前置；第1门三件套 = 现有 8 分打分项的快速检查（对立冲突 → 争议性/爆点叠加，感人 → 爆点叠加·感人共鸣，稀缺 → 人群宽度/身份独占）。
- **定位复盘时**：发现自己选题全在"讨好底层" → 停下来，先修定位再修选题。

### 边界条件
- **第0门不是流量杀手**：变现定位对位是"方向筛"，不是"数据筛"。方向对了但流量分不够 → 回选题决策卡打 8 分。
- **对立冲突 ≠ 挑事**：要的是"天然立场"带来的流量，不是违规对立。涉及医疗/地域/男女的敏感对立 → 过医疗合规 + 星光违规解密（0b / 0c）。
- **"上层稀缺资源"不能炫耀/炫富**：合规用"高客的生活方式 / 医生的稀缺技能"表达，不出现收入数字（星光违规解密：收入承诺红线）。
- **先有定位，再有选题**：如果还没有清晰的"高变现定位"，第0门会一直卡——先去定定位（见 [[05-Skills（技能sop）/短视频方法库/短视频系统/知识库/小红书商业定位|小红书商业定位]]），再回头选题。
- **现状反差提醒**：张医生现有选题库大量走"避坑 / 省钱 / 智商税"（底层视角）——这些题涨粉好用，但按博主框架属于"讨好底层"。变现线要逐步加"上层稀缺资源价值观"视角的题（双线交替：涨粉线留底层视角，变现线加高客视角）。
