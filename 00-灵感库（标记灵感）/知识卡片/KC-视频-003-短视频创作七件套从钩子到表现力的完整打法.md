# 《短视频创作七件套——从钩子到表现力的完整打法》

> **一句话本质**：短视频创作不是玄学，是一套可复制的七件套——开头钩子 → 反差人设 → 高频痛点选题 → 结构 → 语言 → 反转+权威背书 → 表现力，再加一个固定结尾钩子。

---

## 🧩 因果 / 原理

**它解决了什么问题？**
- 普通人拍短视频"不知道从哪下手"、各环节零散、凭感觉创作
- 会写内容但没人看，会拍但留不住人——缺的是全链路的方法
- 每次给伙伴点评都陷在细节里，缺一把统一的标尺

**为什么有效？**
- 七件套覆盖一条视频从"被看到"到"被记住"再到"被信任"的全链路
- 每一件都对应一个观众心理环节：
  - 开头钩子 → 让他停下
  - 反差人设 → 让他记住你是谁
  - 高频痛点选题 → 让他觉得"说的就是我"
  - 结构 → 让他听得懂
  - 语言 → 让他听得下去
  - 反转+背书 → 让他觉得你专业
  - 表现力 → 让他觉得你在跟他说话

---

## 🛠 可执行方法

### 七件套清单

| # | 环节 | 核心动作 | 要点 |
|:-:|------|---------|------|
| 1 | **开头：九大人性钩子** | 视觉 / 赚钱 / 恐惧 / 愤怒 / 八卦 / 猎奇 / 高价值 / 炫富 / 热点 | 3秒内亮出一个钩子 |
| 2 | **人设：反差性人设** | 开头3秒亮身份 | 医生 / 博士 / 恒大 / 差点挂墙上的经历 |
| 3 | **选题：高频痛点** | 评论区是"江湖" | 锁定渠道 → 提取问题排行榜 → 评论区挖案例 |
| 4 | **结构** | 痛点 → 方案 → 步骤 → 总结 | 一条一题，别贪多 |
| 5 | **语言** | 土 + 比喻 + 重复锤 + 反问逼问 | 不高大上、不说教、不端着 |
| 6 | **反转 + 权威背书** | 每篇一个反常识；背书体现专业 | 为转化铺路，让 IP 值钱 |
| 7 | **表现力** | 像朋友聊天 | 自然放松，不是讲师式输出 |

**结尾固定钩子**：关注我，分享更多有价值的内容。

### 最小行动（今天就能做）
下一条视频先只改两处：**开头换成一个"赚钱/恐惧"钩子** + **结尾加固定钩子**。

### 完整执行步骤（写一条视频）
1. 从九大人性钩子里选一个做开头
2. 3秒内亮身份（反差人设）
3. 选题锁定一个高频痛点（评论区挖）
4. 按"痛点→方案→步骤→总结"搭结构
5. 用大白话+比喻写，重复锤+反问逼问
6. 中间埋一个反常识 + 加权威背书
7. 像跟朋友聊天一样讲出来

---

## 📍 场景与边界

### 适用场景
- 任何口播类短视频的创作与点评
- 给团队伙伴统一"什么叫一条好视频"的标尺

### 边界条件
- **纯录屏操作类**（AI工具演示）不完全适用，可只取"选题+结构+结尾钩子"
- 常见失败原因：七件套样样都会但选题不痛 → 选题是根，其他是枝叶
- 前提：先明确这条视频的受众和目的（涨粉/互动/完播/转化）
