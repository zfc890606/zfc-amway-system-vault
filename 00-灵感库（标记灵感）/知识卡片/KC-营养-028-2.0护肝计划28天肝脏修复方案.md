# KC-营养-028-2.0护肝计划28天肝脏修复方案

> **一句话本质**：肝脏是唯一的"无痛觉"器官，等它有感觉时已经损伤了。2.0护肝计划用VC+VB+善衡片+蛋白粉四重营养，配合"养肝餐→7-9点护肝→11点半前深睡眠"的28天节奏，给肝脏做一次系统性修复。

---

## 🧩 因果 / 原理

**肝脏的重要性：**
- 全球乙肝人数2.57亿，中国超1亿
- 肝脏是人体最大的代谢器官，没有痛觉神经——等你有感觉时已经严重了
- 肝损伤的常见原因：不良生活习惯（熬夜、饮酒）、药物损伤、毒素累积、病毒感染

**护肝四重营养修复方案：**

| 营养素 | 作用机制 |
|--------|---------|
| 维生素C | 强力抗氧化，帮助肝脏解毒，清除自由基，针对化学性肝损伤 |
| 维生素B族 | 提高肝的代谢能力，应对不良生活习惯引起的肝损伤 |
| 养脏善衡片（白芍甘草） | 滋养肝血，调理肝脏功能，应对各类损伤 |
| 蛋白质粉 | 肝脏修复的氨基酸原材料，促进肝细胞再生，恢复肝脏功能 |

---

## 🛠 可执行方法

### 28天养肝计划执行流程

**第一步：晚餐吃养肝餐（17:00-19:00）**
- 少吃或不吃肉
- 多吃蔬菜（水果少吃）
- 可吃鸡蛋
- 七分饱

**第二步：护肝计划（19:00-21:00）**
- VC（助解毒）
- VB（提高代谢能力）
- 善衡片（滋养肝血）
- 蛋白粉（修复原料）

**第三步：11点半前睡觉（21:00-23:30）**
- 睡前放松，不刷手机
- 11:30前入睡
- 12:00进入深睡眠（启动肝脏的自我修复机制）

**持续28天为一个周期**

## 📍 场景与边界

- **适用场景**：有肝损伤风险人群（熬夜、饮酒、脂肪肝、乙肝携带者）
- **目标人群**：肝功能指标异常者、脂肪肝患者、经常熬夜/应酬的人群
- **禁忌提醒**：
  - 营养辅助修复，非替代治疗
  - 严重肝病患者需遵医嘱
  - 护肝期间注意饮食清淡
  - 保持规律作息，避免熬夜
