# 《骨干突破训练法：卡点→目标→网络分析→OKR》

> **一句话本质**：团队突破业绩不是靠一场课、一次动员，而是一条"训练闭环"：先认清卡点（目标=突破自己的卡点）→ 目标分解到网络分析 → 落到OKR（3-5件具体事）→ 全程用"粘性（仁爱）+历史记录（数据）"支撑。连续破三道卡点，自信就来了。

---

## 🧩 因果 / 原理

**它解决了什么问题？**
很多骨干"定了目标等于没定"：网络图一画、50/50/100一填，凑够分数就完事，月底照样完不成。根因是**没走完整条训练链**——卡点没找对、粘性没有、OKR没落到事、数据没记录。

**为什么有效？**
林老师的闭环把"玄学式带团队"变成"训练式带团队"：

```
① 认清卡点（先自己，后团队）
   │  目标 = 突破卡点；连破三道 → 自信就来
   ▼
② 目标分解 → 网络分析（画网络图，把分摊到每个人）
   │  前提：粘性（你爱他们、见过30次），否则分解不下去
   ▼
③ OKR（把每个分数变成3-5件具体事：喝茶/讲单/约体检）
   │  分数是抽象的，OKR 让每个人知道"这个月具体做什么"
   ▼
④ 历史记录（每个出分点、每个顾客都要记，用数据说话）
   │  AI 时代把Excel扔给AI：谁最积极？最值得跟进谁？
   ▼
⑤ 定能生慧（每月拿一天，放下手机，静下来做 OKR）
```

**底层逻辑**：
- 卡点是"能力+心态"的卡点，不是数字——"你真正能拿起多重的杠铃"。
- 粘性来自爱："人是一切的起点，第二个是仁爱，后边才是致富。"
- 30次法则：跟进见30次之前别说结束——它是粘性的量化标准。
- 记录历史：医生天天写病历，做安利也要记——"一个人不会突然爆发，他总有规律"。

## 🛠 可执行方法

### 最小行动（今天就能做）
**画一张你的个人网络图**，然后只问自己一个问题：**"去掉小组、去掉龙卷风，我自己一个人能做出多少分？"**——这就是你的卡点。

### 完整执行步骤
1. **认清卡点**：先对外找团队卡点（如团队1万分是卡点）→ 再对内找自己卡点（你个人能产生多少、能带多少）。卡点在自己身上，不在别人身上（"我上不了是因为姓徐不努力"= 得不了冠军怪别人跑得快）。
2. **定目标**：目标 = 突破卡点，且优先突破自己的。目标要"拍桌子"定下来（"我今年非上不可"这个动作）。
3. **目标分解+网络分析**：画出网络图，把目标分摊到每个人（50/50/100，不够加到60/70）。**前提是粘性**——先跟人建立关系（吃饭/喝茶/见30次），否则分配是空中楼阁。
4. **落成OKR**：对每个分摊的分数/项目，写出3-5件具体的事（O=目标，KR=要做的几件事，不超过5件）。"你那个朋友我不认识，答案在现场，你去做。"
5. **做历史记录**：每个出分点、每个顾客的用货记录都记下来；有AI就把Excel扔进去，让它列出"最值得跟进的TOP10"。
6. **每月一次静心OKR**：拿一天时间，把手机放家里，到公共书屋封闭自己，做下月OKR——"定能生慧，勤能补拙"。

### 关键心法（训练时要反复强调）
- **改变自己，影响别人**；想改变别人，最终影响的是自己。
- **为每一个成功喝彩**：秀云姐卡点是100分（没钱、靠销售），就鼓励她50分、50分地上，点滴成塔。
- **不抱怨**：领导人就是"领着一群不动的人做"还能拉出9%的人；你锁定一个人，3个月到半年让他上。

## 📍 场景与边界

### 适用场景
- 骨干定了目标总完不成 → 走完整条链，别只填数字
- 团队分解不下去 → 先补粘性（见过30次吗？），再谈分配
- 新财年/26个月目标要落地 → 用"卡点→目标→网络→OKR"逐层落
- 想用AI管团队数据 → 用"历史记录+AI筛选TOP10"启动

### 边界条件
- ⚠️ 卡点不是回避的借口：正视它、突破它才是卡点；回避它，就什么都不用做。
- ⚠️ 网络分析缺粘性就是骗自己——先解决"爱与了解"，再解决"分数分配"。
- ⚠️ OKR不能超过5件（最好3件）：贪多等于没有。
- ⚠️ 30次法则的前提是"你是好人、不带目的"。

### 常见失败原因
- 只做"目标分解"一步，不做OKR → 分数落不了地
- 光分解别人、不分解自己 → 自己没卡点意识
- 不做历史记录 → 一切都是"感觉"，没有规律可循
- 每月不静心 → 被信息淹没，内在智慧出不来
