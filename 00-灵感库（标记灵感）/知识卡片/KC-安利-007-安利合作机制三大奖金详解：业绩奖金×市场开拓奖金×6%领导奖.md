# KC-安利-007-安利合作机制三大奖金详解：业绩奖金×市场开拓奖金×6%领导奖

> **一句话本质**：安利合作只需两个条件（70元 + 22岁以上），靠三大奖金机制运转——业绩奖金（自己做）、市场开拓奖金（带团队做）、6%领导奖（不做也有）；算账逻辑保证公平：多劳多得、可超越、非零和、助人自助。

---

## 🧩 因果 / 原理

### 合作条件（低到人人可入场）

```
① 年满22岁（学生不能办卡）
② 70元办卡
= 不要求囤货、没有业绩要求、月月自由（做0也不开除）
```

### 三大奖金机制

```mermaid
flowchart LR
    A[业绩奖金 自己做] --> B[市场开拓奖金 带团队做]
    B --> C[6%领导奖 不做也有]
```

| 奖金 | 怎么算 | 关键点 |
|:---|:---|:---|
| **业绩奖金** | 自己卡上营业额 × 比例表（3%~21%，按档位） | 例：6000×3%=180；6万×15%=9000；另加6%电子券 |
| **市场开拓奖金** | 整个部门业绩比例 − 各小部门拨出比例（差额归你） | 例：带4人各6000→总3万×12%−4×6000×3%≈2880（含自己180） |
| **6%领导奖** | 培养出12.5万以上稳定市场，公司额外给市场6% | 例：12.5万×6%=7500/月，**你不做也有** |

### 7人算账案例（讲公平的黄金故事）

```
陈总市场最大(7个6000)  → 拿 720
张医生(自己6000+带1人) → 拿 720
你(自己6000+带4人)     → 拿 2880
4个新人各6000          → 各拿 180
```

> 结论：**市场最大的人，收入不一定最高**；奖金先拨给后面部门（不能少别人的钱），剩下才是你的——系统只看劳动量。

### 为什么说公平=可复制

| 维度 | 传统行业 | 安利 |
|:---|:---|:---|
| 分配 | 零和博弈·分蛋糕 | 非零和·共同做大 |
| 晋升 | 位置只有1个·争破头 | 无人数限制·做到就有 |
| 超越 | 按资排辈·调政策 | 后加入可超越 |
| 收入 | 与上位者绑定 | 与公司签约·自己做主 |

> 核心秘密：**助人自助**——你要赚更多钱，必须先帮伙伴赚到钱；他们拿不到钱，你的差额就没了。

### 收入阶梯（市场=资产）

```
1个12.5万市场(DD)   ≈ 年薪30-40万 · 不做还有
3个市场(营销经理)    ≈ 年薪过百万
6个市场(钻石)       ≈ 年薪200万+
20个市场(FC皇冠大使) ≈ 年薪过千万
```

## 🛠 可执行方法

### 讲制度的"算账三步"

1. **先讲合作门槛**：70元+22岁，人人可为——对比传统合作（如红牛代理要300万）
2. **再算业绩奖金**：3个客户×2000/月=6000→180；30个客户=6万→9000，收入肉眼可见
3. **再算团队奖金**：带4个"不会干"的新人各做6000，你拿2880——做大的路径是"开分店"不是"自己干更多"

### 长客会折扣（转化顾客的算账）

- 长客会积分：5分=1元，前6个月算积分 → 约**5-6折**
- 加上市场比例叠加 → 最终可到**约3.5折**——用折扣讲通"为什么要签长客会"

### 常见提问话术

- "安利是不是传销？" → 用7人算账案例讲公平 + 先发后面部门的钱（谁都不被辜负）
- "我做不好怎么办？" → 做0也没有损失，自由企业；做了是自己的，不做跟前面的人无关
- "怎么超越领导？" → 收入只取决于你的市场劳动量，不受上位者干扰

## 📍 场景与边界

**适用场景：**
- OPP/新人制度培训（算账式讲解）
- 回应"公平不公平/能不能超越/是不是零和"质疑
- 带团队前先让伙伴看懂收入模型

**注意事项：**
- 制度讲"案例+算账"，不讲复杂比例表（有9种12项，只讲三大奖足够）
- 重点突出"6%领导奖=资产收入"和"先发后面的钱=公平"
- 奖金数字是示例教学，实际按公司当期制度为准
