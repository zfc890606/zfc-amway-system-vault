# KC-创业-017-内容结构工具箱：算账说服与三层递进

> **一句话本质**：自媒体教练最可复用的三个内容结构——算账式说服、四句话签约法、三层递进说服——本质都是"先让他自己得出结论，而不是你告诉他答案"。

---

## 🧩 因果 / 原理

### 为什么这些结构有效

好的内容结构不是"教观众怎么做"，而是"让观众自己推导出结论"。三个结构共享同一个底层逻辑：

```
算账式说服 → 给公式→代入算→揭缺口 → 观众自己发现"我真的缺了"
四句话签约法 → 认同→换认知→给证据→降门槛 → 客户自己说"那试试"
三层递进说服 → 病因→机制→方案 → 观众自己觉得"必须行动了"
```

**核心原则：不要告诉他答案，让他自己算出答案。**

---

## 🛠 可执行方法

### 结构一：算账式说服（已吸收）

适用场景：需要让观众自我诊断的内容（健康类/收入类）

**三步走：**
```
第1步：抛公式
  "每天的蛋白质需要 = 体重(kg) × 1.22g"
  
第2步：代入算
  "60kg的人一天需要73g蛋白质"
  "早餐10g + 午餐15g + 晚餐20g = 45g"

第3步：揭缺口
  "每天差28g，一年365天都在缺"
  "你的细胞拿什么修自己？"
```

### 结构二：四句话签约法

适用场景：教成交类脚本/一对一沟通

| 句 | 功能 | 设计原理 |
|:--:|:---|:--------|
| 第1句 | 戳痛点 | 替他说出心里的抗拒 |
| 第2句 | 换认知 | 把"花钱"重新定义为"投资" |
| 第3句 | 讲故事 | 用"跟他差不多的人"的案例建立信任 |
| 第4句 | 造紧迫+降门槛 | 降低门槛让他说"试试" |

### 结构三：三层递进说服

适用场景：解释复杂概念/改变认知的科普类脚本

```
第1层：病因诊断 — "你为什么会这样？"
第2层：机制解释 — "为什么会发生在你身上？"
第3层：方案+行动 — "那怎么办？"
```

**示例（隐性饥饿主题）：**
```
第1层："你一日三餐没少吃，为什么还是缺营养？"
第2层："因为你吃进去的是碳水，细胞需要的是蛋白质和维生素"
第3层："先把三个最基础的补齐——蛋白粉、维C、男士组合"
```

## 📍 场景与边界

**结构选择指南：**

| 内容类型 | 推荐结构 | 原因 |
|:--------|:--------|:----|
| 健康科普（解释概念） | 三层递进 | 先让观众理解问题，再给方案 |
| 健康算账（痛点唤醒） | 算账式说服 | 让观众自己算出缺口 |
| 教成交（销售类） | 四句话签约 | 明确的成交引导路径 |
| 创业共鸣 | 三层递进 | 先共情痛点，再给解法 |

**注意事项：**
- 不要在一个内容里混用多个结构（会让观众困惑）
- 算账式说服和三层递进可以嵌套使用（算账作为三层中的某一层）
- 四句话签约法仅用于"教成交"类脚本，不适合公域短视频
