# KC-创业-019 · 项目打分模型：70分以下不做的决策框架

> **一句话**：用100分打分表评估任何项目/方向，70分以下直接不做，85分以上才加码——把有限的精力押在胜率最高的事上。

---

## 📌 是什么（What）

一个简单但极其有效的 **项目决策工具**：

| 维度 | 分值 | 细分项（各子项5-10分） |
|:----|:----:|:---------------------|
| **流量** | 30 | 触达面(10) / 点击率(10) / 进线率(10) |
| **运营** | 30 | 私域沉淀(10) / 活跃留存(10) / 复购转介绍(10) |
| **产品/服务** | 30 | 口碑(10) / 毛利与交付成本(10) / 标准化扩展性(10) |
| **主观判断** | 10 | 风险可控(5) / 心力与时间匹配(5) |
| **总分** | **100** | |

### 决策规则

| 分数区间 | 决策 |
|:--------:|:----|
| **≥85分** | ✅ 加码投入，集中资源打穿 |
| **70-84分** | 🔄 小步快跑，先小单试错再放大 |
| **<70分** | ❌ 不做，或立刻止损 |

---

## 🧠 为什么重要（Why）

**选择比努力更重要，商业模式比个人能力更重要。**

做安利最怕的不是"不努力"，而是**把时间花在了胜率低的项目上**：
- 这个选题值不值得拍？→ 打分
- 这个人值不值得培养？→ 打分
- 这个方向值不值得试？→ 打分
- 这场活动值不值得搞？→ 打分

**70分以下不做 = 把"不做什么"定得比"做什么"更清晰。**

---

## ⚙️ 怎么用（How）

### 应用场景①：评估短视频选题

| 评估项 | 问题 | 打分 |
|:------|:----|:----:|
| 触达面 | 这个话题你的目标人群感不感兴趣？ | /10 |
| 点击率 | 开头钩子够不够强？能不能让人停下来？ | /10 |
| 进线率 | 看完会不会想私信/评论？ | /10 |
| 私域沉淀 | 这条能引流到私域吗？ | /10 |
| 复购价值 | 这个话题能引出后续内容吗？ | /10 |
| **总计** | | **/50（折算到100分制）** |

### 应用场景②：评估带团队对象

| 评估项 | 问题 | 打分 |
|:------|:----|:----:|
| 意愿 | 他有没有"想要"的状态？ | /25 |
| 行动力 | 说了会不会去做？ | /25 |
| 学习力 | 教了能不能吸收？ | /25 |
| 配合度 | 愿不愿意按系统走？ | /25 |
| **总计** | **<70分先不重点培养** | **/100** |

### 应用场景③：评估一个新方向/产品

直接用100分打分表跑一遍，<70分不做。

---

## 📐 核心公式

```
商业 = 概率 × 效率
        
概率 = 选对方向（70分门槛）
效率 = 流程化 + 模板化 + 自动化（AI杠杆）
```

**先做"胜率工程"**：选对人群与内容结构，别和头部硬拼资源
**再做"效率工程"**：流程化、模板化、自动化
