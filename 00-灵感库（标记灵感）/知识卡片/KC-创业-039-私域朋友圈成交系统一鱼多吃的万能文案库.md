# 《私域朋友圈成交系统——AIDA×信任公式×6种文案，一鱼多吃》

> **一句话本质**：朋友圈不是随便发的日记，而是一套「底层逻辑（AIDA/3S/信任公式）× 6种文案类型 × 一鱼多吃」的私域成交系统——每条朋友圈同时是短视频脚本、直播间主题，用价值观圈降低推销感，让客户因为认可你这个人而买单。

---

## 🧩 因果 / 原理

**它解决了什么问题？**
- 朋友圈发了没转化、像广告、被屏蔽
- 不知道发什么、怎么排期、内容生产太累
- 私域有好友但不会经营，白白浪费信任资产

**为什么有效？**
- **信任公式**：信任 =（专业度 × 可信度 × 亲密度）/ 自我推销感 —— 硬广越多，信任越低；价值吸引代替强行推销
- **6种文案类型**覆盖成交全链路：悬念钩子（打开率）→ 痛点共鸣（互动）→ 价值干货（信任）→ 客户证言（说服）→ 限时福利（转化）→ 人设故事（亲和）
- **一鱼多吃**：一条内容 = 朋友圈 + 短视频脚本 + 直播主题，三处复用，内容生产成本趋近于零
- **价值观圈**：人们购买产品不是因为产品好，而是因为喜欢你、认可你的价值观——弱化装逼/营销感

```
信任 = (专业度 × 可信度 × 亲密度) / 自我推销感
```

---

## 🛠 可执行方法

### 最小行动
从明天起每天发 **3条朋友圈**（早中晚），按「价值干货类 + 人设故事类 + 客户证言类」各一条打底；每条发圈前过一遍信任公式——推销感重就改写成价值表达。

### 完整执行步骤
1. **底层心法**：先记牢信任公式，所有文案先过"推销感"这一关
2. **六类文案轮转**：
   - 悬念钩子 → 数字冲突 / 反常识 / 结果前置
   - 痛点共鸣 → 场景化痛点 + 对比法（"我的学员本来抱着…，结果…"）
   - 价值干货 → 钩子-痛点-方案 / 清单体（可列纯干货，不用太深）
   - 客户证言 → 聊天记录+结果展示 / 对比案例（社会认同）
   - 限时福利 → 倒计时+名额限制 / 赠品诱惑
   - 人设故事 → 个人故事 / 连续剧（恋爱结婚生子创业）/ 价值观输出
3. **发布节奏**：每天≥3条，早中晚；**22:30后曝光率最高**
4. **视觉装修**：高清有信息量的配图（对比图/数据图/客户截图）；15-60秒短视频；短文案6行内、核心放前3行；用【】●→符号排版；头图表明关键信息、巧用置顶
5. **快速生产4法**：语音转文字（灵感立刻说、一气呵成再整理）/ 卡片收集法（关键词收集→提炼唯一主线→重组填肉）/ 配图摘取法（从配图文字片段做延展）/ 多角度表达（一件事10个角度，锻炼基本功）
6. **一鱼多吃**：每次发圈都问"这条能剪成短视频吗？能当直播主题吗？"——能，就三处复用

---

## 📍 场景与边界

### 适用场景
- 私域成交、朋友圈转化（安利顾客/伙伴经营）
- 带教团队伙伴："每天发圈 = 每天生产内容资产"
- 内容系统的素材车间（喂给短视频和直播）

### 边界条件
- **前提是真实**：价值观圈最忌讳装逼被看穿——必须有真实的选择和故事支撑
- **有交付托底**：人设和证言要对应真实交付，别只收钱不交付（口碑会塌）
- **因人设适配**：文案模板要换到自己的人设和领域，不能硬套
- 客户证言涉及他人隐私/收款截图，注意合规与授权
