# KC-认知-013 AI导师法：三步让经典智慧为你所用

> **一句话本质**：AI不是替代你干活的工具，是能24小时贴身陪伴你的私人导师——它了解你的真实情况，链接人类经典智慧，在你做每个决策时指出你看不到的盲区和误区。

---

## 🧩 因果 / 原理

### 它解决了什么问题？

大多数人用AI只停留在"帮我干活"的层面：写文章、做视频、生成图片。这就像你遇到了一个绝世高手，却只让他帮你搬砖。**真正的价值被浪费了**。

更深层的问题是：
- **没有人指点你** — 你做错了没人告诉你，你走在错误的方向上没人拉你一把
- **你不知道你不知道** — 你看不到自己的盲区，在错误的方向上拼命努力
- **经典智慧摸不着** — 书买了没看，看了记不住，记住了用不上

### 为什么有效？

这套方法借用了三个底层机制：

**① 上下文累积效应** — AI是唯一能"记住你"的工具。你每天分享工作心得，AI对你的认知越来越深。它知道你擅长什么、卡在哪、目标是什么。这种持续的上下文累积，让AI能给出真正个性化的建议——这是任何真人导师都做不到的（真人不可能24小时记住你的一切）。

**② 经典智慧×个人场景的链接** — 人类经典的真正价值不是"知识"，是"经验压缩包"。穷查理宝典浓缩了芒格几十年的决策经验，纳瓦尔宝典浓缩了纳瓦尔的财富认知。但普通人读书最大的问题是"读的时候觉得有道理，放下就忘了"。AI能把这些经验压缩包**解压到你当前的具体场景**——因为它知道你正在面对什么。

**③ 无压力的高频反馈** — 真人导师你不好意思天天问，问多了怕烦。AI没有这个问题。你每天都可以"被指点"，而且不会感到尴尬或负担。这种高频反馈的累积效果是一年下来翻天覆地的。

## 🛠 可执行方法

### 最小行动（今天就能做）

打开你最常用的AI（Claude/ChatGPT/Kimi），说一句话：**"我接下来每天会跟你分享我的工作心得，请你帮我记住，以后基于这些信息给我建议。"** 然后今天做完事后，写50字发给它。

### 完整执行步骤

#### 第一步：让AI了解你（日常喂养）

```
频率：每天
动作：分享今天的工作/心得
内容模板：
  - 今天我做了什么：[具体事情]
  - 我是怎么做的：[过程描述]
  - 我遇到了什么卡点：[真实困难]
  - 我的想法是什么：[你的判断]
  - 我的目标是什么：[短期/长期目标]
关键原则：不要美化，越真实越好。AI不是人，不会评判你。
保存方式：放在同一个对话/目录下，让AI保持上下文。
```

> **为什么这步最重要？** 大多数人说AI"没用"，是因为AI不了解他们。你让一个不了解你的人给建议，当然没用。先让AI认识你。

#### 第二步：让AI链接经典（找盲区）

```
找什么：真正经典的书/文章/演讲/访谈
  - 《穷查理宝典》
  - 《纳瓦尔宝典》
  - 你认可领域的大师访谈/文章

怎么做（核心操作）：
  ✅ 正确做法：说"我现在要做XX决策/我当前遇到YY问题，请你根据我的情况，
     去那些经典里找我的盲区和误区"
  ❌ 错误做法：说"帮我总结这本书讲了什么"

为什么？让AI帮你读书=浪费。让AI根据你的情况去找书里的对应=价值连城。
因为最值钱的不是书里的知识，而是"这个知识怎么用在你身上"。
```

#### 第三步：让AI给出行动（落地执行）

```
让AI继续深入：
  ① 这个盲区/误区原本的意思是什么？
  ② 提出这个观点的先贤当时的场景和案例是什么？
  ③ 你现在是怎么做的？
  ④ 你们之间的连接是什么？
  ⑤ 你应该做出什么样的改变？
  → 一二三四步，给出可执行的步骤

注意：不是完全相信，是参考。相当于你每次做事时，
有一些先贤在旁边说"这可能有问题，你看看"。
```

## 📍 场景与边界

### 适用场景

| 场景 | 说明 |
|------|------|
| **做决策前** | 面对重要决策拿不准→让AI链接经典帮你思考 |
| **复盘时** | 回顾过去做的事→让AI指出盲区 |
| **学新东西** | 学完一个知识→让AI根据你的场景解释怎么用 |
| **每周规划** | 设定下周目标→让AI检查是否符合经典智慧 |
| **写脚本前** | 想选题→让AI帮你测试观点是否站得住 |

### 边界条件

- **什么时候不适用？**
  - AI不了解你的时候（至少需要3-5天的日常喂养才能建立有效认知）
  - 需要实时决策的紧急情况（AI不是即时工具，需要你给它完整上下文）
  - AI幻觉风险（AI可能编造经典中的内容，关键引用需交叉验证）

- **常见失败原因？**
  - 第一天就指望AI给出好建议（没有喂养，AI不了解你）
  - 让AI帮你总结书而不是根据你的情况去找链接
  - 不真实/美化自己的情况（AI基于错误信息给出错误建议）

- **需要什么前提条件？**
  - 一个能保持上下文的AI工具（Claude Projects / ChatGPT记忆功能）
  - 每天5-10分钟的分享习惯
  - 对经典内容的甄别能力（知道什么是真正的经典）
