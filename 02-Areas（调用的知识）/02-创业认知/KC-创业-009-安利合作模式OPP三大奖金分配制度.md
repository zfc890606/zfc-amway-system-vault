# 安利合作模式：OPP大奖与分配制度（核心）

> 一句话：**跟安利合作只需"70元 + 年满22岁"，你是自己的老板、跟公司直接签约；三大奖金（业绩奖金·市场开拓奖金·6%领导奖金）算的是公平账——多劳多得、可超越、助人自助、非零和。**

## 一、为什么借安利这个平台

- **供应商支持**：纽崔莱93年稳定靠谱、商誉无风险（品牌倒了白干+产品出事人品都没了）。
- **人才体系支持**：伙伴办卡挂你后面，开分店不用你发工资、不用你算税，公司直接给各人发钱——你只管获客+带人才。
- **做大逻辑**：一年1000万营业额，一个人干不动；找100个人每人干10万，就轻松做大。

## 二、合作条件（人人可为）

- 两个条件仅此而已：**① 年满22岁**（学生不推荐办卡，守国家法律）＋ **② 70元办卡**。
- **不要求囤货、无最低业绩要求、无加入费**。对比：传统品牌合作要你有300万、交2-3万加入费。
- 你是自己的经销商、跟**公司**签约，不是跟你的上司签约、不从他拿货。

## 三、三大奖金机制（核心案例讲解）

> 背景假设：一个陪跑方案约2000元/月，你一个月找3个客户→你的卡 6000元营业额。

### 1️⃣ 业绩奖金（自己做的钱）
- 按营业额月结比率：6000 → 3% = **180元**（另有6%电子券，可用作买东西）。
- 做30个客户（6万营业额）→ 15% = **9000元**。
- **自由**：这个月干0就0，不会被开除——没有最低业绩、不要求囤货，自己是老板。

### 2️⃣ 市场开拓奖金（带团队的钱 · 做大关键）
- 你只做6000，再带 A/B/C/D 四人也各自做6000（你教会他们找客户，这6000是他们自己做的、他们的市场）。
- **整个部门 5×6000 = 30000** → 部门奖金 12% = 3600，先发后面（每人180×4=720）+ 你自己的180 → **你拿 2880**（含180业绩奖 + 2700市场开拓奖）。
- **颠覆性案例**（算明账，7个人收入一目了然）：
  - 陈总市场最大（你上面上线的上线），自己没再多干活 → **720 元**；
  - 你同样带团队 → **2880 元**；
  - 4个新人各干6000 → **180 元**。
  - **市场最大的人收入不一定最高**（传统主任收入最高、翻自己系数，这里不是）。
  - 陈总这个月躺平干0 → 拨完后面部门的钱后自己**0元**。"钱先发后面的部门，谁都不被辜负。"——**先算后面的人，确保每个人努力不被辜负。**
- **公平三维度**：
  - **多劳多得**：你拿2880因为你付出了4份劳动（带4个人）；我只带了一个就只付1份。
  - **可超越**：我加入比陈总晚，能力上来就能超越——传统生意你要超越得看领导调政策，这里做不到，大家都参照同一张表、没有例外。
  - **助人自助**：你不帮 A/B/C/D，他们都做0，你做6000还是180；你帮他们赚到钱，你的收入才上来——**帮人不是利用人**。
- **非零和**：传统是分蛋糕（你多他少、争一个主任位）；这里每个人独立跟公司签约，做多少拿多少，**主任没有个数限制，做到就是你，一万个主任都有**。人跟人合作和谐、没有利益冲突。

### 3️⃣ 6%领导奖金（资产保障 · 关键奖金）
- 当你带的人中有人把市场做到 **12万5**（你可能是5-6000），你就升到21%封顶，随即面临"没差额、没动力教他了"。
- 公司额外奖励：**该市场 12万5 × 6% = 7500元/月** 单独给你，不影响他收入，认可你培养人才的价值。
- **保障 = 不做还有**：市场稳健后停下来也有钱——像"一栋5层的房子月租7500"，而买这栋房要300万；做到一组市场不到一年即可。
- 收入阶梯（月）：
  | 达标 | 收入 |
  |---|---|
  | 1组稳定12万5（DD） | 平均30万/年（Q12DD约30万），不做还有 |
  | 3个DD市场（营销经理） | 年薪过百万（3条线不做还有） |
  | 6个DD市场（钻石） | 年薪200万+ |
  | 20个DD市场（FC） | 年收入过千万 |

## 四、龙卷风商业模式（独有打法 · 人脉众筹）

- **定义**：办卡本就挂某位上线后面；龙卷风=**人脉众筹、对等合作、共同发展**——张、博士、蓝娟、杨哥几人人脉凑到同一条线上。
- 人人都做"一得五"：把各自的人放你后面，市场共用、**各自独立算钱**，市场涨得飞快。
- **目标与节奏**：一人选一个主市场卷到21%→第一条线（目标12万5）→再找三五人卷第二线→第三线。
- **三年百万年薪**：一年卷一条线、三年卷三条线 = 营销经理百万年薪（林伟博士/华工系统独创，统计学设计"为什么是三条、每人贡献三个人脉"）。
- 附加：公司还有**海外旅游**福利（张医生已去过多个国家，带爸爸免费去）。

## 五、市场空间（为什么是大事业）

- **1000万人办过卡，真正做的只有1%（约10万人）**；中国14亿人口，市场远没开始。
- 全球100多个国家和地区都有，奖金制度、纽崔莱全球统一、健康相通；有海外朋友可做国际市场。

## 六、金句

- "安利的公平，是算账算出来的——市场最大的人，收入不一定最高。"
- "先发后面部门的钱，谁都不被辜负。"
- "帮人自助，不是利用人。"
- "一栋5层房子月租7500，要花300万买；在安利做一组稳健市场，一年不到就能拿到这7500。"
