# 深度理解安利奖金制度

> 一句话：奖金制度=**个人销售佣金 + 市场推广服务费 + 6%领导奖 + 年度奖金/股东分红**——从自己当老板到多劳多得公平超越。

## 一、奖金表（PV/BV）

| PV | BV（净营业额） | 月结奖金 |
|---|---|---|
| 100 | 1250 | 0% |
| 200 | 2500 | 3% |
| 600 | 7500 | 6% |
| 1000 | 12500 | 9% |
| 2000 | 25000 | 12% |
| 4000 | 50000 | 15% |
| 7000 | 87500 | 18% |
| 10000 | 125000 | 21% |

另有：+6%电子券、+8%顾客拓展奖、+10%微购佣金、加码奖金（当年9月执行）。

## 二、三大奖金详解

### 1. 个人销售佣金（6-27%）
例：自己体验600元产品，服务10个顾客每人每月用600元，月营业额6000元：
- 6000×9%=540元（佣金）+ 6000×8%=480元（顾客拓展）+ 6000×10%=600元（微购）= 1640元/月。
- 注：500为封顶顾客拓展奖励，600为个人销售10%微购佣金。

### 2. 市场推广服务费（助人自助）
- 你分享6000元，A/B/C/D各分享6000元 → 总营业额5×6000=30000元。
- 本月奖金：30000×18%=5400元；减去4×540=2160元 → 你的收入3240元。
- 加码30%+微购：3240+600+972=4812元。
- 复制4个3万市场：总126000×27%=34020-4×5400=12420元；加码70%+微购=21714元。

### 3. 6%领导奖（拥有资产，获得保障）
- 市场A业绩超12.5万 → 12.5万×6%=7500元/月。
- 资产特点：①不做也有 ②可以继承。

## 三、奖衔与收入

| 达标 | 奖衔 | 年收入 |
|---|---|---|
| 1个月12.5万 | 营销助理 | — |
| 3个月12.5万 | 营销主任 | 10万 |
| 6个月12.5万 | 高级营销主任（DD） | 约15万 |
| 12个月12.5万（Q12DD） | | 约30万 |
| 3个DD市场 | 营销经理 | 50-100万 |
| 6个DD市场 | 高级营销经理 | 100-200万 |

- 年度奖金=股东分红（经理/高经/总监各0.25%全国营业额分红）。

## 四、金句

- 万丈高楼平地起：从开个会员卡、换个产品用、吃好营养早餐开始，平凡的我们也可以拥有不平凡的人生。
- 比尔·盖茨评价：**安利的制度简直无懈可击**。
