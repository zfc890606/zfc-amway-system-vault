# 10 · 基础知识库

> **一句话定位：** 看懂营养学、医学必须的底层学科——基础化学、有机化学、细胞生物学、统计学与科研方法。这些不是营养学本身，而是"读懂营养文献、理解代谢反应、看明白化验单"的工具箱。
>
> **给AI营养师的价值：** 顾客问"为什么这个营养素有用"，能往下追一层——从分子/细胞/证据层面讲清楚，而不只是背结论。

## 一、学科全景

| 子学科 | 解决什么问题 | 与营养的关系 |
|--------|-------------|-------------|
| 基础化学（无机/分析） | 元素、分子、溶液、pH、氧化还原 | 理解电解质、矿物质、酸碱平衡 |
| 有机化学 | 官能团、糖/脂/蛋白质结构 | 营养素本质就是有机分子 |
| 生物化学入门 | 酶、能量货币ATP、代谢反应 | 三大营养素代谢的化学语言 |
| 细胞生物学 | 细胞膜、线粒体、细胞信号 | 营养素如何进入细胞/被利用 |
| 人体分子生物学入门 | DNA→RNA→蛋白质、基因表达 | 表观遗传、个体化营养（精准营养） |
| 统计学与循证医学 | 研究设计、P值、可信区间、Meta分析 | 判断一篇营养文献靠不靠谱 |

## 二、基础化学核心要点

### 1. 原子与分子
- 人体主要由 C、H、O、N、P、S、Ca、K、Na、Cl、Mg 等组成
- **宏量元素**（>体重0.01%）：C H O N P S Ca K Na Cl Mg
- **微量元素**：Fe、Zn、Cu、I、Se、Mn、Mo、Cr、Co、F 等（含量少但缺了不行）

### 2. 溶液与浓度
- **摩尔浓度（mol/L）**：营养学里常用 mg/dL、mmol/L 换算
- **渗透压**：细胞内外液体流动的驱动力（与脱水/水肿相关）
- **pH 与缓冲**：血液 pH 7.35~7.45，靠碳酸氢盐系统缓冲

### 3. 氧化还原
- 氧化 = 丢失电子，还原 = 获得电子
- **自由基**：含不成对电子的分子，攻击细胞膜/蛋白/DNA
- **抗氧化** = 提供电子中和自由基（维C、维E、谷胱甘肽、硒酶）

### 4. 化学键与营养吸收
- **共价键**：营养素分子内部
- **氢键**：蛋白质/水结构的关键
- **离子键**：矿物质的盐形式

## 三、有机化学核心要点

### 1. 官能团（见到的频率排序）
| 官能团 | 例子 | 在营养中的意义 |
|--------|------|---------------|
| 羟基 -OH | 醇、糖 | 亲水、溶于水 |
| 羧基 -COOH | 脂肪酸、氨基酸 | 酸性、可电离 |
| 氨基 -NH₂ | 氨基酸、胺类 | 碱性 |
| 醛基/酮基 | 葡萄糖/果糖 | 还原性、美拉德反应 |
| 酯键 | 甘油三酯 | 脂肪储存形式 |
| 肽键 | 蛋白质 | 氨基酸连接 |
| 磷酸基 | ATP、核酸 | 能量与遗传 |

### 2. 三大营养素的结构基础
- **糖**：Cn(H₂O)n，单糖→双糖→多糖
- **脂肪**：甘油 + 3脂肪酸（甘油三酯）；脂肪酸=长碳链+羧基
- **蛋白质**：20种氨基酸通过肽键连接；侧链R基决定性质

### 3. 重要反应类型
- **水解**：消化过程（淀粉→葡萄糖、脂肪→脂肪酸+甘油、蛋白→氨基酸）
- **酯化/脱酯**：脂肪代谢
- **氧化**：能量释放（β-氧化）
- **美拉德反应**：高温下糖+氨基酸→褐色物质（烤肉香味，也产生AGEs）

## 四、细胞生物学核心要点

### 1. 细胞结构（营养工作相关）
| 结构 | 功能 | 与营养的关系 |
|------|------|-------------|
| 细胞膜 | 选择性通透 | 必需脂肪酸构成膜，膜流动性影响功能 |
| 线粒体 | 能量工厂 | 辅酶Q10、B族、镁、α-硫辛酸参与产能 |
| 内质网/高尔基体 | 蛋白合成加工 | 蛋白质质量 |
| 溶酶体 | 细胞清道夫 | 自噬与抗衰 |
| 细胞核 | 遗传信息 | 叶酸/维B12参与DNA合成修复 |

### 2. 跨膜转运（营养素吸收）
| 方式 | 例子 |
|------|------|
| 简单扩散 | 水、脂溶性分子 |
| 易化扩散 | 葡萄糖（GLUT转运体） |
| 主动转运 | 钠钾泵、钙泵、碘 |
| 胞吞/胞吐 | 大分子、维生素B12 |

### 3. 能量货币 ATP
- ATP = 腺苷 + 3个磷酸
- 高能磷酸键水解释放能量
- 三大营养素 → 乙酰CoA → 三羧酸循环（TCA）→ 氧化磷酸化 → ATP

## 五、分子生物学入门（精准营养基础）

### 1. 中心法则
```
DNA → (转录) → RNA → (翻译) → 蛋白质
```

### 2. 基因与营养（营养基因组学）
| 方向 | 内容 | 案例 |
|------|------|------|
| **营养基因组学** | 基因如何影响营养需求 | MTHFR基因→叶酸利用差异 |
| **营养遗传学** | 营养如何影响基因表达 | 叶酸→DNA甲基化 |
| **表观遗传** | 环境/营养改变基因开关 | 孕期营养影响后代代谢 |

### 3. 与营养相关的信号通路（记住名字即可）
- **mTOR通路**：蛋白质/亮氨酸→肌肉合成信号
- **AMPK通路**：能量不足→开启分解代谢、燃脂
- **NF-κB通路**：炎症信号（姜黄素、n-3抑制）
- **Nrf2通路**：抗氧化应激（萝卜硫素、姜黄素激活）

## 六、统计学与循证医学（看懂文献必备）

### 1. 证据等级金字塔
```
Meta分析/系统评价（最高）
随机对照试验 RCT
队列研究
病例对照研究
横断面调查
专家意见/个案（最低）
```

### 2. 核心统计概念
| 概念 | 通俗解释 | 营养文献用法 |
|------|---------|-------------|
| P值 | 结果纯属偶然的概率 | P<0.05 通常认为"显著" |
| 可信区间CI | 真实值可能落在的范围 | 区间不跨1（OR/RR）才有意义 |
| 相对危险度RR/OR | 暴露组风险是参照组几倍 | >1有害，<1保护 |
| 剂量-反应关系 | 吃越多效果越明显 | 营养素研究常用 |
| 混杂因素 | 干扰真实关系的变量 | 观察性研究最大软肋 |

### 3. 判断一篇营养文献的5个问题
1. 什么研究设计？（RCT 比观察性可信）
2. 样本量多大？随访多久？
3. 有对照吗？随机了吗？盲法吗？
4. 结论是否夸大（观察性研究不能证明因果）？
5. 是谁资助的？（有利益冲突要打折）

### 4. 常见误区
- **相关性 ≠ 因果性**：喝红酒的人更健康≠红酒防病（可能是有钱/生活好）
- **单一营养素 ≠ 食物**：β-胡萝卜素补充剂反而增加肺癌风险（ATBC研究教训）
- **P值陷阱**：P=0.049 与 P=0.051 差别没那么大
