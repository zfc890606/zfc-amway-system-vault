## 一、病理学总论

### 1. 什么是病理学

病理学（Pathology）是研究**疾病的病因、发病机制、病理变化（形态结构、功能与代谢改变）和转归**的医学基础学科。它回答的是三件事：

```
① 病是怎么来的？  → 病因（etiology）
② 病是怎么发展的？→ 发病机制（pathogenesis）
③ 病在身体里长什么样？→ 病理变化（pathological changes，形态+功能+代谢）
```

病理学是连接基础医学（解剖、生理、生化）与临床医学（内、外、妇、儿）的**桥梁学科**。对营养师而言，病理学是"为什么要这样吃"的底层证据来源。

### 2. 疾病发生发展的一般规律

任何疾病都可以浓缩成一条链：

```
病因 → 发病机制 → 病理变化（形态+功能+代谢）→ 转归（痊愈 / 迁延 / 死亡）
```

营养师的工作位置，主要集中在两个环节：

| 环节 | 营养师能做什么 |
|------|--------------|
| 病因环节 | 减少致病因素（控糖、控脂、减盐、限酒、戒加工肉） |
| 机制环节 | 打断损伤链条（抗氧化、抗炎、改善胰岛素抵抗、护线粒体） |
| 转归环节 | 帮助可逆病变逆转、延缓不可逆病变进展 |

### 3. 病理学的核心主题

| 主题 | 核心内容 | 营养相关性 |
|------|---------|-----------|
| **细胞损伤与适应** | 细胞怎么受伤、怎么调整 | ★★★★★ 抗氧化、控糖、护细胞 |
| **损伤的修复** | 再生、纤维化、瘢痕 | ★★★★ 蛋白质、维C、锌促修复 |
| **炎症** | 防御反应（急性/慢性） | ★★★★★ 抗炎饮食是核心 |
| **肿瘤** | 细胞异常增殖 | ★★★★★ 13种癌与肥胖/酒精/加工肉 |
| **循环障碍** | 缺血、血栓、栓塞、梗死 | ★★★★ 血脂、抗凝、血管健康 |
| **动脉粥样硬化** | 血管斑块、心梗脑梗 | ★★★★★ 控脂、抗炎、稳定斑块 |
| **各系统病理** | 肝、肾、胰、肺、脑 | ★★★★ 脂肪肝、CKD、糖尿病 |

### 4. 病理学基本研究方法

| 方法 | 看什么 | 例子 |
|------|--------|------|
| 大体（肉眼）观察 | 器官大小、颜色、质地 | 脂肪肝的大体"油腻肿大" |
| 组织学（显微镜） | 细胞形态、排列 | 肝细胞内的脂滴空泡 |
| 免疫组化 | 特定蛋白表达 | 肿瘤标志物 |
| 分子病理 | 基因、信号通路 | 基因突变检测 |
| 生化检测 | 功能代谢改变 | 肝功能、血脂、CRP |
| 电镜 | 亚细胞结构 | 线粒体肿胀 |

> 对营养师：临床上的**血脂、血糖、CRP、肝功能、尿酸**这些生化指标，本质上是病理变化的"功能侧面"。指标异常=病理变化的信号。

### 5. 病理学的几个基本概念辨析

| 概念 | 含义 | 容易混淆点 |
|------|------|-----------|
| 病因 | 导致疾病发生的因素 | 病因≠诱因 |
| 诱因 | 促使疾病显现的条件 | 高脂饮食是冠心病的诱因之一 |
| 发病机制 | 病因如何一步步造成损伤 | 机制是链条，不是单点 |
| 病理变化 | 形态+功能+代谢的改变 | 指标异常是功能层面的病理变化 |
| 转归 | 疾病的结局 | 痊愈/迁延/恶化/死亡 |

### 6. 病理学与营养学的交叉点（为什么营养师要学病理）

```
病理学的"损伤-适应-炎症-纤维化-硬化"链条
           ↓ 翻译成
营养学的"抗氧化-抗炎-护肝-护肾-防癌"方案
```

营养师学病理，不是为了下诊断，而是为了：

1. **讲得清**——顾客问"为什么脂肪肝会变肝硬化？"，你能讲出"可逆到不可逆"的病理逻辑。
2. **劝得动**——用病理链条解释"为什么现在就要管"。
3. **不越界**——知道哪些是营养能干预的（可逆环节），哪些必须就医（不可逆/急症）。

### 📌 本章「营养应用/话术转化」

| 病理概念 | 讲给顾客听 |
|---------|-----------|
| 病理学链条 | "病不是突然有的，是从一个小损伤慢慢走出来的，营养就是每一步都能拦一下" |
| 可逆 vs 不可逆 | "身体很多问题早期是能回头的，拖到结构都变了就回不了头了" |
| 指标是信号 | "血脂血糖不是数字，是血管和细胞在给你发信号" |

## 二、细胞损伤与适应（营养视角）

### 1. 细胞损伤的原因

细胞是所有疾病的基本单位。理解细胞怎么受伤，是理解一切慢病的第一步。

#### 1.1 损伤原因六大类

| 原因 | 具体内容 | 典型例子 | 营养相关 |
|------|---------|---------|---------|
| **缺氧** | 供氧不足→有氧代谢障碍→ATP↓ | 缺血（动脉硬化→心梗/脑梗）、贫血、CO中毒 | 控脂护血管，减少缺血事件 |
| **物理因素** | 机械、温度、辐射 | 创伤、烧伤、冻伤、放射线 | 维C/锌/蛋白促修复 |
| **化学物质与药物** | 毒物、药物、酒精、环境化学物 | 酒精性肝损伤、药物性肝损伤 | 限酒、护肝营养素 |
| **生物因素** | 病原微生物及其毒素 | 病毒（肝炎）、细菌（沙门氏菌） | 增强免疫、肠道菌群 |
| **免疫反应** | 免疫损伤 | 自身免疫病、超敏反应、移植排斥 | n-3抗炎、维D调节 |
| **遗传性缺陷** | 基因变异 | 家族性高胆固醇血症 | 遗传背景下更要精准营养 |
| **营养失衡** | 缺乏或过量 | 蛋白质缺乏→水肿、维D缺乏→骨软化、铁过量→氧化 | ★营养师主战场 |

#### 1.2 营养失衡作为独立损伤因素（重点）

营养失衡不是"次要因素"，它本身就是病因：

| 类型 | 病理后果 |
|------|---------|
| 蛋白质-能量缺乏 | 生长停滞、肌肉萎缩、水肿（Kwashiorkor/消瘦型） |
| 必需脂肪酸缺乏 | 皮肤屏障受损、炎症失衡 |
| 维生素缺乏 | 坏血病（维C）、脚气病（维B1）、糙皮病（烟酸） |
| 矿物质缺乏 | 缺铁性贫血、缺锌免疫↓、缺硒心肌病 |
| **营养过剩** | 肥胖→脂肪组织炎症、高糖→糖基化损伤、高脂→脂毒 |

> 现代慢病环境下，**营养过剩（over-nutrition）的损伤比营养缺乏更普遍**——这是"代谢性炎症"的病理基础（见第四章）。

### 2. 细胞损伤的机制（营养干预的靶点）

细胞损伤的五条核心机制，条条都与营养素有关：

#### 2.1 细胞膜损伤

- 机制：自由基攻击膜磷脂→膜通透性↑→细胞肿胀死亡。
- 营养靶点：**维E（膜内抗氧化剂）、磷脂、n-3/n-6平衡**——膜是脂质构成的，吃什么脂，膜就是什么质地。

#### 2.2 活性氧（ROS）/氧化应激损伤

- 机制：ROS（超氧阴离子、过氧化氢、羟自由基）攻击DNA、蛋白、脂质。
- 内源性来源：线粒体呼吸链漏出、炎症细胞"呼吸爆发"。
- 外源性来源：吸烟、酒精、高糖高脂饮食、环境污染、紫外线。
- 营养靶点：**维C、维E、硒（谷胱甘肽过氧化物酶组分）、多酚、类胡萝卜素、硫辛酸**。

#### 2.3 ATP生成减少（能量危机）

- 机制：缺氧/线粒体功能障碍→ATP↓→钠泵失效→细胞水肿→损伤。
- 营养靶点：**B族维生素（辅酶）、辅酶Q10、镁、铁（携氧）**。线粒体是"细胞电厂"，电厂缺原料，全厂停电。

#### 2.4 细胞内钙离子升高

- 机制：钙超载→激活磷脂酶、蛋白酶、核酸内切酶→损伤。
- 这是"最终共同通路"之一——多种损伤最后都靠钙超载杀死细胞。

#### 2.5 DNA损伤

- 机制：ROS/化学致癌物/辐射→DNA突变→修复失败→肿瘤/衰老。
- 营养靶点：**叶酸（DNA合成甲基化）、锌（修复酶组分）、抗氧化剂**。

> **一句话总括：** 细胞损伤的五大机制——膜、氧化、能量、钙、DNA——恰好对应营养素能干预的五大方向。这就是"营养护细胞"的病理学证据。

### 3. 细胞适应（可逆的调整）

当刺激温和或持续存在时，细胞会"调整自己"去适应，而不是直接死掉。适应是可逆的，但长期适应会走向失代偿。

#### 3.1 四大适应类型

| 适应 | 定义 | 形态改变 | 营养例子 |
|------|------|---------|---------|
| **萎缩**（Atrophy） | 细胞体积变小 | 细胞器减少、自噬体↑ | 长期卧床→肌肉萎缩（废用性）；缺蛋白→肌少症 |
| **肥大**（Hypertrophy） | 细胞体积增大 | 细胞器增多、蛋白合成↑ | 长期高血压→心肌肥大（代偿性）；力量训练→骨骼肌肥大（生理性） |
| **增生**（Hyperplasia） | 细胞数量增多 | 细胞分裂↑ | 激素→乳腺增生/前列腺增生；缺碘→甲状腺增生 |
| **化生**（Metaplasia） | 细胞类型转变 | 一种细胞变成另一种 | 吸烟→气管纤毛柱状上皮→鳞状化生；慢性胃炎→肠上皮化生 |

#### 3.2 四大适应的病理意义

```
正常细胞
   ├─ 刺激强而短暂 → 损伤（可逆/不可逆）
   ├─ 刺激弱而持续 → 适应（萎缩/肥大/增生/化生）
   └─ 刺激过强/太久 → 适应失败 → 病变（如化生可癌变）
```

关键概念：

- **代偿性肥大**：一个器官出问题，另一个代偿（如一侧肾切除后对侧肥大）。本质是"过度工作"。
- **病理性增生**：激素或生长因子驱动的不受控增殖（如乳腺增生），是肿瘤的"前奏土壤"。
- **化生的风险**：化生是可逆的适应，但**持续刺激下化生可进展为不典型增生→癌**（如Barrett食管：食管柱状化生→腺癌）。这也是"别让慢性刺激持续"的病理理由。

#### 3.3 营养如何干预"适应"

| 适应类型 | 营养干预思路 |
|---------|-------------|
| 萎缩（肌少症） | 足量优质蛋白+亮氨酸+抗阻运动→刺激合成 |
| 肥大（心肌） | 控血压、限钠、减重→减轻心脏负荷，防失代偿 |
| 增生（乳腺/前列腺） | 控制体脂（脂肪→雌激素）、十字花科蔬菜（植物化学物） |
| 化生（食管/胃） | 根除诱因（吸烟/酒精/幽门螺杆菌）+抗氧化抗炎营养 |

### 4. 可逆 vs 不可逆损伤

#### 4.1 判断标准

```
轻损伤 → 可逆性损伤（细胞恢复）
   ├─ 细胞水肿（水变性）：钠泵失灵，细胞肿胀——可逆
   ├─ 脂肪变性：脂滴在细胞内堆积（肝最常见）——可逆
   └─ 玻璃样变/淀粉样变：蛋白质异常聚集——部分可逆
重损伤 → 不可逆损伤 → 细胞死亡
   ├─ 坏死（Necrosis）：病理性、被动性、伴炎症
   └─ 凋亡（Apoptosis）：程序性、主动性、不伴炎症
```

#### 4.2 可逆性损伤详解（营养师重点）

| 可逆损伤 | 定义 | 好发部位 | 营养意义 |
|---------|------|---------|---------|
| **细胞水肿** | 细胞内水分增多，胞质疏松 | 心、肝、肾 | 早期损伤信号，去除病因可恢复 |
| **脂肪变性** | 细胞内脂滴异常堆积 | 肝（最常见）、心、肾 | ★脂肪肝=肝细胞脂肪变性，**早期可逆** |
| **玻璃样变** | 细胞内/间质蛋白均匀红染 | 肾、血管、瘢痕 | 常为长期慢病结果 |
| **黏液样变** | 间质黏液增多 | 结缔组织 | — |

> 核心逻辑：**脂肪变性（尤其脂肪肝）是最典型的可逆损伤**。这也是"脂肪肝能逆转"的病理学依据——只要在可逆窗口期干预。

#### 4.3 不可逆损伤的判断

细胞死亡后，判断"不可逆"的形态学标志（电镜下）：

- 细胞膜完整性破坏
- 线粒体高度肿胀、出现无定形致密物
- 核固缩/核碎裂/核溶解

> **营养师版：** 功能改变（指标异常）→ 可逆窗口；结构改变（影像学确诊的纤维化/硬化）→ 不可逆窗口。**营养干预要赶在"结构改变"之前。**

### 5. 坏死（Necrosis）

#### 5.1 定义与本质

坏死是**活体内局部组织细胞的病理性死亡**，特点是：被动发生、细胞崩解、**引发周围炎症反应**（因为细胞内容物漏出，激活免疫）。

#### 5.2 坏死的主要类型

| 类型 | 特点 | 典型例子 | 营养关联 |
|------|------|---------|---------|
| **凝固性坏死** | 蛋白凝固，轮廓保留 | 心梗、脾梗死、肾梗死 | 缺血→坏死，防缺血是根本 |
| **液化性坏死** | 细胞溶解，形成脓/囊腔 | 脑梗死（脑软化）、脓肿 | 脑梗后营养支持 |
| **干酪样坏死** | 特殊凝固性坏死，松软如奶酪 | 结核 | — |
| **脂肪坏死** | 脂肪细胞破坏，皂化 | 急性胰腺炎、乳腺外伤 | 高脂血症与胰腺炎 |
| **坏疽** | 坏死+腐败菌感染 | 糖尿病足（湿性坏疽） | ★糖尿病管理→防糖尿病足 |
| **纤维素样坏死** | 血管壁纤维蛋白沉积 | 恶性高血压、自身免疫病 | 抗炎、控血压 |

> 坏死是"被动死亡"，会招来炎症；凋亡是"主动死亡"，不招炎症。这个区别是理解"为什么慢病是慢性炎症"的关键之一。

### 6. 凋亡（Apoptosis）

#### 6.1 定义

凋亡是**细胞主动的、程序化的死亡**，由基因调控（caspase家族执行），用于清除多余/受损/衰老细胞。

#### 6.2 坏死 vs 凋亡对比表（营养师要会讲）

| 特征 | 坏死 | 凋亡 |
|------|------|------|
| 本质 | 病理性、被动 | 生理性/病理性、主动 |
| 触发 | 严重损伤（缺氧/毒物） | 基因程序（发育、DNA损伤、免疫） |
| 细胞形态 | 肿胀、破裂 | 皱缩、形成凋亡小体 |
| 炎症反应 | **有**（明显） | **无**（不引发炎症） |
| DNA | 随机降解 | 规律性梯状断裂 |
| 营养/临床意义 | 缺血损伤、慢病终末期 | 清除癌变细胞（化疗目标） |

> 有趣的营养关联：**适度热卡限制/间歇性禁食可促进受损细胞凋亡（清除"僵尸细胞"），而营养过剩抑制凋亡、促异常增殖**——这是"少吃一点抗衰老"的病理学逻辑。

### 7. 自噬（Autophagy）

- 定义：细胞把自身衰老/损伤成分包裹降解再利用的过程。
- 意义：细胞"自食"垃圾，维持稳态；与抗衰老、代谢健康相关。
- 营养关联：**营养充足时自噬受抑制，饥饿/热量限制时自噬增强**——这是"轻断食促进细胞自噬"的分子基础。但注意：自噬增强≠越多越好，需在生理范围内。

|---------|-----------|
| 细胞损伤五机制 | "细胞受伤就五条路：膜坏了、氧化了、没电了、钙乱了、DNA伤了——营养正好四条都能护" |
| 可逆损伤 | "细胞水肿、脂肪变这些早期损伤，撤掉诱因就能恢复——这就是为什么早管早好" |
| 脂肪变性可逆 | "脂肪肝是肝细胞里'长油'了，这步还能回头；等长成硬条就回不了头了" |
| 坏死 vs 凋亡 | "细胞有'被动死亡'和'主动自杀'两种死法，慢病里那种'被动死'会引来一片火（炎症）" |
| 细胞适应 | "身体很能忍，先调整适应，但忍到极限就是病——别让它一直忍" |

## 三、损伤的修复（再生与纤维化）

### 1. 修复的两种方式

细胞死亡/组织损伤后，机体启动修复。两种方式：

```
① 再生（Regeneration）  由同类细胞增殖补充 → 恢复原结构功能（理想）
② 纤维化（Fibrosis）    由纤维结缔组织填补 → 瘢痕形成（功能受影响）
```

营养师要懂的核心：**修复需要"原料"，原料就是营养素。**

### 2. 不同细胞类型的再生能力

| 细胞分类 | 再生能力 | 例子 | 营养意义 |
|---------|---------|------|---------|
| **不稳定细胞**（持续增殖） | 强 | 皮肤表皮、肠上皮、造血细胞 | 蛋白质/微量营养素缺乏→伤口不愈、肠道修复差 |
| **稳定细胞**（受刺激可增殖） | 中等 | 肝细胞、肾小管上皮、腺体 | 肝部分切除后可再生——**肝再生需要蛋白** |
| **永久性细胞**（不增殖） | 无 | 心肌、神经元 | 心梗/脑梗的坏死不可再生→只能靠功能代偿，**防梗>治梗** |

> 关键：**肝是"稳定细胞"中的明星**——肝细胞再生能力很强，这是脂肪肝/肝炎早期可逆转的又一证据。但**心肌和神经元不能再生**，所以心梗、脑梗一旦发生就是永久损伤——预防（营养）远比事后补救重要。

### 3. 肉芽组织（Granulation Tissue）

- 定义：由新生毛细血管+成纤维细胞+炎症细胞构成的新生组织。
- 作用：填补伤口、抗感染、为再上皮化搭桥。
- 肉眼：红色、颗粒状、柔软湿润（"肉芽"之名由来）。
- 结局：逐渐成熟→纤维化→瘢痕。

### 4. 瘢痕与瘢痕修复

| 概念 | 说明 |
|------|------|
| 瘢痕 | 纤维化修复的最终产物，胶原为主 |
| 特点 | 抗张强度低（早期）、无弹性、无功能细胞 |
| 异常瘢痕 | 瘢痕疙瘩、瘢痕挛缩（影响功能） |
| 病理意义 | 器官内瘢痕=纤维化=功能单位被替换（如肝硬化、心肌纤维化、肾小球硬化） |

> **纤维化的本质**：正常的细胞被"瘢痕"替换。**肝硬化、肾纤维化、肺纤维化、动脉硬化斑块里的纤维帽**，本质上都是同一种修复方式在不同器官的表现。

### 5. 影响修复的因素（营养干预清单）

| 因素 | 影响 | 营养对策 |
|------|------|---------|
| **蛋白质** | 细胞增殖和胶原合成的原料 | 足量优质蛋白（创面愈合、术后康复） |
| **维C** | 胶原合成的辅助因子（羟化反应必需） | 维C缺乏→伤口不愈、坏血病 |
| **锌** | 细胞增殖、DNA合成酶的组分 | 锌缺乏→创面愈合延迟 |
| **维A** | 上皮细胞分化、黏液分泌 | 维A缺乏→黏膜修复差 |
| **铁/铜** | 胶原交联酶组分 | 铁/铜参与胶原成熟 |
| **能量** | 修复是高耗能过程 | 能量不足→修复迟缓 |
| 感染/炎症 | 炎症干扰修复 | 抗炎营养、控制感染 |
| 糖尿病 | 高血糖阻碍愈合 | 血糖控制（糖尿病足愈合） |
| 局部血供 | 血供差→修复差 | 运动/戒烟改善循环 |

> **营养师核心结论：** 手术、创伤、溃疡、骨折的恢复期，**蛋白质+维C+锌+能量**是"修复四件套"。这正是营养支持在外科康复中不可替代的病理学原因。

| 病理概念 | 讲给顾客听 |
|---------|-----------|
| 修复需要原料 | "伤口长肉、骨头愈合、肝细胞再生，靠的都是蛋白质和维C这些原料，缺了就长不动" |
| 心肌神经元不可再生 | "心脏和大脑的细胞死了不能长回来，所以血管健康要'防'在前面" |
| 纤维化 | "肝变硬、肾变硬，本质都是好细胞被疤痕替代了——纤维化越少越好" |
| 术后营养 | "手术后医生让吃好的，不是客气，是修复真的需要原料" |

## 四、炎症（慢病之母）

### 1. 炎症的本质与意义

#### 1.1 定义

炎症（Inflammation）是具有血管系统的活体组织对**损伤因子**的**防御性反应**。核心是：**血管反应 + 白细胞反应**。

#### 1.2 炎症是一把双刃剑

| 有益面（防御） | 有害面（慢性损伤） |
|--------------|------------------|
| 清除病原体 | 长期炎症损伤自身组织 |
| 局限损伤（形成脓肿包裹） | 慢性炎症→纤维化→硬化 |
| 启动修复 | 炎症促肿瘤（炎症-癌轴） |
| 招募免疫细胞 | 系统性炎症→胰岛素抵抗/动脉硬化 |

> **营养师要讲的核心观念：** 炎症不是"敌人"，是身体的"消防队"。问题是**消防队长期不撤、火一直在烧**——这才是慢病。

### 2. 炎症的局部表现与全身反应

#### 2.1 局部表现（经典五大征）

```
红（血管扩张）→ 热（血流量↑）→ 肿（渗出）→ 痛（介质刺激神经）→ 功能障碍
```

#### 2.2 全身反应

| 全身反应 | 机制 | 营养关联 |
|---------|------|---------|
| **发热** | 内源性致热原（IL-1、IL-6、TNF）作用于下丘脑 | 发热→代谢↑→耗能量蛋白 |
| 白细胞增多 | 骨髓释放中性粒细胞 | 感染→蛋白需求↑ |
| 急性期蛋白↑ | 肝脏合成CRP、纤维蛋白原 | ★CRP是"炎症警报"，营养干预可降低 |
| 蛋白质分解↑ | 骨骼肌分解供能 | 慢性炎症→肌少症（恶病质） |

> **CRP（C反应蛋白）**是营养师最该认识的炎症指标：慢性低度炎症时CRP轻度升高（2-10 mg/L），它是"身体里小火在炖"的定量信号。

### 3. 炎症介质（Inflammatory Mediators）

炎症的"化学信使"，营养干预往往针对这些介质：

| 介质类别 | 代表 | 来源 | 主要作用 | 营养干预 |
|---------|------|------|---------|---------|
| 血管活性胺 | 组胺 | 肥大细胞 | 血管扩张、通透性↑ | — |
| 花生四烯酸代谢物 | 前列腺素（PGE2）、白三烯 | 膜磷脂（n-6） | 发热、痛、血管扩张 | ★n-3竞争底物，减少促炎类前列腺素 |
| 细胞因子 | TNF-α、IL-1、IL-6 | 巨噬细胞等 | 发热、急性期反应、组织损伤 | ★n-3、多酚抑制 |
| 趋化因子 | IL-8等 | 多种细胞 | 招募白细胞 | — |
| 一氧化氮（NO） | — | 内皮/巨噬细胞 | 血管扩张 | 精氨酸相关 |
| 补体系统 | C3a、C5a | 肝脏合成 | 溶菌、调理、趋化 | — |
| 血小板活化因子 | PAF | 多种细胞 | 血小板聚集 | n-3 |

> **病理学第9版重点：** 花生四烯酸（n-6系）衍生的前列腺素/白三烯是促炎的；**EPA/DHA（n-3系）可竞争性取代花生四烯酸，生成低活性/抗炎介质**（如resolvins、protectins）。这就是"吃鱼油抗炎"的分子病理学依据。

### 4. 急性炎症

#### 4.1 特点

| 特征 | 说明 |
|------|------|
| 时间 | 短（数分钟~数天） |
| 主要细胞 | **中性粒细胞**（细菌急先锋） |
| 主要改变 | **渗出**（血管扩张、液体蛋白外渗、白细胞渗出） |
| 结局 | 痊愈 / 脓肿 / 转为慢性 |

#### 4.2 急性炎症的结局

```
急性炎症
   ├─ 痊愈（清除损伤、修复）——理想结局
   ├─ 脓肿/溃疡（局限化）——需引流或缓慢修复
   ├─ 纤维化（肉芽组织填充）
   └─ 转为慢性（刺激持续或免疫异常）
```

### 5. 慢性炎症

#### 5.1 一般慢性炎症

| 特征 | 说明 |
|------|------|
| 时间 | 数周~数月~数年 |
| 主要细胞 | **巨噬细胞、淋巴细胞、浆细胞** |
| 主要改变 | **增生**（血管增生、纤维化、组织破坏与修复并存） |
| 常见原因 | 病原持续感染（结核、幽门螺杆菌）、自身免疫、长期异物刺激 |

#### 5.2 肉芽肿性炎症

- 定义：以**巨噬细胞及其衍生细胞聚集**（形成肉芽肿）为特征的慢性炎症。
- 例子：结核、麻风、克罗恩病、结节病。
- 形态：上皮样细胞+多核巨细胞（Langhans巨细胞）+周围淋巴细胞。

#### 5.3 慢性炎症的破坏性后果

```
慢性炎症（持续刺激）
   ├─ 组织破坏（蛋白酶、ROS）
   ├─ 纤维化/瘢痕（肝纤维化、肾硬化、肺纤维化）
   ├─ 血管增生（肉芽组织持续存在）
   └─ 癌变风险↑（炎症-肿瘤关联：肝炎→肝癌、IBD→结直肠癌）
```

### 6. 慢性低度炎症与代谢性炎症（Metaflammation）——营养师核心章节

#### 6.1 概念来源

"代谢性炎症"（Metaflammation，metabolic + inflammation）由哈佛学者 **Gökhan S. Hotamisligil** 提出（Nature 2006《Inflammation and metabolic disorders》综述，2017年更新）。核心观点：

> **营养过剩和代谢紊乱，能像病原体一样触发慢性低度炎症。** 这种炎症不像急性炎症那样红热肿痛，而是"静悄悄的、全身性的、低水平的"，却是肥胖、2型糖尿病、动脉粥样硬化、非酒精性脂肪肝、肿瘤、衰老的共同土壤。

#### 6.2 代谢性炎症的病理链条

```
长期营养过剩（高糖高脂高能量）
   ↓
脂肪组织扩张（肥大+增生）
   ↓
脂肪组织缺氧 → 脂肪细胞死亡/应激
   ↓
巨噬细胞浸润脂肪组织（M1促炎型极化）
   ↓
促炎因子释放：TNF-α、IL-6、抵抗素、MCP-1
   ↓
局部+全身性低度炎症（CRP轻度升高）
   ↓
胰岛素受体信号被干扰 → 胰岛素抵抗
   ↓
高血糖/高胰岛素 → 进一步氧化应激、糖基化、脂毒
   ↓
2型糖尿病 / 动脉粥样硬化 / 脂肪性肝炎 / 肿瘤促进
```

#### 6.3 慢性低度炎症 vs 急性炎症对比

| 特征 | 急性炎症 | 慢性低度炎症（代谢性炎症） |
|------|---------|--------------------------|
| 触发 | 感染/损伤/异物 | 营养过剩、内脏脂肪、氧化应激 |
| 强度 | 强 | 低水平、持续 |
| 位置 | 局部 | 全身性（脂肪、肝、血管、脑） |
| 主要细胞 | 中性粒细胞 | 巨噬细胞（M1）、T细胞 |
| 症状 | 红肿热痛 | 无症状或乏力 |
| 指标 | 白细胞↑、CRP明显↑ | CRP轻度↑（2-10）、IL-6、TNF-α |
| 结局 | 痊愈或转慢性 | 胰岛素抵抗→慢病 |

#### 6.4 代谢性炎症的"燃料"是什么

| 燃料 | 机制 |
|------|------|
| 内脏脂肪 | 内脏脂肪比皮下脂肪更易招募巨噬细胞（"炎症性脂肪"） |
| 高血糖/AGEs | 糖基化终产物激活RAGE→促炎 |
| 氧化LDL | 氧化LDL被巨噬细胞吞噬→泡沫细胞+炎症 |
| 肠道菌群失调 | LPS（内毒素）透过屏障→"代谢性内毒素血症" |
| 游离脂肪酸过量 | 脂毒性→ER应激→促炎 |
| 高胰岛素 | 放大炎症信号 |

#### 6.5 代谢性炎症→慢病的"桥"

```
代谢性炎症
   ├─ → 胰岛素抵抗 → 2型糖尿病
   ├─ → 血管炎症 → 动脉粥样硬化
   ├─ → 肝脏炎症 → 非酒精性脂肪性肝炎（NASH）
   ├─ → 神经炎症 → 认知下降（观察性）
   └─ → 促进肿瘤微环境 → 癌症风险↑
```

> **这是营养干预最核心的病理学依据：** 如果炎症是慢病之母，那么"吃出来的代谢性炎症"就是现代慢病最大的可干预源头——**改变饮食结构=掐断炎症燃料**。

### 7. 抗炎营养靶点（病理靶点表）

| 营养素/食物模式 | 抗炎机制（病理层面） | 证据等级 |
|---------------|---------------------|---------|
| **n-3多不饱和脂肪酸（EPA/DHA）** | 竞争性替代花生四烯酸→减少PGE2/白三烯；生成resolvins/protectins促炎症消退 | 强（RCT meta分析） |
| **膳食纤维** | 肠道菌群→短链脂肪酸（丁酸）→抑制NF-κB、促进Treg | 强 |
| **维D** | 调节免疫细胞分化，抑制过度炎症 | 中-强（观察+RCT部分） |
| **多酚（姜黄素、儿茶素、槲皮素）** | 抑制NF-κB通路、抑制COX/LOX、抗氧化 | 中（体内生物利用度有限） |
| **维C** | 抗氧化、再生维E、支持免疫 | 中 |
| **维E** | 膜脂质过氧化链式反应的阻断剂 | 中 |
| **硒** | 谷胱甘肽过氧化物酶组分 | 中 |
| **镁** | 影响CRP、内皮功能 | 中（观察性强） |
| **限制精制糖** | 减少AGEs、减少胰岛素波动 | 强（机制+流行病学） |
| **控脂（减SFA/反式脂肪）** | 减少脂毒、减少LDL氧化 | 强 |
| **地中海饮食/全食物模式** | 多机制叠加（纤维+多酚+n-3+控糖） | 强（PREDIMED等） |
| **限能量/减重** | 减少脂肪组织炎症、减轻巨噬细胞浸润 | 强（减重即抗炎） |

#### 抗炎营养素靶点小结（机制图）

```
膳食模式调整
   │
   ├─ 减少促炎燃料：减糖、减SFA/TFA、减精加工、限酒
   ├─ 增加抗炎底物：n-3（鱼）、橄榄油（MUFA）、纤维（全谷/豆/蔬果）
   ├─ 增加抗炎信号：多酚（浆果/茶/可可）、姜黄
   └─ 降低体脂：能量平衡 → 脂肪组织炎症↓
```

| 炎症双刃剑 | "炎症是身体的消防队，问题是很多人的火一直没灭——不红不肿不等于没有炎症" |
| 代谢性炎症 | "吃出来的火，也能吃灭"——营养过剩会点火，营养调整能灭火 |

## 五、循环障碍与血栓（补充章节）

### 1. 充血与淤血

| 概念 | 定义 | 病理意义 |
|------|------|---------|
| 动脉性充血 | 动脉血流入增多 | 炎症局部红肿热的基础 |
| 静脉性淤血 | 静脉回流受阻 | 慢性心衰→肺淤血/肝淤血；长期淤血→淤血性硬化 |

### 2. 血栓形成（Thrombosis）

#### 2.1 血栓形成的三大条件（Virchow三要素）

```
① 血管内皮损伤   ← 高血压、高血脂、吸烟、高血糖
② 血流缓慢/涡流   ← 久坐、房颤、静脉曲张
③ 血液凝固性增高  ← 高脂、吸烟、肿瘤、炎症
```

#### 2.2 血栓类型与营养关联

| 血栓类型 | 特点 | 常见部位 | 营养关联 |
|---------|------|---------|---------|
| 白色血栓 | 血小板为主 | 动脉（心） | 动脉粥样硬化斑块破裂处 |
| 红色血栓 | 红细胞为主 | 静脉（下肢） | 久坐/深静脉血栓 |
| 混合血栓 | 灰白色与红色相间 | 心腔内 | 房颤 |

#### 2.3 血栓的结局

```
血栓 → 机化再通 / 钙化 / 脱落 → 栓塞 → 梗死
```

### 3. 栓塞与梗死

| 概念 | 定义 | 例子 | 营养意义 |
|------|------|------|---------|
| **栓塞** | 栓子（血栓、脂肪、气体）随血流堵塞血管 | 房颤血栓→脑栓塞 | 防栓=抗凝生活方式 |
| **梗死** | 动脉阻塞→局部缺血坏死 | 心梗、脑梗 | ★心梗脑梗=梗死，不可逆 |

> **营养师核心信息：** 心梗、脑梗本质是"梗死"——永久性坏死（心肌/神经元不可再生）。所以一切心血管营养的核心目标是**防梗死**：控斑块、稳斑块、防血栓。

### 4. 循环障碍的营养对策

| 危险因素 | 营养对策 |
|---------|---------|
| 内皮损伤（高血压/高糖/吸烟） | 控血压（限钠高钾）、控糖、戒烟、抗氧化 |
| 血脂异常（LDL↑） | 减饱和脂肪/反式脂肪、可溶性纤维、植物甾醇 |
| 血液高凝 | 适度n-3、控脂、抗炎、适量运动 |
| 血流缓慢（久坐） | 活动、避免久坐（深静脉血栓预防） |

| 病理概念 | 讲给顾客听 |
|---------|-----------|
| 血栓三要素 | "血堵住要三件事凑齐：血管内皮伤了、血流慢了、血太黏了——营养能管两件半" |
| 梗死不可逆 | "心梗脑梗是'地都塌了'，营养要管的是别让地塌——斑块、血栓、血压" |

## 六、动脉粥样硬化（心血管病理核心）

### 1. 定义与流行病学

动脉粥样硬化（Atherosclerosis）是**动脉内膜的脂质沉积、巨噬细胞浸润、平滑肌细胞增生、纤维帽形成**，导致管壁增厚变硬、管腔狭窄的病变。它是心梗、脑梗、外周血管病共同的病理基础，**全球致死致残第一杀手**。

```
动脉硬化（广义）
   ├─ 动脉粥样硬化（AS，最常见，大中动脉）
   ├─ 细小动脉硬化（高血压→肾/脑小动脉）
   └─ 动脉中层钙化（老年人，临床意义小）
```

### 2. 危险因素

#### 2.1 可控 vs 不可控

| 分类 | 因素 | 营养干预空间 |
|------|------|-------------|
| **不可控** | 年龄、性别（男性/绝经后女性）、遗传家族史 | 无直接干预，但可强化其他方面 |
| **可控（血脂）** | LDL-C↑、HDL-C↓、甘油三酯↑、Lp(a) | ★★★★★ |
| **可控（代谢）** | 高血压、糖尿病/胰岛素抵抗、肥胖、代谢综合征 | ★★★★★ |
| **可控（生活方式）** | 吸烟、饮酒、缺乏运动、高盐高脂饮食 | ★★★★★ |

#### 2.2 代谢综合征（危险因素扎堆）

```
腹型肥胖 + 高血压 + 高血糖 + 高甘油三酯 + 低HDL
        （五项中任三项）→ 代谢综合征
        → 动脉粥样硬化/糖尿病风险叠加
```

> 营养师要讲：**危险因素很少单独来，它们成团出现（代谢综合征）**——因为背后是同一个病根：能量过剩+胰岛素抵抗+代谢性炎症。

### 3. 发病机制（第9版三大经典假说整合）

现代观点整合了三个经典假说：

| 假说 | 核心 | 营养对应 |
|------|------|---------|
| **内皮损伤假说** | 内皮损伤是起始 | 控血压、控糖、戒烟、抗氧化的目标就是保护内皮 |
| **脂质浸润假说** | LDL进入内膜被氧化 | 降LDL、抗氧化 |
| **炎症假说** | 炎症驱动斑块进展与破裂 | 抗炎饮食 |

> 三者不矛盾，而是串成一条链：**内皮损伤→脂质进入氧化→炎症放大→斑块→破裂。**

### 4. 发生全过程（营养师必会讲）

```
第一步：血管内皮损伤
   （高血脂/高血压/高血糖/吸烟/剪切力异常 → 内皮功能障碍）
   ↓
第二步：LDL进入内膜并被氧化（oxLDL）
   （内皮通透性↑ → LDL沉积内膜 → ROS氧化 → 变成"更坏"的oxLDL）
   ↓
第三步：单核细胞进入内膜→巨噬细胞吞噬oxLDL→泡沫细胞
   （巨噬细胞吞"坏脂"吞到爆 → 变成泡沫细胞 → 脂质条纹）
   ↓
第四步：脂质条纹→粥样斑块
   （脂质核心[细胞外脂质+坏死碎片] + 纤维帽[平滑肌+胶原]）
   ↓
第五步：斑块进展
   （脂质核心增大、纤维帽变薄、炎症细胞浸润）
   ↓
第六步（灾难性）：斑块破裂/糜烂 → 血栓形成
   （纤维帽薄的"不稳定斑块"破裂 → 血小板聚集 → 血栓 → 心梗/脑梗）
```

> **病理第9版关键区分：** 斑块的危险性不只看"堵了多少"，更看"稳不稳定"。**急性心梗常由"狭窄不重但易破裂的斑块"引起**——这是颠覆大众认知、也是营养师要讲透的一点。

### 5. 斑块稳定 vs 大小（现代心血管病理核心观念）

#### 5.1 两种斑块

| 特征 | 稳定斑块（"好斑块"） | 不稳定/易损斑块（"坏斑块"） |
|------|---------------------|---------------------------|
| 纤维帽 | 厚 | 薄 |
| 脂质核心 | 小 | 大（坏死脂质多） |
| 炎症细胞 | 少 | 多（巨噬细胞密集） |
| 平滑肌 | 多（胶原多） | 少 |
| 钙化 | 可有 | 点状钙化（不稳定信号） |
| 结局 | 慢性狭窄 | 易破裂→血栓→急性事件 |

#### 5.2 核心结论

> **稳定斑块（纤维帽厚）比小而不稳的斑块更安全。** 一个"堵70%但很稳"的斑块，可能一辈子不惹事；一个"堵30%但很薄、炎症重"的斑块，可能明天就破裂。

#### 5.3 营养如何"稳斑块"

| 干预 | 机制 | 效果 |
|------|------|------|
| **降LDL-C**（减SFA/TFA、可溶性纤维、植物甾醇） | 减少脂质核心原料 | 斑块缩小/稳定 |
| **抗炎**（n-3、纤维、多酚、减内脏脂肪） | 减少炎症细胞浸润、纤维帽变薄 | ★稳定斑块关键 |
| **戒烟** | 减少内皮损伤 | 稳定斑块 |
| **控血压** | 减少剪切力损伤 | 防破裂 |
| **抗栓**（适量n-3、地中海饮食） | 减少血栓形成 | 防急性事件 |
| **他汀类**（遵医嘱） | 降脂+抗炎+稳定斑块 | 循证最强 |

> 这是营养师讲"降脂抗炎"的终极病理逻辑：**我们不是让斑块消失（很难），而是把"易碎的坏斑块"变成"结实的稳斑块"**——降低心梗脑梗的急性风险。

### 6. 各危险因素与营养对应表（详细版）

| 危险因素 | 病理机制 | 营养对策 | 病理学依据 |
|---------|---------|---------|-----------|
| **LDL-C↑** | 脂质沉积的"原料" | 减饱和脂肪（红肉、油炸）、减反式脂肪、可溶性纤维（燕麦/豆类）、植物甾醇 | 脂质浸润假说 |
| **oxLDL（氧化LDL）** | 氧化后的LDL更致动脉粥样硬化 | 维C/E、多酚、控糖（少AGEs） | 氧化应激参与 |
| **甘油三酯↑** | 富含甘油三酯的脂蛋白也促AS | 减糖、减精制碳水、n-3 | 高TG是残余风险 |
| **高血压** | 内皮损伤、剪切力 | 限钠（<5g盐/日）、高钾（蔬果）、DASH/地中海饮食 | 内皮损伤假说 |
| **高血糖/糖尿病** | 内皮糖基化（AGEs）、氧化应激 | 控糖、低GI饮食、减精制糖 | 高糖毒性 |
| **肥胖/内脏脂肪** | 代谢性炎症、脂联素↓、瘦素抵抗 | 能量平衡减重、减内脏脂肪 | Metaflammation |
| **慢性炎症** | 斑块不稳定 | 抗炎饮食（n-3、纤维、多酚） | 炎症假说 |
| **吸烟** | 内皮损伤+氧化 | 戒烟（营养只能辅助） | 内皮损伤 |
| **酒精过量** | 血压↑、甘油三酯↑ | 限酒 | 代谢紊乱 |
| **高同型半胱氨酸** | 内皮损伤（机制有争议） | 叶酸/B12/B6（注意：降同型半胱氨酸RCT未一致显示心血管获益，需严谨） | 血管毒性 |

### 7. 动脉硬化的营养预防证据要点

| 证据来源 | 结论 |
|---------|------|
| PREDIMED研究（地中海饮食） | 补充橄榄油/坚果的地中海饮食，主要心血管事件↓约30% |
| 膳食纤维 | 每增加7g/日膳食纤维，冠心病风险↓约9%（meta分析） |
| 减饱和脂肪 | 用多不饱和脂肪替代饱和脂肪，冠心病风险↓（Cochrane） |
| 食盐 | 高盐→高血压→心血管风险，WHO推荐<5g/日 |
| n-3 | 鱼类消费与心血管事件风险负相关（观察性）；高剂量n-3补充证据不一，需个体化 |
| 反式脂肪 | 明确增加心血管风险（WHO建议消除） |

> **严谨提示：** 营养干预降低心血管风险的证据来自"膳食模式整体"（地中海饮食、DASH）最强；单一营养素补充剂（如β-胡萝卜素、维E大剂量）的RCT未显示保护作用甚至有害——**要讲"吃出来的饮食模式"，不是"补出来的单一成分"。**

## 七、肿瘤病理基础（营养师够用版）

### 1. 肿瘤的基本概念

肿瘤（Tumor/Neoplasm）是机体在各种致瘤因素作用下，局部组织的细胞在**基因水平**失去正常调控，导致**克隆性异常增殖**而形成的新生物。

```
正常细胞 → 基因突变累积 → 克隆性增殖 → 良性/恶性
```

**关键特征：** 肿瘤是"自己的细胞"（不是外来物），但"失控"了——不听正常调控，持续增殖、可侵袭转移。

### 2. 肿瘤的命名与分类

#### 2.1 命名规则

| 组织来源 | 良性 | 恶性（癌/肉瘤） |
|---------|------|----------------|
| 上皮组织 | 腺瘤（如结肠腺瘤）、乳头状瘤 | **癌**（腺癌、鳞癌） |
| 间叶组织 | 纤维瘤、脂肪瘤 | **肉瘤**（纤维肉瘤、骨肉瘤） |
| 淋巴造血 | — | 淋巴瘤、白血病 |

#### 2.2 癌 vs 肉瘤

| 特征 | 癌（上皮来源） | 肉瘤（间叶来源） |
|------|--------------|----------------|
| 占比 | 约80%（最常见） | 少见 |
| 好发年龄 | 中老年 | 青少年多见 |
| 生长 | 较快 | 很快 |
| 转移 | 淋巴道为主 | 血道为主 |
| 例子 | 肺癌、胃癌、乳腺癌 | 骨肉瘤、平滑肌肉瘤 |

### 3. 良性 vs 恶性（生物学行为对比）

| 特征 | 良性肿瘤 | 恶性肿瘤 |
|------|---------|---------|
| 分化 | 好（像正常细胞） | 差（异型性大） |
| 生长方式 | 膨胀性（有包膜） | 浸润性（无包膜，边界不清） |
| 生长速度 | 慢 | 快 |
| 转移 | 不转移 | **可转移**（恶性标志） |
| 复发 | 少 | 多 |
| 对机体影响 | 压迫为主（局部） | 破坏+转移+恶病质（全身） |
| 营养意义 | 手术切除即愈 | ★营养支持是综合治疗一部分 |

> 注意：**良性≠无害**（如颅内良性肿瘤压迫致死）；**"原位癌"**（CIN/异型增生严重阶段）是"癌前"的最早癌变，未突破基底膜，**是干预的最后可逆窗口**。

### 4. 肿瘤发生三阶段（病理核心模型）

```
启动（Initiation）
   致癌物 → DNA损伤/突变（不可逆，但单个突变不够）
   ↓
促进（Promotion）
   促癌因素 → 突变细胞克隆性增殖（可逆！可被营养/化学物抑制）
   ↓
进展（Progression）
   更多突变累积 → 侵袭、转移（恶性度增加）
```

**营养师要抓的窗口：**

> 营养主要在**"促进"环节**可干预——减少促增殖信号（胰岛素/IGF-1、炎症、雌激素），增加抗增殖/促凋亡信号（纤维、植物化学物）。"促进"阶段可逆，"进展"阶段不可逆。

#### 各阶段营养干预点

| 阶段 | 特点 | 营养干预点 |
|------|------|-----------|
| 启动 | 基因突变，不可逆 | 减少致癌物摄入（加工肉、黄曲霉毒素、酒精）、抗氧化减少突变 |
| **促进** | 克隆增殖，**可逆** | ★减胰岛素/IGF-1（控糖控体重）、抗炎、植物化学物、纤维 |
| 进展 | 侵袭转移，不可逆 | 支持治疗、抗恶病质营养 |

### 5. 致癌因素

#### 5.1 化学致癌物

| 类别 | 例子 | 靶器官 |
|------|------|--------|
| 直接致癌物 | 烷化剂 | 多种 |
| 间接致癌物（需代谢活化） | 多环芳烃（烧烤烟熏）、亚硝胺（腌制食品）、黄曲霉毒素B1 | 肺、胃、肝 |
| 促癌物 | 乙醇、雌激素、胆酸 | 肝、乳腺、结肠 |

#### 5.2 物理致癌物

| 因素 | 靶点 |
|------|------|
| 紫外线 | 皮肤（黑色素瘤、基底细胞癌） |
| 电离辐射 | 白血病、甲状腺癌 |
| 石棉/粉尘 | 肺癌、间皮瘤 |

#### 5.3 生物致癌物（病原微生物）

| 病原 | 相关肿瘤 | IARC分级 |
|------|---------|---------|
| EB病毒 | 鼻咽癌、霍奇金淋巴瘤 | 1类 |
| 人乳头瘤病毒（HPV） | 宫颈癌、口咽癌 | 1类 |
| 乙型/丙型肝炎病毒 | 肝细胞癌 | 1类 |
| 幽门螺杆菌 | 胃癌 | 1类 |
| HHV-8 | Kaposi肉瘤 | 1类 |
| 华支睾吸虫 | 胆管癌 | 1类 |

> 营养与感染的交叉：**幽门螺杆菌**与胃癌强相关——分餐、卫生饮食是"食源性防癌"的一环。

### 6. 营养与肿瘤（IARC致癌归因综述为核心）

#### 6.1 肥胖与13种癌症（IARC 2016）

世界卫生组织国际癌症研究机构（IARC）2016年工作组基于大量流行病学证据，确认**肥胖（体脂过多）与至少13种癌症风险增加存在因果关联**：

| # | 癌症 | 关联强度 |
|---|------|---------|
| 1 | 食管腺癌 | 强 |
| 2 | 胃贲门癌 | 强 |
| 3 | 结直肠癌 | 强 |
| 4 | 肝癌 | 中-强 |
| 5 | 胆囊癌 | 强 |
| 6 | 胰腺癌 | 中 |
| 7 | 绝经后乳腺癌 | 强 |
| 8 | 卵巢癌 | 中 |
| 9 | 子宫内膜癌（宫体癌） | 强 |
| 10 | 肾癌（肾细胞癌） | 强 |
| 11 | 脑膜瘤 | 中 |
| 12 | 甲状腺癌 | 中 |
| 13 | 多发性骨髓瘤 | 中 |

**肥胖致癌的病理机制：**

```
肥胖 → 内脏脂肪 → 胰岛素抵抗 → 高胰岛素/IGF-1 → 促增殖抗凋亡
     → 脂肪组织芳香化酶 → 雌激素↑ → 乳腺癌/子宫内膜癌
     → 代谢性炎症（TNF-α/IL-6）→ 肿瘤微环境
     → 瘦素↑/脂联素↓ → 促生长信号
```

> **营养师话术核心：** 肥胖不只是"外形问题"，它是**13种癌症的已知危险因素**——减重到健康体重范围本身就是"防癌"。

#### 6.2 酒精与癌症（IARC 1类致癌物）

| 酒精相关肿瘤 | 机制 |
|------------|------|
| 口腔癌、咽癌、喉癌 | 乙醇→乙醛（DNA损伤） |
| 食管癌 | 乙醛+营养缺乏 |
| 肝癌 | 酒精性肝病→肝硬化→肝癌 |
| 结直肠癌 | 机制多环节 |
| 女性乳腺癌 | 雌激素↑ |

- IARC将酒精列为**1类致癌物**（对人类致癌证据充分）。
- 不存在"安全饮酒量"的致癌阈值（从防癌角度，越少越好）；但心血管角度有"J型曲线"争议，需权衡与个体化。
- 中国指南：成年人如饮酒，建议**男性每日酒精量<25g，女性<15g**（约啤酒750/450ml、葡萄酒250/150ml、白酒50/30ml）。

#### 6.3 加工肉与红肉（IARC 2015）

| 食物 | IARC分级 | 靶器官 | 建议 |
|------|---------|--------|------|
| **加工肉**（火腿、培根、香肠、腊肉） | **1类致癌物** | 结直肠癌 | 尽量少吃 |
| **红肉**（猪牛羊肉） | **2A类（很可能致癌）** | 结直肠癌 | 适量（中国膳食指南：<75g/日畜禽肉） |

**加工肉致癌机制：**

```
腌制/烟熏/亚硝酸盐
   ├─ N-亚硝基化合物（体内形成亚硝胺）→ DNA加合物
   ├─ 血红素铁 → 催化N-亚硝基化合物/脂质过氧化
   └─ 高温加工 → 杂环胺/多环芳烃
```

> 与"营养素"表述一致的讲法：**不是不能吃红肉，而是要控制量、优选加工方式**（蒸煮炖优于烧烤油炸），多吃蔬菜水果（抗氧化、纤维）平衡。

#### 6.4 膳食纤维与结直肠癌（WCRF证据充分）

- WCRF/AICR（世界癌症研究基金会）将"膳食纤维降低结直肠癌风险"列为**证据充分（convincing）**。
- 机制：
  ```
  膳食纤维
     ├─ 稀释/结合致癌物，加速转运（缩短接触时间）
     ├─ 发酵→丁酸→结肠细胞健康+诱导凋亡
     ├─ 增加粪便体积，稀释胆汁酸
     └─ 改善胰岛素敏感性
  ```
- 中国营养学会建议：膳食纤维 **25-30g/日**，多数人实际不足15g。

#### 6.5 植物化学物（Phytochemicals）的保护证据

| 类别 | 食物来源 | 机制 | 证据级别 |
|------|---------|------|---------|
| 十字花科硫代葡萄糖苷（萝卜硫素） | 西兰花、卷心菜 | 诱导解毒酶（Nrf2） | 观察性支持 |
| 多酚（儿茶素、花青素） | 茶、浆果 | 抗氧化、抑制NF-κB | 观察性 |
| 番茄红素 | 番茄 | 抗氧化 | 前列腺癌观察性 |
| 大蒜素 | 大蒜 | 抑制N-亚硝基化合物形成 | 观察性 |
| 姜黄素 | 姜黄 | 抗炎、抗增殖 | 实验室强、人体有限 |
| 大豆异黄酮 | 豆制品 | 雌激素调节 | 乳腺/前列腺观察性 |

> **严谨边界：** 植物化学物预防癌症的**直接证据多为观察性/实验室**，IARC/AICR未把单个植物化学物列为"充分证据降低癌症风险"。正确的讲法是：**"富含植物化学物的蔬菜水果整体降低多种癌症风险（证据中等-充分），而不是某一种提取物丸剂。"**

#### 6.6 高糖/胰岛素与肿瘤

```
高血糖/高糖饮食 → 高胰岛素 → IGF-1/胰岛素信号 → 促增殖、抗凋亡
```

- 胰岛素抵抗/糖尿病与多种癌风险升高相关（结直肠、胰腺、肝、子宫内膜、乳腺）。
- 但**"糖喂癌细胞"的说法要谨慎**：肿瘤确实偏好糖酵解（Warburg效应），但"饿死癌细胞"的断糖/生酮饮食缺乏人类证据，且可能造成营养不良——**营养师不能讲"吃糖喂癌、戒糖抗癌"。**
- 严谨表述："控制血糖和胰岛素水平，可能降低某些癌症的促进信号；整体健康饮食+体重管理是更可靠的防癌路径。"

#### 6.7 肿瘤恶病质（Cancer Cachexia）——营养师的"救命"战场

**定义：** 肿瘤患者出现的**持续性骨骼肌消耗（伴或不伴脂肪丢失）**，不能通过单纯增加进食完全逆转，是肿瘤死亡的常见直接原因（约20-30%肿瘤患者死于恶病质）。

**病理机制：**

```
肿瘤
   ├─ 促炎因子（TNF-α、IL-6）→ 肌肉蛋白分解↑、合成↓
   ├─ 代谢紊乱 → 静息能量消耗↑、糖异生↑
   ├─ 食欲下降（下丘脑信号紊乱）
   └─ 治疗副作用（化疗呕吐、放疗黏膜炎）→ 摄入↓
```

**营养对策（病理逻辑）：**

| 策略 | 病理学依据 |
|------|-----------|
| **足量优质蛋白**（1.2-2.0 g/kg/d，视肾功能） | 对抗肌肉分解，提供合成原料 |
| **能量充足**（避免"饿治"） | 肿瘤患者代谢高，能量不足加速消耗 |
| **n-3（EPA）** | 抗炎、改善食欲、护肌肉（有一定证据） |
| **少量多餐/高能高蛋白食物** | 克服食欲差、早饱 |
| **肠内营养优先**（口服营养补充） | 口服不足时，管饲优于肠外 |
| **运动（阻抗）** | 刺激肌肉合成，对抗恶病质 |

> **铁律：肿瘤患者不能饿。** "饿死肿瘤"是错误的——饿的是患者自己（肌肉和免疫）。营养支持不是"补品"，是肿瘤综合治疗的一部分。

## 八、各系统病理与营养

### 1. 肝脏病理（营养师核心章节）

#### 1.1 肝脏在营养代谢中的枢纽地位

肝脏是人体最大的代谢工厂：糖代谢（糖原合成/分解/糖异生）、脂代谢（脂蛋白合成、脂肪酸氧化）、蛋白合成（白蛋白、凝血因子）、解毒（药物/酒精/氨）、储存（糖原、铁、维A/D、B12）。

#### 1.2 脂肪肝四阶段（病理学主线）

```
① 单纯性脂肪肝（Steatosis）
     肝细胞胞质内脂滴堆积（≥5%肝细胞脂肪变）
     → 完全可逆（撤因即可）
     ↓
② 脂肪性肝炎（NASH/代谢相关脂肪性肝炎 MASH）
     脂肪 + 炎症（气球样变、肝细胞损伤）+ 可伴纤维化
     → 部分可逆（抗炎+减重可逆转/延缓）
     ↓
③ 肝纤维化（Fibrosis）
     星状细胞活化 → 胶原沉积
     → 可延缓/早期部分逆转
     ↓
④ 肝硬化（Cirrhosis）
     假小叶形成、弥漫纤维化、结构破坏
     → 不可逆
     ↓
（终末：肝癌 HCC，肝硬化→肝癌约年发生率2-4%）
```

#### 1.3 各阶段病理细节与可逆性

| 阶段 | 病理改变 | 临床信号（营养师能接触的） | 可逆性 | 营养干预窗口 |
|------|---------|--------------------------|--------|-------------|
| 单纯性脂肪肝 | 肝细胞脂滴（大泡性脂肪变） | 超声"脂肪肝"、ALT可正常 | **完全可逆** | ★减重5-10%、限糖限酒、地中海饮食 |
| 脂肪性肝炎 | 脂肪+炎症+气球样变 | ALT升高、FIB-4/弹性成像异常 | **部分可逆** | 更积极减重（7-10%）、抗炎、控代谢 |
| 肝纤维化 | 纤维间隔 | 弹性成像肝脏硬度↑ | **可延缓/早期可逆** | 继续代谢控制+纤维化监测 |
| 肝硬化 | 假小叶、门脉高压 | 脾大、血小板↓、白蛋白↓ | **不可逆** | 防并发症（低蛋白要遵医嘱，防肝性脑病） |
| 肝癌 | 肝细胞癌 | AFP、影像结节 | — | 早筛（肝硬化者每6个月） |

#### 1.4 脂肪肝的危险因素与营养对应

| 危险因素 | 病理机制 | 营养对策 |
|---------|---------|---------|
| **肥胖/内脏脂肪** | 游离脂肪酸↑→肝脏脂质堆积 | 减重（核心） |
| **胰岛素抵抗/糖尿病** | 胰岛素↑→脂质合成↑ | 控糖、低GI |
| **酒精** | 乙醇代谢→乙醛→脂质堆积+炎症 | 限酒/戒酒 |
| **高糖/果糖过量** | 果糖绕过糖酵解调控→直接促脂质合成 | 减含糖饮料/高果糖加工食品 |
| 高脂高能量 | 脂质底物过剩 | 控制总能量、减饱和脂肪 |
| 蛋白质缺乏 | 脂蛋白合成↓→脂质转运障碍 | 优质蛋白（营养不良性脂肪肝） |
| 快速减重 | 脂质动员过快→肝脏堆积 | 缓慢减重（0.5-1kg/周） |

> **重要命名更新：** 全球已从"非酒精性脂肪性肝病（NAFLD）"改为**代谢相关脂肪性肝病（MAFLD/MASLD）**——强调它本质是**代谢性疾病**，而不是"排除了酒精就没别的原因"。这更支持营养师的定位：脂肪肝是"吃出来的代谢病"，要整体管代谢。

#### 1.5 其他肝脏病理

| 病变 | 说明 | 营养相关 |
|------|------|---------|
| 酒精性肝病 | 脂肪肝→酒精性肝炎→肝硬化 | 戒酒是根本 |
| 病毒性肝炎（乙肝/丙肝） | →肝硬化→肝癌 | 营养支持+控代谢减少进展 |
| 肝豆状核变性（Wilson病） | 铜代谢障碍 | 低铜饮食（遵医嘱） |
| 药物性肝损伤 | 药物代谢毒性 | 慎用成分不明的营养补充剂类制品 |

> ⚠️ 合规提示：**"保肝"不能替代病因治疗**。脂肪肝的第一处方是减重+戒酒+控糖，不是"吃某款保肝营养素"。营养干预是生活方式干预的组成部分，不是药品。

### 2. 肾脏病理（肾病营养依据）

#### 2.1 肾脏的结构与功能单位

- 功能单位：**肾单位**（肾小球+肾小管）。
- 肾小球：滤过血液（滤过屏障：内皮、基膜、足细胞）。
- 肾小管：重吸收+分泌。

#### 2.2 核心病理改变

| 病理改变 | 定义 | 临床信号 |
|---------|------|---------|
| **肾小球硬化**（Glomerulosclerosis） | 肾小球玻璃样变/硬化→功能单位丢失 | 蛋白尿、肌酐↑ |
| **肾间质纤维化** | 间质胶原沉积 | 肾功能进行性下降 |
| **肾小管萎缩** | 肾小管上皮丢失 | 浓缩功能↓ |
| **蛋白尿** | 滤过屏障破坏，蛋白漏出 | 尿蛋白阳性 |

#### 2.3 慢性肾脏病（CKD）进展的营养逻辑

```
肾单位减少（高血压/糖尿病/肾小球肾炎）
   ↓
残余肾小球高滤过（代偿）
   ↓
高滤过→肾小球内高压→进一步硬化（"过度工作反而加速坏"）
   ↓
肾功能进行性下降 → 终末期肾病
```

**关键病理概念：肾小球高滤过理论**——残余肾单位"超负荷工作"反而加速损伤。这就是营养干预的理论基础：

| 干预 | 病理逻辑 |
|------|---------|
| **限制蛋白**（CKD 3期起0.6-0.8g/kg/d，遵医嘱） | 减少高滤过、减少含氮废物（尿素氮） |
| **优质蛋白为主**（乳、蛋、瘦肉） | 必需氨基酸更充分 |
| **控制血压（限钠）** | 减少肾小球内高压 |
| **控糖** | 糖尿病肾病的第一要务 |
| **限磷/限钾**（晚期） | 防高磷血症、高钾血症 |
| **充足能量** | 防蛋白分解（营养状态恶化的肾病患者仍需能量） |

> ⚠️ **严谨边界：** "低蛋白饮食保护肾脏"只适用于**已确诊CKD且经评估**的患者（需要医生/营养师个体化处方），**健康人**盲目低蛋白反而有害。营养师不能自行给顾客"降蛋白"建议。

#### 2.4 蛋白尿的意义

- 蛋白尿 = 肾小球滤过屏障（尤其足细胞）损伤的标志。
- 微量白蛋白尿是糖尿病肾病最早信号之一（糖友应定期查尿微量白蛋白）。
- 蛋白尿本身又进一步损伤肾小管（蛋白超负荷→肾小管炎症）。

### 3. 肥胖病理（脂肪组织作为"内分泌器官"）

#### 3.1 肥胖的病理本质

```
能量摄入 > 能量消耗（长期）
   ↓
脂肪细胞肥大（体积增大）
   ↓
脂肪细胞增生（数量增多，多在童年/青年期定数）
   ↓
脂肪组织缺氧、应激 → 细胞死亡
   ↓
巨噬细胞浸润（"脂肪组织炎症化"）
   ↓
内分泌紊乱 + 代谢性炎症
```

#### 3.2 脂肪组织的内分泌功能（病理第9版强调）

| 脂肪因子 | 肥胖时变化 | 作用 |
|---------|-----------|------|
| **瘦素（Leptin）** | ↑，但抵抗 | 抑制食欲（抵抗时失灵）→"越胖越饿" |
| **脂联素（Adiponectin）** | ↓ | 增敏胰岛素、抗炎、抗动脉硬化（"好因子"下降） |
| TNF-α、IL-6 | ↑ | 促炎、胰岛素抵抗 |
| 抵抗素（Resistin） | ↑ | 胰岛素抵抗 |
| 雌激素（经芳香化酶） | ↑（脂肪转化雄激素） | 乳腺癌/子宫内膜癌风险 |

#### 3.3 肥胖→慢病的病理桥梁

```
肥胖（脂肪组织炎症化）
   ├─ → 胰岛素抵抗 → 2型糖尿病（90%以上2型糖尿病超重/肥胖相关）
   ├─ → 脂肪肝（MAFLD）
   ├─ → 动脉粥样硬化
   ├─ → 高血压（肾素-血管紧张素、钠潴留）
   ├─ → 睡眠呼吸暂停（颈部脂肪）
   ├─ → 骨关节炎（承重+炎症）
   ├─ → 13种癌风险↑（IARC）
   └─ → 肌少性肥胖（脂肪↑+肌肉↓→更差预后）
```

#### 3.4 减重的病理效应（营养干预的"复利"）

| 减重幅度 | 病理改善 |
|---------|---------|
| 5% | 甘油三酯、血糖、内脏脂肪开始改善 |
| 5-10% | 脂肪肝显著改善、胰岛素敏感性↑ |
| 10-15% | 2型糖尿病缓解的可能性显著增加（DiRECT研究） |
| >15% | 心血管风险因子大幅下降 |

> **营养师核心讲法：** 减重不是"为了好看"，是**给脂肪组织"灭火"、给胰岛素"松绑"、给13种癌"降温"**——减重的病理收益是全方位的。

### 4. 胰腺病理（糖尿病相关，补充）

| 病变 | 病理 | 营养相关 |
|------|------|---------|
| 胰岛B细胞功能障碍 | B细胞凋亡/去分化→胰岛素分泌不足 | 早期保护B细胞（控糖减重） |
| 2型糖尿病 | 胰岛素抵抗+B细胞分泌相对不足 | 减重+控糖+运动 |
| 急性胰腺炎 | 胰酶自身消化→脂肪坏死 | 高脂血症诱发者需控脂 |
| 胰腺癌 | 恶性度极高 | 恶病质严重，营养支持 |
