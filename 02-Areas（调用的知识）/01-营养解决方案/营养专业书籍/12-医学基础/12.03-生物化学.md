# 12.03 · 生物化学（小书版）

> **一句话定位：** 营养学的化学底子——三大营养素在体内怎么代谢、能量怎么产生、酶怎么工作、基因怎么被营养影响。讲"脂肪肝的代谢原理""为什么减重要吃蛋白""辅酶Q10干嘛用"都从这里来。

## 〇、阅读指南

### 1. 这门课解决什么问题

生物化学研究**生命的化学基础**——生物大分子的结构与功能、物质代谢、能量转化、基因信息传递。营养师看生化，重点抓住一条主线：

```
吃进去的食物（糖/脂/蛋白）
   ↓ 消化吸收
血液里的营养素
   ↓ 细胞内代谢（生化反应，需要酶的催化）
ATP 能量 + 生物合成原料 + 代谢废物（排出）
```

| 营养师的问题 | 对应的生化章节 |
|------------|--------------|
| 为什么缺 B 族就累？ | 酶与维生素（辅酶） |
| 为什么果糖伤肝？ | 糖代谢（果糖途径） |
| 为什么减重要吃蛋白？ | 蛋白质代谢（氮平衡） |
| 为什么辅酶Q10 重要？ | 能量代谢（呼吸链） |
| 为什么叶酸影响基因？ | 分子营养（DNA甲基化） |
| 化验单上的指标是什么意思？ | 常见代谢物与化验 |

### 2. 与《生理学》的分工

| 学科 | 看什么 | 举例 |
|------|--------|------|
| 生理学 | 器官系统的功能与调节 | 胰岛素怎么指挥细胞 |
| 生物化学 | 分子层面的化学反应 | 糖在细胞里怎么一步步变 ATP |

### 3. 全书结构地图

```
第一板块：结构与功能（酶、维生素、矿物质辅因子）
第二板块：物质代谢（糖、脂、蛋白三大路线）
第三板块：能量代谢（ATP 三途径、呼吸链）
第四板块：分子营养（基因、表观遗传、信号通路）
第五板块：化验衔接（代谢物与临床指标）
```

## 一、生物化学概览

### 1. 生物大分子四大类

| 大分子 | 单体 | 主要功能 |
|--------|------|---------|
| 蛋白质 | 氨基酸 | 结构、酶、激素、抗体、运输 |
| 核酸 | 核苷酸 | 遗传信息（DNA/RNA） |
| 多糖 | 单糖 | 能量储存、结构 |
| 脂质 | 脂肪酸/甘油等 | 能量、细胞膜、信号分子 |

### 2. 代谢的总格局

```
合成代谢（同化）：小分子 → 大分子（需能量）
    ↑
代谢中间池（乙酰CoA 等枢纽）
    ↓
分解代谢（异化）：大分子 → 小分子 → 能量（ATP）
```

**代谢的三大枢纽分子：**

| 枢纽分子 | 地位 |
|---------|------|
| 乙酰CoA | 糖/脂/蛋白代谢的交汇点，进入 TCA 的"门票" |
| 葡萄糖-6-磷酸 | 糖酵解/糖原/磷酸戊糖途径的分岔口 |
| 丙酮酸 | 糖代谢的节点（有氧→乙酰CoA；无氧→乳酸；回补→糖异生） |

### 3. 与营养最相关的三大块

```
① 三大营养素代谢（糖/脂/蛋白）
② 能量代谢（ATP产生）
③ 酶与辅酶（营养素是辅酶的原料！）
```

> **一句话：** 你吃的营养素，很大一部分是去当"酶的零件"（辅酶/辅因子）的。营养素不足 = 零件缺失 = 代谢机器卡壳。

## 二、酶与维生素的关系（重点中的重点）

### 1. 酶的基本特性

**酶**是生物催化剂，绝大多数是蛋白质（少数为 RNA，即核酶）。

| 特性 | 说明 |
|------|------|
| 高效性 | 催化效率比非酶催化高 10^6~10^12 倍 |
| 专一性 | 一种酶通常只催化一种或一类反应 |
| 可调节性 | 活性可被底物、产物、激素、变构调节 |
| 不稳定性 | 对温度、pH 敏感（过热变性失活） |

### 2. 辅因子：酶的"零件盒"

很多酶单独存在时无活性，必须与**辅因子**结合才有活性。

```
全酶 = 酶蛋白 + 辅因子
                ├── 金属离子（无机辅因子）：镁、锌、硒、铜、铁……
                └── 辅酶/辅基（有机小分子，多为维生素衍生物）
                    ├── 辅酶：与酶蛋白结合较松（透析可除去）
                    └── 辅基：与酶蛋白结合牢固
```

> **营养师核心认知：** B 族维生素大多要转成辅酶才能干活。所以"补B族"本质是给代谢机器补零件。

### 3. B族维生素 → 辅酶全表（必须熟）

| 维生素 | 活性形式（辅酶） | 参与的关键反应 | 缺乏后果 |
|--------|-----------------|---------------|---------|
| B1 硫胺素 | TPP（焦磷酸硫胺素） | 丙酮酸脱氢酶、α-酮戊二酸脱氢酶、转酮醇酶 | 脚气病、Wernicke脑病、乏力 |
| B2 核黄素 | FAD / FMN | 琥珀酸脱氢酶、呼吸链复合物Ⅰ、脂肪酸β氧化 | 口角炎、唇炎、舌炎、眼疲劳 |
| B3 烟酸 | NAD⁺ / NADP⁺ | 糖酵解、TCA、呼吸链、脂肪/胆固醇合成 | 糙皮病（皮炎、腹泻、痴呆） |
| B5 泛酸 | CoA（辅酶A）、ACP（酰基载体蛋白） | 脂肪酸合成/氧化、TCA、胆固醇合成 | 罕见（肠道菌可合成） |
| B6 吡哆醇 | PLP（磷酸吡哆醛） | 转氨基、脱羧（GABA合成）、血红素合成 | 周围神经病变、皮炎 |
| B7 生物素 | 生物素化羧化酶（丙酮酸羧化酶、乙酰CoA羧化酶） | 糖异生、脂肪酸合成 | 皮炎、脱发（生蛋清含抗生物素蛋白） |
| B9 叶酸 | THF（四氢叶酸） | 一碳单位转移、dTMP/嘌呤合成 | 巨幼细胞性贫血、同型半胱氨酸↑、神经管缺陷 |
| B12 钴胺素 | 甲钴胺、腺苷钴胺 | 甲硫氨酸合成酶（同型半胱氨酸→甲硫氨酸）、甲基丙二酰CoA变位酶 | 巨幼细胞性贫血、脊髓亚急性联合变性 |

> 🔑 **一句话：** B族维生素缺乏 → 辅酶不足 → 能量代谢全线卡壳。这就是为什么"累、乏力、注意力差"常与B族有关。

### 4. 各 B 族维生素缺缺乏的代谢后果详解

#### B1 缺乏（硫胺素）
- TPP 参与丙酮酸 → 乙酰CoA 的关键步骤。B1 不足 → 丙酮酸堆积 → 能量供应不足。
- **神经症状**：Wernicke 脑病（共济失调、眼肌麻痹）、Korsakoff 综合征（记忆障碍）——常见于酗酒者（酒精干扰 B1 吸收和活化）。
- **循环症状**：脚气病性心衰、水肿。
- **营养应用**：主食过精（精白米面损失 B1）+ 酒精 → 高危；多吃全谷、豆类、瘦猪肉。

#### B2 缺乏（核黄素）
- FAD/FMN 参与呼吸链和脂肪酸β氧化 → 能量代谢受影响。
- **典型表现**：口角炎、唇炎、舌炎、脂溢性皮炎、畏光。
- **营养应用**：奶类、蛋、绿叶菜、动物肝脏；B2 遇光易破坏（牛奶避光储存）。

#### B3 缺乏（烟酸）
- NAD⁺/NADP⁺ 是体内最广泛使用的辅酶（几百种脱氢酶）。
- **糙皮病（pellagra）3D**：皮炎（Dermatitis）、腹泻（Diarrhea）、痴呆（Dementia）。
- **有趣点**：色氨酸可在体内转化为烟酸（60mg 色氨酸≈1mg 烟酸当量），所以"高蛋白人群"相对耐受缺烟酸；玉米为主的膳食易缺乏（玉米中烟酸为结合型，需碱处理）。
- **营养应用**：动物肝脏、瘦肉、鱼、花生；烟酸大剂量（超量）可引起面色潮红、肝损伤——**不作为常规大剂量补充**。

#### B5 缺乏（泛酸）
- CoA 是脂肪酸代谢、TCA 的"快递员"。
- 人类缺乏极罕见（广泛存在于食物，肠道菌也能合成）。

#### B6 缺乏（吡哆醇）
- PLP 是氨基酸代谢的核心辅酶（转氨基、脱羧、脱硫）。
- **作用链接**：GABA（抑制性神经递质）合成需要 B6 → 缺乏可致兴奋、烦躁；血红素合成需要 B6 → 可致小细胞性贫血（少见）。
- 长期异烟肼（抗结核药）治疗可致 B6 缺乏。
- **营养应用**：肉类、全谷、豆类、香蕉；高蛋白饮食者 B6 需求相对增加。

#### B7 缺乏（生物素）
- 生物素是"羧化酶"的零件：丙酮酸羧化酶（糖异生）、乙酰CoA羧化酶（脂肪酸合成）、丙酰CoA羧化酶。
- **生蛋清陷阱**：生鸡蛋清含**抗生物素蛋白**，与生物素结合阻止吸收 → 长期大量吃生蛋清可致缺乏（皮炎、脱发、神经症状）。
- **营养应用**：鸡蛋要熟吃；蛋黄、肝脏、酵母富含生物素。

#### B9 缺乏（叶酸）
- THF 是"一碳单位"载体，参与 dTMP 合成（DNA合成必需）和嘌呤合成。
- **后果链**：细胞分裂快（造血、胎儿）最敏感 → 巨幼细胞性贫血；同型半胱氨酸↑ → 心血管风险；**孕早期缺乏 → 胎儿神经管缺陷**（脊柱裂、无脑儿）。
- **营养应用**：孕前 3 个月至孕早期补充叶酸 400μg/天（我国孕产妇指南推荐，遵医嘱）；深绿叶菜、豆类、肝脏富含；叶酸怕热怕氧化。

#### B12 缺乏（钴胺素）
- 甲钴胺参与甲硫氨酸合成酶反应：同型半胱氨酸 + 甲基 → 甲硫氨酸（同型半胱氨酸代谢的核心）。
- 腺苷钴胺参与甲基丙二酰CoA → 琥珀酰CoA（脂肪酸氧化副产物处理）。
- **后果链**：巨幼细胞性贫血（与叶酸缺乏表现类似）+ **神经损害**（脊髓亚急性联合变性：麻木、步态不稳）——因为髓鞘更新需要 B12。
- **吸收特殊性**：B12 需胃壁细胞分泌的**内因子**才能在回肠吸收 → 胃切除、萎缩性胃炎、长期服抑酸药者易缺；**素食者**（不食肉蛋奶）风险高。
- **营养应用**：动物肝、肉、鱼、蛋、奶；素食者建议关注强化食品或遵医嘱补充；B12 补充与叶酸补充可掩盖贫血表现（需先查）。

### 5. 胆碱、肌醇等"类维生素"物质（营养师了解即可）

| 物质 | 作用 | 营养来源 |
|------|------|---------|
| 胆碱 | 磷脂（卵磷脂）组分、乙酰胆碱前体、甲基供体（→甜菜碱） | 蛋黄、大豆、肝脏 |
| 肌醇 | 磷脂酰肌醇组分、信号分子 IP3 前体 | 全谷、豆类 |
| 肉碱 | 脂肪酸进入线粒体的"摆渡船"（转运长链脂肪酸） | 肉、奶 |

> **营养应用：** 胆碱与叶酸/B12 同属"甲基代谢"网络，共同影响同型半胱氨酸和肝脂肪代谢。

### 6. 矿物质作为辅因子（无机辅因子）

| 矿物质 | 作为什么酶的辅因子 | 功能举例 | 缺乏表现 |
|--------|-------------------|---------|---------|
| 镁 | 300+ 酶（激酶、ATP酶） | ATP 必须结合镁才有活性 | 肌肉痉挛、疲劳、心律失常风险 |
| 锌 | 300+ 酶（DNA聚合酶、碳酸酐酶、碱性磷酸酶）、锌指蛋白 | DNA合成、味觉、免疫、伤口愈合 | 味觉减退、生长迟缓、免疫↓ |
| 硒 | 谷胱甘肽过氧化物酶（GPx）、硫氧还蛋白还原酶、脱碘酶 | 抗氧化、甲状腺激素激活 | 克山病（心肌）、免疫功能↓ |
| 铜 | 细胞色素c氧化酶（复合物Ⅳ）、铜锌SOD、铜蓝蛋白 | 呼吸链、抗氧化、铁转运 | 贫血（铁利用受阻）、结缔组织异常 |
| 铁 | 血红素酶（过氧化氢酶）、细胞色素、铁硫簇蛋白 | 携氧、呼吸链 | 缺铁性贫血、疲劳、怕冷 |
| 锰 | 锰超氧化物歧化酶（MnSOD） | 线粒体抗氧化 | 少见 |
| 钼 | 黄嘌呤氧化酶 | 尿酸代谢 | 罕见 |
| 铬 | （增强胰岛素信号，机制尚在研究中） | 糖代谢辅助 | 意义尚存争议，不过度强调 |

> 🔑 **一句话：** 金属离子不仅是酶的"零件"，还常是"结构件"（锌指蛋白）和"电子搬运工"（铁、铜在呼吸链）。缺了它们，能量代谢、抗氧化、免疫全线受影响。

### 7. 营养应用

| 生化原理 | 营养方案依据 |
|---------|-------------|
| B族=辅酶 | 均衡B族来源：全谷+豆类+蛋奶肉+深绿叶菜 |
| B1/B2/B3→能量 | 疲劳人群排查精制碳水+酒精+奶类不足 |
| 叶酸/B12→DNA与神经 | 备孕/孕期叶酸；老年/胃病患者查B12 |
| B6→氨基酸代谢 | 高蛋白饮食需足量B6 |
| 生物素 | 不吃生蛋清 |
| 镁/锌/硒/铜/铁 | 坚果、海产品、全谷、肉、深绿叶菜多样摄入 |

## 三、糖代谢详解

### 1. 糖的消化吸收与总体去向

```
膳食碳水
  ↓（唾液淀粉酶/胰淀粉酶/肠刷状缘酶）
葡萄糖、果糖、半乳糖
  ↓（小肠吸收 → 门静脉 → 肝）
血糖池（肝脏是"总调度"）
  ├── 氧化供能（糖酵解→TCA→呼吸链）
  ├── 合成糖原（肝/肌储存）
  ├── 转成脂肪（过剩时，肝）
  ├── 转成氨基酸（非必需）
  └── 磷酸戊糖途径（NADPH+核糖）
```

### 2. 糖酵解（无氧/有氧的共同起点）

**位置**：细胞浆。**过程**：葡萄糖 → 2×丙酮酸。

```
葡萄糖
  ↓ 已糖激酶（消耗2ATP）
果糖-6-磷酸
  ↓ 磷酸果糖激酶-1（PFK-1，限速酶！）
果糖-1,6-二磷酸
  ↓
磷酸二羟丙酮 ⇌ 3-磷酸甘油醛
  ↓
2 × 丙酮酸
（净产 2ATP + 2NADH）
```

| 关键酶 | 作用 | 调节 |
|--------|------|------|
| 己糖激酶 | 葡萄糖→6-磷酸葡萄糖 | 被产物抑制 |
| 磷酸果糖激酶-1（PFK-1） | 限速酶 | ATP/柠檬酸抑制；AMP/F-2,6-BP激活 |
| 丙酮酸激酶 | PEP→丙酮酸 | ATP抑制；果糖-1,6-BP激活 |

**有氧 vs 无氧去向：**

| 条件 | 丙酮酸去向 | 产物 |
|------|-----------|------|
| 有氧 | 进入线粒体 → 乙酰CoA → TCA | 大量ATP |
| 无氧（剧烈运动/缺氧） | 乳酸（乳酸脱氢酶 LDH） | 2ATP + 乳酸 |

> **营养应用：** 运动后肌肉酸痛主要来自乳酸的短暂堆积（和微细损伤），几天内代谢清除；高蛋白/碳水补充帮助恢复糖原。

### 3. 有氧氧化的三大步

```
① 丙酮酸 → 乙酰CoA（丙酮酸脱氢酶复合体，需 TPP/B1、FAD/B2、NAD/B3、CoA/B5、硫辛酸）
② 乙酰CoA 进入 TCA 循环（三羧酸循环，线粒体基质）
③ NADH/FADH2 进入呼吸链 → 氧化磷酸化 → ATP
```

**TCA 循环（Krebs循环）每轮产物：**

```
乙酰CoA + 草酰乙酸
  → 柠檬酸 → 异柠檬酸 → α-酮戊二酸 → 琥珀酰CoA → 琥珀酸 → 延胡索酸 → 苹果酸 → 草酰乙酸（循环）
产：3 NADH + 1 FADH2 + 1 GTP（或ATP）+ 2 CO₂
```

| 位置 | 线粒体基质 |
|------|-----------|
| 意义 | 三大营养素的共同"终点站"（糖、脂、蛋白的碳骨架都汇入） |
| 回补反应 | 草酰乙酸等中间物被移走（用于糖异生等）后需回补（如丙酮酸羧化，需生物素） |

### 4. 糖异生——"空腹保血糖"的关键

**糖异生**：非糖物质（乳酸、甘油、生糖氨基酸）在肝（及少量肾皮质）合成葡萄糖。

```
乳酸/甘油/生糖氨基酸
  ↓（反向多数糖酵解步骤，需绕过3个不可逆步骤）
葡萄糖
```

| 关键酶（绕过不可逆步骤） | 所在反应 |
|--------------------------|---------|
| 丙酮酸羧化酶（需生物素） | 丙酮酸 → 草酰乙酸 |
| 磷酸烯醇式丙酮酸羧激酶（PEPCK） | 草酰乙酸 → PEP |
| 果糖-1,6-二磷酸酶 | 果糖-1,6-二磷酸 → 果糖-6-磷酸 |
| 葡萄糖-6-磷酸酶 | 葡萄糖-6-磷酸 → 葡萄糖（**仅肝/肾有**，肌没有） |

> **关键认知：** 肌肉不能直接释放葡萄糖（没有葡萄糖-6-磷酸酶）——肌肉里的糖原只能自己用。所以空腹时维持血糖主要靠**肝糖原分解**和**肝糖异生**。

### 5. 糖原合成与分解

| 项目 | 肝糖原 | 肌糖原 |
|------|--------|--------|
| 作用 | 维持血糖（释放葡萄糖入血） | 肌肉自身供能（不外供） |
| 关键酶 | 糖原磷酸化酶、葡萄糖-6-磷酸酶 | 糖原磷酸化酶（无 G-6-Pase） |
| 储量 | 约 100g（成人） | 约 200~400g（成人） |
| 调控 | 胰高血糖素/肾上腺素促分解 | 肾上腺素、钙促分解 |

```
血糖低 → 胰高血糖素 → 肝糖原分解 → 葡萄糖释放 → 血糖回升
运动 → 肾上腺素 → 肝+肌糖原分解 → 供能
```

> **营养应用：** 运动前补充碳水可"装满糖原库"，运动后 30~60 分钟内补碳水+蛋白恢复糖原最有效（糖原合成酶活性高）。

### 6. 磷酸戊糖途径（PPP）——"NADPH 工厂"

**位置**：细胞浆。**特点**：不走产能主线，产**NADPH** 和 **核糖-5-磷酸**。

```
葡萄糖-6-磷酸
  ↓ 葡萄糖-6-磷酸脱氢酶（G6PD，关键酶）
6-磷酸葡萄糖酸
  ↓
核酮糖-5-磷酸 → 核糖-5-磷酸（核酸合成原料）
       ↓
    产生 2 NADPH
```

| 产物 | 用途 |
|------|------|
| NADPH | ① 抗氧化（还原型谷胱甘肽再生）② 脂肪酸/胆固醇合成（还原力）③ 药物代谢 |
| 核糖-5-磷酸 | DNA/RNA 合成的"糖骨架" |

> **营养关联（G6PD 缺乏/蚕豆病）：** 葡萄糖-6-磷酸脱氢酶缺乏者（我国南方常见），NADPH 生成不足 → 红细胞抗氧化能力下降 → 接触氧化应激（蚕豆、部分药物）时溶血。这是遗传病，与"吃豆"有关但不是营养缺乏。

### 7. 果糖代谢与脂肪肝——"最伤肝的糖"

**果糖的"特立独行"之处：**

| 项目 | 葡萄糖 | 果糖 |
|------|--------|------|
| 吸收 | SGLT1 主动转运 | GLUT5 易化扩散 |
| 进入细胞后 | 可被胰岛素调节 | 不依赖胰岛素 |
| 限速调控 | PFK-1 受 ATP/柠檬酸抑制（"刹车"灵敏） | 果糖激酶不受这些抑制（"刹车"失灵） |
| 代谢去向 | 全身体细胞广泛利用 | 主要被肝脏摄取 |

**果糖 → 脂肪肝的代谢链：**

```
大量果糖（尤其含糖饮料/高果糖玉米糖浆）
  ↓（肝脏，果糖激酶，无反馈刹车）
果糖-1-磷酸
  ↓（醛缩酶B）
甘油醛 + 磷酸二羟丙酮
  ↓
绕过 PFK-1 调控 → 大量进入乙酰CoA → 脂肪酸合成（de novo 脂质合成）
  ↓
肝脏甘油三酯堆积 → 脂肪肝 + 血脂异常 + 尿酸↑（嘌呤代谢）→ 胰岛素抵抗
```

> 🔑 **营养师重点：** "果糖不是血糖友好那么简单"——果糖不直接刺激胰岛素、GI 低，但它绕过了代谢刹车，过量时**直接喂给肝脏做脂肪**。含糖饮料是最典型的"液体果糖炸弹"。水果中的果糖有膳食纤维、多酚等"减速带"，但果汁/饮料没有。

### 8. 糖代谢紊乱的化验链接（简单预告，详见第六章）

| 状态 | 生化表现 |
|------|---------|
| 空腹血糖正常 | 3.9~6.1 mmol/L |
| 空腹血糖受损 | 6.1~7.0 mmol/L |
| 糖尿病 | 空腹 ≥7.0 或餐后2h ≥11.1（需复测确认） |
| 糖化血红蛋白 HbA1c | 反映近 2~3 个月血糖均值 |

### 9. 营养应用

| 糖代谢原理 | 营养方案依据 |
|-----------|-------------|
| PFK-1 刹车 | 高 GI 快速供能（运动后）vs 低 GI 平稳供能（日常） |
| 糖异生 | 空腹时段身体动用糖异生 → 早餐别长期不吃 |
| 糖原库 | 运动前后补碳水策略 |
| 磷酸戊糖途径 | 蔬果抗氧化（NADPH 支持谷胱甘肽系统） |
| 果糖代谢 | 少含糖饮料，警惕"无GI之忧的果糖陷阱" |
| 酒精干扰 | 酒精抑制糖异生 → 空腹饮酒易低血糖 |

## 四、脂代谢详解

### 1. 脂质的分类与功能

| 脂质 | 功能 |
|------|------|
| 甘油三酯 | 能量储存（脂肪组织）、保温、保护 |
| 磷脂 | 细胞膜骨架、信号分子 |
| 胆固醇 | 细胞膜、类固醇激素、胆汁酸、维生素D前体 |
| 游离脂肪酸 | 能量燃料、信号分子 |
| 鞘脂 | 神经髓鞘、信号 |
| 类二十烷酸（前列腺素等） | 炎症/免疫调节 |

### 2. 脂肪动员——"烧脂"的第一步

```
脂肪组织甘油三酯
  ↓ 激素敏感性脂肪酶（HSL，被肾上腺素/胰高血糖素激活、胰岛素抑制）
甘油 + 游离脂肪酸
  ↓
血液（白蛋白运输）→ 组织细胞 → β氧化
```

> **营养应用：** 胰岛素是脂肪动员的"刹车"——高胰岛素血症时脂肪"烧"得少、存得多。减脂需要降低胰岛素水平（低碳/少精制糖）+ 运动。

### 3. β氧化——脂肪酸的"燃烧车间"

**位置**：线粒体。长链脂肪酸需**肉碱穿梭**（CPT-1）进入线粒体。

```
脂肪酸（n个碳）
  ↓ 活化（脂酰CoA，耗2ATP）
  ↓ 肉碱穿梭（CPT-1 限速）
  ↓ 每轮β氧化：脱氢(FADH2)→加水→再脱氢(NADH)→硫解
乙酰CoA（每轮切下2碳）+ FADH2 + NADH
  ↓
TCA → 呼吸链 → ATP
```

| 每轮β氧化产物 | 后续去向 |
|--------------|---------|
| 1 乙酰CoA | TCA → CO₂ + ATP |
| 1 FADH2 | 呼吸链 → 约1.5 ATP |
| 1 NADH | 呼吸链 → 约2.5 ATP |

**一分子棕榈酸（16碳）完全氧化净产约 106 ATP**——所以脂肪是"高密度燃料"。

> **营养应用：** 中链甘油三酯（MCT）不需肉碱穿梭、直接进线粒体快速氧化 → 生酮友好、快速供能；但 MCT 大量使用有肠胃不适。

### 4. 酮体——"低碳时的备用燃料"

```
饥饿/低碳/生酮时，肝内：
乙酰CoA 过剩（β氧化强）
  ↓（乙酰乙酰CoA → HMG-CoA →）
酮体：乙酰乙酸 + β-羟丁酸 + 丙酮（少量）
  ↓ 释放入血
肝外组织（脑、心、肌肉）氧化利用（肝自身不能利用酮体）
```

| 酮体成分 | 性质 |
|---------|------|
| β-羟丁酸 | 主要成分（酸性） |
| 乙酰乙酸 | 中间 |
| 丙酮 | 少量，呼出有"水果味" |

| 状态 | 酮体水平 |
|------|---------|
| 正常（餐后/轻度空腹） | 极低 |
| 长时间禁食/低碳 | 升高（生理性酮症） |
| 1型糖尿病血糖失控 | 急剧升高（酮症酸中毒，危险！） |

> **营养应用：** 生理性酮症（低碳饮食）与糖尿病酮症酸中毒是两回事。生酮饮食需在专业人士指导下进行；**糖尿病/孕妇/肾病人群不建议自行生酮**。

### 5. 脂蛋白——血液里运脂的"货车"

| 脂蛋白 | 核心内容 | 功能 | "好坏"直觉 |
|--------|---------|------|-----------|
| 乳糜微粒 CM | 外源性甘油三酯（来自膳食脂肪） | 把饮食脂肪运到组织 | 餐后升高，正常 |
| VLDL | 内源性甘油三酯（肝合成） | 把肝脂运到组织 | 高→TG高 |
| LDL | 胆固醇（最多） | 把胆固醇运到外周（血管壁） | "坏胆固醇" |
| HDL | 胆固醇（逆向运输） | 从外周回收胆固醇回肝 | "好胆固醇" |

```
膳食脂肪 → CM → 组织利用/储存
肝合成脂肪 → VLDL → 组织；VLDL 残余 → LDL
外周胆固醇 → HDL → 肝（逆向胆固醇转运）
```

| 血脂指标 | 合适水平参考 |
|---------|-------------|
| 甘油三酯 TG | <1.7 mmol/L |
| 总胆固醇 TC | <5.2 mmol/L |
| LDL-C | <3.4 mmol/L（高危人群目标更低） |
| HDL-C | 男性 >1.0，女性 >1.3 mmol/L |

> **营养应用：** 高 TG → 减精制碳水和糖（糖→肝合成TG）+ 限酒 + n-3；高 LDL → 限饱和脂肪/反式脂肪 + 可溶性纤维（燕麦、豆类）。血脂管理需结合整体心血管风险评估，遵医嘱。

### 6. 胆固醇合成与"限饱和脂肪的道理"

**胆固醇合成**主要在**肝脏**：

```
乙酰CoA + NADPH（磷酸戊糖途径提供还原力）
  ↓ HMG-CoA 还原酶（限速酶！他汀类药物靶点）
甲羟戊酸 → … → 鲨烯 → 羊毛固醇 → 胆固醇
```

| 调节因素 | 对 HMG-CoA 还原酶 |
|---------|------------------|
| 胆固醇高 | 抑制（反馈） |
| 胰岛素 | 激活（高碳高糖促合成） |
| 他汀类 | 抑制（药物） |
| 膳食胆固醇 | 反馈抑制（但个体差异大） |

> **关键认知：** 血胆固醇主要来自**自身合成**（约 70~80%），膳食贡献约 20~30%。所以：
> - 对大多数人，**饱和脂肪和反式脂肪比膳食胆固醇本身对血胆固醇影响更大**（饱和脂肪升高 LDL，反式脂肪升 LDL 降 HDL）。
> - 膳食指南不再像过去那样"一刀切限蛋黄"，而是强调整体膳食模式（如"膳食宝塔""地中海饮食"）。

### 7. 必需脂肪酸与 n-3/n-6

**必需脂肪酸**：人体不能合成、必须从食物获得的脂肪酸。

| 必需脂肪酸 | 家族 | 主要来源 | 衍生 |
|-----------|------|---------|------|
| 亚油酸 | n-6 | 植物油（大豆油、玉米油、葵花籽油） | →花生四烯酸→前列腺素（促炎为主） |
| α-亚麻酸 | n-3 | 亚麻籽油、核桃、紫苏 | →EPA→DHA（抗炎为主） |

**n-3 与 n-6 的平衡：**

| 项目 | n-6 系 | n-3 系 |
|------|--------|--------|
| 代表 | 亚油酸、花生四烯酸 | α-亚麻酸、EPA、DHA |
| 类二十烷酸 | 前列腺素PGE2、白三烯LTB4（偏促炎） | 前列腺素PGE3、白三烯LTB5（偏抗炎） |
| 现代膳食 | 普遍过量 | 普遍不足 |
| 建议 | 适量 | 深海鱼/鱼油/亚麻籽补充 |

> **营养应用：** n-3（EPA/DHA）降甘油三酯（抑制肝脏VLDL合成）、抗炎、护心；DHA 对脑和视网膜发育重要。建议每周吃鱼 2 次（尤其深海鱼）；素食者关注 α-亚麻酸（亚麻籽、核桃）。

### 8. 反式脂肪——"双倍坏"

| 来源 | 危害机制 |
|------|---------|
| 氢化植物油（部分氢化）、高温油炸 | LDL↑ + HDL↓ + Lp(a)↑ + 炎症↑ |

> **营养师提醒：** 配料表有"氢化植物油""起酥油""人造奶油"要警惕；"零反式脂肪"若来自配料中含少量也可标注"0"——看配料表比看"0"更靠谱。

### 9. 酒精代谢与脂肪肝——"乙醛的账单"

```
乙醇
  ↓ 乙醇脱氢酶（ADH，需锌）
乙醛（有毒）
  ↓ 乙醛脱氢酶（ALDH2；东亚人常有ALDH2突变→脸红）
乙酸 → 乙酰CoA → 脂肪酸合成
```

| 酒精的代谢后果 | 机制 |
|--------------|------|
| 脂肪肝 | 乙醇→乙酰CoA→脂肪酸合成↑；NADH↑抑制脂肪酸氧化 |
| 高尿酸 | 酒精促进嘌呤分解、乳酸竞争尿酸排泄 |
| 低血糖（空腹） | 酒精抑制糖异生 |
| B族消耗 | 酒精影响 B1/B9 吸收利用 |
| 肝损伤 | 乙醛毒性→肝细胞损伤→酒精性肝病 |

> **营养应用：** "适量饮酒有益心血管"的说法已被大型研究弱化；对不饮酒者不推荐"为健康开始饮酒"。脂肪肝人群尤其应限酒。

### 10. 营养应用

| 脂代谢原理 | 营养方案依据 |
|-----------|-------------|
| 脂肪动员受胰岛素抑制 | 控糖+运动促进"烧脂" |
| β氧化需肉碱 | 肉碱来源：肉类（素食者注意） |
| 酮体 | 低碳/生酮需专业指导；糖尿病慎用 |
| 脂蛋白 | 高TG→减糖限酒；高LDL→限饱和/反式脂肪+可溶纤维 |
| 胆固醇合成 | 限饱和脂肪优于限蛋黄；他汀者关注CoQ10 |
| 必需脂肪酸 | n-3/n-6 平衡，多吃鱼、亚麻籽、核桃 |
| 酒精 | 限量或戒酒；脂肪肝/高尿酸更应限 |

## 五、蛋白质与氨基酸代谢详解

### 1. 蛋白质的营养地位

| 功能 | 说明 |
|------|------|
| 结构 | 肌肉（肌动蛋白/肌球蛋白）、胶原蛋白 |
| 催化 | 酶 |
| 调节 | 激素（胰岛素等）、受体 |
| 免疫 | 抗体、补体 |
| 运输 | 血红蛋白、白蛋白、转铁蛋白 |
| 缓冲/渗透 | 血浆蛋白维持胶体渗透压 |

### 2. 蛋白质消化吸收

```
蛋白质 →（胃蛋白酶，酸性）→ 多肽 →（胰蛋白酶/糜蛋白酶/弹性蛋白酶）→ 小肽+氨基酸 →（肠肽酶）→ 氨基酸/二肽/三肽 → 主动吸收
```

### 3. 转氨基——氨基酸的"互通有无"（需要 B6）

**转氨基**：氨基酸的氨基转移给α-酮酸，生成新的氨基酸和新的α-酮酸。

```
氨基酸1 + α-酮酸1
   ↓ 转氨酶（需PLP/B6）
α-酮酸2 + 氨基酸2
```

| 转氨酶 | 主要分布 | 临床意义 |
|--------|---------|---------|
| 丙氨酸氨基转移酶 ALT | 肝（含量最高） | 升高→肝损伤（脂肪肝、肝炎） |
| 天冬氨酸氨基转移酶 AST | 心肌、肝、骨骼肌 | 升高→肝/心/肌损伤 |

> **营养应用：** 转氨基是"生糖氨基酸"和"生酮氨基酸"转换的枢纽，需要 B6。ALT/AST 升高不等于就是脂肪肝，需结合临床。

### 4. 脱氨基与氨的"解毒流水线"

**氧化脱氨基**（谷氨酸脱氢酶）→ 氨 + α-酮戊二酸。

**氨的毒性**：游离氨对脑有强毒性 → 必须及时转为无毒形式。

```
氨（NH₃）
  ├── 肝内 → 尿素循环 → 尿素（无毒）→ 肾排出
  └── 周围组织 → 谷氨酰胺合成 → 谷氨酰胺（转运形式）→ 到肝/肾
```

### 5. 尿素循环（鸟氨酸循环）

**位置**：肝脏线粒体 + 胞浆。**功能**：把有毒氨转为无毒尿素。

```
氨 + CO₂ + 鸟氨酸 → 瓜氨酸 → 精氨酸琥珀酸 → 精氨酸 → 尿素 + 鸟氨酸（循环）
```

| 环节 | 说明 |
|------|------|
| 需 N-乙酰谷氨酸（AGA）激活 | 尿素循环的"开关" |
| 尿素随尿排出 | 尿素的生成和排泄是"氮排出的主路" |
| 肝功能障碍 | 尿素合成↓ → 血氨↑ → 肝性脑病风险 |

> **营养应用：** 蛋白质摄入 > 需求 → 脱氨基→尿素↑→肾脏负担↑。**肾病/肝病患者的蛋白限制需遵医嘱**；健康人正常蛋白摄入无需担心"伤肾"。

### 6. 氮平衡——"蛋白质是赚还是亏"

```
氮平衡 = 氮摄入（蛋白质） − 氮排出（尿氮为主+粪+汗）
```

| 状态 | 含义 | 常见人群 |
|------|------|---------|
| 零氮平衡 | 摄入=排出 | 健康成人 |
| 正氮平衡 | 摄入>排出（合成>分解） | 儿童、青少年、孕期哺乳期、康复期、增肌 |
| 负氮平衡 | 摄入<排出（分解>合成） | 饥饿、手术、烧伤、慢性消耗病、蛋白摄入不足 |

> 🔑 **营养师重点：** 减重期如果蛋白质不足，身体会"拆肌肉"保命——体重掉了但掉的是肌肉，基础代谢跟着降。**减重必须保蛋白。**

### 7. 必需氨基酸与蛋白质质量

**必需氨基酸（人体不能合成或合成不足，必须从食物获取）9 种：**

| 必需氨基酸 | 备注 |
|-----------|------|
| 亮氨酸 | 支链氨基酸，最强促肌肉合成信号 |
| 异亮氨酸 | 支链氨基酸 |
| 缬氨酸 | 支链氨基酸 |
| 赖氨酸 | 谷类第一限制氨基酸 |
| 苏氨酸 | |
| 甲硫氨酸 | 含硫，甲基供体（→SAM） |
| 苯丙氨酸 | 芳香族 |
| 色氨酸 | 5-羟色胺前体 |
| 组氨酸 | 婴儿必需（近年认为成人也需要） |

**半必需/条件必需：** 精氨酸、谷氨酰胺、半胱氨酸、酪氨酸、牛磺酸（特定条件下需要）。

**蛋白质质量评价：**

| 指标 | 含义 |
|------|------|
| 限制氨基酸 | 含量相对不足、限制整体利用的氨基酸 |

> **营养应用：** "植物蛋白不如动物蛋白"是简化说法——大豆蛋白质量很高；混合搭配（谷+豆）也能补足。老年人、增肌人群对亮氨酸需求更高。

### 8. 支链氨基酸（BCAA）与亮氨酸-mTOR

**BCAA（亮氨酸、异亮氨酸、缬氨酸）特点：**

| 特点 | 说明 |
|------|------|
| 主要在骨骼肌代谢 | 不经肝脏首过（直接给肌肉"加油"） |
| 供能 | 长时间运动时是肌肉的燃料 |
| 促合成 | 亮氨酸是 mTOR 的强效激活剂 |

```
亮氨酸（Leucine）
  ↓（激活）
mTOR 信号通路
  ↓
真核翻译起始因子激活 → 肌肉蛋白合成↑
```

**亮氨酸的"剂量-效应"：**
- 每餐约 2~3g 亮氨酸即可触发肌肉合成信号（约相当于 25~30g 优质蛋白）。
- 老年人存在"合成抵抗"——需要更高亮氨酸剂量。

> **营养应用：** 乳清蛋白富含亮氨酸；增肌/防肌少症：每餐足量优质蛋白+力量训练。**BCAA 单独补不如"完整蛋白+训练"划算**（完整蛋白含全部必需氨基酸）。

```
   ↓ 若蛋白摄入不足
肌肉流失 → BMR 下降 → 平台期 → 反弹
```

| 减重期 | 1.2~1.6 g/kg/天（保肌肉） |
| 增肌/力量训练 | 1.6~2.0 g/kg/天 |
| 肾病（未透析） | 遵医嘱（需限制） |

> **注意：** 以上为营养学共识参考，具体个体化方案请咨询注册营养师或医师。

## 六、能量代谢核心

### 1. ATP：能量的"通用货币"

**ATP（三磷酸腺苷）** 是细胞直接利用的能量分子。ATP → ADP + Pi 释放能量。

```
ATP 的三大生成途径：
① 底物水平磷酸化（糖酵解、TCA的琥珀酰CoA步骤）——不需氧、快
② 氧化磷酸化（呼吸链 + ATP合酶）——需氧、产量最大
③ 磷酸肌酸系统（极短暂爆发供能，肌酸/磷酸肌酸）
```

### 2. ATP 生成三途径对比

| 途径 | 位置 | 需氧 | 每分子葡萄糖产ATP | 特点 |
|------|------|------|------------------|------|
| 糖酵解 | 细胞浆 | 否 | 2 ATP + 2 NADH | 快、爆发力 |
| TCA 循环 | 线粒体基质 | 否（本身不需氧） | 2 GTP + 大量NADH/FADH2 | 枢纽、需呼吸链配合 |
| 氧化磷酸化 | 线粒体内膜 | 是 | 约 26~28 ATP | 大头、需氧 |

**一分子葡萄糖完全有氧氧化净产约 30~32 ATP**（人卫第9版：视穿梭系统不同，30 或 32）。

### 3. 呼吸链（电子传递链）与营养素

**呼吸链**位于线粒体内膜，把 NADH/FADH2 的电子一步步传给氧，泵出质子，驱动 ATP 合酶产 ATP。

```
NADH → 复合物Ⅰ → 辅酶Q（CoQ10）→ 复合物Ⅲ → 细胞色素c → 复合物Ⅳ → O₂
FADH2 → 复合物Ⅱ →（汇入辅酶Q）
```

| 复合物 | 名称 | 需哪些营养"零件" |
|--------|------|------------------|
| Ⅰ | NADH脱氢酶 | FMN（B2）、铁硫簇（铁） |
| Ⅱ | 琥珀酸脱氢酶 | FAD（B2）、铁硫簇 |
| Ⅲ | 细胞色素bc1 | 血红素（铁）、铁硫簇 |
| Ⅳ | 细胞色素c氧化酶 | 血红素（铁）、铜 |

> **关键：** 呼吸链的效率依赖 B2（FAD/FMN）、B3（NAD）、铁、铜。缺任何一环，产能下降 → "累"。

### 4. 辅酶Q10（CoQ10 / 泛醌）

| 项目 | 内容 |
|------|------|
| 位置 | 线粒体内膜，复合物Ⅰ/Ⅱ → 复合物Ⅲ 之间"搬运电子" |
| 角色 | 呼吸链的"快递员"+ 脂溶性抗氧化剂 |
| 内源合成 | 体内可合成（需甲羟戊酸途径，与胆固醇合成共用上游） |
| 含量最高组织 | 心脏、脑、骨骼肌（高耗能） |
| 他汀的关联 | 他汀抑制 HMG-CoA 还原酶 → 上游甲羟戊酸↓ → 内源 CoQ10 合成也减少 |

| 关于 CoQ10 的认知 | 说明 |
|------------------|------|
| 是否需要人人补充 | 健康人膳食+内源合成通常足够 |
| 他汀服用者 | 部分研究提示补充可改善他汀相关肌肉症状，证据仍在积累，遵医嘱 |
| 食物来源 | 肉类、鱼类（牛肉、沙丁鱼）、坚果、西兰花（含量相对高） |
| 补充剂 | 属营养素补充，非药物；剂量和必要性请咨询医师 |

> **营养师客观表述：** CoQ10 是呼吸链必需的，但对"正常人防衰老、提高精力"的疗效证据有限，不夸大、不贬低。

### 5. 底物利用顺序——"身体先烧什么"

```
血糖（优先，最快可用）
  → 糖原（短期储备）
  → 脂肪（中长期储备，需动员+β氧化）
  → 蛋白质（最后才烧，代价大）
```

| 状态 | 主要燃料 |
|------|---------|
| 静息/轻度活动 | 脂肪酸为主（比例随强度变化） |
| 中高强度运动 | 糖类为主（快） |
| 长时间运动后期 | 糖原耗尽→脂肪比例上升 |
| 长时间空腹/低碳 | 脂肪→酮体 |

> 🔑 **这就是"低碳时要保蛋白"的原因**——蛋白质是最后的燃料。低碳初期身体可能分解蛋白，必须通过足量蛋白质摄入保护肌肉。

### 6. 营养素与呼吸链的"组装关系"总表

| 营养素 | 在能量代谢中的角色 |
|--------|-------------------|
| B1 | 丙酮酸/α-酮酸脱氢酶辅酶（TPP） |
| B2 | FAD/FMN（复合物Ⅰ、Ⅱ） |
| B3 | NAD⁺/NADP⁺（脱氢酶） |
| B5 | CoA（乙酰CoA） |
| 铁 | 血红素、铁硫簇（复合物Ⅰ-Ⅲ） |
| 铜 | 复合物Ⅳ |
| 镁 | ATP 的"工作伴侣"（Mg-ATP） |
| 辅酶Q10 | 复合物Ⅰ/Ⅱ→Ⅲ 电子传递 |

### 7. 营养应用

| 能量代谢原理 | 营养方案依据 |
|-------------|-------------|
| 底物顺序 | 运动供能策略：高强度前补碳水、耐力运动补糖 |
| 呼吸链需B族/铁/铜 | 疲劳排查：B族、铁、整体饮食质量 |
| 保护蛋白 | 低碳/节食期高蛋白防肌肉流失 |
| CoQ10 | 他汀服用者咨询医师是否需补充 |
| 镁 | 能量代谢+肌肉放松 |

## 七、分子营养（营养基因组学）

### 1. 中心法则——"信息流"

```
DNA（储存）→（转录）→ mRNA →（翻译）→ 蛋白质（功能）
  ↑
复制（细胞分裂时）
```

| 过程 | 场所 | 主要分子 | 营养素关联 |
|------|------|---------|-----------|
| 复制 | 细胞核 | DNA聚合酶 | 需要核苷酸、镁、锌 |
| 转录 | 细胞核 | RNA聚合酶 | 需要核苷酸、锌 |
| 翻译 | 核糖体 | rRNA/mRNA/tRNA、氨基酸 | 需要全部必需氨基酸、铁、锌、镁 |

### 2. 基因表达调控与营养

基因表达 = DNA 上的信息被"读出"并制造蛋白质的过程。营养素能影响**基因怎么被读**。

### 3. DNA 甲基化——"基因的开关贴纸"

**DNA甲基化**：在 DNA 甲基转移酶（DNMT）催化下，把甲基（—CH₃）加到胞嘧啶（CpG位点）上。甲基化通常**关闭**基因表达。

```
甲基来源（一碳代谢网络）：
叶酸（B9）→ THF → 甲基
B12 → 甲钴胺 → 甲硫氨酸合成酶（同型半胱氨酸→甲硫氨酸）
甲硫氨酸 → SAM（S-腺苷甲硫氨酸，通用甲基供体）
胆碱 → 甜菜碱 → 甲基
```

| 一碳代谢"甲基供应商" | 缺乏后果 |
|---------------------|---------|
| 叶酸 | 同型半胱氨酸↑、DNA合成障碍、神经管缺陷 |
| B12 | 同型半胱氨酸↑、巨幼细胞性贫血、神经损害 |
| 胆碱/甜菜碱 | 甲基供应↓、肝脂肪代谢↓ |

> **营养应用：** 叶酸+B12+胆碱构成"甲基化网络"，共同维持 DNA 甲基化、同型半胱氨酸代谢和肝脏脂肪代谢。孕期叶酸补充是最经典的"营养改变基因表达结局"案例。

### 4. 表观遗传——"饮食写下的基因批注"

**表观遗传**：不改变 DNA 序列，但改变基因表达且可遗传的调节（DNA甲基化、组蛋白修饰、非编码RNA）。

```
环境（营养、压力、运动、毒素）
  ↓
表观遗传修饰（DNA甲基化、组蛋白乙酰化等）
  ↓
基因表达改变（激活或关闭）
  ↓
健康结局（可随生命周期变化）
```

| 表观遗传机制 | 说明 | 营养例子 |
|-------------|------|---------|
| DNA 甲基化 | 常关闭基因 | 叶酸/B12/胆碱供甲基 |
| 组蛋白乙酰化 | 常激活基因 | 丁酸（膳食纤维发酵产物）抑制组蛋白去乙酰化酶 |
| 组蛋白甲基化 | 可激活可抑制 | 与甲基供应有关 |
| 非编码 RNA（miRNA） | 降解/抑制 mRNA | 受营养素调节 |

> **"母体营养-胎儿编程"**：孕期营养影响胎儿基因表观修饰，与成年后慢病风险相关——"生命早期 1000 天"理论的分子基础。

### 5. 核受体与营养素——"营养素是基因的钥匙"

**核受体**：位于胞内，被小分子配体激活后进入核内调控基因转录。

| 核受体 | 配体（营养素/激素） | 调控方向 |
|--------|---------------------|---------|
| 维生素D受体 VDR | 1,25-(OH)₂D₃（活性维生素D） | 钙磷代谢、免疫、细胞分化（调控 1000+ 基因） |
| 视黄酸受体 RAR/RXR | 维生素A（视黄酸） | 发育、免疫、视力 |
| 过氧化物酶体增殖物激活受体 PPARα | 脂肪酸 | 脂肪酸氧化 |
| PPARγ | 脂肪酸衍生物 | 脂肪合成、胰岛素敏感（噻唑烷二酮类降糖药靶点） |
| 肝X受体 LXR | 氧固醇 | 胆固醇代谢 |

> **营养应用（维生素D重点）：** 维生素D不仅是"钙帮手"，通过 VDR 影响免疫、血糖、肌肉。维生素D 缺乏普遍（日照不足）；可通过日晒+食物（脂肪鱼、蛋黄、强化奶）+遵医嘱补充。

### 6. 重要信号通路（营养师版）

信号通路是细胞感知"营养够不够、能量足不足、有没有炎症"的分子开关。

#### ① mTOR 通路——"生长与合成开关"

| 项目 | 内容 |
|------|------|
| 激活 | 氨基酸（尤其亮氨酸）、胰岛素/IGF-1、能量充足 |
| 抑制 | 能量不足、AMPK 激活、雷帕霉素 |
| 下游 | 蛋白质合成↑、细胞生长↑、自噬↓ |
| 营养意义 | 吃蛋白→亮氨酸→mTOR→肌肉合成 |

> **营养应用：** 增肌靠 mTOR；但长期过度激活（高胰岛素、营养过剩）与细胞过度增殖/衰老有关——"适度生长"是关键，间歇性断食的"自噬窗口"即靠 AMPK 通路。

#### ② AMPK 通路——"能量不足的节能开关"

| 项目 | 内容 |
|------|------|
| 激活 | AMP/ATP 比值高（能量不足）、运动、二甲双胍、热量限制 |
| 抑制 | 能量充足、高糖 |
| 下游 | 脂肪酸氧化↑、葡萄糖摄取↑、自噬↑、mTOR↓ |
| 营养意义 | "模拟饥饿"=燃脂+自噬+抗衰老 |

> **营养应用：** 运动是最安全的 AMPK 激活方式；二甲双胍也激活 AMPK（糖尿病一线药，遵医嘱）。

#### ③ Nrf2 通路——"抗氧化防御系统"

| 项目 | 内容 |
|------|------|
| 激活 | 氧化应激、植物化合物（萝卜硫素-十字花科、姜黄素、绿茶多酚、白藜芦醇） |
| 下游 | 抗氧化酶（GPx、SOD、CAT、GST）、II相解毒酶 |
| 营养意义 | 让身体"自己装抗氧化系统" |

> **营养应用：** 与其迷信"超级抗氧化剂"，不如多吃十字花科蔬菜、姜黄、绿茶——激活内源 Nrf2 系统。

#### ④ NF-κB 通路——"炎症的警报系统"

| 项目 | 内容 |
|------|------|
| 激活 | 炎症因子（TNF-α、IL-6）、高血糖、氧化应激、感染 |
| 下游 | 促炎因子↑、粘附分子↑ |
| 抑制 | n-3（EPA/DHA）、姜黄素、运动、热量控制 |
| 营养意义 | 慢性低度炎症是代谢病的共同土壤 |

> **营养应用：** 抗炎饮食（n-3、蔬果多酚、膳食纤维）可抑制 NF-κB 通路 → 改善"炎症驱动的慢病"（胰岛素抵抗、脂肪肝、动脉粥样硬化）。

### 7. 营养基因组学与个性化

| 概念 | 说明 |
|------|------|
| 营养基因组学 | 营养素与基因的相互作用 |
| 单核苷酸多态性 SNP | 基因的"个体差异点" |
| 例子：MTHFR C677T | 该基因变异者叶酸→活性叶酸转化效率下降 → 同型半胱氨酸↑风险 |
| 例子：APOE | 脂代谢相关基因型影响血脂对饮食的反应 |
| 现状 | 基因检测的临床指导意义仍在发展中，需结合专业解读 |

> **营养师客观立场：** "基因决定论"不对，"营养万能"也不对。基因只是"嫌疑方向"，生活方式和饮食是"可控变量"。不推销基因检测。

### 8. 营养应用

| 分子机制 | 营养方案依据 |
|---------|-------------|
| 中心法则 | 蛋白质=合成原料；锌/铁/镁参与 |
| DNA甲基化 | 叶酸/B12/胆碱充足（备孕、高同型半胱氨酸） |
| 表观遗传 | 长期饮食模式影响基因表达（"你吃的不只是饭"） |
| VDR | 维生素D充足（日晒+食物+遵医嘱） |
| mTOR | 蛋白+训练增肌；避免长期营养过剩过度激活 |
| AMPK | 运动、适量热量限制、控糖 |
| Nrf2 | 十字花科蔬菜、姜黄、绿茶 |
| NF-κB | 抗炎饮食：n-3、多酚、纤维 |

## 八、常见代谢物与化验（生化与化验单衔接）

### 1. 血糖（Glucose）

| 项目 | 参考范围（成人空腹静脉血浆） |
|------|------------------------------|
| 正常 | 3.9~6.1 mmol/L |
| 空腹血糖受损 | 6.1~7.0 mmol/L |
| 糖尿病诊断 | 空腹 ≥7.0，或餐后2h ≥11.1，或随机≥11.1伴症状（需复测） |

> 生化背景：血糖由胰岛素/胰高血糖素/肝糖原协调维持。**解读注意：** 单次升高不等于糖尿病，需医院复查（OGTT、HbA1c）。

### 2. 糖化血红蛋白（HbA1c）

| 项目 | 内容 |
|------|------|
| 本质 | 血红蛋白被血糖"糖化"的产物 |
| 反映 | 近 2~3 个月平均血糖 |
| 参考 | <6.5%（达标个体因人而异，遵医嘱） |
| 意义 | 比单次血糖更稳定，反映长期控糖水平 |

### 3. 血脂四项

| 指标 | 参考合适水平（成人） | 生化背景 | 营养要点 |
|------|---------------------|---------|---------|
| 甘油三酯 TG | <1.7 mmol/L | 肝合成VLDL、乳糜微粒转运 | 减糖限酒n-3 |
| 总胆固醇 TC | <5.2 mmol/L | 合成+膳食 | 整体膳食模式 |
| LDL-C | <3.4 mmol/L | 致动脉粥样硬化主要载体 | 限饱和/反式脂肪+可溶纤维 |
| HDL-C | 男>1.0、女>1.3 mmol/L | 逆向胆固醇转运 | 运动、不吸烟 |

### 4. 尿酸（Uric Acid）

| 项目 | 内容 |
|------|------|
| 本质 | 嘌呤代谢终产物 |
| 参考 | 男<420 μmol/L、女<360 μmol/L（血尿酸） |
| 高尿酸 | 痛风风险、肾结石、代谢综合征相关 |
| 营养要点 | 限酒（尤其啤酒）、限高嘌呤（动物内脏、浓汤）、控果糖（果糖促尿酸）、多饮水 |

### 5. 同型半胱氨酸（Hcy）

| 项目 | 内容 |
|------|------|
| 本质 | 甲硫氨酸代谢中间产物 |
| 代谢途径 | ① 甲硫氨酸合成酶（需叶酸、B12）② 转硫途径（需B6） |
| 参考 | <15 μmol/L（高同型半胱氨酸血症通常 >15） |
| 意义 | 心血管风险、认知、妊娠风险相关 |
| 营养要点 | 叶酸+B12+B6 充足（深绿叶菜、全谷、肉蛋）；需排除B12缺乏 |

### 6. 白蛋白（Albumin）

| 项目 | 内容 |
|------|------|
| 本质 | 血浆主要蛋白质（肝脏合成） |
| 参考 | 35~55 g/L |
| 意义 | 蛋白质营养状态、肝功能（但半衰期约20天，反映较慢变化） |
| 营养要点 | 低白蛋白 → 评估蛋白质摄入与疾病消耗；不代表就是"营养不良"单一原因 |

### 7. 肝功能酶（ALT/AST）

| 指标 | 参考范围 | 生化背景 | 升高常见原因 |
|------|---------|---------|-------------|
| ALT | 男9-50、女7-40 U/L（各实验室不同） | 丙氨酸转氨基（需B6） | 脂肪肝、肝炎、药物 |
| AST | 男15-40、女13-35 U/L | 天冬氨酸转氨基 | 肝/心/肌损伤 |
| GGT | 10-60 U/L | 谷氨酰转移酶 | 酒精/胆汁淤积 |

> **注意：** 转氨酶升高不代表一定是脂肪肝，需要结合超声、血脂、血糖等综合评估；营养干预（减重、限酒、控糖）是代谢性肝病基础。

### 8. 肾功能（肌酐/尿素氮）

| 指标 | 参考范围 | 生化背景 | 营养要点 |
|------|---------|---------|---------|
| 肌酐 Cr | 男57~111、女41~73 μmol/L | 肌酸代谢产物，经肾小球滤过 | 受肌肉量影响；反映滤过功能 |
| 尿素氮 BUN | 2.9~8.2 mmol/L | 蛋白质代谢终产物（尿素） | 受蛋白摄入/肝肾功能影响 |
| eGFR | >90 ml/min/1.73m²（年轻成人） | 估算肾小球滤过率 | 慢性肾病分期依据 |

> **解读注意：** 肌酐受肌肉量影响（健身者偏高）；尿素氮受蛋白摄入影响（高蛋白可轻度升高）。异常需医院进一步评估。

## 十、常见问题速查（营养咨询高频）

### Q1：为什么缺 B 族容易累？
B1/B2/B3 是能量代谢辅酶（TPP/FAD/NAD）的原料，缺了产能下降；另外铁、镁、优质蛋白也参与。但"累"的原因很多，需系统评估，不是一吃B族就好。

### Q2：为什么"零卡"饮料也不建议多喝？
零卡甜味剂不供能，但可能影响肠道菌群和摄食信号（GLP-1/胰岛素反应的研究仍在进行）；而且"液体甜味"容易让人在别处多吃。建议以水为主。

### Q3：为什么不推荐空腹大量饮酒？
酒精抑制糖异生，空腹时肝糖原储备又低 → 容易低血糖；长期饮酒伤肝（乙醛）。饮酒不建议空腹。

### Q4：高蛋白会不会伤肾？
健康肾脏能处理正常甚至较高蛋白摄入；但**已有肾病**者需遵医嘱限蛋白。普通人"谈蛋白色变"没必要。

### Q5：补剂 vs 食物，哪个优先？
食物优先（营养素协同、吸收真实）。只有特定人群/特定缺口才考虑补充剂，且需遵医嘱（如孕期叶酸、老年B12、维生素D缺乏）。
