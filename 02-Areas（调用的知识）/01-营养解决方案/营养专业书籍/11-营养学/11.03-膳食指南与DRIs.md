# 11.03 · 膳食指南与DRIs

> **一句话定位：** 中国人"怎么吃、吃多少"的两套国家标准工具——《中国居民膳食指南2022》管"吃什么/怎么吃"，DRIs 2023 管"每种营养素摄入多少"。这是营养工作的法定依据。
>
> **查数工具：** [[02-Areas（调用的知识）/01-营养解决方案/DRIs2023营养素参考摄入量速查全表]]（速查数值直接用那份）。

## 一、中国居民膳食指南（2022）

### 1. 八条准则（核心）
| # | 准则 | 关键动作 |
|---|------|---------|
| 1 | **食物多样，合理搭配** | 每天≥12种，每周≥25种食物 |
| 2 | **吃动平衡，健康体重** | 保持BMI 18.5~23.9 |
| 3 | **多吃蔬果、奶类、全谷、大豆** | 蔬菜300~500g，水果200~350g，奶300~500ml |
| 4 | **适量吃鱼、禽、蛋、瘦肉** | 动物性食物120~200g/天 |
| 5 | **少盐少油，控糖限酒** | 盐<5g、油25~30g、糖≤50g、不饮酒 |
| 6 | **规律进餐，足量饮水** | 三餐规律，饮水1500~1700ml |
| 7 | **会烹会选，会看标签** | 学会读食品标签 |
| 8 | **公筷分餐，杜绝浪费** | 饮食卫生文明 |

### 2. 膳食宝塔（2022版）
```
第五层：盐 <5g  油 25~30g
第四层：奶及奶制品 300~500g  大豆及坚果 25~35g
第三层：动物性食物 120~200g（畜禽40~75+水产40~75+蛋40~50）
第二层：蔬菜 300~500g  水果 200~350g
第一层：谷类 200~300g（全谷杂豆50~150g）薯类 50~100g
```

### 3. 膳食餐盘（一餐怎么配）
```
1/2 盘：蔬菜水果
1/4 盘：全谷物/主食
1/4 盘：优质蛋白
```

### 4. 特殊膳食要求（指南强调）
- **东方健康膳食模式**：我国江南地区饮食（多蔬菜、多鱼、多豆、少油盐、米为主）——被指南推荐为"中国版健康膳食"
- 与DASH、地中海饮食并列为健康膳食模式

## 二、DRIs 体系详解

### 1. 概念（每个字母是什么）
| 指标 | 全称 | 含义 | 应用场景 |
|------|------|------|---------|
| **EAR** | 平均需要量 | 满足50%人群需要的量 | 评价群体摄入是否充足 |
| **RNI/RDA** | 推荐摄入量 | EAR+2SD，满足97~98%人群 | 个体每日摄入目标 |
| **AI** | 适宜摄入量 | 数据不足时用观察值 | 婴儿（母乳喂养量）等 |
| **UL** | 可耐受最高摄入量 | 几乎所有人可耐受的上限 | 防过量中毒 |
| **PI-NCD** | 慢性病预防建议摄入量 | 为预防慢病的推荐值 | 钠、钾、维C等 |
| **AMDR** | 宏量营养素可接受范围 | 供能比范围 | 碳水50~65%、蛋白10~20%、脂肪20~30% |

### 2. 关系图
```
        EAR    RNI(≈EAR+2SD)          UL
         │        │                    │
   ──────┼────────┼────────────────────┼──────→ 摄入量
   不足区│ 适宜摄入区 │      过量风险区
         │        │
         │   PI-NCD（部分营养素，为防慢病）
```
- 摄入 < EAR：缺乏风险高
- 摄入在 RNI~UL：安全充足
- 摄入 > UL：过量中毒风险

### 3. 2023版 DRIs 主要更新
- **钠**：PI-NCD 2000mg/天（约5g盐）
- **钾**：PI-NCD 3600mg/天（升了，鼓励多吃菜果）
- **蛋白质**：老年组提高至 1.17 g/(kg·d)（65岁以上）
- **维生素C**：成人RNI 100mg，PI-NCD 200mg
- **维生素D**：成人RNI 400IU，65+ 600IU
- **膳食纤维**：成人 25~30g/天
- **添加糖**：≤50g，最好≤25g

## 三、如何应用DRIs做营养评估（实操）

### 1. 个体评估（给顾客用）
1. 记录膳食（24h回顾/食物频率问卷）
2. 算出各营养素摄入量（用食物成分表）
3. 与RNI/AI对比：
   - ≥RNI → 充足
   - 80%~RNI → 边缘，建议改善
   - <80% → 不足，重点干预
4. 结合生化指标（血化验）确认

### 2. 群体评估（给社群/家人用）
- 看摄入 < EAR 的比例，>15%人群低于EAR → 群体存在缺乏风险
- 用于营养调查、制定干预方案

### 3. 营养素补充决策
| 情况 | 建议 |
|------|------|
| 膳食摄入充足 | 无需补充，食物优先 |
| 明确缺乏（化验+症状） | 按需补充（治疗剂量） |
| 特定人群（老人/孕妇/纯素） | 针对性补充（D/B12/铁/叶酸） |
| 预防慢病 | 按PI-NCD水平选择 |

**原则：** 食物优先 → 不足补缺口 → 不超过UL → 补充剂不能替代均衡饮食。

## 四、膳食指南应用场景（AI营养师）

| 场景 | 用什么工具 |
|------|-----------|
| 给家庭讲"一日三餐怎么吃" | 膳食宝塔+餐盘 |
| 给顾客算营养缺口 | 24h回顾+DRIs对比 |
| 减脂客户 | 餐盘配比+能量负平衡 |
| 慢病患者 | 在指南基础上按疾病调整（见11.07） |
| 科普内容 | 八条准则就是现成选题库 |
