# 11.04 · 人群营养（书本级详解）

> **一句话定位：** 全生命周期的营养——从受精卵到暮年，不同人生阶段各有各的营养重点。本笔记是"人群营养"主题的专业参考全书：孕妇、乳母、婴幼儿、儿童青少年、老年人、特殊生理状态，每个阶段都给出**营养素推荐量、常见问题、干预思路、AI营养师沟通话术**。
>
> **给谁用：** AI营养师在给不同年龄段的顾客/家人/伙伴做营养方案时，按人群查表调用。
>
> **依据：** 《中国居民膳食指南（2022）》特定人群指南、《中国居民膳食营养素参考摄入量（2023版）》、EWGSOP2 肌少症共识（2019）、WHO《婴幼儿喂养指南》、IOM 孕期增重指南（2009）。

## 〇、人群营养总论

### 0.1 为什么要分人群谈营养

营养需要量不是一条"平均线"，而是随**生命阶段**动态变化的。同样的食物和分量，对一个 8 岁的孩子、一位孕晚期的准妈妈、一位 70 岁的老人，意义完全不同。人群营养研究的就是：**在特定的生理阶段，身体发生了什么变化，营养需求如何跟着变，又该用什么食物去满足。**

| 维度 | 儿童 | 成人 | 老年人 |
|------|------|------|--------|
| 核心任务 | 生长发育 | 维持稳态 | 对抗损耗 |
| 能量需求 | 相对体重高 | 相对稳定 | 逐渐下降 |
| 蛋白质 | 必须足量 | 维持平衡 | 需要上调 |
| 风险方向 | 缺营养→发育迟缓 | 过量→慢病 | 缺营养→衰弱 |

### 0.2 人群营养评估"五步法"

无论面对哪个年龄段的人，AI营养师都按这五步走：

```
① 问清现状 → 年龄、性别、体重、身高、疾病史、用药、生活方式
② 算清需求 → 对照 DRIs 2023 查该人群的推荐摄入量
③ 看清差距 → 把实际饮食和推荐量对比，找缺口
④ 定方案 → 食物优先 + 必要时补充（天然食物解决80%，营养素补充剂只补缺口）
⑤ 跟随访 → 定期复查体重/指标/感受，动态调整
```

| 阶段 | 年龄/状态 | 第一营养素 | 第二营养素 | 关键动作 |
|------|-----------|-----------|-----------|----------|

## 一、孕期营养

### 1.1 孕期生理变化概述

怀孕不是"多一个人吃饭"，而是**母体代谢系统的整体改造**：

| 生理变化 | 说明 | 营养意义 |
|----------|------|----------|
| 血容量增加 | 孕晚期血容量比孕前增加约 40~50% | 铁需要量激增，稀释性贫血高发 |
| 心输出量增加 | 心输出量增加约 30~50% | 能量消耗上升 |
| 基础代谢率上升 | 孕晚期 BMR 升高约 15~20% | 能量需要量增加 |
| 肾血流量增加 | 肾小球滤过率上升约 50% | 部分营养素经尿流失增多（如碘、水溶性维生素） |
| 激素变化 | 孕酮、雌激素、人胎盘生乳素升高 | 血脂升高、胰岛素敏感性下降 |
| 胃肠蠕动减慢 | 孕酮致平滑肌松弛 | 易便秘、胃食管反流 |

**一句话总结：** 孕期营养要同时满足"母体储备 + 胎儿发育 + 胎盘/羊水构建"三份需求。

### 1.2 孕早中晚三期营养重点（详版）

#### 孕早期（0~13 周）

| 项目 | 推荐 | 说明 |
|------|------|------|
| 能量 | 孕前基础上基本不增加 | 孕早期体重增长缓慢，能量需求与孕前相近 |
| 叶酸 | 400μg/天（补充剂）+ 富叶酸食物 | 预防胎儿神经管畸形（脊柱裂/无脑儿）；从备孕开始补，至少持续到孕 3 个月末 |
| 碳水化合物 | ≥130g/天 | 保证葡萄糖供应，防止脂肪动员过度产生**酮症**，酮体可能影响胎儿神经发育 |
| 碘 | 230μg/天 | 胎儿甲状腺素合成依赖母体碘 |
| 蛋白质 | 孕前基础上 +0（与孕前相同） | 孕早期胎儿体重小，但质量不低——优质蛋白来源要保证 |
| 体重 | 增长 0.5~2kg（整个早孕期） | 孕吐严重者允许不增甚至略降 |

> **孕早期特别提醒：** 孕吐（妊娠剧吐）期间"能吃下什么就吃什么"，不必强求营养均衡，重点保证**碳水化合物 ≥130g**（如苏打饼干、白粥、面条），防止酮症。严重呕吐、体重明显下降者应及时就医。

#### 孕中期（14~27 周）

| 项目 | 推荐 | 说明 |
|------|------|------|
| 能量 | 孕前基础上 +300 kcal/天 | 胎儿快速生长、母体储备开始 |
| 蛋白质 | 孕前基础上 +15g/天 | 约相当于每天多一杯奶 + 一个蛋 |
| 钙 | 1000mg/天 | 胎儿骨骼矿化启动，母体"钙库"开始被调用 |
| 铁 | 24mg/天 | 血容量快速扩张，血红蛋白合成需求大 |
| 碘 | 230μg/天 | 继续保证加碘盐 + 每周 1~2 次海产品 |
| DHA | 200mg/天 | 胎儿大脑和视网膜发育高峰 |
| 叶酸 | 400μg/天（可维持补充） | 虽神经管已闭合，仍参与造血 |

#### 孕晚期（28~40 周）

| 项目 | 推荐 | 说明 |
|------|------|------|
| 能量 | 孕前基础上 +450 kcal/天 | 胎儿增重最快、脂肪储备 |
| 蛋白质 | 孕前基础上 +30g/天 | 胎儿组织增长 + 母体储备 |
| 铁 | 29mg/天 | 为分娩失血 + 胎儿储备铁（够生后 4~6 个月用） |
| 钙 | 1000mg/天 | 胎儿骨骼钙化高峰期 |
| DHA | 200mg/天 | 大脑发育最后冲刺 |
| 体重 | 中晚期每周增重按 BMI 对应值 | 见表 1.3 |

> **孕晚期特别提醒：** 最后一个月"一人吃两人补"是误区——能量增长有限，**吃多长的是脂肪，不是胎儿**。重点是提高质量（蛋白质、铁、DHA），不是提高总量。

### 1.3 孕期增重目标（按孕前 BMI）

孕期增重参照 **IOM 2009 标准**（中国指南沿用）：孕前体重越重，允许增重越少。

| 孕前 BMI（中国切点） | 孕前 BMI（IOM） | 总增重范围(kg) | 中晚期每周增重(kg) | 备注 |
|---------------------|----------------|----------------|---------------------|------|
| <18.5（低体重） | <18.5 | 12.5~18 | 0.44~0.58 | 需多长，防低出生体重 |
| 18.5~23.9（正常） | 18.5~24.9 | 11.5~16 | 0.35~0.50 | 最理想区间 |
| 24~27.9（超重） | 25~29.9 | 7~11.5 | 0.23~0.33 | 需控制 |
| ≥28（肥胖） | ≥30 | 5~9 | 0.17~0.27 | 严格管理 |

> **说明：** 表格中 BMI 切点按中国标准；IOM 原版切点 18.5/25/30。给顾客沟通时，用中国切点更贴近体检报告口径。

**增重管理要点：**
- 增重不是匀速的：早孕慢（共 0.5~2kg），中晚快（每周按表）
- 双胎：总增重目标约 17~25kg（正常体重者），需产科营养师个体化管理
- 每周固定时间、同一台秤、早晨空腹称重
- 超重/肥胖孕妇**不建议孕期节食减肥**，但应控制增重速度

### 1.4 孕期能量与宏量营养素

| 营养素 | 孕前（轻体力） | 孕中 | 孕晚 | 哺乳期 |
|--------|--------------|------|------|--------|
| 能量（kcal/d） | 男2250 / 女1800 | +300 | +450 | +500 |
| 蛋白质（g/d） | 女55 | +15 | +30 | +25 |
| 碳水化合物 | 供能 50~65% | 不低于 130g/d | 同 | 同 |
| 脂肪 | 供能 20~30% | 保证 DHA/必需脂肪酸 | 同 | 同 |

**膳食结构建议（孕期每天）：**
- 谷薯类：250~300g（孕中晚期），其中全谷物/杂豆占 1/3
- 蔬菜 300~500g + 水果 200~350g
- 奶类 300~500ml（补钙主力）
- 鱼禽蛋肉 150~200g（孕中）/ 175~225g（孕晚）
- 饮水 1700ml 左右，孕晚期可适当增加

### 1.5 孕期关键微量营养素及推荐量

| 营养素 | 推荐量（孕中/孕晚） | 食物来源 | 缺乏后果 | 补充剂建议 |
|--------|---------------------|----------|----------|------------|
| 叶酸 | 600μg DFE/天 | 深绿叶菜、豆类、动物肝脏 | 神经管畸形、巨幼贫 | 备孕至孕 3 月每天 400μg 补充剂 |
| 铁 | 24/29mg/天 | 红肉、动物血、动物肝脏 | 缺铁性贫血、低出生体重 | 铁蛋白<30μg/L 时医生指导下补铁 |
| 钙 | 1000mg/天 | 奶类、豆制品、绿叶菜、虾皮 | 腿抽筋、骨密度下降、妊高症风险↑ | 饮食不足时补 500~600mg/天 |
| 碘 | 230μg/天 | 加碘盐、海带、紫菜、海鱼 | 胎儿智力发育受损、甲状腺肿 | 加碘盐即可，不额外乱补 |
| DHA | 200mg/天 | 深海鱼（三文鱼/沙丁鱼/秋刀鱼） | 影响胎儿脑眼发育 | 鱼类不足时用藻油 DHA |
| 维D | 10μg(400IU)/天 | 日照、动物肝脏、蛋黄 | 影响钙吸收、骨骼发育 | 常规补充 400IU/天 |
| 维A | 孕早 770~800μg RAE | 动物肝脏、蛋黄、深色蔬果 | 影响胎儿发育 | 不盲目补维A；不吃过量动物肝脏 |
| 锌 | 孕中期 +2mg | 贝类、红肉、坚果 | 胎儿生长受限 | 通常食物可满足 |
| 维生素B12 | 2.9μg/天（孕晚期） | 动物性食物 | 巨幼贫、神经损伤 | 素食孕妇必须重视 |

> **补剂核心提醒：** 孕期必须补的是 **叶酸 + 维D**（几乎所有孕妇需要）；**铁、钙**看情况补（缺才补、遵医嘱）；**DHA** 鱼类不足可补。**不要盲目"大礼包式"补多种营养素**——脂溶性维生素（维A/维D）过量有致畸风险。

### 1.6 孕期禁忌与食品安全

#### 明确禁止

| 项目 | 风险 | 处理 |
|------|------|------|
| 酒精 | 胎儿酒精综合征（智力/面容/发育异常）| **绝对禁酒**，无安全剂量 |
| 吸烟/二手烟 | 流产、早产、低出生体重 | 戒烟 + 远离二手烟 |
| 生鱼片/生肉 | 李斯特菌、弓形虫感染 | 全熟再吃 |
| 未熟鸡蛋 | 沙门氏菌 | 吃全熟蛋 |
| 未巴氏消毒的奶/软奶酪 | 李斯特菌 | 选巴氏消毒产品 |
| 未经处理的动物肝脏 | 维A过量致畸 | 偶尔少量可，不天天吃 |
| 大型掠食性鱼类（鲨鱼、剑鱼、方头鱼） | 甲基汞蓄积影响胎儿神经 | 完全避免 |

#### 严格限制

| 项目 | 限量 | 说明 |
|------|------|------|
| 咖啡因 | <200mg/天 | 相当于约 2 小杯咖啡；茶、可乐、巧克力都要计入 |
| 高糖食物 | 尽量少 | 控糖、控增重 |
| 腌制/熏制食品 | 少吃 | 高盐 + 亚硝酸盐 |
| 花茶/不明中草药 | 遵医嘱 | 部分有子宫兴奋作用 |

#### 可以放心做的事

- 每周 2~3 次海鱼（选三文鱼、鳕鱼、秋刀鱼等低汞鱼）
- 适量运动（散步、孕妇瑜伽、游泳）——除非医生禁止
- 正常洗头、护肤、养宠物（注意清洁、避免猫粪接触）

### 1.7 孕期常见营养相关疾病

#### 孕期贫血

| 项目 | 内容 |
|------|------|
| 诊断标准（WHO） | 孕期血红蛋白（Hb）<110g/L |
| 类型 | 缺铁性贫血最常见（约占 90%以上），其次巨幼细胞性贫血（叶酸/B12缺乏） |
| 高发阶段 | 孕中晚期（血容量扩张 + 铁需求高峰） |
| 危害 | 乏力头晕、胎儿生长发育受限、早产、产后出血风险↑ |
| 实验室线索 | 血清铁蛋白<30μg/L 提示铁储备不足；<20μg/L 提示铁缺乏 |
| 营养干预 | ① 富铁食物：红肉、动物血、动物肝脏每周 1~2 次；② 搭配维C（猕猴桃、橙子）促吸收；③ 浓茶、咖啡与正餐错开（鞣酸抑制铁吸收）；④ 确诊缺铁性贫血后遵医嘱补铁剂 |
| 沟通要点 | "贫血不是小事但也不用慌——先查血常规+铁蛋白，食物补 + 必要时铁剂，两周到一个月复查。" |

#### 妊娠期糖尿病（GDM）

| 项目 | 内容 |
|------|------|
| 筛查时机 | 孕 24~28 周 75g OGTT |
| 诊断标准 | 空腹 ≥5.1 mmol/L 或 1h ≥10.0 或 2h ≥8.5 mmol/L（任一达标即诊断） |
| 营养原则 | ① 控制碳水总量：占全天能量 40~50%；② 选低 GI 主食（燕麦、糙米、全麦）；③ 少食多餐：三餐三点；④ 蛋白质足量、蔬菜多多；⑤ 避免含糖饮料和精制甜点 |
| 血糖控制目标 | 空腹<5.3 mmol/L；餐后1h<7.8；餐后2h<6.7 mmol/L |
| 体重管理 | 按孕前 BMI 控制增重，是 GDM 的一线干预 |
| 结局 | 多数通过饮食+运动可控制；产后 4~12 周复查血糖（GDM 女性远期 2 型糖尿病风险↑） |

#### 妊娠期高血压 / 子痫前期

| 项目 | 内容 |
|------|------|
| 概念 | 孕期血压≥140/90mmHg，伴蛋白尿等为子痫前期；是我国孕产妇死亡重要原因之一 |
| 营养注意 | ① 限盐：每天食盐<6g；② 保证优质蛋白；③ 高钙摄入（1000~1200mg/天）有助预防；④ 控制增重、避免过快；⑤ 适当含钾食物（香蕉、土豆、绿叶菜）——肾功能正常者 |
| 监测 | 居家测血压 + 定期产检（尿蛋白、肝肾功能） |
| 提醒 | 严重头痛、视物模糊、上腹痛需**立即就医**，不属于营养可处理范畴 |

### 1.8 孕期膳食"加分项"清单

- **每周 1~2 次海产品**：补碘 + 补 DHA
- **每天 300~500ml 奶**：补钙主力
- **红肉 + 深绿叶菜搭配**：补铁 + 促吸收
- **全谷物替代部分精米白面**：稳血糖 + 防便秘
- **足量饮水**：防尿路感染、防便秘
- **适当运动**：散步每天 30 分钟，控制体重 + 利于顺产

| 增重焦虑 | "你孕前体重正常，整个孕期长 11~16kg 最理想，每周称一次，别被别人'一个人吃两个人的量'带偏。" |
| 应酬躲酒 | "孕期酒精没有安全剂量，一杯都不要。别人劝你，就说是医生和家里人都盯着。" |
| 合规红线 | 不做诊断、不替代产检、不推销产品；只给食物建议和生活方式建议。 |

## 二、哺乳期营养

### 2.1 哺乳期生理与泌乳

- 母乳是婴儿最理想的食物，含 400 余种成分（免疫物质、乳铁蛋白、益生菌、DHA 等）。
- 泌乳量：足月新生儿约需 600~800ml/天，随月龄增至 800~900ml/天。
- 泌乳需要消耗能量：每分泌 100ml 母乳约消耗 80~90kcal。
- 乳母营养状况**直接影响乳汁中部分营养素浓度**（水溶性维生素、碘、DHA、硒等）；而蛋白质、钙、脂肪等在乳汁中的含量相对稳定（身体会"动用储备"优先保证乳汁质量）。

### 2.2 哺乳期能量与营养素推荐

| 营养素 | 推荐量 | 比孕前增加 | 说明 |
|--------|--------|-----------|------|
| 能量 | 孕前基础上 +500 kcal/天 | +500 | 部分由孕期储备脂肪补充，实际需多吃约 400~500kcal |
| 蛋白质 | 孕前基础上 +25g/天 | +25 | 约等于多一个蛋 + 一杯奶 + 一两瘦肉 |
| 钙 | 1000mg/天 | +200 | 泌乳每天经乳汁带走约 200~300mg 钙 |
| 铁 | 24mg/天 | 持平 | 哺乳期多闭经，铁需求未额外增加，但产后恢复需要 |
| 碘 | 240μg/天 | +120 | 婴儿甲状腺素完全依赖母乳碘，**碘是泌乳期最该盯住的营养素之一** |
| DHA | 200mg/天 | +200 | 直接提升母乳 DHA 含量，利于婴儿脑眼发育 |
| 叶酸 | 550μg DFE/天 | +150 | 维持造血 + 乳汁供给 |
| 维D | 10μg(400IU)/天 | 持平 | 乳汁维D低，婴儿仍需单独补充 |
| 锌 | +4mg（哺乳期 12mg） | +4 | 乳汁锌含量高 |
| 饮水 | 2100ml/天，哺乳前喝一杯 | +600~1000 | 保证泌乳量 |

**膳食结构建议（哺乳期每天）：**
- 谷薯类 300~350g
- 蔬菜 400~500g + 水果 200~350g
- 奶类 300~500ml
- 鱼禽蛋肉 200~250g（其中每周 1~2 次海鱼）
- 饮水 2100ml 以上（乳汁 90% 是水）

### 2.3 泌乳质量与营养的关系

| 乳汁成分 | 受乳母饮食影响 | 说明 |
|----------|----------------|------|
| 蛋白质、钙、脂肪 | 相对稳定 | 身体动用母体储备维持，故乳母易出现钙流失、肌肉消耗 |
| 碘 | **高度依赖** | 乳母碘不足→乳汁碘不足→婴儿甲减/智力发育受损 |
| DHA | 高度依赖 | 乳母多吃鱼/补 DHA→乳汁 DHA 上升 |
| 水溶性维生素（B族、维C） | 中度依赖 | 乳母缺乏则乳汁浓度下降 |
| 维A | 中度依赖 | 富维A食物提升乳汁维A |
| 铁 | 浓度低、较稳定 | 婴儿主要靠出生时储备的铁，乳汁铁少 |

**推论：**
1. 乳母**必须保证碘摄入**（加碘盐 + 海产品），这是"一人吃两人用"最典型的例子。
2. 想提高母乳 DHA → 每周 2~3 次海鱼或补藻油 DHA。
3. 蛋白质和钙——母乳里"不会缺"，但缺的是乳母自己（产后骨质疏松、掉头发、肌肉流失）。所以乳母要"先爱自己"。

### 2.4 饮水与泌乳

- 每天饮水 2100ml 以上，哺乳前/后各喝一杯水（约 200ml）。
- 判断标准：尿液颜色淡黄、每天小便 6~8 次。
- **别喝"下奶汤"当水**：浓白汤（猪蹄汤、鲫鱼汤）主要是脂肪+嘌呤，过量反而堵奶、长肉。想促进泌乳，靠的是**乳汁被规律吸空** + 充足水分，不是喝汤。

### 2.5 哺乳期禁忌

| 项目 | 建议 | 说明 |
|------|------|------|
| 酒精 | 尽量不喝；如必须，建议哺乳后马上喝、间隔 2~3 小时再喂 | 酒精进入乳汁影响婴儿 |
| 咖啡因 | <200mg/天 | 过量可使婴儿烦躁、入睡困难 |
| 吸烟 | 禁止 | 尼古丁进入乳汁 + 二手烟危害 |
| 某些药物 | 遵医嘱 | 多数常用药安全，但需医生评估 |
| 过量进补 | 避免 | 活血类中药、不明成分"月子补品"可能经乳汁影响婴儿 |

### 2.6 母乳不足的营养应对

| 排查项 | 处理 |
|--------|------|
| 是否喂得够勤 | 按需哺乳（每天 8~12 次）是泌乳第一动力 |
| 水分是否充足 | 每天 2100ml+，哺乳前后喝水 |
| 蛋白质/能量是否够 | 哺乳期每日 +25g 蛋白质、+500kcal，别"减肥式"饮食 |
| 是否真的不足 | 看尿量（每天 6 次以上湿尿布）+ 体重增长（每月 600g 左右）判断 |
| 睡眠与压力 | 睡眠差、压力大抑制催乳素，尽量保证休息 |

> **提示：** "没奶"很多是判断错误或喂养方法问题，先评估再干预；确实不足时，混合喂养也是科学选择，不必自责。

### 2.7 AI营养师沟通要点（哺乳期）

| 场景 | 话术 |
|------|------|
| 乳母问怎么吃 | "哺乳期在孕前基础上多 500kcal，多 25g 蛋白质——多一杯奶、一个蛋、一两肉，就够了，不用顿顿大鱼大肉。" |
| 怕胖不敢吃 | "哺乳本身每天消耗约 500kcal，相当于慢跑 40 分钟。你正常吃、喂好奶，体重会自然往回走，别靠节食。" |
| 下奶焦虑 | "泌乳的头号动力是让宝宝多吸，其次是你喝够水。汤是配角，别把白汤当'下奶药'。" |
| 提醒补碘 | "母乳的碘全靠你吃——加碘盐别断，每周一两顿海鱼海带，宝宝的甲状腺就靠它。" |
| 产后掉头发 | "产后掉发多是激素回落 + 营养透支，把蛋白质和铁补上、睡够，一般 6 个月内会恢复。" |
| 合规红线 | 不提"催乳产品"，不做泌乳治疗承诺；严重奶量不足建议就医/泌乳顾问。 |

## 三、婴幼儿营养（0~3岁）

### 3.1 喂养阶段总览表

| 月龄 | 奶量 | 辅食 | 要点 |
|------|------|------|------|
| 0~6 月 | 纯母乳（按需）或配方奶 | 不加辅食 | 不喂水、不喂果汁、不喂蜂蜜 |
| 6 月龄 | 母乳/配方奶 600~800ml | 开始添加：富铁泥糊 | 第一口：强化铁米粉/肉泥 |
| 7~9 月 | 母乳/配方奶 600~800ml | 2~3 餐，泥糊→碎末 | 引入蛋黄、肉、鱼、肝泥 |
| 10~12 月 | 母乳/配方奶 500~600ml | 3 餐 + 1~2 点心 | 手指食物、小颗粒 |
| 13~24 月 | 母乳/配方奶 400~600ml | 3 餐 + 2 点心 | 过渡家庭饮食、清淡 |
| 2~3 岁 | 奶 300~500ml | 三餐两点 | 均衡多样、独立进食 |

> **WHO 建议：** 纯母乳喂养至 6 月龄；6 月龄起添加辅食，并**继续母乳喂养至 2 岁或以上**。

### 3.2 0~6 月龄：纯母乳 / 配方奶

| 问题 | 答案 |
|------|------|
| 纯母乳要喂多久 | 满 6 月龄前纯母乳（不加水、不加果汁） |
| 多久喂一次 | 按需哺乳，新生儿每天 8~12 次 |
| 要不要喝水 | 纯母乳/配方奶喂养的婴儿**不需要额外喂水**（奶中含水足够；额外水挤占奶量、加重肾脏负担） |
| 要不要补维D | 要！出生后数天起每天补 **维D 400IU**，母乳不含足够维D |
| 要不要补铁 | 足月儿出生时储备的铁够用 4~6 个月；早产儿/低体重儿遵医嘱更早补 |
| 能不能喂蜂蜜 | **1 岁内禁蜂蜜**（肉毒杆菌感染风险） |
| 能不能喂果汁 | 不推荐（高糖、影响奶量） |

### 3.3 6~12 月龄：辅食添加

#### 辅食添加时机信号（WHO/中国指南）

宝宝出现以下信号，说明可以添加辅食：
1. 能靠坐、头颈控制良好
2. 对大人食物表现出兴趣（伸手、盯、张嘴）
3. 挺舌反射消失（不再用舌头把食物顶出来）
4. 体重达到出生时 2 倍左右（约 6kg）

#### 辅食添加原则

```
从一到多     每次只引入一种新食物，观察 2~3 天（防过敏监测）
从稀到稠     泥糊→碎末→小颗粒→手指食物
从细到粗     锻炼咀嚼吞咽能力
从少到多     从 1 勺开始，逐步加量
优先富铁     第一口辅食选强化铁米粉/肉泥/肝泥
无盐无糖     1 岁内不加盐、不加糖、不放调味料
```

#### 辅食引入顺序与质地进程

| 月龄 | 质地 | 推荐食物 | 每日辅食次数 |
|------|------|----------|--------------|
| 6 月龄 | 稀滑泥糊 | 强化铁米粉、肉泥、肝泥、南瓜泥 | 1~2 次 |
| 7~9 月 | 稠糊、碎末 | 蛋黄、鱼泥、菜泥、豆腐、稠粥 | 2~3 次 |
| 10~12 月 | 小颗粒、手指食物 | 软饭、小馄饨、煮软的蔬菜条、肉末 | 3 餐 + 1~2 点心 |
| 12~24 月 | 家庭清淡饮食 | 三餐与家人同食，少油少盐 | 3 餐 + 2 点心 |

**高致敏食物（鸡蛋、花生、鱼虾、大豆）要不要回避？**
> 现代指南（WHO/中国 2022）不再建议延迟引入高致敏食物。**4~6 月龄后正常逐个引入反而可能降低过敏风险**；但有明确家族过敏史者，建议在医生指导下进行。

### 3.4 1~3 岁：过渡到家庭饮食

| 项目 | 建议 |
|------|------|
| 奶量 | 每日 300~500ml 奶（奶是钙主力） |
| 三餐 | 与家庭同餐，清淡、软硬适中 |
| 两餐之间 | 健康点心：水果、酸奶、小馒头 |
| 进食技能 | 鼓励自己拿勺子、用手抓手指食物 |
| 食物种类 | 每天 12 种以上、每周 25 种以上（指南理念，尽量接近） |
| 餐桌氛围 | 不看电视、不追喂、不强迫，营造愉悦进食氛围 |

### 3.5 关键营养素：铁、维D、DHA、碘

#### 铁——婴幼儿第一营养素

| 项目 | 内容 |
|------|------|
| 为什么重要 | 铁参与血红蛋白合成和大脑发育；缺铁性贫血影响认知发育且**可能不可逆** |
| 为什么易缺 | 母乳铁含量低；出生储备 4~6 个月耗尽 |
| 推荐量 | 7~12 月龄约 10mg/天 |
| 食物来源 | 强化铁米粉、红肉泥、肝泥（每周 1~2 次）、动物血 |
| 吸收技巧 | 搭配维C（果泥）；避免辅食加盐 |
| 筛查 | 6~12 月龄常规查血常规；贫血高发地区注意预防性补铁 |

#### 维D——出生即补

| 项目 | 内容 |
|------|------|
| 推荐量 | 出生后数天起，每天 **400IU（10μg）**，至少补到 2 岁 |
| 原因 | 母乳维D极低；婴儿户外日照不足、皮肤娇嫩不宜暴晒 |
| 缺乏后果 | 佝偻病（O型腿、枕秃、夜惊、方颅） |
| 来源 | 补充剂为主；配方奶喂养者需计算奶粉中的维D |

#### DHA

| 项目 | 内容 |
|------|------|
| 推荐量 | 0~3 岁约 100mg/天 |
| 来源 | 母乳本身含 DHA（乳母每周吃鱼）；配方奶已强化；辅食加鱼肉 |
| 作用 | 大脑和视网膜发育 |

#### 碘

| 项目 | 内容 |
|------|------|
| 来源 | 母乳/配方奶 + 辅食中加碘盐（1 岁后可加微量盐） |
| 作用 | 甲状腺素合成，影响体格和智力发育 |
| 注意 | 1 岁内不从辅食加盐，但奶制品中的碘要保证 |

### 3.6 一岁内不加盐不加糖（铁律）

| 项 | 原因 |
|----|------|
| 不加盐 | ① 婴儿肾脏未发育成熟，负担重；② 养成清淡口味，降低一生高血压/慢病风险；③ 天然食物中的钠已足够 |
| 不加糖 | ① 龋齿高风险；② 偏好甜味→挑食；③ 空热量→影响正餐 |
| 不喝果汁 | 果汁浓缩糖分、挤占奶量；要吃就吃果泥/水果 |
| 不加蜂蜜 | 肉毒杆菌感染风险（1 岁内禁） |

**具体：** 6~12 月龄辅食不加任何盐糖和调味品；1 岁后逐渐过渡到清淡家庭口味（每天盐<2g）。

### 3.7 常见喂养问题

| 问题 | 应对 |
|------|------|
| 拒吃辅食 | 不强迫；换时间、换花样；家长示范咀嚼 |
| 便秘 | 增加膳食纤维（菜泥、果泥、全谷）、保证饮水、腹部按摩 |
| 食物过敏 | 逐个引入新食物观察 2~3 天；严重过敏（皮疹/呼吸困难）立即就医 |
| 体重不增 | 记录生长曲线（WHO 标准）；先查奶量再查辅食质量 |
| 微量元素缺口 | 定期儿保体检，按需补铁/维D |

### 3.8 AI营养师沟通要点（婴幼儿）

| 场景 | 话术 |
|------|------|
| 第一口辅食 | "6 个月加辅食，第一口选强化铁米粉或肉泥——这个阶段最缺的是铁，不是米汤。" |
| 要不要喂水 | "纯母乳和配方奶的宝宝，6 个月以前不用额外喂水，奶里就有水。" |
| 维D | "出生就开始补维D，每天 400IU，至少到 2 岁，母乳里没有足够的维D。" |
| 老人要加盐 | "1 岁以内不加盐不加糖——孩子肾脏小，清淡口味是一辈子的健康地基。" |
| 挑食 | "每个新食物试 8~15 次才算'试过'，别急着给娃贴'不吃'的标签。" |
| 合规红线 | 不做过敏诊断、不提产品推销、不替代儿保医生。 |

## 四、学龄前与学龄儿童营养（3~12岁）

### 4.1 分龄营养素需求表

| 年龄 | 能量(kcal) | 蛋白质(g) | 钙(mg) | 铁(mg) | 维D(μg) |
|------|-----------|-----------|--------|--------|----------|
| 2~3 岁 | 1000~1250 | 25 | 600 | 9 | 10 |
| 4~5 岁 | 1300~1400 | 30 | 800 | 10 | 10 |
| 6~7 岁 | 1400~1700 | 35~40 | 800 | 13 | 10 |
| 8~10 岁 | 1700~2000 | 40~45 | 1000 | 13~15 | 10 |
| 11~12 岁 | 2000~2400 | 50~60 | 1200 | 15~18 | 10 |

> 注：能量随性别和活动量浮动；铁在青春期前逐渐上升，女孩月经初潮后需求更高。儿童期是**骨骼发育峰值期**，钙在 11~13 岁需求达 1200mg/天。

### 4.2 儿童营养八大要点

1. **蛋白质每餐有**：肉、蛋、奶、豆，早餐也不能少
2. **钙要盯住**：奶 300~500ml/天 + 豆制品 + 绿叶菜
3. **铁别忽视**：红肉每周 2~3 次，女孩初潮后更要关注
4. **维D 常补**：户外 1 小时 + 必要时补充剂
5. **早餐是地基**：占全天能量 25~30%
6. **零食讲选择**：水果、奶、坚果 > 薯片、糖果
7. **含糖饮料最该管**：龋齿 + 肥胖 + 影响食欲
8. **屏幕时间控制**：久坐→肥胖；户外活动促身高

### 4.3 早餐：成绩和体重的地基

| 维度 | 内容 |
|------|------|
| 为什么重要 | 早餐供能占全天 25~30%；不吃早餐→上午注意力差、成绩下降、中午暴食、肥胖风险↑ |
| 好早餐四要素 | 谷类（主食）+ 蛋白质（蛋/奶/肉）+ 蔬果 + 适量奶 |
| 举例 | 全麦面包 + 牛奶 + 鸡蛋 + 一个猕猴桃 |
| 常见坑 | 只吃包子馒头（碳水过多）、只喝牛奶、路边摊高油高盐 |
| 家长动作 | 固定起床时间、提前准备、全家一起吃 |

### 4.4 挑食偏食管理

| 原则 | 具体做法 |
|------|----------|
| 不强迫 | 越逼越不吃；让"吃"变成快乐的事 |
| 反复暴露 | 一种新食物尝试 8~15 次才放弃 |
| 家长示范 | 孩子是模仿动物——大人先吃给他看 |
| 参与感 | 让孩子参与买菜、洗菜、摆盘 |
| 隐藏+暴露结合 | 把不爱的菜切碎混进爱吃的菜里，同时逐步增加曝光 |
| 不奖励不惩罚 | 不拿零食当"吃完青菜的奖励"（会反向强化） |
| 排除疾病 | 长期拒食、体重下降→排查贫血、缺锌、消化问题 |

### 4.5 零食策略

| 推荐零食 | 限零食 | 少给/不给 |
|----------|--------|-----------|
| 水果、酸奶、牛奶 | 饼干、蛋糕、面包 | 薯片、辣条、糖果、含糖饮料 |
| 原味坚果（3 岁+，防呛） | 巧克力 | 冰淇淋（高糖） |
| 蒸红薯、玉米 | 果汁（含糖） | 腌制肉类零食 |

**零食原则：**
- 两餐之间吃，离正餐 1.5 小时以上
- 每天零食不超过 2 次
- 不把零食当奖励或安抚工具

### 4.6 含糖饮料：儿童最大的"隐形糖"

| 项目 | 内容 |
|------|------|
| WHO 建议 | 游离糖摄入<全天能量 10%，最好<5%（5% 约相当于 25g/天） |
| 一瓶可乐含糖 | 约 35~40g（一瓶就超标） |
| 危害 | 龋齿、肥胖、胰岛素抵抗、骨质疏松（碳酸挤占奶量）、多动注意力 |
| 儿童更敏感 | 儿童味觉偏好期形成的嗜甜习惯会延续一生 |
| 替代 | 白水、纯牛奶、无糖酸奶、淡茶 |
| 家庭策略 | 家里不囤含糖饮料；外出就餐也点白水 |

### 4.7 儿童体重管理

| 原则 | 内容 |
|------|------|
| 大原则 | **儿童不搞节食减肥**——会影响生长发育 |
| 正确目标 | 超重者"稳住体重，长高不长胖"（身高增长带走 BMI） |
| 家庭整体调整 | 全家一起改饮食，不单独"惩罚"孩子 |
| 三减一增 | 减糖、减油、减少屏幕 + 增加运动 |
| 运动 | 每天至少 1 小时中等以上强度活动 |
| 睡眠 | 保证睡眠（缺觉→食欲激素紊乱→胖） |
| 心理 | 不嘲笑、不贴标签，保护自尊 |

### 4.8 儿童常见营养相关健康问题

| 问题 | 营养关联 | 对策 |
|------|----------|------|
| 缺铁性贫血 | 影响注意力和学习 | 红肉每周 2~3 次 + 维C；筛查血常规 |
| 龋齿 | 糖 + 口腔卫生 | 控糖、饭后漱口、定期涂氟 |
| 近视 | 户外光照不足、用眼过度 | 每天户外 2 小时（维D 也顺带解决） |
| 便秘 | 膳食纤维 + 饮水不足 | 蔬菜水果 + 全谷物 + 饮水 |
| 免疫力差 | 蛋白质、锌、维D | 均衡饮食 + 睡眠 + 户外 |

### 4.9 AI营养师沟通要点（儿童）

| 场景 | 话术 |
|------|------|
| 不吃早餐 | "孩子的成绩和体重，一半是早餐决定的。一顿好早餐=主食+蛋奶+一点水果，10 分钟搞定。" |
| 挑食 | "别急着给孩子贴'不吃菜'的标签，一样食物要试 8~15 次，家长先吃给他看。" |
| 含糖饮料 | "一瓶可乐的糖就够孩子一天的量了，家里不囤、出门不带，比讲一百遍道理管用。" |
| 小胖墩 | "孩子超重不能饿肚子，要'稳住体重长身高'——全家一起调整饮食，不是让孩子一个人少吃。" |
| 追着喂 | "让孩子自己决定吃多少，家长负责'做什么、什么时候吃'，孩子负责'吃不吃、吃多少'。" |
| 合规红线 | 不做儿童肥胖诊断、不推销减重产品；营养问题只给膳食建议。 |

## 五、青少年营养（12~18岁）

### 5.1 生长突增期特点

青春期是人生的**第二个生长高峰**（第一个是胎儿期到婴儿期），也是最后一个：

| 项目 | 女孩 | 男孩 |
|------|------|------|
| 突增启动 | 约 9~12 岁 | 约 11~14 岁 |
| 身高年增长峰值 | 8~9cm/年 | 9~10cm/年 |
| 体重年增长 | 约 8~10kg | 约 9~11kg |
| 月经初潮 | 约 12~13 岁 | — |
| 骨骼成熟 | 初潮后约 2 年 | 变声后 2~3 年 |

**营养意义：**
- 能量和蛋白质需求到达一生峰值
- **骨量在此期沉积约 40~50%**——现在存的钙，决定 60 岁后的骨密度
- 女孩铁需求因月经上升
- 激素剧变，情绪、睡眠、饮食行为都可能波动

### 5.2 青少年营养素需求

| 营养素 | 推荐量 | 说明 |
|--------|--------|------|
| 能量 | 男 2400~2900 / 女 2050~2400 kcal/天 | 随活动量浮动；运动员更高 |
| 蛋白质 | 男 65~75g / 女 55~60g/天 | 肌肉和器官快速增长 |
| 钙 | **1200mg/天**（11~13 岁峰值） | 一生最高需求；奶 500ml + 豆制品 |
| 铁 | 男 15~16mg / 女 18mg/天 | 女孩月经失血 + 生长 |
| 锌 | 男 10~12.5mg / 女 9~10mg/天 | 生长、性发育、免疫 |
| 碘 | 110~120μg/天 | 甲状腺素；青春期甲状腺肿高发 |
| 维D | 10μg(400IU)/天 | 促钙吸收 + 免疫 |
| 维A | 男孩 800 / 女孩 700μg RAE | 皮肤、视力、免疫 |

### 5.3 三大"必补盯紧"营养素

#### 钙——给 60 岁存骨量

- 峰值骨量的 40~50% 在青春期完成
- 青春期钙缺口→峰值骨量低→老年骨质疏松风险↑
- 来源：奶 500ml/天（约 500~600mg）+ 豆制品 + 绿叶菜 + 坚果
- 不够怎么办：乳制品不耐受者选酸奶、低乳糖奶、钙强化豆奶

#### 铁——女生重点

- 月经期每月失铁约 15~30mg
- 女生缺铁性贫血检出率高，影响注意力、体育成绩、情绪
- 来源：红肉、动物血、动物肝脏；搭配维C
- 素食女生风险更高，建议定期查血常规

#### 碘——青春期甲状腺

- 青春期甲状腺素需求↑，碘不足→甲状腺肿（大脖子）
- 来源：加碘盐 + 每周 1~2 次海带/紫菜/海鱼
- 别矫枉过正：海带一次别吃太多（甲亢风险），正常加碘盐 + 适量海产品即可

### 5.4 节食减肥的危害（重点警示）

| 危害 | 说明 |
|------|------|
| 身高受损 | 热量和蛋白质不足→生长激素分泌受阻→错失长高窗口 |
| 月经紊乱 | 能量不足→功能性下丘脑性闭经，长期可致不孕 |
| 进食障碍 | 过度节食→厌食症/暴食症，病死率高的精神科疾病 |
| 骨量流失 | 钙+能量双缺→青春期骨量"欠账" |
| 免疫力下降 | 蛋白质、锌、铁缺乏→反复感染 |
| 情绪问题 | 节食→血糖波动、神经递质缺乏→易怒、抑郁 |

**正确态度：**
- 青少年体重管理目标是**健康生活方式**，不是"瘦"
- 超重青少年：增加运动 + 减少含糖饮料/油炸/外卖，不搞极端节食
- 与其"少吃"，不如"吃对 + 多动 + 睡够"

### 5.5 青春期女性特殊营养

| 项目 | 内容 |
|------|------|
| 铁 | 月经期重点补铁；痛经者可增加镁（深绿叶菜、坚果） |
| 钙 | 1200mg/天，防未来骨质疏松 |
| 不靠"减肥代餐" | 代餐不能作为青春期主食 |
| 情绪性进食 | 引导规律三餐，不把食物当情绪出口 |

### 5.6 作息、运动与营养

- **睡眠**：青少年需 8~10 小时睡眠；缺觉→瘦素↓饥饿素↑→食欲失控
- **运动**：每天 1 小时中高强度运动（打球、跳绳、跑步）
- **规律三餐**：不吃早餐、深夜吃夜宵都是肥胖高危行为
- **咖啡因**：少喝含咖啡因饮料（影响睡眠 + 钙流失）

### 5.7 AI营养师沟通要点（青少年）

| 场景 | 话术 |
|------|------|
| 想节食减肥 | "你现在节食省下的每一斤，可能要用身高和月经来还。青春期不做极端节食，做'吃对+多动'。" |
| 补钙 | "青春期的钙是一生最贵的——你现在每天 500ml 奶，是给 60 岁的自己存骨量。" |
| 贫血头晕 | "女孩月经期铁流失快，红肉、动物血每周吃两三次，配点维C，别等头晕了才想起来。" |
| 挑食点外卖 | "外卖一周控制在 2 次以内，其余时间家里正常吃饭，蛋白质和蔬菜别靠外卖补。" |
| 熬夜 | "睡不够，食欲激素就乱——先保证 8 小时睡眠，比任何'营养品'都管用。" |
| 合规红线 | 不做体重/进食障碍诊断；严重消瘦或闭经建议就医。 |

## 六、老年营养（60+）

### 6.1 老年人生理变化与营养对策

| 生理变化 | 后果 | 营养对策 |
|----------|------|----------|
| 胃酸分泌减少 | 蛋白质/铁/B12 吸收下降 | 细软易消化、优质蛋白、必要时查 B12 |
| 消化酶减少 | 消化不良 | 少量多餐、充分咀嚼、食物切碎煮软 |
| 味觉嗅觉减退 | 食欲下降、盐越放越多 | 用葱姜蒜/香辛料/醋提味，限盐不靠咸味 |
| 胃肠蠕动减慢 | 便秘 | 膳食纤维 + 饮水 + 适量运动 |
| 肌肉流失（肌少症） | 跌倒、骨折、失能 | 高蛋白 1.2~1.5g/(kg·d) + 阻力运动 |
| 骨量流失（骨质疏松） | 骨折风险↑ | 钙 1000~1200mg + 维D 600~800IU |
| 能量需求下降 | 吃不下却容易胖 | 提高营养密度，不追求"量" |
| 食欲差/早饱 | 摄入不足→衰弱 | 三餐两点、ONS 口服营养补充 |
| 慢病增多 | 高血压/糖尿病/心脑血管 | 按疾病调整（见 11.07） |
| 咀嚼吞咽困难 | 进食量减少 | 质地调整、增稠、防误吸 |

### 6.2 老年人蛋白质与"吃得下"是关键

| 项目 | 内容 |
|------|------|
| 蛋白质推荐量 | 健康老人 **1.0~1.2g/(kg·d)**；肌少症/疾病状态 **1.2~1.5g/(kg·d)** |
| 举例（60kg 老人） | 每天需 60~90g 蛋白质 ≈ 1 个蛋(7g) + 1 杯奶(8g) + 2 两鱼(18g) + 2 两瘦肉(18g) + 半块豆腐(10g) |
| 分配原则 | **每餐 25~30g 优质蛋白，三餐均匀分配**（比"集中一顿大补"更利于肌肉合成） |
| 优质蛋白来源 | 蛋、奶、鱼虾、瘦肉、禽肉、豆制品 |
| 常见误区 | ① 老人"吃素养生"过度→蛋白质不足；② 只喝粥→营养密度太低；③ 忌口太多→营养更缺 |

> **"喝粥养胃"的坑：** 白粥是碳水+水，蛋白质和维生素密度极低。老人顿顿喝粥→肌肉流失加速。正确做法是"粥+蛋+肉末+青菜"，把营养密度提上去。

### 6.3 肌少症（Sarcopenia）——老年营养第一重点

#### 定义

肌少症（sarcopenia）是一种**进行性、广泛性的骨骼肌量减少、肌力下降和身体功能减退**的老年综合征，与跌倒、骨折、失能、死亡风险升高密切相关。

| 项目 | 数据 |
|------|------|
| 社区老人患病率 | 约 10~15% |
| 养老机构 | 更高（可达 30%+） |
| 我国老年肌少症 | 60 岁以上约 5.7%~20%不等，随年龄上升 |
| 后果 | 跌倒、骨折、住院、失能、全因死亡风险↑ |

#### EWGSOP2 诊断流程（2019 国际共识）

```
筛查（高危人群）
  ├─ SARC-F 问卷 ≥4 分
  └─ 小腿围 男<34cm / 女<33cm
        ↓
① 发现"低肌力"（握力 男<27kg / 女<16kg）
   → 判定"可能肌少症"
        ↓
② 确认"低肌肉量"（DXA/BIA 测量）
   → 确诊肌少症
        ↓
③ 评估"身体功能"（步速≤0.8m/s，或 SPPB≤8分，或起立-行走≥20s）
   → 严重肌少症
```

| EWGSOP2 核心指标 | 切点 |
|------------------|------|
| 握力（肌力） | 男 <27kg，女 <16kg |
| 四肢骨骼肌量指数（ASMMI，DXA） | 男 <7.0 kg/m²，女 <5.5 kg/m² |
| 步速（身体功能） | ≤0.8 m/s |
| 小腿围（筛查） | 男 <34cm，女 <33cm |
| 血清白蛋白（辅助参考） | <35g/L 提示营养不良/消耗 |

#### 肌少症干预三件套

```
① 高蛋白：1.2~1.5g/(kg·d)，每餐 25~30g 优质蛋白均匀分配
② 维D：600~800IU/天（缺乏者先补足）
③ 阻力训练：弹力带、深蹲、提踵、握力球，每周 2~3 次
```

**细节：**
- 蛋白质"分餐吃"优于"一顿吃"：早餐 25g + 午餐 25g + 晚餐 25g
- 乳清蛋白/大豆蛋白吸收利用快，可在蛋白质不足时作为补充
- 运动是"开关"，营养是"原料"——**只补蛋白不运动，肌肉也长不起来**
- 肌少症常与肥胖并存（"肌肉衰减型肥胖"）：既要保肌肉又要减脂

### 6.4 骨质疏松营养管理

| 项目 | 内容 |
|------|------|
| 定义 | 骨量减少、骨微结构破坏，脆性骨折风险↑ |
| 高危人群 | 绝经后女性、高龄、体重过轻、骨折家族史、长期卧床 |
| 钙 | 推荐 1000~1200mg/天（饮食 + 必要时补充剂） |
| 维D | 600~800IU/天（有助钙吸收；缺乏者遵医嘱更高剂量） |
| 蛋白质 | 足量蛋白质对骨骼也重要（肌肉-骨骼联动） |
| 运动 | 负重运动（快走、慢跑）+ 抗阻训练刺激成骨 |
| 生活方式 | 戒烟、限酒、防跌倒（居家防滑、照明、扶手） |
| 提醒 | 确诊骨质疏松需**遵医嘱**（可能需要药物），营养是基础不是全部 |

**钙的食物来源排序：**
1. 奶类（吸收率最高）——每天 300~500ml
2. 豆制品（北豆腐、豆腐干）
3. 深绿叶菜（芥蓝、油菜、苋菜）
4. 芝麻酱、坚果、虾皮（高盐，少量）

### 6.5 老人饮食口诀

#### "十拳头"口诀（易记版）

```
一拳头主食（每餐）
+ 一拳头肉鱼（每日）
+ 两拳头蔬菜（每日）
+ 一小拳头豆制品（每日）
+ 一杯奶（每日）
+ 足量饮水（每日 1500~1700ml）
```

#### 中国老年人膳食指南"核心四句话"

1. **食物多样，制作细软**——每天 12 种以上食物
2. **摄入足量优质蛋白**——奶、蛋、鱼、肉、豆
3. **主动足量饮水**——不要等渴了才喝（老人口渴感迟钝）
4. **积极户外活动，延缓肌肉衰减**——多晒太阳补维D

### 6.6 吞咽困难与食物调整

| 等级 | 描述 | 食物调整 |
|------|------|----------|
| 轻度 | 吃硬/干食物易呛 | 切碎、煮软、加汤汁 |
| 中度 | 喝水易呛 | 增稠（增稠剂/藕粉）、小口量 |
| 重度 | 进食困难 | 泥糊状、匀浆膳，必要时管饲（遵医嘱） |

**安全进食原则：**
- 坐直进食，饭后保持坐位 30 分钟
- 一次一小口，咽干净再吃下一口
- 避免一边吃一边说话
- 吃稠不吃稀（稀的流质更易呛）
- 家庭可用"绿（安全）/黄（需谨慎）/红（避免）"食物分层表

> **警示：** 反复呛咳、肺炎、不明原因发热→警惕误吸，需**就医评估**，营养干预需在专业指导下进行。

### 6.7 口服营养补充（ONS）

| 项目 | 内容 |
|------|------|
| 定义 | 经口摄入特殊医学用途配方食品/营养素补充饮品，补充日常膳食不足 |
| 适用 | 食欲差、体重下降、肌少症、围手术期、慢性消耗性疾病 |
| 能量 | 每日补充 400~600kcal（约 1~2 份） |
| 时机 | 两餐之间，不替代正餐 |
| 好处 | 改善体重、肌肉量、降低并发症 |
| 提醒 | 在医生/营养师指导下选用合适的配方；糖尿病/肾病者选对应配方 |

### 6.8 AI营养师沟通要点（老年）

| 场景 | 话术 |
|------|------|
| 老人腿没劲 | "腿没劲不全是'老了'，很可能是肌肉在流失。肌肉是能练回来的——每天补够蛋白 + 练练腿，比躺着养强。" |
| 只喝粥 | "粥越喝越虚——粥是碳水，蛋白质太少。在粥里加蛋花、肉末、青菜，营养密度才够。" |
| 防摔 | "防摔=练肌肉+吃够蛋白+补维D。这三件事做到，跌倒风险能降一大截。" |
| 骨质疏松 | "骨头的事要听医生的，但营养地基你自己能打：每天一杯奶 + 晒太阳 + 吃点深绿叶菜。" |
| 吃不下 | "吃得少就更要吃'精'——一餐里先保证蛋奶肉，吃不下的那部分用营养饮补充。" |
| 怕胆固醇不敢吃蛋 | "健康老人每天一个全蛋没问题，别为'胆固醇'把最便宜最好的蛋白质丢掉。" |
| 合规红线 | 不诊断肌少症/骨质疏松（要医院评估），只做科普和膳食建议；推荐就医检查。 |

## 七、特殊生理状态营养

### 7.1 素食人群

#### 素食分类与风险

| 类型 | 是否吃 | 风险等级 | 核心缺口 |
|------|--------|----------|----------|
| 蛋奶素 | 蛋、奶 | 较低 | 铁、锌（较蛋奶素风险小） |
| 奶素 | 奶 | 中 | 铁、锌、维B12（奶提供B12但量少） |
| 蛋素 | 蛋 | 中 | 钙、维D（无奶） |
| 全素（纯素） | 全部植物 | 高 | **B12、铁、锌、钙、维D、n-3** |

#### 各营养素对策

| 营养素 | 风险 | 对策 |
|--------|------|------|
| 维生素B12 | **必缺**（植物性食物几乎不含） | **全素者必须补充 B12**（这是素食唯一"必须靠补充剂"的营养素）；蛋奶素可从蛋奶获得一部分但建议定期查 |
| 铁 | 植物铁（非血红素铁）吸收率低 | 豆类、深绿叶菜、黑木耳 + 维C同食；避免浓茶咖啡配餐 |
| 锌 | 植物锌受植酸抑制 | 坚果、豆类、全谷物（发酵/浸泡/发芽降低植酸） |
| 钙 | 无奶则缺口大 | 北豆腐、豆浆(钙强化)、芝麻酱、绿叶菜；必要时补充剂 |
| 维D | 植物来源少 | 日照 + 补充剂（尤其北方/冬季） |
| n-3（DHA/EPA） | 植物只有α-亚麻酸 | 亚麻籽油、奇亚籽、核桃；藻油 DHA 是纯素来源 |
| 蛋白质 | 植物蛋白"质量"略低 | 谷豆搭配（氨基酸互补），每餐有豆制品 |

**素食人群"三注意"：**
1. 蛋奶素风险较小，全素必须补 B12
2. 儿童、孕妇、哺乳期全素风险高，建议营养师个体化评估
3. 纯素儿童生长迟缓→必须专业指导，不可"跟着信仰硬扛"

### 7.2 备孕男性

| 营养素 | 作用 | 食物来源 |
|--------|------|----------|
| 锌 | 精子生成、睾酮合成 | 牡蛎、红肉、坚果、全谷物 |
| 硒 | 精子抗氧化、活力 | 海产品、坚果（巴西果）、鸡蛋 |
| 叶酸 | 精子 DNA 质量 | 深绿叶菜、豆类 |
| 维C/维E | 抗氧化，减少精子 DNA 损伤 | 蔬果、坚果 |
| 辅酶Q10 | 精子能量代谢（补充级） | 鱼、肉、坚果 |
| 蛋白质 | 精液主要成分 | 肉蛋奶豆 |

**生活方式清单：**
- 戒烟限酒（吸烟显著降低精子质量和数量）
- 控制体重（肥胖→雄激素↓、精子质量↓）
- 避免睾丸局部高温：少泡热水澡、桑拿、不长时间久坐/骑行
- 规律作息、适度运动、避免熬夜
- 备孕提前 3~6 个月调整（精子生成周期约 72~90 天）

### 7.3 围绝经期女性（45~55 岁）

| 生理变化 | 营养对策 |
|----------|----------|
| 雌激素下降→骨流失加速 | 钙 1000mg/天 + 维D 400~800IU + 负重运动 |
| 雌激素下降→肌肉减少 | 优质蛋白 1.2g/(kg·d) 左右 + 抗阻训练 |
| 潮热、情绪波动 | 大豆异黄酮（豆浆、豆腐）可能缓解部分症状 |
| 代谢率下降→易胖 | 控制精制碳水，增加膳食纤维 |
| 心血管保护激素减少 | 少盐少油、多吃深海鱼（EPA/DHA） |
| 睡眠差 | 晚餐清淡、避免咖啡因下午后摄入 |

**要点：**
- 钙 + 维D 是围绝经期的"刚需"，此时是骨质疏松的"第一次加速流失期"
- 大豆异黄酮每日摄入约 40~80mg（约一杯豆浆 + 一块豆腐）可作为辅助
- 潮热、严重情绪问题需就医评估（必要时激素治疗/专科），营养是辅助
- **"更年期不是病，是人生阶段"**——营养管理做得好，平稳度过

### 7.4 高强度运动人群

| 营养素 | 建议 | 说明 |
|--------|------|------|
| 能量 | 按训练量增加（大强度可 +500~1000 kcal/天） | 不足→掉肌肉、免疫力下降 |
| 碳水化合物 | 5~10g/(kg·d)，耐力项目更高 | 糖原储备 = 运动表现 |
| 蛋白质 | 1.2~2.0g/(kg·d) | 力量训练 1.6~2.0，耐力 1.2~1.6 |
| 训练后窗口 | 运动后 30~60 分钟内补碳水+蛋白 | 促进糖原恢复和肌肉修复 |
| 水分与电解质 | 大量出汗需补钠钾镁；长时运动补盐 | 电解质紊乱→抽筋、中暑 |
| 铁 | 运动人群铁消耗大 | 女运动员/长跑者易缺铁性贫血 |
| 钙/维D | 需足量 | 骨骼应力 + 日照不足 |
| 抗氧化 | 维C、维E、植物化学物 | 中和运动产生的自由基（以食物为主） |

**实用建议：**
- 运动前：运动前 1~3 小时吃易消化碳水（香蕉、全麦面包）
- 运动中：超过 1 小时补充电解质饮料/运动饮料
- 运动后：乳清蛋白 + 香蕉/牛奶，是经典的"恢复餐"
- 普通人规律健身按"1.2~1.6g/kg"即可，不必盲目大量补蛋白质
- 蛋白粉只是"方便的蛋白质来源"，不是必需品——优先天然食物

### 7.5 其他特殊状态简述

| 状态 | 营养要点 |
|------|----------|
| 熬夜人群 | 维B族、抗氧化物（蔬果）、补水；尽量补觉，避免用咖啡因硬扛 |
| 术后恢复 | 高蛋白 1.2~2.0g/(kg·d) + 维C/锌（伤口愈合）+ 能量充足 |
| 长期素食儿童 | 必须专业评估：B12、铁、锌、钙、维D、蛋白质质量 |
| 慢性肾病 | 蛋白质限量（遵医嘱）、低盐低钾（分期管理），不自行"高蛋白" |
| 糖尿病老年 | 控制碳水总量 + 低GI + 优质蛋白，警惕肌少症+糖尿病共病 |
| 贫血待查 | 先查明原因（缺铁/缺B12/其他），再决定补什么，不盲目"补血" |
