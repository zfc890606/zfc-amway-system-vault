# 11.04 · 人群营养

> **一句话定位：** 全生命周期的营养——孕妇、乳母、婴幼儿、儿童青少年、老年人各有各的营养重点。给不同年龄段的顾客/家人做方案时调用。

---

## 一、孕期营养

### 1. 各孕期重点营养素
| 阶段 | 关键营养素 | 要点 |
|------|-----------|------|
| 孕早期（0~13周） | 叶酸400μg/天、碳水≥130g | 防神经管畸形；碳水不足防酮症 |
| 孕中期（14~27周） | 钙、铁、碘、DHA | 胎儿骨骼/大脑快速发育 |
| 孕晚期（28~40周） | 蛋白质+15g、铁、DHA | 补血、储备铁 |

### 2. 孕期增重目标（按孕前BMI）
| 孕前BMI | 总增重(kg) | 中晚期周增重 |
|---------|-----------|-------------|
| <18.5 | 12.5~18 | 0.44~0.58 |
| 18.5~24.9 | 11.5~16 | 0.35~0.50 |
| 25~29.9 | 7~11.5 | 0.23~0.33 |
| ≥30 | 5~9 | 0.17~0.27 |

### 3. 孕期禁忌
- 绝对禁酒、严格限咖啡因（<200mg/天）
- 避免生食（李斯特菌风险）：生鱼片、未熟蛋、软奶酪
- 不吃未经处理的肝脏（维A过量致畸）
- 孕期贫血：最常见缺铁性贫血，孕中晚期必查

## 二、哺乳期营养

| 项目 | 建议 |
|------|------|
| 能量 | 在孕前基础上 +500 kcal/天 |
| 蛋白质 | +25g/天 |
| 钙 | 1000mg/天（泌乳消耗大） |
| DHA | 200mg/天（母乳质量） |
| 饮水 | 充足（泌乳需要） |
| 碘 | 继续加碘盐（宝宝甲状腺素靠母乳碘） |

## 三、婴幼儿营养（0~3岁）

### 1. 喂养阶段
| 月龄 | 喂养 |
|------|------|
| 0~6月 | 纯母乳（首选）或配方奶；**不加水不喂果汁** |
| 6月龄 | 开始添加辅食（富铁泥糊：强化铁米粉优先） |
| 6~12月 | 辅食多样化，从泥糊→碎末→小颗粒 |
| 1~2岁 | 过渡到家庭饮食，清淡 |
| 2~3岁 | 三餐两点，均衡多样 |

### 2. 关键营养素
- **铁**：6月龄后母乳铁不够，必须辅食补铁（红肉泥/肝泥/强化铁米粉）
- **维D**：出生后即补充400IU/天（母乳不含足够维D）
- **DHA**：母乳本身含，配方奶已强化；辅食加鱼
- **盐糖**：1岁内不加盐不加糖

### 3. 辅食添加原则
- 从一到多、从稀到稠、从细到粗
- 每次只加一种新食物，观察3~5天（过敏监测）
- 首选强化铁米粉，逐步加菜泥/肉泥/蛋黄

## 四、学龄前与学龄儿童（3~12岁）

### 1. 营养要点
| 营养素 | 需求特点 |
|--------|---------|
| 蛋白质 | 生长发育关键期，肉蛋奶豆每餐有 |
| 钙 | 800~1200mg/天，骨骼发育峰值 |
| 铁 | 预防缺铁性贫血（影响认知） |
| 维D | 户外活动+必要时补充 |
| 早餐 | 必须吃、吃好（影响成绩和体重） |

### 2. 常见问题
- **挑食偏食**：不强迫、多样化、家长示范
- **零食**：用水果/奶/坚果替代高糖高盐零食
- **含糖饮料**：坚决少喝（龋齿+肥胖）
- **体重**：超重肥胖→家庭整体饮食调整，不搞节食

---

## 五、青少年营养（12~18岁）

- **能量/蛋白质需求高峰**（青春期生长突增）
- 钙1200mg/天（峰值骨量储备——老了防骨质疏松靠现在）
- 铁：女孩月经期更易缺
- 碘、锌：生长发育必需
- **作息**：规律三餐，别用节食减肥（影响身高/月经）

---

## 六、老年营养（60+）

### 1. 老年人生理变化与营养对策
| 变化 | 营养对策 |
|------|---------|
| 消化功能↓（胃酸↓、酶↓） | 细软食物、少量多餐、充分咀嚼 |
| 味觉嗅觉↓ | 用天然香料调味（少盐） |
| 肌肉流失（肌少症） | **高蛋白 1.2~1.5g/(kg·d)** + 阻力运动 |
| 骨密度↓ | 钙1000~1200mg + 维D 800~2000IU |
| 食欲差 | 三餐两点、ONS口服营养补充 |
| 慢病多 | 按疾病调整（见11.07） |

### 2. 肌少症（Sarcopenia）——老年营养第一重点
- 定义：肌肉量+力量+功能下降
- 发生率：社区老人约10~15%，养老机构更高
- 后果：跌倒、骨折、失能、死亡风险↑
- **干预三件套**：高蛋白（每餐25~30g优质蛋白均匀分配）+ 维D + 阻力训练
- 白蛋白<35g/L、小腿围<33cm（男）→ 警惕

### 3. 老人饮食"十拳头"口诀（易记版）
```
一拳头主食 + 一拳肉鱼 + 两拳蔬菜 + 一小拳豆 + 一杯奶 + 一杯水(额外)
```

## 七、特殊生理状态（补充）

### 1. 素食人群
| 类型 | 风险 | 对策 |
|------|------|------|
| 蛋奶素 | 风险较小 | 保证奶蛋 |
| 全素 | 缺B12/铁/锌/钙/n-3 | B12必补（素食者唯一必须靠补充剂）；多吃豆制品/发酵豆制品/强化食品 |

### 2. 备孕男性
- 锌、硒、叶酸、抗氧化营养素
- 戒烟限酒、控制体重（影响精子质量）

### 3. 围绝经期女性（45~55岁）
- 钙+维D（雌激素↓→骨流失加速）
- 大豆异黄酮（可能缓解部分更年期症状）
- 优质蛋白防肌少、控体重
