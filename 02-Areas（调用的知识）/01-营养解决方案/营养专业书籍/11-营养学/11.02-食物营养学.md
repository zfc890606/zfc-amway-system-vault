# 11.02 · 食物营养学

> **一句话定位：** 把营养素"放回食物"——谷薯、蔬果、畜禽鱼蛋奶豆、油盐酒，每类食物含什么、怎么选、怎么存、怎么烹调不丢营养。给顾客讲"吃什么"时直接调用。

---

## 一、食物分类与膳食结构

### 中国居民膳食宝塔（2022）
```
            ▲ 盐 <5g/天，油 25~30g/天
           ▲▲ 奶及奶制品 300~500g/天
          ▲▲▲ 大豆及坚果 25~35g/天
         ▲▲▲▲ 动物性食物 120~200g/天
          （畜禽40~75 + 水产40~75 + 蛋40~50）
        ▲▲▲▲▲ 蔬菜 300~500g + 水果 200~350g
       ▲▲▲▲▲▲ 谷类 200~300g（全谷杂豆50~150g）+ 薯类 50~100g
```

---

## 二、各类食物的营养价值

### 1. 谷薯类（主食）
| 食物 | 营养特点 | 选择建议 |
|------|---------|---------|
| 大米/面粉 | 供能，但精制后丢维生素B族和膳食纤维 | 全谷物替换1/3~1/2 |
| 全谷物（糙米/燕麦/荞麦） | 富B族、镁、膳食纤维、植物化学物 | 每天50~150g |
| 杂豆（红豆/绿豆） | 优质植物蛋白+纤维，低GI | 掺入主食 |
| 薯类（土豆/红薯/山药） | 富钾、VC、膳食纤维 | 部分替代主食（等能量换） |

**关键：** 全谷物富含的膳食纤维+抗性淀粉 = 控糖、降脂、养菌群的核心工具。

### 2. 蔬菜水果
| 类别 | 代表 | 营养亮点 |
|------|------|---------|
| 深色蔬菜（占一半） | 菠菜/西兰花/胡萝卜/番茄 | 胡萝卜素、叶酸、钾、维生素C |
| 十字花科 | 西兰花/卷心菜/萝卜 | 萝卜硫素（抗癌植物化学物） |
| 菌菇类 | 香菇/木耳 | 多糖、膳食纤维、B族 |
| 浆果类 | 蓝莓/草莓 | 花青素、抗氧化 |
| 柑橘类 | 橙子/柚子 | 维C、类黄酮 |

**建议：** 蔬菜300~500g/天（深色占一半），水果200~350g/天（整果>果汁）。
**"沙子"提示：** 果汁不是水果——榨汁丢纤维、升糖快。

### 3. 畜禽鱼蛋类（优质蛋白）
| 食物 | 营养特点 | 注意 |
|------|---------|------|
| 瘦肉（猪牛羊） | 优质蛋白+血红素铁+锌+B12 | 红肉适量（≤500g/周），加工肉少吃 |
| 禽肉（鸡鸭） | 低脂优质蛋白 | 去皮更减脂 |
| 鱼类 | 优质蛋白+n-3（EPA/DHA） | 每周2次深海鱼 |
| 贝类虾类 | 锌、硒、优质蛋白 | 痛风者注意嘌呤 |
| 蛋类 | "完全蛋白"+胆碱+卵磷脂 | 每天1个全蛋没问题 |

**红肉与健康：** 过量红肉/加工肉与结直肠癌风险相关（WHO 2A/1类致癌物），但适量（<70g/天）在平衡膳食内没问题——**别制造焦虑，讲"适量"**。

### 4. 奶类、大豆、坚果
| 食物 | 营养特点 | 建议量 |
|------|---------|--------|
| 奶类 | 钙+优质蛋白+B2 | 300~500ml/天 |
| 酸奶 | 钙+益生菌 | 选低糖 |
| 大豆（黄豆/黑豆） | 植物完全蛋白+异黄酮+卵磷脂 | 25~35g/天（豆腐约150g） |
| 坚果 | MUFA/n-3+维E+镁 | 每天一小把（约10g） |

**大豆与健康：** 大豆异黄酮是"植物雌激素"，正常食用**不**增加乳腺癌风险，反而有保护证据；乳腺增生人群也无需完全回避（除非特殊医嘱）。

### 5. 油盐糖酒
| 项目 | 建议 | 说明 |
|------|------|------|
| 烹调油 | 25~30g/天 | 多种油换着吃 |
| 盐 | <5g/天 | 高钠=高血压主因 |
| 添加糖 | ≤50g，最好≤25g | 隐形糖（饮料/糕点）是大头 |
| 酒 | 最好不喝，喝则限 | 男≤25g酒精/天，女≤15g（约=啤酒750ml/葡萄酒250ml/白酒50ml） |

## 三、食物加工、储存与烹调

### 1. 营养素流失规律
| 因素 | 影响 |
|------|------|
| 温度 | 维C/B族最怕高温 |
| 光照 | 维B2、维C怕光 |
| 水 | 水溶性维生素/矿物质溶水流失（焯水/煮汤） |
| 氧气 | 维C、不饱和脂肪酸氧化 |
| 时间 | 存放越久流失越多 |

### 2. 烹调建议
- **先洗后切、急火快炒**：减少维C流失
- **蒸煮优先**：比煎炸少用油、少产生AGEs
- **蔬菜焯水**：可去草酸（菠菜）但丢维C——权衡
- **主食**：不要过度淘洗（丢B族）；加碱会破坏B族（少用）
- **低温慢煮/蒸**：保留营养又安全

### 3. 常见加工方式评价
| 方式 | 评价 |
|------|------|
| 蒸/煮/炖 | ✅ 保留营养，少油 |
| 急火快炒 | ✅ 短时高温，营养损失小 |
| 油炸 | ⚠️ 高能量+产生AGEs/丙烯酰胺 |
| 烧烤 | ⚠️ 高温产生杂环胺（焦黑部分少吃） |
| 腌制/烟熏 | ⚠️ 高盐+亚硝酸盐（偶尔吃可以） |

### 4. 食物储存
- 冷藏（0~4℃）：蔬果、奶蛋
- 冷冻（-18℃）：肉类（-18℃可存数月）
- 粮油避光密封：防氧化哈败
- 发芽土豆/霉变坚果/长毛面包 → **直接扔，别可惜**

## 四、食品标签解读（顾客常问）

### 营养成分表（每100g/每份）
| 项目 | 看什么 |
|------|--------|
| 能量 | 千焦kJ÷4.18=kcal |
| 蛋白质 | 含量越高越好（奶/肉） |
| 脂肪 | 看饱和脂肪/反式脂肪 |
| 碳水化合物 | 看糖（"碳水化合物"包含糖和淀粉） |
| 钠 | 高钠食品警惕（方便面/火腿/酱料） |
| NRV% | 占每日参考值百分比，超过100%注意 |

### 配料表规则
- **按含量降序排列**：排第一位=含量最多
- 警惕：白砂糖/果葡糖浆/麦芽糖浆排在前面 = 高糖食品
- 氢化植物油/起酥油/植脂末 = 可能含反式脂肪
- "0添加蔗糖" ≠ 无糖（可能含淀粉水解糖/果糖）

### 常见营销话术辟谣
| 话术 | 真相 |
|------|------|
| "0脂肪" | 可能高糖（把脂肪换成糖） |
| "0蔗糖" | 可能含果糖/麦芽糖 |
| "非油炸" | 可能还是高油（烘焙油） |
| "高蛋白" | 看NRV%，≥20%NRV才真算高 |
| "能量xx千焦" | 除以4.18才是大卡 |

## 五、食物相克？辟谣专区

| 说法 | 真相 |
|------|------|
| 菠菜+豆腐=结石 | ❌ 草酸+钙在体内结合量极低，正常吃无碍（菠菜焯水更好） |
| 维生素C+海鲜=砒霜 | ❌ 需巨大剂量+极端条件，普通饮食达不到 |
| 豆浆+鸡蛋=不吸收 | ❌ 生豆浆有抗胰蛋白酶（煮熟即失活），熟豆浆+鸡蛋没问题 |
| 柿子+螃蟹=腹痛 | ⚠️ 高鞣酸+高蛋白，胃弱/空腹时可能不适，非"相克" |

**底层逻辑：** 我国食品安全国家标准体系和现代营养学**不承认"食物相克"**。真正要注意的是：过敏、食物中毒、药物与食物相互作用。

## 六、食物营养学 → 落地工具

| 场景 | 讲什么 |
|------|--------|
| 顾客问"早餐吃什么" | 全谷物+鸡蛋+奶+水果=满分组合 |
| 顾客问"保健品怎么选" | 先从食物补（天然食物营养密度最高），缺口再考虑补充剂 |
| 教客户看标签 | 配料表+营养成分表三看：糖/脂肪/钠 |
| 辟谣 | 食物相克不成立、果汁≠水果、0脂肪≠健康 |
