# 11.00 · 营养学总览

> **一句话定位：** 营养学科的全景地图——这门学科由哪些分支组成，每个分支解决什么问题，AI营养师的工作对应哪些分支。

---

## 一、营养学的定义与范畴

**营养学（Nutrition）：** 研究食物中的营养素及其他生物活性物质，与人体健康、疾病关系的科学。

### 两大方向
| 方向 | 研究什么 |
|------|---------|
| **基础营养** | 营养素种类、功能、代谢、需要量（营养素本身的科学） |
| **应用营养** | 把营养学用到人群/临床/公共政策（怎么吃、怎么干预） |

### 学科分支（与本书库对应）
```
营养学
├── 11.01 营养学基础（营养素与代谢）
├── 11.02 食物营养学（食物中的营养）
├── 11.03 膳食指南与DRIs（"吃多少"的标准）
├── 11.04 人群营养（不同人生阶段）
├── 11.05 公共营养（人群层面干预）
├── 11.06 临床营养（医院里的营养治疗）
├── 11.07 慢性病营养管理（慢病营养处方）
├── 11.08 食品卫生与安全（吃的安全）
└── 11.09 药食同源与保健食品（功效食品）
```

## 二、营养素总分类

### 1. 宏量营养素（需要量大，供能）
| 营养素 | 供能系数 | 主要功能 |
|--------|---------|---------|
| 碳水化合物 | 4 kcal/g | 主要供能 |
| 蛋白质 | 4 kcal/g | 构成修复、供能 |
| 脂肪 | 9 kcal/g | 高效储能、结构功能 |

### 2. 微量营养素（需要量小，不供能但必需）
| 类别 | 成员 |
|------|------|
| 维生素（脂溶性） | A、D、E、K |
| 维生素（水溶性） | B1、B2、B3、B5、B6、B7、B9（叶酸）、B12、C |
| 矿物质（宏量） | 钙、磷、镁、钾、钠、氯、硫 |
| 矿物质（微量） | 铁、锌、铜、碘、硒、铬、锰、钼、钴、氟 |

### 3. 其他膳食成分
- **水**（最被忽视的"营养素"）
- **膳食纤维**（益生元）
- **植物化学物**：多酚、类黄酮、姜黄素、萝卜硫素、番茄红素、花青素
- **生物活性肽**、**益生菌**、**辅酶Q10** 等

## 三、营养学的核心概念（贯穿全书）

### 1. 膳食参考摄入量（DRIs）体系
```
EAR 平均需要量 → RDA/RNI 推荐摄入量 → AI 适宜摄入量 → UL 可耐受最高摄入量
                    PI-NCD（慢性病预防建议摄入量）
AMDR 宏量营养素可接受范围
```
> 详细应用 → [[02-Areas（调用的知识）/01-营养解决方案/营养专业书籍/11-营养学/11.03-膳食指南与DRIs]]

### 2. 膳食质量评价
- **膳食结构**：中国居民膳食宝塔（谷薯→蔬果→畜禽鱼蛋→奶豆→油盐）
- **营养密度**：单位能量中营养素的量（菠菜比薯片高得多）
- **能量平衡**：摄入=消耗+储存（体重的根本逻辑）

### 3. 营养不良两端
```
能量过剩型：肥胖、脂肪肝、代谢综合征
能量不足型：消瘦、蛋白质-能量营养不良、微量营养素缺乏（隐性饥饿）
```

## 四、营养学发展简史（懂历史才有判断力）

| 时期 | 里程碑 |
|------|--------|
| 古代 | 东方"药食同源"；西方"医食同源" |
| 18-19世纪 | 发现氧、能量（燃烧学说） |
| 1912年 | Funk 提出"维生素"概念（Vitamine） |
| 20世纪上半叶 | 逐一发现维生素A/B/C/D等，营养素缺乏病被攻克 |
| 20世纪中后期 | 转向"营养过剩与慢病"研究 |
| 2000年后 | 分子营养学、营养基因组学、精准营养、肠道菌群 |
| 现在 | 从"防缺乏"走向"优化健康、管理慢病、抗衰" |
