# 11.06 · 临床营养

> **一句话定位：** 医院场景下的营养治疗——营养筛查、评估、诊断、营养支持（肠内/肠外）、各疾病营养治疗。这是"把营养当治疗手段"的专业版。
>
> **本页定位：** "书本级"详细版。覆盖从筛查到出院的完整路径，含 NRS-2002 完整评分、MNA-SF/MUST/SGA 条目与判读、GLIM 诊断、五阶梯、ONS、肠内/肠外营养、围手术期、特殊场景与家庭营养。
>
> **主要依据：** 人卫社《临床营养学》、ESPEN 系列指南、GLIM 共识（Cederholm et al., 2019）、NRS-2002 原始文献（Kondrup et al., 2003）、石汉平"营养不良五阶梯治疗原则"。
>
> **完整体系：** 与 [[02-Areas（调用的知识）/01-营养解决方案/临床营养学核心框架]] 配合使用。

## 一、临床营养概述与工作流程

### 1. 定义

**临床营养（Clinical Nutrition）：** 在疾病状态下，通过营养筛查、评估、诊断，采用营养支持/治疗手段，改善患者营养状态、支持疾病治疗、减少并发症、改善临床结局的医学分支。

**核心理念：**

> 营养不良是疾病的一部分——它既是疾病的结果，又会加重疾病、延长住院、增加死亡。营养治疗是医疗的一部分，不是可选项。

### 2. 完整工作流程（六步闭环）

```
筛查（谁有问题）→ 评估（问题多重）→ 诊断（什么问题）
        → 干预（五阶梯）→ 监测（效果）→ 调整
```

| 步骤 | 工具/内容 | 产出 |
|------|----------|------|
| ① 筛查 | NRS-2002 / MNA-SF / MUST / SGA | 是否营养风险 |
| ② 评估 | ABCD（人体测量/生化/临床/膳食） | 风险严重程度、具体短板 |
| ③ 诊断 | GLIM 标准 | 营养不良类型与严重度 |
| ④ 干预 | 五阶梯（教育→ONS→EN→PN） | 营养支持方案 |
| ⑤ 监测 | 体重、生化、耐受性 | 效果与不良反应 |
| ⑥ 调整 | 阶梯升降、配方调整 | 更新的方案 |

**核心顺序（永恒原则）：**

```
膳食 > 口服营养补充（ONS）> 肠内营养（EN）> 肠外营养（PN）
"能肠内不肠外、能口服不输液"
```

### 3. 关键时间节点

| 节点 | 要求 |
|------|------|
| 入院 | 24小时内完成营养筛查 |
| 有风险者 | 48小时内完成营养评估 |
| 确诊营养不良 | 尽早启动营养支持 |
| ICU患者 | 48小时内启动肠内营养（除非禁忌） |

## 二、营养筛查工具详解

**营养筛查（Screening）：** 用简单、快速、标准化的工具，从人群中"筛出"有营养风险者，以便进一步评估。**筛查不等于诊断。**

### 1. NRS-2002（成年住院患者·推荐首选）

**来源：** Kondrup et al., 2003，ESPEN 推荐用于成年住院患者，我国《临床营养指南》推荐入院 24h 内完成。

#### 第一步：初筛（4个快速问题，任一"是"则进入终筛）

| 序号 | 初筛问题 |
|------|---------|
| ① | BMI < 20.5 kg/m² 吗？ |
| ② | 近3个月体重下降吗？ |
| ③ | 近1周膳食摄入减少吗？ |
| ④ | 病情严重吗（如ICU）？ |

> 任一答"是" → 进入终筛；全否 → 每周复筛。

#### 第二步：终筛评分（营养受损评分 + 疾病严重程度评分 + 年龄校正）

**A. 营养受损评分（0~3分）：**

| 分值 | 条件 |
|------|------|
| 0分 | 营养状态正常 |
| 1分 | 近3个月体重下降 >5%；或近1周进食量减少 25%~50% |
| 2分 | 近2个月体重下降 >5%；或 BMI 18.5~20.5 且一般情况差；或近1周进食量减少 50%~75% |
| 3分 | 近1个月体重下降 >5%（或近3个月 >15%）；或 BMI <18.5 且一般情况差；或近1周进食量减少 75%~100% |

**B. 疾病严重程度评分（0~3分）：**

| 分值 | 疾病类型 | 举例 |
|------|---------|------|
| 0分 | 正常营养需求 | 一般轻症 |
| 1分 | 轻度疾病（需求轻度增加） | 髋骨骨折、慢性疾病急性发作或并发症、肝硬化、COPD、长期血液透析、糖尿病、一般肿瘤患者 |
| 2分 | 中度疾病（需求中度增加） | 腹部大手术、卒中、重症肺炎、血液恶性肿瘤 |
| 3分 | 重度疾病（需求重度增加） | 颅脑损伤、骨髓移植、ICU患者（如APACHE>10） |

**C. 年龄校正：** ≥70岁 总分加 **1分**。

**判读：**

| 总分 | 结论 |
|------|------|
| ≥ 3分 | 有营养风险 → 制定营养支持计划 |
| < 3分 | 无营养风险 → 住院期间每周复筛 |

> ⚠️ 注意事项：NRS-2002 初筛依赖 BMI，不能站立/测量的患者需换算（如用小腿围、腓肠肌部位估计）；昏迷/无法回答的患者由家属代答。

### 2. MNA-SF（老年人·简版微型营养评定）

**来源：** Nestlé Nutrition Institute 开发，适用于 ≥65岁 老年人（社区/医院/养老院），满分 14 分。共 6 个条目：

| 条目 | 内容 | 计分 |
|------|------|------|
| ① 近3个月食欲/进食量 | 严重减少=0；中度减少=1；无变化=2 | 0~2 |
| ② 近3个月体重下降 | >3kg=0；不知道=1；1~3kg=2；无下降=3 | 0~3 |
| ③ 活动能力 | 卧床=0；能下床不外出=1；正常活动=2 | 0~2 |
| ④ 近3个月心理应激/急性疾病 | 有=0；无=2 | 0~2 |
| ⑤ 神经心理问题（痴呆/抑郁） | 严重=0；轻度=1；无=2 | 0~2 |
| ⑥ BMI（或小腿围替代） | BMI<19=0；19~21=1；21~23=2；≥23=3；若BMI不可测：小腿围<31cm=0，≥31cm=3 | 0~3 |

**判读：**

| 总分 | 结论 |
|------|------|
| 12 ~ 14分 | 营养正常 |
| 8 ~ 11分 | 营养不良风险 |
| 0 ~ 7分 | 营养不良 |

### 3. MUST（社区/门诊·通用营养不良筛查工具）

**来源：** 英国肠外肠内营养协会（BAPEN）开发，适用于社区、门诊、住院通用，对卧床/坐轮椅者也适用。共 5 步：

| 步骤 | 内容 | 评分 |
|------|------|------|
| ① BMI评分 | BMI>20.0=0；18.5~20.0=1；<18.5=2 | 0~2 |
| ② 近期体重下降评分（3~6月非计划性） | <5%=0；5~10%=1；>10%=2 | 0~2 |
| ③ 急性疾病影响 | 急性疾病致禁食/摄入不足 >5天=2分 | 0~2 |
| ④ 总分 | ①②③ 相加 | 0~6 |
| ⑤ 风险分级与方案 | 见下表 | — |

**判读与管理：**

| 总分 | 风险 | 处理 |
|------|------|------|
| 0分 | 低风险 | 常规护理，住院每周复筛 |
| 1分 | 中风险 | 观察，记录膳食，若持续1周无改善需处理 |
| ≥2分 | 高风险 | 制定并实施营养支持计划，转营养科 |

### 4. SGA（主观全面评定）

**来源：** Detsky et al., 1987，经典临床主观评定，适用于住院患者，强调**病史+体格**，由受过训练的人员实施。

**A. 病史部分：**

| 项目 | 内容 |
|------|------|
| 体重变化 | 近6个月变化趋势、近2周变化（下降→再升高=胃纳恢复好） |
| 膳食摄入变化 | 由正常→固体→软食→流质→仅液体→几乎不进食 |
| 胃肠道症状 | 持续 >2周 的恶心、呕吐、腹泻、厌食 |
| 功能活动 | 正常→亚理想→卧床/活动受限 |

**B. 体格部分：**

| 部位 | 观察 |
|------|------|
| 皮下脂肪 | 眼窝、肱三头肌、胸部 |
| 肌肉消耗 | 颞肌、锁骨、肩部、肩胛、大腿、膝 |
| 水肿 | 踝部、骶部水肿；腹水 |

**分级：**

| 级别 | 含义 |
|------|------|
| A级 | 营养良好 |
| B级 | 中度营养不良（或怀疑） |
| C级 | 重度营养不良 |

### 5. 四工具对比总表

| 对比项 | NRS-2002 | MNA-SF | MUST | SGA |
|--------|----------|--------|------|-----|
| 适用人群 | 成年住院患者 | 老年人 | 社区/门诊/住院通用 | 住院患者 |
| 侧重点 | 疾病严重度+营养受损 | 老年人多维度 | 简易风险分层 | 病史+体格综合 |
| 是否依赖身高体重 | 是（BMI） | 是（BMI/小腿围替代） | 是（BMI） | 部分 |
| 所需时间 | 5~10分钟 | 3~5分钟 | 3~5分钟 | 10~15分钟 |
| 评分形式 | 0~7分（≥3风险） | 0~14分（≤11风险，≤7营养不良） | 0~6分（≥2高风险） | A/B/C三档 |
| 培训要求 | 低 | 低 | 低 | 中高 |
| 我国推荐 | 住院首选 | 老年科/社区 | 社区/门诊 | 住院综合评估 |

**选择口诀：** 住院成 人 选NRS，老年选MNA-SF，社区门诊选MUST，要全面诊断用SGA。

## 三、营养评估（ABCD）

**营养评估（Assessment）：** 对筛查阳性者进行更深入的定量与定性评价，回答"问题多重、缺在哪"。ABCD 是经典框架。

| 字母 | 维度 | 关键指标 | 常用参考 |
|------|------|---------|---------|
| A | Anthropometry 人体测量 | 身高、体重、BMI、中上臂围（MAC）、小腿围、皮褶厚度、腰围 | BMI 18.5~23.9（中国）；MAC/小腿围下降提示肌肉流失 |
| B | Biochemistry 生化 | 白蛋白、前白蛋白、血红蛋白、总淋巴细胞计数、电解质（钾钠钙磷镁）、转铁蛋白 | 白蛋白<35g/L、前白蛋白<200mg/L 提示蛋白质营养受损 |
| C | Clinical 临床 | 疾病诊断、用药（激素/免疫抑制剂）、症状（食欲/恶心/腹泻）、肌肉消耗体征 | 疾病严重度、炎症状态（CRP） |
| D | Dietary 膳食 | 24h回顾、FFQ、摄食比例、吞咽障碍、饮食限制 | 摄入 vs DRIs/需求；<50%需求>1周 为显著摄食不足 |

### 各维度详解

**A·人体测量要点：**
- **白蛋白的"慢"与"快"：** 白蛋白半衰期约 20 天，反映长期蛋白状态；前白蛋白半衰期约 2 天，反映近期变化。急症时白蛋白会因炎症"稀释"下降，需结合炎症指标（CRP）解读。
- **体重是金指标：** 非自主体重下降 >5%（3个月内）即有意义；肌少症关注小腿围<31cm、握力下降。

**B·关键生化指标速查：**

| 指标 | 参考范围（方向性） | 营养意义 |
|------|-------------------|---------|
| 血清白蛋白 | ≥35 g/L | 内脏蛋白储备（慢指标） |
| 前白蛋白 | ≥200 mg/L | 近期蛋白摄入（快指标） |
| 血红蛋白 | 男≥130 g/L；女≥120 g/L | 贫血/铁营养 |
| 淋巴细胞计数 | ≥1.5×10⁹/L | 免疫功能与蛋白营养 |
| CRP | <8 mg/L | 炎症程度（干扰营养指标解读） |
| 血磷/钾/镁 | 磷0.85~1.51；钾3.5~5.3；镁0.75~1.02 mmol/L | 再喂养综合征监测 |

**C·临床评估要点：**
- 记录原发病、手术/创伤、感染、发热（每升高1℃，静息能量消耗约增加10%~13%）
- 用药：糖皮质激素增加分解代谢、利尿剂致电解质紊乱、免疫抑制剂影响肠道
- 体检：颞肌/锁骨/肩胛肌肉是否凹陷、有无水肿腹水

**D·膳食评估要点：**
- 估算实际摄入 vs 目标需要（如 <50%需求持续>1周 → 显著摄食不足）
- 问清：食欲、咀嚼吞咽、恶心呕吐、腹泻便秘、饮食禁忌、外送/管饲

> 📌 输出：评估结果 → 判断是否符合营养不良诊断（GLIM）→ 定营养支持方案。

## 四、营养不良诊断（类型与GLIM标准）

### 1. 营养不良的类型

| 类型 | 别称 | 机制 | 特征 | 典型人群 |
|------|------|------|------|---------|
| 消瘦型（能量不足型） | 干瘦型 Marasmus | 能量摄入严重不足，机体分解脂肪与肌肉供能 | 皮下脂肪+肌肉明显消耗，但内脏蛋白可相对正常，无水肿 | 长期饥饿、吸收障碍、恶性肿瘤晚期 |
| 水肿型（蛋白质缺乏型） | 恶性营养不良 Kwashiorkor | 蛋白质摄入严重不足，但能量尚可 | 低白蛋白、凹陷性水肿，脂肪相对保留，肝脏脂肪浸润 | 蛋白质摄入不足、严重感染/创伤急性期 |
| 混合型 | — | 能量与蛋白质均不足 | 上述两者兼有 | 临床上最常见 |
| 肌少症性营养不良 | — | 肌肉量/功能减少+炎症/疾病 | 肌肉减少、肌力下降 | 老年人、慢性病、肿瘤 |

### 2. GLIM 营养不良诊断标准（国际共识）

**来源：** Global Leadership Initiative on Malnutrition，Cederholm et al., 2019，2019 年发布于 *Clinical Nutrition* 与 *JPEN*，全球主流共识。

#### 第一步：用已验证筛查工具确认"有风险"

先用 NRS-2002 / MUST / MNA-SF 等筛出阳性者，才进入第二步诊断。**筛查阳性是诊断前提。**

#### 第二步：诊断 = 表型标准（≥1项）+ 病因标准（≥1项）

**表型标准（身体表现）：**

| 表型 | 诊断界值 |
|------|---------|
| ① 非自主体重下降 | 6个月内 >10%；或 3个月内 >5% |
| ② 低BMI | 亚洲人群：<18.5（<70岁）；<20（≥70岁）（欧美人群界值更高） |
| ③ 肌肉量减少 | 用已验证方法测定（如 DXA、BIA、超声、CT 骨骼肌指数、小腿围等） |

**病因标准（致病原因）：**

| 病因 | 内容 |
|------|------|
| ① 摄食减少或吸收障碍 | 摄入 ≤50% 需求 >1周；或任何程度摄入减少 >2周；或影响消化吸收的胃肠道疾病 |
| ② 疾病负担/炎症 | 急性疾病/损伤（严重感染、烧伤、创伤、大手术）；慢性疾病伴炎症（肿瘤、COPD、慢性心衰、慢性肾病、慢性肝病等） |

#### 严重程度分级

| 分级 | 表型标准满足程度 |
|------|-----------------|
| 中度营养不良 | 6个月体重下降 5%~10%；或 BMI 轻度降低；或轻度肌肉减少 |
| 重度营养不良 | 6个月体重下降 >10%；或 BMI 显著降低；或重度肌肉减少 |

> 💡 记法：**表型（表现）+ 病因（原因）各取一**。看"掉多少（体重/BMI/肌肉）"+"为什么掉（没吃够/有炎症）"。

### 3. 营养不良的临床后果

| 后果 | 说明 |
|------|------|
| 免疫低下 | 感染风险↑，伤口愈合延迟 |
| 肌肉衰减 | 肌力↓、活动能力↓、跌倒风险↑ |
| 呼吸肌无力 | 脱机困难、肺炎风险↑ |
| 住院时间延长 | 并发症↑、费用↑ |
| 死亡率↑ | 严重营养不良是死亡独立预测因素 |

## 五、营养支持五阶梯

**提出者：** 石汉平教授。把营养支持按"创伤从小到大、依赖程度从低到高"分为五级，治疗原则是"**首选低阶梯，逐级上升；能下则下**"。

```
第五阶梯：全肠外营养 TPN
第四阶梯：部分肠内 + 部分肠外（SPN/PPN）
第三阶梯：全肠内营养 TEN
第二阶梯：饮食 + 口服营养补充 ONS
第一阶梯：饮食 + 营养教育
```

### 各阶梯适应症与具体操作

| 阶梯 | 内容 | 适应症 | 具体操作 |
|------|------|--------|---------|
| 第一阶梯 | 饮食 + 营养教育 | 营养状况基本正常、轻度风险、可经口进食 | 膳食指导、食物强化（加蛋白/能量）、少食多餐、营养素补充 |
| 第二阶梯 | 饮食 + ONS | 经口进食不足（<60%需求）、营养不良风险、慢性消耗 | 3正餐 + 3次ONS（3+3）；每次200~250ml；目标补足400~600kcal/日 |
| 第三阶梯 | 全肠内营养 TEN | 无法经口/经口不足且胃肠道功能可利用 | 鼻胃/鼻肠管、PEG/PEJ，管饲全营养制剂，泵或重力输注 |
| 第四阶梯 | 肠内 + 肠外（SPN） | 单纯EN不足（EN满足不了60%需求）；EN禁忌且需部分支持 | 以EN为主，不足部分用PN补充（渐进式补充） |
| 第五阶梯 | 全肠外营养 TPN | 肠道功能不可用/EN禁忌（肠梗阻、严重肠缺血、高流量肠瘘等） | 全合一（AIO）经中心/外周静脉输注 |

### 升降阶梯原则（60% 与 50%）

| 方向 | 原则 | 解释 |
|------|------|------|
| **升阶梯** | 当前阶梯满足不了 **60%** 目标需求，持续 **3~5天** → 上升到上一级 | 例：吃+ONS只够50%需求，3天后仍不够 → 上TEN |
| **降阶梯** | 下一阶梯能满足 **≥50%** 目标需求 → 逐步下移 | 例：EN恢复后能经口吃够一半 → 从TEN降到ONS |
| **前提** | 任何升降都要先评估胃肠道功能与耐受 | 肠道可用优先肠内 |

> 💡 记忆：**升阶梯看"60%"，降阶梯看"50%"**。60%是"不够，要升级"的红线；50%是"够了，可以下移"的底线。

### 为什么"能肠内不肠外"

| 维度 | 肠内营养（EN） | 肠外营养（PN） |
|------|--------------|--------------|
| 肠道屏障 | 维持肠黏膜完整性 | 肠道"闲置"，屏障受损、菌群移位 |
| 生理途径 | 符合生理消化吸收 | 绕过消化道，非生理 |
| 费用 | 低 | 高 |
| 并发症 | 主要为胃肠道/机械 | 导管感染、代谢紊乱风险更高 |
| 适用 | 肠道可用者首选 | 肠道不可用者才用 |

## 六、口服营养补充（ONS）

### 1. 定义与价值

**ONS（Oral Nutritional Supplements）：** 经口摄入的特殊医学用途全营养/组件配方，作为日常膳食之外的补充，用于改善营养摄入。**是门诊、家庭、出院后最常用的营养支持形式。**

**优势：**

| 优势 | 说明 |
|------|------|
| 无创、安全 | 不需要置管，患者接受度高 |
| 灵活 | 可居家、可门诊、可病房 |
| 证据充分 | 老年肌少、肿瘤、围手术期等均证实降低并发症 |

### 2. 制剂类型表

| 类型 | 能量密度 | 蛋白特点 | 适用人群 |
|------|---------|---------|---------|
| 标准全营养型 | 1.0 kcal/ml | 蛋白约15%能量 | 多数营养不良人群，基础选择 |
| 高能量型 | 1.5 kcal/ml（1.3~2.4） | 同比例提高 | 摄入量受限、需控液体量者（心衰、肾衰） |
| 高蛋白型 | 1.0~1.5 kcal/ml | 蛋白≥20%能量（≥10g/100ml） | 创伤/手术恢复、肌少症、肿瘤恶病质 |
| 糖尿病型 | 缓释碳水 | 高单不饱和脂肪酸、低GI | 糖尿病、血糖波动者 |
| 肾病型 | 低蛋白/专用氨基酸 | 必需氨基酸为主 | 慢性肾病（尤其未透析） |
| 肝病型 | 高支链氨基酸BCAA | 高BCAA、低芳香族氨基酸 | 肝硬化、肝性脑病 |
| 肺病型 | 低碳水、高脂肪 | — | COPD、呼吸衰竭（降低CO₂产生） |
| 短肽/氨基酸型 | 预消化 | 水解蛋白/单体氨基酸 | 消化吸收功能受损（胰腺炎恢复期、短肠） |
| 纤维型 | 含膳食纤维 | 可溶性纤维 | 便秘/腹泻、肠内菌群调节 |
| 免疫营养型 | 含n-3、精氨酸、谷氨酰胺、核苷酸 | — | 大手术、重症（围术期/ICU特定阶段） |

### 3. 用法（3+3 模式）

**标准用法：**

```
3顿正餐 + 3次ONS（餐间2次 + 睡前1次）
每次 200~250 ml
每日目标补充 400~600 kcal（ESPEN对营养不良者建议）
```

| 时间 | 安排 |
|------|------|
| 早餐后 | ONS 200~250ml |
| 午餐后 | ONS 200~250ml |
| 下午/睡前 | ONS 200~250ml |
| 正餐 | 尽量保证，不因ONS减少正餐 |

**要点：**
- 小口慢饮（10~15分钟内喝完），避免整瓶灌入引起腹泻/腹胀
- 冰箱取出可稍放至室温或微温（不超过40℃，避免蛋白变性）
- 与药物间隔至少1~2小时
- 依从性差时：换口味、换制剂、分次喝、加调味

### 4. 适用人群

| 人群 | 理由 |
|------|------|
| 老年人食欲差/体重下降 | 摄入不足常见，ONS纠正简单 |
| 肿瘤患者 | **荷瘤患者终身ONS推荐**（ESPEN） |
| 术后恢复期 | 高代谢需求，经口不足 |
| 慢性消耗性疾病 | 慢阻肺、慢性心衰、透析 |
| 肌少症 | 高蛋白型尤其适合 |
| 吞咽功能尚可但进食量少者 | 全营养型补充 |

> ⚠️ 禁忌/谨慎：完全肠梗阻、严重吞咽困难（需评估误吸）、对成分过敏者。吞咽障碍者需评估能否安全口服。

## 七、肠内营养（EN）

### 1. 定义与适应证

**肠内营养（Enteral Nutrition）：** 经胃肠道提供营养素的方式，包括口服（ONS）和管饲。**只要肠道有功能，就应优先使用肠内营养。**

**适应证：**
- 经口进食不足/不能（<60%需求持续3~5天）
- 高代谢需求（创伤、烧伤、感染、大手术后）
- 神经性吞咽障碍（卒中、脑外伤）
- 意识障碍/昏迷
- 消化道疾病（炎性肠病、短肠综合征恢复期、胰腺炎恢复期）
- 术前营养支持

### 2. 途径选择

| 途径 | 时长 | 说明 | 适用 |
|------|------|------|------|
| 鼻胃管（NG） | <3~4周 | 最常用，操作简单；反流误吸风险相对高 | 短期，胃功能正常 |
| 鼻肠管（幽门后） | 短期 | 通过幽门至十二指肠/空肠，防反流误吸 | 高误吸风险、胃瘫、重症胰腺炎 |
| 胃造口（PEG） | >4周 | 内镜下置入，舒适、美观 | 长期管饲（吞咽障碍、肿瘤） |
| 空肠造口（PEJ） | >4周 | 经皮或手术置入空肠，绕过胃 | 胃功能障碍、上消化道梗阻 |

**途径选择原则：**
```
预计管饲 <4周 → 首选鼻胃管；有误吸风险 → 幽门后（鼻肠管）
预计管饲 >4周 → 考虑造口（PEG/PEJ）
胃可用 → 胃途径；胃瘫/反流 → 空肠途径
```

### 3. 制剂分类

| 类型 | 氮源 | 特点 | 适用 |
|------|------|------|------|
| 整蛋白型 | 完整蛋白质 | 渗透压接近等渗，口感好 | 胃肠消化功能正常 |
| 短肽型 | 水解蛋白（肽） | 预消化、易吸收、低致敏 | 消化功能受损（胰腺炎、炎性肠病） |
| 氨基酸型 | 单体氨基酸 | 无渣、极低致敏 | 严重消化吸收障碍（短肠、克罗恩急性期） |
| 疾病专用型 | 疾病调整 | 糖尿病/肾病/肝病/肺病/肿瘤专用 | 相应疾病伴营养问题 |
| 组件制剂 | 单一营养素 | 蛋白/脂肪/碳水/纤维单组件 | 配方调整、目标补充 |

### 4. 输注方式与速度

| 方式 | 特点 | 起始速度 |
|------|------|---------|
| 一次性推注 | 简便，胃肠道刺激大 | 200~400ml/次，每日4~6次 |
| 间歇性重力滴注 | 每4~6小时滴注一次 | 起始慢，逐步加快 |
| 连续性泵输注 | 最平稳，最易耐受 | 起始 20~40 ml/h → 每8~12h增加20ml/h → 目标 80~125 ml/h |

**原则：** 从低浓度、低速度、小剂量开始，逐步加量（"循序渐进"），观察耐受性。

### 5. 禁忌症

| 禁忌症 | 说明 |
|--------|------|
| 完全性肠梗阻 | 肠道不通 |
| 严重麻痹性肠梗阻 | 肠蠕动丧失 |
| 严重消化道出血 | 需禁食观察 |
| 顽固性呕吐 | 不能耐受 |
| 严重急性腹泻 | 大量腹泻时暂停 |
| 腹膜炎/腹腔严重感染 | 需外科处理 |
| 急性胰腺炎重症期（早期高脂） | 早期可能需要短时禁食/PN过渡 |
| AGI（急性胃肠损伤）Ⅳ级 | 肠道完全衰竭 |

### 6. 并发症及处理

| 类别 | 并发症 | 原因 | 处理 |
|------|--------|------|------|
| 胃肠道 | 腹泻（最常见） | 输注过快、渗透压高、制剂污染、抗生素相关、低蛋白 | 减慢速度、稀释、换短肽/纤维型、检查感染、止泻药辅助 |
| 胃肠道 | 腹胀/恶心呕吐 | 输注过快、胃排空差、体位不当 | 减慢、抬高床头30~45°、促胃动力药、改幽门后 |
| 胃肠道 | 便秘 | 液体不足、纤维不足、活动少 | 补液、加可溶纤维、适度活动 |
| 机械性 | 堵管 | 制剂附着、给药未冲管 | 定期温开水冲管、用专用通管刷/酶液 |
| 机械性 | 导管移位/脱出 | 固定不当、患者躁动 | 妥善固定、约束/安抚、复位后X线确认 |
| 代谢性 | 高血糖 | 输注过快、制剂糖高、应激 | 控速、换糖尿病型、血糖监测、必要时胰岛素 |
| 感染性 | 吸入性肺炎 | 反流误吸 | 抬高床头、幽门后置管、评估胃残余量 |
| 感染性 | 制剂污染 | 配置/保存不当 | 现配现用、<4℃保存≤24h、无菌操作 |

**预防是关键：** 床头抬高30~45°、定期冲管、控制输注速度、监测耐受。

## 八、肠外营养（PN）

### 1. 定义与适应症

**肠外营养（Parenteral Nutrition）：** 经静脉途径提供营养素。**只在肠道不可用或不足时使用**（"肠道可用时绝不首选"）。

**适应症（"肠功能衰竭"场景）：**

| 适应症 | 说明 |
|--------|------|
| 短肠综合征 | 术后残留小肠不足 |
| 高流量肠瘘 | 营养从瘘口流失 |
| 肠缺血/肠梗阻（完全性） | 肠道无法使用 |
| 腹腔间隔室综合征 | 腹压升高致肠功能衰竭 |
| 严重吸收障碍 | 顽固性腹泻、放射性肠炎 |
| 严重胰腺炎重症期（早期） | 肠道刺激禁忌期 |
| 严重营养不良术前（肠道不耐受） | 无法经肠内支持 |
| 放化疗严重黏膜炎 | 无法经口/肠内 |

### 2. 途径

| 途径 | 时长 | 渗透压限制 | 说明 |
|------|------|-----------|------|
| 外周静脉（PPN） | ≤7~10天 | ≤900 mOsm/L | 需低渗透配方，易静脉炎 |
| 中心静脉（CVC/PICC） | >2周 | 可高渗（可达1800~2000 mOsm/L） | 全合一常规途径 |
| 输液港（PORT） | >4周/长期 | 可高渗 | 长期家庭PN首选 |

> ⚠️ 高渗配方必须经中心静脉，否则静脉炎风险极高。输注时严格无菌、定期评估导管。

### 3. 全合一（AIO/Three-in-One）配方

**"全合一"= 葡萄糖 + 氨基酸 + 脂肪乳 + 电解质 + 微量元素 + 维生素 + 水，装在同一袋中经同一静脉输注。**

| 组分 | 参考量 | 说明 |
|------|--------|------|
| 能量总量 | 25~30 kcal/(kg·d)（稳定期） | 危重急性期可允许性低热卡 |
| 葡萄糖 | 供能50%~60% | 最大输注速度≤5mg/(kg·min) |
| 脂肪乳 | 供能25%~35% | 成人最大1~1.5 g/(kg·d)；n-3/橄榄油/鱼油制剂可选 |
| 氨基酸 | 蛋白质0.8~1.5 g/(kg·d)（稳定期）；危重1.2~2.0 | 不足会致蛋白分解 |
| 电解质 | 钠钾钙镁磷按需 | 尤其监测磷钾镁 |
| 微量元素 | 锌铜锰硒铬等 | 常规添加 |
| 维生素 | 水溶+脂溶 | 长期PN必须补充 |
| 液体量 | 按出入量平衡 | 心肾患者限制 |

**输注方式：** 持续24h泵注 或 循环输注（如夜间10~12h，白天活动）。

### 4. 并发症及处理

| 类别 | 并发症 | 原因 | 处理 |
|------|--------|------|------|
| 导管相关 | 导管相关性血流感染（CRBSI） | 无菌操作不严、长期留置 | 严格无菌置管与维护、疑感染即拔管+培养 |
| 导管相关 | 血栓/堵管 | 高渗刺激、导管留置 | 规范冲管、抗凝评估、处理导管 |
| 代谢 | **高血糖（最常见代谢并发症）** | 糖输注过快、应激、糖尿病 | 控速、血糖监测、胰岛素、降糖配方 |
| 代谢 | 低血糖 | 突然停药、胰岛素过量 | 逐步减停PN、监测血糖 |
| 代谢 | 高脂血症 | 脂肪乳过量、清除障碍 | 查血脂、减量或停脂 |
| 代谢 | 电解质紊乱 | 配方不当、再喂养 | 常规监测、及时调整 |
| 肝脏 | 肝功能异常/胆汁淤积 | 长期PN、缺乏肠内刺激 | 尽早恢复EN、循环输注、鱼油脂肪乳 |
| 代谢性骨病 | 骨量减少 | 长期PN钙磷维D异常 | 监测骨密度、补钙磷维D |
| 其他 | 再喂养综合征 | 严重营养不良者起始过猛 | 见下一章，预防优先 |

**PN监测频率（方向性）：**

| 阶段 | 监测 |
|------|------|
| 起始期（第1周） | 每日：血糖、电解质（含磷钾镁）、体重、出入量 |
| 稳定期 | 每周：肝功能、血脂、电解质、营养指标（白蛋白/前白蛋白） |

### 5. 关键提醒

- **能肠内尽早肠内：** 即使PN中，也要每天评估能否加EN（哪怕少量，保护肠道）。
- **不要"过度喂养"：** PN起始从偏低能量开始，逐步达标，尤其严重营养不良者。
- **糖脂比：** 避免单糖过多（高血糖、肝脂肪变），保证必需脂肪酸。

## 九、再喂养综合征（预防优先）

### 1. 什么是再喂养综合征

**再喂养综合征（Refeeding Syndrome）：** 长期饥饿/严重营养不良者，重新开始营养支持后，因**胰岛素分泌骤增、电解质向细胞内转移**，出现**低磷、低钾、低镁**及水钠潴留、维生素B1缺乏等严重代谢紊乱，可致心律失常、呼吸衰竭甚至死亡。

**发病时机：** 重新进食后 **48~72小时** 内最危险。

### 2. 高危人群

| 高危因素 | 说明 |
|---------|------|
| 长期饥饿/禁食 | >7~10天摄入极少 |
| 严重体重下降 | 3~6月内下降 >10%~15% |
| 慢性消耗 | 慢性酒精中毒、神经性厌食、肿瘤恶病质 |
| 长期静脉输液（无营养） | 低能量支持后 |
| 电解质已异常 | 起始前已低磷钾镁 |
| 老年/极度消瘦 | BMI <16~18.5 |

### 3. 机制（用一句话讲清楚）

```
重新进食 → 血糖↑ → 胰岛素↑ → 磷钾镁"冲进"细胞内
→ 血磷/钾/镁骤降 + 维生素B1耗竭 → 心衰、心律失常、神经症状
```

### 4. 预防与处理流程

| 步骤 | 措施 |
|------|------|
| 识别 | 评估高危因素（见上表） |
| 起始能量 | **从 10~15 kcal/(kg·d) 开始**（严重者从更低），每4~7天逐步增加 |
| 先补微量 | 起始前/同时**补维生素B1（硫胺素）≥100mg/日**（预防韦尼克脑病） |
| 补充电解质 | 监测并补充**磷、钾、镁**（及时纠正） |
| 蛋白 | 起始蛋白不宜过高，逐步增加 |
| 液体 | 控制液体量，防水肿（心衰风险） |
| 监测 | 起始1周每日：电解质、血糖、生命体征、出入量、体重 |
| 节奏 | "慢启动、慢加量"——饿得越久，越要慢慢喂 |

**再喂养综合征处理要点表：**

| 电解质 | 危险低值 | 处理方向 |
|--------|---------|---------|
| 血磷 | <0.65 mmol/L | 口服/静脉补磷，密切监测 |
| 血钾 | <3.5 mmol/L | 补钾，心电监护 |
| 血镁 | <0.75 mmol/L | 补镁（低镁可致低钾难纠正） |

> 💡 一句话记忆：**"先补B1，低能量起步，盯紧磷钾镁，慢慢加量。"** 饿坏了的人不能猛补。

## 十、围手术期营养（ERAS理念）

### 1. ERAS 简介

**ERAS（Enhanced Recovery After Surgery，加速康复外科）：** 以循证为基础的围手术期综合管理方案，营养是其中核心环节。目标：减少应激、促进恢复、缩短住院。

### 2. 术前营养（评估与支持）

**术前营养风险筛查：** 所有择期手术患者术前都应筛查（NRS-2002）。

**术前营养支持指征（满足任一即应考虑术前支持7~14天）：**

| 指征 | 界值 |
|------|------|
| 体重下降 | 近6个月 >10%（或近3个月 >5%） |
| BMI | <18.5 |
| NRS-2002评分 | ≥5分 |
| 血清白蛋白 | <30 g/L |
| 摄入不足 | 经口/ONS无法满足需求 |

**术前营养支持方式：** 首选经口/ONS；不足则EN；肠道不可用才PN。一般 **7~14天**，使营养状态改善后再手术。

**术前禁食新观念（告别"隔夜禁食"）：**

| 内容 | 传统 | ERAS现行推荐 |
|------|------|-------------|
| 固体食物 | 术前12h禁食 | 术前6h禁固体 |
| 清流质 | 术前6h禁水 | 术前2h可喝清流质 |
| 碳水化合物负荷 | 常规禁食 | **术前2~3h 喝含碳水饮料（约400ml 12.5%碳水），减胰岛素抵抗** |

> 💡 术前2~3小时喝碳水饮料能减轻术后胰岛素抵抗、减少蛋白质分解，是ERAS标志性措施。糖尿病/胃排空障碍者需个体化。

### 3. 术后营养（早期恢复）

| 项目 | 推荐 | 理由 |
|------|------|------|
| 进食时机 | **术后24h内尽早经口进食/EN**（无禁忌时） | 促进肠道蠕动、降感染、加速愈合 |
| 术后蛋白质 | ≥1.2~1.5 g/(kg·d) | 支持组织修复 |
| 能量 | 25~30 kcal/(kg·d) | 术后分解期需求↑ |
| 咀嚼/吞咽评估 | 颌面/颈部手术需评估 | 防误吸 |
| 途径 | 首选经口→ONS→EN；PN仅限肠道不可用 | 能肠内不肠外 |
| 血糖 | 控制在 6~10 mmol/L | 高血糖增加感染 |

**常见术后营养问题与对策：**

| 问题 | 对策 |
|------|------|
| 恶心呕吐 | 少量多餐、避开油腻、止吐药 |
| 腹胀便秘 | 缓泻/可溶纤维、适度活动、咀嚼充分 |
| 食欲差 | ONS补充、口味多样化、家人陪伴进食 |
| 体重不升 | 复查营养评估、加ONS/EN、排查吸收问题 |

## 十一、临床营养特殊场景速查

### 1. 危重症（ICU）

**原则：** 尽早启动EN，允许性低热卡，蛋白质优先保证，监测再喂养。

| 项目 | 建议 | 依据/说明 |
|------|------|----------|
| 启动时机 | 入院/入ICU后 **48h内** 启动EN（无禁忌） | 越早越获益 |
| 能量（急性期） | 允许性低热卡 **20~25 kcal/(kg·d)** | 避免过度喂养加重代谢负担 |
| 能量（恢复期） | 25~30 kcal/(kg·d) | 按监测调整 |
| 蛋白质 | **1.2~2.0 g/(kg·d)** | 创伤/烧伤更高（2.0~2.5） |
| 途径 | 首选EN；EN不足（<60%需求3~5天）→ 补充PN | 渐进式SPN |
| 血糖 | 控制 **7.8~10 mmol/L**（宽松目标） | 严格低血糖目标获益有限且低血糖风险↑ |
| 特殊患者 | ARDS/严重呼衰可考虑低碳水高脂、免疫营养 | 降低CO₂产生 |
| 再喂养 | 长期饥饿者从低能量起步，防再喂养综合征 | 见第九章 |

**要点：** 危重患者"喂对时机、喂对量"比"喂很多"更重要；**允许性低热卡 ≠ 长期低热卡**，度过急性期要逐步达标。

### 2. 肿瘤营养

**肿瘤营养不良高发：** 约30%~80%肿瘤患者存在营养不良；恶病质是死亡常见原因之一。营养治疗能改善生活质量、提高治疗耐受。

**"五大原则"（石汉平）：**

```
① 癌性恶病质：及早预防
② 营养筛查：确诊即筛查（所有肿瘤患者）
③ 三级诊断：营养筛查 → 营养评估 → 综合测定
④ 五阶梯治疗：教育→ONS→EN→SPN→TPN
⑤ 代谢调节：n-3脂肪酸、运动、药物等综合干预
```

**肿瘤恶病质要点：**

| 项目 | 建议 |
|------|------|
| 蛋白质 | **1.5~2.0 g/(kg·d)**（高于普通人群） |
| n-3多不饱和脂肪酸 | EPA ≥1.5~2.0 g/日（抗炎、保肌肉） |
| 能量 | 25~30 kcal/(kg·d)，不盲目"少吃饭饿死肿瘤" |
| 运动 | 阻力运动（抗肌肉流失）+有氧 |
| ONS | **荷瘤患者终身ONS推荐**（ESPEN） |
| 放化疗期间 | 黏膜炎/恶心时：ONS、EN（必要时PN过渡） |

> ⚠️ 必须纠正的误区：**"不吃饭饿死癌细胞"是错的**——会先饿死自己，肿瘤照长。营养支持与抗肿瘤治疗并行不悖。

### 3. 肝病营养

**核心问题：** 肝硬化患者普遍存在营养不良（肝糖原储备差、分解代谢↑、摄食减少），营养不良是预后不良因素。

| 项目 | 建议 |
|------|------|
| 能量 | **30~35 kcal/(kg·d)**（常高于普通患者） |
| 蛋白质 | 1.2~1.5 g/(kg·d)；**肝硬化合并肝性脑病不主张严格限蛋白** |
| 肝性脑病 | 加用**支链氨基酸BCAA**制剂；植物蛋白优于动物蛋白（新观点） |
| 脂肪 | 可加中链甘油三酯MCT（吸收不依赖胆盐） |
| 钠 | 限钠（腹水/水肿时 <2g/日） |
| 维生素 | 补充脂溶性维生素（A/D/E/K）、锌、B族 |
| 进餐 | 少量多餐、夜间加餐（缩短空腹时间，减少蛋白分解） |

**关键观念转变：** 传统"肝病要少吃蛋白"已被更新——**对无肝性脑病者，蛋白质摄入充足更重要**；即使有肝性脑病，也应保证蛋白并联合BCAA，而不是禁蛋白。

### 4. 肾病营养（慢性肾脏病 CKD）

**原则：** 在保证能量充足的前提下，按分期控制蛋白质、钠、钾、磷、液体。

| 分期/状态 | 蛋白质建议 | 要点 |
|-----------|-----------|------|
| CKD 3~5期（未透析） | **0.6~0.8 g/(kg·d)** 低蛋白饮食（可配合复方α-酮酸） | 优质蛋白占≥50% |
| 血液透析 | **1.0~1.2 g/(kg·d)** | 透析丢失氨基酸 |
| 腹膜透析 | **1.2~1.5 g/(kg·d)** | 腹膜丢失蛋白更多 |

| 营养素 | 注意 |
|--------|------|
| 能量 | 25~35 kcal/(kg·d)（标准体重），充足能量才能让低蛋白"省蛋白" |
| 钠 | <2g/日（控血压、控水） |
| 钾 | 高钾血症者限制（香蕉、橘子、深色蔬菜、土豆等） |
| 磷 | CKD3~4期 <800mg/日；CKD5期 <1000mg/日；磷结合剂 |
| 液体 | 水肿/少尿者限制（尿量+500ml） |
| 复方α-酮酸 | 配合极低蛋白饮食时使用，提供必需氨基酸骨架 |

> ⚠️ 肾病营养个体差异极大，**必须由肾内科+营养师共同制定**，蛋白限制不能一刀切（营养不良风险同样致命）。

### 5. 呼吸系统疾病（COPD/呼吸衰竭）

**核心问题：** 慢阻肺患者能量消耗高、体重下降常见（"肺恶病质"）；高碳水会增加CO₂产生，加重通气负担。

| 项目 | 建议 |
|------|------|
| 能量 | **30~35 kcal/(kg·d)**（或按Harris-Benedict×应激系数） |
| 蛋白质 | **1.2~1.5 g/(kg·d)** |
| 碳水化合物 | 降低占比（约40%~45%），避免高碳水（呼吸商↑→CO₂↑） |
| 脂肪 | 提高占比（约35%~40%），供能效率高、CO₂产生少 |
| 进餐 | 少量多餐，避免餐后腹胀影响膈肌活动 |
| 补充 | 维生素D、n-3脂肪酸、抗氧化营养素 |
| 机械通气 | 目标能量需结合呼吸状态评估（通气参数影响代谢） |

> 💡 记法：**"肺病吃油不吃糖"**——低碳水高脂肪降低CO₂产生，减轻呼吸负担。但需注意脂肪乳输注速度（过快影响氧合）。

## 十二、出院后家庭营养（HEN/HPN）

### 1. 概念

**家庭营养支持（Home Nutrition Support）：** 患者出院后在家中继续接受营养支持，分为 **家庭肠内营养（HEN）** 和 **家庭肠外营养（HPN）**。适应症：出院后仍需营养支持且家庭条件允许。

### 2. 适合哪些人

| 场景 | 营养支持形式 |
|------|-------------|
| 吞咽障碍（卒中、头颈肿瘤术后） | HEN（PEG长期管饲） |
| 短肠综合征稳定期 | HPN（长期）或 HEN |
| 肿瘤恶病质 | ONS（家庭自我管理） |
| 慢病消耗（COPD/心衰/肾衰） | ONS |
| 神经退行性疾病 | HEN |

### 3. 出院前准备（关键步骤）

```
① 全面评估：营养方案、家庭照护者、经济、可及性
② 确定方案：制剂、途径、输注计划、目标量
③ 培训照护者：冲管、给药、输注、体位、识别并发症
④ 备齐物资：制剂、输注泵、耗材
⑤ 制定随访计划：预约复诊、营养科随访
⑥ 应急预案：堵管、发热、腹泻怎么办，联系谁
```

### 4. 随访监测指标

| 周期 | 监测内容 |
|------|---------|
| 每周（早期） | 体重、摄入量、耐受性、体温 |
| 每月 | 体重趋势、白蛋白/前白蛋白、电解质、肝功能（PN） |
| 每3个月 | 全面营养评估、生活质量、并发症筛查 |
| 定期 | 导管评估（PN）、口腔/吞咽评估（HEN） |

**家庭营养"报警信号"（需及时就医）：**

| 症状 | 可能 |
|------|------|
| 发热、寒战 | 导管感染（HPN）/吸入性肺炎（HEN） |
| 堵管 | 导管堵塞（可先用温水/酶液通管） |
| 腹泻>3天 | 制剂不耐受/感染 |
| 呕吐、腹胀持续 | 胃排空障碍、梗阻 |
| 体重持续下降 | 方案不足，需调整 |

### 5. 依从性与心理支持

- 家庭营养是长期治疗，患者和家属易疲惫，需要**定期心理支持、同伴支持**
- 让"营养治疗"成为日常习惯：固定时间、简化操作、家属分工
- 定期回顾目标：能否减量？能否经口进食更多？**能降阶梯就降阶梯**

| 价值 | 说明 |
