### 1️⃣ 🧩 10分钟OPP — 算账式展示安利事业机会

> **一句话**：用10分钟，把安利的收入逻辑算得明明白白。

| 条目 | 内容 |
|------|------|
| **源文件** | [[../../03-Resources（参考素材资料）/02-创业/10分钟OPP（电脑版）.md\|10分钟OPP（原文件）]] |
| **已建知识卡片** | [[../知识卡片/KC-安利-006-10分钟OPP：算账式展示安利事业机会\|KC-安利-006 10分钟OPP]] |
| **核心逻辑** | 1个市场（75元/月）→ 7个市场（26,250元/月）→ 3个达标市场（~50万/年）→ 6个达标市场（~100万/年） |
| **对我的意义** | 这是跟任何人讲安利事业机会的"开场白" — 必须烂熟于心、脱口而出 |

**关键数据一表通：**
```
个人市场  →  1个 (2,500元 / 200分)   →  月收入 75元
          →  3个 (12,500元 / 1,000分) →  月收入 1,125元
          →  7个 (125,000元 / 10,000分) →  月收入 26,250元

达标市场  →  3个 →  年收入 ~50万（营销经理级）
          →  6个 →  年收入 ~100万（高级营销经理/钻石级）
```

**📊 销售指数分数速查（1分 = 12.5元）：**
```
营业额（元）     │  销售指数（分）
     2,500      │       200分
     7,500      │       600分
    12,500      │     1,000分
    25,000      │     2,000分
    50,000      │     4,000分
    87,500      │     7,000分
   125,000      │    10,000分（= 1万分 ✅ 达标线）
```
> 💡 **以后对业绩统一讲"分"**：比如"我这个月做了2,000分" = 25,000元营业额；"部门冲万分" = 冲125,000元达标。

### 2️⃣ 📊 安利奖励制度深度解析 — 管道的底层设计

> **一句话**：安利不是卖产品赚钱，而是**建立资产（管道）** — 鼓励分享、奖励复制、保障世袭。

| 条目 | 内容 |
|------|------|
| **源文件** | [[../../03-Resources（参考素材资料）/02-创业/安利奖励制度深度解析.md\|安利奖励制度深度解析（原文件）]] |
| **已建知识卡片** | [[../知识卡片/KC-安利-005-安利奖励制度解析：管道资产与助人自助\|KC-安利-005 安利奖励制度解析]] |
| **涵盖内容** | 大健康背景 → 业绩奖金表 → 三大奖金（个人/市场开拓/6%领导奖）→ 奖衔体系 → 五大价值 → 人生规划 |
| **对我的意义** | 这是你做短视频、讲 OPP、带伙伴的**内容弹药库** — 每条都能挖出选题 |

**五大核心价值速览：**
```
① 自己的事业  — 收入只取决于你的业绩，不受推荐人影响
② 公平可超越  — 努力决定收入，后加入可以超越领导人
③ 助人自助    — 你帮的人越多，你赚得越多（正和游戏）
④ 保障世袭    — 6%领导奖 = 不做也有 + 可以继承
⑤ 大事业无上限 — 可以无限复制，像麦当劳开3万家店
```

### 3️⃣ 🚀 奖衔阶梯 — 从起点到 FC 的里程碑

```
营销助理 ── 单月达成12.5万（10,000分 / 万分）
    ↓
营销主任 ── 三个月达成12.5万（10,000分 / 万分）
    ↓
高级营销主任(DD) ── 六个月达成12.5万（10,000分 / 万分） ← 第一个里程碑
    ↓
营销经理 ── 3个DD市场（3×万分达标）→ 年收入 ~50万
    ↓
高级营销经理 ── 6个DD市场（6×万分达标）→ 年收入 ~100万
    ↓
营销总监 ── 更多市场
    ↓
FC 皇冠大使 ── 最高奖衔 → 年收入 800~1,000万
                 └─ 全球分红 + 股东权益
```
