## 一、新人起步心法 — 四个确定

### ① 确定大健康行业

```
国策背景：
- 健康中国2035目标：人均预期寿命80岁以上
- 2030年大健康产业规模预计达29.1万亿
- "健康是1，其他都是后面的0"
```

> 带新人第一步：帮TA看清趋势，建立行业信心。

### ② 确定是安利

安利的企业文化（三本书拆成三句话）：
- **决定一个人的成功，不是赢了多少人，而是帮了多少人**
- **拥有自己的事业，即拥有改变人生的机会**
- **人类需要从植物中获取营养，而不是从药瓶中**

> 带新人第二步：不只是推销产品，而是传递价值观。

### ③ 确定你想要的结果

```
目标阶梯：
┌─ 先做0-1：帮助10个家庭获得健康 → 月收入4000
├─ 再做1-4：1万分 → 月收入1.5w → 年收入40~50w
└─ 复制4×4：年收入超100w → 被动收入
```

> 带新人第三步：帮TA设定清晰可量化的目标。

### ④ 定位与能量

| 维度 | 核心心法 |
|------|---------|
| **你是BOSS** | 清晰的定位——你不是打工者，你是创业者 |
| **能量** | 高能量吸引人，低能量怎么伪装都没用 |
| **能量来源** | ①文化自信 ②种好种子 ③上不封顶的成长 |
| **发心** | 爱在前，利在后——消费的本质是悦己，创业的本质是助人 |
| **连接** | 把"你和我"变成"我们" |

> 带新人第四步：帮TA找到内在驱动力，建立创业者心态。

## 二、四大连接 — 驱动团队成长

```
① 人与人的连接
   → 用朋友圈展示切换人设（从消费者→分享者→创业者）

② 人与知识的连接
   → 学习营养知识、产品知识、创业方法

③ 人与解决方案的连接
   → 帮人解决健康问题、财富问题

④ 人与事业机会的连接
   → 让对的人看到安利的机会
```

### 关键动作

- **筛选对的人**：把时间放在对的人和对的事情上
- **KOC行为**：动机缘于欲望，要具备点燃的意识
- **说到做到、拿到结果，才有力量**
- **自用+改变+分享**（朋友圈、视频号）

## 三、一人公司三阶段 — 可复制给伙伴的成长路径

```
1.0 个人IP闭环：
   流量 → 运营 → 产品/服务 → 收现
   （先跑通最小闭环）

2.0 赛道叠加：
   在1.0基础上扩品类、扩人群、扩商业模式

3.0 系统化：
   AI工作流 + 自营生态 → 结构性优势
```

### 核心认知（可用来辅导伙伴）

**① 商业度量=概率×效率**
- 先抬胜率（选对人群、选对内容）
- 再降成本（流程化、模板化、AI化）
- 先收现、稳现金流

**② 项目打分模型（100分）**
| 维度 | 分值 | 检查项 |
|------|------|--------|
| 流量 | 30 | 触达面/点击率/进线率 |
| 运营 | 30 | 私域沉淀/活跃留存/复购转介绍 |
| 产品/服务 | 30 | 口碑/毛利与交付成本/标准化 |
| 主观判断 | 10 | 风险可控/心力与时间匹配 |

- ≥85分 → 加码
- 70-84分 → 小步快跑
- <70分 → 不做或止损

**③ 非标 × 高客单 × 复购（业务做大三要素）**
- 非标：可叠加品牌和故事，创造价差
- 高客单：低价客户服务成本高，价值低
- 复购：流量稀缺，复购是核心杠杆

**④ 战略顺序：先放大用户价值，再放大用户数量**
- 顺序错了，所有努力都变成内耗

## 四、带团队的行动框架

### 新人辅导四步法

```
① 确定方向
   → 帮TA看清行业趋势 → 建立信心
   
② 确定平台
   → 传递安利价值观 → 建立认同
   
③ 确定目标
   → 设定可量化的短期目标 → 建立动力
   
④ 确定定位
   → 帮TA找到自己的能量来源 → 建立身份
```

### 团队复制四步法

```
① 自己做 → 拿到结果（说到做到，才有力量）
② 带着做 → 复制方法（标准化可复制）
③ 看着做 → 独立操作（放手让TA干）  
④ 帮TA做 → 复制领导者（让TA也能带人）
```

### 伙伴成长状态诊断

| 阶段 | 特征 | 带法 |
|------|------|------|
| 🟢 萌芽期 | 热情高、不懂 | 手把手教标准动作 |
| 🟡 成长期 | 懂一些、不稳定 | 指导+鼓励，帮TA度过波动 |
| 🔵 成熟期 | 能独立、缺信心 | 多支持，放手让TA做 |
| 🟣 领导者 | 有能力、有信念 | 完全授权，培养TA带人 |
