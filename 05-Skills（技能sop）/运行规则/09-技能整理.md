# 09 · 技能整理 — 新装 skill 自动更新到《自媒体实操zfc》

> **触发**：用户说"新装了 skill / 帮我盘点 skill / 更新 skill 清单 / 整理一下 skill"；或会话中发现某个可用 skill 未登记进 [[01-Projects（进行的项目）/自媒体实操zfc.md]]「二十九、已安装 Skill 清单」。

## 自动触发时机

1. **GitHub 安装流（用户指定 · 2026-08-30）**：用户发 GitHub 仓库链接（skill URL）+ 说"帮我安装" → 安装完成后**立即**跑整理流程（无需再问）。判断依据：消息里有 `github.com` 链接 + 安装意图词（装 / 安装 / install）
2. **用户明说**："新装了个 skill"、"盘点 / 整理 skill"、"更新 skill 清单"
3. **会话启动发现**：系统技能列表出现未登记的新 skill（对比清单就能看出来）
4. **任务中偶遇**：执行写脚本/公众号等任务时，发现正在用的 skill 不在清单里

> ⚠️ **装完即整理**：任何"GitHub 链接 → 安装"的请求，交付时把「已整理进 自媒体实操zfc」作为安装完成的一部分汇报，不用等用户再提醒。

## 执行流程（盘点 → 对比 → 更新 → 归档）

1. **盘点**：`ls ~/.claude/skills/`（全局）+ 项目 `05-Skills（技能sop）/短视频方法库/`（自媒体系技能文件）→ 列出全部 skill
2. **对比**：与 自媒体实操zfc.md「二十九、已安装 Skill 清单」逐项核对 → 找出**新增 / 缺失 / 改名**
3. **更新清单**（外科手术式，只动新增部分）：
   - 新增 skill 写入对应分类：📝内容创作 / 📤多平台发布 / 🛡质量去AI味 / 🔧开发效率 / 🔎全网调研
   - 更新 29.1「总数与分类」计数、二十九节日期戳、29.7 备注（新增 skill + 日期）
4. **重要 skill 写详细章节**：仿「二十八、gbro-cover-design」格式（30秒看懂 / 装在哪&怎么触发 / 工作流程 / 核心规则 / 首次配置），编号顺延（三十、三十一…）
5. **联动**：如 操作系统总控台 / README / 相关规则提到该 skill → 同步更新（可选）
