# 🟠 小红书内容风险检测清单

> **适用范围：** 安利 × 大健康 × 互联网创业类短视频/图文内容
> **依据：** 2026年小红书社区公约2.0 + 三品一械发帖红线 + 最新违禁词词典
> **⚠️ 小红书审核比视频号更严，尤其健康类和导流类。发之前必须过这个清单。**

> **与视频号核心区别：** 视频号红线在"功效虚假宣传"，小红书红线在"无资质不得提产品+不得导流"。前者管你说什么，后者管你是什么身份+往哪引流。

---

## 一、健康功效类（🔴 小红书最高危区，比视频号更严）

小红书2026年核心原则：**非医疗资质者，全面禁止推广任何具体产品**，包括提及产品名称、功效、使用体验。

### ❌ 绝对不能说

| 违规类型 | 典型违规词 | 风险等级 |
|---------|-----------|:-------:|
| **宣称医疗功效** | 治病、治疗、根治、消炎、杀菌、抗癌、降压、降糖、药到病除 | 🔴 封号 |
| **保健品功效宣称** | "吃了XX睡眠变好了""补充XX营养""增强免疫力"——即使是真的，无资质也不准说 | 🔴 封号 |
| **绝对化功效承诺** | 最有效、100%有效、无效退款、零风险、无副作用、永久有效 | 🔴 封号 |
| **减肥/瘦身类** | 减肥、瘦身、溶脂、燃脂、7天瘦X斤、不反弹、瘦脸 | 🔴 封号 |
| **普通食品暗示功效** | 排毒、调理、改善体质、调节内分泌、抗氧化、抗衰老 | 🟠 限流/下架 |
| **护肤品暗示医疗** | 祛痘、消炎、医用级、修复敏感肌、祛疤、脱敏 | 🟠 限流/下架 |
| **制造健康焦虑** | "你的细胞在饿""隐性饥饿""99%的人都不知道""身体在求救" | 🟠 限流 |

### ✅ 安全说法（只做纯科普，不提产品）

```
✓ "肝脏是人体重要的解毒器官……"（可以，不提产品）
✓ "GST酶在肝脏解毒中起到关键作用……"（可以，纯生化科普）
✓ "我的个人习惯是每天早上喝一杯温水……"（可以，个人习惯）
✗ "我每天早上喝一杯XX产品，肝脏好多了……"（不行，提了产品+功效）
```

### 📌 特殊红线：2026年2月新规

**买手/达人不允许在任何场景推广：**
- OTC药品
- 保健食品（含蓝帽子产品）
- 医疗器械
- 医疗及健康服务

违规者**永久关闭直播权限及商品分享功能**。

## 二、导流与私域引流（🔴 小红书最易封号区）

小红书对导流的打击力度远超视频号。**这是安利创业者在小红书上的最大风险点。**

### ❌ 绝对不能说/做

| 违规行为 | 说明 | 风险等级 |
|---------|------|:-------:|
| **留联系方式** | 微信、QQ、手机号、二维码、邮箱——包括谐音（V、卫信、威❤）、emoji、拼音、拆分字 | 🔴 永久封号 |
| **私信引流** | "私信我领资料""后台踢我""看主页"——AI语义识别会判定为导流 | 🟠 限流/警告 |
| **评论区引导** | "想要链接的姐妹私我""评论区扣1"——被判定为交易引导 | 🟠 限流 |
| **包裹塞卡片** | 商品包裹附带微信号小卡片——平台会追溯到账号 | 🔴 永久封号 |
| **主页引流** | 头像/昵称/简介留微信号、邮箱、网址 | 🟠 限流/改资料 |

### ✅ 安全做法
```
✓ 只做内容，不主动引导私信
✓ 简介放"全网同名"（其他平台同名账号自然引流）
✓ 让用户自己搜索你的其他平台
✗ 任何形式的"加我""私我""找我"
```

## 三、极限词与广告法（🟠 限流高发区）

| 违规类别 | 禁用词示例 |
|---------|-----------|
| **最高级** | 最、第一、唯一、顶级、极致、完美、全网第一 |
| **绝对化** | 100%、永久、永不、万能、包治、完全、绝对 |
| **虚假承诺** | 无效退款、一吃见效、三天见效、立刻见效 |
| **行业第一** | 全国第一、行业领先、销量冠军、NO.1 |
| **价格误导** | 全网最低价、白菜价、跳楼价、免费送 |

## 四、内容标注合规

| 场景 | 要求 | 风险 |
|-----|------|:----:|
| **AI生成内容** | 必须勾选"AI辅助创作"标签 | 未标注→限流，多次违规→降权 |
| **品牌合作** | 商业笔记必须标注"本笔记已参与品牌合作" | 未标注→下架/限流 |
| **产品使用体验** | 必须是真实自用，不能虚构体验 | 虚假种草→封号 |
| **搬运/洗稿** | 禁止搬运他人内容、AI洗稿 | 检测到→降权/封号 |

## 五、内容场景专项风险

### 评论区风险（很多人忽略）
| 风险 | 说明 |
|-----|------|
| 评论区有人问"怎么买""多少钱" | 不要回复！回复了也算你的导流行为 |
| 有人评论问功效 | 不要回复功效相关内容 |
| 自己抢沙发引导 | "想知道怎么做的看主页↑"——这也是导流违规 |

**正确做法：** 评论区的产品/价格/购买相关问题一律不回复，或者只回"感谢关注～"

### 直播风险
| 风险点 | 说明 |
|-------|------|
| 口播产品功效 | 同上，无资质不准说功效 |
| 引导加微信 | 直播中说"加微信"会被AI实时识别 |
| 展示二维码 | 画面中出现二维码直接断播 |

## 六、账号安全

| 风险行为 | 后果 |
|---------|:----:|
| 一机多号（同设备切3个以上账号） | 触发风控，封禁率>90% |
| 虚拟号码注册 | 封禁率>90% |
| 频繁修改资料 | 触发人工审核 |
| 被批量举报 | 自动触发平台核查 |

## 📋 出稿前自检流程

每次发小红书前，过这6关：

```
☐ 第一关：健康功效
    ├─ 有没有提具体产品名？              → 有则删
    └─ 有没有暗示功效（哪怕是间接的）？   → 有则改为纯科普

☐ 第二关：导流检查
    ├─ 正文有没有"私我""找我""加我"？    → 有则删
    ├─ 评论区有没有引导？                 → 有则删
    └─ 简介/头像有没有联系方式？          → 有则删

☐ 第三关：极限词检查
    └─ 有没有"最""第一""100%"等绝对化词？→ 有则改为温和表述

☐ 第四关：AI标注
    └─ AI生成内容是否勾选了标签？          → 没勾则勾选

☐ 第五关：品牌合作
    └─ 涉及商业推广是否标注了合作？        → 没标则标注

☐ 第六关：评论区预案
    └─ 如果有人问产品/价格/购买，怎么回？  → 提前想好安全话术
```
