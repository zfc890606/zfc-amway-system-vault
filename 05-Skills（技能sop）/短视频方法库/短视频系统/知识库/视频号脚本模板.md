## 通用风格检查点（所有模板适用）

开始写之前，问自己：
- 这条视频的**嘴替点**是什么？——观众心里说不出口的那句话是什么？
- 情绪**曲线**怎么走？——参考风格系统中的六种情绪曲线
- **自信感**怎么体现？——有没有说一句笃定的结论？

每条脚本写完之后，过一遍 [[视频号脚本风格系统#八、写稿自检清单]]；**涨粉型内容必过「涨粉复核6要素」**：① 零产品 ② 转发对象具体化 ③ 删我测试 ④ 下一集测试 ⑤ 成长弧线 ⑥ ≥2传播原子（见 [[视频号脚本风格系统#✅ 涨粉复核（强制·升级版）]]）。

## 模板一：痛点共鸣型

### 信息
- **时长**：60-90秒
- **对应情绪曲线**：曲线A（扎心→共情→翻转→再扎→给解法→收尾）
- **嘴替重点**：痛点开场必须是观众心里说不出的委屈/挫败
- **自信锚点**：中间"后来我发现了…"这段要笃定

### 结构

```
🎬 【0:00-0:05】 痛点开场
   嘴替法：替他说出心里话
   "你是不是[目标人群]也遇到过这个问题？"
   "你是不是[具体痛点]？"

🎬 【0:05-0:10】 共情
   情绪法：拉近距离，承认自己也踩过坑
   "我以前也是这样的…"
   "其实这不是你的问题…"

🎬 【0:10-0:45】 解决方案（核心干货）
   自信法：用具体案例+对话，不要讲道理
   "后来我用了这个方法…"
   "第一步…第二步…第三步…"
   （确保三点是递进关系，不是并列）

🎬 【0:45-0:55】 [可选] 原因/底层逻辑
   "为什么很多人卡在这？因为…"

🎬 【0:55-1:00】 一句话总结 + CTA
   不要"所以"开头，直接说结论
   "先让自己成为答案，别人自然来找你"
   "你现在卡在哪？评论区告诉我，我帮你分析"
```

## 模板二：方法教学型

### 信息
- **时长**：60-120秒
- **对应情绪曲线**：曲线B（质疑→承认踩坑→发现问题→给方法→收尾）
- **嘴替重点**：开场替他说出错误做法，让他觉得"说的就是我"
- **自信锚点**：全程用"我告诉你""我跟你说个事"开场，自信输出

### 结构

```
🎬 【0:00-0:05】 痛点 + 承诺
   嘴替法：先说出他现在的错误做法
   "你是不是觉得[常见错误做法]？"
   "我告诉你，真正做起来的人根本不是这么干的"

🎬 【0:05-0:10】 快速建立信任
   自信法：用具体结果说话
   "我用了这个方法，[具体成果]"

🎬 【0:10-1:10】 分步教学
   对话法：每一步都用具体场景+对话来呈现，不要干讲
   "第一步（做什么 + 为什么 + 具体例子）"
   "第二步（做什么 + 为什么 + 具体例子）"
   "第三步（做什么 + 为什么 + 具体例子）"

🎬 【1:10-1:20】 总结强调
   "很多人搞错了什么？以为…其实是…"

🎬 【1:20-1:30】 CTA
   "你现在卡在哪一步？评论区告诉我"
   或 "关注我，分享更多有价值的内容"
```

## 模板三：案例见证型

### 信息
- **时长**：90-120秒
- **对应情绪曲线**：曲线E（背景→转折→结果→方法→邀请）
- **嘴替重点**：中间让观众产生"他跟我一样普通"的代入感
- **自信锚点**：结尾"你也可以"要有力量

### 结构

```
🎬 【0:00-0:05】 结果前置
   "我有个伙伴，[具体结果]，他是怎么做到的？"

🎬 【0:05-0:15】 背景介绍
   嘴替法：让观众觉得"这不就是我吗"
   "他原来是做[什么]的，遇到[什么困难]"

🎬 【0:15-0:45】 转折点
   "后来他做了[什么改变]…"

🎬 【0:45-1:15】 具体方法
   自信法：方法要具体，可复制

🎬 【1:15-1:30】 你的角色
   "我帮他做了[什么]…"

🎬 【1:30-1:40】 总结 + CTA
   "所以你也可以。想跟他一样，私信我"
```

## 模板四：认知颠覆型

### 信息
- **时长**：45-60秒
- **对应情绪曲线**：曲线C（抛出问题→打破认知→深入解释→对号入座→结论）
- **嘴替重点**：开头替他说出那个"最怕被问的问题"
- **自信锚点**：认知翻转那一刻要果断有力

### 结构

```
🎬 【0:00-0:03】 颠覆性观点
   嘴替法：替他说出他最想反驳的那个观点
   "你是不是也觉得安利就是卖产品的？"
   "我告诉你，安利真正赚钱的人，都不是在卖产品"

🎬 【0:03-0:10】 制造好奇心
   情绪法：停顿 + 放慢
   "是不是很意外？我告诉你真相…"

🎬 【0:10-0:35】 解释/论证
   自信法：三段递进，不要并列
   "真正做起来的人都在做这三件事…"

🎬 【0:35-0:45】 结论强化
   "所以不要再[错误做法]了"

🎬 【0:45-0:50】 CTA
   "你被问过这个问题吗？评论区聊聊"
```

```
   "其实这个问题背后的原因是什么…"

🎬 【0:10-0:40】 营养方案
   自信法：算账式科普，让他对号入座

🎬 【0:55-1:00】 总结 + CTA
```

## 模板七：Problem→Solution 极简结构（姜胡说式）

> **来源**：[[姜胡说-评论区问题分析]] — 博主原话："问题解决方案，问题解决方案，最后一句总结，完事了"
> **核心原则**：结构越简单，执行越容易。不用花里胡哨的开头，痛点到、方案给、收尾走。

### 信息
- **时长**：45-90秒
- **对应情绪曲线**：无刻意曲线 — 靠"痛点够痛"带情绪，不是靠表演带情绪
- **嘴替重点**：第一句话必须是观众心里正在想的那个问题
- **自信锚点**：方案要笃定，不要说"我觉得""可以试试"，要说"我告诉你"
- **适用场景**：教程类、方法类、答疑类、知识分享类
- **核心记忆**：不要讲道理，直接给方案

### 结构

```
🎬 【0:00-0:05】 痛点直击（嘴替——替他说出心里话）
   不要铺垫，不要"今天给大家分享一个……"
   直接说：
   "你是不是[具体问题]？"
   "你是不是也[具体困境]？"
   "[最怕被问的问题]……"

🎬 【0:05-0:10】 方案承诺（自信——给出明确答案方向）
   "我告诉你，真正有用的方法就3步"
   "很多人搞错了，其实应该这么做——"
   "很简单，你只需要做三件事……"

🎬 【0:10-0:50】 3-5步解决方案（干货——每步要具体到能跟着做）
   博主原话："问题解决方案，一二三四五"

   "第一步：[做什么]"
   "第二步：[做什么]"
   "第三步：[做什么]"

   要点：
   √ 每步说清楚"做什么"+"为什么这么做"
   √ 用具体例子，不要讲抽象道理
   × 不要并列三点没有递进

🎬 【0:50-1:00】 [可选] 为什么很多人做不到（⚠️ 过滤层）
   博主原话："我如果讲道理播放量会低，但我要过滤"
   "为什么很多人卡在这？因为……"

   ⚠️ 加这层 = 牺牲播放量，换精准粉丝
   ⚠️ 不加这层 = 播放量更高，但用户没那么精准
   ⚠️ 想清楚你要什么，再决定加不加

🎬 【1:00-1:05】 一句话总结
   博主原话："最后一句总结"
   "所以记住——[核心结论/金句]"
   "就这么简单。"
```

### 博主亲述（来自视频原文）

> "拍短视频很简单吧，搜集问题，尤其是付费的问题。他就能直接命中用户的痛点...人们听的就是我想要的东西...你有什么问题吗？我告诉你解决方案12345步，一句话总结，完事了。"

### 这个模板和前面6个模板的区别

| 维度 | 模板一~六 | 模板七（姜胡说式） |
|------|----------|------------------|
| **情绪设计** | 有预设情绪曲线 | 不刻意设计，靠痛点带情绪 |
| **共情环节** | 专设共情段落 | 不要共情，直接给方案 |
| **原因解释** | 放结构里默认有 | 标为"可选"且说明是过滤层 |
| **拍摄难度** | 需要表演能力 | 会说人话就能拍 |
| **流量特性** | 推送型（算法推荐） | **搜索型（长尾资产）** |
| **语言风格** | 按风格系统定调 | 人们怎么说你就怎么说 |
| **适合谁** | 有表演基础/想打造人设 | 只想**解决问题、积累资产** |

### 💡 使用建议

1. **先用模板七拍前10条** — 成本最低、最容易坚持
2. **每条开头前3秒必须是"你是不是[具体问题]"**
3. **语言检测**：读出来，像不像你跟朋友说话？不像就重写
4. **搜得到吗？** 标题和文案要用"人们搜问题时打的字"，不要用专业术语
5. **[可选]过滤层什么时候加？** — 你已经有一批基础粉丝了，想筛选出高质量粉丝时加
6. **这个模板拍的视频** — 刚开始没流量很正常，博主说了：推送流量半个月没了，**搜索流量一直有**

### 一句话记忆

```
痛点 → 方案 → 步骤 → [过滤] → 总结
选题从评论区来，结构就这么简单，语言说人话，视频成资产
```

## 模板八：个人叙事型 / 身份IP型

> **来源：** 基于你的爆款视频（7000播放/364转发/146关注）提炼——这是你所有内容里**涨粉效率最高**的类型。
> **核心逻辑：** 观众看完不是学到了方法，而是**认识了"你是这样的人"**。

### 信息
- **时长**：90-150秒（叙事型需要比操作型更长）
- **对应情绪曲线**：曲线G（好奇→共鸣→认知升级→信任→使命）
- **嘴替重点**：替他说出"我也想成为那样的人"
- **自信锚点**：你的经历本身就是最强的自信——不需要"我告诉你"，只需要"我走过来了"
- **适用场景**：
  - 涨粉期——让新粉快速建立对你的认知
  - 里程碑分享——有了新成就/新身份
  - 每5-10条实操内容插1条——调节节奏，拉近关系
- **核心原则**：不是"展示我很牛"，是"**我走过你正在走的路，这是我想明白的事**"

### 结构

```
🎬 【0:00-0:20】 身份时间线开场
   开场法：用开场三模式中的模式B（身份时间线型）
   目标：触发"他怎么做到的？"的好奇心

   "[具体年份] + [从哪起步] + [关键转变] + [现在的反差结果]"

   要点：
   √ 必须有具体时间锚点（"2017年"不是"以前"）
   √ 起点要平凡（兼职、晚上、周末）→ 让观众代入
   √ 转变要反差大（辞掉三甲医院 → 6年没上班）
   √ 用自问自答接住好奇心："很多人问我怎么做到的？今天跟你聊聊"

🎬 【0:20-1:30】 N个顿悟/认知（2-3个）
   结构法：不是教步骤，是"这些年我想明白的事"
   每个顿悟的结构：

   "第X件事……[想通了什么]……[用了一个比喻/场景/数据]……[这让我的做法变了什么]……"

   顿悟设计要点：
   · 每个顿悟必须配一个生活化的比喻（如"挑水vs管道"）
   · 比喻 = 观众能转述给别人的传播引擎
   · 顿悟之间要有递进感（不是并列三个道理）
   · 最打动人的顿悟往往涉及"身份认知转变"（如"从开药到给方案"）

🎬 【1:30-1:50】 价值观表达 / 反行业叙事
   信任法：敢于批评自己行业的乱象，建立深度信任

   "我也得说句实话……[很多人把XX搞坏了]……[但我怎么看]……"

   要点：
   √ 批评的是"乱象"不是"行业本身" → 你是在正名
   √ 给出的价值观要简单有力（"安利是一个工具"）
   √ 这段是"信任高潮"——观众最想转发的往往就是这段

🎬 【1:50-2:15】 桥段：过渡到当前使命
   承接法：从过去的经验自然过渡到现在在做什么

   "[一个当前趋势/变化]……[但我的看法不太一样]……[引用一本书/一个实验/一个数据]……[基于我的经验，我判断……]"

   要点：
   √ 不要生硬转折（"说完了过去，现在讲讲AI"→ ❌）
   √ 用"书/实验/数据"做锚点增加深度
   √ 把"你的经验"和"时代趋势"连接起来

🎬 【2:15-2:30】 当前使命 + 双钩结尾
   "我想干的事很简单——[一句话说清你的使命]……[你的系统已经跑通了]……"

   评论钩：
   "你也在[做同一件事]吗？你以前[做过什么]？评论区可以聊一聊"
   或 "如果你也[某个状态]，评论区打个'1'"

   追更钩：
   "关注我，分享更多有价值的内容"（想强化追更，可换："关注我，下一条讲[和埋的种子相关的事]"）
```

### 种子钩子策略（重要）

这条模板的追更钩**不能随机选**，需要提前在视频中埋种子：

```
第1次出现：在第一个洞察中提一句"后来我养成了一个习惯……"
第2次出现：在第二个洞察中点明"我的XX一直在替我干活"
第3次出现：在结尾追更钩直接预告"下一条讲怎么建这个XX"

这样追更钩就不是"随便说的"，而是观众心里已经好奇了三次的事情。
```

### 你的个人叙事素材池（可复用元素）

| 元素 | 可用角度 |
|------|---------|
| **医生身份** | 三甲医院→做安利→辞职→6年没上班（核心反差） |
| **兼职起步** | 白天上班晚上做→证明了"普通人也能走出来" |
| **银章经历** | 从兼职做到银章→证明系统有效 |
| **知识库习惯** | 每天往知识库存东西→展示系统化思维 |
| **AI应用** | 已经用AI跑通知识库+内容系统→从经验到方法 |
| **带团队出国的经历** | 不是个人牛是系统牛→谦虚+格局 |
| **价值观表达** | "安利是工具"→敢说真话 |

### 使用建议

1. **频率控制：** 每5-10条实操插1条叙事型，既保持实用价值又持续建立IP
2. **每次选2-3个素材组合：** 不要一次把所有故事讲完，留一些下次用
3. **同一个故事可以换角度讲：** "医生辞职"可以从"勇气"讲，也可以从"判断力"讲，还可以从"系统"讲
4. **这个模板的视频数据特点：** 完播率可能不如方法型，但**关注转化率和转发率更高**——适合涨粉期密集使用

### 一句话记忆

```
身份反差开场 → N个顿悟（配比喻） → 价值观表达 → 使命收尾
不是教你怎么做，是让你知道"我是谁"
```
