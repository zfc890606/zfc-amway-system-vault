# 📱 公众号贴图（小绿书）方法论

> **一句话：** 公众号贴图 = 微信用"更轻的图文"抢碎片时间的新流量入口，**发布门槛低（3-6张图+几句配字）、不依赖粉丝、算法强推、有明确流量主变现**；核心打法是"**窄人群 + 小主题 + 痛点-方法-行动三图 + 7天测试**"，跑通后升级成深度内容。
> **别名速查：** 公众号"图片消息/图文"→ 圈内叫"小绿书"→ 2026 官方更名为"**贴图**"，并推出只能发贴图的"**贴图号**"（与视频号并列）。
> **用途：** 发贴图 / 起贴图号 / 把健康营养内容做成贴图前的**方法库层**。执行走 [[公众号创作总控台]]；与公众号长文、视频号的联动见 [[内容全平台分发矩阵]]；想系统看爆文逻辑先读 [[公众号爆款方法论（总纲×四大思维）]]。
> **查重说明：** 2026-09-04 全网搜索整理，库内此前仅 [[03-Resources（参考的资料）/03-短视频/公众号变现营-从流量到留量20天课程拆解]] 顺带提过小绿书，无独立方法论，本档为去重后的新建。

## 〇、先认清战场：贴图为什么现在流量高

| 变化 | 对张医生的意义 |
|------|--------------|
| **官方战略级扶持** | 2026 把"贴图"提到与公众号、视频号并列；服务号信息流有专门版块、主页有贴图标签页、"看一看"密集推荐、"搜一搜"新增贴图号分类入口 |
| **转发即大图** | 贴图转发到聊天时以 **3:4 大图全屏**展示，天然比链接标题更抢眼 |
| **推荐机制 ≠ 订阅机制** | 贴图走"发布"而非"群发"，系统不主动推给粉丝、**主要靠算法推荐** → 零粉/低粉也有机会拿大流量（实测单篇推荐率 90%+） |
| **数据肉眼可见的好** | 首批开通流量主的贴图号创作者：贴图内容平均阅读比传统图文高 **3-5 倍**，停留时长 +40%（网络教程口径） |
| **窗口期红利** | 现在做的人少、内容供给不足、平台还在补贴期 → **普通人成本最低的公域入口之一**；当一个流量入口还没被商业化时价值最大 |
| **长尾强** | 视频 7 天没流量就死，贴图发了一个半月还在涨，可持续带阅读和转化 |

> 📌 **结论：** 营养/健康赛道天然适合贴图（食谱/清单/对比图，中老年"点得动、转得起"），配合你"AI营养师"人设，是 2026 低成本测选题 + 公域涨粉的新入口。

## 一、爆款底层：让人"看完想转发"的 5 种心理

不是图好看才爆，是**戳中一种转发动机**才爆：

| 类型 | 触发点 | 例子 |
|:---:|------|------|
| ① 共鸣类 | "说的就是我" | 打工人的一天 / 正在走下坡路的行业 |
| ② 互动类 | 自带话题钩子，评论区吵起来 | "你在第几档"列表型、选项型 |
| ③ 利他类 | 读者想转给在乎的人 | 大学新生安全提醒（家长转孩子） |
| ④ 猎奇类 | 反常识 + 悬疑不点破 | 强视觉图 + 一句留白，让读者脑补 |
| ⑤ 怀旧类 | 老物件老照片勾回忆 | 80/90 后童年物件，转发率极高 |

**可直接套用的 3 个结构模板：**
- **列表排序型**：按数字排档配话（"十大补血食物排行榜"）
- **反转段子型**：悬念 → 误会 → 反转（适合养生冷知识）
- **人生感悟型**：一句金句 + 干净大图（适合人设/情感内容）

## 二、选题方法论（贴图作为"选题探针"）

### 2.1 窄人群公式（先定人群，再定主题）

> **我帮助【某类人】，在【某个场景】里，用【一种简单方法】，解决【一个小问题】。**

人群越具体越有画面感。忌"做给所有人看"——那等于没人看。

### 2.2 高流量主题方向（全网拆解高频出现）

家的秩序（收纳/断舍离）· 情感共鸣金句 · 育儿教育（反焦虑）· **健康养生（轻知识+收藏型）** · 打工人共鸣+方法论 · 家居美学 · 冷知识 · 职场成长 · 装修避坑 · 清洁妙招 · 养猫知识 · 时令美食 …

### 2.3 健康/营养/食谱赛道 4 类选题（张医生主场）

| 类型 | 公式 | 例子 |
|:---:|------|------|
| 清单盘点类 | "数字 + 名词"给人安全感 | 《十大补铁食物》 |
| 季节时令类 | 跟着节气走，时效性强、转发率高 | 《秋天最该吃的 5 种菜》 |
| 问题解决类 | 直击具体痛点 | 《对睡眠有帮助的 7 种食物》 |
| 对比科普类 | 打破认知，传播快 | 《红枣 vs 黑枣，哪个更补血？》 |

- **减肥/食谱类爆款公式：** 权威背书 + 时间承诺 + 数字结果 + 人群标签（如"协和医生推荐的 7 天食谱，55 岁阿姨瘦了 8 斤"——注意：**张医生版本要过合规闸门，去掉不能说的承诺**）
- **信息块三件套**（每张图/每段一个食物）：食物名 + 核心营养数据 + 大白话作用解释；整篇 300-500 字即可。

### 2.4 新手"7 天 7 组"测试法

每天发 1 组，每组 3-6 张图，每组只讲一个主题，连续记录数据。复盘看 **5 个指标**：
1. 哪类标题更容易被打开
2. 哪类图更容易被点赞
3. 哪类主题更容易被评论
4. 哪类内容带来新增关注
5. 哪类能带动旧文章/旧视频阅读

> 阅读不错但没人关注/评论 = 泛流量；有人留言"想学/想要" = 这个主题值得深挖。

## 三、单篇结构：3 图 + 配字 + 标题

### 3.1 三图结构（新手默认框架）

| 第几张 | 任务 |
|:---:|------|
| 第一张 | **戳痛点**（让目标人群停下："这说的就是我"） |
| 第二张 | **给方法**（干货/清单/步骤） |
| 第三张 | **给行动**（收藏、转发、关注理由、评论区扣 1） |

### 3.2 配字 80-150 字
只做两件事：① 补充图片没说清的信息；② 引导读者关注你的持续价值。

### 3.3 标题 / SEO / 标签
- 标题直接决定打开率（对标爆款同行标题框架，或收集 10-20 个爆款标题喂 AI 生成相似款）
- 标题、内容、合集名**嵌入关键词** → 吃"搜一搜"搜索流量
- 每篇加 **2-4 个话题标签**（#营养 #养生食谱 #中老年健康…）帮系统识别赛道

## 四、做图：找图 / 官方AI / 第三方AI / 封面规范

### 4.1 官方免费路径（最省事）
- **公众号后台"AI 配图"**（腾讯混元）：新建文章 →"图片"→"AI 配图"；支持比例 1:1 / 4:3 / 2.35:1（公众号封面 1024×436）。提示词结构：主体+动作+场景+风格+色彩+情绪+镜头。
- **手机"文字海报"**（仅公众号助手 App）：输入文字（≤140 字）→ 一键生成海报封面，现有 6 个模板，风格像小红书封面。

### 4.2 第三方 AI 生图（批量/质感更可控）
- 工具：**豆包、即梦、文心一格**（水彩插画风健康图）；**GPT Image 2**（质感好，注意按平台比例生成）。
- 营养插画参考提示词：`水彩风格的[食物]插画，写实细腻，自然光线，白色背景，俯视角度，色彩鲜艳饱满，笔触柔和，有轻微阴影，画面干净简洁`
- 去 AI 味：加风格词打底（电影级质感/浅景深/柔和光线/4K/真实摄影）；**AI 出图文字常错 → 标题字后期用修图软件加**；饱和度可降 10-15%。
- 找图渠道：抖音/小红书/百度搜图 → 转风格、改滤镜、裁剪去重（避版权）。

### 4.3 封面规范（唯一值得花钱的地方）
**3:4 竖版为主（信息流展示友好）+ 字要大 + 主体单一 + 对比强烈**；固定模板、固定配色、固定字体，让读者一眼认出你的号。

> ⚠️ **AI 真相：** AI 制作内容**不限流**；AI 批量自动发低质内容**才限流**。做法：AI 做初稿 → **人工审核每一张** → 手动发布。

## 五、发布 SOP（关键开关别漏）

### 5.1 手机端（最快，5 分钟内）
1. 打开**"公众号助手"App**（或微信内"我 → 视频号和公众号/作品 → 发贴图"）
2. 点"贴图" → 创作方式三选一：**拍照 / 文字海报 / AI 生图**
3. 加标题 + 简短描述
4. ⭐ **关键开关**：打开"**平台推荐**"（否则不进推荐池）+ 打开"**赞赏 / 留言区广告**"（收益来源）
5. 发布

### 5.2 PC 端
公众号后台（mp.weixin.qq.com）→"新的创作"→"贴图"→ 上传（本地上传 / 图片库 / 微信扫码 / AI 配图四种）。

### 5.3 频率与养号
- **新号先养号 5-7 天**：发生活/风景/绿植类铺垫账号权重，再转正式赛道；不养号直接发，推流可能慢 1-2 个月
- **手动发布，不要定时**；一天 **3-5 条**即可，频繁会被判批量操作限流
- 不要一上来高频、乱换赛道——系统和读者都不知道你是谁

## 六、账号与涨粉

- **垂直到窄人群**：账号名要直白（"XX阿姨爱健康"式比高大上管用——张医生可考虑"AI营养师张医生"直接占住身份）
- **贴图里藏定位**：只发好看的图没给关注理由 = 流量留不住；封面/结尾金句做得好，用户会帮你截图转发
- **长尾运营**：好的贴图会被收藏、转发、长按截图，回访旧图 → 新关注
- **跑通后升级**：把数据好的贴图升级为 ①长文教程 ②系列栏目 ③资料/服务入口（见第八节联动）

### 8.1 营养线（抓顾客 / 留人）
- 健康食谱、清单、对比图做成贴图 → 天然收藏型内容 → 中老年转发
- 例：《三高的 5 个吃饭小习惯》《晚餐这样搭，第二天不掉链子》——**全部走合规话术，见第九节**

### 8.2 创业线（涨粉 / 抓伙伴）
- "AI营养师"人设干货：AI 做图方法、AI 工具测评、AI×安利认知 → 做成贴图探针
- 例：《我用 AI 10 分钟做一张养生图》《AI营养师的一天》

### 8.3 "一条内容双发"联动（库内已验证打法 · ✅ 已接线 2026-09-04）
**贴图讲浅 → 公众号长文讲深 → 长文里带"完整版看同名公众号"**；贴图同时测哪个主题能爆，爆了再升级短视频/长文/微课，形成探针-放大闭环（参考 [[公众号变现营-从流量到留量20天课程拆解]] 的 D10 与 [[内容全平台分发矩阵]]）。

## 九、合规红线（健康垂类特别版）

> 产出前先过 [[05-Skills（技能sop）/运行规则/01-合规网关]]，一票否决。健康类贴图额外注意：

- **说"营养素"，不叫"保健品"**
- 不写**功效/绝对化/治疗类**词（美白、补气血、治疗、降三高…）→ 改**生活化表达**（"脸色亮了""睡得踏实"）
- 三条红线：不引导问诊 / 不引导评论区谈病情 / 不引导平台外学医领资料
- 营养类结尾加免责
- 图片版权：别直接用别人图，AI 生成或找图后转风格去重

## 十、避坑清单

- ❌ 只发好看的图，没给"这说的就是我 / 我能收藏 / 能转给朋友"的价值感
- ❌ 只盯流量，不设计关注理由（贴图里要藏清晰定位）
- ❌ 盲目抄爆款结构，却不服务一个具体人群的具体场景
- ❌ 一上来追求高频、乱换赛道
- ❌ 批量自动发布 = 粗糙 = 平台不推
- ❌ 照搬夸大收入截图、轻信"每天半小时躺赚"（现实：熟练后单篇仍需 1-2 小时）
