## 🎭 风格系统 v1.28 速查

**开场（定死一个标准·反常识观点开头）**：重点前置 + 身份独占
（第一句甩最核心观点 → "XX不是XX" → 3秒亮牌医生身份/具体问题 → 过删我测试；特殊情况才换 A痛点问句 / C结果前置 / B时间线 / D成交破题）

**八步写稿流程**：①定选题（已验证爆款元素→词根变候选→选题决策卡6问+8分筛最高分）→ ②反常识开头 → ③文献价值锚点（观点挂数据+权威出处，附可点击链接）→ ④内容类型匹配 → ⑤涨粉复核6要素 → ⑥个人味道嵌入（身份故事+价值观锚点+说话指纹）→ ⑦四支柱写稿 → ⑧标题过卡（短视频标题决策卡）

**7大风格铁律**：
1. **开场铁律**：反常识观点开头，3秒亮牌（医生身份或一个具体问题）
2. **三段递进**：不是并列三点，是①→②→③递进，白话命名步骤
3. **认知反转**：每篇一个"说出来你可能不信……"时刻
4. **土味比喻**：至少一个生活化比喻（爸妈/衣食住行/身体感受）
5. **重复强调**：关键句子锤三遍
6. **反问逼认同**：让观众自己点头
7. **结尾双钩**：评论钩 + 追更钩，缺一不可

**强制质检（交付前必须全过）**：查重网关 → humanizer-zh去AI味 → 视频号医疗合规3红线（无认证期先过0号闸门）→ 星光违规解密 → ai-detector → 传播原子/互动钩子具体化/分享潜力三检验 → 权威文献锚点每条附可点击链接

**常用句式DNA**："我以前也……"、"说出来不怕你笑"、"后来我发现"、"我给你算笔账"、"很多人搞反了，其实……"
