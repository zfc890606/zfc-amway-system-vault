# 🤖 AI 录屏演示账号 · 口播配合录屏写作规则

> **定位**：本规则服务 **AI 录屏演示账号**——用"屏幕录屏 + 右下角小窗人像 + 旁白"展示张医生整套 AI 落地系统（本地知识库 / Skills 技能 / 操作流程规则），让人看完想学、想抄作业、想跟着用。
> **与安利主线的关系**：独立第二条脚本线。安利主线 = 口播涨粉（认同张医生这个人）；本线 = 演示教学（想学这套系统）。选题源复用 [[00-灵感库（标记灵感）/AI选题库|AI选题库]] 的 A 操作类。
> **交付物 = 纯口播文案 + 录屏配合提示**：我交付**口播文案**（连续段落，照说就行），在关键处用**【录屏提示】**标出"这一段口播时屏幕大概在做什么"。画面由你自己录屏把控，文案能配合录屏节奏就够，不用我出画面分镜。
> **触发词**：说"写AI脚本，A-00X" / "写AI演示脚本，主题是XXX" → 按本规则出口播文案。
> **存储位置**：`00-灵感库（标记灵感）/AI选题脚本库/`（口播文案与现有 AI 脚本同库存放）
> **运营层 → [[AI录屏演示账号·爆款运营方法论]]**：本文档管"怎么写"，方法论管"怎么爆"（结构/剪辑/配比/双平台/人设）。

## 二、五大留存机制（全网 AI 录屏/教程账号验证）

### ① 钩子不是"观点"，是"结果/痛点"
- 教程/演示类黄金结构：**Hook(前5s) → Demo(75s) → CTA(10s)**，90 秒是短链最佳长度。
- 社交平台教程 **>2 分钟完播率断崖下跌**，总长上限 **3-4 分钟**。
- 开头第一句点名痛点或提前亮出成果，不做自我介绍、不说"今天教大家"。
- **演示必须在 45-60 秒内开始**——观众是来看操作的，不是来听铺垫的。

### ② 口播永远不念画面，只讲"为什么"和"接下来发生什么"
- ❌ "我点击右上角这个按钮"（复述画面 = 废话）
- ✅ "我为什么点这个？因为免费版默认不给你导出，必须在这里开权限"
- 这是录屏类脚本和口播脚本最大的分水岭（Show, Don't Tell）。

### ③ 节奏按"节拍"(Beat)，口播里埋录屏时机
- 整个操作拆成 **5-8 个节拍**，每个节拍 = 一个画面状态 + 一句"为什么"。
- **每 30-60 秒给一个新视觉锚点**（放大/高亮/字幕要点/切画面）——画面静止 = 观众划走。
- 口播里对应埋**【录屏提示】**，提示你"这段配什么画面、什么时候放大/高亮"。
- **每 1-2 分钟一个"记忆锚点"**（小提问/案例/截图），段落间停 2 秒。

### ④ "抄作业"价值 = 收藏/转发引擎
- AI 教程类账号**第一信号是收藏率**（利他价值），不是点赞。
- 脚本末尾一定留"能带走的东西"：**提示词原文 / 文件模板 / 操作路径清单**。
- 起号三感：**新鲜感（入场券）+ 有用感（干货留人）+ 希望感（"我也可以"）**。

### ⑤ 系列化 = 关注理由
- **一个操作点一集，结尾预告下集**——录屏账号涨粉的核心手段。
- 内容配比建议：**AI 实操落地 40% + 行业判断/认知 35% + 热点大白话 25%**，热点每周 ≤2 条（流量高但不涨粉）。

## 三、七步写作规则

```
① 选题（一个操作点/集）
   ├─ 三大源头：张医生实操经验 / 全网AI用户痛点 / AI×营养师落地
   ├─ 快筛3问：有人搜？能真实演示？观众想"抄"？
   └─ 一次只讲一个可复制的操作点，不讲大而全
   ↓
② 结果前置设计
   ├─ 先定"观众看完能带走什么"（提示词/文件/流程）
   └─ 设计开头：结果展示 或 痛点一句话
   ↓
③ 操作节拍拆解（5-8个Beat）
   └─ 每个Beat = 一个画面状态 + 一句"为什么这么做"
   ↓
④ 口播文案写作
   ├─ 连续段落，口语，讲"为什么"+"接下来发生什么"，不念画面
   ├─ 关键处插入**【录屏提示】**（这是录屏动作时机，不是念出来的）
   └─ 总长 ≤3-4分钟，60-90秒为黄金短链
   ↓
⑤ 钩子 + CTA 设计
   ├─ 开头5s：痛点/结果钩子（具体到不用思考）
   └─ 结尾：Recap 关键步骤 + 下集预告（关注理由）
   ↓
⑥ 质检（强制）
   ├─ humanizer-zh 去AI味 + content-risk-detector + ai-detector
   ├─ 星光违规解密（0c）：境外AI工具演示 / 收入承诺 / 副业诱导
   ├─ 涉及营养流程时：医疗合规三条红线 + 免责
   └─ "抄作业检验"：观众能一句话转述"学到了什么"吗？
   ↓
⑦ 交付（见下方交付格式）
   ├─ 纯口播文案（含【录屏提示】）
   ├─ 录屏素材清单（缺口清单：要录哪几段、哪些界面要准备）
   └─ 发布三件套 + 朋友圈文案
```

## 四、口播文案模板（含录屏提示）

```
【录屏：小窗人像入镜，背景虚化，字幕大字"30秒找到任何笔记"】
读了很多课、记了很多笔记，要用的时候一个都想不起来？我花四个月建了个第二大脑，现在 30 秒能调出任何一条笔记。

【录屏：打开 Obsidian → 检索框输入关键词 → 结果秒出 → 放大高亮检索结果】
你看，比如我昨天记的这条营养笔记，现在一句话就能叫出来。

【录屏：文件目录滚动，箭头标注".md 纯文本、本地存储"】
为什么我选 Obsidian？因为笔记是纯文本存在你自己电脑上，不靠任何云服务——软件倒闭了，笔记还在。

【录屏：四层文件夹逐层展开，每层配一行字幕要点】
结构就四层，别想复杂了：灵感入口 → 卡片提炼 → 专题归类 → 输出成品。

……（中间节拍按同法写）

【录屏：小窗人像放大，字幕 Recap 三句话，结尾预告】
记住就三句话：先丢进去、用起来、让它慢慢长。下集我教你"录音怎么自动变成知识卡片"，关注了才能刷到。
```

**写稿规则（口播版口诀）**：
- 口播是"解说词"，不是"教程正文"——每句都对应一个录屏画面时刻。
- 【录屏提示】标的是：**操作动作 + 视觉强调（放大/高亮/箭头/字幕）**，你照提示操作即可。
- 节奏：操作前停 2 秒、重点处放慢重复、段落间留缺口。
- 音频质量 > 画质：音质差是观众放弃的第一大原因。

## 五、合规红线（本线专属 + 全账号通用）

### ⚠️ 本线专属：境外 AI 工具演示（0c 星光违规解密）
> ❌ 演示 GPT 等境外 AI 工具（需翻墙）、"AI+赚钱/副业"教学 → 讲 AI 应用方法不演示工具

张医生整套系统核心是 Claude（境外工具）。录屏账号策略：
1. **录屏主角优先用国内工具**：DeepSeek / 豆包 / 飞书妙记 / 即梦 / 剪映——覆盖 90% 操作流程。
2. **必须展示 Claude 时**：只截取"输入→输出"关键区，不出现翻墙相关界面/字样，或"讲方法不演示工具"。
3. **赚钱/副业类选题**：一律"我的经历分享 / 方法讲解"，不出现具体收入数字。

### 全账号通用红线（照抄，不另起炉灶）
- ❌ 收入承诺：月入 X 万 / 变现 / 搞钱 / 回报 → 只讲方法不讲数字
- ❌ 副业诱导：普通人副业变现 / 宝妈宝爸 / 白手起家 / 躺平 → "我的经历分享"
- ❌ 招商加盟：出现"招商"→ 用"扩店/千城万店/盟商"
- ❌ 医疗功效词（涉及营养时）：根治/治愈/消炎/降压/100%有效 → 通用营养学常识+个人感受
- ❌ 极限词：顶级/第一/最/唯一/永久 → "权威/头号"
- ❌ 引流词：加微信 / 评论区留号 / 私信我 → 留在平台内（关注/粉丝群）
- ❌ 结果保证：包学包会 / 保证 / 无效退款 → 切断因果关系
- ⚠️ 语境叠加：没触发违禁词也可能被 AI 语境识别判违规

## 六、爆款运营模块（摘要 · 详见方法论文档）

> **运营层全量打法 → [[AI录屏演示账号·爆款运营方法论]]**（本文档管"怎么写"，方法论管"怎么爆"：结构/剪辑/配比/双平台/人设/数据迭代）。

- **黄金结构**：Hook(前5s结果/痛点) → Demo(60-75s录屏) → CTA(结尾5-10s)，60-90秒最佳，总长≤3-4分钟。
- **高收藏公式**：焦虑或欲望 → 降低门槛 → 展示结果 → 给出路径 → 留下缺口 → 引导行动；收藏率是教程号第一信号。
- **录屏三铁律**：1080P+ / 30fps+ / 关通知+只录操作窗口+暗色模式；提示词停留≥3秒；每30-60秒一个视觉锚点。
- **剪辑公式**：0-3s成片闪屏钩子 → 3-15s快进生成过程 → 15-20s关键帧定格 → 20-25s提示词 → 25-30s成片+CTA。
- **内容配比**：实操40% + 判断/认知35% + 热点25%（热点每周≤2条）；一个操作点一集+下集预告=关注理由。
- **双平台**：视频号30s简洁版（社交推荐，盯完播/收藏/粉赞比）｜抖音15-30s视觉版（算法池，前3秒视觉爆点，AI内容标注）。
- **人设杠杆**：全网没人讲"医生×AI落地系统"——身份反差即钩子；瞄准小白用户（收藏率高、数据好）。
