## 全流程（8 步 · 每步 1 个动作 + 1 个文件）

```
你说"写公众号 / 把脚本X改成公众号 / 发公众号"
  │
  ▼
① 定线 ──→ 读 规则系统「一、双阶段策略」：这条走 涨粉线 还是 守IP线？
  ▼
② 选题 ──→ `bigpeng-hot-gzh`（主·格式引擎）：喂张医生营养素材 + agent-reach 调研营养行业 → 出 4 选题方向 × 各 3 标题
         → 弹药库取题补量（267 痛点）→ 方法论「对标思维」找方向 /「测试思维」选可测题
         → 全部过「选题卡」（一票否决+8分+搜索词）
  ▼
③ 标题 ──→ `bigpeng-hot-gzh`（主·格式引擎）：按 7 公式出 6 候选标题（喂张医生营养素材）
         → 标题决策卡 5 步精选（合规→公式→三要素→搜一搜→3选1）⚠️ 不可直接发
  ▼
④ 写作 ──→ 规则系统「四~八」定内容（开头8秒/结构/金句≥2/背书/结尾）
         → 结尾结构定死：名片图 → 金句收束 → 互动钩子 → 转发引导
         → wewrite 引擎执行（brief→claims→draft→review）
  ▼
⑤ 质检 ──→ humanizer-zh → content-risk-detector → ai-detector
         → 医疗合规 7 条 → 2026 新规（AI标注）→ 星光违规解密
  ▼
⑥ 发布区 ──→ 文章模板 PUBLISH 标记（内部记录不推）
         → 中间按文案配内容图 1-2 张（xhs-note-creator 16:9 图形卡模板为主）
         → 结尾固定张老师名片图 + 封面讲师照+PIL合成
  ▼
⑦ 排版推送 ──→ gzh-AI-Design（暖蓝医养·校验0 ERROR）→ 推草稿箱
  ▼
⑧ 交付复盘 ──→ 交付纯净版 + 存 公众号草稿/article-XXX
         → 发后 2h 冷启动 → 24h 看数据 → 7 天按 方法论「数据思维」复盘迭代
```

> 🎯 **`bigpeng-hot-gzh` = 格式引擎（选题/标题主工具）**：爆款选题和标题以它的 7 公式 + 8 模板为主。**内容素材喂张医生营养/健康内容**（弹药库 / KC / DJ / 知识库），**调研面向 AI营养师/营养行业**（agent-reach 挖痛点热点）。skill 出「壳」、张医生内容填「核」；出稿后仍必过选题卡 / 标题决策卡 + 医疗合规红线，**不能直接发布**。

## 双脑分工（1 句记住）

> **决定爆不爆的（选题/标题/结构/金句/背书）→ 全部由你的方法论管；wewrite 引擎只负责把决定写出来、审干净、封存好。** 引擎不懂"张医生爆款"，别再让它自由发挥选题标题。

| 层 | 负责什么 | 用什么 |
|----|---------|--------|
| 策略层 | 定线/选题/标题/结构/金句/背书 | 规则系统 + 标题决策卡 + 弹药库 + 方法论 + `bigpeng-hot-gzh`（选题/标题） |
| 执行层 | 写初稿/审稿/封存 | wewrite 引擎 |
| 呈现层 | 排版/配图 | gzh-AI-Design + xhs-note-creator（内容卡）/豆包/图库实拍 |
| 发布层 | 推草稿箱 | wewrite-publish / gzh-AI-Design push |
| 复盘层 | 数据复盘/迭代 | 方法论「数据思维」 |
