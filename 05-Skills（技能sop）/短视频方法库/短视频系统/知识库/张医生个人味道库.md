# 👤 张医生个人味道库 — 把"我"写进每条脚本

> **定位：** 安利主线脚本写稿⑤步**强制取用**的"我的素材库"。把总控台「创业者定位」变成可直接写进脚本的片段——每条脚本至少带走 **1-2个身份故事 + 1个价值观锚点 + 1个说话指纹**。
> **来源：** [[00-灵感库（标记灵感）/操作系统总控台|操作系统总控台]]「创业者定位」+ 已验证爆款脚本（059 医生不学营养 / 033 我的安利十年 / 070 营养素≠保健品）里已经跑通用法的个人素材。
> **用法：** 写稿时按线别（营养线/创业线）从①②取素材、③④定味道，过⑤的嵌入规则。

> ⚠️ **身份呈现安全线（无认证期·强制·2026-08-21 锁死）**：从医经历**只当"人生故事"讲，绝不当"专业背书"用**。
> - ✅ 创业线可讲经历（"我在医院干了快十年"→讲到"为什么做营养"打住）｜❌ 健康线一律不带身份（明示暗示都不行）
> - **落点检验**：经历当**故事**出现=安全；当**专业信源**出现=跨线（"手术台见过所以你要补…"=账号级风险）
> - 配套铁律：[[视频号脚本风格系统]] 铁律18

## 🗣️ ② 说话指纹（语言层的"张医生味"）

> **写稿时至少挑1处用上。** 这些是你一开口别人就认得出的语言习惯——比"扎一刀"更能让观众认出你。

| 指纹 | 用法 | 示例句式 | 备注 |
|------|------|---------|------|
| **口头禅"对不对？是不是？"** | 段尾反问，逼观众自己点头 | "对不对？你想想是不是这个道理" | 互动开场"听到吗？看到吗？"可作破冰 |
| **"非常简单"** | 笃定降门槛，先给确信再给方法 | "我告诉你，这件事其实非常简单" | 与"并不难"呼应 |
| **医生式逻辑 首先→第二→第三** | 结构骨架（注意与铁律6递进平衡） | "首先你要知道……第二……第三才是……" | 营养科普/方法教学型最稳 |
| **为什么→因为 递进** | 认知解释，讲机制不讲结论 | "为什么你天天缺？因为早餐那点才10g——" | 营养线核心指纹 |
| **自问自答** | 抛问题自己答，一句话点透 | "那怎么办？——先给自己建个系统" | 认知颠覆型转场用 |
| **重点重复3遍** | 关键概念换说法反复强调 | "没有退路。没有退路了。我们都没有退路的。" | 定调时刻用（059/张医生式） |
| **对比制造冲击** | 传统医疗vs健康管理、卖产品vs方案、挑水vs管道、消防队vs建筑队 | "临床医学是消防队模式——灭火就走；营养学是建筑队模式——给材料让身体自己修" | 强比喻传播原子来源 |
| **数字敏感** | 用具体数字让人对号入座 | "你每天需要73g蛋白质，早餐那点才10g——天天缺" | 算账法（见视频号脚本风格系统·降维打击） |
| **价值升华** | 结尾拔高：积福报/时间自由/受人尊敬 | "做这件事，不是赚多少钱，是积福报" | 使命收尾用 |

## 💎 ③ 价值观锚点（可嵌入的"态度"）

> **写稿时至少嵌1个**——它是这条脚本的"三观"，也是观众转发的理由。每条给了可直接用金句。

| 价值观 | 脚本金句（可直接嵌入） | 适用线 |
|--------|----------------------|--------|
| **健康是自己的事** | "健康是自己的事——自我管理+生活方式，别把它全交给任何人" | 营养线 |
| **健康要投资** | "健康是要投资的，不投入不产生效益，最忌一毛不拔" | 营养线 |
| **人生不是轨道是旷野** | "人生不是轨道，是旷野——为你想过的生活去奋斗，别给自己设限" | 创业线 |
| **勇气** | "敢选择、敢承担、敢负责——相信直觉走对路" | 创业线 |
| **利他有底线** | "我从顾客的角度开方案，不为业绩强推——这是我做安利的底线" | 双线（信任锚） |
| **极客精神** | "死磕细节，每一步做到极致——结果不会差" | 创业线（AI打法） |

## ⚙️ ⑤ 写稿嵌入规则（强制 · v1.26）

> **⑤写正文时执行，⑦质检时复核。** 对应 [[视频号脚本风格系统]] ③爆款设计 + ⑤写正文 + ⑦质检清单。

```
每写一条安利主线脚本，强制带走：
  □ 身份故事 × 1-2个
      → 按线别从①取（营养线取学医组 / 创业线取转型组+农村组）
      → 放在：开头3秒（身份钩子）或 中间（成长弧线/算账案例）
  □ 价值观锚点 × 1个
      → 从③取，嵌在"态度表达"或结尾金句处
      → 让观众能一句话转述你的立场
  □ 说话指纹 × 至少1处
      → 从②取，自然落在口头语/反问/重复/对比上
      → 不是硬塞，是"我平时就这么说话"
  □ AI营养师身份落点（自然提及或暗示）
      → 营养线落"对顾客"语 / 创业线落"对伙伴"语
      → 不硬塞，埋种子钩子或使命收尾处

质检（⑦过"个人味道嵌入"板块）：
  □ 删掉全文"张医生要素"（身份故事/价值观/指纹）再读，还剩什么？
     → 剩不下 = 味道到位 = 过关
     → 删了还成立 = 这条换谁讲都行 = 补个人味道
```

> **一句话记住：观众关注的不是完成态的权威，是成长中的张医生——把你真实的坑、真实的狠、真实的口头禅写进去，就是你的味道。**
