# 🎭 脚本风格系统 — 张医生式笃定 × 推进信息密度 × 个人味道（IP 默认风格 · v1.26）

> **v1.21 定死：你本身就是IP，观众是来看你判断的。默认风格 = 张医生式笃定（扎一刀→再扎一刀→继续扎→"这点小事不难"）+ 推进信息密度（信息冲击→强比喻→权威数据→金句，推着观众往前走）。不再靠"共鸣/嘴替"。**
> 参考来源：已验证爆款（059 医生不学营养 373K播放 / 070 营养素≠保健品 转发率11.75%全库第一 / 006 智商税 72K播放）+ 张医生式笃定表达

### 🏆 已验证爆款公式（059/070/006 共同规律 · v1.21 写稿默认照此走）

**一句话公式：** `身份独占选题 + 医生第一人称（转变叙事优先）+ 认知递进或分装式并列 + 强比喻传播原子 + 多重权威背书 + 零产品 + 自白型互动钩子`

| 要素 | 爆款做法 | 验证 |
|------|---------|------|
| 选题 | 用户正在搜的问题 / 得罪人拆解具体商品 | "是不是智商税"=全网最大搜索词；燕窝/阿胶/虫草/鹿茸具体靶子 |
| 开头3秒 | 身份+惊人事实双钩（场景嵌入，不硬说"我是医生"） | 059："考执医那年，几千页教材营养学不到20页" |
| 身份用法 | 转变叙事 > 权威背书（"我以前也信过"） | 006："我也曾经信营养素没用，研究了三年想通" |
| 结构 | 三层认知递进 / 分装式并列（2-4个转发包） | 006三层递进 / 070四段并列拆解 |
| 强比喻 | 生活级、一句话可转述 | 汽油vs香水（070）/ 消防队vs建筑队（059）/ 砖瓦盖房子（006） |
| 权威背书 | 每个核心观点≥1个官方出处 | 070背书×5 → 转发率11.75%全库第一 |
| 信息密度 | 每15秒一个新认知，短句段落小 | 006完播17.17%（每6人1人看完） |
| 传播原子 | ≥2个，每个有明确转发对象 | 059有3个→转发26,716；036有0个→转发6 |
| 零产品 | 涨粉视频整条不出现品牌名 | 059/070/006 一字不提 |
| 结尾 | 自白型互动钩子（不用思考就能答） | "买过营养素放家里过期吗？" |

## 📋 写稿流程·八步（从选题到交付——写每条脚本照此走）

> **总原则：先想清楚"这条给谁看、要什么数据"，再动笔。** 下面 8 步把写稿拆到底，每步标注了要看哪个小节。卡在哪一步，翻对应小节。
> **爆款思维贯穿：③ 写前设计 6 要素 → ⑦ 写后复核 6 要素，双保险。**

```
① 定选题 ─────────────────────────────────────────
   第1步 选来源（4入口）：
     · 痛点排行榜 → TOP痛点（大众在搜的，优先）
     · AI选题库 → AI×安利主线
     · 海外信息差库 → 独家稀缺（详细见第3步）
     · 你直接指定主题
   第2步 对方向（内容策略·配比）：
     · 营养线（留人）还是创业线（涨粉）？内容类型是什么？
     · 按配比查：这条该不该现在做？同类型是否扎堆？
   第3步 海外信息差·唯一信息（走入口③时）：
     · 扫海外源 → 让AI翻译+口语化提炼 → 入库 → 选1条
     · 检查：国内没人讲过（唯一）？切国内痛点？有原始出处（文献可查）？
     · 出口：海外唯一信息 + 反常识观点开头（②）→ 天然稀缺组合
   第4步 选题决策卡（定死规则·必过，细则见「🎯 选题决策卡」）：
     第一关 一票否决4问（任一不过 = 换题）：
       ① 用户在问吗？（答案焦虑）→ 标题是用户心里的问题，不是你的感慨
       ② 只有你能讲吗？（删我测试）→ 换个博主这条还成立吗？
       ③ 有人搜吗？（搜索词验证）→ 微信搜一搜/小红书有海量同类问题吗？
       ④ 题目把答案说完了吗？（结论前置检测·v1.25新增）→ 说完=观众不用点进来=换
     第二关 天花板打分8项（每项1分，满分8）：
       人群宽度 / 争议性 / 具体靶子 / 转发对象 / 朋友圈友好度 / 权威背书 / 传播原子 / 爆点叠加
       判定：≥7 值得拍 → 5-6 改造后拍 → ≤4 换题
   第5步 定测试变量：固定=涨粉（唯一变量·定死，不再询问），自动做预测
   卡住看：🎯 选题决策卡 + 创作本质（〇）+ 内容策略·海外信息差选题法

② 开场（定死一个标准，不再纠结）────────────────────
   反常识观点开头 = 重点前置 + 身份独占（见五·反常识观点开头）
   公式：第一句甩最核心观点 → 用"XX不是XX"反常识说 → 过身份独占检查
   同时它是嘴替：这句就是观众心里那句没说出口的话
   特殊情况才换：
     A 痛点问句（求互动）/ C 结果前置（讲结果）/ B 身份时间线（涨粉）/ D 成交型破题（成交）
   卡住看：开头钩子公式库（五）

③ 爆款设计（★动笔前先把7要素定下来）────────────────
   ① 涨粉点：只有我能讲的视角是啥？删掉"我"还剩什么？（身份独占）
   ② 转发点：想让观众转给谁？埋几个原子？（转发对象 + ≥2传播原子）
   ③ 人设弧线：有"暴露→补位"的成长弧线吗？（成长弧线）
   ④ 零产品：产品名/推销暗示 → 删（零产品铁律）
   ⑤ 个人味道（v1.26新增·强制）：从 [[张医生个人味道库]] 选 1-2个身份故事 + 1个价值观锚点 + 至少1个说话指纹——按线别取（营养线取学医组 / 创业线取转型组+农村组），删我测试延伸为"删掉张医生要素还剩什么"
   卡住看：八、涨粉复核6要素 + [[张医生个人味道库]]

④ 选内容类型 → 套模板 ─────────────────────────────
   ⚠️ v1.21 定死：一律走 张医生式笃定（扎一刀→再扎一刀→继续扎→"这点小事不难"）+ 推进信息密度。
   直接亮身份、直接给结果，不绕弯。
   内容类型只决定"装什么的结构"，不决定语气：
   认知颠覆→模板四（主力）/ 方法教学→模板二或七 / 案例见证→模板三
   营养科普→模板五 / 答疑解惑→模板六 / 个人叙事→模板八（涨粉效率最高）
   卡住看：脚本模板库

⑤ 写正文（默认：张医生式笃定 + 推进信息密度 · v1.21）────────
   · 笃定感：扎一刀→再扎一刀→继续扎→"这点小事不难"（张医生式·默认）
   · 自信感：笃定结论，不端不装（支柱②）
   · 信息密度：信息冲击→强比喻→权威数据→金句，每15秒一个新认知（059/070验证）
   · 真实感：读出声、删"第一第二"、留缺口、加一粒沙子（十二）
   · 嘴替感（仅辅助·已降级）：需要拉近距离时再用（支柱①）
   同时嵌入：洞见卡金句 + 权威背书（铁律13）+ 文献价值锚点（铁律14）+ 传播原子≥2个 + **个人味道（身份故事+价值观锚点+说话指纹·v1.26强制·见 [[张医生个人味道库]]）**
   海外信息差专属三层结构（走海外选题时）：
     第1层 反常识观点开头（已定死，见②）
     第2层 甩一手信息：原始出处/论文/数据（信息差·唯一）
     第3层 降维打击：为什么 + 临床真实代价 + 算账法（认知深+身份独+表达狠）
     ＋每个核心观点挂一个文献锚点（铁律14·强制）——"数据+出处"才是深度
   按第③步的设计写——涨粉点、转发点、弧线不能跑偏

⑥ 设计结尾 ────────────────────────────────────────
   双钩：评论钩（"你卡在哪？评论区说"）+ 追更钩（"关注我，分享更多有价值的内容"）
   或认知收尾（没问问题但人人有话想说——059式）
   价值锚定：这条会让人期待下一条吗？（下一集测试）
   卡住看：结尾钩子公式库（六）

⑦ 过质检清单（强制，全部打勾才交付）─────────────────
   □ 开头3秒亮牌复核
   □ 涨粉复核6要素（零产品/转发对象/删我测试/下一集测试/成长弧线/≥2传播原子）
   □ **个人味道嵌入（v1.26强制）：用了身份故事吗（≥1个·匹配线别）？嵌了价值观锚点吗？有说话指纹吗？落到AI营养师身份了吗？删掉"张医生要素"还剩什么？→ 见 [[张医生个人味道库]]**
   □ 查重网关（洞见卡+知识卡+已有脚本）
   □ humanizer-zh去AI味 → ai-detector复核
   □ 风险排查（视频号7类/小红书10项/营养类免责）
   □ **视频号医疗合规（强制·一票否决·2026-08-09锁死）：出现"我帮你看看/分析""把你的情况发我""评论区说你的病" → 整条重写**
   □ 传播原子 + 互动钩子具体化 + 分享潜力
   □ 行业对抗 + 科学事实核验
   卡住看：八、写稿自检清单

⑧ 交付 + 入库 ─────────────────────────────────────
   第1步 设计标题（强制过「📌 短视频标题决策卡」→ 3备选选1 → 填进📱三件套）
   第2步 输出：纯文案 + 📱三件套 + 📱朋友圈转发文案 + 🎬章节进度条预览
   第3步 存入：脚本库 script-NNN-xxx + 更新选题库标记 + 末尾追加「🎯本期测试变量」
   末尾板块（固定）：🎯本期测试变量 → 其下附「权威文献锚点（全部真实可查）」→ 见下方「交付模板」
```

#### ⚡ 第一关：一票否决 4 问（任一不过 → 换题，别浪费一次拍摄）

| # | 快筛问题 | 怎么测 | ✅ 爆款证据 | ❌ 非爆款反例 |
|:-:|---------|--------|-----------|-------------|
| ① | **用户在问吗？**（答案焦虑） | 标题是不是用户心里正纠结的问题，而不是你的感慨？ | "营养素是不是智商税"——全网最强搜索词（006→72K） | "营销套路遍地的时代"——现象评论，没人想搜（036→406） |
| ② | **只有你能讲吗？**（身份独占·删我测试） | 换个博主，这条还成立吗？ | "医生为什么不学营养"——只有医生出身能讲（059→373K🏆） | "蛋白质定量"——营养师/健身博主都能讲（079→5.5K） |
| ③ | **有人搜吗？**（搜索词验证） | 微信搜一搜 / 小红书搜一下，有没有大量同类问题？ | 慢性病 / 药店vs安利 / 智商税，全有海量搜索 | "营销套路多"→ 没人在搜 = 没有流量池 |
| ④ | **题目把答案说完了吗？**（结论前置检测·v1.25新增） | 选题/标题一句话是不是已把结论给完？给完→观众不用点进来 | "富人和中产的孩子，10年后谁更惨？"——悬念+三重爆点（老板IP方法论） | "富人的孩子都在转运动"——结论已给完，不用点开 |

#### 📊 第二关：天花板打分 8 项（决定优先级）

> 每项 ✅=1分 / 🟡=0.5分 / ❌=0分。**满分 8 分，分数 = 这条选题的流量天花板。**

| # | 打分项 | ✅ 满分标准 | 爆款怎么做（证据） |
|:-:|--------|-----------|------------------|
| ④ | **人群宽度** | 从人性底层欲望出发（求财/避险/变美/健康/尊严/好奇）——欲望越底层，覆盖人群越宽 | 智商税=健康+省钱+求安心，覆盖"相信+犹豫+不信"全部人群（006→72K）；蛋白质定量只覆盖"正在算蛋白量的人"（079→5.5K） |
| ⑤ | **争议性** | 天然有双方立场 | "安利能不能调理慢性病"——两边开撕都是流量（001→46K）；"要真诚"没人反对 = 0 流量（036） |
| ⑥ | **具体靶子** | 能落到具体商品/对象 | 燕窝/阿胶/虫草/鹿茸逐一拆解，观众转发有明确对象（070→转发率11.75%🏆） |
| ⑦ | **转发对象** | 观众转发时脑子里有一个具体的人 | "转给买过燕窝的姑姑""转给看病的亲戚"——没有对象的转发发不出去 |
| ⑧ | **朋友圈友好度** | 能进中老年 / 送礼 / 孝心场景 | 070 朋友圈转发 1,037 占 9.1%，059 占 10.9%；079 只占 1.6% |
| ⑨ | **权威背书** | 有官方数据/指南可挂 | WHO 60%vs8%（059）；疾控/中华医学会×5（070）——让转发者"有理有据" |
| ⑩ | **传播原子** | 能提炼一句可转述金句 | "产品有用≠你有用""汽油vs香水""消防队vs建筑队"——0 个金句 = 6 次转发（036） |
| ⑪ | **爆点叠加** | 能拆出 ≥2 重"人性力"（冲突/焦虑/恐惧/好奇/利益） | "富人和中产的孩子，10年后谁更惨？"=阶层对比+代际焦虑+结果危机感，三重叠加（老板IP方法论）；只打一重好奇的"富人的孩子都在转什么"≈60分 |

#### 🚦 判定标准

| 打分 | 判定 | 动作 |
|:----:|------|------|
| **7-8 分** | 🏆 **高天花板** | **值得拍**——按已验证公式直接写稿（行业揭秘 / 认知颠覆 / 分装式拆解） |
| **5-6 分** | ⚠️ **中天花板** | **可拍但要改造**——补身份独占视角、换宽口径开头、给每个观点想好"转给谁" |
| **≤4 分** | ❌ **低天花板** | **换题**——公式再好也撑不起播放（079 教训：内容指标全库顶级，选题撑不住只有 5.5K） |

**一句话记住：先过 4 问（答案焦虑 × 身份独占 × 有人搜 × 结论前置），再打 8 分（人群 × 争议 × 靶子 × 转发 × 朋友圈 × 背书 × 金句 × 爆点叠加）——分高就拍，分低就换，别用拍摄的辛苦去赌一个低天花板的题。**

> **金句（v1.25 新增）：打动的不是观众的猎奇心，是他心里那个还没得到答案的问题。** 做内容不是为了让视频爆，是让你的思想被传播、让信任自然发生——选题对应"你的品牌用哪个角度呈现洞察 + 你想让谁认同你的价值判断"。

### 🎯 交付模板：文件末尾固定板块（🎯本期测试变量 + 权威文献锚点）

```
- 预测5秒完播率：____%

  ② [核心观点/数据]（[权威出处：机构/期刊/年份]）

- 差异化：与 [已有脚本编号] 错开——本条 = [差异化角度]

```

**锚点写法（对应铁律14）：** 每条锚点 = `[具体数字/结论]（[权威出处：机构/期刊/年份]）`；国外一手信息优先（CDC/WHO/Lancet/NIH/NEJM…）信息差价值最高；每个核心观点至少挂 1 个可查证出处；拿不准→标"待核验"或删。参考已验证：script-084 海外文献版（CDC 60.2% + Lancet 2022 + Davis 2004 + WHO 60% + NIH 精准营养）。

## 〇、创作本质：创造稀缺 × 放大情绪

> **短视频文案的核心就两件事：创造稀缺 + 放大情绪。**
> 所有技法、结构、风格选择，最终都是为这两个目的服务。
> **内容基本定律（v1.25·2026-08-12）：一条内容要么引发冲突，要么引发思考——打动的不是观众的猎奇心，是他心里那个还没得到答案的问题。** 做内容不是为了让视频爆，是让你的思想被传播、让信任自然发生（老板IP方法论）。

### 创造稀缺 — "你的观点别人没说过"

观众划走的原因只有一个：**你说的东西他在别处听过。**

| 创造稀缺的维度 | 做法 | ❌ 平庸 | ✅ 稀缺 |
|--------------|------|--------|---------|
| **信息差** | 讲别人不知道的事实（海外前沿→中文翻译=独家护城河） | "吃蛋白粉对身体好" | "你每天需要73g蛋白质，早餐那点东西才10g——你天天都在缺" / "今年美国FDA刚更新的报告里写着……" |
| **视角差** | 用观众没想过的角度解读 | "被拒绝很正常" | "你以为你怕的是被拒绝？不对。你怕的是那个被拒绝之后的自己。" |
| **体验差** | 讲你做到但别人没做到的结果 | "坚持就会有结果" | "我签了50个长客会，续约率80%——我做对了三件事" |
| **冲突差** | 说出别人不敢说的话 | "安利确实容易被误解" | "我告诉你，90%的人做安利搞反了顺序——先买产品再找客户，错得离谱" |
| **表达差** | 同样的道理，你说得比别人狠/准 | "被拒绝要调整心态" | "手机拿起来又放下。编辑好的消息看了又看。最后锁屏。叹口气。" |

### 创造稀缺的核心技法：让他自己说服自己

最高级的稀缺，不是你说了一个别人不知道的事——**是你给了他一个公式，他自己算完，自己得出了结论**。

**算账法（三步骤）：**

| 步骤 | 做法 | 示例 |
|:----:|------|------|
| **① 抛公式** | 给一个简单可算的公式 | "你每天需要73g蛋白质" |
| **② 代入算** | 用他日常的数值算给他看 | "早餐不到10g，午餐15-20g，晚餐20g——加起来45-50g" |
| **③ 揭缺口** | 不算不知道，一算吓一跳 | "离73g差了一大截。每天缺，天天缺，一年365天都在缺" |

**为什么有效？** 因为结论是他自己算出来的，不是你告诉他的。你告诉他的他可能不信，他自己算出来的他没法反驳。

同样，这个方法也能用在**放大情绪**——算完账后的"缺口"本身就是一种焦虑制造，让他自动对号入座。

**核心问题（写每句都问自己）：**
> 这句话，观众能不能在别处听到？
> - 能 → 删了重写，或者换个说法
> - **不能 → 留下，这就是你的稀缺性**

### 海外信息差 — 你在海外，这是别人偷不走的稀缺

> 信息差打法：把海外前沿内容用中文口语化转述——**选题本身稀缺，绕开同质化竞争**。你人在海外，能看到国内创作者看不到的一手信息，这就是你的独家护城河。

| 领域 | 海外来源示例 | 变成中文内容长什么样 |
|------|------------|-------------------|
| 🥗 营养线 | PubMed / WHO / FDA / NEJM / 梅奥诊所 / 哈佛营养系 | "美国刚发的10万人追踪20年的研究——" |
| 🚀 创业线 | 硅谷动态 / YouTube创业者 / 海外播客 | "我在海外看到的一种新打法——" |
| 🤖 AI线 | OpenAI/Google发布 / ArXiv论文 / 海外AI工具 | "国外刚出的这个AI工具，国内还没人讲——" |

**每周信息差流水线（30分钟）**：扫3个海外源 → 挑1-2条"国内没人讲 + 切国内痛点"的 → 让AI翻译+口语化提炼（反向提问提示词见 [[内容策略]]）→ 入库痛点排行榜/关键词库 → 写脚本用 **反常识观点开头**。

**⚠️ 边界（强制）**：海外信息 ≠ 免检。数字/结论必须溯源到原始出处，过科学事实核验；翻译不夸大研究结论；营养类内容加免责。

### 降维打击创作法 — 别人抄不走的深度

> 降维打击 = 用更高维度的信息 / 认知 / 身份 / 表达，碾压同赛道内容。**海外信息差只是"第一层稀缺"（他找不到源头），降维打击才是"第二层壁垒"（他就算找到也讲不出）。**

**四个降维维度（海外信息差内容特别适用）：**

| 维度 | 别人在做 | 你降维到哪 | 示例 |
|------|---------|-----------|------|
| ① **信息降维** | 讲国内二手的"听说" | 讲海外一手源头（论文/指南/原始数据） | 别人："吃鱼油好"；你："NEJM刚发表的3万人研究——" |
| ② **认知降维** | 讲"是什么" | 讲"为什么 / 底层机制" | 别人："蛋白质要多吃"；你："为什么你天天缺？因为早餐那点才10g——" |
| ③ **身份降维** | 转述 / 搬运 | 医生专业解读（结合临床真实案例） | 别人翻译论文；你："我在手术台上见过太多指标一塌糊涂的——" |
| ④ **表达降维** | 罗列观点 | 算账法 / 框架让观众自己得出结论 | 别人："你要注意营养"；你："你每天需要73g，早餐10g，你自己算——" |

**降维打击检验标准：** 这条内容，同赛道博主能 1:1 复制吗？
- 能 → 你还跟他在同一维度，不够深
- 不能（他得先翻原始论文 / 没有你的临床经验）→ 你已经降维打击了

**三重护城河公式：**
> **信息差（他找不到源头） × 认知深（他讲不出机制） × 身份独占（他没有临床） = 抄不走**

### 放大情绪 — "把观众的情绪推到顶点"

短视频的本质不是传递信息，是**传递感受**。信息他记不住，感受他忘不了。

| 情绪放大步骤 | 方法 | 示例 |
|------------|------|------|
| **① 识别情绪** | 用户现在是什么情绪？焦虑/委屈/愤怒/不甘/恐惧？ | "你是不是特别憋屈？明明很努力了，结果还不如不做" |
| **② 具象化** | 不要说抽象词，说具体场景 | "被拒绝很难受" → "手机拿起来又放下，编辑好的消息看了又看，最后锁屏" |
| **③ 推高点** | 用扎心话、狠话把情绪推到顶点 | "你以为你怕的是被拒绝？不对。你怕的是那个被拒绝之后的无能的自己。" |
| **④ 给出口** | 给解法或认知翻转，让情绪有释放 | "后来我发现，真正的问题不是我该不该开口，是我不知道怎么开口" |
| **⑤ 拉回来** | 情绪不能一直高，结尾要收得住 | "你现在卡在哪一步？评论区告诉我，我帮你分析" |

**情绪放大的核心口诀：**
> **先让他不舒服，再帮他舒服。**
> 别怕让观众难受——他难受了才会记住你，你帮他不难受了他才会信任你。

### 两个原理的关系

```
创造稀缺        ×        放大情绪
（理性锚点）            （感性驱动）

给他一个"不走的理由"     给他一个"行动的冲动"

缺了稀缺：内容正确但没记忆点 → 划走
缺了情绪：道理都对但没人转发 → 不破圈
两者都有：观众看完"咯噔"一下，还想看下一条
```

**一条文案的自检：**
- □ 创造稀缺：观众看完会不会觉得"这个观点我第一次听到"？
- □ 放大情绪：观众看完心里会不会"咯噔"一下？

### 反差人设 — "让观众猜不透你"

> **人设的最高境界不是统一，是反差。** 观众以为你是A，结果你是B——这种反差感让人上瘾。

| 反差类型 | 怎么做 | 示例 |
|---------|------|------|
| **身份反差** | 你的外在形象和说话方式形成对比 | 看着像专家，说话像隔壁老张 |
| **认知反差** | 你以为我要说A，结果我说B | "你以为做安利最重要的是口才？我告诉你——是耳朵。" |
| **经历反差** | 我现在很行，但我以前也很惨 | "我现在的团队有50人，但三年前我连一个客户都留不住" |
| **态度反差** | 对熟人一个态度，对原则另一个态度 | "我平时很好说话，但在这件事上我寸步不让" |

**反差人设的核心：让观众产生"嗯？"的瞬间。**
- 没有反差 → 观众5秒就知道你是什么人 → 无聊
- 有反差 → 观众想看"你到底还能说出什么" → 上瘾

## 一、核心理念

```
一条好脚本 = 创造稀缺（你的观点别人没说过）
             + 放大情绪（把观众的情绪推到顶点）
             + 反差人设（让观众猜不透你）
             + 嘴替感（替他说出心里话）
             + 自信感（不端不装，娓娓道来）
             + 情绪感（起伏变化，敢爱敢恨）
```

**为什么是"嘴替"？**
- 观众刷到你的视频，前3秒的判断标准是：**"这人说的是不是我？"**
- 你说出了他想说但说不出口的话，他就觉得你懂他
- 他觉得你懂他，才会听你继续说下去

**为什么"创造稀缺"是第一条？**
- 你说的话他在别处也能听到 → 他为什么要看你？
- 只有你能讲、你敢讲、你讲得不一样 → 他才会留下来

**为什么"放大情绪"是第二条？**
- 信息他记不住，感受他忘不了
- 先让他不舒服，再帮他不舒服——他就记住你了

## 二、三条风格支柱

> ⚠️ **v1.21 定死：支柱①嘴替感降级为可选辅助。** 你已经是IP，不再靠"替观众共鸣"拉新——默认走 张医生式笃定 + 推进信息密度（见 四、十）。嘴替只在个别场景辅助用，不作为选型依据。

### 支柱①：嘴替感 — "替观众说话"（已降级·仅辅助）

| 维度 | 做法 | 错误示范 | 正确示范 |
|------|------|---------|---------|
| **替他说出心里话** | 一开口就击中他没说出来的想法 | "很多人做安利会担心被拒绝" | "你是不是最怕别人问你'你做的是不是传销'" |
| **替他说出顾虑** | 把他心里那个"但是…"先说出来 | "被拒绝很正常，不用太在意" | "手机拿起来又放下，编辑好的消息看了又看，最后锁屏，叹口气——我都干过" |
| **替他说出怀疑** | 把他自我怀疑的声音具象化 | "坚持就会有结果" | "你心里有个声音说：是不是我真的不行？" |
| **替他说出委屈** | 共情但不煽情 | "做安利确实不容易" | "特别憋屈。明明很努力了，结果客户没几个，家里人还说'早告诉过你不行'" |

**嘴替公式：**
> "你是不是也[具体场景]？" + "我心里知道你在想什么：" + [具象化他内心的声音]

### 支柱②：博主式自信自然 — "不端不装，娓娓道来"

| 维度 | 做法 | 错误示范 | 正确示范 |
|------|------|---------|---------|
| **算账式说服** | 用具体数字让人对号入座 | "坚持吃产品对身体好" | "你每天需要73g蛋白质，早餐那点东西才10g，天天缺" |
| **具体案例** | 讲具体的人、具体的对话 | "我们有个客户吃了以后效果不错" | "我说张姐，你脂肪肝偏高对吧？你每天早晚两勺，三个月指标肯定不一样" |
| **不端不装** | 承认自己踩过坑 | "做安利要用正确的方法" | "我以前也是，签了十几个客户，续约的不到一半" |
| **娓娓道来** | 语速适中，不赶不拖，留白 | "第一第二第三"快速罗列 | 先用故事引出问题，再给方法，给完方法再补充一句"你想想是不是这个道理" |
| **自信但不傲慢** | 笃定地说出结论，不加修饰语 | "可能这个方法会比较好" | "我告诉你，你这么搞不行。换我来教你。" |

**博主式自信公式：**
> "我跟你讲个事" / "我告诉你" + [笃定的结论] + "是不是这个道理？"

### 支柱③：姜胡说式情绪表现力 — "情绪有起伏，节奏有变化"

| 维度 | 做法 | 错误示范 | 正确示范 |
|------|------|---------|---------|
| **情绪曲线** | 一条脚本内情绪有起有伏 | 全程同一语调 | 扎心开场 → 否定认知 → 给解法 → 再扎 → 拉起来 |
| **节奏变化** | 短句和长句交替，快慢结合 | 全是平均长度的句子 | "你不是怕被拒绝。不对。你怕的是那个被拒绝之后的自己。" |
| **敢表达真实情绪** | 敢说狠话、敢表达愤怒和委屈 | "被拒绝也是成长的一部分" | "我当时就傻了。你知道吗？签完我以为完事了。" |
| **留白和停顿** | 关键句说完停一下，让观众消化 | 一口气说完不带喘 | "但今天我要跟你说一个真相——（停顿）可能会让你不舒服" |
| **真诚 > 完美** | 说得不好没关系，但要说真话 | 听起来像背稿子 | "我跟你讲……嗯……这个事情我想了很久" |

**姜胡说式情绪曲线口诀：**
> **开头扎一刀，中间揉一揉，结尾拉一把。**
> 别怕让观众不舒服，先让他不舒服，再帮他舒服。

## 三、写作铁律（12条）

### ⚡ 开头：3秒定生死

**铁律1：不要铺垫，直接扎心**
- ❌ "今天想跟大家聊聊关于做安利被拒绝这件事"
- ✅ "手机拿起来又放下。编辑好的消息看了又看。最后锁屏。叹口气。"

**铁律2：第一句话必须"重点前置 + 身份独占"（v1.21：不再靠"嘴替"）**
- ❌ "今天想跟大家聊聊营养素"（无重点、无身份，任何人能说）
- ✅ "我考执医那年，几千页教材，营养学不到20页"（身份+惊人事实双钩·059式）

**铁律3：用具体场景代替抽象概念**
- ❌ "有人脉困扰"
- ✅ "朋友圈发了没人理，身边的人看到你就躲"

### 🧠 中间：结构要活

**铁律4：用"否定→打破→重建"替代平铺直叙**
- ❌ "被拒绝的时候，你可以换个角度想"
- ✅ "你以为你怕的是被拒绝？不对。你怕的是那个被拒绝之后的自己。"

**铁律5：每30秒让观众内心产生一次"嗯？"**
- 每一个小段落都要有一个认知翻转或一个具体场景
- 从头到尾都讲一个道理，观众就跑了

**铁律6：三个观点不要并列，要递进**
- ❌ "第一…第二…第三…"（并列，没推背感）
- ✅ "先说你踩的第一个坑→然后说你以为踩完了其实还有第二个→最后告诉你最狠的那个"

**铁律7：多用对话，少讲道理**
- ❌ "要跟客户建立信任关系"
- ✅ "我说张姐，你脂肪肝偏高对吧？每天早晚两勺，三个月指标肯定不一样"

**铁律8：敢说狠话**
- ❌ "可能这个方法会比较好"
- ✅ "我告诉你，你这么搞不行。错得很离谱。"

### 💥 结尾：收得住，有回响

**铁律9：结尾不要煽情，要笃定**
- ❌ "希望这条视频对你有帮助~"
- ✅ "你现在卡在哪一步？评论区告诉我，我帮你分析。"

**铁律10：每条结尾的CTA不一样，不要重复同一句话**
- ✅ 每条结尾钩子都指向下一条内容，形成连续剧效果

**铁律11：不要"所以"开头**
- ❌ "所以记住一句话"
- ✅ "先让自己成为答案，别人自然来找你"（直接说，不加引导）

### 🎯 全局

**铁律12：写完读一遍——像不像人说的话？**
- 读出声来。如果读起来不像你跟朋友聊天，删了重写。
- 检验标准：**"我朋友会这么跟我说话吗？"**

**铁律13：核心观点必须有权威背书（强制）**
- 讲营养/健康/效果，必须给核心观点配权威来源支撑（官方数据/医学指南/国家政策/专家共识）
- ❌ "有人说吃营养素对身体好"（无出处，转出去会被反驳）
- ✅ "中国疾控中心数据：十个中国人九个半钙没吃够"（有理有据）
- ✅ "中华医学会指南白纸黑字：微营养素是人体代谢'不可或缺'的，专家一致率100%"
- 目的：**让转发者"有理有据"，降低转发社交风险**——观众转发的不只是观点，是有底气的立场

**铁律14：核心观点必须有「文献价值锚点」（强制·2026-08-05新增）**
> 深度 = 可查证。每个核心观点，最好挂一个"国外研究/权威数据"锚点——观众转发时"有理有据"，你的内容也因此有别人抄不走的深度。
> 和铁律13的分工：**铁律13管"有没有出处"（防反驳），铁律14管"深度和信息差"（防同质）**——国外一手文献/数据是价值锚点里含金量最高的。

| 锚点类型 | 例子 | 观众感受 |
|---------|------|---------|
| **国外权威数据** | "美国60%成年人在吃营养素"（CDC NHANES） | 信息差，国内没人讲 |

### 反常识观点开头 — 前3秒定生死

> **开头总原则：重点前置** — 第一句 = 整条视频最核心、最有冲击力的一句话（观点/结果/结论），绝不铺垫、绝不自我介绍、绝不"今天聊聊"。
> - **反常识观点开头** = 重点前置的最佳载体：用"XX不是XX"把核心观点直接甩出来
> - **结果前置（C）** = 同原则的另一载体：用"我做了XX，结果XX"把结果甩出来
> - **身份独占** = 给前置的这个观点"上保险"：确保它只有你能讲

> 核心：开场不是自我介绍，是**观点炸弹**——第一句话甩一个和大众认知对着干的判断，制造认知冲突，逼观众停下来。
> 核心法则："前3秒定生死。3秒留不住人，后面写得再好也没人看到。"

| 要素 | 做法 | 反例（平庸） | 正例 |
|------|------|------------|----------------|
| **反常识判断** | 第一句就是"XX不是XX"式结论 | "今天聊聊营养素的重要性" | "很多医生反对营养素，但我在三甲干了X年，我劝你……" |
| **身份独占/反差** | 用你的身份制造反差（"医生却反对同行"）——重点是**只有你能讲** | "我是张医生" | "我是个医生，但我要说句得罪同行的话……" |
| **戳痛点** | 反常识要长在观众的真实痛点上 | 纯抖机灵 | 反常识观点 + 观众正痛的那个问题 |

**公式：** `我告诉你 + [反常识判断] + [身份背书/自嘲]`

**身份独占检查（强制·开头就卡）：** 开头是身份独占最关键的一道关——3秒留人靠的就是"这句话只有你能讲"。写完开头逐条过：
- [ ] **① 换人测试**：这个反常识观点，换成别的医生/营养师能讲吗？能 → 不够独占，换或加独家视角
- [ ] **② 删我测试**：删掉开头的"我"和身份词，还剩什么？剩不下=身份即内容=过关；删了还成立=换个博主也能讲
- [ ] **③ 补独家**：不够独占时，用你的独家经历补位——三甲麻醉 / 农村娃考医学院 / 开店亏光（059验证：删掉"我考执业医师/在医院轮转"就只剩"营养学很重要"）

**适用：** 认知颠覆型 / 个人叙事型 / 涨粉型内容——最狠、最反常识，但别硬套，观点必须你真信。

**黄金开头公式：**
> 选题爆款（痛点TOP级） + 开头抢（九大人性钩子选一个 / 或 反常识观点开头） + 第一句就是嘴替

### 成交型破题开头（30%成交转化型专用）— 第一句让"对的人"认出自己

## 十、参考对标：张医生式笃定风格

> 来源：[[2026-07-14-专注工作与自我改变的决心-张医生分享]]（团队内部分享，整理于 2026-07-14）
>
> 张医生的表达风格可以作为"博主式自信"的极端化样本——更狠、更决绝、不留余地。

### 风格特征总览

```
张医生式笃定 = 0个否定词 × 极端比喻 × 行为先于认知
```

队友A的观察："他讲话里面没有一个否定词，没有'还可以''还不错'，是目标清晰坚定。"

### ① 语言特征

| 维度 | 张医生的做法 | 可复用的技法 |
|------|------------|------------|
| **0否定词原则** | 全程不用"可能、也许、还可以、还不错、我觉得" | 写稿后全文搜索否定词，全部删掉 |
| **极端比喻** | "把自己腿打断、手砍掉、剃光头、辞职" | 用极端场景打破观众的舒适区，比温和说理更有效 |
| **反问推进** | "还用你讲是不是？关键是你为什么要？" | 用反问代替陈述，逼迫观众自己思考 |
| **短句击穿** | "没有退路。没有退路了。我们都没有退路的。" | 同一句话重复三次，一次比一次短，一次比一次重 |
| **笃定结论** | "一定一定拿下，并不难。" | 双"一定" + "并不难"——先给确信，再降门槛 |

### ② 情绪曲线特征

张医生的情绪曲线属于 **极端版痛点共鸣型**：

```
😐 场景还原（"你打给领导人打电话打什么？"）
😅 扎心揭穿（"继续加油——领导人就只能鼓励你了。"）
🔥 极端比喻（"把自己腿打断"）→ 情绪拉到最高
💪 笃定收尾（"你的银章一定一定拿下，并不难"）
```

区别于姜胡说式的"扎一刀→揉一揉→拉一把"，张医生是**扎一刀→再扎一刀→继续扎→然后说"这点小事不难"**。

### ③ 与现有三大支柱的对比

| 对比项 | 博主式自信 | 姜胡说式情绪 | 张医生式笃定 |
|-------|-----------|------------|------------|
| **核心** | 不端不装，娓娓道来 | 起伏变化，敢爱敢恨 | **0否定词，极端笃定** |
| **语言** | 算账式说服+具体案例 | 短长交替+留白停顿 | 重复短句击穿+反问 |
| **金句示例** | "天天缺" | "你是不是也这样？" | **"没有退路了。"** |
| **适合场景** | 方法教学/营养科普 | 痛点共鸣/案例见证 | **破局动员/下定决心的内容** |
| **风险** | 过于平实 | 过度煽情 | **过于极端，可能劝退保守型观众** |

### ④ 可借鉴的写作技法

**技法1：三段递进否定**
```
"没有退路。
没有退路了。
我们都没有退路的。"
```
→ 第一句陈述事实 → 第二句加强 → 第三句把听者拉进来（"我们"）
→ 适用：脚本中需要"定调"的关键时刻

**技法2：反问→自答→再反问**
```
"关键是你为什么要？这个东西它不是那么容易想明白。
你要经常跟自己对话才行。"
```
→ 先抛问题让观众思考 → 不给标准答案，给思考方法
→ 适用：认知颠覆型脚本的中间转折

**技法3：极端比喻→降维收束**
```
"把自己的腿打断，把自己手砍掉……
我不是建议大家都辞职啊。"
```
→ 先用极端比喻制造冲击 → 再往回拉一下表明不是疯话
→ 适用：需要打破观众认知框架时

### ⑤ 什么时候用张医生式风格（v1.21：默认通用）

> v1.21 起，这就是全部内容的默认风格。不再是"动员专用"——笃定语气 + 推进信息密度，对外涨粉、认知颠覆、营养科普、团队动员统一走这条。
> 强度靠"往回拉一下"控制：极端比喻后用一句"我不是建议大家都辞职啊"收束，打破框架但不劝退。

| 适用情况 | 强度把控 |
|---------|---------|
| 🔹 破局动员类视频 | 极端比喻 → 往回拉（"不是让你们都辞职"） |
| 🔹 给"做了但没做起来"的人打气 | 短句击穿 → 笃定收尾（"并不难"） |
| 🔹 对外涨粉 / 认知颠覆 / 营养科普 | 信息密度推进 → 权威数据落地（059/070式） |
| 🔹 讲产品功效/使用说明 | 不夸大、不做疗效承诺，数据挂权威出处 |

## 十一、流量思维：芒果TV，不是CCTV

> **不要做CCTV式的专家，要做芒果TV式的自己人。**
> CCTV做的是"我来讲，你来听"——专家心态，高高在上。
> 芒果TV做的是"你在聊什么，我来陪你聊"——用户心态，去用户多的地方。

### 核心理念：去用户多的地方"偷听"

```
❌ 专家思维（CCTV）：
   "我专业，我来讲，你们听着"
   → 输出自己知道的内容
   → 用户感受：他懂很多，但跟我有什么关系？

✅ 用户思维（芒果TV）：
   "用户在哪聊？他们在聊什么？"
   → 去评论区、去搜索框、去同行评论区"偷听"
   → 用户感受：他说的就是我遇到的事！
```

### 四步"偷听"法

| 步骤 | 做什么 | 产出 |
|------|-------|------|
| **① 找地方** | 去用户聚集的地方（小红书评论区、知乎回答、公众号留言、搜索下拉框、百度知道） | 知道用户在哪儿 |
| **② 听什么** | 听他们的问题、困惑、抱怨、想要的 | 拿到真实痛点 |
| **③ 提炼** | 把他们的原话提炼成选题和关键词 | 更新痛点排行榜+关键词库 |
| **④ 用嘴替还回去** | 用他们的语言，回答他们的问题 | 写脚本 |

### 做"自己人"的三个原则

| 原则 | 做法 | ❌ 错误 | ✅ 正确 |
|------|------|---------|---------|
| **讲人话** | 用户怎么说，你就怎么说 | "建立全域获客体系" | "让更多人能找到你" |
| **讲人话** | 用生活场景，不用专业术语 | "提升客户留存率" | "签了约的人，怎么让他下个月还找你" |
| **先听后说** | 先听懂用户的问题，再回答 | 自说自话讲产品 | 先复述他的问题，再给答案 |
| **不端着** | 承认自己也有不懂的 | "我来教你" | "我以前也这样，后来发现…" |

### 实战检验

写脚本前问自己三个问题：

```
① 这句话，我的目标用户会这么说吗？
   → 不会 → 换成人话
   
② 用户问的是不是这个问题？还是我在自顾自讲？
   → 自顾自讲 → 去评论区"偷听"一圈再写

③ 我是站在讲台上说，还是蹲在他旁边说？
   → 讲台上 → 下来，蹲在他旁边
```

**一句口诀：**
> **你不是专家，你是帮用户解决问题的自己人。**
> 专家的知识你留着用，专家的姿态你丢掉。

## 十二、真实感写作法 — "像在聊天，不是在讲"

> **最高级的文案，是你听他说话的时候，感觉不到"这是写好的"。**
> 你朋友给你讲一件事，他不会按一二三来，不会用漂亮的过渡句，不会每句话都完整。
> 他会说"哎你知道吗，后来我才发现……"，他会说"不对，我换个说法"。
> 这就是真实感。

### 结构化 vs 聊天化

| 维度 | ❌ 结构化文案（听了像在听课） | ✅ 聊天化文案（听了像在聊天） |
|------|---------------------------|---------------------------|
| **开头** | "今天我要跟你分享一个方法" | "哎我跟你说个事——不对，我重新说" |
| **过渡** | "第一……第二……第三……" | "然后你猜怎么着？""后来我才发现一个事" |
| **举例** | "比如有个客户，她一开始……" | "我认识一个人……算了不说名字" |
| **结尾** | "你现在卡在哪一步？评论区告诉我" | "你先试试，不行再来找我" |
| **语言** | 每句话都完整、干净、没废话 | 有语气词、有重复、有"嗯……怎么说呢" |
| **态度** | "我来教你" | "我也是这么过来的" |

### 四步写出"聊天感"

**① 写完之后，读出声来**

读的时候问自己：**我朋友会这么跟我说话吗？**
- 不会 → 说明太书面了，改
- 会 → 过关

**② 把"教学感"替换成"分享感"**

| ❌ 教学感 | ✅ 分享感 |
|---------|---------|
| "我今天给你拆三个坑" | "我后来发现了一个事……" |
| "第一点……" | "先说一个最离谱的" |
| "为什么会这样？因为……" | "我当时也纳闷——后来我才搞明白" |
| "所以你应该怎么做？" | "后来我是这么干的" |

**③ 每30秒埋一个"然后呢？"**

真实感的核心不是"写得真"，是**让人想知道下一句**。怎么做到？

```
每讲完一段，问自己：
这段最后一句，观众会不会想知道"然后呢？"
→ 不会 → 说明这段太完整了，留个缺口
→ 会 → 过关
```

**留缺口的技巧：**
- "我说了一句话——他当场愣住了。你猜我说了什么？"
- "后来我才发现，问题根本不是这个。真正的原因是……"
- "然后我做了一件事，三个月后——结果我自己都没想到"

**④ 加一粒"沙子"——一句真实得没必要说的话**

真实感和假话的最大区别是什么？**假话太干净了，真话里总有"没必要说的话"**。

比如你要说"我以前也很难"——
- ❌ 假（太干净）："我以前也特别难，三个月没出单"
- ✅ 真（有沙子）："我以前也特别难——说出来不怕你笑，三个月没出单，我老婆说你到底行不行啊"

那个"说出来不怕你笑"就是沙子。它不推动剧情、不传递信息，但就这一句，整段话就真了。

**沙子的类型：**
- 自嘲："说出来不怕你笑""虽然这么说挺丢人的"
- 犹豫："嗯……怎么说呢""我想了一下"
- 细节场景："那天我坐沙发上，手机拿起来又放下"
- 承认不懂："说实话我当时也不知道怎么办"
- 小吐槽："你说气不气人""是不是很无语"

### "一步一步戳中想听的欲望"的秘密

这不是技巧问题，是**节奏问题**。

```
❌ 一步到位：
"做安利怕被拒绝？因为你觉得你在求人。"

✅ 一步一步来：
"你说你不敢开口。
你以为你怕的是什么？
被别人拒绝？
不是。
你怕的是那个被拒绝之后的无能的自己。"
```

**秘密就是：别一次性说完。** 每句只说一半，让他自己走完剩下的一半。

具体做法：
1. 先说一个事实 → 让他想"然后呢？"
2. 再推翻它 → 让他想"那是什么？"  
3. 再揭开答案 → 让他想"真的假的？"
4. 再给验证 → 让他想"那我是不是也可以？"

每一步都踩在他心里那个"下一句想问什么"的点上。

### ⚠️ 节奏控制：口语化入场，但不啰唆

> **聊天感 ≠ 绕弯子。** 最怕的是：口语化了，但讲了半天还没进入主题。

| ❌ 口语化但啰唆 | ✅ 口语化且快速 |
|---------------|---------------|
| "哎我跟你说个事。你知道吗，我最近发现了一个特别有意思的事情。这个事情是这样的……"（5句才进入） | "哎我跟你说个事。你有没有那种感觉——手机拿起来又放下？"（2句进入痛点） |
| "我以前也是这样，真的，一点都不夸张，我那会儿特别难……" | "我以前也是这样——说出来不怕你笑，三个月没出单。" |

**"快进慢出"原则：**

```
开头（快）→ 两句内进入核心痛点
中间（慢）→ 展开情绪，一步一步戳
结尾（收）→ 不拖沓，收得住
```

**检验标准：** 去掉前两句，如果内容不受影响 → 说明前两句是废话，删。

### 自检清单（追加）

写完一条脚本，除了过之前的清单，再加这5条：

- [ ] 读出声来——像不像你跟朋友说话？
- [ ] 有没有"教学感"的过渡词？（第一/第二/所以/因此）→ 删
- [ ] **去掉前两句，内容受影响吗？** → 不受影响说明开头太啰唆，删
- [ ] **前两句内进入核心痛点了吗？** → 没有 → 重新开头
- [ ] 每段最后一句，会不会让人想知道"然后呢？"
- [ ] 有没有一粒"沙子"？（一句没必要说但说了就真了的话）
- [ ] 如果把这脚本发给你朋友看，你会不好意思吗？→ 会就对了
