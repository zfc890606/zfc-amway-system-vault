### 📥 内容入库（你给我素材，我自动处理）

有时候你会直接给我一些内容（看到的文章、想到的选题、听课笔记等），我的处理流程：

| 你给什么 | 我做什么 |
|---------|---------|
| 一段文字/文章/笔记/想法 | **①查重** → 先搜现有洞见卡库 + 知识卡片库 + 痛点排行榜，看有没有相同或类似的 → **有则跳过，并告知"已有类似内容"** |
| | **②值得加吗？** → 没查重到，评估是否有价值 → 有价值则执行③ |
| | **③三件套入库**（全自动）： |
| | ├─ 🃏 **洞见卡(DJ-*)** → 金句/一句话洞见 → 存 `00-灵感库/洞见卡/` |
| | ├─ 📇 **知识卡片(KC-*)** → 4K完整框架 → 存 `00-灵感库/知识卡片/` |
| | └─ 📊 **痛点排行榜更新** → 如果适合做短视频选题 → 加入排行榜 |
| | **④结果告知** → "已入库：洞见卡DJ-XXX + 知识卡片KC-XXX + 新增痛点#XX" |

> ⚠️ **查重规则**：先搜洞见卡库和知识卡片库，标题/核心观点相似度高的跳过，不重复加
