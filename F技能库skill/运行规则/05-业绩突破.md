# 05 · 业绩突破 — 用户说"破业绩/帮我带部门/帮部门①②③冲业绩"时执行

1. **大脑** → 读 [[业绩突破导航]]（当前站位→突破策略→三部门不同带法→每周节奏）
2. **素材** → 读 `A知识沉淀大脑/01-旧知识沉淀/02-创业知识/` 全部内容（10分钟OPP、AI新打法工作指南、领导力工具箱等）
3. **补给** → 检索入库新内容中与创业/业绩/团队相关的洞见卡（DJ-创业*/DJ-团队*）和知识卡片（KC-创业*）

- **Step 1**：诊断三个部门最新数据 → 对比业绩突破导航中的市场结构诊断
- **Step 2**：制定突破策略 → 按4步法帮部门从5-8万跨到12.5万，参考创业素材工具
- **Step 3**：三部门不同带法（情景领导力）→ 部门③(~1万)→S2教练型：陪跑+四确定法；部门②(5-8万)→S3支持型：给建议+资源借力；部门①(5-8万)→S3→S4过渡：放手+顾问式跟进
- **Step 4**：输出每周节奏计划 → 周一方向→周三进度→周五复盘→周日蓄能

产出 → 更新业绩突破导航状态 + 记录陪跑日志。

**变体**：
- **帮部门①/②/③冲业绩** → 读业绩突破导航→针对该部门当前阶段（S2/S3/S4）→调对应领导力工具→输出本周陪跑计划
- **没指定阶段**（只说"帮我做短视频"）→ 先读总控台 → 判断当前卡在哪 → 自动执行对应阶段
