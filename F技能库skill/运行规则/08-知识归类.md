## 自动归类

新内容 → **先过查重网关**（见 `01-合规网关.md` 0a）→ ①先提炼金句→洞见卡（DJ-*）→ ②够深再写知识卡片（KC-*，按上表前缀）→ ③创业/认知/团队/生活类同步生成朋友圈文案（PYQ-*，按 [[B自媒体大脑/05-朋友圈创作/创作脚本规则/张医生-朋友圈写作流程规则-v3.0-融合版|朋友圈写作流程规则 v3.0 融合版]] · 只发创业生活+AI操作+活动转化 · **营养科普类不配PYQ**）→ ④适合短视频→更新痛点排行榜。**爆款视频产出后 → 记录到 爆款视频/**（含完整数据+分析+可复制经验）。

## 处理优先级

| 输入类型 | 默认动作 |
|---------|---------|
| 新书/文章笔记 | → 提炼成知识卡片（对应板块前缀） |
| 飞书妙记/听课 | → 提取金句→先写洞见卡（DJ-*），够深再写知识卡片（KC-*），创业/认知/团队/生活类才同步生成PYQ存 `B自媒体大脑/05-朋友圈创作/交付脚本库/`（营养科普类不配PYQ）；完整转写存 `A知识沉淀大脑/03-飞书笔记存档/飞书妙记同步/` |
| 新选题/痛点 | → 更新 `评论区选题池.md` / 痛点记录 |
| 新脚本 | → 走完流水线后存 `B自媒体大脑/01-视频号创作/交付脚本库/`（AI类→B/04），更新操作系统总控台状态 |
| 爆款视频 | → 记录到 `B自媒体大脑/01-视频号创作/交付脚本库/爆款素材库/`，含完整数据+分析+可复制经验 |
| 日常思考/复盘 | → 写 `G每日复盘/`，有价值的提炼成洞见卡（DJ-*），够深再成知识卡片（KC-*） |
| 团队培训/听课 | → 写笔记到 `A知识沉淀大脑/01-旧知识沉淀/05-带团队/` |
| 独立工具 | → 存独立工具区（`F技能库skill/02-其他技能/` 等），不参与4板块流水线 |
