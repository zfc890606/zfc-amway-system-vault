# 01 · 合规网关 — 任何产出强制过检（一票否决）

> **适用**：脚本（安利/AI/公众号/朋友圈/直播话术）、洞见卡、知识卡片、公众号文章、任何对外内容产出。
> **规则**：先查重，再过医疗合规与平台违规红线，**不过不交付**。交付时按各流水线要求附权威文献锚点。

## 0b. 视频号医疗合规质检（不过不交付）

0. **账号级前提**：先完成视频号职业认证；**张医生确认无资质 → 写脚本在①定选题前先过「🚧 0号闸门·无认证期选题落点判定」（见[[B自媒体大脑/01-视频号创作/创作脚本规则/视频号脚本风格系统]]写稿流程开头）：落点属疾病/功效/指标层健康科普 → 换题不写稿；营养观念/健康观念科普 → 可写但必须过「健康观念科普安全边界」（只讲观念不碰疾病）；白名单见 [[发布风控总表-无认证期]]（2026-08-21 限流后锁死）**
1. **不引导问诊**："评论区告诉我，我帮你分析/看看"、"把你的情况/体检报告发我"、"私信我帮你调理" → 一律删，改纯认知互动（"这条说的情况你遇到过吗？评论区聊聊看法"）
2. **不引导评论区公开讨论病情**："你什么病/指标？评论区说说" → 改"聊聊你的看法"
3. **不引导平台外学医/领医疗资料/收徒**："加微信领资料、教你调理、中医收徒" → 删；医疗内容不挂"领资料"钩子
4. **全账号不留联系信息**：头像/签名/简介/公众号名/标题/定位/活动/直播预约/评论/音频/合集
5. **营养健康类结尾强制加免责**："以上为健康科普分享，不构成诊疗建议，个体情况请咨询专业医师"

细则 → [[视频号风险检测清单]]「〇、医疗问诊合规」；写稿规则 → [[视频号脚本风格系统]] 铁律15

## 0c. 视频号+抖音违规解密质检（不过不交付）

完整规则 → [[视频号抖音违规解密-星光研习社提炼]]。**创作必查红线速记：**
- ❌ **收入承诺**：月入X万/财富自由/变现/搞钱/利润/回报/千或万 → 只讲方法不讲数字
- ❌ **副业诱导**：普通人副业变现/宝妈宝爸/白手起家/躺平 → 改"我的经历分享"
- ❌ **招商加盟**："招商"二字 → 用"扩店/千城万店/盟商"
- ❌ **AI违规**：演示GPT等境外AI工具（需翻墙）、"AI+赚钱/副业"教学 → 讲AI应用方法不演示工具
- ❌ **医疗功效词**：根治/治愈/消炎/降压/包治百病/一盒见效/100%有效 → 通用营养学常识+个人感受
- ❌ **极限词**：顶级/第一/全网第一/最/唯一/永久/独家/首选 → "权威/头号"
- ❌ **引流词**：加微信/企微二维码/评论区留号/私信我/绿泡泡/链接我 → 留在平台内（关注/粉丝群/公众号引流）
- ❌ **线下课**："线下课" → "面授/面对面"；❌ **结果保证**：包学包会/保证/无效退款 → 切断因果关系，不做结果保证
- ⚠️ **语境叠加**：无违禁词也可能被AI语境识别判违规（"现金流/回报/本金"叠加=讲股票）；大促敏感期额外收紧
- **限流判断**：流速断崖式下降→倒查3分钟内违规点；有风险时不要加热/投流（投流二次审查直接限流）

## 0d. 权威文献锚点 — 每条强制附可点击链接

「🎯 本期测试变量」下「权威文献锚点」每条必须附可点击原文链接（URL），写进脚本里点开能核实：
- 格式：`① [核心观点/数据]（[权威出处：机构/期刊/年份]）｜🔗 [点击查看](https://原文链接)`
- 链接要求：官方/机构/期刊/权威媒体原网页，真实可访问；找不到→保守表述或删掉，不能只写出处不写链接
- 交付输出和存入脚本库的脚本文件都要带链接（Obsidian 中 markdown 链接可直接点击）
- 口播正文和简介不出现链接（合规），只放脚本末尾「权威文献锚点」区

## 0e. 公众号 2026 新规避坑质检（不过不交付）

详细规则 → [[公众号写作规则系统]]「十·半、2026 平台新规避坑清单」。**必查红线：**
- 🚨 **AI 标注强制**：文首不写【AI辅助创作】字样（2026-08-27 张医生定），但后台发布必须勾选"含 AI 生成内容"；不勾→限流甚至处罚
- 🚨 **非真人自动化创作条款**：批量AI生成/改写/拼接/搬运+程序托管连续发布→专项治理；✅真人AI辅助（AI出框架+人工润色注入真实细节）合规，❌全文AI一键生成不注入真人经验→违规
- 🚨 **违规导流新规**：三种违规导流（内容/互动/多重嵌套）→提前限流；文末少放二维码/外链，改"关注→加企微社群"合规闭环
- 🚨 **不日更牺牲质量**：高频更新冲掉单篇推荐周期（优质文可连推7天+）；"三天磨一篇精品 > 日更水文"
- 🚨 **不盲目追10万+**：流量至上→取关率+20%、长期传播力-50%；先做对的人，再做爆的量
- **数据纪律**：完读率<30%有问题 / 跳出率>70%改开头 / 赞阅比≥2.5% / 转阅比≥8%；冷启动2小时（核心群+朋友圈+行业群）；发布高峰早6-8点/晚7-9点
