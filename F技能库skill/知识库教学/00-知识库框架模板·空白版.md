# 📐 知识库框架模板 · 空白版（只要框架，没有内容）

> 本模板**只含骨架与规则，不含任何具体业务内容**。
> 拿到手要做的只有三件事：**① 想好自己的核心领域 → ② 照骨架建目录 → ③ 填自己的内容**。
>
> 结构来源：一套在真实运转的"个人操作系统"框架（A–H 九功能位 + 总控台）。可用任何行业、任何人生目标。

---

## 0. 建库前先想清楚 4 件事（填空）

| # | 要定的 | 我的答案（示例写法） |
|---|--------|-------------------|
| 1 | 库的名字 | 例：我的第二大脑 |
| 2 | 我的核心领域（2–5 个） | 例：健康 / 事业 / 读书 / 育儿 |
| 3 | 我的内容出口（1–5 个） | 例：短视频 / 图文 / 朋友圈 / 直播 |
| 4 | 要不要接 AI 自动化 | 要 / 不要 |

> 核心领域 = 你知识库的"4 个抽屉"，后面所有卡片都归到这几个抽屉里。

---

## 1. 骨架总览（功能位，不是死名字）

```
我的第二大脑（库根）
│
├── 🧠 A 沉淀大脑      = 数据库：收件箱 → 加工 → 归档
├── 🎬 B 输出工厂      = 内容出口：选题 → 创作 → 交付
├── 👥 C 行动看板      = 把"下一步"集中管理（项目/待办）
├── 📺 D 工作台·项目   = 某个专门项目（按需）
├── 🏔️ E 工作台·对外   = 对外交付物/成长路径（按需）
├── 🛠 F 方法库        = 技能 / SOP / 运行规则（AI 用）
├── 🔁 G 每日复盘      = 每日闭环
├── ⚙️ H 系统板块      = 系统级文件（工作文件/会议/制度）
│
└── 🎛️ 总控台          = 一屏入口：首页导航 + 常用指令
```

**用字母 + 功能命名**：字母表顺序 = 你的使用顺序（先沉淀→再输出→再行动→复盘）。

> 💡 名字可改。比如你不做自媒体，B 可叫"输出大脑"（作品/成果）；你不带团队，C 可叫"项目工作台"。
> **字母位置代表的"功能"别乱，名字随你。**

## 3. 每个位置内部怎么搭（通用子结构）

```
A 沉淀大脑/
├── 00-新知识入库/          ← 收件箱（所有新东西第一站）
│   ├── 金句卡/             ← 一句话级别的卡片
│   └── 知识卡/             ← 完整认知框架的卡片
├── 01-旧知识归档/          ← 加工完的卡片，按领域归档
│   ├── [领域①]/  [领域②]/  [领域③]/  [领域④]/ …  ← 你在§0填的领域
└── 03-外部笔记同步/        ← 录音转写/剪藏自动同步进来（可选）

B 输出工厂/
├── 00-选题库/              ← 所有可能的选题/灵感池
├── 01-出口平台①/
├── 02-出口平台②/
├── 03-出口平台③/
│    每个出口平台统一三件套：
│    ├── 创作规则/          ← 该平台的规则与流程
│    ├── 创作模板/          ← 该平台的模板与提示词（给 AI/自己复用）
│    └── 交付作品库/        ← 已完成的成品
└── 04-…(要几个出口就建几个)

C 行动看板/
├── [领域①]看板.md          ← 每个领域一张：待办/进行中/下一步
├── [领域②]看板.md
└── 通用工作流/             ← 你反复要用的流程（例：微课/陪跑/活动）

F 方法库/
├── 运行规则/               ← 编号 01–09 的 SOP（合规/复盘/归类…）
└── 技能方法/               ← 按分类放方法技能

G 复盘/   →  按日期：2026-09-08.md

H 系统板块/ → 01-工作文件 / 02-会议安排 / 03-制度与运作
```

## 4. 通用规则（任何库都适用）

1. **目录用两位编号** `00-` `01-` `02-`… → 文件列表按顺序排，不靠字母乱序。
2. **命名带中文注释** `00-新知识入库` → 一眼看懂是干什么。
3. **每层放一个 `index.md`** → 只写"本目录干什么 + 链接"，入口永远好找。
4. **卡片统一命名** `类型-领域-序号-主题`，见 §5。
5. **先想再建**：目录够用就好，别一次建满——**领域从 2 个开始跑，跑顺了再加**。

---

## 5. 卡片/文件命名规范（通用）

| 类型 | 命名 | 说明 | 例 |
|------|------|------|-----|
| 💡 金句卡 | `DJ-领域-序号-主题` | 一句话洞见/金句 | `DJ-领域①-001-一句话主题` |
| 🧩 知识卡 | `KC-领域-序号-主题` | 完整认知框架 | `KC-领域①-001-一个概念` |
| ✍️ 成品·短内容 | `PYQ-日期-主题` | 朋友圈/短状态 | `PYQ-2026-09-08-主题` |
| 🎬 成品·平台① | 按平台定，如 `SC-序号` | 各平台成品 | `SC-001` |
| 🔁 复盘 | `YYYY-MM-DD` | 每日复盘 | `2026-09-08.md` |

**命名三原则**：① 前缀让人一眼知道"这是哪类"；② 领域词对应 §0 的核心领域；③ 序号 3 位自动递增，不重复。

## 6. 内容运转流水线（通用骨架）

```
灵感/录音/读书/聊天
    │
    ▼  "这是灵感"
00-新知识入库（收件箱）
    │  查重：和已有卡片比，重复就跳过
    ├─ 只有一句金句   → 金句卡 DJ-*
    ├─ 有完整逻辑     → 知识卡 KC-*（一句话→底层逻辑→怎么用→边界）
    ├─ 能做内容       → 进 B/选题库
    └─ 是行动任务     → 进 C/行动看板
    │
    ▼ 归档
01-旧知识归档 / 对应领域
    │
    ▼ 反哺
B 输出工厂 → 作品 → G 复盘 → 迭代
```

## 7. 🚧 建库命令（复制到你的空库终端执行）

> 说明：下面只有**功能骨架**，`[领域①]` 这类占位目录等你填好 §0 再手动建（或改命令里的名字）。
> macOS/Linux 直接可用；Windows PowerShell 删掉行尾 `\` 写成一行。

```bash
mkdir -p \
  "A沉淀大脑/00-新知识入库" \
  "A沉淀大脑/01-旧知识归档" \
  "A沉淀大脑/03-外部笔记同步" \
  "B输出工厂/00-选题库" \
  "B输出工厂/01-出口平台①/创作规则" \
  "B输出工厂/01-出口平台①/创作模板" \
  "B输出工厂/01-出口平台①/交付作品库" \
  "C行动看板" \
  "D工作台·专项" \
  "E工作台·对外" \
  "F方法库/运行规则" \
  "F方法库/技能方法" \
  "G复盘" \
  "H系统板块/01-工作文件" \
  "H系统板块/02-会议安排" \
  "总控台"
```

建完后再补 3 个文件：根 `README.md`（库首页）、`总控台/index.md`（入口导航）、各目录 `index.md`。

## 8. 起步清单（前两周只做这些）

- [ ] §0 四件事想清楚（领域先定 2 个）
- [ ] 跑 §7 命令建出骨架
- [ ] 写根 `README.md` + `总控台/index.md`
- [ ] 每天：新东西丢进 `A/00-新知识入库`，至少加工成 **1 张卡**
- [ ] 每周：选 2–3 张卡串成 1 个成品 → 放到 `B`
- [ ] 每天/每周写 `G复盘`
- [ ] 领域超过 4 个、目录不够用 → 再加

> **心态**：不要追求一次完美。**每天写 1 张卡就是胜利，每周出 1 个作品就是丰收。** 断了一天不要紧，捡起来继续——系统不惩罚重启。
