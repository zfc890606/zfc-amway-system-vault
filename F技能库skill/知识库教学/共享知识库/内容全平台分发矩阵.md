# 🔄 内容全平台分发矩阵（张医生版）

> **一句话：** 同一个母题只创作一次（视频号母版），改四遍（公众号/小红书/朋友圈/视频号），一套系统吃透四个平台。选题库是母题源头，各平台方法论是改编工厂。
> **核心公式：** 母题源头 → 视频号母版 → 四平台改编（放大/压缩/提炼）→ 各存各库
> **配套：** 各平台方法论见「关联参考」；本卡只定"怎么分发"，不重复各平台写作规则。

---

## 一、分发模型

```
选题库痛点（母题源头，如"营养素是不是智商税"）
        │
        ▼
  视频号脚本 = 母版（走最严全流程）
        │
   ┌─────┼──────┬──────┐
   ▼     ▼      ▼      ▼
 公众号  小红书  朋友圈  视频号
 阅读体   图文   一条圈   口播
（放大） （改造） （提炼） （原版）
```

> **核心心法：母版只创作一次，其他三平台全部从母版改编——不是写四遍，是改四遍。**

## 三、改编逻辑（换血不是换皮）

### 🎬 视频号 = 母版（全量）
- 完整创作，过选题决策卡（6问+8分）+ 质检8项 + 权威文献锚点（附可点击链接）
- 产出：纯文案 + 📱三件套 + 📱朋友圈转发文案 + 🎬章节进度条预览
- 存 → `B自媒体大脑/01-视频号创作/交付脚本库/script-NNN-`
- 触发："帮我写安利脚本，痛点#X"

### 📱 公众号 = 放大（阅读体）
- 口播体 → 阅读体改写，扩展成 1500-2000 字，加📚参考资料 + 免责声明
- 配图：豆包 Seedream 2-3张 + 讲师照片1-2张 + 封面单独生成
- 排版：gzh-AI-Design 暖蓝医养主题（中老年友好17px）→ 推送草稿箱
- 存 → `B自媒体大脑/02-公众号创作/交付脚本库/`
- 触发："把脚本X改成公众号"

### 📕 小红书 = 压缩改造（图文/竖屏）

> ⚠️ **两卡双过（2026-08-19 定）：** 小红书内容必须同时经过 [[小红书商业定位]]（选题方向）+ [[小红书方法规则]]（落地+合规）——商业定位定"拍什么"，方法规则定"怎么发"，缺一不可。

- **① 选题方向** → 过 [[小红书商业定位]]「三·拍什么」四大题材矩阵（营养避坑/妈妈场景/身份故事/避雷大实话）
- **② 选题落地** → 过 [[小红书方法规则]]「三·选题规则」（选题改造 + 一票否决3问 + 天花板6分）
- **③ 写作发布** → 过 [[小红书方法规则]]「四~七」：标题≤20字（前5字放大词）、封面≤5字大字 + 正文标题管搜索、搜索四维布局、每条给收藏理由
- **④ 合规** → 过 [[小红书方法规则]]「十」医疗合规10条 + 小红书风险清单
- 形态：图文笔记（起号期 7:3 的主力）或 竖屏60-90s 口播
- 存 → 小红书库（或脚本库标注"发小红书"）
- 触发："把脚本X发小红书"

### 💬 朋友圈 = 提炼（口语钩子）
- 一条口语化圈（100-200字），一个钩子 + 一个转发对象
- **铁律：不搬视频脚本**，按 [[张医生-朋友圈写作模板与规则]] 出圈
- 4问自检：一条一点 / 口语聊天 / 开头有钩子 / 转发对象明确
- 存 → `B自媒体大脑/05-朋友圈创作/交付脚本库/PYQ-*`
- 触发："写朋友圈，主题是XX"

## 四、错峰发布节奏

同一母题**不要同一天四个平台全发**（像刷屏 + 审核窗口不同）。建议节奏：

| 时间 | 平台 | 动作 |
|------|------|------|
| 第1-2天 | 视频号 | 母版发出 + 朋友圈转发文案 |
| 第3天 | 小红书 | 图文版（搜索卡位） |
| 第4-5天 | 公众号 | 长文（深度承接） |
| 当周任一天 | 朋友圈 | 插1条母题圈（口语钩子，配图） |

---

## 五、关键规则

1. **母版选型**：默认以视频号脚本当母版——它过选题决策卡 + 质检8项 + 文献锚点，是最扎实的一版，其他平台从它改编质量最高。
2. **改编 ≠ 复制**：小红书最忌讳和视频号一字不差（原创判定 + 用户反感直销）；朋友圈明文规定"不搬视频脚本"。每个平台换一次血，不是换一个皮。
3. **查重网关不冲突**：同一母题多平台分发 = 有意差异化改编，不算内容重复；**选新母题时才过查重**。
4. **各存各库**：脚本库 / 公众号草稿 / 小红书库 / 朋友圈文案库，各平台产出落对应位置。
5. **合规各自过**：小红书过10条红线、视频号过7类+医疗合规、公众号过7条——各平台红线独立检查，一个不过都不能发。

---

## 六、一键指令

> **"帮我把「痛点#X」做全平台分发"** → 自动按本矩阵出四平台内容：
> 视频号母版脚本 → 公众号长文 → 小红书图文 → 朋友圈文案，各走各管线、各存各库。
>
> - 默认全平台分发；例外：用户指定"只要小红书/只要朋友圈"等 → 只出指定平台
> - 执行顺序固定：先母版（视频号脚本）→ 其余三平台按矩阵改编
