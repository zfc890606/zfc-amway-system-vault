## 二、视频号医疗合规三条红线（强制 · 一票否决）

> **2026-08-09 锁死 · 违规定性（视频号官方）：** 医疗/大健康账号出现"疑似引导用户进行线上讨论/线下问诊/医疗教学"，判定存在不可控风险 → 禁止传播/限流，可申诉。
> **后果：** 账号限流、多条视频被拒。**这是全账号级风险，不只是单条话术的问题。**

### 0. 账号级前提（医疗/健康账号必须先完成职业认证）

**核心原则：无资质不科普。** 发布专业医疗健康内容，或账号名称/简介/背景图自称"医生""老中医"等职业身份的账号，**必须完成视频号职业认证**——否则账号本身即处于"无资质医疗科普"高危状态（这正是反复被判定"医疗教学"的深层原因）。

| 要求 | 内容 |
|------|------|
| 认证主体 | 个人：医生 / 医学教授 / 护士 / 药师等；机构：公立/民营医院机构认证 |
| 认证材料 | 医师资格证 + 医师执业证 + 医院在职证明（具体到科室）；平台通过卫健委官方渠道核验 |
| 身份一致性 | 出镜人 = 认证人 = 证照信息，三者必须一致；严禁资质出借/转让/买卖/挂靠 |
| 直播额外要求 | 健康科普直播需准入申请（有效期 1 年），直播间显著标明：①真实姓名 ②职称 ③执业证书编号 ④所在机构 |

> 提示：若你具备医学背景（医生/药师/护士等），优先完成职业认证，从根上解除"无资质医疗科普"风险。

### 三条红线（一条都不能碰）

| # | 红线 | 典型违规话术（❌） | 安全说法（✅） |
|:-:|------|------------------|--------------|
| 1 | **不引导线上/线下问诊** | "评论区留下你的情况，我帮你看看""私信我，把体检报告发我""想调理的来找我" | 只讲通用营养学常识与个人经验，不点对点给方案 |
| 2 | **不引导评论区公开讨论病情** | "你什么症状？评论区说说""你血糖多少？评论区告诉我" | "这条讲的是不是你的困惑？评论区聊聊你的看法" |
| 3 | **不引导平台外学医/领资料/收徒** | "加我微信领健康资料""关注公众号学调理方法""来跟我学中医" | "关注我，主页有更多健康科普"（留在平台内） |

### 全账号不留联系信息的位置（账号级）

> 账号头像 · 账号签名 · 账号简介 · 公众号名字 · 视频标题 · 视频定位 · 活动标题 · 直播预约标题 · 评论 · 音频标题 · 合集标题

### 脚本写稿四不

1. **不索要病情信息**：体检报告、指标、症状、用药情况——一律不主动要。
2. **不点对点给方案**："你这种情况应该…" → 改成"这种情况，日常可以参考…"（普适 + 免责）。
3. **不引导私信看诊**：医疗/营养内容里，"私信我"都别用，互动留在平台内。
4. **不加医疗资料钩子**："领资料"只可用于创业/AI 类非医疗内容，医疗内容一律不用。

### 互动钩子安全替换表（写结尾前对照）

| 场合 | ❌ 违规（引导问诊/谈病情） | ✅ 安全（纯认知互动） |
|------|------------------------|---------------------|
| 结尾互动 | "你卡在哪一步？评论区告诉我，我帮你分析" | "这条说的情况你遇到过吗？评论区聊聊看法" |
| 结尾互动 | "把你的情况发我，我帮你看看" | "你怎么看？评论区聊聊" |
| 结尾互动 | "评论区说说你的病/你的指标" | "健康科普仅供参考，个体情况请咨询专业医师" |
| 追更 | "关注我，私信我教你" | "关注我，下条继续拆" |
| 领资料 | "加微信领健康资料" | "关注我，主页有更多分享"（医疗内容不挂领资料） |

|------|---------|----------|

**官方明确点名"坚决打击"的医疗风险内容：**
- 主动引导用户咨询病症 / 引流至私人联系方式
- 引导用户描述病症并提供诊断建议、开展任何形式的在线问诊
- 无资质讲解具体疾病的治疗手段、用药方案、病理药理、检验报告分析（= 医疗教学）
- 编造医疗养生谣言、夸大普通食材功效、绝对化用语（包治 / 100% / 根除 / 根治）

**处罚阶梯：** 提醒教育 → 减少推荐 → 限流/下架 → 中断直播 → 禁播 → 取消"健康科普"资质 → 封号。

## 三、视频号 7 大类风险清单（逐项排查）

### 1. 健康功效类（⚠️ 最高风险区）

视频号重点打击的就是**虚假宣传功效**，这是红线中的红线。

| 违规类型 | 典型违规词 | 风险等级 |
|---------|-----------|:-------:|
| 宣称医疗功效 | 治病、消炎、降压、降糖、治疗、根治、痊愈、预防疾病、代替药品 | 🔴 封号 |
| 宣称保健功效（超出批准范围） | 减肥、瘦身、排毒、抗癌、疏通血管、修复细胞、改善睡眠（普通食品说这些不行） | 🔴 封号 |
| 绝对化功效承诺 | 100%有效、奇效、一吃见效、三天见效、无效退款 | 🟠 限流/下架 |
| 制造健康焦虑 | "你的细胞在饿""隐性饥饿""悄悄毁掉你的健康"——这类话术需谨慎，可能被判定为制造焦虑 | 🟠 限流 |
| 代替药物暗示 | "吃了就不用吃药了""比吃药安全" | 🔴 封号 |

**安全说法对照：**

| ❌ 危险 | ✅ 安全 |
|--------|--------|
| "降血糖降血压" | "日常饮食搭配参考" |
| "排毒减肥" | "体重管理、均衡膳食" |
| "调理身体"（普通食品慎用） | "日常保养、营养补充" |
| "治愈了我的XX病" | "我自己吃了之后感觉精力好了很多"（只讲个人感受，不承诺疗效） |
| "蛋白质能修复细胞"（可能被判定为伪医学） | "蛋白质是人体必需的营养素之一"（讲通用营养学常识） |

**安全区指南：**
```
✅ 可以说：
  - 通用营养学常识（"蛋白质是人体必需的七大营养素之一"）
  - 个人使用感受（"我吃了之后感觉精力好了"）
  - 产品成分介绍（但不与疾病关联）

❌ 不能说：
  - 任何与"治疗疾病"挂钩的表述
  - 暗示产品可以代替药物
  - 制造健康焦虑后立即推荐产品（会被判定为违规营销）
```

### 2. 绝对化用语类（容易忽略但违规）

| ❌ 违规 | ✅ 合规替换 |
|--------|-----------|
| 最、第一、全网第一、No.1、Top1 | 优质、精选、热门、口碑款 |
| 顶级、极致、完美、万能 | 高品质、受欢迎、实力推荐 |
| 唯一、首选、冠军、天花板 | 人气款、热门推荐 |
| 绝对、百分百、无敌 | 非常、很、相当 |

### 3. 收入承诺类（直销/创业类内容的重灾区）

内容涉及"创业""副业""收入"，是视频号金融类规则的敏感区。

| 违规类型 | 典型违规词 | 风险 |
|---------|-----------|:----:|
| 收入承诺 | 月入过万、月入五万、年入百万、轻松月入 | 🟠 限流/下架 |
| 稳赚不赔 | 稳赚、躺赚、保本、零风险、只赚不赔 | 🔴 封号 |
| 暴富诱导 | 暴富、一夜暴富、财富自由、快速致富 | 🟠 限流 |
| 诱导加盟 | 跟我干月入XX、招代理、拉人头 | 🔴 封号 |

**安全说法对照：**

| ❌ 危险 | ✅ 安全 |
|--------|--------|
| "我做安利月入三万" | "这是我个人的经历分享"（加声明） |
| "跟我做，月入过万不是梦" | "我把我的方法分享给你，你可以参考" |
| "稳赚不赔的副业" | "一个值得了解的创业机会" |
| "年入百万"（具体数字） | "收入上了一个新台阶"（模糊表述） |

> **核心原则：不讲具体收入数字，不讲"保证你能赚多少"。**

### 4. 引流导流类（视频号严查）

| ❌ 违规 | 说明 |
|--------|------|
| 视频中展示个人微信/QQ/电话 | 可在主页留"视频号小店"入口，不能直接留微信号 |
| 评论区引导"加我微信" | 会被判定为违规导流 |
| 用"领资料"诱导加私域 | 变相引流也会被处罚 |
| 私信群发广告 | 频繁被举报会导致功能受限 |

**合规做法：** 私信引导要留在**视频号生态内**——"私信我，我发链接给你"（指向视频号小店）、"关注我，下条告诉你"（留在平台内）、主页挂"视频号小店"入口。

### 5. 内容创作红线（2026 年新规）

| 规则 | 说明 |
|:----:|------|
| 🤖 AI 生成需标注 | 用 AI 生成的文案/画面，需要在显著位置标注"本内容由AI生成/辅助生成" |

### 6. 安利/直销类特殊注意事项

| 场景 | 风险 | 建议 |
|:----:|:----:|:-----|
| 讲"做安利赚钱" | 触达"收入承诺"和"诱导加盟"两条红线 | 不讲具体数字，讲方法讲逻辑 |
| 讲"产品效果" | 触达"健康功效违规"红线 | 只讲个人感受，不讲治疗功效 |
| 引导"加我了解" | 触达"违规引流"红线 | 引导到视频号小店或留在评论区 |
| 展示团队收入 | 触达"多层分销"敏感区 | 慎用，最好模糊化 |
| 讲"直销vs传销" | 本身不违规，但措辞不当会被判定为争议内容 | 用客观事实，不要激烈辩论 |

### 7. 发布前自检清单（3 分钟过一遍）

## 四、小红书 10 项风险清单（逐项排查）

> **与视频号核心区别：** 视频号红线在"功效虚假宣传"，小红书红线在"无资质不得提产品 + 不得导流"。前者管你说什么，后者管你是什么身份 + 往哪引流。**小红书审核比视频号更严，尤其健康类和导流类，发之前必须过。**

### 逐项排查表

| # | 风险类别 | 风险描述（❌） | 合规做法（✅） | 替换示例 |
|:-:|---------|--------------|--------------|---------|
| 1 | 宣称医疗功效 | 治病、治疗、根治、消炎、杀菌、抗癌、降压、降糖、药到病除 | 只做纯科普，不提产品 | "肝脏是人体重要的解毒器官……" |
| 2 | 营养素功效宣称 | "吃了XX睡眠变好了""补充XX营养""增强免疫力"——即使是真的，无资质也不准说 | 无资质不提及任何具体产品，只做纯科普 | 只讲通用营养常识，不点名产品 |
| 3 | 绝对化功效承诺 | 最有效、100%有效、无效退款、零风险、无副作用、永久有效 | 用温和、可验证的表述 | "这是我个人的日常习惯" |
| 4 | 减肥/瘦身类 | 减肥、瘦身、溶脂、燃脂、7天瘦X斤、不反弹、瘦脸 | 讲体重管理、均衡膳食 | "体重管理、均衡膳食" |
| 5 | 普通食品暗示功效 | 排毒、调理、改善体质、调节内分泌、抗氧化、抗衰老 | 只描述食物本身成分，不挂功效 | "每天一杯温水是我的个人习惯" |
