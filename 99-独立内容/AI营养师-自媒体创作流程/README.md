## 这是什么

本文件夹是**张医生（AI营养师）**自媒体创作系统的「产品化版本」——把主知识库中的创作引擎（选题 → 脚本 → 朋友圈 → 公众号 → 质检 → 复盘）整理成 **8 个可读手册**。

- ✅ **是**：一套完整的创作操作系统 + 指令表 + 模板 + 质检清单
- ✅ **是**：可直接教给伙伴复制的「方法论 + 工具清单」
- ❌ **不是**：内部流水线的机器日志

> 📌 核心思路：**"你负责出镜和判断，AI 负责找题、写稿、审核、发布。"**

## 🚀 怎么用这套系统

### 场景一：你完全不会拍，想开始
1. 读 [[00-系统总控台]] → 搞清楚全流程
2. 打开 [[01-选题库]] → 从 206 个痛点里挑一个
3. 说指令：**"帮我写脚本，第 X 号痛点"** → AI 按 02 的流程交付纯文案
4. 你出镜拍 → 发完 3 天说 **"帮我复盘"**

### 场景二：内容已经跑起来，想提效
- 文案复用 → [[03-脚本库]] 查历史脚本
- 朋友圈同步 → [[04-朋友圈文案系统]]
- 公众号长文 → [[05-公众号创作系统]]（AI 写完直接推草稿箱）

### 场景三：不确定能不能发
- 发布前必过 → [[06-质检合规清单]]（医疗合规三红线是一票否决）
- 特别提醒：**健康类账号先完成视频号职业认证**，无资质科普 = 账号级风险

## 🤝 给伙伴怎么复制

1. **复制整个文件夹**给对方（纯 md，任何笔记软件可开）
2. 对方只需要再装一个 **AI 工具（Claude Code 等）**，就能复现"说什么 → AI 做什么"的整套指令
3. 素材替换：把 [[01-选题库]] 换成 TA 自己赛道的选题，把 [[02-脚本创作系统]] 的风格铁律改成 TA 自己的口吻
4. 工具清单可参考 [[05-Skills（技能sop）/知识库教学套件/00-四步部署流程]]

> 💡 一句话：**给伙伴的不是脚本，是"会自己生长内容的系统"。**
