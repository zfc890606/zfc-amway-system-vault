## 三、脚本库使用说明

**脚本库是历史资产，可反复调用。三条用法：**

| 场景 | 怎么用 |
|------|--------|
| **写新脚本前查重** | 先说"帮我写脚本，主题是 XXX"前，先对照本章索引——已有同主题脚本就换角度或标注差异化，不重复写 |
| **拍之前找参考** | 按主题分类找到同类脚本，参考它的开场、结构、权威背书和结尾双钩怎么设计 |
| **复用爆款结构** | 标注「爆款标杆/爆款新拍」的脚本（如 script-033/034）是数据验证过的结构，新选题可以直接套同款框架 |

**几个约定：**

1. **编号规则**：安利脚本 `script-NNN`；AI 脚本 `AI-script-分类-编号`（A=操作 / B=认知 / C=AI+安利创业）。
2. **正文格式**：每条脚本都是纯口播文案 + 视频发布三件套（标题 / 简介 / 标签）+ 朋友圈转发文案 + 测试变量 + 权威文献锚点。
3. **查重网关**：写新脚本前，AI 会自动比对洞见卡库 + 知识卡片库 + 本脚本库，有重复先标注差异点再继续。
4. **标题说明**：索引中的标题为脚本原始标题（历史命名），个别标题用词为早期命名原貌，正文内容均按「营养素」统一表述。
5. **免责提醒**：脚本内营养健康内容均含免责声明，发布前请再次过第 06 章质检合规清单。
