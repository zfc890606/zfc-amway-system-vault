## 一、公众号写作规则系统（涨粉线 / 守IP线 双线）

> **一句话：** 公众号爆文 = **70% 选题 + 20% 大纲 + 10% 内容**。标题定打开率、开头定读完率、金句定转发率、**身份定涨粉天花板**。

### 1. 双阶段策略（写前先定线）

| 维度 | 阶段① 涨粉线（0→1000粉） | 阶段② 守IP线（1000粉+） |
|------|--------------------------|------------------------|
| **核心目标** | 让陌生人关注你 | 让粉丝信任你、期待你 |
| **内容侧重** | 认知价值、身份独占选题 + 国内外文献展开认证 | 专业深度 + 个人叙事 + 系列化 |
| **产品政策** | **零产品**（整篇不提产品名） | 可轻提及，但不推销 |
| **首选选题类型** | 行业揭秘 / 认知颠覆 / 争议科普 | 个人叙事 / 方法教学 / 系列专栏 |
| **结尾动作** | 引导关注 + 讨论 | 引导评论 + 收藏 + 转发 + 下期预告 |
| **核心指标** | 涨粉转化率、分享率 | 完读率、收藏复开率、互动率 |

> 📌 **记忆口诀：涨粉靠"身份+认知"，守IP靠"专业+故事"。阶段①不卖货，卖的是"这个人值得关注"。**

### 2. 选题规则（过卡才写）

**第一关 · 一票否决 3 问**（任一不过 → 换题）：

| # | 问题 | 怎么测 |
|:-:|------|--------|
| ① | **读者在问吗？**（答案焦虑） | 标题是不是读者心里正纠结的问题？ |
| ② | **只有你能讲吗？**（身份独占 · 删我测试） | 去掉你的身份，换个博主还能写吗？ |
| ③ | **有人搜吗？**（搜索词） | 微信搜一搜有没有大量同类问题？ |

**第二关 · 天花板打分 7 项**（≥6 写 / 4-5 改造后写 / ≤3 换题）：

人群宽度 × 争议性 × 具体靶子 × 转发对象 × 朋友圈友好 × 权威背书 × 传播原子

**公众号特增（比短视频多两条）：**
- [ ] **搜一搜验证**：搜一搜月活 8 亿，贡献约 27% 公众号涨粉——标题必埋读者会搜的词
- [ ] **保存价值**：清单/食谱/步骤类内容天然被收藏、截图、转家族群（健康赛道完读 + 分享双高）

### 3. 标题规则（5 步出标题）

```
① 合规红线过滤（一票否决）→ ② 选公式 → ③ 三要素检验 → ④ 搜一搜测试 → ⑤ 出3备选
```

**🥇 健康赛道 5 大公式（中老年已验证，主战场）：**

| 公式 | 模板 | 机制 |
|------|------|------|
| 症状+排查 | "晨起嘴里'发苦'，先排查这几种…" | 恐惧驱动 |
| 权威+禁忌 | "医生提醒：过了 XX 岁，宁愿 A 也别做 B" | 权威+禁忌 |
| 人群+共性 | "寿命短的男性，睡觉通常有 4 个'共性'" | 对号入座 |
| 自测+恭喜 | "没有这 5 个情况，说明身体保养得很好，恭喜" | 小焦虑+庆幸 |
| 排行+意外 | "睡前最养人的 5 个习惯，喝牛奶仅排第三！" | 悬念+反常识 |

**🥈 通用公式（已验证）：** 反认知 · 对比 · 共鸣 · 数字利益 · 比喻

**核心规律（500 篇 10 万+ 验证）：**
1. 制造认知缺口，别把答案写进标题（80% 爆款标题不给结论）
2. 数字要有参照物（"用这 3 个技巧，我每月多赚了五千" > "3 个技巧"）
3. 让读者在标题里看到自己（用生活片段，不用"慢病人群"这类标签）
4. "你"字放标题前 1/3（代入感不断层）
5. 标题 ≤30 字，口语化，像跟朋友分享八卦

### 4. 开头规则（黄金 8 秒，决定完读率）

> **三个留人密码：场景化别总结 / 冲突前置别铺垫 / 悬念钩子别剧透**

| 写法 | 案例 | 完读率 |
|------|------|:---:|
| ❌ 总结式 | "时间过得真快，转眼我已经 65 岁了……" | 12% |
| ✅ 场景式 | "那天晚上 10 点，我蹲在卫生间洗衣服，客厅传来儿媳的笑声……" | 87% |

**两种开头模板：**
- **模板A · 身份场景化（涨粉线首选）**：把专业身份揉进具体场景，不硬说"我是医生"
- **模板B · 痛点场景化（科普线首选）**：第一句就是读者熟悉的场景

**开头铁律：**
- 开头 3 句让读者"对号入座"——写读者经历过的事，再问"你是不是也这样"
- 直接告诉读者三点：**你要讲什么？为什么值得看？看完能得到什么？**
- 不写背景、不写心路历程、不开场白

### 5. 正文结构规则

**三种主结构（按目的选）：**

| 结构 | 适用 | 结构说明 |
|------|------|---------|
| ① 认知递进型 | 涨粉线首选 | 某件事 → 发现不是这样 → 再往深一层 → 原来如此；每层都是独立转发点 |
| ② 分装式并列型 | 转发线首选 | 一条文章 = 2-4 个"转发分装包"，每段独立成立、独立可转 |
| ③ 健康科普型 | 专业线 | 开头场景化 → 反常识暴击 → 权威背书 → 解决方案具象化 → 情感投射 → 结尾共鸣 |

> 分装测试：把中间任意一段单独截出来，能独立成立吗？给每段想好"转给谁"。

**段落规则：**
- 小标题是钩子：H2/H3 要吸引人，不是干巴巴的"第二部分"
- 峰终定律：开头抓人、结尾有力、中间至少一个"高潮点"
- 每段 3-5 行，移动端阅读要呼吸感
- 风格：土味比喻（至少一个生活化比喻）、老师式表达（允许自曝其短）、重复强调关键句

### 6. 传播原子（金句）规则

- 每篇 **≥2 个传播原子**（0 个金句 = 6 转发，3 个金句 = 26,716 转发）
- **包袱后放**：金句放中后部，先铺垫后引爆
- **检验**：观众能不能一句话完整转述这篇核心观点？不能 → 重写金句
- 金句类型：强比喻 · 惊人数据 · 金句翻转

### 7. 权威背书规则

| 目的 | 数量 | 来源 |
|------|:---:|------|
| 涨粉型 | ≥1 个 | 官方数据/医学指南/国家政策/专家共识 |
| 转发型 | 2-5 个 | 同上，越多转发者越有底气 |

> 公众号比短视频更好的点：可以直接放链接/出处，让转发者"有理有据"、零社交风险。

**📚 参考资料展示（强制）：**
- 每篇正文末尾附「参考资料」板块（放免责声明之前），列出核心权威来源 **3-7 条**
- 用读者可读格式：`机构/期刊 + 年份 + 一句用途`
- 完整 PMID/DOI 学术格式只存文件末尾内部记录（不推送）

**🧾 国内外文献随文嵌入（强制 · 展开式）：**
- 凡文章观点涉及某篇文献/研究/指南/官方数据，把文献展开成一段证据，用专业文献认证观点
- 写法三步：① 一句话说清观点 → ② 引出文献（机构/期刊/年份 + 研究怎么做、样本多大）→ ③ 结论落回观点
- 涨粉线 · 高增长选题 → 文献展开强制；方法教学/清单类 → 至少保留文末「参考资料」
- 原则：宁少勿假——只写真实可查的文献，不编造

### 8. 结尾规则（转发黄金地段）

```
① 金句收束（一句话总结全文）
② 互动钩子（具体到不用思考就能答）
③ 转发引导（"转给需要的朋友/家人"）
④ 下篇预告（守IP线必用，制造追更期待）
```

- ✅ "你家里是不是也囤了一堆过期营养素？"（随口能答）
- ❌ "你觉得专业重要还是人脉重要？"（要思考，没人回）
- 转发钩子写进正文：写稿时就埋"这份清单转给爸妈"

### 9. 排版规则（中老年友好）

| 元素 | 规范 |
|------|------|
| 正文字号 | 17-18px（中老年阅读友好） |
| 行距 | 1.75-2 倍 |
| 段落 | 每段 3-5 行，不超过 7 行，段间空行 |
| 小标题 | H2/H3 清晰，本身就是钩子 |
| 金句 | `> 引用块` 突出 |
| 强调 | 重点**加粗**，别整段加粗 |
| 图片 | 与内容一致，色彩统一；封面 2.35:1（900×383） |
| 标题 | ≤30 字，避免被截断 |
| 清单/食谱 | 用列表，天然带保存价值 |

### 10. 合规红线（一票否决）

| # | 红线 | 禁用示例 | 温和替代 |
|:-:|------|---------|---------|
| 1 | 不暗示疗效 | 治愈/特效/治疗/疗效/根治/康复 | 饮食上可以留意的 3 件事 |
| 2 | 不绝对化 | 最/100%/彻底/第一 | 很多人用错的方式，改一下更好 |
| 3 | 不健康恐吓 | 再不 XX 就晚了 | 换个方式对我 |
| 4 | 不引导问诊 | 把你的情况发我 | 只做认知分享 |
| 5 | 营养素 ≠ 药品 | 能治 XX 病 | 永远不写"能治 XX 病" |
| 6 | 敏感词缓冲 | 抗癌/补肾 | 配"公认/建议"等词 |
| 7 | 结尾免责 | — | 加"以上为健康科普分享，不构成诊疗建议" |

> 医疗健康类账号，任何一条触发 → 整篇重写。

### 11. 写作前自检清单

- [ ] 定线：这条走涨粉线还是守IP线？
- [ ] 选题：过一票否决 3 问 + 天花板 7 分 + 搜一搜 + 保存价值
- [ ] 标题：5 步出 3 备选（合规过滤 → 公式 → 三要素 → 搜一搜 → 3 选 1）
- [ ] 开头：场景化？3 句对号入座？
- [ ] 结构：认知递进/分装并列/健康科普，有高潮点？
- [ ] 金句：≥2 个传播原子？一句话能转述？
- [ ] 背书：涨粉 ≥1、转发 2-5 个权威来源？
- [ ] 文献随文嵌入：涉及文献的观点展开成证据段了吗？
- [ ] 结尾：金句收束 + 随口能答钩子 + 转发引导 + 预告？
- [ ] 排版：17-18px、行距 1.75、段落 ≤7 行、引用块？
- [ ] 合规：7 条红线全过？

## 二、选题决策卡 + 标题决策卡

### 1. 选题决策卡（定死规则）

**快筛 3 问（一票否决）：**

| # | 问题 | 动作 |
|:-:|------|------|
| ① | 读者在问吗？（答案焦虑） | 否 → 换题 |
| ② | 只有你能讲吗？（删我测试） | 换个博主也能写 → 换题 |
| ③ | 有人搜吗？（搜一搜有海量同类？） | 否 → 换题 |

**打分 7 项（每项 0/1）：**

| # | 打分项 | 说明 |
|:-:|--------|------|
| 1 | 人群宽度 | 覆盖人群够不够大 |
| 2 | 争议性 | 有没有讨论空间 |
| 3 | 具体靶子 | 有没有具体对象/商品/话术可拆 |
| 4 | 转发对象 | 读者会转给谁 |
| 5 | 朋友圈友好 | 转出去有没有"孝心 + 健康提醒"价值 |
| 6 | 权威背书 | 能不能找到权威来源支撑 |
| 7 | 传播原子 | 有没有可一句话转述的金句 |

> 结论：≥6 值得写 / 4-5 改造后写 / ≤3 换题。

### 2. 标题决策卡（5 步出标题）

> 文章写完后强制过这张卡 → 10 分钟产出 3 个备选标题（不同公式、不同角度）→ 选 1 个。打开率 90% 由标题决定。

**流程：**

```
① 合规红线过滤（一票否决，不过不发布）
→ ② 选公式（按优先级）
→ ③ 三要素检验（身份独占 × 利益点 × 好奇心，≥2 分过关）
→ ④ 搜一搜测试（读者会搜这个词吗？）
→ ⑤ 产出 3 个备选标题（标注公式 + 目标人群 + 转发对象）
```

**公式库（10 大公式 · 按优先级）：**

| 优先级 | 公式 | 一句话说明 | 营养线示例 | 创业线示例 |
|:--:|------|-----------|-----------|-----------|
| 🥇 | 反认知 | 颠覆常识，最抓眼球 | "医生为什么不给你开营养素处方？" | "做健康行业 6 年没上过班，我悟了 3 件事" |
| 🥇 | 对比 | 制造价格/认知反差 | "药店 9 块 9 vs 两百多的营养素，差在哪？" | "打工月薪 5 千 vs 自己做 5 万，差的不是努力" |
| 🥈 | 共鸣话题 | 替读者说出心声 | "体检报告正常，但你就是不舒服，对吗？" | "做过没做起来，不是你不行" |
| 🥈 | 数字+利益 | 具体可感 | "慢病人群最容易忽略的 3 个营养素" | "一部手机 3 件事就够了" |
| 🥉 | 俏皮话/比喻 | 土味比喻 | "把营养素当保健品，等于把汽油当香水" | "别再做搬运工，做管道工" |
| 🥉 | 拟人化 | 物当人说 | "你的肝在喊：换个方式对我" | "你的能力在报警：别光挂一档" |
| 🥉 | 修饰词 | 加情绪强化 | "这是医生最想让你知道的 1 个真相" | "这是我踩过最贵的坑，希望你别踩" |
| ⚠️ | 热点代入 | 蹭热点要合规 | "世界肝炎日，医生想跟你说句实话" | "AI 时代，普通人还有没有机会？" |
| ⚠️ | 负面词汇 | 损失感驱动，易踩恐吓 | 慎用，只用温和版 | "别再做无用功：很多人第一步就搞反了" |
| ⚠️ | 速成 | 给快速结果，易虚假承诺 | ❌ 营养类禁用 | "3 个方法，普通人也能上手" |

> 优先级：优先用 🥇🥈 类，🥉 做调味，⚠️ 类慎用（合规风险高）。

**三要素检验（≥2 分过关）：**

| 要素 | 检验问题 | 得分 |
|------|---------|:---:|
| 身份独占 | 标题里有"你的身份"独特视角吗？去掉身份还成立吗？ | 0/1 |
| 利益点 | 读者点开，明确知道能得到什么？ | 0/1 |
| 好奇心 | 有没有悬念，让人不点开难受？ | 0/1 |

**搜一搜测试：**
- [ ] 把标题核心词在微信搜一搜搜一遍 → 有海量同类 = 流量池在
- [ ] 用读者日常会搜的话，不是专业术语
- [ ] 搜出来的全是同行爆文 → 选题有戏，标题做差异

**产出 3 个备选标题：**

| 方案 | 标题 | 公式 | 三要素分 | 目标人群 | 转发对象 |
|:--:|------|------|:---:|---------|---------|
| A | | 反认知/身份独占 | /3 | | 转给____ |
| B | | 对比/数字 | /3 | | 转给____ |
| C | | 共鸣/比喻 | /3 | | 转给____ |

> 每个标题都要想好"转发对象"——读者会转给谁？转得出去才有传播。

**已验证高分标题（可直接套结构）：**

| 标题 | 公式 | 验证 |
|------|------|------|
| "医生为什么不给你开营养素处方？" | 反认知+身份独占 | 转发率 9.08%（全库第二） |
| "医生为什么不学营养学？" | 反认知+身份独占 | 37 万播放/5,671 涨粉（天花板） |
| "把营养素当保健品，等于把汽油当香水" | 比喻 | 转发率 11.75%（全库第一） |
| "药店 9 块 9 和两百多的营养素，到底差在哪？" | 对比 | 评论互动最高 |
| "为什么很多人很反感吃营养素？" | 共鸣+拆情绪 | 转发率 8.18%（全库第三） |

## 三、发布流程（AI 写作管线 → 配图 → 推草稿箱）

> **一句话：** 你说"把脚本X改成公众号，推到草稿箱"，自动跑完整管线：AI 写作引擎 → 质检三道关 → gzh-AI-Design 排版（暖蓝医养·中老年友好）→ 豆包 Seedream 自动配图 → 推送公众号草稿箱。你只需去后台 → 草稿箱 → 加封面图 → 发布。

### 1. 整条管线（3 Phase）

```
Phase 1：AI 写作引擎
  ├─ 读脚本/知识卡片/洞见卡 → 任务书（受众/问题/核心判断/反方）
  ├─ 主张清单（3-6 条）
  ├─ 草稿 → 审稿评分（5 项编辑评分）
```
