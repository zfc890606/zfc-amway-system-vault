# 🌱 180天重养计划 — 微信小程序（社群陪伴打卡）

> 发起人创建计划 → 伙伴凭邀请码加入 → 每天**早晚各拍照打卡一次** → 所有人共享一个**可视化打卡工作台**，用"一起坚持"的氛围带动伙伴。
> 技术栈：**微信小程序 + 微信云开发**（免服务器、免域名、免费额度够用）。

---

## ✨ 功能

| 模块 | 说明 |
|------|------|
| 🎟️ 邀请制加入 | 发起人创建计划拿到 6 位邀请码，伙伴输码+昵称加入 |
| 📷 早晚拍照打卡 | 每天早/晚各一次，拍照可配文字，也可不带照片只写句话 |
| 📅 180天打卡日历 | 6阶段 × 30 天格子（GitHub 风），早晚颜色深浅一眼看清 |
| 🏆 连续打卡排行榜 | 全员按当前连续天数排序，前三名上色 |
| 📊 完成率统计 | 全员完成率（早晚都算）+ 6 阶段趋势条 |
| 📣 今日动态 | 今天谁打了卡、拍的照片实时刷出来（30 秒轮询） |
| 🌿 180 条重养提示 | 6 大阶段主题，每天一条"今日重养小提示" |
| 👤 我的 | 个人日历格 + 连续/最佳/打卡/完整统计 + 最近打卡明细 + 改昵称 |

## 🚀 快速开始（4 步）

1. **改两处配置**：`project.config.json` 的 `appid`、`miniprogram/app.js` 的 `env`（云环境ID）
2. **建数据库**：云开发控制台新建 `plans` / `members` / `checkins` 三个集合，权限全选「仅创建者可读写」，按 [[数据库设计]] 建索引
3. **部署云函数**：微信开发者工具 → 右键 `cloudfunctions/` 下每个函数 → 「上传并部署（云端安装依赖）」，共 7 个
4. **上传设体验版**：开发者工具「上传」→ 公众平台设体验版 → 体验成员加伙伴 → 发起人外发邀请码

详细步骤见 → [[部署指南]]

## ⚠️ 内容合规（社群内部用也要守）

- **不涉及医疗**：180 条提示全部是"生活方式陪伴"（作息/运动/情绪/关系），不写诊疗建议、不承诺疗效
- **不对外收集敏感信息**：只存昵称 + 打卡照片，不存姓名/电话/身份证；照片仅对加入计划的伙伴可见
- **照片权限**：存储保持「仅创建者可读写」，工作台照片由云函数转临时链接加载，无需开放公共读权限；请确保只有你信任的伙伴拿到邀请码
- 若以后要正式公开上架：需要企业主体 + 微信认证（300元/年）+ 对应类目资质，社群内部用体验版即可
