# 🩺 慢病案例库 — 微信小程序（团队内部工具）

> 张医生团队慢病管理案例库：手机随手记 → AI 自动归类到板块 → 醒目标题 → 好搜好调。
> 技术栈：**微信小程序 + 微信云开发**（免服务器、免域名、免费额度够用）。

---

## ✨ 功能

| 功能 | 说明 |
|------|------|
| 🧩 板块归类 | 肥胖 / 痛风 / 糖尿病 / 高血压 / 免疫 / 症状管理 / 其他，首页 Tab 切换 |
| 🤖 AI 自动归类 | 粘贴案例文字 → AI 自动分板块 + 起醒目标题 + 提取客户画像与指标 |
| 🔍 搜索 | 按关键词搜标题 / 主诉 / 指标 |
| 📋 详情 / 编辑 / 删除 | 完整案例记录，团队内可共同维护 |
| 📊 统计 | 各板块案例数、我录入的案例数 |
| 👥 团队共用 | 所有读写走云函数，体验版分发给团队伙伴即可 |

## 🚀 快速开始（3 步）

1. **改两处配置**：`project.config.json` 的 `appid`、`miniprogram/app.js` 的 `env`（云环境ID）
2. **部署云函数**：微信开发者工具 → 右键每个云函数 → 「上传并部署（云端安装依赖）」
3. **配置 AI 密钥**：`classifyCase` 云函数 → 环境变量 → 添加 `AI_API_KEY`（[DeepSeek 开放平台](https://platform.deepseek.com/) 注册拿 Key，几块钱够用很久）

详细步骤见 → [[部署指南]]

## ⚠️ 合规红线（团队内部用也要守）

- **脱敏**：案例只存化名 + 年龄段，不存客户全名、电话、身份证等
- **不承诺疗效**：记录为「生活方式干预复盘」，不写"治愈""保证见效"
- **不对外**：本工具仅团队内部学习使用，不对外提供诊疗建议；未公开上架前用「体验版」分发即可，无需医疗类目资质
- 若以后要公开上架给顾客：需要企业主体 + 微信认证 + 医疗健康类目资质，或改走「健康记录工具」角度
