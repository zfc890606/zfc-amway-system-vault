# 企业微信微盘素材读取 · 接入指引

> 目标：读取企业微信微盘里的文件/图片素材（培训资料、产品图、课件等），供 AI 营养师整理、调用。
> 工具位置：`99-独立内容/企业微信微盘工具/`
> 完成时间：约 10 分钟

---

## 📌 你需要准备的三样东西

| # | 凭证 | 哪里拿 | 放在哪 |
|---|------|--------|--------|
| ① | **企业ID（CorpID）** | 企业微信管理后台 → 我的企业 → 企业信息 → 企业ID | config.json → `corpid` |
| ② | **应用Secret** | 企业微信管理后台 → 应用管理 → 自建应用 → 创建应用 → Secret | config.json → `corpsecret` |
| ③ | **微盘接口权限** | 应用管理 → 自建应用 → 接口授权 → 勾选「微盘」 | 后台操作，无需填入 |

---

## 🪜 三步操作

### 第一步：拿企业ID
1. 电脑登录 [企业微信管理后台](https://work.weixin.qq.com/wework_admin/loginpage)
2. 左侧菜单 → **我的企业** → **企业信息**
3. 复制 **企业ID**（一串字母数字，如 `ww1234567890abcdef`）

### 第二步：创建自建应用 + 拿Secret
1. 左侧菜单 → **应用管理** → **应用** → **创建应用**
2. 填应用名称（如"AI营养师素材库"）、选择可见范围（建议选你自己即可）
3. 创建后进入应用详情页 → **Secret** 旁边点「查看」→ 用微信扫码验证后复制
4. 记下 **AgentId**（应用详情页顶部，后续扩展用）

### 第三步：授权微盘权限
1. 在**同一个自建应用详情页** → 往下找到 **「API接收消息」上方 / 「微盘」权限**
2. 具体位置：**应用管理 → 自建应用 → 接口授权 → 找到「微盘」→ 点击授权**
3. 或者：**微盘** 是独立应用，在「应用管理」里找到「微盘」→ 设置 → 添加 API 使用成员
4. 确保应用对微盘有**读权限**（能列出空间、文件、下载）

## ⚙️ 填入配置

用文本编辑器打开：

```
99-独立内容/企业微信微盘工具/config.json
```

把 `corpid` 和 `corpsecret` 替换成你的真实值：

```json
{
  "corpid": "ww1234567890abcdef",
  "corpsecret": "你的Secret字符串"
}
```

## ✅ 测试

终端运行：

```bash
cd "99-独立内容/企业微信微盘工具"

# ① 测试凭证是否有效
python3 wedrive_read.py token

# ② 列出所有微盘空间
python3 wedrive_read.py spaces

# ③ 列出某个空间的文件
python3 wedrive_read.py files <spaceid>

# ④ 下载某个文件到本地
python3 wedrive_read.py download <fileid> ./下载的素材
```

如果第①步显示 `✅ token 获取成功`，就说明接通了！

## ⚠️ 安全提醒

1. **Secret 相当于应用密码**：泄露后别人能用你的企业身份发消息/读数据。不要发到群里、不要截图外传。
2. 建议**可见范围只设你自己**，后续要开放给伙伴再加。
3. 如果 Secret 泄露，在后台**重置 Secret** 即可，然后更新 config.json。
4. config.json 包含敏感信息，**不要放进 git / 不要发给我之外的人**。
