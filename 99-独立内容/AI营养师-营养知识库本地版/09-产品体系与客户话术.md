## 一、纽崔莱品牌历史与有机种植哲学

### 1.1 品牌缘起：来自东方的灵感

纽崔莱（Nutrilite）品牌始于 1915 年，创始人卡尔·宏邦作为牛奶公司商务代表来到中国，在上海生活、工作长达 12 年。他的三个关键观察促成了品牌革命性的营养理念：

1. **紫花苜蓿的价值**：关注紫花苜蓿（"草头"）的营养价值，最早将其运用到膳食补充剂中。
2. **阶层与健康的反差**：以肉类和白米为主食的城市富人常患脚气等疾病，而以菠菜和糙米为主食的农民却很少患病，由此萌发"研制营养补充品来平衡膳食"的理念。
3. **中医药的启发**：对中国"药食同源""天人合一"理念产生浓厚兴趣，萌生了"植物营养素（Phytonutrients）"的概念。

**核心洞察**：土壤养分是植物营养的基础——精耕法导致土壤养分流失，进而影响植物营养密度。卡尔·宏邦坚信"几乎人类需要的所有营养，都能在植物中找到"，这一信念坚持了 90 余年，成为纽崔莱最核心的品牌护城河。

### 1.2 品牌关键时间轴

| 年份 | 里程碑 |
|------|--------|
| 1915 | 卡尔·宏邦首次来到中国，关注紫花苜蓿 |
| 1919–1927 | 在上海观察中国人饮食与健康，萌生营养补充理念 |
| 1934 | 研制出世界第一款从植物提取的多种维生素/矿物质营养补充食品 |
| 1939 | 更名"纽崔莱产品公司"，品牌正式推出 |
| 1942 | 买下第一家自有农场，提出"纽崔莱农耕规范"，倡导免化学农药的有机种植 |
| 1948 | 王牌产品"倍立健片"诞生 |
| 1972 | 进入安利大家庭 |
| 1998 | 重返中国市场，首款产品为蛋白粉 |
| 2015 | 无锡安利（中国）植物研发中心建成 |
| 2024 | 纽崔莱创立 90 周年 |

### 1.3 有机种植哲学：四大自有有机农场

纽崔莱坚持"从种子到成品"的全链条有机管控，是全球唯一在**自有有机农场种植、采收、加工植物原料**的维生素及膳食补充剂品牌。

| 农场 | 位置 | 规模 | 特点 |
|:----|:----|:----|:----|
| 巴西农场 | 巴西 | 24,870 亩 | 巴西首个国家认证有机农场 |
| 鲑鱼湖西农场 | 美国 | 2,434 亩 | 北美最大有机草本农场之一 |
| 鲑鱼湖东农场 | 美国 | 5,256 亩 | 有机沙质土壤，哥伦比亚河灌溉 |
| 培塔可农场 | 墨西哥 | 9,645 亩 | 墨西哥政府指定模范有机农场 |

- 四大自有有机农场总面积超过 **37,900 亩**。
- 全球 **150+ 家合作认证农场**，中国超过 **50 家**认证农场。
- 有机种植方式：天然肥料 + 豆科植物固氮 + 蚯蚓养护土壤；实行休耕；严禁化学农药，用金盏花、大蒜提取杀菌杀虫剂，释放瓢虫等益虫；用地下水/江河湖水灌溉，以人造卫星系统监测水质。

### 1.4 科研实力与行业贡献

- **种子资源**：1956 年起探索种子最佳来源，建立业界最大的品种资源库，前瞻性开展航天育种。
- **国家科研**：两度参与国家"十三五"重点科研项目——助力长江中下游土壤环境改善、参与中药保健产品行业标准建立。
- **DRIs 标准修订（三度独家支持）**：
  - 2013 年：全球首次将植物营养素纳入居民营养素摄入标准；
  - 首创预防非传染性慢性病的营养素建议摄入量；
  - 2023 年：再度新增 6 种植物营养素。
- **前沿合作**：与斯坦福大学共建健康生活实验室；开发"神农"AI 系统；与中国航天合作航天育种。

### 1.5 品牌理念与质量管理

- **品牌理念**："自然的精华，科学的精粹"。
- **生产标准**：以制药的标准生产——一片倍立健需通过 **272 项检测**；每批产品通过 **300 多种**质量测试。
- **研发积累**：超 **60 项**人体临床试验、**190 多项**专利、**300 多篇**学术研究；通过 GMP 质量管理认证。
- **信任背书**：全球销量领先的维生素和膳食补充剂品牌；中国奥委会 **15 年合作伙伴**（运动员食品检测标准比普通食品严格约 300 倍，15 年通过每一次检测）；2016 年获中国食品七星经典奖。
- **公益行动**：2015 年"为 5 加油"计划，为 3–5 岁贫困地区儿童提供学前营养改善。

## 二、纽崔莱全谱产品修复体系与剂量配平

> 📌 **2026 年 7 月新版简化方案（当前默认）**：精简为 **5 款产品**——蛋白粉 6 勺 + 男士组合 2 包 + 新款高纯鱼油 4 粒 + 针叶樱桃维 C 1 片 + 天然维生素 B 片 1 片（已移除钙镁片、小麦胚芽油维 E、基源欣活）。本章以下内容为**全谱修复体系（深度修复存档方案）**，用于理解完整产品逻辑；实际执行以最新简化方案为准。

### 2.1 蛋白质赤字对冲逻辑

**现代膳食三大隐性缩水**：

1. **养殖缩水（15–20%）**：速生肉高水分、高脂肪、低营养密度。
2. **烹饪变性（20–30%）**：高温 + 劣质油 → 美拉德反应 → AGEs 毒化 → 蛋白无法被蛋白酶剪切。
3. **消化卡壳（20%）**：慢病人群胃酸普遍不足 → 大分子蛋白无法离子化吸收。

**实际到账率**：一个自认为"天天吃肉"的上班族，标称 55g 蛋白质，细胞实际到手仅约 25g。而慢病修复需要 1.2–1.6g/kg（60kg 成人 = 72–96g），赤字高达 50–70g。

> ⚠️ **注意**：此处"kg"应指**去脂体重/理想体重**。超重/肥胖者禁用实际体重，需先用校正体重法算出基数再套用（详见 KC-营养-059）。

### 2.2 蛋白质剂量决策树（石汉平教授 ONS 共识）

| 阶段 | 剂量 | 适用人群 | 配平方案 |
|------|------|---------|---------|
| 基础维持 | 1.0g/kg | 健康稳定期 | 正常饮食 |
| 慢病修复 | 1.2–1.5g/kg | 基础慢病调理 | 膳食 60g + 3 勺蛋白粉 24g |
| 深度修复 | 1.6–2.0g/kg | 严重少肌/顽固平台期 | 膳食 60g + 5 勺蛋白粉 40g + 夜间基源欣活 |

**安全前提（一票否决）**：先看肾功能与胃肠消化力。CKD 3 期及以上肾病患者严格限 0.6–0.8g/kg，且必须全用优质植物蛋白，不能冲高。

| B 族成员 | 修复目标(TRD) | 产品实际叠加 | 结果 |

| B9 | 800–1000μg | 300 + 130×3 = 690μg + 膳食 | 约 900μg 黄金区 |

> ⚠️ B12 提示：常规组合全天仅约 11.5μg，用于普通调理（降低同型半胱氨酸）足够；但糖尿病神经病变等严重神经损伤需额外追加临床级活性甲钴胺（500–1000μg）。

### 2.4 钙镁配平：重镁轻钙策略

- 慢病人群钙不超 800mg，镁提到 500–800mg。
- 镁作为天然钙通道阻滞剂死守细胞膜，防止钙超载。
- 配平示例：倍立健（170mg 镁）+ 3–5 片钙镁片（83mg/片）= 419–585mg 镁。

## 三、汉本萃系列：中西精粹养生体系

### 3.1 营养进化与中医五脏对应

**营养进化趋势**：基础营养 → 精准营养 → 基因 → 养生（专业化 + 生活化双轨）。

**汉本萃核心理念**：更直接、更简单、更有效。每个配方对应一个脏腑功能，从护眼（葆明）到养胃（葆蔚）到润肺（清润）到补肾（葆源），形成完整的中式养生营养方案矩阵。

**中医五脏对应表（五行体系）**：

|------|-----|-----|-----|-----|-----|
| 五行 | 木 | 火 | 土 | 金 | 水 |
| 五色 | 青 | 红 | 黄 | 白 | 黑 |
| 五味 | 酸 | 苦 | 甘 | 辛 | 咸 |
| 开窍 | 目 | 舌 | 口 | 鼻 | 耳 |
| 五谷 | 麦 | 稷 | 黍 | 稻 | 菽 |

### 3.2 六大产品体系

#### ① 葆明 · 护眼（肝开窍于目）

**核心配方**：
- 黑加仑：改善眼部微循环，促进眼部营养供给；
- 杭菊：散风清热，平肝明目；
- 枸杞：滋补肝肾，益精明目；
- 叶黄素 10mg + 玉米黄质 2mg（人体无法合成）。

**临床数据（90 天科研试验）**：视疲劳改善 81%；明视持久度改善 81%；眼睛干涩改善 67%；黄斑色素光密度显著提升。

**适用人群**：长期看屏幕、眼干眼涩、视力减退、老年黄斑变性风险人群。

#### ② 活妍 · 气血（心主血、脾统血）

**核心功能**：补气养血（人参 + 传统补气药材）、增强免疫、改善贫血、改善微循环、促进美白。

**滋阴安神延伸（妍续年轻态）**：融合山药、短梗五加等传统养生智慧，滋阴润燥、安神除烦；科研试验显示配方组对卵巢与卵母细胞有一定保护作用（卵巢损伤程度小于对照组，卵母细胞更饱满、结构更清晰）。

**适用人群**：气血不足、面色萎黄、乏力、手脚冰凉。

#### ③ 清润 · 肺（肺主气）

**核心功能**：益气润肺、提升肺功能、保护动脉、抗氧化。

**中医理论**："诸气者，皆属于肺""肺朝百脉"（《黄帝内经·素问》）；东方"气"对应西方"免疫系统"，正气存内，邪不可干。

#### ④ 葆蔚 · 胃（脾胃为后天之本）

**核心功能**：养胃护胃；保护胃黏膜（分泌黏液形成保护屏障）；抑制幽门螺杆菌；提供黏膜细胞所需营养物质。

**中医经典**："百病皆有脾胃衰而生""胃气为养生之主，胃强则强，胃弱则衰"。

**常见胃部不适**：食欲不佳、消化不良、打嗝、反酸、胃胀、胃痛。

#### ⑤ 葆源 · 肾（肾属先天）

**核心功能**：精气神三补。
**中医理论**："肾藏精，精生髓，精髓化血"。

#### ⑥ 灵芝 · 仙草级全能选手

**核心成分**：灵芝多糖 + 灵芝三萜；归心、肺、肝、肾四经。

**四大功能**：
- 双向调节免疫：增强免疫细胞活性 + 维稳减少过敏；
- 保肝护肝：改善脂肪肝，减轻各类肝损伤，减轻肝纤维化；
- 润肺平喘：扶正固本，改善肺气亏虚；
- 养心安神：调节大脑神经递质，可安神助眠。

**品质保证**：99% 破壁技术（充分释放活性成分，更易吸收）；546 项农残零检出；道地赤芝，中国/美国/欧盟/日本四大有机认证（纽崔莱金牌农场）。

### 3.3 使用建议

1. 先用中医辨证判断体质方向；
2. 再匹配对应的汉本萃产品；
3. 每个配方都需结合基础营养方案（如灵芝可配合护肝计划使用）。

## 四、2.0 护肝计划（28 天肝脏修复方案）

### 4.1 肝损伤的常见原因

肝损伤的健康问题日益普遍，常见原因包括不良生活习惯等带来的肝脏代谢负担。WHO 报道全球乙肝人数 2.57 亿，中国乙肝人数已超 1 亿——养肝护肝势在必行。

### 4.2 护肝计划修复机制

| 营养 | 作用机制 |
|------|---------|
| 维生素 C | 针对化学性肝损伤，强力抗氧化，帮助肝脏解毒，清除自由基，给肝脏减负 |
| 维生素 B | 提高肝脏代谢能力，应对不良生活习惯引起的肝损伤 |
| 养脏善衡片 | 含白灼甘草，滋养肝血，调理肝脏功能，应对各类损伤 |
| 蛋白质粉 | 作为肝脏修复的氨基酸原材料，促进肝细胞再生，恢复肝脏功能 |

### 4.3 28 天执行方案

1. **晚餐吃养肝餐**：不吃或少吃肉，多吃蔬菜（水果少吃），可吃鸡蛋；
2. **19:00–21:00 护肝计划**：VB 护肝 + VC 解毒 + 善衡片养肝 + 蛋白粉；
3. **23:30 前睡觉，24:00 进入深睡眠**：启动肝脏修复机制；
4. **持续 28 天**。

## 五、长客会签约底层逻辑（从观念引导到数据说服）

### 5.1 核心问题与底层逻辑链

**最大痛点**：签约容易续约难、客户容易断签。很多人拼命讲优惠，但客户买了也坚持不下来。**更深层的问题是：客户不认为自己每天都需要吃营养素**——他觉得"今天可以吃，明天可以不吃"。

**为什么有效**：当客户算清楚自己的"营养缺口"，他会意识到：不是我愿不愿意吃的问题，是我每天都需要补上这个缺口。长客会从"我要你买"变成"你帮自己一个忙"——客户从被动接受变成主动选择。

**底层逻辑链**：

```
隐性饥饿（细胞在挨饿）
  → 每天都需要补充营养素
  → 长期坚持需要经济划算
  → 长客会以更经济的长期方式供应
  → 因为划算所以坚持
  → 因为坚持有效果所以愿意分享
  → 市场自然裂变
```

### 5.2 四步沟通法

**第 1 步：建立认知——你为什么会生病？**
- 从细胞层面讲：人由细胞组成，细胞的原材料是 7 大营养素；
- 中国人的饮食结构普遍失衡（碳水超标、蛋白质/水/维生素不足）；
- 关键话术："你不是突然生病的，是每天欠了身体的债，几十年累积出来的。"

**第 2 步：数据冲击——算你的"营养缺口"**
- 水：体重(kg) × 30ml——算出来每天缺多少；
- 蛋白质：体重(kg) × 1.22g——算出来每顿饭缺多少；
- 关键话术："你看看你早上吃的，能不能达到 25 克蛋白质？吃不到那么多，你上午脑子转不动、容易累、容易饿，就是这个原因。"

**第 3 步：解释机制——为什么吃了没效果？**
- 生命器官（心肝肺肾大脑）vs 非生命器官（皮肤、头发、伤口）；
- 营养不够时，全部被生命器官截走——所以你吃一勺蛋白粉（8 克）没感觉，因为你缺口 34 克；
- 关键话术："不是产品没用，是你的身体在'战时配给'——先保命，再管美，轮到皮肤的早就没了。"

**第 4 步：给出方案——长客会是"每天吃"的机制**
- 基础配方：蛋白粉 + 维 C + 男士活力组合；
- 长客会通过持续的月度供应与积分机制，让长期坚持补充在经济上更划算；
- 关键话术："你不是在花钱买营养素，你是用更划算的方式，把每天的营养缺口补上。长客会只是帮你把这个习惯固定下来——就像每月交话费一样自然。"

### 5.3 破除常见顾虑

**客户说："我怕每个月寄过来吃不完。"**

回应："那是因为你还没算清楚你每天需要多少。你来算算——你体重多少？每天需要多少蛋白质？现在吃到了多少？……你看，你每天缺口这么大，你还怕吃不完？你是不够吃！"

### 5.4 适用场景与边界

**适用场景**：
- 老客户聊续约/断签时；
- 新客户对长客会有顾虑（怕囤货、怕吃不完）；
- 客户说"安利产品太贵了"；
- 客户说"我吃过，没效果"；
- 团队伙伴问"长客会推不动怎么办"。

**边界条件**：
- **什么时候不适用？** 客户经济条件确实非常困难（真吃不起 vs 觉得没必要是两个不同的问题）。
- **常见失败原因？** 一上来就讲优惠、跳过观念直接推方案。
- **需要什么前提条件？** 你首先要理解并能讲清楚"隐性饥饿"的逻辑，自己先认真吃。

## 六、慢病管理破局框架（临床控标 × 健康管理治本）

### 6.1 底层逻辑

**慢病管理的正确姿势是"两条腿走路"**：

| 维度 | 临床医疗 | 健康管理 |
|------|---------|---------|
| 职责 | 控制指标、延缓损伤、防并发症（保命） | 解决病因、生活方式重塑、营养干预（治本） |
| 作用点 | 对症处理，未触及病因 | 直接作用于病因 |
| 结果 | 有底线价值，但停掉药指标易反弹 | 从根源上有机会逆转 |

**底层逻辑链**：
1. 慢病的病根 = 生活方式（高血压→盐+压力；糖尿病→饮食+运动；痛风→代谢+饮食），不是"缺药"；
2. 临床医疗的职责 = 对症处理——有价值，但没作用到病因；
3. 不解决病因 = 治不好；
4. 健康管理 = 针对病因——管生活方式、做营养干预、重塑饮食/运动/压力；
5. 结论：临床控标（守底线）+ 健康管理治本（求逆转），两条腿缺一不可。

### 6.2 执行步骤与话术

**最小行动**：跟任何"三高/指标高"的人讲一句话——**"指标是医生管，病因是你管。"**

**完整执行步骤**：
1. **立框架**：先分清"控标"和"治本"——医院负责控标（保命），生活方式负责治本（逆转）；
2. **找病因**：把某一慢病拆到生活方式上（高血压→盐+压力；糖尿病→饮食+运动；痛风→代谢+饮食）；
3. **讲局限**：药和手术能降指标，但停掉药指标反弹，因为病根没动；
4. **给方案**：营养干预 + 生活方式重塑 + 运动，直接作用于病因；
5. **给希望**：不是让你停药，是两条腿走路——药保命，营养 + 生活方式争取逆转。

**话术模板**：
> 医院把你的血压从 160 降到 140，那是保命；但你要的可能是有一天不用天天吃药——那部分，医院给不了，得从生活方式和营养干预里拿。

### 6.3 边界条件

- **绝对不否定医疗**：药物/手术控制指标是保命底线，必须强调"两条腿走路"；
- **不做诊疗承诺**：说"有机会逆转/恢复"，不说"保证停药"（医疗合规）；
- **个体差异**：以专业评估为准，本文是认知框架而非处方。
