## 这是什么

本文件夹是**张医生（AI营养师）**的营养知识库「产品化版本」——把主知识库中散落在各目录的**约 200 个营养相关文件**，去重合并成 **11 个主题化 md 文件**。

- ✅ **是**：一套系统、可检索、可直接讲给顾客听的营养知识体系（理论 + 方案 + 机制 + 产品 + 话术 + 文献 + 书籍）
- ❌ **不是**：客户个案集（不含真实客户信息）
- ❌ **不是**：价格/促销政策文件

> 📌 纯 Markdown 格式，任何笔记软件 / 文本编辑器都能打开。内部 `[[链接]]` 指向原知识库，仅供溯源参考。

## 🚀 怎么用

### 1. 学习路径（新人）
```
先读 01（观念）→ 02（慢病方案）→ 03（轻断食）
再按需查 04 / 05（机制深度）
```

### 2. 顾客沟通
| 场景 | 打开哪个文件 |
|------|-------------|
| 讲健康观念 / 打破"没病就不用管" | 01 + 07 金句 |
| 客户有慢病（三高/糖尿病/痛风/脂肪肝） | 02 |
| 客户要减重 / 控糖 | 03 |
| 客户问"到底缺什么、怎么补" | 04 + 10（DRIs速查表） |
| 客户要产品方案 | 09 |

### 3. 写内容（短视频 / 公众号 / 朋友圈）
- 开头/结尾金句 → **07**
- 核心知识框架 → **01-05 + 06**
- 权威背书 / 文献出处 → **08**
- 产品话术 → **09**

### 4. 查资料
- 快速查证一个知识点 → **06**（卡片索引式）
- 查营养素参考量 → **10** 的 DRIs2023 速查表

## 🤝 怎么分享给伙伴

1. **直接复制**：整个文件夹复制给对方即可（纯 md，Obsidian / Typora / 语雀 / 飞书文档都能打开）
2. **转 docx / PDF**：需要可打印版本时，用脚本打包规则转成文档
3. **伙伴拿到后三步上手**：
   - ① 先读 README 了解结构
   - ② 按 [[00-知识入库流程]] 把 TA 自己的新知识加进来
   - ③ 这套系统就变成 TA 自己的 AI营养师知识库

> 💡 给伙伴的价值主张：**别人给你一仓库文件，你给你一套知识操作系统。**
