# 00 · 知识入库流程

> **新知识进库五步：查重网关 → 提炼洞见卡 → 4K知识卡片 → 朋友圈文案 → 选题更新**
> 任何新内容（读书 / 听课 / 文章 / 灵感 / 案例）进来，都走这套流程，保证知识库**不重复、有结构、能用起来**。

---

## 📊 流程总览

```
新内容进来
   │
   ▼
╔════════════════════════════╗
║  STEP 1  🔍 统一查重网关     ║
║  查：已有洞见卡 + 知识卡片    ║

║  无重复 → ✅ 继续           ║
╚════════════════════════════╝
   │
   ▼
STEP 2  🃏 提炼洞见卡（DJ-*）   ← 一句话金句 + 即用方法
```

## STEP 1 · 查重网关（强制）

| 对比库 | 查什么 | 有重复怎么办 |
|--------|--------|-------------|
| 洞见卡库（DJ-*） | 核心金句 / 洞见 | 跳过，或改写差异化角度 |
| 知识卡片库（KC-*） | 核心框架 / 认知 | 跳过，或改写差异化角度 |
| 已有脚本 / 选题库 | 选题角度 / 内容结构 | 标注差异点再继续 |

> ⚠️ 这是第一步，**不是最后一步**。查重不过，后面的流程不跑。

---

## STEP 2 · 提炼洞见卡（DJ-*）

**一句话洞见**，核心是「科普比喻 + 金句」。

```markdown
---
tags: [洞见, 营养]
---

# DJ-营养-XXX 标题（一句话本质）

> **一句话洞见**：……
> （用比喻把复杂知识说成人话，比如"血管像水管""肝脏是化工厂"）

**给客户一句大白话：** "……"

**适用场景：** 短视频开场 / 朋友圈 / 客户沟通
```

- 每条 **只装一个点**
- 金句要能**原样说出口**，不需要解释就能懂

---

## STEP 3 · 4K 知识卡片（KC-*）

内容够深时，把洞见卡升级成完整知识框架（四要素 4K）：

| 要素 | 回答的问题 |
|------|-----------|
| ① 一句话本质 | 这张卡片的核心结论是什么？ |
| ② 因果 / 原理 | 它解决什么问题？为什么有效？（可含数据、机制、表格） |
| ③ 可执行方法 | 最小行动是什么？完整执行步骤？ |
| ④ 场景与边界 | 适用场景？不适用/禁忌？ |

```markdown
# 《XXX》

> **一句话本质**：……

## 🧩 因果 / 原理
- 解决了什么问题？
- 为什么有效？（数据 / 机制 / 出处）

## 🛠 可执行方法
### 最小行动（今天就能做）
### 完整执行步骤

## 📍 场景与边界
### 适用场景
### 边界条件

## 🔗 关联
- 来源：
- 相关卡片：[[KC-营养-XXX]]
```

**分类前缀**：
- 营养 / 健康 / 产品 → `KC-营养-*`
- 创业 / 安利 / 认知 → `KC-创业-*`
- 短视频 / 内容 / 流量 → `KC-视频-*`
- 团队 / 领导力 → `KC-团队-*`
- 底层认知 / 思维模型 → `KC-认知-*`

---

## STEP 4 · 朋友圈文案（可选）

内容够"出圈"时，同步生成朋友圈文案（PYQ-*）：

- **一条一点**：一条只讲一个点
- **口语聊天**：像跟朋友说话，不教学
- **开头有钩子**：第一句抓人
- **转发对象明确**：写给谁看的，心里有数

> 注意：朋友圈文案**不搬视频脚本原文**，要重新写。

## STEP 5 · 选题更新

判断这条知识**适不适合做短视频**：
- 是高频痛点？ → 进 [[痛点排行榜]]
- 是 AI / 工具方向？ → 进 [[AI选题库]]
- 更新后标记：`已入库 → 选题#XX`

---

## 📌 规范备忘

1. **名词统一**：全文用「营养素」，不使用旧行业称谓（除非引用原话）
2. **用词严谨**：不写绝对化承诺（"包治 / 100%"），用"有助于 / 研究表明 / 可能"等保守表述
3. **不收录客户个案**：真实客户姓名、体检数据、联系方式一律不进知识库
4. **每条知识留来源**：读书 / 听课 / 文章，写清楚出处，方便溯源
5. **金句进 07、框架进 06**：新卡定期合并进 [[06-知识卡片全集]] 和 [[07-洞见金句全集]]
