# 📊 谢医生 · 全营养轻断食体重数据

> 数据来源：谢医生自行记录的"全营养轻断食"打卡表
> 测量方式：轻断食日及复食日第二日早上上完厕所，空腹称体重

---

## 📋 说明

- 每次轻断食记录 **2个数据点**：轻断食当日 → 复食日第二日（反映轻断食效果）
- 数据格式：`体重(斤) / BMI / 体脂率 / 内脂等级 / 蛋白质%`
- ⚠️ 原始数据中第7次、第8次的复食日日期疑似笔误（标为1.17），已按规律修正

### 关键发现

| 指标 | 变化 | 分析 |
|:----:|:----:|:----|
| 🏋️ **体重** | 182.1 → 167.6 斤（▼14.5） | 平均每周减 ~1.8 斤，健康可持续 |
| 🫁 **内脂** | 13 → 10 级（▼3级） | **最佳成果**——内脏脂肪大幅减少，降低慢性病风险 |
| 📉 **体脂率** | 29.7% → 22.3%（▼7.4%） | 减重同时体脂率同步下降，无肌肉流失迹象 |
| 🥩 **蛋白质** | 15.3% → 17.1%（▲1.8%） | **蛋白质稳步上升**，说明肌肉量在保持/增长——轻断食方案执行到位 |

### 波动规律
- 每次轻断食后减重 **1.0~3.2 斤**，平均每次有效减重 **~1.6 斤**
- 轻断食日之间有回升（非轻断食日体重回弹 0.5~2 斤），属正常生理波动
- 第2个月减重速度放缓但**体成分持续优化**（内脂继续降、蛋白质继续升）
